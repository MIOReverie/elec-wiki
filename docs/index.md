## 课程

四门课是有先后的：电工学 → 数字电路 → 模拟电子 → 嵌入式。后一门直接用前门的结论，运放建立在电路定律上，外设时序建立在数电上，所以按这个顺序读最省力。

只想让手上那块 STM32 动起来，可以走[嵌入式](/embedded/)课程主页里的「动手派」路径（07 → 13 → 10 → 11），缺哪块用正文里的**前置胶囊**就地补。

> 临时板块（学完删）：需要复习线性代数时从这里进入，两版并行。[现代结构](/linalg/)按 Strang/3Blue1Brown 几何直觉先行，[经典结构](/linalg-classic/)按同济《线性代数》顺序、计算方法与解题步骤先行；两者相互独立，也与四门电学课相互独立，复习完即可移除这个入口。

## 从这里开始

对号入座，三行里挑一行，只点那一行：

- 完全零基础，想按顺序学：起点是学习地图里的[阶段 0 · 电学入门与安全](/map#stage-0)，4–6 小时，先认识电压电流和「哪些动作会受伤」。开读前花 20 分钟过一遍[符号与约定](/guide/notation)：虚数单位为什么用 $j$、小写与大写（瞬时值 / 有效值）、相量头顶那个点，这三处读错，后面每一页都会跟着错。
- 一周内要考试：不用按顺序读。翻[公式速查表](/shared/cheatsheet)，加上每章的核心小节与例题；具体挑哪几章，地图的速通路线已经列成清单。
- 手上有板子或舵机，想先做出东西：直接进[项目专题](/topics/)，按页面顶部的前置章节回头补；也可以从[实验与仪器](/lab/)的三小时上手清单开始，先学会量，再谈做。

想先看清全站结构再决定，走[学习地图](/map)：四门课、实验和专题被排成 0 到 7 八个阶段，每段写明读哪几页、大概多久、怎么算过关，文末一张按目标选行的决策表。站里的四个交互约定（前置胶囊、可拖参数的演示、图解、搜索）收在[怎么用这个站](/guide/start)，4 分钟读完。

## 这个 wiki 怎么用

路线定了以后，剩下的动作都是查：

::: tip 三个查的入口
- 查一个词：点右上角搜索（或按 <kbd>Ctrl</kbd> + <kbd>K</kbd>），中文按 2-gram 分词，输「戴维南」「转差率」都找得到；词条本身收在[术语与前置知识索引](/guide/glossary)。
- 查一条公式：[公式速查表](/shared/cheatsheet) 按主题分组，每条给了符号、SI 单位与适用前提，页内 Ctrl/⌘ + F 再搜一次。
- 查某一页在哪：[全部页面](/guide/pages) 是完整索引，适合「我记得见过但想不起来在哪个课程」的时候。
:::

## 这里有什么，没有什么

站里有四门课的正文、可以拖参数的演示、前置知识卡片、公式速查表、依赖图谱，还有一份[内容状态表](/guide/status)。这份表由脚本扫描正文生成，会告诉你哪几节已经能当教材读，哪几节还只是提纲；标记了「核心」但内容偏薄的章节也写在里面，不会拿「敬请期待」盖过去。

它是一份个人学习笔记，不是教材的替代品：考纲里偏冷门的部分没有覆盖，例题的答案也谈不上标准。正文整理自秦曾煌《电工学》、康华光《电子技术基础》等教材，引用和勘误见[关于本站](/guide/about)。
