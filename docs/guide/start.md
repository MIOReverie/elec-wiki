# 怎么用这个站

## 选一条路径

| 你的情况 | 走这条 | 大概耗时 |
| --- | --- | --- |
| 第一次学，要能做题 | 课程主页 → 从 01 顺序读 → 每章做演示、做例题 | 电工学约 12 h |
| 考前一周，只求骨架 | 每章「结论先行」+「考点速记」+ [公式速查表](../shared/cheatsheet) | 约 6.5 h |
| 学过但忘了，想补漏 | 先看[依赖图谱](../ee/graph)，从卡住的那章读起 | 按需 |

## 三个交互约定

**1. 前置知识胶囊**
正文里像 <span class="demo-chip">💡 戴维南定理</span> 这样的小胶囊，点一下从右侧滑出卡片：先是一句话摘要，下面是完整卡片。按 <kbd>Esc</kbd> 或点「继续阅读」回到原处——**页面滚动位置不会丢**。

**2. 演示（DemoBox）**
带「交互演示」标签的框里，滑块、按钮都可以动，图形会实时重算。建议先自己拖到极端值（比如把负载拖到 0、把频率拖到谐振点），再看正文的解释——比先读结论印象深。

**3. 图解（FigBox）**
图解框下面是图注，写的是「这张图想让你看见什么」。公式和图对不上时，以图为准，然后回来改公式。

**4. 搜索**
右上角搜索框或 <kbd>Ctrl</kbd> + <kbd>K</kbd>。中文按 2-gram 分词，输入「戴维南」「转差率」「卡诺图」都能命中；支持拼音首字母以外的模糊匹配，但**不支持拼音**。

## 页面上的标注

| 标注 | 含义 |
| --- | --- |
| 🔴 核心 | 必读，考试与后续章节都依赖 |
| 🟡 了解 | 看结论和公式即可，推导可跳 |
| 🟢 可跳过 | 与其它课程重叠或偏专题，学过直接跳 |
| ⏱ 约 30 min | 按「读结论 + 做演示 + 看例题」估的时间，不含自己做题 |
| 本页更新于 … | 来自 git 提交时间；只改过格式也会更新 |

## 外观与打印

- 右上角的 ☀/🌙 切换浅色/深色；默认跟随系统。
- 公式、表格、演示都适配了窄屏；侧边栏在手机上收进左上角「课程目录」。
- 打印页面时会自动隐藏导航与侧边栏，表格与公式保留——[公式速查表](../shared/cheatsheet)可以直接打成 A4。

## 遇到问题

- 公式渲染错位、图不显示：翻到页面底部看是否有更新提示，或在[关于与版权](./about)里找反馈方式。
- 内容有错：请指出章节与那句原话，比「感觉不对」有用得多。
