# B 站网课推荐

<Meta time="10 min" level="指南" note="四门课八个视频链接，都是逐条查过 B 站公开数据才写进来的" />

本站是文字笔记，演示和例题能让你自己动手，但**推导过程、老师的口音与板书节奏、现场画波形的那几步**，视频还是更省力。这一页把四门课对应的公开网课列出来，每条都标了体量（分 P 数、总时长）与播放量，方便你按时间预算挑。

数据由维护者在 2026-10-21 用 B 站公开接口逐条核验：分 P 数、时长、播放量都按当天的返回值原样记录，没有估、也没有凑整。

## 结论先行：三种读法怎么配视频

| 你的处境 | 视频怎么用 | 主要看哪几条 |
| --- | --- | --- |
| **时间紧**（考前、临时要用） | 只看单集或速成片段，不追整套 | 舵机那一集、单集舵机专题；考哪章搜哪章的单集 |
| **系统学**（第一次学，要能做题） | 跟一套完整课，配本站章节做例题 | 模拟电子的国家精品版、电工学教材课、数电的 56 集 |
| **做项目**（要动手做出东西） | 边做边看，缺什么补什么 | 江协科技 STM32 入门 + 陈加油嗯的舵机专题 |

一句话：**视频负责「过程」，本站负责「结论 + 动手验证」**。先读本站结论建立直觉，再让视频把推导讲一遍，最后回来做例题——顺序反了，往往看完视频还是不会算。

上半的播放量与搬运源一样偏低，属于典型的「链接还在、内容不一定稳」的情况。**搬运源不稳定，搜「哈工大 电工学 姜三勇」找最新上传**，别认死某一条链接。

怎么配合本站用：先读各章「结论先行」，把 KCL/KVL、三要素法、相量这些骨架立起来，再看视频里老师一步步推；视频讲到某个例题时暂停，自己先算，再对答案。章节对应关系：直流部分配 [01 基尔霍夫定律](../ee/01-basics/kcl-kvl)，暂态配 [三要素法](../ee/03-transient/three-factor)，正弦稳态配 [相量法](../ee/04-ac/phasor)，三相配 [三相电路](../ee/05-three-phase/circuit)；下半的电机部分配 [异步电动机](../ee/06-machine/induction-motor)。

| [同课高清版（国家精品）](https://www.bilibili.com/video/BV1W7411B7BQ) | 清华 · 华成英 | 56 个分 P，约 41.8 小时 | 约 6.2 万 | 同样的课，想要看得清的板书 | [模拟电子 · 课程主页](../analog/) |

第一条画质偏低（480×360），板书和特性曲线经常糊成一片；播放量高说明它是很多人第一眼找到的那版。两条内容一致，**只是清晰度不同**，看长视频建议直接走国家精品版。

怎么配合本站用：模电的难点不是概念而是「一张曲线图上三四个量同时动」，先在本站把 [三极管工作状态](../prereq/bjt-regions)、[静态工作点与负载线](../prereq/q-point-loadline) 这两个胶囊点开，建立「曲线 + 负载线」的图像，再去看华老师推放大倍数，你会跟得上得多。每看完一段回来做 [基本放大电路](../analog/amplifiers) 与 [运算放大器](../analog/opamp) 的例题，公式自己动手代一遍，比看视频里代一遍有用。

这套课的节奏偏讲课式：板书清楚、例题多，最后一段的课后题精讲只有 6.9 小时，是「做完作业对答案」的用法，不适合当独立课程听。

怎么配合本站用：数电最怕「听课全懂、化简全错」，所以顺序倒过来更有效——先在本站做一遍 [逻辑代数与卡诺图](../digital/boolean-kmap) 的交互演示，把圈组规则变成手上动作，再看视频里老师怎么处理带无关项的卡诺图；[门电路](../digital/gates) 与 [组合逻辑](../digital/combinational) 两章看完后，用课后题精讲核对解法。时序部分别只看视频，本站 [触发器](../digital/flip-flops) 的波形演示能让你一眼看出建立保持时间错在哪。

江协这套是入门里播放量最夸张的一条，讲法是「新建工程 → 写代码 → 下载看现象」，几乎没有理论铺垫，正好和本站相反。舵机在 P16 里只占合集的一小段，主讲的还是 PWM 呼吸灯与直流电机；陈加油嗯那条 23.5 分钟的单集则把「PWM 配参 → 写 CCR → 接线供电」压缩在一条视频里，适合临时救急。

怎么配合本站用：先看本站 [定时器与 PWM](../embedded/timer-pwm) 弄清楚 CNT 与 CCR 到底在比什么，再跟视频配一遍参数，你会发现你比视频多知道「为什么是 PSC 71」；到舵机时，视频里的接线一旦跳过电源细节，就回来读 [13 · 舵机控制](../embedded/13-servo-control) 的供电与共地部分——那里讲的是视频里最常被省略、却最容易烧板的一段。

## 怎么自己判断一门课值不值得看

三个五分钟就能做完的检查，比看播放量靠谱：

1. **先看目录是否覆盖你的缺口**：把「分 P 列表」当目录扫一遍，找你现在卡住的那几个关键词（比如「转差率」「卡诺图无关项」「PWM 互补输出」）。目录里没有，播放量再高也帮不上你；有但排在很后面，就只跳着看那几集。
2. **看前 3 集的节奏**：前 3 集决定你能不能坚持。判断标准不是「讲得深不深」，而是**有没有一上来就给结论、有没有随讲随写例题**。如果前 3 集都在铺垫历史与定义，而你又时间紧，换一门。
3. **看有没有配套讲义、代码或习题**：有讲义/课件/源码的课，你可以在视频外自己复现，学习效率通常高一档；只有嘴讲的课，看完一遍很容易什么都不剩。本站列的这几门里，江协科技有配套资料与代码，数电那套有课后题精讲，正好对应不同用法。

再补一条容易忽略的：**看更新与合集状态**——分 P 是否齐全、有没有标「已完结」、最近有没有评论说某集失效。这些都决定你花 40 小时之后能不能把课听完。
