# 这个站是什么

<Meta time="3 min" level="指南" note="先弄清楚它是什么，再决定怎么读" />

这是一个**个人维护的电学学习 Wiki**：四门课（电工学、数字电路、模拟电子、嵌入式开发）的正文、公式、图解和可交互演示放在同一个站里，互相链接、按课程组织。

它不是教材的电子版，也不是题库。它解决的是三个具体问题：

1. **时间有限时，先读什么** —— 每节都标了「核心 / 了解 / 可跳过」和预计耗时，课程主页给了速通、系统、补强三条路径。
2. **看不懂的前置知识，不用跳走** —— 正文里的胶囊按钮点开就是一张前置知识卡片，读完按 <kbd>Esc</kbd> 回到原处。
3. **结论记不住，想验证** —— 50 处可拖参数的 DemoBox 演示（背后是 44 个仿真组件），把公式变成能自己动的东西。

## 内容范围

| 课程 | 章节数 | 定位 |
| --- | --- | --- |
| [电工学](../ee/) | 22 节 + 3 节数电速览 | 强电与工程视角的主线 |
| [数字电路](../digital/) | 9 节 | 从数制到 AD/DA、Verilog 与 FPGA 的离散逻辑 |
| [模拟电子](../analog/) | 10 节 | 从器件到直流电源、传感器的连续信号 |
| [嵌入式开发](../embedded/) | 13 节 | STM32 外设、RTOS 与舵机控制 |
| [项目专题](../topics/) | 5 页 | 电源、电机驱动、舵机云台与电力电子入门，把课程知识做成东西 |
| [实验与仪器](../lab/) | 5 页 | 万用表、示波器、焊接与实验台安全，动手前先过一遍 |

项目专题与实验仪器不是第五、第六门课：它们以四门课（尤其模拟电子与嵌入式）的结论为前置，把「会用公式」推到「会搭、会测、会调」——课上没讲透的器件与电路，在专题里按项目串起来，仪器与安全页则是动手前的公共底座。

除此之外还有三类工具页：

- [公式速查表](../shared/cheatsheet)：全部公式、单位、符号约定，考前扫一遍；
- [知识依赖图谱](../ee/graph)：哪一章依赖哪一章，用来排顺序；
- [内容状态与成熟度](./status)：由构建脚本扫描正文生成，直白写出每节写到什么程度。

## 写作原则

- **结论先行**：每页开头先给能直接用的结论，推导只放在理解必需的地方。
- **数字要能验算**：例题里的数值都自己算过；能画图的不用文字描述。
- **不装作完整**：没写透的章节会在[内容状态](./status)里标出来，而不是用「敬请期待」糊过去。
- **可溯源**：内容基于秦曾煌《电工学》、康华光《电子技术基础》等教材整理，引用与勘误见[关于与版权](./about)。
