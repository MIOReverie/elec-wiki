# 隐私与免责

<Meta time="2 min" level="指南" note="一个纯静态站点的隐私说明可以很短，这里把它写全" />

## 数据收集：没有

这个站是**纯静态站点**：全部页面在构建期生成后丢到静态托管上，没有后端服务器、没有数据库、没有账号系统。访问本站时：

- **不留姓名与联系方式**——没有注册、登录、留言表单，想联系作者请走 GitHub issue（见[关于与版权](./about)）；
- **不用 Cookie**——站点自身不设置任何 Cookie；
- **不加载第三方脚本**——没有统计（Analytics）、没有广告、没有字体/CDN 外链，页面引用的全部资源都随站点同源部署；
- **不追踪访问者**——没有埋点，没有指纹采集，服务器侧如果有访问日志，也归静态托管平台（如 GitHub Pages / Cloudflare Pages）的默认策略管，与本站无关。

## localStorage 的用途

唯一的本地存储是 VitePress 默认主题写入的一个键：

| 键 | 内容 | 用途 |
| --- | --- | --- |
| `vitepress-theme-appearance` | `light` / `dark` / `auto` | 记住你选的浅色 / 深色外观 |

它只保存在你自己的浏览器里，不上传、不同步、不参与任何统计。清除浏览器站点数据即可删除。

搜索索引（本地搜索用的）在浏览器内存里完成检索，关键词不会发往任何服务器。

## 强电安全免责

本站内容用于**学习与复习**，不能替代教材、课程标准或工程规范。特别提醒：

- 涉及**强电操作**（220 V 市电、三相电、电机控制）的内容仅为原理讲解，实操必须遵守现行国家标准（GB）与设备手册，在具备资质和断电、验电、放电等安全措施的条件下进行；
- 器件选型、参数计算、安全距离等数据请以厂商数据手册与最新国标为准，本站例题数字只为教学演示做了简化；
- 依据本站内容进行实验、施工或设备改造造成的任何人身与财产损失，本站不承担责任。
