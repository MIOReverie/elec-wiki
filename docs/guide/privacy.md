# 隐私与免责

<Meta time="2 min" level="指南" note="纯静态站点能收集的东西本来就不多，这里把话说全" />

站上没有后端。页面在构建期生成完就是一摞静态文件，没有数据库、没有账号系统，也没有哪段服务端代码在跑。

所以下面这几件事都做不了，不是承诺，是结构上就没有：

- 不留姓名与联系方式：没有注册、登录、留言表单，想联系作者请走 GitHub issue（见[关于与版权](./about)）；
- 不用 Cookie：站点自身不设置任何 Cookie；
- 不加载第三方脚本：没有统计，没有广告，没有字体或 CDN 外链，页面引用的资源全部随站点同源部署；
- 不追踪访问者：没有埋点，没有指纹采集。托管平台（GitHub Pages、Cloudflare Pages 这类）自己的访问日志归平台管，与本站无关。

## 本地只存一个键

VitePress 默认主题会往 localStorage 写一个值，用来记住你选的外观：

| 键 | 内容 | 用途 |
| --- | --- | --- |
| `vitepress-theme-appearance` | `light` / `dark` / `auto` | 记住你选的浅色 / 深色外观 |

它只待在你自己的浏览器里，不上传、不同步、不参与任何统计。清掉浏览器站点数据就没了。

搜索也一样：索引在浏览器内存里检索，关键词不发往任何服务器。

## 强电安全免责

这里的内容供学习与复习用，替代不了教材、课程标准或工程规范。有几条得单独提醒：

- 涉及强电操作（220 V 市电、三相电、电机控制）的部分只讲原理。真上手必须按现行国家标准（GB）与设备手册来，并且具备资质、做好断电验电放电；
- 器件选型、参数计算、安全距离这些数据，以厂商数据手册与最新国标为准。站里例题的数字为了讲清楚做过简化；
- 照着这里的内容做实验、施工或改设备，出了人身与财产损失，本站不承担责任。
