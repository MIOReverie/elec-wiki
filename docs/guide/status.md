## 为什么有这一页

一个学习站最容易骗人的地方是「看起来什么都有」。所以这一页不写「已全部完成」，而是把每节的实际内容量摊开：**多少字、几道例题、几个演示、有没有易错清单**。数字从 Markdown 源文件里数出来，每次构建都会重算。

## 判定标准

| 列 | 含义 |
| --- | --- |
| 字数 | 去掉代码块与 HTML 标签后的正文非空白字符数 |
| 例题 | 形如 `::: tip 例 N · …` 的例题块数量 |
| 演示 / 图 | `<DemoBox>` 与 `<FigBox>` 的个数 |
| 结 / 错 / 工 | 是否含「结论先行」「易错点」「工程实例」三个模块 |
| 成熟度 | **完整**：≥3000 字且 ≥4 道例题；**够用**：≥1800 字且 ≥2 道；**偏薄**：其余 |

「偏薄」不代表内容错，只代表它目前更像**提纲**：够用来复习结论，不够用来第一次学。

## 怎么用这张表

- **第一次学**：优先挑「完整」的章节精读；「偏薄」的先看别的资料，或用本站的结论 + 速查表兜底。
- **复习**：三列全绿的章节可以只扫「结论先行」和「易错点」。
- **想参与**：从「偏薄」且你正好在学的章节开始补，比从头写新章更有价值——见[写作与贡献指南](./contributing)。
