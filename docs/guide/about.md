# 关于与版权

<Meta time="3 min" level="指南" note="内容从哪来、能不能转载、发现错误找谁说" />

一个个人维护的电学学习站，非官方、非商业，跟任何出版社、学校都没有关系。正文是学习笔记的整理，演示在浏览器里现算，没有后端，也没有埋点与广告。

- 维护者：[MIOREverie](https://github.com/MIOREverie)
- 技术栈：VitePress 1.6 + Vue 3 + KaTeX。图形与仿真全部手写 Canvas 或 SVG，没有引入图表库。
- 构建：每次提交由 GitHub Actions 跑内容检查、死链检查与静态构建。

## 内容来源

正文按下面这些教材的章节顺序与术语搭骨架，文字用自己的话重写，另外补了演示、例题和工程实例：

- 秦曾煌《电工学（第七版）》上、下册，电工学课程主线
- 康华光《电子技术基础（数字部分 / 模拟部分）》，数字电路与模拟电子课程主线
- 王兆安《电力电子技术》、Cortex-M 与 STM32 参考手册，整流与嵌入式相关章节

公式、定律、器件参数属于公有知识；正文表述、图示、例题与演示代码是本站自己整理的。哪段文字看着和教材原文高度雷同，请指出来，我改写。

## 勘误与反馈

指错的时候，把章节、原句、你认为正确的说法一起给出来，比说一句「这里不对」有用得多。渠道优先这两个：

1. 在 [GitHub](https://github.com/MIOREverie) 提 issue；
2. 如果你是从朋友那里拿到这个站的，直接把章节链接和截图发回去。

确认之后我会改正文、补说明，页脚保留 git 更新时间。这个站没有版本号，只有提交历史。
