17 · 机械特性 · 起动 · 调速 ​

核心 约 45 min起动方式是本章最常考的内容；调速则是变频器时代的看家本领

稳定运行区在哪 ​

TTT-sss 曲线以 sms_msm​ 分界：

  • 0<s<sm0 < s < s_m0<s<sm​：稳定区（负载转矩变大 → sss 变大 → 电磁转矩变大去平衡它，自收敛）

心智模型：机械特性 = 一张「可查」的曲线

把整章归结成一句：一台异步电机的全部行为都画在 TTT-sss 这一张曲线上，而这条曲线只由 TmaxT_{max}Tmax​、sms_msm​ 两个参数决定。所以每道题的起手式都一样——先在曲线上定位当前工作点（由 nnn 或 sss 算出），再判断它在稳定区（s<sms<s_ms<sm​，自收敛）还是不稳定区（s>sms>s_ms>sm​，直到堵转）。起动、调速、制动，本质都是问「怎么把这条曲线或工作点掰到我想去的地方」。

工程实例 ​

变频器怎么让一台老电机"起死回生"？ 风机、水泵改成变频驱动后，流量用转速调而不是用阀门挡 —— 省掉的正是被阀门消耗的那部分功率（功率 ∝ 转速³，流量减半时功率只剩 1/8）。这是目前最大的电机节能市场。

软启动器是什么？ 晶闸管调压的启动装置，本质上就是"连续可调的降压启动"，按斜坡把电压升上去，起动电流限制在 2~3 倍 INI_NIN​。比 Y-△ 平滑，比变频器便宜，适合不需要调速但要软起/软停的场合（水泵、压缩机）。

易错清单 ​

  1. TmaxT_{max}Tmax​ 与 R2R_2R2​ 无关 —— R2R_2R2​ 只移动它的位置（sms_msm​）
  2. 降压启动降的是转矩的平方，重载一定起不来
  3. Y-△ 启动的前提：电机正常运行是 △ 接 + 负载轻
  4. 变频调速必须同时调压保持 U/fU/fU/f，否则低频磁通过饱和
  5. Kloss 公式解出的两个 sss 根，取小于 sms_msm​ 的
  6. 起动电流大 ≠ 起动转矩大（cos⁡φ2\cos\varphi_2cosφ2​ 的锅，见第 16 章 · 三相异步电动机原理）
  7. 串励/绕线式转子串电阻是"既限流又增矩"的唯一方法，但只适用于绕线式
