07 · 定时器与 PWM ​

核心 约 48 minPSC / ARR 忘了 +1、改了 ARR 没同步改 CCR、死区换算用错基准——这三个错占了定时器问题的大半

这一页要解决什么：代码里写 Prescaler = 71; Period = 999;，你以为得到 1 ms，示波器上量到 1.001 ms；给舵机调角度时顺手改了 ARR，结果舵机自己飘到别的角度；同一个定时器一边输出电机 PWM、一边在中断里改 CCR，波形偶尔抖一下。这三件事问的是同一句话：三个寄存器里到底谁决定什么，改动一个会连带影响哪些东西。读完这一页你应该能：从目标频率反解出 PSC 与 ARR、算出占空比与它的最小步进、用输入捕获测频率、配置互补输出并算出死区该填多少，并且知道中心对齐模式为什么会让频率变成一半。

读这页之前

  • 需要会：频率与周期的倒数关系（f=1/Tf=1/Tf=1/T）；百分比与整除的估算；十六进制与寄存器位域（）。这一页的数学只有乘除，没有微积分。
  • 这一页用到的符号：fTIMf_{TIM}fTIM​（送进定时器的时钟）、fcntf_{cnt}fcnt​（计数频率，PSC 分频之后的那个）、PSC（预分频寄存器）、ARR（自动重装载寄存器 auto-reload）、CNT（当前计数值）、CCR（捕获 / 比较寄存器 capture-compare）、tDTSt_{DTS}tDTS​（死区计数的单位时间）、DTG（死区发生器寄存器的 8 位字段）。含义总表见符号与约定。
  • fTIMf_{TIM}fTIM​ 从哪来：见 。要特别记住一条：APB 预分频不为 1 时，挂在该总线上的定时器时钟会自动 ×2，忘了这一条所有时间都差一倍。
  • 四个词先给一句话：预分频（prescaler）是把输入时钟除以一个整数；自动重装载（auto-reload）是计数器数到某个值就回零；占空比（duty）是一个周期里高电平所占的比例；死区（dead time）是互补的两路输出之间强行插入的「都关断」空档。正文第一次遇到时逐个展开。

先看三个真实场景。第一：想用定时器做 1 ms 中断，按手册写了 PSC = 71、ARR = 999，示波器上却是 1.001 ms——多出来的那 1 个计数就是「数到 ARR 就溢出」这句话里那个 +1。第二：舵机本来稳在 90°，为了让 PWM 更细腻把 ARR 从 19999 改成 9999，同一句 CCR = 1500 立刻让舵机转到了别的角度——因为占空比等于 CCR/(ARR+1)CCR/(ARR+1)CCR/(ARR+1)，分母变了。第三：电机驱动里上下两管互补输出，示波器上看到偶尔出现一个尖峰电流，炸掉了一颗 MOS 管——那不是干扰，是两管同时导通的直通。

三件事的共同点：定时器只有三个旋钮，但它们互相牵连。这一页先把三个旋钮各自的作用说清楚，再谈怎么用它们拼出定时、PWM、测频与互补驱动。

结论先行 ​

  1. 定时器本质是一个可配置的计数器：时钟经 PSC 分频得到计数频率，CNT 从 0 数到 ARR 就溢出并产生更新事件，因此周期 T=(PSC+1)(ARR+1)/fTIMT=(PSC+1)(ARR+1)/f_{TIM}T=(PSC+1)(ARR+1)/fTIM​。
  2. 三个寄存器分工不同：PSC 决定「一格多长」、ARR 决定「一轮有多少格」、CCR 决定「一轮里在哪一格翻转」。三个公式里全都有 +1。
  3. PWM 是「CNT 与 CCR 比较」的产物：占空比 =CCR/(ARR+1)=CCR/(ARR+1)=CCR/(ARR+1)；改 CCR 只影响本通道，改 ARR 或 PSC 会影响该定时器的所有通道和溢出频率。
  4. 频率与分辨率此消彼长：fPWM×级数=fcntf_{PWM}\times\text{级数}=f_{cnt}fPWM​×级数=fcnt​。两个都要，唯一出路是抬高 fcntf_{cnt}fcnt​（减小 PSC）。
  5. 互补输出必须插死区：死区是两管同时关断的空档，防的是上下管直通短路；它会吃掉有效占空比，取手册最小值加一点余量即可，不是越大越安全。

心智模型：三级流水线，四个数决定一切

时钟定下「一拍多长」，PSC 定下「一个计数多长」，ARR 定下「数到哪里算一轮」，CCR 定下「一轮里哪一段是高」。所有时间参数都是这四个数的函数，没有第五个旋钮。

这条模型能解释三个常见困惑：为什么改 ARR 会让舵机角度漂（分母变了）；为什么改 CCR 波形不会抖（新值下一轮才生效）；为什么中心对齐模式频率只有一半（一轮要走两趟，先上后下）。

一、三个组成部分：PSC、ARR、CCR 各管什么 ​

这一节只回答一个问题：三个寄存器分别决定什么，为什么公式里都有 +1。

定时器内部可以分成三块，各管一段：

部分寄存器作用
时基单元PSC、ARR、CNT产生时间基准：多久数一次、数到多少算一轮
捕获 / 比较通道CCRx输出 PWM（比较）或测量外部信号（捕获），每个通道一套
时钟与触发内部时钟 / 外部脉冲 / 其他定时器决定计数来源，可实现级联与同步

为什么每个公式都有 +1：PSC 是「分频系数减一」。硬件做的是「数到 PSC 就发一次计数脉冲」，从 0 数到 71 一共 72 次，所以实际分频比是 PSC+1PSC+1PSC+1。ARR 同理：CNT 从 0 数到 ARR 一共 ARR+1ARR+1ARR+1 个数，然后回零。手册里写的是寄存器值，公式里用的是实际次数——这就是「忘了 +1 差一个计数」的来源。

计数模式共有三种，它决定 CNT 怎么走：

  • 向上计数（最常用）：CNT 从 0 数到 ARR，溢出后回 0，产生更新事件（可触发中断）。
  • 向下计数：从 ARR 数到 0，溢出回 ARR。溢出时刻与向上计数相同，但翻转点落在周期末端，某些斩波场合方便。
  • 中心对齐（先上后下）：一个周期内 CNT 先 0→ARR 再 ARR→0，共 2(ARR+1)2(ARR+1)2(ARR+1) 步。PWM 波形左右对称，谐波更小。

频率与周期公式（记住 +1）：

fcnt=fTIMPSC+1,T更新=ARR+1fcnt=(PSC+1)(ARR+1)fTIMf_{cnt} = \frac{f_{TIM}}{PSC + 1},\qquad T_{更新} = \frac{ARR + 1}{f_{cnt}} = \frac{(PSC+1)(ARR+1)}{f_{TIM}} fcnt​=PSC+1fTIM​​,T更新​=fcnt​ARR+1​=fTIM​(PSC+1)(ARR+1)​

顺序永远是这样：第 1 步定 PSC（选一个好算的计数频率）、第 2 步定 ARR（由目标周期反除）、第 3 步定 CCR（由占空比乘出来）。反过来先定 CCR 会没地方放，因为 ARR+1ARR+1ARR+1 是从 fTIM/(PSC+1)f_{TIM}/(PSC+1)fTIM​/(PSC+1) 里除出来的。

计数来源也可以换，四种常见选择：

  • 内部时钟：默认，做定时与 PWM；
  • 外部脉冲引脚：直接数脉冲个数，做流量计、转速计；
  • 另一个定时器的触发输出：级联，让几路 PWM 同步启动；
  • 编码器接口：两相正交输入，硬件自动增减 CNT（第四节讲）。

三个寄存器认清了，但公式是死的，参数是活的。下一节先用最基础的用法——定时中断——把它跑一遍。

二、定时中断：最基础的用法 ​

这一节只回答一个问题：要「每隔 T 精确地做一次事」，两个寄存器怎么取值。

用定时器做周期任务，比软件延时可靠得多。软件延时的误差来自循环体每次执行的周期数：一次循环被中断打断、被流水线填充、被编译器优化重排，几个百分点就累积成明显的偏差，而且换一个优化等级就变。硬件定时器与代码无关，只与时钟树有关。

例 1 · 用 72 MHz 定时器做 1 ms 定时中断

题目：定时器时钟 fTIM=72f_{TIM}=72fTIM​=72 MHz（F103 经典配置，APB1 上的定时器已 ×2），要求每 1 ms 进一次更新中断。求 PSC、ARR，并说明为什么不是 1000。

先想什么：两个未知数、一个方程，所以有一个自由度——先把它用在「让计数频率变成好算的数」上。1 MHz 意味着每次计数正好 1 µs，后面所有时间都能用微秒数直接当寄存器值写。

第一步，定 PSC：想让 fcnt=1f_{cnt}=1fcnt​=1 MHz

PSC+1=72 MHz1 MHz=72 ⇒ PSC=71PSC + 1 = \frac{72\ \text{MHz}}{1\ \text{MHz}} = 72\ \Rightarrow\ PSC = 71 PSC+1=1 MHz72 MHz​=72 ⇒ PSC=71

第二步，定 ARR：1 ms = 1000 µs，需要数 1000 次

ARR+1=1000 ⇒ ARR=999,T=999+11 MHz=1 msARR + 1 = 1000\ \Rightarrow\ ARR = 999,\qquad T = \frac{999+1}{1\ \text{MHz}} = 1\ \text{ms} ARR+1=1000 ⇒ ARR=999,T=1 MHz999+1​=1 ms

为什么不写 1000：CNT 从 0 数到 1000 一共 1001 个数，周期会变成 1001 µs（误差 0.1%）。想「数 1000 次」，寄存器就要填 999。

为什么选 PSC = 71 而不是别的：因为 PSC 本身要 +1，选 71 才得到 72 分频。（选 PSC 的判据不是「好看」，而是「除得尽」——见例 5 的反例。）

定时中断把「时间」这条线走通了。但定时器最有价值的用法不是数时间，而是输出波形——下一节。

三、PWM 输出：占空比到底在改什么 ​

这一节只回答一个问题：一串方波怎么等效成一个「可调的模拟量」，以及三个旋钮各自改变它的哪个属性。

PWM（Pulse Width Modulation，脉宽调制）用「高电平占多大比例」来等效地给出一个模拟量。占空比（duty cycle）就是这个比例：

duty=CCRARR+1,fPWM=fcntARR+1,Vavg=VCC×duty\text{duty} = \frac{CCR}{ARR+1},\qquad f_{PWM} = \frac{f_{cnt}}{ARR+1},\qquad V_{avg} = V_{CC}\times \text{duty} duty=ARR+1CCR​,fPWM​=ARR+1fcnt​​,Vavg​=VCC​×duty

三个式子各管一件事，这也正是三个寄存器的分工：

  • 改 CCR → 只改占空比，频率不动（本通道专属）；
  • 改 ARR → 频率变，占空比也变（分母变了）——这就是舵机角度漂移的根源；
  • 改 PSC → 计数频率变，频率与分辨率一起变，且影响该定时器的所有通道。

「等效直流」是低频等效的说法：后级电路带宽远高于 fPWMf_{PWM}fPWM​ 时，它看到的近似是一个恒定电压。LED 的热时间常数在几十毫秒量级，1 kHz 的 PWM 对它就是平均电流；但音频功放的输入端会把 20 kHz 的载波直接放大成可听见的噪声——同一条原理，边界不同。

配置要点（HAL）：

c
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);             // 启动 PWM 输出
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 300);    // 改 CCR（占空比）
__HAL_TIM_SET_AUTORELOAD(&htim3, 999);                // 改 ARR（频率）

__HAL_TIM_SET_COMPARE 只写 CCR，不产生更新事件，所以可以随时调用而不会打断当前这一轮波形；__HAL_TIM_SET_AUTORELOAD 改 ARR 同理，新值在下一轮生效。这正是「在线调参不出毛刺」的用法。

PWM 模式 1 与模式 2：模式 1 是「CNT < CCR 时输出有效电平」，模式 2 相反。「有效电平」由极性（TIM_OCPOLARITY_HIGH/LOW）决定，占空比反了就是这两处之一调错了。此外还有模式 3/4（PWM + 互补），专门留给高级定时器的死区控制用（第五节）。

例 2 · 驱动舵机：50 Hz、90°

题目：舵机要求 50 Hz（周期 20 ms）的 PWM，靠绝对脉宽定角度：0.5 ms→0°、1.5 ms→90°、2.5 ms→180°。用 1 MHz 计数频率（PSC = 71）求 ARR 与 CCR。

先想什么：舵机「只认脉宽不认占空比」，所以顺序必须是先锁频率，再算脉宽。先锁频，意味着 ARR 一旦定了就不许动。

第一步，锁频率：

ARR+1=1 MHz50 Hz=20000 ⇒ ARR=19999ARR + 1 = \frac{1\ \text{MHz}}{50\ \text{Hz}} = 20000\ \Rightarrow\ ARR = 19999 ARR+1=50 Hz1 MHz​=20000 ⇒ ARR=19999

第二步，把脉宽换成计数值（1 µs 一个计数）：

角度脉宽CCR占空比
0°0.5 ms5002.5%
90°1.5 ms15007.5%
180°2.5 ms250012.5%

验算：CCR=1500CCR=1500CCR=1500 → 脉宽 1500/1 MHz=1.51500/1\ \text{MHz}=1.51500/1 MHz=1.5 ms ✓；占空比 1500/20000=7.5%1500/20000=7.5\%1500/20000=7.5% ✓。

为什么不能改 ARR：若把 ARR 改成 9999（频率变成 100 Hz），同样写 CCR = 1500，脉宽变成 1.5 ms 没变、但周期变成 10 ms，舵机内部的解码会把「1.5 ms 相对 10 ms」当成另一个指令——角度立刻漂。极端情况下频率远低于 50 Hz，舵机会一直顶到限位不停机，那是真的会烧舵机的。（为什么不改 CCR 就行：CCR 只改脉宽，分母没动，角度就按脉宽走。）

例 3 · PWM 分辨率与频率的取舍

题目：同一个定时器、1 MHz 计数频率，ARR 取 99、999、9999 三档，各自的频率与占空比步进是多少？该选哪一档？

先想什么：这是「同一块蛋糕怎么分」的题。一轮的刻度总数就是 ARR+1ARR+1ARR+1，它同时决定「频率」和「最小步进」，两者只能一起变。

fPWM=1 MHzARR+1,步进=1ARR+1f_{PWM} = \frac{1\ \text{MHz}}{ARR+1},\qquad \text{步进} = \frac{1}{ARR+1} fPWM​=ARR+11 MHz​,步进=ARR+11​

怎么选：

  • LED 调光：取 ARR = 999（1 kHz、0.1% 步进），人眼完全看不出台阶；
  • 舵机：频率被锁死在 50 Hz，ARR = 19999 → 步进 0.005%，分辨率非常富裕；
  • 音频 / 超声波：需要 20 kHz 以上，ARR 被迫变小，分辨率下降——此时必须提高计数频率（减小 PSC）来补偿。

输出这一半讲完了，另一半是它的逆过程：把外部来的信号量出来。下一节。

四、输入捕获与编码器接口 ​

这一节只回答两个问题：外部信号的周期怎么用定时器量出来，以及正交编码器的方向怎么让硬件自动判断。

输入捕获是 PWM 的逆过程：外部信号的边沿到来时，硬件把此刻的 CNT 值锁存进 CCR，你再读出来。「锁存」意味着这个数不会因为 CNT 继续跑而变。两次捕获之差就是信号周期：

周期=ΔCNTfcnt,f=fcntΔCNT\text{周期} = \frac{\Delta CNT}{f_{cnt}},\qquad f = \frac{f_{cnt}}{\Delta CNT} 周期=fcnt​ΔCNT​,f=ΔCNTfcnt​​

例 4 · 用输入捕获测频率，以及它的分辨率极限

题目：计数频率 1 MHz，捕获配成上升沿触发。测 1 kHz 与 100 kHz 两种信号，各自的计数值与误差是多少？

先想什么：先算「一个周期里有多少个计数」。计数值越大，一个计数带来的相对误差越小——这是测周期法的精度公式。

被测频率ΔCNT\Delta CNTΔCNT一个计数对应的频率误差
1 kHz1000约 1 Hz（0.1%）
10 kHz100约 100 Hz（1%）
100 kHz10约 10 kHz（10%）

为什么高频测不准：f=fcnt/ΔCNTf = f_{cnt}/\Delta CNTf=fcnt​/ΔCNT，ΔCNT\Delta CNTΔCNT 变小时，同样的 ±1 个计数会让 fff 跳得更大。100 kHz 时只有 10 个计数，差一个是 10% 的误差。

两种解法：

  1. 降低 PSC，把计数频率抬上去（比如 72 MHz 计数 → ΔCNT\Delta CNTΔCNT 变成 720，误差回到 0.14%）；
  2. 改用测频法：用另一个定时器开 100 ms 闸门，在闸门内累计边沿数 NNN，则 f=N/0.1f=N/0.1f=N/0.1 Hz。误差只取决于闸门本身的精度，与被测信号无关——这是测高频的正解。

验算：1 MHz 计数、测 1 kHz → ΔCNT=106/103=1000\Delta CNT = 10^6/10^3 = 1000ΔCNT=106/103=1000 ✓，与表一致；频率分辨率 106/1000−106/1001≈110^6/1000 - 10^6/1001 \approx 1106/1000−106/1001≈1 Hz ✓。

溢出的坑：被测信号周期很长时，CNT 可能在两次捕获之间溢出多次，必须把溢出次数一起记进去算——这是输入捕获最常见的进阶错误。

编码器接口是另一条路：正交编码器输出 A、B 两相脉冲（相位差 90°），定时器配成编码器模式后硬件根据两相的相位关系自动判断方向并增减 CNT，软件不用写中断。要点两条：

  • 通常配成 TI1 与 TI2 双边沿计数（4 倍频），转一圈的计数 = 物理线数 × 4；
  • 测速流程是「每 10 ms 读一次 CNT，用本次值减上次值」：转速=Δ/(线数×4)/0.01 s\text{转速} = \Delta/(\text{线数}\times4)/0.01\ \text{s}转速=Δ/(线数×4)/0.01 s。若 Δ\DeltaΔ 长期为负或大幅超过 ARR，说明发生了回绕（低速时溢出）或转向翻转——必须用有符号减法并判断跨越，否则电机反转时读数会出现正负跳变甚至恒定不变这类反直觉现象。

普通定时器到这里就讲完了。真正驱动电机的那一半能力，只在高级定时器上才有——下一节。

五、高级定时器：互补输出与死区 ​

这一节只回答一个问题：驱动 H 桥时为什么必须插死区，以及那个 8 位的 DTG 该填几。

TIM1 / TIM8 这类高级定时器多出三样东西：互补输出 + 死区（一对反相的 PWM，中间插入都关断的空档）、刹车输入 BKIN（外部故障信号直接硬件关断输出，比软件快得多）、重复计数器（让 PWM 周期是更新周期的整数倍）。

死区（dead time）的物理来源值得单独说清。MOSFET 从栅压超过阈值到真正导通、以及从导通到彻底关断，都需要时间（典型几十到几百纳秒，还要加上栅极电荷的充放电）。如果上管的下降沿与下管的上升沿严格同一时刻，在那几十纳秒里两管同时导通，母线电压经它们直接短路到地——这叫直通（shoot-through）。它持续时间极短，但峰值电流可达安培级，反复发生会让开关管和驱动芯片一起烧掉。死区就是强行在这两条边沿之间插一段空档：先让一只彻底关断，再让另一只开始导通。

例 5 · 电机调速：16 kHz、30% 占空比的完整参数

到这里，四个寄存器、三种用法（定时、PWM、捕获）、一个保护机制（死区）都齐了。最后一节看它们在真实产品里怎么配合。

六、工程实例 ​

这一节把前面的参数组合成三个真实场景，每个场景都只需要改一两个旋钮，但改错哪一个后果不同。

LED 呼吸灯：用 PWM 调光，让 CCR 从 0 平滑升到 ARR 再降回 0。频率取 1~2 kHz、ARR = 999（步进 0.1%）。实现上不要用软件延时扫亮度，而是把 CCR 的更新挂到 100 Hz 左右的更新中断上按表递增——中断里只做一次寄存器写入，扫完一轮约 10 ms。

亮度不是线性的

人眼对暗部变化更敏感，所以线性 ramp 会觉得「前半段变化快、后半段慢」。产品里通常存一张 256 级的 gamma 表（按平方或指数曲线，如 CIE 1931 校准值），用亮度等级号去查 CCR，而不是直接把等级号当 CCR 写。

直流电机调速：频率选择很关键——太低（<1 kHz）会听到线圈啸叫并出现抖动，太高（>20 kHz）开关损耗上升。常用 10~20 kHz。参数就是例 5：PSC = 17、ARR = 249 得 16 kHz，CCR 在 0~250 之间连续可调。若换成小电机、开关损耗压力不大，可降到 8 kHz（ARR+1=500ARR+1=500ARR+1=500）换取 0.2% 的更细台阶。注意别直接照搬「电机说明书里的 25 kHz」：那是电机本体允许的范围，驱动端还要看栅极驱动器能否在这个周期里塞下死区。

舵机：参数完全由例 2 锁死（PSC = 71、ARR = 19999、CCR 写 500~2500）。工程上再加两件事：一是用输出比较或输入捕获实测脉宽，确认硬件真的输出了 0.5~2.5 ms（串口转接线的二极管会吃掉约 0.6~0.7 V，压降后脉宽可能不足）；二是上电时先把 CCR 写 1500（中间位）再启动输出，避免初始化瞬间输出 0 脉宽让舵机猛撞限位。

死区与 H 桥：每一相都是上下管互补驱动，必须开死区。设 1 µs 死区后，占空比两端会被压缩甚至钳死，工程上要按三条处理：

  • 给 100% 其实只有约 96.8%（死区吃掉的那 3.2%，见例 6）；
  • 可用调速区间收缩到 5%~95%；
  • 软件里对 CCR 做上下限钳位，不允许直接跑到 0 或 ARR+1ARR+1ARR+1。

最后一个坑：时基寄存器与通道寄存器是分工的

ARR / PSC 改了会影响该定时器的所有通道与溢出频率；CCR 改了只影响本通道。这就是「电机与舵机共用同一个定时器」会互相干扰的原因——一个定时器做一件事，比事后调参数便宜得多。

七、易错清单 + 自检 ​

按踩坑频率从高到低排，格式是「错误做法 → 会得到什么 → 正确做法」。

  1. PSC / ARR 忘了 +1 → 周期差一个计数，高频时误差放大 → 记住「寄存器值 = 次数 − 1」。
  2. 定时器时钟忘了 ×2 → 所有时间差一倍 → APB 分频 ≠ 1 时定时器时钟自动翻倍（见 04 · 时钟系统）。
  3. 改了 ARR 却没同步改 CCR → 占空比跟着变，舵机角度漂移 → 先锁频率再调 CCR。
  4. PWM 引脚没配成复用推挽（F1 上还忘开 AFIO 时钟）→ 定时器在跑，引脚无信号 → 配成复用模式（见 05 · GPIO）。
  5. 占空比反了 → 亮度/转速与预期相反 → 检查 PWM 模式 1/2 与输出极性。
  6. 中心对齐忘了周期翻倍 → 频率只有设定值的一半 → T=2(ARR+1)/fcntT = 2(ARR+1)/f_{cnt}T=2(ARR+1)/fcnt​。
  7. 输入捕获测高频时分辨率不够 → ±1 个计数就是百分之几的误差 → 减小 PSC，或改用测频法。
  8. 编码器模式没设 4 倍频 → 分辨率少 4 倍 → TI1、TI2 双边沿计数。
  9. 死区换算用错基准 → 死区时间差几十倍 → tDTSt_{DTS}tDTS​ 跟 fcntf_{cnt}fcnt​ 走，不是 fTIMf_{TIM}fTIM​。
  10. 死区过大 → H 桥两端调不到 0% 与 100% → 取手册最小值加余量。
  11. 把溢出频率当成定时中断周期用 → 数与预期不符 → 溢出频率 =fcnt/(ARR+1)=f_{cnt}/(ARR+1)=fcnt​/(ARR+1)，与 CCR 无关。

自检（先自己想，答案在下面一行）：

  1. 72 MHz 定时器要产生 1 ms 中断，PSC 与 ARR 各取多少？为什么不是 1000？
  2. 舵机 90° 在 50 Hz、1 MHz 计数下的 CCR 是多少？若把 ARR 改成 9999 会怎样？
  3. ARR 从 999 改到 99，PWM 频率与占空比步进分别怎么变？16 kHz 下死区 1 µs 对应 DTG 填几？

（答案：PSC = 71、ARR = 999，因为 CNT 从 0 数到 1000 是 1001 个数；CCR = 1500，改 ARR 会改变分母，角度漂移；频率从 1 kHz 升到 10 kHz，步进从 0.1% 变成 1%；tDTSt_{DTS}tDTS​ = 250 ns，DTG = 4。）
