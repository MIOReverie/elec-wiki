25 · 触发器与时序电路 ​

📎 教材下册速览：本章是《电工学》下册第 25 章 · 触发器与时序电路的压缩版。完整版见数字电路课 05 · 触发器 与 06 · 计数器与寄存器。

了解 约 25 min核心：状态方程 + 时序图

结论先行 ​

  1. 触发器有记忆：Qn+1Q^{n+1}Qn+1 取决于输入和原状态 QnQ^nQn
  2. D 触发器：Qn+1=DQ^{n+1} = DQn+1=D（边沿触发）—— 最常用
  3. JK 触发器：Qn+1=JQˉn+KˉQnQ^{n+1} = J\bar Q^n + \bar K Q^nQn+1=JQˉ​n+KˉQn —— 功能最全，J=K=1J=K=1J=K=1 时翻转
  4. 时序电路 = 组合电路 + 存储电路；分同步（共用一个时钟）和异步
  5. 分析三步：写驱动方程 → 代入特性方程得状态方程 → 列状态表/时序图

规律层：时序逻辑的命门是「有记忆」

判断时序逻辑也只问一句：输出受不受「原状态 QnQ^nQn」影响？ 受，就是时序——Qn+1Q^{n+1}Qn+1 由输入和现态共同决定，时钟负责让状态「翻页」。所以分析时序电路永远是三步：写驱动方程 → 代入特性方程得状态方程 → 列状态表 / 画时序图。触发器是「一位记忆」，寄存器是「一组记忆」，计数器是「记忆 + 反馈计数」——一步步都从这条展开。

时序电路分析方法 ​

① 写各触发器的驱动方程（每个输入端 = 输入和现态的函数）
② 把驱动方程代入触发器的特性方程 → 得到状态方程 Qⁿ⁺¹
③ 写输出方程
④ 列状态转换表 / 状态图
⑤ 画时序图，归纳功能

例 1 · JK 触发器：给一串 J、K，画出 Q 的波形

下降沿触发的 JK 触发器，初始态 Qn=0Q^n = 0Qn=0，时钟逐个来临时的 (J,K)(J, K)(J,K) 依次为 (1,0)→(1,1)→(0,1)→(1,1)→(0,0)(1,0) \to (1,1) \to (0,1) \to (1,1) \to (0,0)(1,0)→(1,1)→(0,1)→(1,1)→(0,0)。求每个时钟沿之后的 QQQ。

解

用特性方程 Qn+1=JQˉn+KˉQnQ^{n+1} = J\bar Q^n + \bar K Q^nQn+1=JQˉ​n+KˉQn 逐拍算（只在时钟沿瞬间采样，边沿之后输入怎么变都不影响）：

时钟沿(J,K)(J,K)(J,K)QnQ^nQn代入特性方程Qn+1Q^{n+1}Qn+1
1(1, 0)01×1+1×0=11\times1 + 1\times0 = 11×1+1×0=11（置 1）
2(1, 1)11×0+0×1=01\times0 + 0\times1 = 01×0+0×1=00（翻转）
3(0, 1)00×1+0×0=00\times1 + 0\times0 = 00×1+0×0=00（保持 0）
4(1, 1)01×1+0×0=11\times1 + 0\times0 = 11×1+0×0=11（翻转）
5(0, 0)10×0+1×1=10\times0 + 1\times1 = 10×0+1×1=11（保持 1）

所以 QQQ 的变化是 0→1→0→0→1→10 \to 1 \to 0 \to 0 \to 1 \to 10→1→0→0→1→1。两步记忆法对照：J=1,K=0J=1, K=0J=1,K=0 置 1；J=0,K=1J=0, K=1J=0,K=1 清 0；J=K=1J=K=1J=K=1 翻转；J=K=0J=K=0J=K=0 保持——四种情况各出现一次，这就是 JK「功能最全」的来历。

常用时序器件 ​

寄存器 ​

并行输入/并行输出的 D 触发器组，用来暂存数据；移位寄存器可左移/右移（串并转换）。

计数器 ​

类型特点
异步（行波）计数器低位输出触发高位时钟，有累积延迟，简单但慢
同步计数器所有触发器共用时钟，速度快，需要进位逻辑
集成 74LS1614 位同步二进制加计数，带异步清零、同步置数、使能端

任意进制计数器（常考）：

  • 清零法（复位法）：计到 NNN 时产生清零信号 → 构成 NNN 进制
  • 置数法（置位法）：计到某值时同步置入初值 → 构成 MMM 进制

例：用 74LS161 构成十进制：计到 1010（10）时令 RˉD=0\bar R_D = 0RˉD​=0 异步清零 → 0~9 循环。

例 2 · 用 74LS161 构成十进制计数器

74LS161 是 4 位同步二进制加计数（0000→11110000 \to 11110000→1111 共 16 态），带异步清零端 RˉD\bar R_DRˉD​。要构成十进制（N=10N = 10N=10），数一下状态：0000∼10010000 \sim 10010000∼1001 正好 10 个，所以计到 1010 的瞬间就要清零。

解

反馈逻辑：用一个与非门检测 1010——1010 里为 1 的位是 Q3Q_3Q3​ 和 Q1Q_1Q1​，所以接 Q3Q1Q_3 Q_1Q3​Q1​，两者同时为 1 时与非门输出 0，接到 RˉD\bar R_DRˉD​。

状态序列：0000→0001→⋯→1001→0000 \to 0001 \to \cdots \to 1001 \to0000→0001→⋯→1001→ （下一个计数脉冲到来，状态刚要变成 1010，RˉD\bar R_DRˉD​ 立刻变 0）→0000\to 0000→0000。

注意 1010 是一个窄脉冲状态（出现后立即被清掉），稳定循环里只有 0∼90 \sim 90∼9。

关键对比（异步 vs 同步清零）：

  • 异步清零（74161 是这种）：检测到 N=1010N = 1010N=1010 就清——因为清零不看时钟，说清就清；
  • 同步清零（如 74163）：要检测 N−1=1001N-1 = 1001N−1=1001，等下一个时钟沿才生效，同样得到 0∼90 \sim 90∼9。

两种接法差 1：异步用 NNN 译码，同步用 N−1N-1N−1 译码。考试画错这一位，整个状态数就多一个或少一个。

555 定时器（选学要点） ​

  • 单稳态：触发后输出一个固定宽度脉冲，tW=1.1RCt_W = 1.1RCtW​=1.1RC
  • 多谐振荡器：自激振荡输出方波，T=0.7(R1+2R2)CT = 0.7(R_1+2R_2)CT=0.7(R1​+2R2​)C，f=1.43(R1+2R2)Cf = \dfrac{1.43}{(R_1+2R_2)C}f=(R1​+2R2​)C1.43​
  • 施密特触发：波形整形、消抖

考点速记 ​

考法关键
画时序图先画 CLK，按边沿逐个更新 Q（注意是边沿不是电平）
判断触发器类型看是否有 JJJ、KKK、DDD、TTT 输入
异步 / 同步清零异步立刻生效，同步要等下一个时钟边沿
构成 N 进制清零法（异步清零用 NNN，同步清零用 N−1N-1N−1）
555 频率计算f=1.43(R1+2R2)Cf = \dfrac{1.43}{(R_1+2R_2)C}f=(R1​+2R2​)C1.43​

易错点

  • 边沿触发只在时钟跳变瞬间采样，CLK 保持期间输入变化不影响输出
  • 异步清零端是低电平有效（RˉD\bar R_DRˉD​），接线别搞反
  • 同步清零法计到 N−1N-1N−1 就要产生清零信号（等下一个边沿才清零）；异步清零法计到 NNN 立刻清零 —— 差 1
  • 主从 JK 触发器存在"一次变化现象"，边沿触发没有
