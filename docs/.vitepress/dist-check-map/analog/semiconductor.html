01 · 半导体器件 ​

核心 约 50 min二极管/稳压管/三极管/场效应管四种积木的特性、参数与直流分析

本章的两块地基：单向导电的物理来源（）与三极管的工作区判据（）。这两张卡片讲的是「为什么」，本章讲的是「怎么算」。

结论先行 ​

  1. 本征半导体掺杂成 P / N 型，PN 结的单向导电性（正偏导通、反偏截止）派生出二极管、稳压管、三极管、场效应管全部器件——四种器件共享同一个结。
  2. 二极管近似模型三档：理想（0 V 导通）、恒压（硅 0.7 V / 锗 0.2 V）、折线（死区 + 导通电阻）。工程估算用恒压模型，精度要求高时用指数特性。
  3. 稳压管工作在反向击穿区：电压几乎不随电流变。限流电阻必须同时满足「IZI_ZIZ​ 不小于维持电流」和「IZI_ZIZ​ 不超过最大功耗」，两头都要算。
  4. 三极管是电流控制器件：IC=βIBI_C=\beta I_BIC​=βIB​、IE=IB+ICI_E=I_B+I_CIE​=IB​+IC​。三种接法（共射/共集/共基）不是换管子，是换「哪个极接地」。
  5. 场效应管是电压控制器件：ID=gmVGSI_D=g_mV_{GS}ID​=gm​VGS​，输入电阻极高。增强型 MOS 有开启电压 VGS(th)V_{GS(th)}VGS(th)​，低于它完全截止——这就是「CMOS 输入不能悬空」的根源。

推导脉络：从一块硅到一个器件 ​

本征硅（载流子很少，不爱导电）
  │ 掺五价元素 → N 型（多电子）
  │ 掺三价元素 → P 型（多空穴）
  ▼
P 型 + N 型 → PN 结
  │ 空间电荷区（耗尽层）形成内电场
  │ 正偏：外电场削弱内电场 → 多子扩散 → 导通
  │ 反偏：外电场加强内电场 → 少数载流子漂移 → 截止
  ▼
三种命运：
  只用单向导电性 ──────────────► 二极管 / 稳压管
  两个背靠背的结 + 薄基区 ─────► 三极管（用 IB 控制 IC）
  用电场控制沟道宽度 ──────────► 场效应管（用 VGS 控制 ID）

工程实例：一块电路板上的四种管子 ​

打开一台普通开关电源适配器，四种器件都在：

  • 整流桥里的四个二极管：把交流切成单向（见电工学 22 章），工作在开关区；
  • 功率三极管/MOS：高频开关，饱和与截止两态切换（PWM 调速同一思想）；
  • 稳压管或 TL431：采样反馈回路的基准电压源（例 2 的实际应用）；
  • 运放：误差放大器，比较输出采样与基准——一个运放内部就有十几对差分管（第 5 章 · 集成运算放大电路主角）。

易错清单 + 自检 ​

  • 二极管导通压降的方向：电流从阳极进才降压 0.7 V，方向搞反会把一个 0.7 V 的电源当成断路。
  • 稳压管不能反接当普通二极管用：它设计的工作点就在击穿区，正偏时反倒像个普通二极管。
  • 三极管的 β\betaβ 不是常数：随 ICI_CIC​ 和温度明显变化，精确设计必须留余量（β\betaβ 可能腰斩）。
  • 饱和区的 IC≠βIBI_C\ne\beta I_BIC​=βIB​：这是最常见的分析错误——先判区，再选公式。
  • MOS 是绝缘栅：手指一抹就是一层静电荷场，焊接时必须先放电——双极型三极管没这么娇气，但 MOS 拆封就得小心。
