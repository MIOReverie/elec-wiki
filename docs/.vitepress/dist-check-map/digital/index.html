数字电路 ​

指南 约 5 min从数制到可编程逻辑，按「能动手验证」的方式重学一遍

数字电路研究「只用 0 和 1 能算出什么、怎么算」。它和电工学是两条线：电工学讲连续量的电压电流，数电讲离散量的逻辑与状态。两者在多处交叉——整流滤波之后接 ADC，就把模拟世界交给了数电；继电控制里的自锁，其实就是最简单的状态保持。

本课程按新课从零写，不假设先修：每章都配可交互演示，能自己拖、自己验证。

学完能得到什么 ​

  • 在二进制、十六进制、BCD、补码之间自由换算，并知道补码为什么能统一加减法；
  • 用布尔代数和卡诺图化简逻辑函数，能从真值表直接写出最简与或式；
  • 说清 TTL / CMOS 的差别，知道 CMOS 输入为什么不能悬空、三态门为什么能接总线；
  • 设计译码器、数据选择器、加法器，读懂 74 系列器件的引脚与使能；
  • 用 D/JK 触发器搭计数器与寄存器，分析时序图的建立/保持与计数模值；
  • 把数字系统与模拟世界接起来：采样定理、DAC/ADC 结构、PWM 调制；
  • 把纸面逻辑落成真实硬件：读得懂 Verilog 的 module / assign / always @(posedge clk)，知道 FPGA 的综合、布局布线与时序约束各自在管什么。

和电工学的关系 ​

  • 数电不需要电路分析基础，但学了会更顺：理解「为什么 CMOS 输入不能悬空」要用一点电位概念。
  • 继电接触器控制里的自锁/互锁，已经是「状态保持」的思想，和触发器一脉相承。
  • PLC 与梯形图的扫描周期，是数字系统「时序」观念的工业版。
  • 更细的器件机理在模拟电子；这里只关心逻辑行为，不纠结管子的偏置。

第 09 章在整门课里的位置 ​

前八章把「逻辑关系」讲完了：卡诺图给出最简式，触发器给出特性方程，计数器给出模值与分频比。09 章回答的是另一个问题——这些纸面结论怎么变成一块真芯片里同时运转的硬件。

  • 它不是简单地把前八章翻译成代码：同一句加法，函数式写法综合出来是组合逻辑，always @(posedge clk) 里写才是每拍执行一次的寄存器；
  • 它给出了一条新的主线：综合 → 布局布线 → 时序约束 → 下载，以及「为什么我的设计跑不到 100 MHz」；
  • 它把 04/05/06/07 章各挑了一个代表（译码器、D 触发器、计数器、存储器）写成完整代码，用一张对照表把两边钉在一起；
  • 学它不要求先有编程基础，但要能接受「你在描述电路，不是在叙述步骤」。

相关实验与专题 ​

数字电路的结论大多是「时序上对不对」，而时序正是示波器最擅长看的东西：

  • 示波器（/lab/oscilloscope）：第 05、06 章讲的建立/保持与计数模值，在纸上是几条竖线，在屏幕上就是稳定的方波和偶尔的毛刺。用示波器读一次 PWM 的占空比，比背十遍时序图有用。
  • AD/DA 与脉冲调制在实物上的样子：第 08 章采样定理与 PWM 那节的公式，到直流电机驱动里会变成「PWM 频率选多少、为什么会有转矩脉动」的具体取舍。
  • 实验与仪器总览（/lab/）：门电路、计数器这类纯数字实验用面包板就能搭，总览页三小时清单里有一项就是用示波器读 MCU 输出的 1 kHz、25% 方波，正好是本课 06、08 章的落地。
  • STM32 的 GPIO 与定时器（嵌入式 05、07）：寄存器配置、时钟分频、计数器比较，本质上就是本课 06 章的计数器搬进芯片。学完这里再去看 PSC/ARR/CCR，会发现它们不是新东西。
