看不懂的词点开就是

从这里开始 ​

第一次来、或者复习时不知道该翻开哪一页，可以从学习地图看起：它把四门课、实验和专题排成从「电学入门与安全」到「电力电子与进阶」的八个阶段，每个阶段写明读哪几页、大概多久、怎么算过关，文末还有一张按目标选路线的决策表。想先动手的话，实验与仪器从万用表、示波器和焊接讲起，附带一份三小时的第一次上手清单；手上已经有想造的东西，可以直接翻项目专题，电源、电机驱动、舵机云台三个项目各自列了前置章节，缺哪块补哪块。

这个 wiki 怎么用 ​

三条最常用的入口

  • 从头学一遍：从电工学按 01 → 22 的顺序读。每章前面有前置知识胶囊兜底，遇到没学过的东西点开就能补。
  • 只差考前突击：直接翻公式速查表，再扫每章末尾的「易错点 / 考点速记」。
  • 只想查一个词：点右上角搜索（或按 Ctrl + K），中文按 2-gram 分词，输「戴维南」「转差率」都找得到。

这里有什么，没有什么 ​

站里有四门课的正文、可以拖参数的演示、前置知识卡片、公式速查表、依赖图谱，还有一份内容状态表。这份表由脚本扫描正文生成，会告诉你哪几节已经能当教材读，哪几节还只是提纲；标记了「核心」但内容偏薄的章节也写在里面，不会拿「敬请期待」盖过去。

它是一份个人学习笔记，不是教材的替代品：考纲里偏冷门的部分没有覆盖，例题的答案也谈不上标准。正文整理自秦曾煌《电工学》、康华光《电子技术基础》等教材，引用和勘误见关于本站。
