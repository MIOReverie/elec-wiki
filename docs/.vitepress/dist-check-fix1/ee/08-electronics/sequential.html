25 · 触发器与时序电路 ​

了解 约 35 min三个坑最深：把电平触发当边沿触发；异步清零接 N 而同步清零接 N−1；把时序图按电平画

这一页要解决什么：上一页所有电路的输出都留不住——输入一变，结果就没了。这一页给数字电路装上第一个「记忆」元件：触发器。读完你应该能：说清两个反相器凭什么能存住一位、写出四种触发器的特性方程并互相换算、分辨电平触发与边沿触发会各自出什么错、按「驱动方程 → 状态方程 → 状态表 / 时序图」三步分析任意小规模时序电路、用一片 74LS161 拼出任意进制计数器、并算对 555 的脉宽与频率。

📎 教材下册速览：本章是《电工学》下册第 25 章（触发器与时序电路）的压缩版。完整版见数字电路课 05 · 触发器（含建立时间、亚稳态、时钟周期预算）与 06 · 计数器与寄存器（含移位寄存器与 555 的完整推导）。

读这页之前

  • 需要会：真值表与与或非（23 · 数字电路基础）、组合逻辑的分析与设计（24 · 组合逻辑电路）、卡诺图化简（）。
  • 这一页用到的符号：QnQ^nQn 是现态（当前这一拍的状态），Qn+1Q^{n+1}Qn+1 是次态（下一个时钟沿之后的状态），上标只是「第几拍」的编号，不是指数；Q‾\overline{Q}Q​ 是互补输出（永远与 QQQ 相反）；DDD、JJJ、KKK、TTT、SSS、RRR 是各触发器的输入；CLK 是时钟；RD‾\overline{R_D}RD​​、SD‾\overline{S_D}SD​​ 是异步清零 / 置位端，名字上的横线表示低电平有效（写 0 才起作用，写 1 不起作用）。全部约定见符号与约定。
  • 三个词先给一句话：触发器（flip-flop）是能存一位的最基本单元；时钟（CLK）是一路不停在 0/1 之间来回的方波，它不传数据，只打拍子；时序图（timing diagram）是把 CLK 与各信号按时间轴画在一起的一组波形，横轴时间，每根信号一行，同一竖直位置=同一时刻。
  • 不需要微积分：全页只做逻辑运算与查表，唯一的算术是 tW=1.1RCt_W=1.1RCtW​=1.1RC 与 T=0.7(R1+2R2)CT=0.7(R_1+2R_2)CT=0.7(R1​+2R2​)C 两次乘法。

先看一个具体的麻烦。你按下墙上的电灯开关，灯亮了。可如果开关的触点在闭合那一瞬间弹了两下（机械开关几乎都会），单片机就会读到「按、松、按」——一次按键被当成两次，计数器多加一次。在软件里加个延时也不行：延时期间若正好来了一次真正的新按键，就被吞掉了。

第二个麻烦是实验课上的常见困惑：同一个 D 触发器，把 DDD 直接接开关，时钟接信号源。结果发现时钟保持高电平的整段时间里，DDD 一变输出就跟着变——这哪像记忆元件？两个麻烦指向同一件事：「记住一位」与「什么时候允许它改」是两件不同的事。这一页先讲前者，再讲后者。

结论先行 ​

  1. 触发器之所以能记一位，是因为两个反相器首尾相接形成双稳态：只有两个稳定状态，中间那个平衡点不稳定。
  2. 次态由「输入 + 现态」共同决定，写成一句话就是特性方程：D 型 Qn+1=DQ^{n+1}=DQn+1=D，JK 型 Qn+1=JQn‾+K‾QnQ^{n+1}=J\overline{Q^n}+\overline{K}Q^nQn+1=JQn​+KQn。
  3. 触发方式决定「什么时候看输入」：电平触发会在时钟高电平期间反复翻转（空翻），边沿触发只在跳变瞬间采样一次——现代电路一律用边沿触发。
  4. 时序电路 = 组合电路 + 存储；分析固定三步：写驱动方程 → 代入特性方程得状态方程 → 列状态表 / 画时序图。
  5. 现成器件分三类：寄存器（暂存与移位）、计数器（模 NNN 循环，任意进制靠清零法或置数法，异步与同步差一个数）、定时器（555 给脉宽与频率）。

规律层：时序逻辑的命门是「有记忆」

判断时序逻辑也只问一句：输出受不受「原状态 QnQ^nQn」影响？ 受，就是时序——Qn+1Q^{n+1}Qn+1 由输入和现态共同决定，时钟负责让状态「翻页」。触发器是「一位记忆」，寄存器是「一组记忆」，计数器是「记忆 + 反馈计数」，三者都从这一条展开。

一、为什么能记住一位：双稳态 ​

这一节只回答一个问题：两个反相器首尾相接，凭什么能把一位存住。

双稳态（bistable）的意思是电路只有两个稳定平衡点。把两个非门接成一个环：QQQ 经过一个非门变成 Q‾\overline{Q}Q​，Q‾\overline{Q}Q​ 再经过一个非门变回 QQQ——这一圈刚好自洽两次。于是有两种自洽情形：Q=1Q=1Q=1、Q‾=0\overline{Q}=0Q​=0，或者 Q=0Q=0Q=0、Q‾=1\overline{Q}=1Q​=1。两种都能无限维持，因为它们互相证明。

这个环有一个隐患：如果两个门的延迟差别大，环会在两个状态之间来回「摇」很久才停下。工程上的解决办法是把它做成受控的——加一个「许可信号」，只有在许可的那一瞬间才允许它改。这个许可信号就是时钟。

能存一位之后，问题变成「什么时候允许它改」。下一节先给四种触发器的账本，再讨论时间。

二、四种触发器：特性方程就是一张表 ​

这一节只做一件事：把「下一拍是什么」写成输入与现态的函数，并列出四种触发器各自的写法。

特性方程（characteristic equation）是触发器的全部行为描述：给定输入和现态，算出次态。它不含时间、不含电路细节，就是一张对照表。四种常见触发器如下：

触发器特性方程说明
DQn+1=DQ^{n+1} = DQn+1=D跟随输入，最常用
JKQn+1=JQn‾+K‾QnQ^{n+1} = J\overline{Q^n} + \overline{K}Q^nQn+1=JQn​+KQn功能最全，J=K=1J=K=1J=K=1 时翻转
TQn+1=TQn‾+T‾QnQ^{n+1} = T\overline{Q^n} + \overline{T}Q^nQn+1=TQn​+TQnT=1T=1T=1 翻转、T=0T=0T=0 保持
T′Qn+1=Qn‾Q^{n+1} = \overline{Q^n}Qn+1=Qn​恒翻转，最简的二分频器
RSQn+1=S+R‾QnQ^{n+1} = S + \overline{R}Q^nQn+1=S+RQn约束：SSS、RRR 不能同时为 1

JK 把四种操作都装进一个器件，值得单独记：J=1,K=0J=1,K=0J=1,K=0 置 1；J=0,K=1J=0,K=1J=0,K=1 清 0；J=K=1J=K=1J=K=1 翻转；J=K=0J=K=0J=K=0 保持。这四种操作分别对应「置位 / 复位 / 取反 / 保持」——所以它「功能最全」。

RS 的约束不是设计缺陷，而是逻辑必然：SSS、RRR 同时为 1 意味着「既要置 1 又要清 0」，次态无法定义。JK 就是在它上面把「同时为 1」这个非法组合重新定义成翻转，从而消掉了约束。

特性方程只说「下一拍是什么」，没说「什么时候算这一拍」。时间这件事，下一节专门处理。

三、触发方式：电平、主从、边沿 ​

这一节只回答一个问题：时钟的什么形态才算「许可」，不同许可方式会各出什么错。

三种方式，按历史顺序也是按优劣排：

  • 电平触发（level-triggered）：时钟为高（或为低）的整段时间都允许改。问题是空翻——时钟高电平期间若输入变了多次，输出就翻转多次，一个时钟周期里状态可能翻好几下，这个电路就没法按拍分析了。
  • 主从触发（master-slave）：用两级锁存器串起来，前级在时钟高电平期间接数据、后级在低电平期间接前级的结果，从而在一个周期内只更新一次。它解决了空翻，但仍有「一次变化现象」：时钟高电平期间输入变化可能被后级记住。
  • 边沿触发（edge-triggered）：只在时钟跳变的那一瞬间采样，上升沿（↑）或下降沿（↓）。现代芯片几乎全是这一种——它保证了一个时钟周期内状态只可能变一次，于是「一拍一步」可以严格推算。

异步端是另一条时间通道：RD‾\overline{R_D}RD​​（清零）与 SD‾\overline{S_D}SD​​（置位）不受时钟约束，一按就生效，优先级高于一切同步输入。它们的作用是「开机时把状态摆到已知位置」，代价是把「一切都在沿上发生」这个前提破坏掉——所以正常工作时应当接无效电平，只在复位瞬间动它。

还有一种更隐蔽的时间限制：数据必须在时钟沿之前稳定一段时间（建立时间 tsut_{su}tsu​）、在沿之后还要稳一段时间（保持时间 tht_hth​），否则触发器会进入既不是 0 也不是 1 的亚稳态。这两条由工艺决定，构成「这个电路最快能跑多快」的约束，完整推导见数字电路课 05 · 触发器 与 。

触发方式定了「什么时候看输入」，接下来就可以把时间切成拍，一拍一拍地推。下一节把这件事固定成三步。

四、时序电路分析三步 ​

这一节做一件事：给你一个含触发器的电路，按固定三步推出它的全部状态变化。

先给三个词的准确含义，它们就是三步的产物：

  • 驱动方程（drive equation）：每个触发器输入端等于什么（输入变量与现态的函数）。它是「线路图」翻译成「方程」的第一步。
  • 状态方程：把驱动方程代入特性方程，得到 Qin+1=f(输入,Qn)Q_i^{n+1}=f(\text{输入},Q^n)Qin+1​=f(输入,Qn)。它才是真正描述「下一拍」的式子。
  • 状态转换表 / 状态图 / 时序图：同一个结果的三种画法。状态表是「现态 → 次态」的表格；状态图把状态画成圆圈、转移画成箭头；时序图把 CLK 与各 QQQ 按时间轴排成波形，同一竖直位置就是同一时刻。

步骤固定为五小步（前三步是主线）：

① 写各触发器的驱动方程（每个输入端 = 输入和现态的函数）
② 把驱动方程代入触发器的特性方程 → 得到状态方程 Qⁿ⁺¹
③ 写输出方程（如果输出不是直接取自 Q）
④ 列状态转换表 / 状态图
⑤ 画时序图，归纳功能

为什么必须按这个顺序：时序电路里有环（输出回到输入），不能像组合电路那样「从输入一路算到输出」。唯一能算的方向是时间——用 QnQ^nQn 算出 Qn+1Q^{n+1}Qn+1，再把 Qn+1Q^{n+1}Qn+1 当新的现态。第 ① 步写驱动方程，是为了让每一拍的代数运算能机械地重复。

分析完电路，再看看现成的时序器件都替你做了什么。下一节按「寄存器 → 计数器 → 定时器」走一遍。

五、常用时序器件 ​

这一节做一件事：认识三类现成器件，并记住它们各自解决什么问题。

寄存器（register）是一组共用一个时钟的触发器：时钟沿一到，整组同时存下当前输入，于是它能「暂存一个字」。移位寄存器把前一级的输出接后一级的输入，沿一拍移一位，用于串行 ↔ 并行转换（比如把串行收到的 8 位拼成一个字节）。

计数器（counter）是「每来一个时钟，输出按固定规律变一次」的电路，最常用的规律是数数。它的全部信息是模（modulus，记作 NNN）：一个循环里有几个状态。

类型特点
异步（行波）计数器低位输出触发高位时钟，延迟累积，简单但慢
同步计数器所有触发器共用时钟，速度快，需要额外进位逻辑
集成 74LS1614 位同步二进制加计数，带异步清零、同步置数、使能端

任意进制计数器是考试重点，只有两条路：

  • 清零法（复位法）：计到某个值时产生清零信号，硬把它拉回 0。异步清零要检测 NNN——因为「说清就清」，检测到 NNN 时它还没真的停在 NNN 上。
  • 置数法（置位法）：计到某个值时同步装入一个初值，从初值继续数。同步置数要检测 N−1N-1N−1——因为要等下一个时钟沿才生效。

两种接法只差一个数，却是最常失分的地方：异步清零用 NNN 译码，同步清零 / 置数用 N−1N-1N−1 译码。

555 定时器（选学，但公式要背）是「模拟电路怎么变成时钟源」的经典答案：内部两个比较器加一个 RS 触发器，靠外部 RC 充放电定时。

  • 单稳态：来一个触发脉冲，输出一个固定宽度的脉冲，tW=1.1RCt_W=1.1RCtW​=1.1RC；
  • 多谐振荡器：自激振荡输出方波，T=0.7(R1+2R2)CT=0.7(R_1+2R_2)CT=0.7(R1​+2R2​)C，f=1.43(R1+2R2)Cf=\dfrac{1.43}{(R_1+2R_2)C}f=(R1​+2R2​)C1.43​；
  • 施密特触发：把缓慢变化的波形整形成陡边沿，也用来给按键消抖。

器件会用了，但「会接」和「会算」是两件事。下一节用两道题把三步分析法和清零法各走一遍。

六、例题 ​

两道题分别考「按拍推状态」和「拼模值」——前者考时序图的画法，后者考清零法差一个数。

例 1 · JK 触发器：给一串 J、K，画出 Q 的波形

题目：下降沿触发的 JK 触发器，初始态 Qn=0Q^n=0Qn=0，时钟逐个来临时 (J,K)(J,K)(J,K) 依次为 (1,0)→(1,1)→(0,1)→(1,1)→(0,0)(1,0)\to(1,1)\to(0,1)\to(1,1)\to(0,0)(1,0)→(1,1)→(0,1)→(1,1)→(0,0)。求每个时钟沿之后的 QQQ，并画时序图。

先想什么：题目给的是「每个沿来时的 (J,K)(J,K)(J,K)」，不是连续波形——所以先把输入想成「每拍一个常数」，答案就是五步查表。抓两句：只在沿瞬间采样；翻不翻转看 J,KJ,KJ,K 的四种组合，不必每次代公式。

步骤：用特性方程 Qn+1=JQn‾+K‾QnQ^{n+1}=J\overline{Q^n}+\overline{K}Q^nQn+1=JQn​+KQn 逐拍算（只在时钟沿瞬间采样，边沿之后输入怎么变都不影响）：

时钟沿(J,K)(J,K)(J,K)QnQ^nQn代入特性方程Qn+1Q^{n+1}Qn+1
1(1, 0)01×1+1×0=11\times1+1\times0=11×1+1×0=11（置 1）
2(1, 1)11×0+0×1=01\times0+0\times1=01×0+0×1=00（翻转）
3(0, 1)00×1+0×0=00\times1+0\times0=00×1+0×0=00（保持 0）
4(1, 1)01×1+0×0=11\times1+0\times0=11×1+0×0=11（翻转）
5(0, 0)10×0+1×1=10\times0+1\times1=10×0+1×1=11（保持 1）

（为什么第 1 拍能置 1：J=1J=1J=1 时式子里 JQn‾=1J\overline{Q^n}=1JQn​=1，第二项恒为 0，所以次态与现态无关，直接被钉成 1。）

验算（两条独立路径）：

  1. 用四种操作口诀复核：J=1,K=0J=1,K=0J=1,K=0 置 1 ✓；J=K=1J=K=1J=K=1 翻转，从 1 翻成 0 ✓；J=0,K=1J=0,K=1J=0,K=1 清 0，本来就是 0 ✓；J=K=1J=K=1J=K=1 翻转，从 0 翻成 1 ✓；J=K=0J=K=0J=K=0 保持 1 ✓。五拍全对。
  2. 检查图的形状：Q 只在五条竖虚线处变化，虚线之间是水平段；若画成「斜着变」或「跟着 J 变」，就是把边沿触发错当成了电平触发 ✗。

这一节最该带走的一句：画时序图时先画 CLK 与采样虚线，再一格一格填 Q——只要 Q 在虚线之间动过，就是画错了。

例 2 · 用 74LS161 构成十进制计数器

题目：74LS161 是 4 位同步二进制加计数（0000∼11110000\sim11110000∼1111 共 16 态），带异步清零端 RD‾\overline{R_D}RD​​。用它构成十进制（N=10N=10N=10）。

先想什么：先数状态。0000∼10010000\sim10010000∼1001 正好 10 个，所以稳定循环只到 1001。再定清零信号接哪个码：异步清零不受时钟管，「说清就清」，所以要检测计到 10（1010）的那一刻把它拉回 0——检测 NNN，不是 N−1N-1N−1。

步骤：

  1. 定状态与模：稳定状态 0000∼10010000\sim10010000∼1001 共 10 个，故 N=10N=10N=10，需要 4 位触发器（23=8<10≤16=242^3=8<10\le16=2^423=8<10≤16=24）。
  2. 写反馈逻辑：检测 1010——这一码里为 1 的位是 Q3Q_3Q3​ 与 Q1Q_1Q1​，所以取 Q3Q_3Q3​、Q1Q_1Q1​ 接与非门（Q3Q1Q_3Q_1Q3​Q1​ 同时为 1 时输出 0），输出接 RD‾\overline{R_D}RD​​。（为什么只接两位就够：从 0000 递增时，Q3=Q1=1Q_3=Q_1=1Q3​=Q1​=1 第一次出现恰好是 1010；1011、1110、1111 都在清零之后才可能出现，来不及被用上。所以不必做全译码，省门。）
  3. 确认清零类型：74LS161 的 RD‾\overline{R_D}RD​​ 是异步的——不看时钟，一有效立刻清 0。所以检测 N=1010N=1010N=1010 本身，而不是 N−1N-1N−1。
  4. 画出序列：0000→0001→⋯→1001→0000\to0001\to\cdots\to1001\to0000→0001→⋯→1001→（下一拍刚要变 1010，RD‾\overline{R_D}RD​​ 立刻拉低）→0000\to0000→0000。

验算：

  • 数状态：0∼90\sim90∼9 一共 10 个，与要求的模 10 一致 ✓。
  • 对差一错误：若误按同步清零的思路检测 1001，则计到 9 就清零，循环只剩 0∼80\sim80∼8 共 9 个状态——模 9，少一个。这就是「异步用 NNN、同步用 N−1N-1N−1」这句话的来历。
  • 检查约束：161 共 16 态，N=10≤16N=10\le16N=10≤16，可行；若 N>16N>16N>16 就要两片级联。

关键对比（异步 vs 同步清零）：

  • 异步清零（74161）：检测到 NNN 就清——因为清零不看时钟，说清就清；
  • 同步清零（如 74163）：要检测 N−1N-1N−1，等下一个时钟沿才生效，同样得到 0∼90\sim90∼9。

易错清单 ​

按踩坑频率从高到低排，格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 把电平触发当边沿触发 → 时序图在时钟高电平期间画了多次翻转，按拍推算时状态对不上 → 边沿触发只在跳变瞬间变一次，Q 的水平段必须横跨整个时钟周期。
  2. 异步清零接 N−1N-1N−1，或同步清零接 NNN → 状态数差一个，模 N 变成模 N±1 → 记死「异步 NNN、同步 N−1N-1N−1」。
  3. 异步清零端当成高有效 → 接反后芯片一直处于清零状态，永远数不上去 → RD‾\overline{R_D}RD​​ 的横线表示低有效，写 0 才起作用。
  4. 把 Qn+1Q^{n+1}Qn+1 的上标当指数 → 误以为 Q2=Q×QQ^2=Q\times QQ2=Q×Q，式子读不通 → 上标只是第几拍的编号。
  5. 列状态表时漏掉「现态」这一列 → 每个输入都算出两个可能的次态，无法判断 → 状态表的行必须包含现态 QnQ^nQn。
  6. 主从 JK 的「一次变化现象」当成边沿触发 → 高电平期间输入变化被记住，结果与手册不符 → 主从不是边沿；现代器件用边沿触发。
  7. 默认异步清零「想什么时候按都行」 → 在时钟沿附近清零会引发竞争，状态不确定 → 异步端只在系统复位瞬间用，正常工作时接无效电平。
  8. 移位寄存器方向搞反（左移 / 右移）→ 串并转换的位序颠倒 → 先确认哪一端是「低位先入」。
