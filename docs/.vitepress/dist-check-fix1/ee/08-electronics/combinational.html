24 · 组合逻辑电路 ​

了解 约 35 min两个坑最深：把带反馈的电路当成组合逻辑；用 138 时忘了它的输出是低电平有效

这一页要解决什么：给你一张门电路图，你得说出它干什么；给你一句话需求（比如「三人表决」），你得画得出图。这一页给这两件事各一套固定流程，并说明为什么同一句需求有人画半页门、有人只用一片芯片。读完你应该能：一眼判断一个电路有没有记忆、按四步分析任意小规模电路、按五步设计并化简、用 74LS138 或 74LS151 直接实现函数而不化简、以及解释为什么一个「恒为 1」的输出在示波器上会冒负脉冲。

📎 教材下册速览：本章是《电工学》下册第 24 章（组合逻辑电路）的压缩版。完整版见数字电路课 04 · 组合逻辑电路——那里有译码器 / 选择器的完整设计与交互演示；化简工具见 02 逻辑代数与卡诺图，器件层纪律见 03 门电路。

读这页之前

  • 需要会：与、或、非三种运算，真值表的读法（23 · 数字电路基础）；二进制与十六进制（）。
  • 这一页用到的符号：AAA、BBB、CCC 是输入变量，YYY 是输出；A‾\overline{A}A 是逻辑非（读作「A 非」）；mim_imi​ 是最小项（第 iii 个输入组合对应的乘积项，三变量时 m5=A‾BCm_5=\overline{A}B Cm5​=ABC，编号 5 就是 101 的十进制值）；∑m(… )\sum m(\dots)∑m(…) 读作「这些最小项相或」；⊕\oplus⊕ 是异或。全部约定见符号与约定。
  • 两个词先给一句话：组合逻辑的每个输出只由当前输入决定；时序逻辑的输出还取决于之前存下来的状态。这两句话就是整章的骨架，第二节会给出判据。
  • 不需要先学触发器：本页所有电路都没有记忆元件；「记忆」那一半在 25 · 触发器与时序电路。

先看两个场景。第一个：老师要求做一个三人表决器，至少两人同意时输出 1。有人老老实实画三个与门、三个或门再加一堆非门，涂满半页；同桌只用一片 74LS138 加一个与非门，三根线接完。功能一模一样，器件数差了五倍——差在「知不知道该用中规模器件」。第二个：你按表达式 Y=A+A‾Y=A+\overline{A}Y=A+A 搭了一个电路，静态分析它恒等于 1，可示波器上每次输入翻转都冒一个 10 ns 的负脉冲。两个场景是同一件事的两面：怎么用最少的门实现功能，以及实现完了为什么还会骗人。

结论先行 ​

  1. 组合逻辑的判据只有一句：输出只取决于当前输入，没有「上一次」。
  2. 分析是逆向流水线（图 → 表达式 → 真值表 → 功能），设计是正向流水线（功能 → 真值表 → 表达式 → 图），两条都是四到五步，顺序不能乱。
  3. 真值表里输出为 1 的每一行写一个最小项，全体相加就是与或式——这是设计的标准入口。
  4. 译码器的输出就是全部最小项，数据选择器的地址端可以当变量用：一片中规模器件能省掉整段化简。
  5. 竞争冒险来自不同路径的门延迟不同，判据是式子里出现 A+A‾A+\overline{A}A+A 型结构，消除靠冗余项、滤波或选通。

规律层：组合逻辑的命门是「无记忆」

判断一个电路是不是组合逻辑，只问一句：输出会不会受「上一次」影响？ 不会——输出纯粹是当前输入的函数，像一张查表。所以分析与设计其实是同一条流水线的两个方向；中规模器件（编码 / 译码 / MUX / 加法器）无非是把这条流水线的某一段固化进了芯片。

一、判据：先问「有没有记忆」 ​

这一节只回答一个问题：怎么一眼看出一个电路是组合逻辑还是时序逻辑。

组合逻辑（combinational logic）指输出只由当前输入决定的电路：输入变，输出立刻跟着变；输入不变，输出就停在那里，且与「历史上发生过什么」无关。它的对立面是时序逻辑（sequential logic）：输出还取决于电路内部存着的状态。判据不在门数多少，而在有没有把输出接回输入——有反馈、有存储元件，就可能带记忆。

判据有了，可拿到一张图之后按什么顺序读？下一节把这套读法固定成四步，顺序错了会白算一遍。

二、分析四步：从图到功能 ​

这一节只做一件事：给你一张门电路图，按固定顺序把它的功能说出来。

真值表（truth table）在这一步是终点：把输入的所有组合逐行列出，输出填在同一行——它不依赖任何化简技巧，是对电路功能的完整描述。四步是：

① 从输入到输出逐级写出表达式（每个门的输出都起个名字）
② 化简
③ 列真值表（2ⁿ 行，逐行代）
④ 归纳功能（用人话说：这是加法器？比较器？多数表决？）

为什么顺序不能乱：先写表达式是为了把「级」压成「式」，式子里如果直接带中间变量，真值表就得逐级算，行数翻倍。而先化简再列表还有一个隐蔽的好处——化简后若出现 A‾B+AB‾\overline{A}B + A\overline{B}AB+AB 这类熟悉形状，功能往往一眼可辨，不必列完 8 行才发现是异或。

分析只考「读懂」，设计要反过来「造出来」。下一节把反向的流水线也固定成五步。

三、设计五步：从功能到图 ​

这一节做一件事：给你一句需求，走完五步得到一张门电路图。

最小项（minterm）是与或式的基本砖块：一个包含全部输入变量、每个变量以原变量或反变量出现一次的乘积项。nnn 个变量有 2n2^n2n 个最小项，编号就是这个组合的十进制值——三变量的 m5m_5m5​ 对应 101，所以 m5=AB‾Cm_5 = A\overline{B}Cm5​=ABC。

五步是：

① 确定输入/输出变量，给每个取值赋含义（1 表示什么、0 表示什么）
② 列真值表（2ⁿ 行，一行都不许漏）
③ 写出表达式：从输出为 1 的每一行写一个最小项，全体相或（与或式）
④ 化简（卡诺图 / 公式法）
⑤ 画逻辑图（按手头有哪种门变换形式）

与或式（sum of products）读作「先与后或」：每个最小项是一个与项，最后全体相或。第 ③ 步之所以能这么机械，是因为真值表里输出为 1 的那几行恰好就是让函数为 1 的全部条件——把它们并起来，自然覆盖所有为 1 的情形。

五步里最费时间的是第 ④ 步，而这一步有时可以整段跳过。下一节讲怎么用一片中规模器件把它省掉。

四、中规模器件：把化简这一步省掉 ​

这一节做一件事：认识四类常考器件，并记住它们各自「白送」了什么。

编码器（encoder）解决「多路里哪一路有信号」：输入 2n2^n2n 根线，输出 nnn 位二进制码。优先编码器（priority encoder）在几路同时有效时只编优先级最高的那一路——现实里总要有个先后，比如键盘同时按下两个键。以 8-3 线 74LS148 为例（输入低电平有效）：

Y2=I4+I5+I6+I7,Y1=I2+I3+I6+I7,Y0=I1+I3+I5+I7Y_2 = I_4+I_5+I_6+I_7,\quad Y_1 = I_2+I_3+I_6+I_7,\quad Y_0 = I_1+I_3+I_5+I_7 Y2​=I4​+I5​+I6​+I7​,Y1​=I2​+I3​+I6​+I7​,Y0​=I1​+I3​+I5​+I7​

译码器（decoder）是反过来：输入 nnn 位码，2n2^n2n 个输出里只有一个有效。以 3-8 线 74LS138 为例，它的输出是低电平有效（被选中的那一路输出 0，其余全 1），另有使能端（enable，G1G_1G1​、G2A‾\overline{G_{2A}}G2A​​、G2B‾\overline{G_{2B}}G2B​​）——三个使能必须都满足，芯片才工作，否则所有输出恒为 1。

它的白送之处在于：8 个输出就是三变量的全部最小项（取反形式）。于是任意三变量函数只要「把需要的几路取出、与非一下」即可：

Y(A,B,C)=∑m(1,3,5)=Y1‾⋅Y3‾⋅Y5‾‾Y(A,B,C)=\sum m(1,3,5)=\overline{\overline{Y_1}\cdot\overline{Y_3}\cdot\overline{Y_5}} Y(A,B,C)=∑m(1,3,5)=Y1​​⋅Y3​​⋅Y5​​​

数据选择器（multiplexer，MUX）是从 2n2^n2n 路数据里按地址选一路送到输出：

Y=∑imiDiY=\sum_i m_i D_i Y=i∑​mi​Di​

把地址端当逻辑变量、数据端按真值表接 0 或 1，它就变成一台通用函数发生器——连化简都不用做，代价是器件浪费（这就是它和译码器路线的取舍：省脑子还是省芯片）。

加法器是组合逻辑的样板工程：

  • 半加器（half adder）：只加两个本位，S=A⊕BS=A\oplus BS=A⊕B，C=ABC=ABC=AB，不考虑低位来的进位；
  • 全加器（full adder）：再加一个进位输入 CinC_{in}Cin​，S=A⊕B⊕CinS=A\oplus B\oplus C_{in}S=A⊕B⊕Cin​，Cout=AB+(A⊕B)CinC_{out}=AB+(A\oplus B)C_{in}Cout​=AB+(A⊕B)Cin​；
  • 多位：串行进位（低位进位一级级传，慢）对超前进位（并行算出各位进位，快）。

数值比较器（comparator）比较两个二进制数大小：1 位时 A>BA>BA>B 即 AB‾A\overline{B}AB；多位从高位往低位比，高位分出胜负就不再管低位。

器件本身没错，错的是「多个信号同时变」时的时序。下一节解释为什么一个静态分析恒为 1 的输出会冒脉冲。

五、竞争冒险：恒为 1 的输出为什么冒负脉冲 ​

这一节只回答一个问题：一个理论上永远输出 1 的电路，为什么示波器上每次输入翻转都冒一个窄脉冲。

竞争（race）指同一个信号经不同路径到达同一个门的时间不同；冒险（hazard）指竞争造成的错误输出；那个窄脉冲俗称毛刺（glitch）。判据很具体：表达式里某个变量同时以原变量和反变量出现，且两条路径延迟不等，就可能冒险——最典型的是 Y=A+A‾Y=A+\overline{A}Y=A+A：静态看恒为 1，动态时 A 先变、A‾\overline{A}A 后变，中间那一小段两个输入都是 0，输出就掉下去了。

三种消除办法，按工程上从便宜到彻底的顺序：

  1. 加冗余项（在卡诺图上补一个「多余」的圈）：给 Y=AB+A‾CY=AB+\overline{A}CY=AB+AC 补上 BCBCBC 这一项——它平时被另外两项覆盖、不影响函数值，但当 B=C=1B=C=1B=C=1、AAA 正在翻转时 BCBCBC 始终为 1，毛刺就被兜住了。代价是多一个门。
  2. 加滤波电容：靠电容把窄脉冲「磨平」，最简单，但会拖慢边沿，高速电路不能用。
  3. 加选通脉冲：等信号稳定后再取样，本质是把「什么时候读输出」这件事推迟到毛刺之后。

到这里三件事齐了：判据、流程、器件与陷阱。下面用两道题把它们串成动作。

六、例题 ​

两道题方向相反：例 1 是「用现成芯片实现函数」（省掉化简），例 2 是「从需求画到图」（走完五步）。每道题都先看「先想什么」——那是方法选择。

例 1 · 用 74LS138 实现 Y=∑m(1,3,5)Y=\sum m(1,3,5)Y=∑m(1,3,5)

题目：只用一片 74LS138 和一个门，实现三变量函数 Y=∑m(1,3,5)Y=\sum m(1,3,5)Y=∑m(1,3,5)。

先想什么：题目没有要求「门数最少」，只要求用 138——这就是提示：别去化简，直接把最小项拿来用。138 的 8 个输出恰好是三变量的全部最小项（低有效），所以 YYY 等于「m1,m3,m5m_1,m_3,m_5m1​,m3​,m5​ 中至少一个为真」，也就是三个低有效输出里至少一个为 0。这个逻辑正是与非门。

步骤：

  1. 地址端接线：题目说 AAA 是最高位，所以 A→A\toA→ 138 的最高地址端，C→C\toC→ 最低地址端。（为什么必须按位序接：地址端接反时输入码与实际最小项编号错位，八个输出全乱。）
  2. 使能端接有效电平：G1=1G_1=1G1​=1、G2A‾=0\overline{G_{2A}}=0G2A​​=0、G2B‾=0\overline{G_{2B}}=0G2B​​=0。（为什么单独强调：138 不使能时所有输出恒为 1，此时 YYY 恒为 0，现象是「完全没反应」，非常难查。）
  3. 三个需要的输出 Y1‾\overline{Y_1}Y1​​、Y3‾\overline{Y_3}Y3​​、Y5‾\overline{Y_5}Y5​​ 接到三输入与非门。（为什么用与非门而不是与门：输出低有效，1 在输出上表现为 0，所以「取或」要变成「取与非」。）
  4. 写出表达式：Y=Y1‾⋅Y3‾⋅Y5‾‾Y=\overline{\overline{Y_1}\cdot\overline{Y_3}\cdot\overline{Y_5}}Y=Y1​​⋅Y3​​⋅Y5​​​。

验算（逐行对）：ABC=001ABC=001ABC=001 时 Y1‾=0\overline{Y_1}=0Y1​​=0，与非门「有 0 出 1」→ Y=1Y=1Y=1 ✓；011011011、101101101 同理为 1 ✓；其余五种输入时三个输出全为 1，与非门输出 0 ✓。八行全部吻合。

若手头只有与门：每个输出后各串一级非门，把 Yi‾\overline{Y_i}Yi​​ 变回 YiY_iYi​，再用或门合并——功能相同，多三个门。这就是「按手头器件变形」那一步的实际含义。

例 2 · 设计三人表决器

题目：三个人各投一票（赞成 = 1），多数赞成时通过（Y=1Y=1Y=1）。按设计五步走一遍。

先想什么：三个输入、一个输出，需求是「1 的个数 ≥ 2」。这是一句关于个数的话，不是关于某个变量的话——所以真值表按「数 1 的个数」填，比硬背更快；化简后期望得到三项，每项对应「某两人同时赞成」。

  1. 定变量：输入 AAA、BBB、CCC（各代表一个人的票，1 = 赞成），输出 YYY（1 = 通过）。（为什么先赋值含义：不写清 1 代表什么，真值表填到一半就会犹豫。）

这一节最该带走的一句：所有「多数」「至少几个」的需求，化简后都会变成「两两组合」的样子，可以直接当结论记住。

易错清单 ​

按踩坑频率从高到低排，格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 把带反馈的电路当组合逻辑 → 列出的真值表与实际输出对不上，越算越乱 → 先找有没有输出回流到输入，有就按时序电路分析。
  2. 用 138 实现函数时忘了输出低有效 → 用与门去合并，得到的是原函数的反 → 用与非门合并；只有与门时先各串一级非门。
  3. 使能端漏接或接反 → 芯片不工作，所有输出恒 1，表现出来是「完全没反应」 → 三个使能端按有效电平接死。
  4. 优先编码器的优先级搞反 → 编码结果指向错的那一路 → 通常下标大的优先（I7I_7I7​ 最高），查手册确认。
  5. 真值表漏行 → nnn 变量只写了 2n−22^n-22n−2 行，化简出错的项找不到来源 → 习惯按 000、001、010…顺序写满。
  6. 卡诺图圈 3 格或 5 格 → 写出的项变量个数对不上 → 圈只能是 2k2^k2k 格。
  7. 以为静态分析正确就没问题 → 实际电路在输入翻转瞬间冒毛刺，下游误触发 → 检查 A+A‾A+\overline{A}A+A 型结构，必要时加冗余项。

自检 ​

  1. 一个八输入、三输出的电路，所有门都没有反馈——它一定是组合逻辑吗？为什么？
  2. 为什么译码器的输出「就是全部最小项」？低电平有效这件事让表达式多了什么？
  3. 表达式 Y=AB+A‾CY=AB+\overline{A}CY=AB+AC 里有没有竞争冒险的可能？如果有，冗余项应该加哪一项？
