24 · 组合逻辑电路 ​

📎 教材下册速览：本章是《电工学》下册第 24 章 · 组合逻辑电路的压缩版。完整版见数字电路课 04 · 组合逻辑电路——那里有译码器/选择器的完整设计与交互演示。

了解 约 25 min编码器/译码器/数据选择器 + 分析与设计两步走

结论先行 ​

  1. 组合逻辑：输出只取决于当前输入，无记忆（区别于时序逻辑）
  2. 分析：逻辑图 → 表达式 → 真值表 → 功能描述
  3. 设计：功能 → 真值表 → 表达式 → 化简 → 逻辑图
  4. 中规模器件：编码器（多→少）、译码器（少→多）、数据选择器 MUX（多选一）、加法器
  5. 竞争冒险：门延迟不同导致瞬间毛刺 → 加滤波电容或冗余项或选通脉冲消除

规律层：组合逻辑的命门是「无记忆」

判断一个电路是不是组合逻辑，只问一句：输出会不会受「上一次」影响？ 不会——输出纯粹是当前输入的函数，像一张查表。所以分析与设计其实是同一条流水线的两个方向：分析是「逻辑图 → 表达式 → 真值表 → 功能」，设计反过来「功能 → 真值表 → 表达式 → 逻辑图」。那些中规模器件（编码 / 译码 / MUX / 加法）无非是把这条流水线的某一段固化进了芯片。

分析与设计 ​

分析（拿到电路图）：

① 从输入到输出逐级写出表达式
② 化简
③ 列真值表
④ 归纳功能

设计（拿到功能需求）：

① 确定输入/输出变量，赋值含义
② 列真值表
③ 写出表达式（从输出为 1 的行写"与或式"）
④ 化简（卡诺图 / 公式法）
⑤ 画逻辑图（按可用门的类型变换形式）

常用中规模器件 ​

编码器（如 8-3 线优先编码器 74LS148） ​

输入 I0∼I7I_0\sim I_7I0​∼I7​（低电平有效），输出 3 位二进制码。优先编码器按优先级高的输入编码。

译码器（如 3-8 线译码器 74LS138） ​

输入 3 位码，8 个输出中只有一个有效（低电平有效则其余为高）。

关键用法：译码器输出 = 全部最小项 → 加一个门就能实现任意 3 变量逻辑函数：

Y(A,B,C)=∑m(1,3,5)=Yˉ1⋅Yˉ3⋅Yˉ5‾Y(A,B,C) = \sum m(1,3,5) = \overline{\bar Y_1 \cdot \bar Y_3 \cdot \bar Y_5} Y(A,B,C)=∑m(1,3,5)=Yˉ1​⋅Yˉ3​⋅Yˉ5​​

例 1 · 用 74LS138 实现 Y=∑m(1,3,5)Y = \sum m(1,3,5)Y=∑m(1,3,5)

把 A,B,CA, B, CA,B,C 接到 138 的地址端（AAA 接最高位），三个使能端都接有效电平。138 的输出是低电平有效：输入为 iii 时 Yˉi=0\bar Y_i = 0Yˉi​=0，其余为 1。所以要实现的 1 在 m1,m3,m5m_1, m_3, m_5m1​,m3​,m5​，就把 Yˉ1,Yˉ3,Yˉ5\bar Y_1, \bar Y_3, \bar Y_5Yˉ1​,Yˉ3​,Yˉ5​ 三个输出接到一个三输入与非门：

Y=Yˉ1⋅Yˉ3⋅Yˉ5‾Y = \overline{\bar Y_1 \cdot \bar Y_3 \cdot \bar Y_5} Y=Yˉ1​⋅Yˉ3​⋅Yˉ5​​

验算（逐行对）：ABC=001ABC = 001ABC=001 时 Yˉ1=0\bar Y_1 = 0Yˉ1​=0，与非门「有 0 出 1」→ Y=1Y = 1Y=1 ✓；ABC=011ABC = 011ABC=011、101101101 同理为 1 ✓；其余五种输入下三个输出全为 1，与非门输出 0 ✓。八行全部吻合。

易错点：输出低有效 means 要用与非门（不是与门）；若手头只有与门，得在每个输出后再串一级非门。另外三个使能端漏接是常见失分点——138 不使能时所有输出全是 1，YYY 恒 0。

数据选择器 MUX（如 8 选 1 74LS151） ​

Y=∑imiDiY = \sum_{i} m_i D_i Y=i∑​mi​Di​

把地址端当作逻辑变量、数据端接 0/1 → 可实现任意组合逻辑（不用化简）。

加法器 ​

  • 半加器：S=A⊕BS = A\oplus BS=A⊕B，C=ABC = ABC=AB（不考虑低位进位）
  • 全加器：S=A⊕B⊕CinS = A\oplus B\oplus C_{in}S=A⊕B⊕Cin​，Cout=AB+(A⊕B)CinC_{out} = AB + (A\oplus B)C_{in}Cout​=AB+(A⊕B)Cin​
  • 多位：串行进位（慢）/ 超前进位（快）

数值比较器 ​

1 位：A>BA>BA>B 即 ABˉA\bar BABˉ；多位从高位比到低位。

竞争冒险 ​

不同路径的门延迟不同 → 输出出现不应有的窄脉冲（毛刺）。

判断：表达式中某变量同时以原变量和反变量出现（如 Y=A+AˉY = A + \bar AY=A+Aˉ 型）→ 可能冒险。

消除方法：

  1. 加滤波电容（最简单，但会拖慢边沿）
  2. 增加冗余项（卡诺图加一个多余的圈）
  3. 加选通脉冲（等稳定后再取样）

易错点

  • 组合逻辑没有记忆，输出只由当前输入决定；看到"上一次输出"影响这次就是时序电路
  • 74LS138 输出是低电平有效（YiY_iYi​ 上面有横线），实现函数时要取反再与
  • 用译码器实现函数时别忘了使能端要接有效电平
  • 优先编码器的优先级是下标大的优先（通常 I7I_7I7​ 最高）
