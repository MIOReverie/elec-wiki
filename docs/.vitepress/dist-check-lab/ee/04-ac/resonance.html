11 · 谐振与频率特性 ​

了解 约 35 minQ 值是全章的主角：选择性好和通频带宽是一对矛盾

结论先行 ​

  1. 串联谐振条件：XL=XCX_L = X_CXL​=XC​ → ω0=1LC\omega_0 = \dfrac{1}{\sqrt{LC}}ω0​=LC​1​。此时 Z=RZ = RZ=R 最小、III 最大、UUU 与 III 同相
  2. UL=UC=QUU_L = U_C = QUUL​=UC​=QU —— 可能远高于电源电压（电压谐振，可击穿元件）
  3. Q=ω0LR=1ω0CR=1RLCQ = \dfrac{\omega_0 L}{R} = \dfrac{1}{\omega_0 C R} = \dfrac{1}{R}\sqrt{\dfrac{L}{C}}Q=Rω0​L​=ω0​CR1​=R1​CL​​，BW=f0QBW = \dfrac{f_0}{Q}BW=Qf0​​（精确成立，非近似）
  4. QQQ 大 → 选择性好但通频带窄；QQQ 小 → 反之。这是全章唯一的矛盾
  5. 并联谐振：阻抗最大（=R=R=R）、总电流最小，支路电流 IL≈IC=QII_L \approx I_C = QIIL​≈IC​=QI（电流谐振）

规律层：谐振的本质只有一句话

谐振 = 感抗与容抗恰好抵消、电路整体退化成纯电阻的那一个频率点。所有「高 QQQ」「窄带宽」「电压 / 电流谐振」都是这句话的推论，不是独立的新规律。先记住 ω0=1/LC\omega_0 = 1/\sqrt{LC}ω0​=1/LC​（只由 LLL、CCC 决定，与 RRR 无关），其余都是围绕它的展开。

一、串联谐振：电抗归零的那一刻 ​

RLC 串联的阻抗 Z=R+j(XL−XC)Z = R + j(X_L - X_C)Z=R+j(XL​−XC​)。当

XL=XC  ⇒  ω0L=1ω0C  ⇒  ω0=1LC,f0=12πLCX_L = X_C \;\Rightarrow\; \omega_0 L = \frac{1}{\omega_0 C} \;\Rightarrow\; \boxed{\omega_0 = \frac{1}{\sqrt{LC}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}} XL​=XC​⇒ω0​L=ω0​C1​⇒ω0​=LC​1​,f0​=2πLC​1​​

谐振瞬间，电抗部分整体消失，电路退化成一个纯电阻：

谐振频率 f0f_0f0​ 只由 LLL 和 CCC 决定，与电阻无关 —— RRR 只影响曲线的「尖」与「钝」。

通用谐振曲线 ​

把电流归一化，f0f_0f0​ 和 RRR 都被约掉，得到一条只含 QQQ 的曲线：

II0=11+Q2(η−1η)2,η=ff0\boxed{\frac{I}{I_0} = \frac{1}{\sqrt{1 + Q^2\left(\eta - \dfrac{1}{\eta}\right)^2}}, \qquad \eta = \frac{f}{f_0}} I0​I​=1+Q2(η−η1​)2​1​,η=f0​f​​

二、品质因数 Q：一个数字决定全部 ​

Q=ω0LR=1ω0CR=1RLCQ = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{1}{R}\sqrt{\frac{L}{C}} Q=Rω0​L​=ω0​CR1​=R1​CL​​

三个表达式等价（用 ω02=1/LC\omega_0^2 = 1/LCω02​=1/LC 互推），考题里已知条件不同就换着用。QQQ 的物理意义有两层：

  1. 电压放大倍数：UL=UC=QUU_L = U_C = Q UUL​=UC​=QU。谐振时电感（或电容）上的电压是电源的 QQQ 倍
  2. 能量保持能力：Q=2π×储能每周期耗能Q = 2\pi \times \dfrac{\text{储能}}{\text{每周期耗能}}Q=2π×每周期耗能储能​。QQQ 越大，能量在回路里「存活」的周期数越多

电力系统为什么怕串联谐振

UL=QUU_L = QUUL​=QU 意味着 Q=30Q = 30Q=30 的回路里，电容或电感要承受 30 倍额定电压 —— 绝缘直接击穿。所以电力系统中串联谐振是要预防的事故（铁磁谐振过电压），而无线电里是主动利用的工具。同一个物理现象，立场决定态度。

三、通频带：半功率点与 BW ​

工程上定义 半功率点：电流降到 I0/2I_0/\sqrt2I0​/2​ 的频率（此处 P=I2RP = I^2RP=I2R 也降到 Pmax/2P_{max}/2Pmax​/2，功率减半）。两个半功率点 f1f_1f1​、f2f_2f2​ 之间就是通频带：

BW=f2−f1BW = f_2 - f_1 BW=f2​−f1​

代入通用曲线，令 I/I0=1/2I/I_0 = 1/\sqrt2I/I0​=1/2​：

Q2(η−1η)2=1  ⇒  η1,2=∓ 1/Q+1/Q2+42Q^2\left(\eta - \frac{1}{\eta}\right)^2 = 1 \;\Rightarrow\; \eta_{1,2} = \frac{\mp\,1/Q + \sqrt{1/Q^2 + 4}}{2} Q2(η−η1​)2=1⇒η1,2​=2∓1/Q+1/Q2+4​​η2−η1=1Q  ⇒  BW=f0Q\eta_2 - \eta_1 = \frac{1}{Q} \;\Rightarrow\; \boxed{BW = \frac{f_0}{Q}} η2​−η1​=Q1​⇒BW=Qf0​​​

注意这个结果是精确的（不是高 QQQ 近似），QQQ 高达几百时误差才需要考虑。于是：

  • QQQ 翻倍 → 曲线尖一倍 → 选择性好一倍，但通频带窄一倍
  • QQQ 减半 → 通频带宽一倍，但邻台也漏进来一倍

同一个 Q，两种相反的需求

  • 收音机选台：要 QQQ 大。中频 465 kHz、带宽 10 kHz，Q=46.5Q = 46.5Q=46.5 —— 专门把邻台摁掉
  • 音频放大：要 QQQ 小。20 Hz – 20 kHz 全通过，QQQ 甚至不需要「谐振」这个概念
  • 示波器探头：QQQ 要精确补偿到 1 附近，否则方波过冲振铃 —— 这就是探头上的补偿电容要拿螺丝刀调的原因

四、并联谐振：阻抗的峰 ​

RLC 并联（理想元件），用导纳分析更自然：

Y=1R+j(ωC−1ωL)Y = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right) Y=R1​+j(ωC−ωL1​)

谐振条件 B=ωC−1/(ωL)=0B = \omega C - 1/(\omega L) = 0B=ωC−1/(ωL)=0 —— 同一个 ω0\omega_0ω0​。此时：

  • 导纳模最小：∣Y∣=1/R|Y| = 1/R∣Y∣=1/R
  • 阻抗模最大：∣Z∣=R|Z| = R∣Z∣=R
  • 总电流最小：I0=U/RI_0 = U/RI0​=U/R
  • 支路电流 IL≈IC=QII_L \approx I_C = QIIL​≈IC​=QI（Q=R/ω0LQ = R/\omega_0 LQ=R/ω0​L），可能远大于总电流

例 3 · 并联谐振

R=1 kΩR = 1\,\text{k}\OmegaR=1kΩ、L=1 mHL = 1\,\text{mH}L=1mH、C=1 μFC = 1\,\mu\text{F}C=1μF 并联，接 U=100U = 100U=100 V。求 f0f_0f0​、谐振时的总电流和支路电流。

元件选型按支路电流

电源只供出 100 mA，电感/电容里却流过 3.16 A（31.6 倍）！所以并联谐振回路里，电感和电容要按支路电流选型，熔断器/导线也按支路电流配 —— 按总电流配会在谐振时烧毁。

「电流谐振」的名字就是这么来的：大电流在 L、C 之间来回晃，电源几乎不出力。

:::

工程实例 ​

  • 收音机选台：天线回路 + 可变电容组成串联谐振回路，QQQ 做到几十，只让目标电台的信号「起振」进放大器，邻台被抑制。转动旋钮改变 CCC → 改变 f0f_0f0​ → 选台。
  • 中频放大器：超外差接收机把各电台统一搬到 465 kHz 中频，中周（中频变压器）就是 465 kHz 的谐振回路，负责筛出中频、抑制邻近频率。
  • 阻波器：电力线上并联谐振回路串在载波通信里，对 50 Hz 呈高阻抗（不挡工频电流），对高频通信信号呈低阻抗（让高频通过）。
  • 铁磁谐振过电压（事故）：电网中电感（变压器、互感器）与电容（电缆、断口）偶然构成串联谐振，ULU_LUL​ 过电压数倍，烧毁设备。防止办法：破坏谐振条件（接入阻尼电阻）或避免中性点直接接地运行方式。
  • 石英晶体谐振器：QQQ 值高达 104∼10610^4 \sim 10^6104∼106，频率稳定度远胜 LC 回路 —— 所有精密时钟（单片机晶振、手表）都靠它。

易错点（按踩坑频率排序） ​

  1. 谐振频率 f0f_0f0​ 与 RRR 无关，只由 LLL、CCC 决定
  2. QQQ 公式里 RRR 是回路总电阻（含电感线圈自身电阻），不只是外接电阻
  3. 串联谐振 UL=QUU_L = QUUL​=QU 很大 → 元件耐压按 QUQUQU 选，不是按 UUU
  4. 并联谐振支路电流 =QI= QI=QI → 元件按支路电流选型，不是总电流
  5. BW=f0/QBW = f_0/QBW=f0​/Q 是精确结果，不是高 QQQ 近似
  6. 串联谐振 ZZZ 最小、并联谐振 ZZZ 最大 —— 说反了整个应用全反
  7. 电力系统防谐振，无线电用谐振 —— 应用场景别搞混
  8. 并联谐振若考虑线圈电阻，谐振频率略低于 1/LC1/\sqrt{LC}1/LC​（理想公式的前提要知道）
