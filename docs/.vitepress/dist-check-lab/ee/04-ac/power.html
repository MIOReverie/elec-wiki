10 · 功率与功率因数 ​

核心 约 40 minP / Q / S 三个功率的关系，以及为什么要并联电容

结论先行 ​

  1. P=UIcos⁡φP = UI\cos\varphiP=UIcosφ（有功，W）、Q=UIsin⁡φQ = UI\sin\varphiQ=UIsinφ（无功，var）、S=UIS = UIS=UI（视在，VA）

  3. 无功不是「没用」，而是在电源与储能元件之间来回交换的能量 —— 但它照样占线路、占变压器容量
  4. 提高 cos⁡φ\cos\varphicosφ 的方法：在负载两端并联电容（串联不行，会改变负载电压）

无功到底有没有用

「无功」常被误解成「没用的功」。更准确的说法：它是建立磁场（电机）或电场（电容）所必须的能量，只是它在电源和负载之间来回流动、平均不消耗。没有无功，变压器不能变压、电机不能转 —— 但线路流过它照样发热、照样占用发电机容量。所以工程上不是消灭无功，是就地补偿，别让它在电网里长途奔波。

三、为什么要提高功率因数：算一笔账 ​

PPP 一定时，I=PUcos⁡φI = \dfrac{P}{U\cos\varphi}I=UcosφP​ —— 功率因数越低，电流越大：

电流一大，三个后果全是钱：

  1. 线路损耗 I2R线I^2R_{线}I2R线​ 剧增。电流翻倍 → 损耗变四倍
  2. 线路压降 IR线IR_{线}IR线​ 增大，末端电压不足（用户灯不亮、电机转不动）
  3. 电源容量被白白占用。一台 100 kVA 的变压器，负载 cos⁡φ=0.7\cos\varphi = 0.7cosφ=0.7 时只能带 70 kW 的有功负载；补到 0.95 能带 95 kW —— 同一台设备，多带 36% 的负荷

一个量化直觉

cos⁡φ\cos\varphicosφ 每降一档，成本是指数上升的：0.5 → 2.0 倍电流，0.6 → 1.67 倍，0.7 → 1.43 倍，0.8 → 1.25 倍，0.9 → 1.11 倍。

所以供电局把 0.9 设为考核线：低于它要收力率调整电费（罚款），高于它有奖励。

四、并联电容补偿：完整推导 ​

心智模型：并联电容补偿「只动线路、不动负载」

补偿的本质是给无功电流在负载旁边开一条「就近泄放」的支路，让电源少送无功。它绝不改变负载两端的电压，因此负载本身的工作状态（电流、功率、功率因数）纹丝不动——变的是从电网吸取的总电流。这也是为什么必须并联、不能串联：串联会改变负载分压，破坏负载工作点。

相量图推导 ​

以 U˙=U∠0°\dot U = U\angle0°U˙=U∠0° 为参考。补偿前，负载电流 I˙1\dot I_1I˙1​ 滞后 φ1\varphi_1φ1​，拆成两个分量：

I˙1=I1cos⁡φ1⏟有功分量 I˙a+jI1sin⁡φ1⏟无功分量（滞后为正）\dot I_1 = \underbrace{I_1\cos\varphi_1}_{\text{有功分量 } \dot I_a} + \underbrace{jI_1\sin\varphi_1}_{\text{无功分量（滞后为正）}} I˙1​=有功分量 I˙a​I1​cosφ1​​​+无功分量（滞后为正）jI1​sinφ1​​​

并联电容后，电容电流 I˙C\dot I_CI˙C​ 超前电压 90°（电容的天性）：

I˙2=I˙1+I˙C\dot I_2 = \dot I_1 + \dot I_C I˙2​=I˙1​+I˙C​

因为 I˙C\dot I_CI˙C​ 与无功分量方向相反，它把无功分量抵消掉一部分，而有功分量分毫未动：

I˙C=−j(I1sin⁡φ1−I2sin⁡φ2)\dot I_C = -j(I_1\sin\varphi_1 - I_2\sin\varphi_2) I˙C​=−j(I1​sinφ1​−I2​sinφ2​)

电容提供的无功（电容发出无功，符号取负的约定下）：

QC=Q1−Q2=Ptan⁡φ1−Ptan⁡φ2Q_C = Q_1 - Q_2 = P\tan\varphi_1 - P\tan\varphi_2 QC​=Q1​−Q2​=Ptanφ1​−Ptanφ2​QC=P(tan⁡φ1−tan⁡φ2),C=QCωU2=P(tan⁡φ1−tan⁡φ2)ωU2\boxed{Q_C = P(\tan\varphi_1 - \tan\varphi_2), \qquad C = \frac{Q_C}{\omega U^2} = \frac{P(\tan\varphi_1 - \tan\varphi_2)}{\omega U^2}} QC​=P(tanφ1​−tanφ2​),C=ωU2QC​​=ωU2P(tanφ1​−tanφ2​)​​

三个前提：PPP 不变（补偿不改变负载）、UUU 是电容两端电压（通常取电源电压）、单位统一（P 用 W 还是 kW，CCC 的单位跟着变）。

为什么必须并联，不能串联 ​

串联电容也会改变功率因数，但它同时改变了负载分压 —— 负载端电压不再是电源电压，负载的工作状态被破坏（灯变暗、电机转速变）。并联则不然：电容直接跨接在电源/负载两端，负载电压不变，只是给无功电流提供一条「就近泄放」的通道。

过补偿 ​

补偿过头（cos⁡φ2\cos\varphi_2cosφ2​ 超过 1 变成容性），I˙2\dot I_2I˙2​ 从滞后变成超前 —— 线路电流重新变大，还会抬高末端电压。所以补偿目标一般定在 0.9 ~ 0.95，刻意留一点感性。

例 4 · 概念题（判断题高频）

判断：(a) 并联电容后，负载本身的电流、功率因数都不变。(b) 串联电容也能提高功率因数，工程上可以替代并联。(c) 补偿电容越大越好。

解

(a) 对。 负载两端电压没变、负载自身参数没变，所以负载的电流 I1I_1I1​、功率 cos⁡φ1\cos\varphi_1cosφ1​ 原封不动。变的是线路总电流（I1+ICI_1 + I_CI1​+IC​ 的相量和 I2<I1I_2 < I_1I2​<I1​）。这是全章最重要的一句话。

(b) 错。 串联电容会分压，负载端电压 UL≠UU_L \ne UUL​=U，工作点被改变 —— 电机可能过压、灯可能变暗。并联方案中电容与负载承受同一电压，互不干扰。

(c) 错。 补到 cos⁡φ≈1\cos\varphi \approx 1cosφ≈1 之后继续加电容就过补偿了：I˙2\dot I_2I˙2​ 反变成超前，线路电流重新增大，末端电压被抬高，甚至危及绝缘。经济最优通常补到 0.9 ~ 0.95。

工程实例 ​

  • 电容补偿柜：工厂配电室里一排排金属柜，里面是分组的三相电力电容器（每相多个电容并联后星接）。控制器检测实时 cos⁡φ\cos\varphicosφ，欠补偿就多投一组，过补偿就退一组 —— 你车间里那台「嗡嗡响的铁柜」干的就是这件事。
  • 异步电动机：空载时 cos⁡φ\cos\varphicosφ 只有 0.2 ~ 0.3（几乎纯感性，只建立磁场不带负载）。这就是「大马拉小车」费电的数学根源：电机选型偏大会让全厂功率因数被拖垮。
  • 家用光伏逆变器：现代逆变器能主动发出/吸收无功，帮屋顶弥补本地无功 —— 户用场景补偿不起电容柜时，这是替代方案。
  • 电费单：工商业电费里有一项「力率调整电费」，就是按全月平均 cos⁡φ\cos\varphicosφ 奖惩。低于 0.9 罚款，高于 0.9 奖励 —— 功率因数直接写在钱上。

易错点（按踩坑频率排序） ​

  1. 并联补偿后负载本身的 III、PPP、cos⁡φ\cos\varphicosφ 全都不变，变的只是线路总电流
  2. 公式里 PPP 用 kW、CCC 算出来却忘了换算（10310^3103 的坑）
  3. UUU 用错：单相取端电压，三相要用相电压（见第 13 章 · 三相功率与测量，公式变为 QC=P(tan⁡φ1−tan⁡φ2)Q_C = P(\tan\varphi_1-\tan\varphi_2)QC​=P(tanφ1​−tanφ2​)、C=QC/(3ωU相2)C = Q_C/(3\omega U_{相}^2)C=QC​/(3ωU相2​)）
  4. 无功 QQQ 的符号：感性负载 Q>0Q > 0Q>0（吸收），电容 Q<0Q < 0Q<0（发出）
  5. 复功率是 U˙I˙∗\dot U\dot I^*U˙I˙∗，用了 I˙U˙∗\dot I\dot U^*I˙U˙∗ 无功反号
  6. 过补偿的危害（电压升高、电流反弹）常被忽略
  7. 把 cos⁡φ\cos\varphicosφ 当角度直接代入三角函数的反函数时搞反（φ=arccos⁡cos⁡φ\varphi = \arccos\cos\varphiφ=arccoscosφ，不是 cos⁡φ=arccos⁡φ\cos\varphi = \arccos\varphicosφ=arccosφ）
