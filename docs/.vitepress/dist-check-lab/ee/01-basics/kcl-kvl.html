02 · 基尔霍夫定律与电位 ​

核心 约 45 minKCL/KVL 是整门课的两根柱子，后面所有方法都是它们的变形

结论先行 ​

  1. KCL（结点）：∑I=0\sum I = 0∑I=0，即流入 = 流出。本质是电荷守恒。
  2. KVL（回路）：∑U=0\sum U = 0∑U=0，即电位升 = 电位降。本质是能量守恒。
  3. 两者与元件性质无关（线性/非线性、直流/交流都成立），只取决于电路的连接方式（拓扑）。
  4. 电位是相对参考点的量；换参考点电位全变，但任意两点间电压不变。
  5. 独立方程数：nnn 个结点有 n−1n-1n−1 个独立 KCL，bbb 条支路有 b−n+1b-n+1b−n+1 个独立 KVL。这两个数字只与拓扑有关，算题前先写出来。

一句话抓住本质，后面所有方法都是它的变形

  • KCL = 对「点」（结点）列电流：流入 = 流出。
  • KVL = 对「回路」列电压：电位升 = 电位降。
  • 支路电流法、网孔法、结点电压法（下一章）不是新规律，只是 KCL/KVL 搭配欧姆定律的不同「消元策略」。把这两根柱子吃透，后面全是应用。

一、为什么需要它们：两条守恒律 ​

电路里没有别的守恒律可用，只有两条：

守恒的东西作用范围数学形式
KCL电荷任意闭合面（不限于结点）∑I=0\sum I = 0∑I=0
KVL能量任意闭合回路∑U=0\sum U = 0∑U=0

这两条之所以成立，是因为电路本身不允许"凭空产生电荷"或"凭空产生能量"。

一个物理图像

把电路想象成一个连通的水管网络。KCL 是"任一封闭容器里既不凭空多水也不凭空少水"；KVL 是"沿一圈走回原点，水位差总和为零"。所以两点之间的电压与路径无关 —— 你从哪条路"量"都一样，这个性质保证了电位能定义。

二、KCL：结点电流定律 ​

KCL · 结点电流

∑I入=∑I出或∑I=0\sum I_{\text{入}} = \sum I_{\text{出}} \qquad \text{或} \qquad \sum I = 0 ∑I入​=∑I出​或∑I=0

广义结点：把 nnn 个结点、bbb 条支路包含进一个任意闭合面，穿过该面的电流代数和同样为 0。这在"求某一部分电路的总电流"时非常省事。

两个必须记牢的性质：

  1. 只认"穿进/穿出"，不认元件是什么。电阻、电容、电源、受控源一视同仁。
  2. 电流带符号。约定流入为正、流出为负（或反之，全题统一即可），代数相加。

广义结点：一个能立刻用的技巧 ​

问"流入某块的电流 III 是多少"，不用逐条支路算 —— 直接在块外面画个圈，对穿过这个圈的电流列一次 KCL，一个方程搞定。

这在求"流入放大器输入端的偏置电流"、"某条主干线上的总电流"时是省时间的关键。

三、KVL：回路电压定律 ​

先任意指定绕行方向，沿方向走：经过电阻"+"→"−"记 +IRIRIR（电位降），"−"→"+" 记 −IRIRIR；经过电源"−"→"+++" 记 +E+E+E，"+++"→"−" 记 −E-E−E。全程代数和为 0。

∑U=0例如E−IR1−IR2−IR3=0\sum U = 0\quad\text{例如}\quad E - IR_1 - IR_2 - IR_3 = 0 ∑U=0例如E−IR1​−IR2​−IR3​=0

唯一的纪律：绕行方向一旦选定，全程不要改。 改了就等于给自己换了一套符号，结果必然自相矛盾。

KVL 的两种列法

  1. 全电压式（沿圈把每个元件的 uuu 加起来）：适合串联回路，一步到位。
  2. 电位式（只写电源，靠"电位升=电位降"）：适合多电源网络，能省掉所有电阻项，因为纯电阻串联分压可以直接用电位差。

考试里如果题目要"各点电位"，第 2 种更省事。

四、电位：参考点是人为选的 ​

电位与电压

Uab=Va−VbU_{ab} = V_a - V_b Uab​=Va​−Vb​

参考点电位规定为 0。求某点电位：从该点沿任意路径"走"到参考点，把沿途电压降代数相加。

关键认知：电位是"相对量"，电压是"绝对量"。

  • 换参考点，所有 VVV 都会平移同一个常数，但 UabU_{ab}Uab​ 完全不变。
  • 所以没说参考点的电位是"没意义的"。题目没给参考点，你可以自己选一个（习惯选：多条支路的公共汇合点、电源负极、接地符号处）。

五、独立方程数：算题前先算这个 ​

这是最容易被忽视、也最省时间的一条：

独立 KCL 数=n−1独立 KVL 数=b−n+1\boxed{\text{独立 KCL 数} = n-1}\qquad \boxed{\text{独立 KVL 数} = b-n+1} 独立 KCL 数=n−1​独立 KVL 数=b−n+1​

其中 nnn = 结点数，bbb = 支路数。两者之和 =b=b=b，正好等于未知支路电流的个数。

用法举例：4 个结点、6 条支路 → 独立 KCL = 3，独立 KVL = 6-4+1 = 3。列 3 个 KCL + 3 个 KVL 正好解 6 个支路电流。

"独立"体现在哪：nnn 个结点里，任选一个作参考点，剩下 n−1n-1n−1 个各有独立方程（对参考点列 KCL 得到的是 0=00=00=0，无信息）。

概念判断题常在这里

问"若 nnn 个结点 bbb 条支路，则可列出的独立 KCL 与独立 KVL 方程数分别为" —— 答案是 (n−1,  b−n+1)(n-1,\;b-n+1)(n−1,b−n+1)，记死。

六、典型题型与套路 ​

题型 A：求各点电位 ​

① 选参考点（没给就自己选）
② 用 KVL/KCL 求出回路电流
③ 从已知点沿任意路径逐段累加电压降

题型 B：求开路电压（UocU_{oc}Uoc​） ​

假想回路法：在开路处补一条支路，设其电流为 III（其实 I=0I=0I=0，但先留着）。列方程时含 IRIRIR 的项会自己消掉（因为 I=0I=0I=0），方程自然化简。若题目给的电阻中恰好有一个 RRR，可以故意把 III 设成 ER\dfrac{E}{R}RE​，这样该项不为零、但可整除掉。

这是"电桥/复杂网络求开路电压"的唯一实用套路。

题型 C：求两点间电压 ​

优先找不经过元件内部的路径（沿导线走），因为导线上无压降，能大幅简化。

例 1 · 完整解 KVL：两电源串联回路

E1=12VE_1 = 12\text{V}E1​=12V、E2=6VE_2 = 6\text{V}E2​=6V、R1=R2=2ΩR_1 = R_2 = 2\OmegaR1​=R2​=2Ω、R3=4ΩR_3 = 4\OmegaR3​=4Ω 构成一个串联回路（E1E_1E1​、E2E_2E2​ 同向串联，即两个电源"顺着重力"叠在一起）。求电流与各元件功率。

解

第一步，先判断电路类型。 全部串联 → 可先用 合并，也可直接列 KVL（更清晰）。

第二步，定绕行方向与符号。 设回路电流 III 沿"从 E1E_1E1​ 负极出发 → 经 R1R_1R1​ → E1E_1E1​ 内部 → R3R_3R3​ → R2R_2R2​ → E2E_2E2​ → 回 E1E_1E1​ 负极"为正方向。

E1E_1E1​、E2E_2E2​ 同向串联，电动势相加：E总=12+6=18VE_{\text{总}} = 12+6 = 18\text{V}E总​=12+6=18V

第三步，KVL：

E1+E2−I(R1+R2+R3)=0E_1 + E_2 - I(R_1+R_2+R_3) = 0 E1​+E2​−I(R1​+R2​+R3​)=018−I(2+2+4)=0  ⇒  I=188=2.25A18 - I(2+2+4) = 0 \;\Rightarrow\; I = \frac{18}{8} = 2.25\text{A} 18−I(2+2+4)=0⇒I=818​=2.25A

验证同向的判断是否正确：如果是反向，应为 12−6=6V12-6=6\text{V}12−6=6V、I=0.75AI=0.75\text{A}I=0.75A。两个电流差别很大，所以这个判断错了整题就错。判断依据是电源的 +++ 极位置，画草图最保险。

第四步，各元件功率。 全串联，电流相同：

元件计算PPP
R1R_1R1​I2R1=(2.25)2×2I^2R_1 = (2.25)^2\times2I2R1​=(2.25)2×210.125W10.125\text{W}10.125W
R2R_2R2​(2.25)2×2(2.25)^2\times2(2.25)2×210.125W10.125\text{W}10.125W
R3R_3R3​(2.25)2×4(2.25)^2\times4(2.25)2×420.25W20.25\text{W}20.25W
E1E_1E1​−E1I=−12×2.25-E_1 I = -12\times2.25−E1​I=−12×2.25−27W-27\text{W}−27W（发出）
E2E_2E2​−E2I=−6×2.25-E_2 I = -6\times2.25−E2​I=−6×2.25−13.5W-13.5\text{W}−13.5W（发出）

第五步，验算：

∑P=−27−13.5+10.125+10.125+20.25=−40.5+40.5=0✓\sum P = -27 - 13.5 + 10.125+10.125+20.25 = -40.5+40.5 = 0\quad✓ ∑P=−27−13.5+10.125+10.125+20.25=−40.5+40.5=0✓

注意 R3R_3R3​ 耗散最多（RRR 最大），所以"最热的"是它 —— 散热设计要看功率分布，不是电流分布。

例 2 · 广义结点：一次 KCL 求出总电流

两条支路分别流入某结点：支路 1 电流 I1=2AI_1 = 2\text{A}I1​=2A（流入），支路 2 电流 I2=3AI_2 = 3\text{A}I2​=3A（流出）。另有一条未知电流 I3I_3I3​ 从该结点流出。求 I3I_3I3​。

解

对结点列 KCL：流入只有 I1I_1I1​，流出有 I2+I3I_2+I_3I2​+I3​：

I1=I2+I3  ⇒  I3=2−3=−1AI_1 = I_2 + I_3 \;\Rightarrow\; I_3 = 2-3 = -1\text{A} I1​=I2​+I3​⇒I3​=2−3=−1A

I3<0I_3<0I3​<0 说明真实方向是流入该结点 1A1\text{A}1A。

这是 KCL 最直接的用法。 若还要求电压，先用电阻算各支路电流、再用 KVL 求电压 —— 顺序永远是"先电流后电压"。

例 3 · 开路电压与电位计算（综合）

电路：E1=10VE_1=10\text{V}E1​=10V（左端上正）、R1=4ΩR_1=4\OmegaR1​=4Ω、E2=6VE_2=6\text{V}E2​=6V（右端上正）、R2=6ΩR_2=6\OmegaR2​=6Ω，四个元件围成一个矩形回路，R1R_1R1​ 在左边、R2R_2R2​ 在右边，两个电源分别在上下两边，R1R_1R1​ 与 R2R_2R2​ 串联接在 E1E_1E1​ 上，E2E_2E2​ 并联在 R2R_2R2​ 两端。求 R2R_2R2​ 两端电压 UabU_{ab}Uab​（aaa 上、bbb 下）及 aaa 点电位（以 bbb 为参考）。

解

第一步，画草图定符号。 设回路电流 III 顺时针，aaa 为 R2R_2R2​ 上端、bbb 为 R2R_2R2​ 下端（也就是 E1E_1E1​ 负极、E2E_2E2​ 下端）。

注意 E2E_2E2​ 直接并在 R2R_2R2​ 两端，所以 UabU_{ab}Uab​ 就是 E2E_2E2​ 的电压。若 E2E_2E2​ 标"上正"，则恒有 Uab=+6VU_{ab}=+6\text{V}Uab​=+6V —— 这一眼就能看出答案，但它只是 E2E_2E2​ 单独作用时的结果？不，E1E_1E1​ 也影响 R2R_2R2​ 上的电压。所以还要算。

第二步，对回路列 KVL（顺时针，起点 bbb 点）。

走一圈：b→b \tob→ 上边经 E1E_1E1​（从−-−到+++，升 E1E_1E1​）→\to→ a→a \toa→ 下边经 R1R_1R1​（从+++到−-−，降 IR1IR_1IR1​）→b\to b→b。这一路给出：

E1−IR1=Uab  ⇒  10−4I=UabE_1 - IR_1 = U_{ab} \;\Rightarrow\; 10 - 4I = U_{ab} E1​−IR1​=Uab​⇒10−4I=Uab​

第三步，对下半个回路（E2E_2E2​ 与 R2R_2R2​ 构成的回路）列 KVL。 R2R_2R2​ 电流就是 III（串联），E2E_2E2​ 直接并在 R2R_2R2​ 上、方向与 UabU_{ab}Uab​ 同向：

Uab=E2=6V  （若 I>0 与 E2 同向）U_{ab} = E_2 = 6\text{V}\;\text{（若 } I>0 \text{ 与 } E_2 \text{ 同向）} Uab​=E2​=6V（若 I>0 与 E2​ 同向）

第四步，联立求解。

10−4I=6  ⇒  I=1A,Uab=6V10 - 4I = 6 \;\Rightarrow\; I = 1\text{A},\qquad U_{ab} = 6\text{V} 10−4I=6⇒I=1A,Uab​=6V

验算电流方向合理性：I=1A>0I=1\text{A}>0I=1A>0，说明假设的顺时针成立（E1E_1E1​ 单独就足以顶开 E2E_2E2​）。若算得负值，就说明是 E2E_2E2​ 在主导。

第五步，求电位。 以 bbb 为参考，Vb=0V_b=0Vb​=0，则：

Va−Vb=Uab=6V  ⇒  Va=+6VV_a - V_b = U_{ab} = 6\text{V} \;\Rightarrow\; V_a = +6\text{V} Va​−Vb​=Uab​=6V⇒Va​=+6V

若改选 aaa 为参考，则 Va′=0V_a'=0Va′​=0，Vb′=−6VV_b'=-6\text{V}Vb′​=−6V。注意 Va′V_a'Va′​ 与 Vb′V_b'Vb′​ 都变了，但 Va′−Vb′=6VV_a'-V_b'=6\text{V}Va′​−Vb′​=6V 没变 —— 这就是电位与电压的本质区别。

例 4 · 电桥不能直接算（引出下一章）

一个电桥网络：E=12VE=12\text{V}E=12V，R1=R2=100ΩR_1=R_2=100\OmegaR1​=R2​=100Ω，R3=R4=50ΩR_3=R_4=50\OmegaR3​=R4​=50Ω。求桥中点电流 I桥I_{\text{桥}}I桥​。

解

先观察：如果 R1/R2=R3/R4R_1/R_2 = R_3/R_4R1​/R2​=R3​/R4​，即 100/100=50/50=1100/100 = 50/50 = 1100/100=50/50=1，那么中点两端电位相等，桥中没有电流，可以"短路"或"开路"处理。

本题 R1R2=1=R3R4\dfrac{R_1}{R_2}=1 = \dfrac{R_3}{R_4}R2​R1​​=1=R4​R3​​，故 I桥=0I_{\text{桥}}=0I桥​=0。

如果条件不满足呢？ 比如把 R4R_4R4​ 改成 30Ω30\Omega30Ω：此时 R3R4=5030≠1\dfrac{R_3}{R_4}=\dfrac{50}{30}\ne1R4​R3​​=3050​=1，桥中就有电流了。但这个网络既不是纯串联也不是纯并联，无法用 化简，必须用 变换或直接列 KCL/KVL。

这就是本课"化简四步"存在的原因：化简不是万能钥匙，遇到"电桥"这种结构就得换方法。

考点速记 ​

考法关键
独立方程个数KCL n−1n-1n−1 个，KVL b−n+1b-n+1b−n+1 个
求未知支路电流对结点列 KCL，通常只需一个方程
求开路电压用假想回路列 KVL（开路处 I=0I=0I=0，电阻压降为零）
求某点电位选参考点 → 沿路径累加
某块电路的总电流广义结点：在外面画个圈，一次 KCL
功率验算求完全部支路后检查 ∑P=0\sum P = 0∑P=0
电桥判断R1/R2=R3/R4R_1/R_2 = R_3/R_4R1​/R2​=R3​/R4​ 时桥中无电流

易错点 ​

  • ∑I=0\sum I = 0∑I=0 里的 III 带符号，不是绝对值相加
  • 列 KVL 时绕行方向一旦选定全程不要改
  • 电位是相对量，没给参考点就要自己选（选支路汇合点最方便）
  • KCL/KVL 不适用于分布参数电路（高频、长线）
  • 电压 UabU_{ab}Uab​ 与电流参考方向要分别判断，不要假定它们关联
