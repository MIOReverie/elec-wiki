07 · 三要素法：RC / RL ​

核心 约 45 min一阶电路的万能公式，背下它这章就结束了

这一页要解决什么：上一页说了「换路瞬间」怎么算，但换路之后那条曲线长什么样、任意时刻的电压电流是多少？这一页给一阶电路一个万能解法：只要求出三个数（起点、终点、时间常数），整条曲线就被唯一确定。读完你应该能对任意只含一个储能元件的电路，求出任意响应 f(t)f(t)f(t)，并说清每个数是从哪张电路里来的。

读这页之前

  • 需要会：换路定则与 t=0+t=0_+t=0+​ 等效电路（）、稳态等效（电容开路、电感短路，见上一页）、串联与并联（）、分压（）。
  • 这一页用到的符号：f(t)f(t)f(t)（要 求的响应量，随时间变化的任一电压或电流）、f(0+)f(0_+)f(0+​)、f(∞)f(\infty)f(∞)、τ\tauτ（时间常数，单位秒）、ReqR_{eq}Req​（等效电阻：从储能元件端口看进去、独立源置零后测到的电阻，单位 Ω）、uCu_CuC​、iLi_LiL​。全部约定见符号与约定。
  • 会用到的数学：指数函数 e−t/τe^{-t/\tau}e−t/τ 与自然对数 ln⁡\lnln（求「达到某值要多久」时要用 ln⁡\lnln，即 exe^xex 的反函数）。

你给一个电路，只有一个电容和一个电阻。电源是 12 V，电阻是 2 kΩ，电容是 100 μF。合闸后电容电压要多久才充到 6 V？——这道题要算的量出现在一个指数里，而指数的三个参数来自三个不同的电路：起点来自换路瞬间那张图，终点来自最终稳态那张图，速度来自把电源短路的第三张图。这一页要做的，就是把「一个指数」翻译成「三张电路 + 三个数」。

结论先行 ​

  1. 一阶电路（只含一个储能元件）的任何响应都只有一个指数，写成同一个式子：f(t)=f(∞)+[f(0+)−f(∞)]e−t/τf(t) = f(\infty) + \big[f(0_+) - f(\infty)\big]e^{-t/\tau}f(t)=f(∞)+[f(0+​)−f(∞)]e−t/τ。
  2. 起点 f(0+)f(0_+)f(0+​)：先用换路定则拿 uC(0+)u_C(0_+)uC​(0+​) 或 iL(0+)i_L(0_+)iL​(0+​)，再在 t=0+t=0_+t=0+​ 等效电路上求目标量。
  3. 终点 f(∞)f(\infty)f(∞)：换路后的稳态——电容开路、电感短路，按纯电阻电路算。
  4. 时间常数 τ\tauτ：RC 电路 τ=ReqC\tau = R_{eq}Cτ=Req​C，RL 电路 τ=L/Req\tau = L/R_{eq}τ=L/Req​；ReqR_{eq}Req​ 是从储能元件端口看进去的等效电阻。
  5. 三个特例（RC 充电、RC 放电、RL 接通）都只是这个通式填数的产物，不需要单独背。

三要素法 = 先定点、再连线

把三要素法当成一个固定套路，顺序就是纪律：① 先用换路定则钉住起点 f(0+)f(0_+)f(0+​) → ② 用稳态（C 开路 / L 短路）钉住终点 f(∞)f(\infty)f(∞) → ③ 从储能元件端口看进去求 τ\tauτ → ④ 才代公式。三个点一钉，中间那条指数曲线就被唯一确定了——所以「先求三要素、后写表达式」的顺序不能乱，跳步最容易在 f(∞)f(\infty)f(∞) 和 τ\tauτ 上翻车。

一、这章为什么可以这么短 ​

这一节只回答一个问题：为什么一阶电路的解能被压缩成三个数。

因为一阶电路的解是唯一的，不管电路多复杂，全部信息都压缩在三个数里：

  • 起点 f(0+)f(0_+)f(0+​)：电路「从哪开始」
  • 终点 f(∞)f(\infty)f(∞)：电路「到哪结束」
  • 时间常数 τ\tauτ：电路「走多快」

整条曲线就是这三点决定的。所以本章不推公式，只教你怎么把这三个数求对。

二、三要素逐一求法 ​

这一节把三要素法拆成三个动作，每个动作都点明「在哪种电路上算」。第 1 要素最容易出错，第 3 要素最容易算错。

第 1 要素：f(0+)f(0_+)f(0+​) ​

核心：用换路定则拿到 uC(0+)u_C(0_+)uC​(0+​) 或 iL(0+)i_L(0_+)iL​(0+​)，再在 t=0+t=0_+t=0+​ 的等效电路上算目标量。

t=0+t=0_+t=0+​ 等效电路的画法：

  • 电容：电压已知 → 用电压源替代（uC(0+)u_C(0_+)uC​(0+​)）
  • 电感：电流已知 → 用电流源替代（iL(0+)i_L(0_+)iL​(0+​)）

最常见的错：目标量不是储能元件时忘了重算

如果题目要求的是 uR1(t)u_{R_1}(t)uR1​​(t)（电阻两端电压），它在 t=0+t=0_+t=0+​ 可能突变。必须在 t=0+t=0_+t=0+​ 等效电路上重新算，不能靠 uCu_CuC​ 直接推。

举个例子：EEE 经 R1R_1R1​ 串 R2R_2R2​ 串 CCC。求 uR1u_{R_1}uR1​​：

  • t=0−t=0_-t=0−​：CCC 未充电，uC=0u_C=0uC​=0 → uR1=uR2=E/2u_{R_1}=u_{R_2}=E/2uR1​​=uR2​​=E/2
  • t=0+t=0_+t=0+​：uC=0u_C=0uC​=0（未突变）→ uR1=uR2=E/2u_{R_1}=u_{R_2}=E/2uR1​​=uR2​​=E/2（一样）

但如果是开关直接接到 CCC 两端，此时 uR1u_{R_1}uR1​​ 会瞬间从 0 跳到 EEE，而 uCu_CuC​ 从 EEE 跳到 0。这种题必须画 t=0+t=0_+t=0+​ 等效电路，不能用「uCu_CuC​ 不突变」倒推。

第 2 要素：f(∞)f(\infty)f(∞) ​

稳态三句话：

直流稳态  ⇒  {电容→开路 (iC=0)电感→短路 (uL=0)\text{直流稳态} \;\Rightarrow\; \begin{cases}\text{电容} \to \text{开路 }(i_C=0)\\ \text{电感} \to \text{短路 }(u_L=0)\end{cases} 直流稳态⇒{电容→开路 (iC​=0)电感→短路 (uL​=0)​

然后就是纯电阻电路，用 或 算。

为什么稳态是「电容开路、电感短路」？

物理上：稳态时电容充满电后不再有电流通过；电感电流恒定后不再有感应电动势。这不是「近似」，而是 duCdt=0\dfrac{du_C}{dt}=0dtduC​​=0 和 diLdt=0\dfrac{di_L}{dt}=0dtdiL​​=0 的直接推论。

对直流而言，这意味着电容相当于一个断开的开关，电感相当于一根导线。

第 3 要素：τ\tauτ ​

τRC=ReqC,τRL=LReq\tau_{RC} = R_{eq}C,\qquad \tau_{RL} = \frac{L}{R_{eq}} τRC​=Req​C,τRL​=Req​L​

ReqR_{eq}Req​ 的求法（关键）：把独立源置零（电压源短路、电流源开路），然后从储能元件的两个端子看进去的等效电阻。

三个要素各自从哪张电路来，现在都清楚了。接下来要回答一个问题：这三个数凭什么就能定死整条曲线。

三、时间常数的物理意义 ​

这一节只回答一件事：τ\tauτ 这个数到底在说什么。

τ\tauτ 的量纲是秒。它告诉你电路的「记性」有多长：t=τt=\taut=τ 时过渡过程走完 63.2%，t=3τt=3\taut=3τ 时走完 95%。

工程速算

「5τ 规则」：任何一阶电路，经过 5τ5\tau5τ 就认为进入稳态。这个规则在滤波器截止频率、开关电源环路稳定性、继电器动作延时估算里都用得上。

影响 τ\tauτ 的因素 ​

τRC∝Req⋅C电阻大、电容大 → 变化慢τRL∝LReq电感大、电阻小 → 变化慢\begin{aligned} \tau_{RC} &\propto R_{eq}\cdot C &&\text{电阻大、电容大 → 变化慢}\\ \tau_{RL} &\propto \frac{L}{R_{eq}} &&\text{电感大、电阻小 → 变化慢} \end{aligned} τRC​τRL​​∝Req​⋅C∝Req​L​​​电阻大、电容大 → 变化慢电感大、电阻小 → 变化慢​

工程含义：

  • 要让电路快速响应 → 减小 τ\tauτ（RC 减小 RRR 或 CCC）
  • 要让电路滤除慢变化 → 增大 τ\tauτ（RC 加大 RRR 或 CCC，低通滤波）

到这里，起点、终点、速度三个数都有了意义。下一节把它们组装成一套固定的操作顺序，让你在考场上不会跳步。

四、解题步骤（套公式） ​

这一节把三要素法变成一个四步清单，每一步都点明「在哪张电路上算」。

① 求 f(0₊)   —— 换路定则 + t=0₊ 等效电路
② 求 f(∞)    —— 稳态电路（C 开路、L 短路）
③ 求 R_eq    —— 从 C/L 端口看进去的等效电阻（独立源置零）
④ 代入 f(t) = f(∞) + [f(0₊) − f(∞)]e^(−t/τ)

万能步骤：不管电路多复杂，只要是一阶（只有一个储能元件），这四步一定能搞定。

判断是否一阶

数储能元件个数：1 个 → 一阶，用三要素法；2 个 → 二阶，必须列微分方程或用拉普拉斯变换/算子法。

五、三个特例（背下来） ​

这一节把通式代进去，导出三个最常考的形状——你会发现它们不需要背。

RC 充电（零状态，uC(0)=0u_C(0)=0uC​(0)=0，充到 EEE）：

uC=E(1−e−t/τ)u_C = E\left(1 - e^{-t/\tau}\right) uC​=E(1−e−t/τ)

就是这个电路在充电（闭合 S 后，uCu_CuC​ 沿指数从 0 爬到 EEE）：

RC 放电（零输入，uC(0)=U0u_C(0)=U_0uC​(0)=U0​，放向 0）：

uC=U0e−t/τu_C = U_0 e^{-t/\tau} uC​=U0​e−t/τ

RL 接通直流（零状态，iL(0)=0i_L(0)=0iL​(0)=0，升到 E/RE/RE/R）：

iL=ER(1−e−t/τ)i_L = \frac{E}{R}\left(1 - e^{-t/\tau}\right) iL​=RE​(1−e−t/τ)

特例怎么从三要素推出来（不要死记）

把三要素法的 f(0+)f(0_+)f(0+​)、f(∞)f(\infty)f(∞) 填进通用公式，立刻得到特例。以 RC 充电为例：

  • f(0+)=uC(0+)=0f(0_+) = u_C(0^+) = 0f(0+​)=uC​(0+)=0（电容电压不突变）
  • f(∞)=Ef(\infty) = Ef(∞)=E（稳态电容充满）
  • 代入：uC(t)=E+(0−E)e−t/τ=E(1−e−t/τ)u_C(t) = E + (0-E)e^{-t/\tau} = E(1-e^{-t/\tau})uC​(t)=E+(0−E)e−t/τ=E(1−e−t/τ) ✓

所以三个特例不需要背，只需要会填三要素。

典型例题 ​

这一节四道题按「电路复杂程度」排：例 1 是最基本的 RC 充电，例 2 是 RL 接通并顺手求时间，例 3 是没有电源的放电过程（能量去哪了），例 4 是换路加并联电阻——考 ReqR_{eq}Req​ 到底该从哪看。每题都先看「先想什么」。

例 1 · RC 充电：uC(t)u_C(t)uC​(t)、i(t)i(t)i(t) 与「到某值要多久」

六、微分电路与积分电路（工程应用） ​

这一节讲三要素法的两个副产品：同一套电路，取输出电压的位置不同，就变成微分器或积分器。

条件输出取自公式波形变换
微分电路τ≪tp\tau \ll t_pτ≪tp​（脉冲宽度）电阻两端uo≈RCduidtu_o \approx RC\dfrac{du_i}{dt}uo​≈RCdtdui​​方波 → 尖脉冲
积分电路τ≫tp\tau \gg t_pτ≫tp​电容两端uo≈1RC∫uidtu_o \approx \dfrac{1}{RC}\int u_i dtuo​≈RC1​∫ui​dt方波 → 三角波

为什么会这样：

  • 微分电路：输出取自电阻 uR=RCduCdt≈RCduidtu_R = RC\dfrac{du_C}{dt} \approx RC\dfrac{du_i}{dt}uR​=RCdtduC​​≈RCdtdui​​。当 τ\tauτ 远小于脉冲宽度时，电容两端电压几乎等于输入（电容「跟着」输入变），电流 C duidt\dfrac{C\,du_i}{dt}dtCdui​​ 只在边沿上有尖峰 → 输出窄脉冲。
  • 积分电路：输出取自电容。当 τ\tauτ 远大于脉冲宽度时，电容「来不及」充满，uC≈1RC∫uidtu_C \approx \dfrac{1}{RC}\int u_i dtuC​≈RC1​∫ui​dt → 方波积出三角波。

常见应用

  • 微分：边沿检测（数字电路里的单稳态/施密特触发器输入级）
  • 积分：PWM 生成、模拟-数字转换、脉冲宽度测量

七、二阶电路预告（RLC 串联） ​

这一节只做一个预告：为什么三要素法不能用在 RLC 上。

当电路有 2 个储能元件（如 RLC 串联），三要素法失效，必须看阻尼类型：

阻尼条件响应
过阻尼 ζ>1\zeta>1ζ>1R>2L/CR>2\sqrt{L/C}R>2L/C​两个指数，无振荡
临界 ζ=1\zeta=1ζ=1R=2L/CR=2\sqrt{L/C}R=2L/C​临界阻尼，最快无振荡
欠阻尼 ζ<1\zeta<1ζ<1R<2L/CR<2\sqrt{L/C}R<2L/C​衰减振荡

关键理解：RRR 越大越「迟钝」（过阻尼），RRR 越小越「活泼」（欠阻尼振荡）。这与直觉相反 —— 很多人以为大电阻阻尼大，实际上电阻消耗能量，阻尼能量来自 RRR。

RLC 串联的交流分析（阻抗、谐振、品质因数）放在第 09 章 · RLC 串联与阻抗与第 11 章 · 谐振与频率特性。

易错点 ​

按踩坑频率排序，每条给出「错误做法 → 会得到什么 → 正确做法」。

  • ReqR_{eq}Req​ 必须是从储能元件两端看进去的等效电阻，不是随便抓一个电阻 → τ\tauτ 差好几倍。

  • 求 f(0+)f(0_+)f(0+​) 时如果目标量不是 uCu_CuC​/iLi_LiL​，它可能突变，必须在 t=0+t=0_+t=0+​ 电路上重新算。
  • 三要素法只适用于一阶电路（一个储能元件）；二阶（RLC）必须列微分方程。
  • 电容放电时若 τ\tauτ 太大，实际会因漏电流而比公式慢。
  • 「开关接通瞬间电容相当于短路、电感相当于开路」—— 这说的是电流/电压的极端值，不是元件消失。
