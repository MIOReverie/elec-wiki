08 · 波形的发生和变换 ​

核心 约 45 min正弦振荡的相位/幅值两条件 + RC/LC/石英三代 + 非正弦波发生器

非正弦波发生器的两块积木（滞回比较器、积分器）都建立在运放线性/非线性两种工作方式上，判据见 。

结论先行 ​

  1. 振荡 = 正反馈 + 选频 + 稳幅。两个条件缺一不可：相位条件（环路相移 0°，正反馈）与幅值条件（环路增益 ≥1）。只满足相位条件叫「谐振」，不振荡。
  2. 文氏桥 RC 振荡器：f0=1/(2πRC)f_0=1/(2\pi RC)f0​=1/(2πRC)，起振要求同相放大器增益 >3>3>3（Rf>2R1R_f>2R_1Rf​>2R1​）；频率低（Hz~百 kHz）、频率稳定度差（10−3∼10−210^{-3}\sim10^{-2}10−3∼10−2），适合音频。
  3. LC 振荡器：f0=1/(2πLC)f_0=1/(2\pi\sqrt{LC})f0​=1/(2πLC​)，频率高（百 kHz~百 MHz）、稳定度 10−4∼10−510^{-4}\sim10^{-5}10−4∼10−5，无线电的主力。
  4. 石英晶体：等效 QQQ 高达 104∼10610^4\sim10^6104∼106，稳定度 10−610^{-6}10−6 以上——一切数字系统时钟的祖宗（见数电 06 章 555的对照）。
  5. 非正弦波发生器（方波/三角波/锯齿波）= 滞回比较器 + 积分器，第 7 章 · 信号的运算和处理两个方块一接就成。

推导脉络：从自激（坏）到振荡器（好） ​

第 6 章 · 放大电路中的反馈里自激是要防的病害：相移 180° + ∣AF∣≥1|AF|\ge1∣AF∣≥1 → 寄生振荡。同一章反着读就是振荡器设计：主动把相移凑成 0°（或 360°），把增益设到刚好过 1。区别只在于「选频网络」：放大器的相移随频率乱跑，选频网络只在一个频率上恰好满足相位条件，于是振荡频率被钉死。

正反馈环路 ─► [ 选频网络：只在 f0 处相移为 0 ] ─► [ 放大器：增益略大于 1 ]
                                                        │
                       稳幅环节 ◄─── 输出太大时自动压低增益 ─┘

稳幅必须非线性（二极管、热敏电阻、灯丝、AJC 自动增益控制）：线性元件增益恒定，振幅会一路涨到饱和，波形削成平顶。

工程实例：一块单片机板上的三种振荡 ​

  • 16 MHz 石英 + 反相器：CPU 主时钟，10−610^{-6}10−6 级稳定度保证串口波特率不错帧；
  • 32.768 kHz 石英：RTC 实时时钟，215 分频正好得 1 s（数电 06 章计数器的经典用法）；
  • RC 振荡（内部）：看门狗和上电延时，10−210^{-2}10−2 稳定度无所谓，省一个晶振钱；
  • 没有振荡器的场合：PWM 调速（数电 08 章）直接用定时器时钟分频——频率精度跟着主时钟，不需要选频网络。

易错清单 + 自检 ​

  • 两个条件都要查：相位 0° 但增益 0.5 → 不起振；增益 3 但相移不对 → 不起振或乱振。上电第一件事用示波器看波形，别只看频率计读数。
  • 起振增益要略大于 1，稳态增益必须等于 1：前者靠设计余量，后者靠非线性稳幅，两者是不同机制。
  • 文氏桥的 F=1/3 别忘了：所以后级要 3 倍，直接接射随（增益 1）永远不振。
  • LC 回路别直接挂重负载：Q 被拉崩、频率漂移，用抽头或射随隔离。
  • 石英有静电损伤与驱动功率上限：驱动过大频漂甚至振裂，数据手册的 PmaxP_{max}Pmax​ 不是装饰。
  • 自检：把例 1 的 RfR_fRf​ 从 22 kΩ 想象中调到 20 kΩ——理论上环路增益 1.0，实际呢？再调到 30 kΩ，波形会削顶（稳幅环节忙不过来）。起振余量与稳幅能力是一对矛盾，这就是振荡器调试的全部手感。
