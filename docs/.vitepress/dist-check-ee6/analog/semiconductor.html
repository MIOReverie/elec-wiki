01 · 半导体器件 ​

核心 约 50 min最容易错的不是公式，是「先判区再选公式」——三极管在饱和区已经不满足 I_C=βI_B，MOS 低于 V_GS(th) 则是完全关断

这一页要解决什么：模电的四种器件（二极管、稳压管、三极管、场效应管）其实共享同一个 PN 结，差别只在「用它的哪一个行为」。读完你应该能：说出单向导电的物理来源、给二极管选合适的近似模型、给稳压管算出一颗不会烧也不会饿死的限流电阻、判定一颗三极管在哪个区，以及看懂 MOS 参数表里 VGS(th)V_{GS(th)}VGS(th)​ 与 gmg_mgm​ 这两个数到底在说什么。

你手上有一支 LED 和一节 5 V 电源。顺着插，它亮；反过来插，它不亮——换用普通白炽灯泡，怎么插都亮。区别不在电源，也不在线，而在那个只有两个脚的小东西：它只允许电流往一个方向走。这个「单向」的性质不是碰巧长出来的，是被一块半导体内部的电场设计出来的。

更具体一点：要给单片机供 3.3 V，电网给的是 220 V 交流。中间要经历降压、整流、滤波、稳压。完成这四步的器件——二极管、稳压管、三极管、MOS 管——在同一个电路板上各司其职，却都由同一件事派生：一块半导体里两块不同性质的区域贴在一起。这一页就把这件事从上到下讲一遍。

结论先行 ​

  1. 四种器件共享一个 PN 结：差别只在用它的哪一个行为——单向导电（二极管）、反向击穿（稳压管）、两个结叠在一起用电流控制电流（三极管）、用电场控制沟道宽窄（MOS）。
  2. 二极管用三档模型：理想（0 V 导通）、恒压（硅 0.7 V / 锗 0.2 V，估算首选）、折线/指数（精度分析用）。先选模型，再动手算。
  3. 稳压管工作在反向击穿区：电压几乎不随电流变；限流电阻必须同时满足「IZI_ZIZ​ 不小于维持电流」和「IZI_ZIZ​ 不超过最大功耗」，两头都要算。
  4. 三极管是电流控制器件：IC=βIBI_C=\beta I_BIC​=βIB​，但这条式子只在放大区成立——先判区，再选公式。
  5. MOS 是电压控制器件：栅源电压 VGSV_{GS}VGS​ 低于开启电压 VGS(th)V_{GS(th)}VGS(th)​ 时完全截止，ID=0I_D=0ID​=0；超过之后 IDI_DID​ 由过驱动电压 Vov=VGS−VGS(th)V_{ov}=V_{GS}-V_{GS(th)}Vov​=VGS​−VGS(th)​ 的平方决定。

一句话抓住全局：这一章在问同一个问题

一块半导体上，「控制电流的办法」一共有几种？答案是三种：用电压方向（结要么通要么不通）、用小电流（三极管，β\betaβ 倍放大）、用电场（MOS，gmg_mgm​ 倍转换）。后面四种器件只是这三种办法的工程形态。抓住这一点，参数表上几十个数就不会互相打架。

一、从一块硅到一个结：器件是怎么来的 ​

这一节只做一件事：给出「四种器件为什么能在同一块材料上长出来」的因果链，不推公式。

纯净的硅（本征半导体 intrinsic semiconductor：没掺任何杂质的硅，可动载流子极少，几乎不导电）在常温下能提供载流的电子很少。往里面掺极微量的五价元素（磷、砷，外层五个电子），多出来的那个电子可以自由移动 → 得到 N 型半导体；掺三价元素（硼，外层三个电子），晶格里缺一个电子，这个空缺就是空穴（hole：可以看成带正电、能移动的位置），能像正电荷一样参与导电 → 得到 P 型半导体。掺杂（doping：往纯硅里按百万分之一量级掺入杂质）这个过程本身不改变化学性质，只改变导电能力。

把 P 型和 N 型贴在一起，界面附近发生两件事：N 区的电子扩散到 P 区填补空穴、P 区的空穴扩散到 N 区，于是界面两侧各留下一层不能移动的正负离子，形成空间电荷区（也叫耗尽层 depletion region：这一薄层里几乎没有可动载流子）；这些固定离子建立一个从 N 指向 P 的内电场，它会阻止扩散继续进行。这就是 PN 结的全部物理来源。

耗尽层和内电场都有了，下一个问题是：外接电源怎么作用于它。这就是「正偏 / 反偏」这两个词的含义。

二、正偏导通、反偏截止：一句话和两个方向 ​

这一节回答最接近直觉的那个问题：为什么接对了就通、接反了就断。

正偏（forward bias：外加电压的 P 侧电位高于 N 侧）：外电场方向与内电场相反，把耗尽层压薄 → 多数载流子可以源源不断穿过界面 → 导通。此时管压降维持在约 0.7 V（硅），这是克服内电场所需的「过路费」。

反偏（reverse bias：外加电压的 P 侧电位低于 N 侧）：外电场与内电场同向，把耗尽层拉宽 → 多数载流子被推得更远 → 只有极少量的少数载流子（minority carrier：P 区里的电子、N 区里的空穴，数量极少）漂过界面形成微安级漏电流 → 视作截止。

两者合并就是那句要背的话：正偏导通、反偏截止，即单向导电性。详细的物理图像与三种模型成立条件见 。

这里最常犯的方向错

「电流从阳极（P 侧）流入才降压 0.7 V」，不是随便一给就减 0.7。方向反了要把管子当断路，而不是当一个 −0.7 V 的电源。判断办法只有一条：先假设管子导通，算出电流是否为正；为负说明假设不成立，管子其实是截止的。

单向导电性只是一个行为。同一个结还有三个可以被利用的行为——于是长出四种器件。下一节看它们各自的「用法」。

四、二极管：先选模型，再动手算 ​

这一节回答一个具体问题：面对一个含二极管的电路，第一步该做什么。

答案是：先判断题中二极管是导通还是截止，再按模型代值。三档模型按精度从粗到精排列：

为什么允许把 0.7 V 当常数？因为指数曲线在大电流区非常陡——电流差几十倍，压降才差 0.1 V 左右。把非线性压平成常数，正是估算的收益来源（更详细的推导见 ）。

有了「导通时压降 0.7 V」这条规则，第一个直接应用就是限幅：把输出摁在安全线以内。这就是例 1。

五、稳压管：工作在「反向击穿」这个危险区 ​

这一节回答一个反直觉的问题：为什么有人说二极管怕反向击穿，稳压管却专门工作在反向击穿区。

因为可控的击穿不损坏器件。反向电压超过某一数值时，结内的载流子在强电场下发生雪崩倍增，电流急剧增大而端电压几乎不变——只要外部有限流电阻把功耗压住，这个过程可以长期稳定重复。所以：

  • 普通二极管：反向击穿 = 永久损坏，必须避免；
  • 稳压管（齐纳二极管 Zener diode：专门设计工作在反向击穿区的二极管）：反向击穿 = 正常工作点，符号的区别是阴极那道折线改成「⏊」形。

工程用法的关键是一颗限流电阻 RRR：它承担多余的电压，并把穿透管子的电流限制在安全范围内。

结点 a 处按 KCL 有 IR=IZ+ILI_R=I_Z+I_LIR​=IZ​+IL​。稳压的全部机制就在这一条式子里：输入或负载变化时，差额由 IZI_ZIZ​ 吸收。设计 RRR 时要同时卡住两头——下限要保住 IZI_ZIZ​ 不低于维持电流（手册上常记为 IZmin⁡I_{Z\min}IZmin​，本例取 5 mA），上限要保住功耗不超限。这就是例 2。

二极管与稳压管都是「两端器件」，没法控制多个电流。要得到可以放大的东西，需要三个极。下一节是 BJT。

六、三极管：用小电流搬运大电流 ​

这一节回答两个问题：IC=βIBI_C=\beta I_BIC​=βIB​ 里的 β\betaβ 到底是什么，以及这条公式什么时候不能用。

双极型三极管（BJT，Bipolar Junction Transistor）内部是两个背靠背的 PN 结，中间夹一层极薄的基区。结构上三个极：发射极 E、基极 B、集电极 C。它的巧妙之处在于——基极电流只需要很小：发射结正偏时，从发射区注入的大多数载流子几乎全部穿过薄基区被集电极收集，只有极少部分在基区复合形成 IBI_BIB​。于是 ICI_CIC​ 与 IBI_BIB​ 的比例基本恒定：

IC=βIB,IE=IB+IC=(1+β)IBI_C=\beta I_B,\qquad I_E=I_B+I_C=(1+\beta)I_B IC​=βIB​,IE​=IB​+IC​=(1+β)IB​

这里 β\betaβ（beta，共射电流放大系数）就是「一个基极电子能带动多少个集电极电子」，典型 50~200。β\betaβ 会随 ICI_CIC​ 与温度变化（可能腰斩），所以设计时要按最小值折算留余量。

但这条公式有一个前提：管子必须在放大区。

七、场效应管：用电压控制，输入端几乎不取电流 ​

这一节解释三个必考的量：VGS(th)V_{GS(th)}VGS(th)​、VovV_{ov}Vov​ 与 gmg_mgm​，以及它们之间的关系。

场效应管（FET，Field Effect Transistor；这里只讲最常见的 N 沟道增强型 MOS）的三个极是栅极 G、漏极 D、源极 S。栅极与半导体之间隔着一层绝缘的氧化物，所以直流下栅极几乎不取电流——输入电阻极高（109 Ω10^{9}\ \Omega109 Ω 以上）。它的原理是：栅压 VGSV_{GS}VGS​ 为正时吸引电子到栅下面的硅表面，形成一条连通源漏的沟道（channel）；电压越高沟道越宽、导电能力越强。

工程实例：一块电路板上的四种管子 ​

打开一台普通开关电源适配器，四种器件都在：

  • 整流桥里的四个二极管：把交流切成单向（见电工学 22 章），工作在开关区，用第一层行为「单向导电」；
  • 功率三极管 / MOS：高频开关，饱和与截止两态切换（PWM 调速同一思想），用第四层的三个区；
  • 稳压管或 TL431：采样反馈回路的基准电压源，用第三层的反向击穿——例 2 的实际应用；
  • 运放：误差放大器，比较输出采样与基准，一个运放内部就有十几对差分管（第 5 章 · 集成运算放大电路的主角）。

四种器件在一块板子上各占一段，选型的依据正是这一页的四条结论：要不怕反接 → 二极管；要稳定的参考 → 稳压管；要线性放大 → 三极管的放大区；要高效率开关 → MOS 的饱和/截止。

四种器件的用法都清楚了，最后把这一页最容易翻车的地方按频率排一遍。

易错清单 ​

按踩坑频率从高到低排，每条格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 不管工作区直接套 IC=βIBI_C=\beta I_BIC​=βIB​ → 在饱和时算出远大于实际的电流 → 先算需求 IC=βIBI_C=\beta I_BIC​=βIB​，再算天花板 VCC/RCV_{CC}/R_CVCC​/RC​，谁小听谁的。
  2. 二极管导通压降方向搞反 → 把一个 0.7 V 的电源当成断路（或反过来把断路算成导通）→ 电流必须从阳极（P 侧）流入才降 0.7 V；不确定就先假设导通，算出的电流为负说明其实截止。
  3. 稳压管反接当普通二极管用 → 正偏时它反倒像个普通二极管，失去稳压能力 → 稳压管的工作点就在反向击穿区，符号上阴极那道线是折线。
  4. 以为 β\betaβ 是常数 → 温度一变工作点漂出放大区 → β\betaβ 随 ICI_CIC​ 与温度明显变化，设计时按最小值（甚至 β/2\beta/2β/2）留余量。
  5. 限流电阻只按标称输入算 → 电网波动或负载跳变时稳压失效或管子烧毁 → 下限工况（低输入 + 重负载）与上限工况（高输入 + 空载）各算一次。
  6. MOS 栅极悬空 → 静电使栅压不确定，管子半开不全开而过热烧毁 → 栅极必须有确定的直流通路；拆封、焊接前先放电。
  7. 把 VGS(th)V_{GS(th)}VGS(th)​ 当成「刚开始有一点点电流」的电压 → 用它估算电流会得到偏小的结果 → 它是沟道形成的门槛，电流由超过它多少（VovV_{ov}Vov​）的平方决定。
