08 · 正弦量与相量法 ​

核心 约 40 min相量法是交流电路的『编译器』：把微积分变成复数代数

结论先行 ​

  1. 正弦量三要素：幅值 UmU_mUm​、角频率 ω\omegaω、初相位 ψ\psiψ —— 三者确定，正弦量唯一确定
  2. 有效值 U=Um/2U = U_m/\sqrt2U=Um​/2​（仪表读数、设备铭牌默认都是有效值，由热效应定义）
  3. 相量 = 携带幅值和相位的复数：U˙=U∠ψ\dot U = U\angle\psiU˙=U∠ψ（模用有效值）
  4. 相量法的威力：把微分方程变成复数代数方程，且 KCL/KVL 形式不变
  5. 同频正弦量合成：幅值 Um=U1m2+U2m2+2U1mU2mcos⁡φU_m = \sqrt{U_{1m}^2 + U_{2m}^2 + 2U_{1m}U_{2m}\cos\varphi}Um​=U1m2​+U2m2​+2U1m​U2m​cosφ​ —— 有效值不能直接相加
  6. 只有同频率的正弦量才能画在同一张相量图上；相量是复数不是时间函数

心智模型：相量法是一台「微积分 → 代数」的编译器

它没有改变任何物理规律——KCL、KVL 照样成立。它只是把「对正弦量求导 / 积分」这件事，翻译成「复数乘 jωj\omegajω / 除 jωj\omegajω」。所以相量域里你直流电路的全部解题动作（串并联、分压、节点法……）原封不动地可用。记住一句话：频率已被「同频假设」定死，剩下要解的只有幅值和相位两个数——恰好是一个复数的两个自由度。

一、为什么要用相量：把微积分变成代数 ​

直流电路里电阻的伏安关系是 u=Riu = Riu=Ri，一个乘法。而电感和电容是微积分关系：

uL=LdiLdt,iC=CduCdtu_L = L\frac{di_L}{dt}, \qquad i_C = C\frac{du_C}{dt} uL​=LdtdiL​​,iC​=CdtduC​​

列出来的 KCL/KVL 是微分方程，解起来很痛苦。但有一个关键的数学事实：

线性电路中，如果所有电源都是同频率的正弦量，那么全电路各处的响应也都是同频率的正弦量。

频率不用求解了，剩下要定的只有幅值和相位两个数。而一个复数恰好有两个自由度 —— 让复数的模扛幅值、辐角扛相位，正弦量的全部信息就压缩成一个数。进一步有：

  • 求导 ddt\frac{d}{dt}dtd​ → 乘以 jωj\omegajω（幅值乘 ω\omegaω、相位转 90°）
  • 积分 ∫dt\int dt∫dt → 除以 jωj\omegajω（幅值除 ω\omegaω、相位转 −90°）

于是微分方程退化成了复数代数方程。KCL、KVL 的形式原封不动：

∑I˙=0,∑U˙=0\sum \dot I = 0, \qquad \sum \dot U = 0 ∑I˙=0,∑U˙=0

这就是相量法的全部魔法：换了一套符号，解题动作和直流电路一模一样。

旋转相量：相量的几何来历

让一个复数 U˙=Um∠ψ\dot U = U_m\angle\psiU˙=Um​∠ψ 以角速度 ω\omegaω 逆时针旋转，它在虚轴上的投影就是正弦瞬时值：

Im[Umej(ωt+ψ)]=Umsin⁡(ωt+ψ)=u(t)\mathcal{Im}\left[U_m e^{j(\omega t+\psi)}\right] = U_m\sin(\omega t+\psi) = u(t) Im[Um​ej(ωt+ψ)]=Um​sin(ωt+ψ)=u(t)

所以「相量」这个词很诚实：它就是旋转矢量的快照。同一张相量图上并排画几个相量，它们之间的夹角就是相位差。

为什么处处用有效值

万用表测出来的、电机铭牌上印的、配电网说的「220 V」，全是有效值。所以相量的模默认用有效值 —— 这样 P=UIcos⁡φP = UI\cos\varphiP=UIcosφ 直接成立，不用到处除 2\sqrt22​。只有画波形图、谈击穿绝缘时才用幅值。

三、复数工具箱 ​

相量运算法则和普通复数完全一样，只有一条实用经验：加减用代数型，乘除用极坐标。

A=a+jb=∣A∣∠φ,∣A∣=a2+b2,φ=arctan⁡baA = a + jb = |A|\angle\varphi, \qquad |A| = \sqrt{a^2+b^2},\quad \varphi = \arctan\frac{b}{a} A=a+jb=∣A∣∠φ,∣A∣=a2+b2​,φ=arctanab​

四个必须背下来的恒等式：

j=1∠90∘,1j=−j,j2=−1,ej90∘=jj = 1\angle 90^\circ, \qquad \frac{1}{j} = -j, \qquad j^2 = -1, \qquad e^{j90^\circ} = j j=1∠90∘,j1​=−j,j2=−1,ej90∘=j

jjj 的几何意义是「逆时针转 90°」：任何相量乘 jjj 就是相位超前 90°，除 jjj（即乘 −j-j−j）就是滞后 90°。电抗的正负号全靠它解释。

四、同频正弦量相加：有效值不能直接加 ​

两个同频正弦量 u1u_1u1​、u2u_2u2​ 相加，频率不变，合成幅值由相位差 φ\varphiφ 决定：

Um=U1m2+U2m2+2U1mU2mcos⁡φ\boxed{U_m = \sqrt{U_{1m}^2 + U_{2m}^2 + 2U_{1m}U_{2m}\cos\varphi}} Um​=U1m2​+U2m2​+2U1m​U2m​cosφ​​

三种最特殊的情况值得单独记住：

最高频错误

把两个同频正弦量的有效值直接相加。除非同相，否则一定错。正确做法只有一条路：各自写成相量 → 复数相加 → 取模。

比如两个 10 V 有效值、相位差 90° 的电压串联，总电压有效值是 102+102=14.14\sqrt{10^2+10^2} = 14.14102+102​=14.14 V，不是 20 V。

相量法求合成的标准三步：

① 各量写成统一形式（都用有效值或都用幅值，别混用）
② 转成代数型 a + jb，实部虚部分别相加
③ 结果转回极坐标：取模 = 幅值，辐角 = 初相位

例 2 · 同频正弦量求和（相量法标准考题）

u1=10sin⁡(ωt+30°)u_1 = 10\sin(\omega t + 30°)u1​=10sin(ωt+30°) V、u2=10sin⁡(ωt−60°)u_2 = 10\sin(\omega t - 60°)u2​=10sin(ωt−60°) V，求 u=u1+u2u = u_1 + u_2u=u1​+u2​。

解

第一步，写相量（这里用幅值做模，因为题给的是幅值）：

第二步，代数型相加：

U˙m=(8.66+5.00)+j(5.00−8.66)=13.66−j3.66\dot U_m = (8.66 + 5.00) + j(5.00 - 8.66) = 13.66 - j3.66 U˙m​=(8.66+5.00)+j(5.00−8.66)=13.66−j3.66

∣U˙m∣=13.662+3.662=14.14 V,ψ=arctan⁡−3.6613.66=−15°|\dot U_m| = \sqrt{13.66^2 + 3.66^2} = 14.14\ \text{V}, \qquad \psi = \arctan\frac{-3.66}{13.66} = -15° ∣U˙m​∣=13.662+3.662​=14.14 V,ψ=arctan13.66−3.66​=−15°u=14.14sin⁡(ωt−15°) Vu = 14.14\sin(\omega t - 15°)\ \text{V} u=14.14sin(ωt−15°) V

例 4 · 概念辨析（判断题高频）

判断下列说法对错，并说明理由。

(a) 两个正弦电压频率不同，也可以画在同一张相量图上比较相位。 (b) 相量 U˙\dot UU˙ 是一个随时间旋转的矢量。 (c) 相量等于瞬时值，只是写法不同。

解

(a) 错。 相量图上相量之间的夹角代表相位差，而不同频率的两个量相位差本身随时间变化，没有固定值可画。相量图只对同频量有意义。

(b) 错。 相量是复数（一对固定的数：模和辐角）。「旋转相量」是理解其来历的教学模型 —— 真正旋转的是 UmejωtU_me^{j\omega t}Um​ejωt，而相量只是它 t=0t=0t=0 时刻的快照。所以 U˙≠u(t)\dot U \ne u(t)U˙=u(t)，两者永远不相等，只是一个对应两种写法。

(c) 错。 同 (b)。相量携带的是幅值 + 相位，丢失了「随时间变化」这部分信息 —— 因为频率已经被同频假设定死了，不需要再携带。

工程实例 ​

  • 仪表读数：交流电压表、电流表读的都是有效值。用它们测 220 V 单相电机时，U=220U = 220U=220 V 就是有效值，绝缘和耐压按幅值 311 V 考核。
  • 电网频率：中国电网 f=50f = 50f=50 Hz，ω=314\omega = 314ω=314 rad/s，T=20T = 20T=20 ms。这个数字在后面每一章都会反复出现，建议形成条件反射：看到 314 就想到 50 Hz。
  • 示波器测相位：双通道示波器是唯一能直接看到 ψ\psiψ 的仪器 —— 数格数 × 每格时间 × 360° = 相位差。相量法算出来的相位，最终要靠示波器验证。
  • 音频频段：人耳 20 Hz – 20 kHz，对应角频率 125 – 125660 rad/s。同一个电容在 20 Hz 和 20 kHz 下的容抗差 1000 倍 —— 这就是分频器能工作的原因。

  3. 不同频率的正弦量不能画在同一张相量图上
  4. 相量是复数不是时间函数，U˙≠u(t\dot U \ne u(tU˙=u(t
  5. 加减法忘记转成代数型，直接拿极坐标的模做加减
  6. arctan⁡\arctanarctan 的值域是 (−90°,90°)(-90°, 90°)(−90°,90°)，实部为负时要手工加/减 180° 才是真正的辐角
