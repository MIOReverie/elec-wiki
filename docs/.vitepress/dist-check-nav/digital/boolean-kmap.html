02 · 逻辑代数与卡诺图 ​

核心 约 30 min化简逻辑函数：公式法看功底，卡诺图看眼力

本页用到两条前置知识： 与 。看完本页再回头看这两张卡，公式法的每一步都会变得理所当然。

结论先行 ​

  1. 逻辑变量只有 0/1，基本运算是与（·）、或（+）、非（‾）。一切数字系统都能用这三种搭出来。
  2. 德摩根定律是万能钥匙：A+B‾=Aˉ ⁣⋅ ⁣Bˉ\overline{A+B}=\bar A\!\cdot\!\bar BA+B​=Aˉ⋅Bˉ、AB‾=Aˉ+Bˉ\overline{AB}=\bar A+\bar BAB=Aˉ+Bˉ（「非」进去，符号翻转）。
  3. 化简的目的：门更少、连线更少、更便宜也更不容易出错。
  4. 公式法靠熟练，卡诺图靠图形——考试和工程都推荐卡诺图，因为它不会「漏化简」。
  5. **无关项（don't care）**可以当 1 也可以当 0，专门用来把圈画大。

二、布尔代数基本定律 ​

化简用的每一条定律，以及「为什么要用吸收律而不是展开」这类判断，见 。

类别公式
交换律A+B=B+A,  AB=BAA+B = B+A,\; AB = BAA+B=B+A,AB=BA
结合律(A+B)+C=A+(B+C),  (AB)C=A(BC)(A+B)+C = A+(B+C),\; (AB)C = A(BC)(A+B)+C=A+(B+C),(AB)C=A(BC)
分配律A(B+C)=AB+AC,  A+BC=(A+B)(A+C)A(B+C) = AB+AC,\; A+BC = (A+B)(A+C)A(B+C)=AB+AC,A+BC=(A+B)(A+C)
同一律A+0=A,  A⋅1=AA+0=A,\; A\cdot 1 = AA+0=A,A⋅1=A

德摩根定律最重要，务必背熟：

A+B‾=Aˉ⋅BˉAB‾=Aˉ+Bˉ\overline{A+B} = \bar A\cdot\bar B \qquad \overline{AB} = \bar A + \bar B A+B​=Aˉ⋅BˉAB=Aˉ+Bˉ

它的用处：把「与」变「或」、把「或」变「与」，是画电路、写程序条件、做硬件描述语言时的日常操作。

例 1 · 公式法化简 Y=(A+B)(A+C)Y = (A+B)(A+C)Y=(A+B)(A+C)

展开后用吸收律收尾：

Y=A⋅A+AC+AB+BC=A+A(B+C)+BC=A(1+(B+C))+BC=A+BCY = A\cdot A + AC + AB + BC = A + A(B+C) + BC = A\bigl(1+(B+C)\bigr) + BC = A + BC Y=A⋅A+AC+AB+BC=A+A(B+C)+BC=A(1+(B+C))+BC=A+BC

即 Y=A+BCY = A + BCY=A+BC。验证：当 A=1A=1A=1 时两边都是 1；当 A=0A=0A=0 时左边 (B)(C)=BC(B)(C)=BC(B)(C)=BC、右边 BCBCBC，一致。

三、卡诺图：把「相邻」画出来 ​

卡诺图的排列规则、圈 1 的硬规则与无关项的用法，见 。

卡诺图的诀窍是按格雷码排列——相邻两格只有一位变量不同，这样「圈相邻格」在数学上才等价于「消去那个变化的变量」。

圈 1 的规则：

  1. 圈必须包含 2k2^k2k 个相邻的 1（1、2、4、8…）
  2. 圈越大越好（消掉的变量越多）
  3. 圈数越少越好
  4. 每个 1 至少被圈一次
  5. 圈内变量取值不变的保留，变化的消去，写成一个与项，各圈相「或」

规则读起来抽象，圈起来全是肌肉记忆。下面这个演示把四道典型函数做成了可上手的格子：按住拖动画矩形，面板会实时告诉你圈住了哪些最小项、消掉了谁、剩下什么与项；确认后圈会累积成最终表达式，并统计 1 格覆盖进度。

两道题值得先动手再往下看：

  • 3 变量（F=∑m(0,1,2,5,6,7)F=\sum m(0,1,2,5,6,7)F=∑m(0,1,2,5,6,7)）：试试能不能只圈 3 个 2 格圈盖满全部 6 个 1，并找出那个「另一个等价最优解」
  • 4 变量（F=∑m(0,2,4,6,8,10,12,14)F=\sum m(0,2,4,6,8,10,12,14)F=∑m(0,2,4,6,8,10,12,14)）：答案只与 DDD 有关。普通矩形圈不出来——最左一列和最右一列在普通表里相隔天涯，在卡诺图里却是邻居。借助左右两侧淡淡的副本列：把最左主格和它左边的副本列一起框住（或最右主格加它的右副本），松手就是跨边界的 8 格大圈，这正是卡诺图与普通方格表的本质区别

例 2 · 三变量卡诺图：三个圈合成一个函数

化简 F(A,B,C)=∑m(0,1,2,5,6,7)F(A,B,C)=\sum m(0,1,2,5,6,7)F(A,B,C)=∑m(0,1,2,5,6,7)。

填图（行 AAA，列 BCBCBC 格雷码 00→01→11→10）：

A\BC00011110
01101
10111

画圈（每个 2 格圈消去 1 个变量）：

  • ① {m0,m1}\{m_0,m_1\}{m0​,m1​}：横向圈，A=0A=0A=0、B=0B=0B=0 不变，CCC 变 → 与项 AˉBˉ\bar A\bar BAˉBˉ
  • ② {m2,m6}\{m_2,m_6\}{m2​,m6​}：竖向圈（跨 A=0/1A=0/1A=0/1 两行），B=1B=1B=1、C=0C=0C=0 不变 → 与项 BCˉB\bar CBCˉ
  • ③ {m5,m7}\{m_5,m_7\}{m5​,m7​}：横向圈，A=1A=1A=1、C=1C=1C=1 不变 → 与项 ACACAC
F=AˉBˉ+BCˉ+ACF = \bar A\bar B + B\bar C + AC F=AˉBˉ+BCˉ+AC

为什么这就是最优：图里找不出 4 格圈——四个 2×22\times22×2 块各自都掺着一个 0。6 个 1、每圈最多盖 2 格，所以至少 3 个圈；上面正好 3 个圈无重叠地盖满 6 格，项数不可能再少。

验算（逐点比对）：m0m_0m0​：AˉBˉ=1\bar A\bar B=1AˉBˉ=1 ✓；m1m_1m1​：AˉBˉ=1\bar A\bar B=1AˉBˉ=1 ✓；m2m_2m2​：BCˉ=1B\bar C=1BCˉ=1 ✓；m3m_3m3​：三项全 0 ✓（原函数此处就是 0）；m4m_4m4​：全 0 ✓；m5m_5m5​：AC=1AC=1AC=1 ✓；m6m_6m6​：BCˉ=1B\bar C=1BCˉ=1 ✓；m7m_7m7​：AC=1AC=1AC=1 ✓。

两个提醒：

  • 圈可以重叠（m7m_7m7​ 同时属于 ③ 和别的圈也没事），规则只是「每个 1 至少被圈一次」。
  • 最简式不唯一：AˉCˉ+BˉC+AB\bar A\bar C + \bar B C + ABAˉCˉ+BˉC+AB 是另一个同样 3 项的最优解（横向/竖向搭配不同）。只要项数一样少、逐点验算全对，就是对的——考试写哪个都行。

例 3 · 四变量：一整列都是 1

化简 F=∑m(0,2,4,6,8,10,12,14)F=\sum m(0,2,4,6,8,10,12,14)F=∑m(0,2,4,6,8,10,12,14)。

这 8 个全是「偶数」编号的 minterm，意味着最低位 DDD 都是 0。卡诺图（行 AB、列 CD，均格雷码）：

AB\CD00011110
001001
011001
111001
101001

第 00 列和第 10 列（对应 D=0D=0D=0）整列都是 1，合成一个大圈覆盖全部 8 格，A,B,CA,B,CA,B,C 都在圈内变化被消去，只剩「D=0D=0D=0」这个条件：

F=DˉF = \bar D F=Dˉ

先看规律再画圈：8 个 minterm 全是偶数号 → 二进制最低位都是 0 → 不用画图就能猜出答案与 DDD 以外的变量无关。卡诺图只是把这个猜测「看见」。

例 4 · 利用无关项

化简 F=∑m(1,3,5,7,9)+d(11,13,15)F=\sum m(1,3,5,7,9) + d(11,13,15)F=∑m(1,3,5,7,9)+d(11,13,15)。

ddd 是无关项（某几种输入组合硬件上不会出现，可当 1 也可当 0）。这里 1 和 ddd 恰好铺满了「D=1D=1D=1」的所有格子：

AB\CD00011110
000110
010110
110dd0
1001d0

把 ddd 当 1，整个 D=1D=1D=1 的区块连成一圈（8 格），A,B,CA,B,CA,B,C 全消去：

F=DF = D F=D

若死板地不碰无关项，会得到更复杂的式子——无关项是「免费的增大圈」，考试必考。

四、工程实例 ​

用一块 3-8 译码器 + 一个与非门实现任意 3 变量函数：74LS138 的 8 个输出正好对应 8 个最小项（低电平有效）。把函数包含的那些最小项对应的输出「相与」，就等于原函数。这比手写一堆门省事得多——而背后的原理，正是卡诺图里「每个圈 = 一个与项」。

化简直接省成本：一个监控逻辑若原式要 12 个门，卡诺图化简后可能只要 4 个。在量产芯片里，少一个门就是实打实的面积和功耗下降。

五、易错清单 + 自检 ​

  • [ ] 卡诺图必须按格雷码排（00→01→11→10），按 00→01→10→11 排会破坏相邻性，圈错
  • [ ] 圈必须是 2k2^k2k 个，3 个、6 个这种不能圈
  • [ ] 无关项不是「随便填」，是为了把圈画大；填错方向反而更糟
  • [ ] 德摩根：AB‾\overline{AB}AB 变 Aˉ+Bˉ\bar A+\bar BAˉ+Bˉ（与或互换），别漏掉「符号翻转」
  • [ ] 异或的扩展：A⊕B⊕CA\oplus B\oplus CA⊕B⊕C 是「奇校验」——1 的个数为奇数才出 1

自检：用卡诺图化简 F=∑m(4,5,6,7,12,13,14,15)F=\sum m(4,5,6,7,12,13,14,15)F=∑m(4,5,6,7,12,13,14,15)。（提示：看第 10 行与第 11 行——答案 F=BF = BF=B）
