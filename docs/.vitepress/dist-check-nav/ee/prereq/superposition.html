叠加定理 ​

线性电路中，任一支路的响应 = 各独立源单独作用时响应的代数和。

"单独作用"的操作：

  • 不作用的电压源 → 短路（U=0U = 0U=0）
  • 不作用的电流源 → 开路（I=0I = 0I=0）
  • 受控源必须保留，不能置零

限制：

  • 只适用于线性电路
  • 只能叠加电压、电流，功率不能叠加（P∝I2P \propto I^2P∝I2，非线性）

完整内容见 05 · 叠加 · 戴维南 · 最大功率
