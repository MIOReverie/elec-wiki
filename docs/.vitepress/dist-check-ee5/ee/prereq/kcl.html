基尔霍夫电流定律 KCL ​

卡片 约 5 minKCL 用的是参考方向下的代数值，不是绝对值；先定「流入为正」再代数相加，符号自己会告诉你答案

一句话结论：任一结点，任一时刻，流入的电流之和等于流出的电流之和（∑I=0\sum I = 0∑I=0）——因为电荷不能凭空产生也不能凭空消失。

日常说法与正式定义 ​

  • 日常说法：水管网络里，水在一个三通口既不能自己多出来也不能自己消失——进来的等于出去的。
  • 正式定义：任一结点、任一时刻，穿过该结点的各支路电流的代数和为零：
∑I=0⟺∑I入=∑I出\sum I = 0 \quad \Longleftrightarrow \quad \sum I_{入} = \sum I_{出} ∑I=0⟺∑I入​=∑I出​

本质是电荷守恒（结点不能堆积电荷）。如果电流真的不相等，多出来的电荷会让结点电位一直升高，直到不再有电流——这与稳态矛盾。

一句话抓住本质

KCL 说的不是「电流守恒」，而是电荷守恒在结点上的投影。它与元件性质无关：电阻、电容、电源、受控源一视同仁；线性/非线性、直流/交流也都成立。

符号逐个读：

符号含义
III电流，带参考方向
I入I_{入}I入​、I出I_{出}I出​相对于该结点的流入电流、流出电流
结点三条或三条以上支路相接的连接点

怎么用：先定方向，再代数相加 ​

只有一条纪律，但它是 KCL 唯一的坑：

每个 III 都带着自己相对结点的方向（参考方向），不是各支路电流的绝对值相加。

做法：全题统一约定「流入为正、流出为负」（或反过来，都行），然后代数相加。若算得某条支路为负，说明它的实际方向与你假设的箭头相反，而不是「电流是负的」这种物理上不存在的说法。

广义结点 ​

把电路里任意一块区域（一个闭合面）看作一个结点，穿过这个面的电流代数和也为 0。

这是 KCL 最省时间的用法：想知道「流入某一块电路的总电流」时，不必逐条支路算——在那一块外面画个圈，对穿过这个圈的电流列一次 KCL，一个方程就够。

常见误解 ​

  1. 把 ∑I=0\sum I=0∑I=0 当绝对值相加 → 方程恒不成立或解出荒唐值 → 每个 III 都带相对结点的符号，先定「流入为正」再代数相加。
  2. 解出负电流后以为算错了 → 改数字凑正数 → 负号是结论：实际方向与箭头相反。
  3. 以为 KCL 只对「真正的结点」成立 → 遇到复杂网络不会用 → 广义结点：对任意闭合面都成立。
  4. 以为 KCL 依赖元件性质 → 遇到非线性元件就不敢用 → KCL 只依赖连接方式。
  5. 在长线、高频下照用 → 结论与实际不符 → 分布参数电路要用传输线理论。

例题 ​

例 1 · 一个结点的 KCL

题目：一个结点上接三条支路。支路 1 流入 I1=2I_1=2I1​=2 A，支路 2 流出 I2=3I_2=3I2​=3 A，支路 3 也是流出，电流 I3I_3I3​ 未知。求 I3I_3I3​。

先想什么：题目只问电流、不问电压，所以只需要 KCL——KVL 在这道题里没有用武之地。（先看未知量的类型，再选定律，这是省时间的关键。）

步骤：

  1. 定符号规则：流入为正、流出为负。
  2. 列 KCL：I1−I2−I3=0I_1 - I_2 - I_3 = 0I1​−I2​−I3​=0。
  3. 代入：2−3−I3=0⇒I3=−1 A2 - 3 - I_3 = 0 \Rightarrow I_3 = -1\ \text{A}2−3−I3​=0⇒I3​=−1 A。

验算（把结果代回原式，按「流入为正、流出为负」求和）：2−3−(−1)=02 - 3 - (-1) = 02−3−(−1)=0 ✓。

结果的物理意义：I3<0I_3<0I3​<0 说明支路 3 的实际方向与箭头相反，也就是流入该结点 1 A。此时结点上：流入 2+1=32+1=32+1=3 A，流出 333 A，仍然守恒 ✓。

这一节最该带走的一句：若还要求电压，先用电阻关系算出各支路电流，再用 KVL 求电压。顺序永远是「先电流后电压」，反过来会多出未知数。

在正文里什么时候用得上 ​

完整内容见 02 · 基尔霍夫定律与电位

KCL 是结点电压法的全部内容（列出来的每个方程都是一条 KCL），也是支路电流法、戴维南定理求等效电阻（加一个测试电流源）反复用到的东西。凡是题目问「某条支路里有多少电流」「某块电路吸收多少总电流」，都先想到 KCL。
