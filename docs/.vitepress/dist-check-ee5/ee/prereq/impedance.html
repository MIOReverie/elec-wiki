阻抗与导纳 ​

卡片 约 5 min电感是「电压超前」，电容是「电流超前」——两个 90° 方向相反，这一句错了后面谐振、功率因数全部反向

一句话结论：阻抗 ZZZ 是「电压 ÷ 电流」这个复数：电阻是纯实数、电感是 +j+j+j、电容是 −j-j−j；所以电感的电压超前电流 90°、电容的电流超前电压 90°，两者方向相反。

日常说法与正式定义 ​

  • 日常说法：直流下电阻「挡路」，电感「短路」，电容「断路」；到了交流，电感和电容开始「挡路」，而且挡的方式很特别——它们不让电流变小，只是让电压和电流错开一个角度。
  • 正式定义：正弦稳态下元件两端的相量电压与相量电流之比称为阻抗：
Z=U˙I˙=R+jX=∣Z∣∠φZ = \frac{\dot U}{\dot I} = R + jX = |Z|\angle\varphi Z=I˙U˙​=R+jX=∣Z∣∠φ

它的倒数称为导纳：

Y=1Z=G+jBY = \frac{1}{Z} = G + jB Y=Z1​=G+jB

中文术语提醒

导纳的虚部 BBB 叫电纳（不是「电抗」）；电抗是 XXX。两个名字只差一个字，指的却是互为倒数的两个量，读题时要看清楚是 XXX 还是 BBB。

串联时怎么加 ​

串联电路里电流相同，所以各元件的阻抗直接相加：

Z=R+j(XL−XC),∣Z∣=R2+X2,φ=arctan⁡XL−XCRZ = R + j(X_L - X_C),\quad |Z| = \sqrt{R^2+X^2},\quad \varphi = \arctan\frac{X_L-X_C}{R} Z=R+j(XL​−XC​),∣Z∣=R2+X2​,φ=arctanRXL​−XC​​

于是：

  • XL>XCX_L > X_CXL​>XC​ → 感性（电流滞后电压）
  • XL<XCX_L < X_CXL​<XC​ → 容性（电流超前电压）
  • XL=XCX_L = X_CXL​=XC​ → 阻性（谐振，Z=RZ = RZ=R 最小）

一句口诀

电感在「上」，电流滞后；电容在「下」，电流超前。 记忆办法：电感的阻抗是 +jωL+j\omega L+jωL，正号在上方。

直流极限：电感短路、电容开路 ​

当 ω=0\omega=0ω=0（直流）时：

  • 电感：ZL=jωL=0Z_L = j\omega L = 0ZL​=jωL=0 → 短路（电压为零，电流可以任意大）
  • 电容：ZC=1jωC→∞Z_C = \dfrac{1}{j\omega C} \to \inftyZC​=jωC1​→∞ → 开路（电流为零）

这两条不是「特例规定」，而是从公式里自然掉出来的：直流下电感里的电流不随时间变（导数为 0，所以没有电压），电容两端电压不变（所以没有电流）。

常见误解 ​

  1. 把「阻抗」当成「电阻」 → 用 ∣Z∣|Z|∣Z∣ 直接当阻值算功率 → 阻抗是复数，实部 RRR 才是耗能的部分，P=I2RP = I^2RP=I2R 用的是它。
  2. 说成「电容的电压超前 90°」 → 阻抗三角形的方向全反 → 电容是电流超前电压 90°（等价说法：电容电压滞后 90°）。
  3. 用电阻的直觉理解电抗 → 以为电流被「挡住」变小 → 电抗不改变电流的大小，只改变相位。
  4. 在直流下还用电抗公式 → 算出除零 → 直流直接用「电感短路、电容开路」这两句。
  5. 以为电感电容是「阻抗小/大」 → 以为 XCX_CXC​ 随频率升高而变大 → XC=1/(ωC)X_C = 1/(\omega C)XC​=1/(ωC) 随频率升高而变小；XL=ωLX_L = \omega LXL​=ωL 随频率升高而变大。
