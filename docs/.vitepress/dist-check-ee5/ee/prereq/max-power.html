最大功率传输 ​

卡片 约 5 min匹配点上效率恰好 50%：负载拿到的功率和白白浪费在源内阻上的功率一样多——这是「最大功率」与「最高效率」不可兼得的根源

一句话结论：负载电阻等于源的内阻时，负载拿到的功率最大，Pmax=UOC2/(4Req)P_{max} = U_{OC}^2/(4R_{eq})Pmax​=UOC2​/(4Req​)；但此时效率只有 50%，所以电力系统绝不这样匹配，只有信号电路才追求它。

日常说法与正式定义 ​

  • 日常说法：手电筒的电池和灯泡要「配套」——电池内阻太大，灯泡就不亮；电池内阻太小，电池自己发热浪费。有一个刚刚好的搭配。
  • 正式定义：负载 RLR_LRL​ 从含源二端网络获得最大功率的条件是阻抗匹配：
RL=ReqPmax=UOC24ReqR_L = R_{eq} \qquad P_{max} = \frac{U_{OC}^2}{4R_{eq}} RL​=Req​Pmax​=4Req​UOC2​​

其中 UOCU_{OC}UOC​ 是含源网络的开路电压，ReqR_{eq}Req​ 是它的戴维南等效电阻（把独立源置零后从端口看进去的电阻）。

符号逐个读：

符号含义
RLR_LRL​负载电阻
ReqR_{eq}Req​含源网络的等效内阻（戴维南电阻）
UOCU_{OC}UOC​开路电压（把负载拿掉，两端的电压）
η\etaη效率，负载得到的功率占电源发出的功率的比例

为什么效率只有 50% ​

匹配点上 RL=ReqR_L = R_{eq}RL​=Req​，流过内阻的电流和流过负载的电流一样大，于是内阻损耗和负载得到的功率相等：

PL=I2RL=I2Req=P内阻P_L = I^2R_L = I^2R_{eq} = P_{内阻} PL​=I2RL​=I2Req​=P内阻​η=PLPL+P内阻=12=50%\eta = \frac{P_L}{P_L + P_{内阻}} = \frac{1}{2} = 50\% η=PL​+P内阻​PL​​=21​=50%

所以「最大功率」和「最高效率」不可兼得——这是本卡最该带走的一句话。

两种场景，两种选择 ​

场景目标做法
电力系统（输电、变压器）效率高、发热少RL≫ReqR_L \gg R_{eq}RL​≫Req​，几乎不匹配
信号/通信电路（天线、功放输出）从源取到的功率最大RL=ReqR_L = R_{eq}RL​=Req​，做阻抗匹配

为什么电力系统不匹配：输电线有电阻，电流大了损耗 I2RI^2RI2R 就大。宁可少取一点功率，也要把线路损耗压下去——所以高压输电不是为了「送更多电」，而是为了「送同样的电时电流更小」。

为什么信号电路要匹配：发射机的功放输出级本身效率不高，它的任务是把「有限的射频功率」尽可能多地送进天线（天线就是负载）。这时 RL=ReqR_L=R_{eq}RL​=Req​ 的意义是「不浪费信号」。

交流推广：共轭匹配 ​

在交流电路里，条件变成共轭匹配：

ZL=Zeq∗即RL=Req 且 XL=−XeqZ_L = Z_{eq}^* \qquad \text{即} \qquad R_L = R_{eq}\ \text{且}\ X_L = -X_{eq} ZL​=Zeq∗​即RL​=Req​ 且 XL​=−Xeq​

（Z∗Z^*Z∗ 读作 ZZZ 的共轭复数：实部不变、虚部变号。）直观理解：负载的电抗要抵消源的漏抗，否则电流被拉偏，功率反而上不去。

常见误解 ​

  1. 以为「最大功率」总是好事 → 把电源配到 50% 效率 → 先问一句：这是输电还是送信号？
  2. 以为匹配点是效率最高点 → 算效率时用错公式 → 匹配时效率恰好 50%，效率最高在 RL→∞R_L \to \inftyRL​→∞。
  3. 把 UOCU_{OC}UOC​ 当成「带载时的电压」 → 最大功率算错 → UOCU_{OC}UOC​ 是开路电压，带载后端电压只有它的一半。
  4. 交流里只匹配电阻部分 → 电流被漏抗拉偏，功率上不去 → 交流要共轭匹配，虚部也要抵消。
  5. 以为戴维南等效电阻 ReqR_{eq}Req​ 就是电源内阻 → 在有其它元件的网络里算错 → ReqR_{eq}Req​ 要把独立源置零后从端口看进去。

例题 ​

例 1 · 求最大负载功率

题目：某含源二端网络的开路电压 UOC=12 VU_{OC}=12\ \text{V}UOC​=12 V，戴维南等效电阻 Req=3 ΩR_{eq}=3\ \OmegaReq​=3 Ω。接一个可调负载 RLR_LRL​，求：(a) RLR_LRL​ 取何值时负载功率最大？(b) 最大功率是多少？(c) 此时效率是多少？

先想什么：三个问号其实是同一个式子的三层，所以先把 PLP_LPL​ 写成 RLR_LRL​ 的函数。

步骤：

  1. 电流：I=UOCReq+RLI = \dfrac{U_{OC}}{R_{eq}+R_L}I=Req​+RL​UOC​​。
  2. 负载功率：
PL=I2RL=UOC2RL(Req+RL)2=144 RL(3+RL)2P_L = I^2R_L = \frac{U_{OC}^2R_L}{(R_{eq}+R_L)^2} = \frac{144\,R_L}{(3+R_L)^2} PL​=I2RL​=(Req​+RL​)2UOC2​RL​​=(3+RL​)2144RL​​

（为什么先写成函数：要找的是「RLR_LRL​ 取多少时这个函数最大」，而不是套一个背下来的结论。）

  1. 求极大值：对 RLR_LRL​ 求导并令导数为零，得 RL=Req=3 ΩR_L = R_{eq} = 3\ \OmegaRL​=Req​=3 Ω。（也可以用均值不等式：把 PLP_LPL​ 改写成 PL=UOC2Req2/RL+2Req+RLP_L = \dfrac{U_{OC}^2}{R_{eq}^2/R_L + 2R_{eq} + R_L}PL​=Req2​/RL​+2Req​+RL​UOC2​​，分母里 Req2/RLR_{eq}^2/R_LReq2​/RL​ 与 RLR_LRL​ 之和 ≥2Req\ge 2R_{eq}≥2Req​，等号在 RL=ReqR_L=R_{eq}RL​=Req​ 时成立，所以分母最小、功率最大。）
  2. 最大功率：
Pmax=UOC24Req=14412=12 WP_{max} = \frac{U_{OC}^2}{4R_{eq}} = \frac{144}{12} = 12\ \text{W} Pmax​=4Req​UOC2​​=12144​=12 W

（为什么分母是 4：Req=RL=3R_{eq}=R_L=3Req​=RL​=3 时 I=12/6=2 AI = 12/6 = 2\ \text{A}I=12/6=2 A，PL=22×3=12 WP_L = 2^2\times3 = 12\ \text{W}PL​=22×3=12 W。）

  1. 效率：η=RLReq+RL=36=50%\eta = \dfrac{R_L}{R_{eq}+R_L} = \dfrac{3}{6} = 50\%η=Req​+RL​RL​​=63​=50%。

验算（换个负载试试）：取 RL=6 ΩR_L = 6\ \OmegaRL​=6 Ω，I=12/9=1.333 AI = 12/9 = 1.333\ \text{A}I=12/9=1.333 A，PL=1.3332×6=10.67 WP_L = 1.333^2\times6 = 10.67\ \text{W}PL​=1.3332×6=10.67 W < 12 W ✓（偏离匹配点，功率下降）。取 RL=1.5 ΩR_L = 1.5\ \OmegaRL​=1.5 Ω，I=12/4.5=2.667 AI = 12/4.5 = 2.667\ \text{A}I=12/4.5=2.667 A，PL=2.6672×1.5=10.67 WP_L = 2.667^2\times1.5 = 10.67\ \text{W}PL​=2.6672×1.5=10.67 W < 12 W ✓（对称地下降，说明匹配点确实是极大值）。

注意：功率曲线关于 RL=ReqR_L=R_{eq}RL​=Req​ 是对称的——RL=1.5R_L=1.5RL​=1.5 与 RL=6R_L=6RL​=6 给出同一个 10.67 W。这在估算时很有用：负载电阻偏离匹配点多少，功率就掉多少。
