电路模型与理想元件 ​

卡片 约 5 min模型只管端口对外的关系：理想电压源的电压由外电路决定，理想电流源的电流由外电路决定——两者都不能同时被钉死

一句话结论：电路模型 = 把实际器件抽象成若干「理想元件」的连接，只关心端口的 uuu-iii 关系；而理想元件里最该记住的一条分工是：电压源钉死电压、电流源钉死电流，二者必居其一。

日常说法与正式定义 ​

  • 日常说法：现实里的电池、线圈、电容都「不太规矩」——电池电压会随负载掉，线圈会发热也有电阻。工程师的做法不是放弃它们，而是先画一个规矩的模型，算出结果，再回头看这个模型在什么范围内够用。
  • 正式定义：电路模型是把实际器件抽象成若干理想元件的连接，只关心端口的 uuu-iii 关系。理想元件有两种：有源（能向外送电：电源）与无源（不能自己发电：电阻、电感、电容）。

实际电源模型 = 理想源 + 内阻 ​

理想元件太理想，真实的电源总有一份内阻：

  • 实际电压源 = 理想电压源 EEE 串内阻 R0R_0R0​
  • 实际电流源 = 理想电流源 ISI_SIS​ 并内阻 R0R_0R0​

内阻 R0R_0R0​ 不是「零件脏了」，而是电源内部导体、电解液、绕组本来就导电，于是它和负载分走同一份电压。

记忆分工的一句话

电压源是「电压给足，电流随你」；电流源是「电流给足，电压随你」。 记住这一句，就不会在「这个电源到底输出多少」上绕圈子。

常见误解 ​

  1. 以为理想电压源的电流也是固定的 → 画图时给电压源标一个电流值 → 电压源只钉死电压，电流完全由外电路决定；反过来理想电流源只钉死电流。
  2. 把 u=Ldidtu = L\dfrac{di}{dt}u=Ldtdi​ 里的 LLL 当成「电感两端电压」 → 套欧姆定律算出假阻值 → LLL 是电感量（单位 H），它决定的是「电流变化多快才产生这么高的电压」。
  3. 以为模型越简单越好，直接用理想源 → 算出「电源电压恒为 12 V」→ 实际带载后端电压会掉，一接负载结论就失效。
  4. 以为 RRR、LLL、CCC 是「三种不同的电阻」 → 它们只是三种不同的端口关系：线性比例、比例于电流变化率、比例于电压变化率。

例题 ​

例 1 · 实际电源带载：端电压掉了多少

题目：一个标称 6 V 的电池（电动势 E=6E=6E=6 V，内阻 R0=0.2 ΩR_0=0.2\ \OmegaR0​=0.2 Ω）接一个 RL=2.8 ΩR_L=2.8\ \OmegaRL​=2.8 Ω 的负载。求电流、负载端电压，以及电源内阻上白白消耗的功率。

先想什么：题目给的是「标称 6 V」——那其实是开路电压，带载后端电压要掉。所以第一步不是套欧姆定律，而是先认清用的是哪个模型。

步骤：

  1. 电流：I=ER0+RL=60.2+2.8=2 AI = \dfrac{E}{R_0+R_L} = \dfrac{6}{0.2+2.8} = 2\ \text{A}I=R0​+RL​E​=0.2+2.86​=2 A。（为什么分母要加 R0R_0R0​：内阻与负载串在同一条回路上，流过的是同一个电流。）
  2. 负载端电压：U=IRL=2×2.8=5.6 VU = IR_L = 2\times2.8 = 5.6\ \text{V}U=IRL​=2×2.8=5.6 V。（为什么用 IRLIR_LIRL​ 而不是 EEE：端电压是「到手的那一份」。）
  3. 内阻上的损耗：P0=I2R0=22×0.2=0.8 WP_0 = I^2R_0 = 2^2\times0.2 = 0.8\ \text{W}P0​=I2R0​=22×0.2=0.8 W。

验算（用功率守恒）：电源发出 P=EI=6×2=12P = EI = 6\times2 = 12P=EI=6×2=12 W；负载吸收 PL=I2RL=22×2.8=11.2P_L = I^2R_L = 2^2\times2.8 = 11.2PL​=I2RL​=22×2.8=11.2 W，内阻吸收 0.8 W。12=11.2+0.812 = 11.2+0.812=11.2+0.8 ✓（全电路 ∑P=0\sum P = 0∑P=0）。

注意：负载拿到的 5.6 V 已经比标称的 6 V 低了近 7%——这就是「标称电压」与「实际电压」的差别，也是电源内阻存在的直接后果。
