基础

  • 电功率与电能P = UI；关联方向下 P>0 吸收功率，P<0 发出功率。全电路功率守恒。01 · 电路模型与参考方向 →
  • 电路模型与理想元件把实际器件抽象成 R / L / C / 电源 等理想元件的集合，只关心端口的 u-i 关系。01 · 电路模型与参考方向 →
  • 电位与参考点电位是相对量，换参考点电位全变，但任意两点间电压不变。02 · 基尔霍夫定律与电位 →
  • 电压电流的参考方向先任意假设一个方向，算出来为正说明实际方向一致，为负说明相反。关联/非关联方向决定功率符号。01 · 电路模型与参考方向 →
  • 电源有载 / 开路 / 短路有载 I=E/(R₀+R)；开路 I=0、U=E；短路 I=E/R₀ 极大，必须避免。01 · 电路模型与参考方向 →
  • 基尔霍夫电流定律 KCL任一节点：ΣI = 0（流入 = 流出）。本质是电荷守恒，与元件性质无关。02 · 基尔霍夫定律与电位 →
  • 基尔霍夫电压定律 KVL任一回路：ΣU = 0（电压升 = 电压降）。本质是能量守恒。02 · 基尔霍夫定律与电位 →
  • 欧姆定律关联方向下 U = RI；非关联方向加负号。电阻是耗能元件。01 · 电路模型与参考方向 →

分析方法

  • 戴维南 / 诺顿定理任何含源二端网络 = 电压源 U_oc 串 R_eq（或电流源 I_sc 并 R_eq）。求复杂电路中一条支路的最快方法。05 · 叠加定理 · 戴维南 · 最大功率 →
  • 电压源 ⇄ 电流源等效变换实际电压源 E 串 R₀ ⇄ 实际电流源 Iₛ = E/R₀ 并 R₀。只对外等效。03 · 串并联与电源等效变换 →
  • 电阻串并联等效串联 R=ΣRᵢ、分压；并联 1/R=Σ1/Rᵢ、分流。串并联是化简电路的第一刀。03 · 串并联与电源等效变换 →
  • 叠加定理线性电路中，每个独立源单独作用之和 = 共同作用。不作用源置零（电压源短路、电流源开路）。05 · 叠加定理 · 戴维南 · 最大功率 →
  • 分压与分流公式串联：Uₖ = Rₖ/ΣR · U；并联两电阻：I₁ = R₂/(R₁+R₂) · I。03 · 串并联与电源等效变换 →
  • 结点电压法选参考点，以结点电压为未知量列 KCL：G·U = Iₛ。最省方程数的通用方法。04 · 支路电流法与结点电压法 →
  • 星形 ⇄ 三角形变换Y→△：R△ = ΣR_Y两两积之和 / 对面R_Y；对称时 R△ = 3R_Y。03 · 串并联与电源等效变换 →
  • 最大功率传输负载 R_L = R_eq 时获得最大功率 P_max = U_oc²/(4R_eq)，效率仅 50%。05 · 叠加定理 · 戴维南 · 最大功率 →

暂态

  • 换路定则u_C 与 i_L 不能突变：u_C(0₊)=u_C(0₋)、i_L(0₊)=i_L(0₋)。其它量都可以突变。06 · 储能元件与换路定则 →
  • 时间常数 τRC 电路 τ = R_eq·C；RL 电路 τ = L/R_eq。τ 是过渡过程走完 63.2% 所需时间。07 · 三要素法：RC / RL →

交流

  • 串联谐振ω₀ = 1/√(LC)，此时 X=0、Z=R 最小、I 最大，U_L 与 U_C 可能远高于电源电压。11 · 谐振与频率特性 →
  • 复数与相量运算相量是复数的极坐标写法：A∠ψ = A(cosψ + j sinψ)。乘除用极坐标，加减用代数型。08 · 正弦量与相量法 →
  • 功率因数 cosφP = UI cosφ，Q = UI sinφ，S = UI。提高 cosφ 可减小线路电流与损耗。10 · 功率与功率因数 →
  • 有效值（RMS）有效值 = 在相同时间内产生相同热效应的直流值。正弦量 U = U_m/√2。08 · 正弦量与相量法 →
  • 正弦量三要素幅值 U_m、角频率 ω、初相位 ψ。三要素确定则正弦量唯一确定。08 · 正弦量与相量法 →
  • 阻抗与导纳Z = R + jX，Z_L = jωL，Z_C = 1/(jωC) = -j/(ωC)。感抗使电压超前，容抗使电流超前。09 · RLC 串联与阻抗 →

三相

  • 对称三相电源三个幅值相同、频率相同、相位互差 120° 的正弦电动势。Y 接时 U_l = √3 U_p 且超前 30°。12 · 三相电路 →

磁路与电机

  • 变压器变比U₁/U₂ ≈ N₁/N₂ = k，I₁/I₂ ≈ 1/k，Z₁ = k²Z_L。只变交流、不能变直流。15 · 变压器 →
  • 磁路欧姆定律Φ = F/R_m = NI/(l/μS)，与电路欧姆定律同构，但铁磁材料 μ 非线性。14 · 磁路基础 →
  • 转差率 ss = (n₀ - n)/n₀。s=0 空载（理想），s=1 堵转，额定 s_N 通常 2%~6%。16 · 三相异步电动机原理 →

电子技术

  • 布尔代数与逻辑门与/或/非 + 德摩根定律。真值表 ↔ 逻辑表达式 ↔ 电路图 三者互转是基本功。23 · 数字电路基础 →
  • 触发器具有记忆功能的基本单元。D 触发器：Qⁿ⁺¹ = D（时钟边沿到来时）。25 · 触发器与时序电路 →
  • 二极管单向导电正向导通（硅管压降约 0.7V）、反向截止。整流电路的基础。（模电已学）22 · 整流 · 滤波 · 稳压 →

数字电路

  • 布尔代数与化简与或非三种运算、德摩根定律、吸收律与冗余项；化简的判据是项数最少、每项字面数最少。02 · 逻辑代数与卡诺图 →
  • 建立时间与保持时间触发器的采样窗口：时钟沿之前数据要稳定够久（建立），沿之后还要稳够久（保持）。05 · 触发器 →
  • 卡诺图与最小项按格雷码排列，圈 1 的规则：圈必须含 2^k 个相邻的 1，圈数最少、字面数最少；无关项用来把圈画大。02 · 逻辑代数与卡诺图 →
  • 门电路扇出与驱动能力扇出 = 输出能带动的输入数，取高电平与低电平两个方向中较小者；扇出不足时用缓冲器扩展。03 · 门电路与集成器件 →

模拟电子

  • 静态工作点与负载线Q 点定位置、直流与交流负载线定摆幅；最大不失真输出取两侧余量的较小值。02 · 基本放大电路 →
  • 三极管工作区放大区、饱和区、截止区的判据；先算需求 I_C=βI_B，再算天花板 V_CC/R_C，谁小听谁的。01 · 半导体器件 →
  • 虚短与虚断运放线性区的两条近似规则：输入电流近似为零、两个输入端电位近似相等；前提是有负反馈。07 · 信号的运算和处理 →
  • PN 结与二极管模型耗尽层与内电场造成单向导电；工程估算用恒压模型（硅 0.7 V），小信号用动态电阻 nV_T/I_DQ。01 · 半导体器件 →

嵌入式

  • 寄存器映射寄存器就是占据固定地址的一小块内存；基地址加固定偏移，读-改-写或用 BSRR 原子置位。03 · 嵌入式 C 与寄存器思维 →
  • 时钟树HSI/HSE 经 PLL 倍频再分频到各总线；外设时钟默认关闭，APB 预分频不为 1 时定时器时钟自动乘二。04 · 时钟系统（RCC 与时钟树） →
  • DMA 与缓存一致性DMA 搬运不占 CPU；带 D-Cache 的芯片上 DMA 写内存后必须 Invalidate，否则 CPU 读到旧值。10 · ADC 与 DMA →
  • NVIC 优先级抢占优先级决定能否嵌套，子优先级只决定同时挂起时的排队顺序；数值越小优先级越高。06 · 中断与 NVIC →
