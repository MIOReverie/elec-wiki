05 · 叠加定理 · 戴维南 · 最大功率 ​

核心 约 50 min戴维南定理是本章最值钱的工具，几乎每道综合大题的第一步都是它

结论先行 ​

  1. 叠加定理：线性电路中，各独立源单独作用之和 = 共同作用。不作用的电压源短路、电流源开路，受控源保留。
  2. 戴维南定理：含源线性二端网络 = UOCU_{OC}UOC​ 串 ReqR_{eq}Req​；诺顿 = ISCI_{SC}ISC​ 并 ReqR_{eq}Req​；UOC=ISCReqU_{OC} = I_{SC}R_{eq}UOC​=ISC​Req​。
  3. 最大功率传输：RL=ReqR_L = R_{eq}RL​=Req​ 时 Pmax=UOC24ReqP_{max} = \dfrac{U_{OC}^2}{4R_{eq}}Pmax​=4Req​UOC2​​，但效率只有 50%。
  4. 功率不能叠加（P∝I2P \propto I^2P∝I2），也不存在"频率相关"的等效 —— 戴维南等效是纯电阻的等效，仅对直流/单频正弦有效。
  5. 互易定理（补充）：线性电阻网络中，R12=R21R_{12}=R_{21}R12​=R21​（单端口等效电阻），常考判断题。

一、叠加定理：为什么成立 ​

线性电路的响应 = 各独立源单独作用的响应之和。

证明思路（了解即可）：若所有源同时乘以常数 kkk，全电路响应也乘 kkk（齐次性）；若源相加，响应相加（可加性）。这两个性质合起来就是叠加。

三个必要条件，缺一不可：

  1. 电路是线性的（所有元件满足齐次性 + 可加性）
  2. 只对独立源做分解
  3. 受控源永远保留（它不是独立源）

叠加定理的三步操作

① 保留一个独立源，其余独立源置零：
   电压源 → 短路（理想电压源 U=0 就是一根导线）
   电流源 → 开路（理想电流源 I=0 就是断路）
   ★ 受控源 → 原样保留，绝不置零
② 单独求目标响应（电流或电压）
③ 代数相加（注意方向：同向相加，反向相减）

最高频错误：把电压源置零时画成"去掉电源" —— 电压源短路就是短接一根线，不是断开！电流源开路才是断开。

功率为什么不能叠加：

P=UI,U=U1+U2,I=I1+I2P = UI,\quad U = U_1+U_2,\quad I=I_1+I_2 P=UI,U=U1​+U2​,I=I1​+I2​UI=(U1+I2)(I1+I2)=U1I1+U2I2⏟分开算+U1I2+U2I1⏟交叉项，漏掉了！UI = (U_1+I_2)(I_1+I_2) = \underbrace{U_1I_1 + U_2I_2}_{\text{分开算}} + \underbrace{U_1I_2+U_2I_1}_{\text{交叉项，漏掉了！}} UI=(U1​+I2​)(I1​+I2​)=分开算U1​I1​+U2​I2​​​+交叉项，漏掉了！U1​I2​+U2​I1​​​

所以：

P≠P1+P2\boxed{P \ne P_1+P_2} P=P1​+P2​​

正确做法：用叠加求出总电压或总电流，再算功率。

二、戴维南定理：三步法 ​

定理：任何线性二端网络（从外部看只有两个端子），对外部电路而言，等效于一个电压源 UOCU_{OC}UOC​ 串一个电阻 ReqR_{eq}Req​。

心智模型：戴维南是「切割 + 看网孔」，不是死记三步

  1. 切割：在端口 A、B 处把待求支路（负载）和网络 N 切开。N 对外部只剩 A、B 两个端点。
  2. A、B 的数值由网孔决定：UOCU_{OC}UOC​、ReqR_{eq}Req​ 不是凭空来的——它们取决于 N 内部那一个（或几个）网孔回路。所以求 UOCU_{OC}UOC​ 的实质是：先把切割回路的电流算出来，再用 KVL 把 A、B 两点间的电压写下来。
  3. 切割可以多次：N 内部若还复杂，就再切一刀，把 N 拆成几个子网络，各自先求等效，再拼回去（串则电压相加、电阻相加；并则电流相加、电阻并联）。

第 1 步：求 UOCU_{OC}UOC​（切一刀，算切割回路电流，KVL 写 U_AB） ​

断开负载，从端口 A、B 测量开路电压。对应心智模型第 2 步：这一步的本质是——把切割后剩下的回路电流先算出来，再用 KVL 把 A、B 两点间的电压表达出来（参见上面的「切割」图）。

三种方法（按可靠性排序）：

  1. 用 或 KVL 直接求
  2. 用叠加定理分源求（多个电源时更清晰）
  3. 用 先化简

注意：UOCU_{OC}UOC​ 一定与负载无关，只由网络内部决定。

第 2 步：求 ReqR_{eq}Req​ ​

方法 A（不含受控源）：把所有独立源置零 → 电压源短路、电流源开路 → 直接求端口 A、B 间的等效电阻。

方法 B（含受控源）：外加电源法

在端口 A、B 外加一个电压 UUU，求流入端口的电流 III：

Req=UIR_{eq} = \frac{U}{I} Req​=IU​

注意：外加的电压和流进来的电流，要用同一个参考方向（III 流入 A 端为正）。

方法 C（万能但要求开路/短路都存在）：

Req=UOCISCR_{eq} = \frac{U_{OC}}{I_{SC}} Req​=ISC​UOC​​

限制：如果端口开路时电流无界（ISC=∞I_{SC}=\inftyISC​=∞）或短路时电压无界，这个公式失效，必须回到方法 A/B。

第 3 步：接回负载 ​

I=UOCReq+RL,UL=RLReq+RLUOCI = \frac{U_{OC}}{R_{eq}+R_L},\qquad U_L = \frac{R_L}{R_{eq}+R_L}U_{OC} I=Req​+RL​UOC​​,UL​=Req​+RL​RL​​UOC​PL=RL(Req+RL)2UOC2P_L = \frac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2 PL​=(Req​+RL​)2RL​​UOC2​

诺顿定理与两者的关系 ​

诺顿：ISCI_{SC}ISC​ 并 ReqR_{eq}Req​。它和戴维南只是同一件事的两种画法：

ISC=UOCReqI_{SC} = \frac{U_{OC}}{R_{eq}} ISC​=Req​UOC​​

什么时候用戴维南、什么时候用诺顿

  • 端口串联其他电路 → 用戴维南（电压源串电阻）自然
  • 端口并联其他电路 → 用诺顿（电流源并电阻）自然
  • 求功率 → 戴维南更方便（PLP_LPL​ 公式简洁）

口诀：戴维南求串联，诺顿求并联。

三、含受控源时求 ReqR_{eq}Req​（难点） ​

外加电源法的标准流程 ​

以一个含电压控制电流源（VCCS）的电路为例：

  • 电路：一个 R1R_1R1​ 并联 VCCS（βV1\beta V_1βV1​），R2R_2R2​ 串联
  • 在端口外加电压 UUU，求 I=U/ReqI = U/R_{eq}I=U/Req​

步骤：

  1. 在端口加测试电压 UUU
  2. 用 或 KCL 求出 III（把受控源的控制量用测试电压表示）
  3. Req=U/IR_{eq} = U/IReq​=U/I

关键点：受控源在这一步必须保留，因为它对外等效电阻有贡献。

特殊情况：Req=0R_{eq} = 0Req​=0 或 Req=∞R_{eq} = \inftyReq​=∞ ​

  • 端口被理想电压源直接短路 → Req=0R_{eq}=0Req​=0
  • 端口被理想电流源直接开路 → Req=∞R_{eq}=\inftyReq​=∞
  • 负阻电路 → Req<0R_{eq} < 0Req​<0（如隧道二极管、有源滤波器）

ReqR_{eq}Req​ 可以是负数！

如果电路含受控源，ReqR_{eq}Req​ 可能是负值 —— 这在无源电路里不可能（电阻必为正）。这种情况出现在有源电路（放大器反馈网络、隧道二极管）中。

负阻的实际应用：负阻振荡器、隧道二极管放大器。

四、最大功率传输 ​

对 PL=RL(Req+RL)2UOC2P_L = \dfrac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2PL​=(Req​+RL​)2RL​​UOC2​ 求导，令导数为零：

dPLdRL=0  ⇒  RL=Req\frac{dP_L}{dR_L} = 0 \;\Rightarrow\; \boxed{R_L = R_{eq}} dRL​dPL​​=0⇒RL​=Req​​Pmax=UOC24Req\boxed{P_{max} = \frac{U_{OC}^2}{4R_{eq}}} Pmax​=4Req​UOC2​​​

效率：

η=PLP总=RLReq+RL\eta = \frac{P_L}{P_{总}} = \frac{R_L}{R_{eq}+R_L} η=P总​PL​​=Req​+RL​RL​​

当 RL=ReqR_L=R_{eq}RL​=Req​ 时，η=50%\eta = 50\%η=50%。

为什么电力系统不追求最大功率传输？

电力传输的成本主要是线损 I2RI^2RI2R。若 RLR_LRL​ 很小（短路电流大），线损 I2RI^2RI2R 会剧增。实际策略是让负载电流尽可能小，用升压-降压变压器把负载"匹配"到远小于线阻的高电阻状态 —— 此时效率高（η→1\eta \to 1η→1），代价是负载电压/电流偏离额定。

所以"最大功率匹配"用于低功率信号电路（功放、天线），"最大效率匹配"用于功率传输。

交流情形（共轭匹配）：在交流电路里，最大平均功率的条件不是 RL=ReqR_L=R_{eq}RL​=Req​，而是

ZL=Zeq∗（共轭）Z_L = Z_{eq}^* \quad\text{（共轭）} ZL​=Zeq∗​（共轭）

即 RL=ReqR_L = R_{eq}RL​=Req​ 且 XL=−XeqX_L = -X_{eq}XL​=−Xeq​（虚部相反）。详见 与交流篇。

五、互易定理（补充了解） ​

定理：在纯电阻网络中，若从端口 1 注入电流 III 在端口 2 产生电压 UUU，则从端口 2 注入同一电流 III 在端口 1 产生同样的 UUU。

R12=R21\boxed{R_{12} = R_{21}} R12​=R21​​

注意：

  • 只适用于纯电阻线性网络（不含受控源、不含电源）
  • "同一电流"很关键
  • 常出概念判断题

例 1+ · 多次切割：网络内部再切一刀

第二刀：N 内部还能再切——它本身就是「前级等效块」串「后级等效块」。每块本身已经是戴维南形：

易错点（按踩坑频率排序） ​

  1. 受控源不能置零！ 求 ReqR_{eq}Req​ 时受控源要保留，用外加电源法
  2. 电压源置零 = 短路（接一根线），电流源置零 = 开路（断开）—— 别搞反
  3. 功率不能叠加：P1+P2≠PP_1+P_2 \ne PP1​+P2​=P，要先用叠加求出总电流再算功率
  4. 叠加时每个独立源单独作用要画独立的电路图，别在一张图上改
  5. 戴维南等效只对端口外成立，求网络内部功率必须回到原电路
  6. 最大功率匹配时效率仅 50%，电力系统从不这样工作
  7. ReqR_{eq}Req​ 可能是负数（含受控源时）
  8. UOC/ISCU_{OC}/I_{SC}UOC​/ISC​ 法在 ISC=∞I_{SC}=\inftyISC​=∞ 或 UOC=∞U_{OC}=\inftyUOC​=∞ 时失效
  9. 互易定理只适用于纯电阻线性网络，不含受控源和电源
