19 · 继电接触器控制 ​

了解 约 25 min重点：自锁、互锁、保护环节；看懂主电路与控制电路两张图

结论先行 ​

  1. 控制电路的全部招式，本质只有一招：用触点去控制线圈，再用线圈去带动别的触点
  2. 自锁：把接触器自己的常开辅助触点并联在起动按钮两端 —— 松手后电流改走这条"捷径"，电机继续转
  3. 互锁：把对方的常闭辅助触点串联进自己的线圈回路 —— 从线路上杜绝两个接触器同时吸合（正反转的命门）
  4. 保护分工：熔断器管短路、热继电器管过载、接触器管失压/欠压 —— 三者不能互相替代
  5. 看电路图先分两半：主电路（大电流，决定电机转不转）和控制电路（小电流，决定主电路何时通）

熔断器和热继电器为什么必须同时存在

熔断器靠"电流大→迅速熔断"保护短路，但它有熔断误差，略过载时可能长期不动作；热继电器靠双金属片受热弯曲，动作慢（秒级），正好补上过载这一段。反过来，短路电流（几十倍额定）会在热继电器动作之前就把电机烧了，所以必须靠熔断器先切断。

一句话：熔断器管"突然的大电流"，热继电器管"慢慢变大的电流"。

基本环节一：自锁（长动控制） ​

如果只把按钮直接串在线圈回路里，那就是点动——手按着电机转，一松手就停。要"按一下就一直转"，必须让接触器自己把自己接上：

按下 SB2 ──→ KM 得电 ──→ 主触点闭合（电机转）
                          └→ 辅助常开闭合 ──┐
松开 SB2 ─────────────────────────────────┘（电流改走辅助触点，线圈继续得电）

关键在于这条并联的"捷径"：按钮只管"点火"，点火之后由 KM 自己的触点续上。按 SB1（停止）切断整条回路，KM 失电，辅助触点断开，"捷径"消失，下次起动还要重新按 SB2。

先看静态接线——自锁触点只跨接在起动按钮 SB2 两端：

画自锁的头号错误：把停止按钮也框进并联支路

自锁触点只能跨接在起动按钮 SB2 两端，绝不能在 SB2 靠电源侧取线、把 SB1 停止按钮一起并进去。一旦并联支路跨过了停止触点，按 SB1 时电流仍能从并联支路绕过去，KM 线圈不断电——停止失灵。判断口诀：停止按钮必须单独串在并联支路的上游，让所有电流都先过它这一关。

为什么「松开按钮还继续转」这件事值得专门看一眼

新手最常见的困惑是：按钮都松开了，电路凭什么还通？答案就在这张时序图上——KM 线圈的导通条件在 t=2s 那一刻发生了转移：从"SB2 闭合"变成了"KM 自己的常开触点闭合"。条件是同一个（回路闭合），只是提供这个条件的东西换了。

工程上这条捷径也带来一个性质：掉电后不会自起动。停电时 KM 失电、自锁解除；复电后必须重新按 SB2，电机才会转。这叫"失压保护"，是接触器控制相对闸刀开关的一大优势。

基本环节二：互锁（正反转） ​

要让电机反转，办法是对调两根火线。于是用两个接触器：KM1 直接送电（正转），KM2 交叉送电（反转）。问题是——如果两个接触器同时吸合，两相火线会通过它们的主触点直接短接，相间短路。

互锁就是把对方线圈回路的"门"锁上：

KM1 线圈回路：… — KM2 常闭 — KM1 线圈
KM2 线圈回路：… — KM1 常闭 — KM2 线圈

KM1 一吸合，它的常闭辅助触点就断开，于是 KM2 的回路必然断开——即使有人误按了反转按钮也没用。

正转直接按反转按钮会怎样

什么都不会发生——KM2 的回路被 KM1 的常闭互锁触点断着。必须先按停止，再按反转。现场如果要求"直接切换"，那就要在程序/电路里加"先停后动"的时序（用 PLC 做很轻松，第 20 章 · PLC 与梯形图会看到）。

有的电路还额外加按钮互锁（把对方的常闭按钮串进自己回路）和机械互锁（两接触器滑块互相挡住），构成双重甚至三重保险。考试里只要求画出电气互锁那一对常闭触点。

多地控制是最容易被做反的一个：起动并联（任一地点都能起动）、停止串联（任一地点都能停止）。写成逻辑式就是 (SBA∨SBB)⋅(SBC∧SBD)(SB_A \lor SB_B)\cdot(SB_C \land SB_D)(SBA​∨SBB​)⋅(SBC​∧SBD​)。

看图方法（四步） ​

  1. 先看主电路：从左到右，电源 → QS → FU → KM 主触点 → FR 热元件 → 电机。粗线、大电流。
  2. 再看控制电路：从上到下，控制电源 → 保护元件 → 按钮/触点组合 → 线圈。细线、小电流。
  3. 同一字母 = 同一电器：KM 的线圈、主触点、辅助触点虽然画在不同位置，动作是同时的。
  4. 触点画的是常态：图上所有触点都是"线圈未得电"时的状态。分析之前要先判断：通电后哪些线圈会得电？得电后哪些触点会动作？

例题 ​

例 1 · 电器选型

一台 4 kW、380 V 三相异步电动机，cos⁡φ=0.85\cos\varphi = 0.85cosφ=0.85、η=0.87\eta = 0.87η=0.87，直接起动。选择熔断器、热继电器、接触器的规格。

  • 热继电器：整定值按 INI_NIN​ 取 → 选 8~10 A 可调规格，调到 8.2 A 附近
  • 接触器：主触点额定电流 ≥ INI_NIN​ → 选 10 A 或 16 A 等级（留裕量），线圈电压与控制电源一致（220 V 或 380 V）

例 2 · 电路分析：少了自锁会怎样

下图是一个"三相异步电动机直接起动控制电路"，但运行人员反映：电动机只能点动，一松手就停。电路其它部分完好，故障在哪？

控制回路：L — FU — FR常闭 — SB1(停止) — SB2(起动) — KM线圈 — N

解：对照起保停的标准结构，缺少的是与 SB2 并联的那对 KM 常开辅助触点（自锁触点）。

没有它，线圈得电的唯一条件就是"SB2 被按着"；手一松，回路立即断开，KM 失电、主触点分开，电机停转——表现正是点动。

排查方法：看图纸上起动按钮两端有没有并联一个标着 KM 的常开触点；实物上看 KM 的辅助触点端子（13-14 号）有没有接线。修复后松手能保持运行，即可确认。

例 3 · 电路分析：正反转互锁

一台机床要求主轴能正反转。图纸上 KM1、KM2 各自线圈回路都完整，但没有互锁触点。运行一段时间后发生了相间短路。解释原因，并说明至少两种补救措施。

解：原因——操作人员先按了正转（KM1 吸合），未按停止就直接按了反转。此时 KM2 的线圈回路是通的，KM2 也吸合；两组主触点同时闭合，L1、L2 两相火线通过 KM1、KM2 的主触点形成低阻通路 → 相间短路，熔断器熔断（如果选得合适）或烧毁触点。

补救（按可靠性排序）：

  1. 电气互锁（必须）：把 KM1 的常闭辅助触点串进 KM2 线圈回路，KM2 的常闭串进 KM1 回路。此后 KM1 吸合时 KM2 回路必然断开，误按反转按钮也不会动作。
  2. 按钮互锁（推荐）：用带常闭触点的复合按钮，把反转按钮的常闭触点串进正转回路。按下反转时先断开正转，再接通反转。
  3. 机械互锁（辅助）：两个接触器安装连锁机构，一个吸合时物理挡住另一个的衔铁。

顺带一个设计细节：互锁用的是接触器的常闭辅助触点，不是主触点——主触点粗、电流大，但它吸合时也是闭合的，起不到"互锁"作用。

例 4 · 行程开关自动往复

工作台由电机驱动，要求在 A、B 两点之间自动往返。说明需要哪些电器、怎么接线。

解：需要的器件：两个接触器（KM1 前进、KM2 返回）、两个行程开关（SQ_A 装在 A 点、SQ_B 装在 B 点）、起动按钮 SB2、停止按钮 SB1。

接线思路（这是"行程控制 + 自锁"的组合）：

  • 正转（前进）支路：SB2 起动 → KM1 自锁 → SQ_B 常闭 → KM1 线圈
  • 反转（返回）支路：KM1 的常开触点（或 SQ_A 的常开）起动 → KM2 自锁 → SQ_A 常闭 → KM2 线圈

工作过程：按 SB2，KM1 得电，工作台前进；到 B 点撞下 SQ_B，其常闭断开 → KM1 失电停车，同时 SQ_B 常开闭合 → KM2 得电，工作台返回；到 A 点撞下 SQ_A → KM2 失电、KM1 得电，如此往复。按 SB1 停车。

注意 SQ_A、SQ_B 的接线方向：每一个行程开关都要"到位时切断当前方向的接触器、接通反方向的接触器"，接反了就会一直朝一个方向跑到底。

工程实例：一台机床的控制柜里有什么 ​

以最常见的 CA6140 车床为例，打开电气柜你会看到：

  • 进线：三相四线（三根火线 + 一根零线）经刀开关或断路器引入
  • 主电路：断路器 → 两个接触器（主轴正反转）→ 热继电器 → 主轴电机；另一路给冷却泵电机（顺序控制：主轴转了才允许开冷却泵）
  • 控制电路：取两根线作 220 V 控制电源（一根火线 + 一根零线，或两根火线之间取 380 V），往下是熔断器 → 热继电器常闭 → 各按钮与接触器触点 → 各线圈
  • 指示灯：电源、运行、故障三色指示——控制电路本身也能驱动指示灯，这就是"用小电流控制大电流"思想的延伸

现场排故的第一反应应该是：先看接触器有没有吸合（听声音、看指示），没吸合就往控制回路查（熔断器、热继电器是否动作、按钮触点是否接触不良），吸合了但电机不转就往主回路查（主触点烧蚀、电机断相）。

易错清单 ​

  • 触点画的是常态，不是当前状态。分析前先判断哪些线圈会得电
  • 自锁触点与起动按钮并联，互锁触点串在对方线圈回路里——"并联/串联"两个字是考点
  • 正反转必须互锁，否则相间短路
  • 热继电器用常闭触点串在线圈回路里；动作后要手动复位
  • 熔断器不能当过载保护用，热继电器不能当短路保护用
  • 同一接触器的线圈、主触点、辅助触点动作是同时的，但画在图的不同位置
  • 多地控制：起动并联、停止串联
  • 选型用额定电流（PN/3UNcos⁡φηP_N/\sqrt3 U_N\cos\varphi\etaPN​/3​UN​cosφη），不要用功率粗除电压
