12 · 三相电路 ​

核心 约 40 min这是电工学里最像『工程』的一章：所有结论都能从单相知识推出来，但必须先分清『线』和『相』

结论先行 ​

  1. 对称三相电源：幅值相同、频率相同、相位互差 120°，且 ∑U˙=0\sum \dot U = 0∑U˙=0
  2. Y 接：Ul=3 UpU_l = \sqrt3\,U_pUl​=3​Up​，Il=IpI_l = I_pIl​=Ip​，U˙AB\dot U_{AB}U˙AB​ 超前 U˙A\dot U_AU˙A​ 30°
  3. △ 接：Ul=UpU_l = U_pUl​=Up​，Il=3 IpI_l = \sqrt3\,I_pIl​=3​Ip​
  4. 对称三相电路 → 归结为一相计算，其余两相把相位旋转 ∓120° 即可
  5. 中性线的作用是把中性点钉死在 0 电位；断开 + 负载不对称 → 中性点位移 → 轻载相电压飙升
  6. 我国工频：相电压 220 V、线电压 380 V（380=3×220380 = \sqrt3\times220380=3​×220）

本章唯一要背的口诀

「Y 起压，△ 起流」 —— Y 接时是电压相差 3\sqrt33​ 倍，△ 接时是电流相差 3\sqrt33​ 倍，另一个量两种接法下相等。

一、为什么用三相，而不是单相 ​

三个理由，一个比一个硬：

  1. 瞬时功率恒定。单相电路的 p(t)p(t)p(t) 以两倍频率脉动（），电机会抖；三相合成后 p=32UpIpcos⁡φp = \dfrac32U_pI_p\cos\varphip=23​Up​Ip​cosφ 是一条平线。
  2. 旋转磁场。三个空间上互差 120° 的绕组通入互差 120° 的电流，自然产生旋转磁场 —— 这是所有交流电机的地基。
  3. 省铜。同样输送功率、同样损耗，三相比单相省 25% 的导线。

二、三相电源与线/相电压 ​

三相发电机的三个绕组（A-X、B-Y、C-Z）在空间上互差 120°，产生

uA=Umsin⁡ωt,uB=Umsin⁡(ωt−120∘),uC=Umsin⁡(ωt+120∘)u_A = U_m\sin\omega t,\qquad u_B = U_m\sin(\omega t-120^\circ),\qquad u_C = U_m\sin(\omega t+120^\circ) uA​=Um​sinωt,uB​=Um​sin(ωt−120∘),uC​=Um​sin(ωt+120∘)

任一时刻 uA+uB+uC=0u_A+u_B+u_C = 0uA​+uB​+uC​=0 —— 所以三根火线就能构成回路，不需要回线。

Y 接：3\sqrt33​ 和 30° 是怎么来的 ​

电源 Y 接时，三个绕组的末端 X、Y、Z 接在一起成为中性点 N，首端 A、B、C 引出：

  • 相电压 U˙A、U˙B、U˙C\dot U_A、\dot U_B、\dot U_CU˙A​、U˙B​、U˙C​：首端到中性点，有效值 Up=220U_p = 220Up​=220 V
  • 线电压 U˙AB、U˙BC、U˙CA\dot U_{AB}、\dot U_{BC}、\dot U_{CA}U˙AB​、U˙BC​、U˙CA​：两根火线之间，Ul=380U_l = 380Ul​=380 V

用 KVL 直接推 U˙AB=U˙A−U˙B\dot U_{AB} = \dot U_A - \dot U_BU˙AB​=U˙A​−U˙B​：

U˙AB=Up∠0∘−Up∠(−120∘)=Up[(1+0.5)+j 0.866]=3 Up∠30∘\dot U_{AB} = U_p\angle 0^\circ - U_p\angle(-120^\circ) = U_p\big[(1+0.5) + j\,0.866\big] = \sqrt3\,U_p\angle 30^\circ U˙AB​=Up​∠0∘−Up​∠(−120∘)=Up​[(1+0.5)+j0.866]=3​Up​∠30∘

两个结论一次到手：幅值 3\sqrt33​ 倍，相位超前 30°。B-C、C-A 同理（超前 30°，依次滞后 120°）。

最容易丢分的地方

3\sqrt33​ 关系只对 Y 接的电源成立。负载 Y 接时，如果中性线完好，负载相电压仍是 220 V；一旦中性线断开且负载不对称，负载相电压就不再是 220 V 了（见第五节）。

△ 接 ​

三个绕组首尾相接成三角形：Ul=UpU_l = U_pUl​=Up​（线电压就是相电压）。但线电流是相邻两个相电流之差：

I˙A=I˙AB−I˙CA=3 Ip∠(−30∘)\dot I_A = \dot I_{AB} - \dot I_{CA} = \sqrt3\,I_p\angle(-30^\circ) I˙A​=I˙AB​−I˙CA​=3​Ip​∠(−30∘)

即 Il=3 IpI_l = \sqrt3\,I_pIl​=3​Ip​，线电流滞后对应相电流 30°。

三、对称三相负载 → 归结为一相 ​

心智模型：一相计算法 —— 对称三相 → 只算一相，其余旋转 ±120°

这是一种「降维」技巧，不是新规律。为什么成立？对称负载下 U˙A、U˙B、U˙C\dot U_A、\dot U_B、\dot U_CU˙A​、U˙B​、U˙C​ 只是同一组量旋转 120° 的结果，而电路对三相完全对称（旋转对称性）——B、C 的一切结论都能从 A 相「转」出来，不必重算。 操作顺序不能颠倒：判断接法 → 定相电压 → 只算 A 相 → 把 A 相相量旋转 ∓120° 得 B、C → 最后才用线量关系（Il=IpI_l=I_pIl​=Ip​ 或 3Ip\sqrt3I_p3​Ip​）。一上来就找「线电流怎么算」，最容易把自己绕晕。

这是本章最实用的工具。条件：负载对称 + 有中性线（或三线制对称），此时中性点电位为 0，三相彼此独立：

① 取出 A 相，按单相交流电路算（Z、I、P 全会）
② B 相：把 A 相的所有相量旋转 −120°
③ C 相：把 A 相的所有相量旋转 +120°
④ 中性线电流 I_N = I_A + I_B + I_C = 0

为什么能这样算？ 因为 U˙A、U˙B、U˙C\dot U_A、\dot U_B、\dot U_CU˙A​、U˙B​、U˙C​ 只是同一组量旋转 120° 的结果，而电路对三相完全对称 —— 数学上叫"旋转对称性"，工程上叫"一相计算法"。

四、中性点位移：三相版的分压器 ​

还记得单相的分压器吗？负载一变，分点电位就漂。三相 Y 接负载在中性线断开时，就是三组分压器共用同一个分点：U˙N′N=U˙AZA+U˙BZB+U˙CZC1ZA+1ZB+1ZCU˙A′=U˙A−U˙N′N （B、C 同理）\dot U_{N'N} = \frac{\dfrac{\dot U_A}{Z_A}+\dfrac{\dot U_B}{Z_B}+\dfrac{\dot U_C}{Z_C}}{\dfrac{1}{Z_A}+\dfrac{1}{Z_B}+\dfrac{1}{Z_C}} \qquad \dot U'_{A} = \dot U_A - \dot U_{N'N}\ \text{（B、C 同理）} U˙N′N​=ZA​1​+ZB​1​+ZC​1​ZA​U˙A​​+ZB​U˙B​​+ZC​U˙C​​​U˙A′​=U˙A​−U˙N′N​ （B、C 同理）

物理图像：ZCZ_CZC​ 越小（负载越重），中性点 N′N'N′ 被 CCC 相"吸"得越靠近 CCC 电源端，于是 CCC 相电压越低、另两相被抬得越高。

例 1 · Y 接对称负载（一相计算法）

三相四线制，线电压 380 V。每相负载 Z=8+j6 ΩZ = 8+j6\,\OmegaZ=8+j6Ω（感性）。求相电流、线电流、中性线电流和总有功功率。

解

Y 接 + 有中性线 → 负载相电压 = 电源相电压 = 380/3=220380/\sqrt3 = 220380/3​=220 V。

第一步：只算 A 相。

第二步：推另外两相。 阻抗角不变，只是电源相量旋转：

I˙B=22∠(−156.9∘) A,I˙C=22∠83.1∘ A\dot I_B = 22\angle(-156.9^\circ)\ \text{A},\qquad \dot I_C = 22\angle 83.1^\circ\ \text{A} I˙B​=22∠(−156.9∘) A,I˙C​=22∠83.1∘ A

第三步：Y 接 Il=IpI_l = I_pIl​=Ip​。

Il=Ip=22 AI_l = I_p = 22\ \text{A} Il​=Ip​=22 A

第四步：中性线电流。 三个相电流大小相等、相位互差 120° → 相量和为零：

I˙N=I˙A+I˙B+I˙C=0\dot I_N = \dot I_A+\dot I_B+\dot I_C = 0 I˙N​=I˙A​+I˙B​+I˙C​=0

P=3 UlIlcos⁡φ=3×380×22×0.8=11.58 kWP = \sqrt3\,U_lI_l\cos\varphi = \sqrt3\times380\times22\times0.8 = 11.58\ \text{kW} P=3​Ul​Il​cosφ=3​×380×22×0.8=11.58 kW

本题的思路含量

一相计算法的顺序不能颠倒：先判断接法 → 定相电压 → 算一相 → 旋转推其余 → 最后才用线量关系。很多人一上来就找"线电流怎么算"，反而把自己绕晕。

例 2 · 同一负载改成 △ 接（功率差 3 倍）

把例 1 的负载 Z=8+j6 ΩZ = 8+j6\,\OmegaZ=8+j6Ω 改接成 △，仍接 380 V 线电压。求相电流、线电流、总功率。

解

△ 接时负载相电压 = 线电压 = 380 V（这是关键的第一步判断）。

相电流：

Ip=38010=38 AI_p = \frac{380}{10} = 38\ \text{A} Ip​=10380​=38 A

线电流（Il=3IpI_l = \sqrt3 I_pIl​=3​Ip​，且滞后相电流 30°）：

Il=3×38=65.8 AI_l = \sqrt3\times38 = 65.8\ \text{A} Il​=3​×38=65.8 A

功率：

P=3×380×65.8×0.8=34.7 kWP = \sqrt3\times380\times65.8\times0.8 = 34.7\ \text{kW} P=3​×380×65.8×0.8=34.7 kW

对比：同一个阻抗，△ 接的功率是 Y 接的 3 倍（34.7/11.58=334.7 / 11.58 = 334.7/11.58=3）。

为什么正好是 3 倍？ 两步叠加：相电压涨了 3\sqrt33​ 倍 → 相电流涨 3\sqrt33​ 倍；同时线电流又多一个 3\sqrt33​ 倍。而 P∝UpIpP \propto U_p I_pP∝Up​Ip​，于是 3×3=3\sqrt3\times\sqrt3 = 33​×3​=3。

记住这个结论，第 17 章 · 机械特性 · 起动 · 调速直接用

正常 △ 接运行的电机，启动时改接成 Y，启动电流和启动转矩都降到 1/3。 这就是 Y-△ 降压启动的全部依据。

例 3 · 断中性线 + 不对称负载（中性点位移实算）

三相四线制给三盏白炽灯供电：A、B 相各 220 V/100 W，C 相 220 V/40 W。中性线断开后，各灯电压变成多少？哪盏灯危险？

解

第一步：把灯变成电阻。

第二步：用中性点位移公式。 三相对称电源相量（有效值 220 V）代入：

U˙N′N=U˙A484+U˙B484+U˙C12101484+1484+11210\dot U_{N'N} = \frac{\dfrac{\dot U_A}{484}+\dfrac{\dot U_B}{484}+\dfrac{\dot U_C}{1210}}{\dfrac{1}{484}+\dfrac{1}{484}+\dfrac{1}{1210}} U˙N′N​=4841​+4841​+12101​484U˙A​​+484U˙B​​+1210U˙C​​​

分子、分母都是复数相量和。算出来（取 U˙A=220∠0∘\dot U_A = 220\angle0^\circU˙A​=220∠0∘）：

∣U˙N′N∣=55 V|\dot U_{N'N}| = 55\ \text{V} ∣U˙N′N​∣=55 V

第三步：各相负载电压 = 电源相电压 − 中性点位移。

例 4 · 中性线电流：什么时候不为零

本例 I˙B\dot I_BI˙B​ 与 I˙C\dot I_CI˙C​ 的虚部正好抵消，剩下与 I˙A\dot I_AI˙A​ 同相的 11 A。

  • 负载对称（三相阻抗完全相同）→ I˙N=0\dot I_N = 0I˙N​=0，可以省掉中性线（三相三线制）

"对称可省线，不对称必须留"。注意"对称"指三相阻抗完全相同（大小和阻抗角都要一样），不是"功率相同"。

工程实例 ​

为什么家里是 220 V，工厂动力是 380 V？ 都是从同一套 Y 接系统引出来的：火线到中性点 220 V（相电压）供照明和家用电器；两根火线之间 380 V（线电压）接三相电机。三相电机内部是三相绕组，本来就需要三相电源；而单相设备取一根火线加中性线即可 —— 一套系统，两种用法。

中性线为什么不能断？ 居民楼是典型的不对称负载（各家电器不同时开）。物业检修时若误断中性线，轻载的那几户电压飙升，电视机、空调率先烧毁。因此规范要求中性线截面不小于火线，且不得加开关/熔断器。

易错清单 ​

  1. 3\sqrt33​ 只对 Y 接成立，△ 接是 Ul=UpU_l = U_pUl​=Up​；搞反接法是本章第一大错
  2. Y 接的 30° 是"线电压超前相电压"，△ 接是"线电流滞后相电流 30°"—— 一个在电压侧，一个在电流侧，别记混
  3. 相量运算不能直接用有效值相加：U˙AB=U˙A−U˙B\dot U_{AB} = \dot U_A - \dot U_BU˙AB​=U˙A​−U˙B​ 是相量差，不是 220−220220-220220−220
  4. 一相计算法的前提是"对称 + 中性点不位移"；不对称三线制必须先算中性点位移
  5. 中性线电流是相量和，三个 10 A 的相电流其中线电流可能是 0，也可能是 17 A
  6. 铭牌上的 380 V / 220 V 是线电压，电机内部每相承受的是 220 V（Y 接时）
