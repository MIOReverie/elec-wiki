13 · 三相功率与测量 ​

核心 约 25 min一个公式 + 一种测量方法就够用了，但两者的细节都容易丢分

结论先行 ​

  1. 对称三相总有功功率：P=3UpIpcos⁡φ=3 UlIlcos⁡φP = 3U_pI_p\cos\varphi = \sqrt3\,U_lI_l\cos\varphiP=3Up​Ip​cosφ=3​Ul​Il​cosφ —— Y 接和 △ 接形式完全相同
  2. 公式里的 φ\varphiφ 是相电压与相电流的相位差，不是线电压与线电流的
  3. Q=3 UlIlsin⁡φQ = \sqrt3\,U_lI_l\sin\varphiQ=3​Ul​Il​sinφ，S=3 UlIlS = \sqrt3\,U_lI_lS=3​Ul​Il​，且 S2=P2+Q2S^2 = P^2+Q^2S2=P2+Q2
  4. 测量：两表法（三线制，最常用）、三表法（四线制）
  5. 两表读数是代数和；cos⁡φ<0.5\cos\varphi < 0.5cosφ<0.5 时有一表读数为负
  6. 由两表读数可反推 tan⁡φ=3WC−WAWA+WC\tan\varphi = \sqrt3\dfrac{W_C-W_A}{W_A+W_C}tanφ=3​WA​+WC​WC​−WA​​（大减小）

一、从瞬时功率出发：为什么是 32\dfrac3223​ ​

单相时 p(t)=u(t)i(t)p(t) = u(t)i(t)p(t)=u(t)i(t) 以两倍频率脉动，平均值 P=UIcos⁡φP = UI\cos\varphiP=UIcosφ。三相则完全不同 —— 第 12 章 · 三相电路那张图已经看过：三个错开 120° 的脉动功率相加，脉动正好抵消：p(t)=pA+pB+pC=32 UpIpcos⁡φ=常量p(t) = p_A+p_B+p_C = \frac32\,U_pI_p\cos\varphi = \text{常量} p(t)=pA​+pB​+pC​=23​Up​Ip​cosφ=常量

平均功率 = 瞬时功率（因为已经不脉动了）：

P=32 UpIpcos⁡φP = \frac32\,U_pI_p\cos\varphi P=23​Up​Ip​cosφ

这里 UpU_pUp​、IpI_pIp​ 是幅值（峰值）。换成有效值（U=Um/2U = U_m/\sqrt2U=Um​/2​、I=Im/2I = I_m/\sqrt2I=Im​/2​）：

P=3UpIpcos⁡φ\boxed{P = 3U_pI_p\cos\varphi} P=3Up​Ip​cosφ​

32\dfrac3223​ 这个因数的来历

32UmImcos⁡φ=32(2U)(2I)cos⁡φ=3UIcos⁡φ\dfrac32 U_mI_m\cos\varphi = \dfrac32(\sqrt2 U)(\sqrt2 I)\cos\varphi = 3UI\cos\varphi23​Um​Im​cosφ=23​(2​U)(2​I)cosφ=3UIcosφ。 记不住就用"三相各贡献一份，共 3 份"来记 —— 但要知道 32\dfrac3223​ 的存在意味着三相机器的利用率比单相高，这是三相省铜的数学根源。

二、统一成线电压线电流 ​

Y 接：Up=Ul/3U_p = U_l/\sqrt3Up​=Ul​/3​，Ip=IlI_p = I_lIp​=Il​ → P=3⋅Ul3⋅Ilcos⁡φ=3 UlIlcos⁡φP = 3\cdot\dfrac{U_l}{\sqrt3}\cdot I_l\cos\varphi = \sqrt3\,U_lI_l\cos\varphiP=3⋅3​Ul​​⋅Il​cosφ=3​Ul​Il​cosφ

△ 接：Up=UlU_p = U_lUp​=Ul​，Ip=Il/3I_p = I_l/\sqrt3Ip​=Il​/3​ → P=3⋅Ul⋅Il3cos⁡φ=3 UlIlcos⁡φP = 3\cdot U_l\cdot\dfrac{I_l}{\sqrt3}\cos\varphi = \sqrt3\,U_lI_l\cos\varphiP=3⋅Ul​⋅3​Il​​cosφ=3​Ul​Il​cosφ

两种接法殊途同归 —— 这就是公式统一的原因。无功和视在功率同理：

Q=3UpIpsin⁡φ=3 UlIlsin⁡φ,S=3UpIp=3 UlIlQ = 3U_pI_p\sin\varphi = \sqrt3\,U_lI_l\sin\varphi,\qquad S = 3U_pI_p = \sqrt3\,U_lI_l Q=3Up​Ip​sinφ=3​Ul​Il​sinφ,S=3Up​Ip​=3​Ul​Il​

规律层：为什么两种接法公式一模一样

Y 接把电压除 3\sqrt33​、电流不变；△ 接把电流除 3\sqrt33​、电压不变——一个乘在电压上、一个乘在电流上，3⋅133\cdot\dfrac{1}{\sqrt3}3⋅3​1​ 殊途同归都化成 3\sqrt33​。所以记一个公式 P=3 UlIlcos⁡φP=\sqrt3\,U_lI_l\cos\varphiP=3​Ul​Il​cosφ 就够，接法只影响你「求相量」那一步。

两个「φ」别搞混

  • 公式里的 φ\varphiφ = 相电压与相电流的相位差 = 每相负载的阻抗角
  • 线电压与线电流之间还隔着 30°（Y 接）或 −30°（△ 接）

所以"线电压与线电流的夹角"不是 φ\varphiφ。只有 Y 接且负载对称时，两者数值才恰好相等（因为 30° 的偏移在相量图上是固定的，而 φ\varphiφ 是负载的阻抗角 —— 严格说它们本来就不是一回事）。

三、两表法（二瓦计法） ​

适用场合：三相三线制（没有中性线），对称或不对称负载都行。

接法：两个功率表的电流线圈分别串入 A、C 两根火线，两个电压线圈的另一端都接第三条火线 B。

  • WAW_AWA​：测 UABU_{AB}UAB​ 与 IAI_AIA​ → WA=UlIlcos⁡(φ+30∘)W_A = U_lI_l\cos(\varphi+30^\circ)WA​=Ul​Il​cos(φ+30∘)
  • WCW_CWC​：测 UCBU_{CB}UCB​ 与 ICI_CIC​ → WC=UlIlcos⁡(φ−30∘)W_C = U_lI_l\cos(\varphi-30^\circ)WC​=Ul​Il​cos(φ−30∘)
  • 总功率：P=WA+WCP = W_A + W_CP=WA​+WC​（代数和）

心智模型：两表法 —— 两根火线 + 一块「隐含」的第三线

这是一种新的测量思路：三线制只有三根火线、没有中性线，却只用两块表。第三根火线不必测——它的电流由 KCL 决定（I˙B=−(I˙A+I˙C)\dot I_B = -(\dot I_A+\dot I_C)I˙B​=−(I˙A​+I˙C​)），所以两表读数就携带了全部三相的功率信息。 操作规则：总功率取两表代数和 P=WA+WCP = W_A + W_CP=WA​+WC​；反推功率因数用 tan⁡φ=3WC−WAWA+WC\tan\varphi = \sqrt3\dfrac{W_C-W_A}{W_A+W_C}tanφ=3​WA​+WC​WC​−WA​​（大减小）。cos⁡φ<0.5\cos\varphi<0.5cosφ<0.5 时 WAW_AWA​ 会翻负——不是表坏，把它的电流线圈反接后按负值代入即可。

加起来为什么正好是 3cos⁡φ\sqrt3\cos\varphi3​cosφ ​

WA+WC=UlIl[cos⁡(φ+30∘)+cos⁡(φ−30∘)]=UlIl⋅2cos⁡30∘cos⁡φ=3 UlIlcos⁡φ✓W_A+W_C = U_lI_l\big[\cos(\varphi+30^\circ)+\cos(\varphi-30^\circ)\big] = U_lI_l\cdot2\cos30^\circ\cos\varphi = \sqrt3\,U_lI_l\cos\varphi ✓ WA​+WC​=Ul​Il​[cos(φ+30∘)+cos(φ−30∘)]=Ul​Il​⋅2cos30∘cosφ=3​Ul​Il​cosφ✓

一只表为什么会反偏 ​

从图上看得很清楚：WA=cos⁡(φ+30∘)W_A = \cos(\varphi+30^\circ)WA​=cos(φ+30∘) 在 φ=60∘\varphi = 60^\circφ=60∘ 时过零，之后变负；而 WC=cos⁡(φ−30∘)W_C = \cos(\varphi-30^\circ)WC​=cos(φ−30∘) 一直到 φ=120∘\varphi = 120^\circφ=120∘ 才过零（常规负载到不了）。

读到负值怎么办

不是表坏了，也不是接错了。 负载功率因数很低（cos⁡φ<0.5\cos\varphi < 0.5cosφ<0.5，例如空载变压器、轻载电机）时必然出现。处理办法：把那只表的电流线圈两个端钮对调（或扳到极性开关），读数记为负值代入 P=WA+WCP = W_A+W_CP=WA​+WC​。

反推功率因数 ​

tan⁡φ=3 WC−WAWA+WC\tan\varphi = \sqrt3\,\frac{W_C-W_A}{W_A+W_C} tanφ=3​WA​+WC​WC​−WA​​

（用大的减小的，保证结果为正；分母是两表代数和。）

四、三表法 ​

适用场合：三相四线制（有中性线），尤其负载不对称时 —— 每相接一个功率表：

P=WA+WB+WCP = W_A+W_B+W_C P=WA​+WB​+WC​

两表法 vs 三表法的分界线

两表法三表法
接线三线制（无中性线）四线制（有中性线）
表数23
不对称负载可以可以
四线制不对称不行必须用

原因：四线制有中性线电流 INI_NIN​，两表法只测了两根火线的电流，INI_NIN​ 那条路的功率漏掉了。

例题 ​

例 1 · 读铭牌（最常见的题型）

一台三相异步电动机铭牌：PN=5.5P_N = 5.5PN​=5.5 kW、UN=380U_N = 380UN​=380 V、IN=11.6I_N = 11.6IN​=11.6 A、nN=1440n_N = 1440nN​=1440 r/min、cos⁡φN=0.84\cos\varphi_N = 0.84cosφN​=0.84。求额定输入功率和效率。

解

输入功率（注意用线电压线电流）：

P1N=3 UNINcos⁡φN=3×380×11.6×0.84=6.41 kWP_{1N} = \sqrt3\,U_NI_N\cos\varphi_N = \sqrt3\times380\times11.6\times0.84 = 6.41\ \text{kW} P1N​=3​UN​IN​cosφN​=3​×380×11.6×0.84=6.41 kW

效率（铭牌功率是轴上输出机械功率）：

ηN=PNP1N=5.56.41=85.8%\eta_N = \frac{P_N}{P_{1N}} = \frac{5.5}{6.41} = 85.8\% ηN​=P1N​PN​​=6.415.5​=85.8%

与铭牌标注一致 ✓（这验证了公式用对了）。

顺带：n0=60f/p=60×50/2=1500n_0 = 60f/p = 60\times50/2 = 1500n0​=60f/p=60×50/2=1500 r/min（p=2p=2p=2 由 1440 推断），转差率 s=(1500−1440)/1500=0.04s = (1500-1440)/1500 = 0.04s=(1500−1440)/1500=0.04。

本题的陷阱

铭牌上的 PNP_NPN​ 是输出机械功率，UNU_NUN​、INI_NIN​ 是线电压线电流。三件事必须同时用对：公式才不会错。若误把 5.5 kW 当输入功率去求 cos⁡φ\cos\varphicosφ，会算出 0.72 —— 与铭牌 0.84 差一大截。

例 2 · 两表法读数求总功率与功率因数

三相三线制，两表读数 WA=1200W_A = 1200WA​=1200 W、WC=600W_C = 600WC​=600 W。求总有功功率、无功功率和功率因数。

解

总有功功率（代数和，这里两表都正，直接加）：

P=WA+WC=1800 WP = W_A+W_C = 1800\ \text{W} P=WA​+WC​=1800 W

功率因数：

tan⁡φ=3 WC−WAP=3×6001800=0.577\tan\varphi = \sqrt3\,\frac{W_C-W_A}{P} = \sqrt3\times\frac{600}{1800} = 0.577 tanφ=3​PWC​−WA​​=3​×1800600​=0.577φ=30∘,cos⁡φ=0.866\varphi = 30^\circ,\qquad \cos\varphi = 0.866 φ=30∘,cosφ=0.866

Q=Ptan⁡φ=1800×0.577=1039 varQ = P\tan\varphi = 1800\times0.577 = 1039\ \text{var} Q=Ptanφ=1800×0.577=1039 var

验算（用 S2=P2+Q2S^2 = P^2+Q^2S2=P2+Q2）：S=18002+10392=2078S = \sqrt{1800^2+1039^2} = 2078S=18002+10392​=2078 VA，3UlIl\sqrt3U_lI_l3​Ul​Il​ 若成立需 UlIl=1200U_lI_l = 1200Ul​Il​=1200 ✓（2078/3=12002078/\sqrt3 = 12002078/3​=1200）

两表读数的信息量

两表读数不仅给出 PPP，还能定出 cos⁡φ\cos\varphicosφ —— 所以现场没有功率因数表时，接两块功率表就够用了。WA=WCW_A = W_CWA​=WC​ 时 φ=0\varphi = 0φ=0（纯阻）；WA=0W_A = 0WA​=0 时 φ=60∘\varphi = 60^\circφ=60∘（cos⁡φ=0.5\cos\varphi = 0.5cosφ=0.5）。

例 3 · 一表翻负（低功率因数负载）

同一电路，负载变成 cos⁡φ=0.4\cos\varphi = 0.4cosφ=0.4。设 UlIl=1000U_lI_l = 1000Ul​Il​=1000 VA，求两表读数。

φ=arccos⁡0.4=66.4∘\varphi = \arccos 0.4 = 66.4^\circφ=arccos0.4=66.4∘

总功率：

例 4 · 反问题：已知功率求电流

某三相负载 P=30P = 30P=30 kW、Ul=380U_l = 380Ul​=380 V、cos⁡φ=0.75\cos\varphi = 0.75cosφ=0.75。求线电流。

工程实例 ​

为什么供电局考核功率因数？ 从 Il=P/(3Ulcos⁡φ)I_l = P/(\sqrt3U_l\cos\varphi)Il​=P/(3​Ul​cosφ) 看，cos⁡φ\cos\varphicosφ 越低，输送同样的有功功率需要的电流越大，线路损耗 I2RI^2RI2R 按平方涨。cos⁡φ=0.5\cos\varphi = 0.5cosφ=0.5 时的线损是 cos⁡φ=1\cos\varphi = 1cosφ=1 时的 4 倍 —— 这部分损耗由供电部门承担，所以要考核、要罚款（详见 ）。

一块功率表能不能测三相功率？ 能，用"一表法"测三相对称负载：只测一相再乘 3。条件是负载严格对称。现场三相三线制更常用两表法，四线制用三表法 —— 因为现场负载几乎不可能严格对称。

易错清单 ​

  1. φ\varphiφ 是相电压与相电流的夹角，不是线电压与线电流的夹角
  2. 两表读数是代数和；cos⁡φ<0.5\cos\varphi < 0.5cosφ<0.5 时一表为负，不能取绝对值相加
  3. 两表法只适用于三线制；四线制不对称负载必须用三表法
  4. tan⁡φ\tan\varphitanφ 公式里是 大减小，别把顺序写反
  5. 铭牌功率是轴上输出，求输入功率要除以效率；UUU、III 是线量
  6. 380=3×220380 = \sqrt3\times220380=3​×220 只是近似（实际 3×220=381\sqrt3\times220 = 3813​×220=381），算题时按题目给的数走，别纠结末位
