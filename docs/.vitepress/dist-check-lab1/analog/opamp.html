05 · 集成运算放大电路 ​

核心 约 50 min虚短虚断的成立条件是「负反馈 + 深反馈」——开环或正反馈时套上去是概念性错误；另一定频错误是双端/单端输出增益差 2 倍

这一页要解决什么：上一章的分立放大电路，每一级都要自己搭偏置、算 Q 点，元器件一多就难调。集成运放把整套电路做进一片硅。读完你应该能回答三件事：为什么运放的输入级非要用两个一模一样的管子（差分对）并配一个恒流源尾巴；这个结构凭什么做到「放大有用信号、无视两输入端同向窜入的干扰」；以及虚短虚断这两条法则究竟是真实存在的还是一种近似——它的边界在哪里。

读这页之前

  • 需要会：KCL 与 KVL（、）、戴维南等效（）、三极管工作区与 rber_{be}rbe​ 的来历（、上一页第 3 节）。
  • 这一页用到的符号：uIDu_{ID}uID​、uICu_{IC}uIC​（差模、共模输入电压）；A˙d\dot A_dA˙d​、A˙c\dot A_cA˙c​（差模、共模电压增益）；CMRR\text{CMRR}CMRR（共模抑制比）；IOI_OIO​（恒流源电流）；AodA_{od}Aod​、ridr_{id}rid​、ror_oro​（开环增益、输入电阻、输出电阻）；VBEV_{BE}VBE​（发射结压降，硅约 0.7 V）；VTV_TVT​（热电压，常温 26 mV）；u+u_+u+​、u−u_-u−​（同相端、反相端电位）。全部约定见符号与约定，首次出现处本页都就地解释。
  • 会用到对数：只在解释微电流源的一行里出现，不参与例题计算。不需要复数，因为本页只做中频小信号，频率问题留给第 3 章 · 放大电路的频率响应。
  • 三个术语先给一句话：差分放大是用两只参数相同的管子对称地放大两个输入之「差」的电路；镜像电流源是用一路基准电流「复制」出多路相同电流的电路；虚短虚断是运放在深度负反馈下的两条近似规则。正文逐条展开。

热电偶输出的信号只有几十毫伏，而它拖着的两根导线上同时感应了几十毫伏的工频干扰——两者混在一起，幅度相当。用普通单管放大器去放，放大出来的一半是噪声。但换成运放的两个输入端（分别接两根导线），输出端几乎只有那几十毫伏的有用信号。

关键不在于运放有多「灵敏」，而在于它的输入级只承认两根线之间的差值：同向的那部分干扰被结构性地抵消掉了。这种「同时兼顾两件事」的能力来自一个极其简单的想法——把电路做成左右完全对称。这一页把这个想法从上到下讲一遍。

结论先行 ​

  1. 集成运放的输入级几乎都是差分放大：靠电路的对称性放大「差」、抑制「共」——这是它能同时放大有用信号、无视同相干扰的原因。
  2. 抑制共模靠「长尾」：公共发射极上的电阻或恒流源把共模电流顶回去。恒流源的交流电阻可达 100 kΩ 以上，把 CMRR 推到 70 dB 量级。
  3. 偏置不靠笨电阻，靠电流源：镜像 / 微电流源用一路基准电流复制出多路静态电流，硅片面积小、精度高、对电源起伏不敏感。
  4. 理想运放两条法则：虚短（u+=u−u_+=u_-u+​=u−​）+ 虚断（i+=i−=0i_+=i_-=0i+​=i−​=0）。这两条是第 7 章 · 信号的运算和处理全部应用的分析起点，前提只是「开环增益足够大 + 负反馈闭环」。
  5. 实际运放有边界：开环增益有限（约 100 dB）、带宽有限、输入输出有摆幅限制、存在失调与温漂——精度设计要逐条对账。

一句话抓住本页的结构

集成运放内部就三段：差分输入级（决定抗干扰能力）→ 中间电压放大级（决定增益）→ 互补输出级（决定带载能力），外加电流源链给三级提供静态偏置。本页四节正好对这四块。抓住这张框图，参数表上几十个数就知道该归到哪一段。

一、差分放大：把「差」挑出来的对称性 ​

这一节只回答一个问题：两个输入怎么被拆成「有用」和「无用」两部分。

差分放大器（differential amplifier）的两个输入端 uI1u_{I1}uI1​、uI2u_{I2}uI2​，可以被分解成一对搭档：差模信号（differential-mode signal）是两者之差，共模信号（common-mode signal）是两者的平均值：

uID=uI1−uI2 (差模),uIC=uI1+uI22 (共模)u_{ID}=u_{I1}-u_{I2}\ (\text{差模}),\qquad u_{IC}=\frac{u_{I1}+u_{I2}}{2}\ (\text{共模}) uID​=uI1​−uI2​ (差模),uIC​=2uI1​+uI2​​ (共模)

这个分解不是数学游戏，它正好对应物理世界的两件事：有用信号通常加在两线之间（差模），而干扰（50 Hz 工频、地电位差、温度引起的两输入端同向漂移）通常同时、同向地加到两根线上（共模）。所以「分辨差共」等价于「分辨信号与干扰」。

反过来合成也一样成立（用上面两式解得）：

uI1=uIC+uID2,uI2=uIC−uID2u_{I1}=u_{IC}+\frac{u_{ID}}{2},\qquad u_{I2}=u_{IC}-\frac{u_{ID}}{2} uI1​=uIC​+2uID​​,uI2​=uIC​−2uID​​

于是任何一对输入都可以看成「一个共模分量 + 一半差模加在这边、减半加在那边」。这一句话就是整个差分电路的分析入口。

对称性为什么有用？把两半边分别看：

  • 差模输入（uI1=+uID/2u_{I1}=+u_{ID}/2uI1​=+uID​/2、uI2=−uID/2u_{I2}=-u_{ID}/2uI2​=−uID​/2）：T1 的电流增加、T2 的电流减小，一增一减。两个集电极电位反向变化，从两个集电极之间取出的电压就是两者的差——等于单边变化的两倍。
  • 共模输入（uI1=uI2=uICu_{I1}=u_{I2}=u_{IC}uI1​=uI2​=uIC​）：两管电流同时增加，尾巴上的总电流随之增大，尾巴上的压降把两管的发射极电位一起顶高 → 相当于给两管同时加了一股负反馈，把电流压回去 → 两个集电极电位同向变化。若从两个集电极之间取输出（双端输出），两个相同的变化互相抵消。

于是得到一个漂亮的分工：双端输出对差模有两倍增益，对共模增益为零。

差分把「差」挑出来了，但整套电路还需要一个稳定的偏置电流。这个电流从哪里来？下一节回答。

二、偏置的艺术：镜像电流源与微电流源 ​

这一节回答两个问题：为什么集成运放里几乎没有大电阻，以及一路基准电流怎么变成多路。

答案藏在硅片工艺里：做一颗电阻占用的面积远大于做一颗管子，而且大电阻的绝对精度差、温度系数大。所以集成设计的第一原则是——用管子做电阻，用电流源代替电阻。

镜像电流源（current mirror）是这样工作的：两只参数完全相同的管子，把它们的基极连在一起、发射极都接地，那么两只管子的 VBEV_{BE}VBE​ 相同 → 两只管子的 IBI_BIB​ 相同 → 两只管子的 ICI_CIC​ 也相同。于是左边那一路流多大电流，右边那一路就「照镜子」一样复制出多大的电流。

三、虚短与虚断：把运放当黑箱用的两条法则 ​

这一节回答一个必须诚实回答的问题：u+=u−u_+=u_-u+​=u−​ 是真的吗？

不是真的，但它是一个好到可以把误差忽略掉的近似。 推导只有两行。运放的输出是

uo=Aod(u+−u−)u_o=A_{od}(u_+-u_-) uo​=Aod​(u+​−u−​)

同理，虚断（virtual open：两输入端电流近似为零）来自输入电阻 ridr_{id}rid​ 极大（106∼1012 Ω10^{6}\sim10^{12}\ \Omega106∼1012 Ω），流进输入端的电流小到可以忽略。

  1. 虚短：u+=u−u_+=u_-u+​=u−​（负反馈下）；
  2. 虚断：i+=i−=0i_+=i_-=0i+​=i−​=0。

虚短的前提必须每次检查

虚短的推导用了「uo=Aod(u+−u−)u_o=A_{od}(u_+-u_-)uo​=Aod​(u+​−u−​)，而 uou_ouo​ 是有限值」这一步。只有在负反馈闭环下输出才会稳定在某个有限值。若运放开环（如比较器）或接成正反馈，输出直接打到正负饱和，此时 u+−u−u_+-u_-u+​−u−​ 可能相差好几伏，虚短完全不成立。这两条法则及其成立条件的详细说明见 ，第 7 章 · 信号的运算和处理所有公式都建立在这个前提上。

工程实例：一片运放是怎么被「设计」出来的 ​

一片运放的版图，就是本页四块内容的拼装：

  • 输入级：PNP 差分对（耐压高、输入范围宽）或 NPN，尾端一个恒流源——例 1、例 2 的硅片版；
  • 电平移位：直接耦合会把电位越抬越高，用 PNP 或电流源搬回中线；
  • 中间级：达林顿 + 有源负载，一级拿下 60 dB 以上增益；
  • 输出级：甲乙类互补（第 4 章 · 功率放大电路）+ 限流保护，附过温关断；
  • 频率补偿：内部一颗 30 pF 电容做主极点（第 3 章 · 放大电路的频率响应的波特图 + 第 6 章 · 放大电路中的反馈的稳定性），保证单位增益闭环不自激——这就是 741 敢开深反馈还稳的原因。

易错清单 ​

按踩坑频率从高到低排，每条格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 在开环或正反馈场合套用虚短 → 比较器输出已饱和，u+≠u−u_+\ne u_-u+​=u−​ → 虚短的前提是负反馈 + 深反馈；判断反馈极性是第一步。
  2. 把双端输出的公式套到单端输出上 → 增益算成两倍 → 单端 A˙d=−βRC/(2rbe)\dot A_d=-\beta R_C/(2r_{be})A˙d​=−βRC​/(2rbe​)，双端是这个的两倍；口径要与 A˙c\dot A_cA˙c​ 一致。
  3. 以为虚短等于同一点，把两输入端用导线连起来分析 → 电路被短成错的拓扑 → 虚短只是电压相等、电流为零；虚断才是电流条件，两条必须同时用。
  4. 共模输入范围不考虑 → 输入共模电压太高会把尾电流源推饱和、差分管退出放大区 → 选型时要确认输入共模范围覆盖信号的实际摆幅。
  5. 镜像电流源精度当无穷 → 多路偏置不一致 → 精确值 IC2=IC1/(1+2/β)I_{C2}=I_{C1}/(1+2/\beta)IC2​=IC1​/(1+2/β)；高精度场合用威尔逊电流源或外接精密电阻。
