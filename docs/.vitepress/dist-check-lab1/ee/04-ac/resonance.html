11 · 谐振与频率特性 ​

了解 约 45 minQ 是这一页唯一的主角：选择性好和通频带宽是一对不可调和的矛盾，所有工程取舍都从这里来

这一页要解决什么：上一页讲功率时，频率是个固定在 50 Hz 的背景参数；这一页把它变成变量。当频率变化时，感抗与容抗朝相反方向走，一定会在某个频率上正好抵消——那一刻电路的行为会突然变样。这一页回答：这个频率是多少（只由 LLL、CCC 决定）、那一刻电压电流会变成什么样（可能比电源大几十倍）、以及「选得准」和「通得宽」为什么不能同时要。读完你应该能算谐振频率、算品质因数、算通频带，并判断一个回路是用来选频还是用来阻波。

读这页之前

  • 需要会：阻抗 Z=R+j(XL−XC)Z=R+j(X_L-X_C)Z=R+j(XL​−XC​) 与相量法（、）；有效值（）。这一页不引入新定律，全部是阻抗公式的推论。
  • 这一页用到的符号：ω0\omega_0ω0​、f0f_0f0​ 谐振角频率与谐振频率（电路自己「愿意」工作的那个频率）、QQQ 品质因数（quality factor：一个无量纲的数，衡量回路存能量的本事，见第二节）、BWBWBW 通频带（bandwidth，能有效通过的频率宽度，单位 Hz）、η=f/f0\eta=f/f_0η=f/f0​ 归一化频率。全部约定见符号与约定。
  • 注意一个撞名：这里的 QQQ 是品质因数，和上一页的无功功率 QQQ（单位 var）完全不是一个东西。判断依据很简单：带单位 var 的是无功，纯数字、几十到几百的是品质因数。全站都靠上下文与单位区分。
  • 需要的数学：开平方、解一元二次方程（推导通频带时用到）、对数坐标只是看图用的，计算不需要。

收音机面板上那个调台旋钮，转一点点，一个台就清楚了、隔壁台就沉下去了。旋钮背后是一个可变电容：转动它，CCC 变了，回路的谐振频率就跟着变，正好扫过你想听的那个电台。可这台收音机为什么不能「一次收下所有台」？因为让它选得准的那个性质（回路对这个频率特别敏感），同时也让它对别的频率特别不敏感。想要全收，就什么也收不清。

另一边，电力工程师对同一件事的态度完全相反：电网里如果偶然凑出一个谐振回路，电容或电感上会出现几十倍额定电压，绝缘当场击穿。同一个物理现象，无线电里是工具，电力系统里是事故。 这一页把它算清楚。

结论先行 ​

  1. 谐振的条件只有一条：感抗与容抗相等（XL=XCX_L=X_CXL​=XC​），于是 ω0=1LC\omega_0=\dfrac{1}{\sqrt{LC}}ω0​=LC​1​——只由 LLL、CCC 决定，与 RRR 无关。
  2. 串联谐振时阻抗最小、电流最大、电压电流同相；单个元件上的电压可达 QUQUQU，所以叫电压谐振。
  3. 品质因数 Q=ω0LR=1ω0CR=1RLCQ=\dfrac{\omega_0L}{R}=\dfrac{1}{\omega_0CR}=\dfrac{1}{R}\sqrt{\dfrac LC}Q=Rω0​L​=ω0​CR1​=R1​CL​​，它同时是「电压放大倍数」和「储能与每周期耗能之比」。
  4. 通频带 BW=f0QBW=\dfrac{f_0}{Q}BW=Qf0​​（精确成立，不是近似）：QQQ 越大选得越准，但能通过的频率范围越窄。
  5. 并联谐振是串联的对偶：阻抗最大、总电流最小，而支路电流可达总电流的 QQQ 倍，所以叫电流谐振。

规律层：谐振的本质只有一句话

谐振 = 感抗与容抗恰好抵消、电路整体退化成纯电阻的那一个频率点。所有「高 QQQ」「窄带宽」「电压谐振 / 电流谐振」都是这句话的推论，不是独立的新规律。先记住 ω0=1/LC\omega_0=1/\sqrt{LC}ω0​=1/LC​，其余都是围着它展开。

一、谐振：电抗归零的那一刻 ​

这一节只回答一个问题：为什么「感抗等于容抗」会让整个电路的行为突变。

RLC 串联的阻抗是 Z=R+j(XL−XC)Z=R+j(X_L-X_C)Z=R+j(XL​−XC​)，其中 XL=ωLX_L=\omega LXL​=ωL、XC=1ωCX_C=\dfrac{1}{\omega C}XC​=ωC1​。两者都随频率变，而且方向相反：频率升高，感抗变大、容抗变小。

同一个 RLC：低频段 X_C 大（呈容性），高频段 X_L 大（呈感性），交点处电抗为零——这就是谐振频率。注意两条曲线在对数轴上都是直线

两条曲线的交点就是谐振点，它与 LLL、CCC 的具体取值无关（横轴已经按 f0f_0f0​ 归一化）。令 XL=XCX_L=X_CXL​=XC​：

ω0L=1ω0C  ⟹  ω0=1LC,f0=12πLC\omega_0L=\frac{1}{\omega_0C}\;\Longrightarrow\;\boxed{\omega_0=\frac{1}{\sqrt{LC}},\qquad f_0=\frac{1}{2\pi\sqrt{LC}}} ω0​L=ω0​C1​⟹ω0​=LC​1​,f0​=2πLC​1​​

注意这个结果里没有 RRR。RRR 只决定曲线有多尖（下一节），不决定峰在哪里。

谐振瞬间，电抗部分整体消失，电路退化成纯电阻：

ULU_LUL​ 与 UCU_CUC​ 都能到 QUQUQU —— 这需要一个新数 QQQ，它就是下一节的主角。也正因为「电压能放大」，谐振在电力系统里是要防的事故，在无线电里是要用的工具，两边的立场都由这一个数决定。

二、品质因数 Q：一个数字决定全部 ​

这一节只回答一个问题：QQQ 究竟是什么，为什么它能同时决定放大倍数和曲线形状。

品质因数（quality factor）的定义，是「谐振时电抗上的电压与总电压之比」：

Q=ULU=ω0LR=1ω0CR=1RLC\boxed{Q=\frac{U_L}{U}=\frac{\omega_0L}{R}=\frac{1}{\omega_0CR}=\frac{1}{R}\sqrt{\frac LC}} Q=UUL​​=Rω0​L​=ω0​CR1​=R1​CL​​​

三个表达式完全等价（用 ω02=1/LC\omega_0^2=1/LCω02​=1/LC 互推），考题里已知什么就挑哪个用。注意第三个：它说明 QQQ 只由 RRR、LLL、CCC 三个数决定，L/CL/CL/C 越大（相对 RRR）越「好」。

QQQ 的物理意义有两层，两层都要会：

  1. 电压放大倍数：UL=UC=QUU_L=U_C=QUUL​=UC​=QU。谐振时电感或电容上的电压是电源电压的 QQQ 倍。
  2. 能量保持能力：Q=2π×回路储能每周期耗能Q=2\pi\times\dfrac{\text{回路储能}}{\text{每周期耗能}}Q=2π×每周期耗能回路储能​。QQQ 越大，能量在回路里「活」的周期数越多，衰减越慢。

电力系统为什么怕串联谐振

UL=QUU_L=QUUL​=QU 意味着 Q=30Q=30Q=30 的回路里，电容或电感要承受 30 倍额定电压——绝缘直接击穿。所以电力系统中串联谐振（尤其是铁磁谐振）是要预防的事故，而无线电里它是主动利用的工具。判断标准不是「谐振好不好」，而是「这个电压有没有人受得了」。

QQQ 这个数还会决定另一件事：这条曲线到底有多尖。下一节把它量化。

三、通频带：半功率点与 BW ​

这一节只回答一个问题：怎么用一个数说明「这个回路选得多准」。

先把电流归一化，把 f0f_0f0​ 和 RRR 都约掉，得到一条只含 QQQ 的通用谐振曲线：

II0=11+Q2(η−1η)2,η=ff0\boxed{\frac{I}{I_0}=\frac{1}{\sqrt{1+Q^2\left(\eta-\dfrac{1}{\eta}\right)^2}},\qquad \eta=\frac{f}{f_0}} I0​I​=1+Q2(η−η1​)2​1​,η=f0​f​​

工程上定义半功率点：电流降到 I0/2I_0/\sqrt2I0​/2​ 的那个频率。之所以叫半功率，是因为 P=I2RP=I^2RP=I2R，电流降到 1/21/\sqrt21/2​，功率正好降到一半。两个半功率点 f1f_1f1​、f2f_2f2​ 之间的宽度就是通频带（bandwidth）：

BW=f2−f1BW=f_2-f_1 BW=f2​−f1​

代入通用曲线，令 I/I0=1/2I/I_0=1/\sqrt2I/I0​=1/2​，即 Q2(η−1η)2=1Q^2\left(\eta-\frac1\eta\right)^2=1Q2(η−η1​)2=1：

η−1η=±1Q  ⟹  η1,2=∓ 1/Q+1/Q2+42\eta-\frac{1}{\eta}=\pm\frac{1}{Q}\;\Longrightarrow\;\eta_{1,2}=\frac{\mp\,1/Q+\sqrt{1/Q^2+4}}{2} η−η1​=±Q1​⟹η1,2​=2∓1/Q+1/Q2+4​​

两式相减，1/Q2+4\sqrt{1/Q^2+4}1/Q2+4​ 抵消：

η2−η1=1Q  ⟹  BW=f0Q\eta_2-\eta_1=\frac{1}{Q}\;\Longrightarrow\;\boxed{BW=\frac{f_0}{Q}} η2​−η1​=Q1​⟹BW=Qf0​​​

这个结果是精确的

BW=f0/QBW=f_0/QBW=f0​/Q 常被当成高 QQQ 近似，其实精确成立——推导里只用了 η2η1=1\eta_2\eta_1=1η2​η1​=1 这一条（两个半功率点关于 f0f_0f0​ 对称，在 η\etaη 轴上互为倒数）。这也顺带给出一条实用推论：f1=f0η2f_1=\dfrac{f_0}{\eta_2}f1​=η2​f0​​、f2=f0η2f_2=f_0\eta_2f2​=f0​η2​，两个半功率点的几何平均正好是 f0f_0f0​，用算术平均（f0±BW/2f_0\pm BW/2f0​±BW/2）会有千分之几的偏差。

于是取舍变得很直接。这里引入一个词：选择性（selectivity，指回路从一堆频率里挑出想要那一个、把别的压下去的能力）：

  • QQQ 翻倍 → 曲线尖一倍 → 选择性好一倍，但通频带窄一半。
  • QQQ 减半 → 通频带宽一倍，但邻台也漏进来一倍。

同一个 Q，两种相反的需求

  • 收音机选台：要 QQQ 大。中频 465 kHz、带宽 10 kHz，Q=46.5Q=46.5Q=46.5——专门把邻台摁掉。
  • 音频放大：要 QQQ 小。20 Hz~20 kHz 全通过，QQQ 甚至不需要「谐振」这个概念。
  • 示波器探头：QQQ 要正好补偿到 1 附近，否则方波过冲振铃——这就是探头上那颗电容要拿螺丝刀调的原因。

串联看完，还差它的对偶：把三个元件改成并联，一切都会反过来。

这一节只回答一个问题：同样的 LLL、CCC 改成并联后，哪些量反过来了。

  • 支路电流 IL≈IC=QII_L\approx I_C=QIIL​≈IC​=QI，可能远大于总电流

例 2 · 反问题：已知带宽求参数

题目：收音机中频放大器的中心频率 f0=465f_0=465f0​=465 kHz，要求通频带 BW=10BW=10BW=10 kHz。回路电阻 R=10 ΩR=10\ \OmegaR=10 Ω，求所需 QQQ、LLL、CCC。

例 3 · 并联谐振：小总电流、大支路电流

题目：R=1 kΩR=1\ \text{k}\OmegaR=1 kΩ、L=1L=1L=1 mH、C=1 μC=1\ \muC=1 μF 并联，接在 U=100U=100U=100 V 的电源上。求 f0f_0f0​、谐振时的总电流与支路电流。

先想什么：并联题先问一句「三个元件真的是并联吗」——本题给的是理想元件，RRR 独立支路，所以 Y=1/R+j(ωC−1/ωL)Y=1/R+j(\omega C-1/\omega L)Y=1/R+j(ωC−1/ωL) 直接可用。若 RRR 是线圈自身电阻（与 LLL 串联后再并 CCC），结论会略有偏差，那是另一种模型。

步骤：

  1. 谐振频率（与串联同一公式）：
f0=12πLC=12π10−3×10−6=12π×3.16×10−5=5033 Hzf_0=\frac{1}{2\pi\sqrt{LC}}=\frac{1}{2\pi\sqrt{10^{-3}\times10^{-6}}}=\frac{1}{2\pi\times3.16\times10^{-5}}=5033\ \text{Hz} f0​=2πLC​1​=2π10−3×10−6​1​=2π×3.16×10−51​=5033 Hz

元件选型按支路电流

电源只供 0.1 A，电感电容里却流过 3.16 A（31.6 倍）。所以并联谐振回路里的电感和电容要按支路电流选型，熔断器与导线也按支路电流配——按总电流配，谐振时会烧。

三道题做完，这一页的计算部分就齐了。最后把这些结论放回工程里，看它们各自出现在什么设备上。

六、工程实例 ​

这一节把谐振放回真实设备：哪些场合要它的「尖」，哪些场合怕它的「高」。

  • 收音机选台：天线回路 + 可变电容组成谐振回路，QQQ 做到几十，只让目标电台的信号进放大器。转动旋钮改 CCC → 改 f0f_0f0​ → 选台。
  • 中频放大器：超外差接收机把各电台统一搬到 465 kHz 中频，中周就是 465 kHz 的谐振回路，负责筛出中频、抑制邻近频率。
  • 阻波器：电力线载波通信把并联谐振回路串在线上，对 50 Hz 呈高阻抗（不挡工频电流），对高频通信信号呈低阻抗（让高频通过）。
  • 铁磁谐振过电压（事故）：电网中电感（变压器、电压互感器）与电容（电缆、断口电容）偶然构成串联谐振，ULU_LUL​ 过电压数倍，烧毁设备。防止办法是破坏谐振条件（接入阻尼电阻）或改变运行方式。
  • 石英晶体谐振器：QQQ 高达 104∼10610^4\sim10^6104∼106，频率稳定度远胜 LC 回路——所有精密时钟（单片机晶振、手表）都靠它。

这些设备的共同点只有一个：既要频率选得准，又要电压承受得住。下面把这一页的坑排一遍。

七、易错清单（按踩坑频率排序） ​

按踩坑频率从高到低排，每条格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 说 f0f_0f0​ 与 RRR 有关 → 谐振频率算错、调参调到死胡同 → f0f_0f0​ 只由 LLL、CCC 决定，RRR 只改变曲线的尖与钝。
  2. QQQ 公式里的 RRR 只算外接电阻 → QQQ 偏大、ULU_LUL​ 偏小，实测对不上 → RRR 是回路总电阻，含电感线圈自身电阻。
  3. 串联谐振按 UUU 选元件耐压 → 谐振时击穿 → 按 QUQUQU 选。
  4. 并联谐振按总电流选元件 → 谐振时烧毁 → 按支路电流 QIQIQI 选。
  5. 把 BW=f0/QBW=f_0/QBW=f0​/Q 当近似式 → 多写一堆修正项 → 它精确成立；真正要小心的是别用算术平均求 f1f_1f1​、f2f_2f2​。
  6. 串联、并联的阻抗说反 → 全部应用跟着反 → 串联 ZZZ 最小、并联 ZZZ 最大。
  7. 把品质因数 QQQ 与无功功率 QQQ 混用 → 单位、量级全错 → 看单位：var 是无功，纯数几十到几百是品质因数。
  8. 并联谐振用理想公式算含线圈电阻的回路 → 频率偏高、QQQ 偏大 → 阻抗不纯时谐振频率略低于 1/LC1/\sqrt{LC}1/LC​。
