换路定则 ​

卡片 约 5 min连续的只有 u_C 和 i_L 两个量；电容电流、电感电压都能瞬间跳变

换路（开关动作）那一瞬间，只有电容电压 uCu_CuC​ 和电感电流 iLi_LiL​ 不能跳变，其余所有量——电阻上的电压电流、电容电流、电感电压——都可以突变。

日常说法与正式定义 ​

日常的说法是「电感有惯性，电流想变但来不及」「电容像弹簧，压缩量不能一下子改」。这两句比喻都对，而且指向同一件事：储能元件里存着能量，能量不能瞬间改变。

正式定义：把开关动作的时刻记作 t=0t = 0t=0，则换路前一瞬间记作 0−0_-0−​、换路后一瞬间记作 0+0_+0+​，有

uC(0+)=uC(0−)iL(0+)=iL(0−)u_C(0_+) = u_C(0_-) \qquad i_L(0_+) = i_L(0_-) uC​(0+​)=uC​(0−​)iL​(0+​)=iL​(0−​)

符号说明：

符号含义说明
uCu_CuC​电容两端电压状态变量，连续
iLi_LiL​流过电感的电流状态变量，连续
0−0_-0−​ / 0+0_+0+​换路前 / 后的一瞬间两者时间差为零，但电路结构可能已变
WC=12CuC2W_C = \tfrac12 Cu_C^2WC​=21​CuC2​电容储能能量不能突变，所以 uCu_CuC​ 不能突变
WL=12LiL2W_L = \tfrac12 Li_L^2WL​=21​LiL2​电感储能同理，iLi_LiL​ 不能突变

为什么偏偏是这两个量 ​

能量的表达式里只有 uCu_CuC​ 和 iLi_LiL​ 是以平方出现的：

WC=12CuC2WL=12LiL2W_C = \tfrac12 C u_C^2 \qquad W_L = \tfrac12 L i_L^2 WC​=21​CuC2​WL​=21​LiL2​

如果 uCu_CuC​ 能瞬间从 0 跳到 10 V，那么这段时间趋于零、功率趋于无穷，电源要在零时间里送出有限的能量——物理上做不到。所以能量连续 ⇒ 状态变量连续。

而其它量都只是「派生量」：电容电流 iC=C duC/dti_C = C\,du_C/dtiC​=CduC​/dt 是 uCu_CuC​ 的变化率，uCu_CuC​ 在 t=0t=0t=0 处有一个折角，斜率就可以瞬间改变，iCi_CiC​ 也就跟着跳；电感电压 uL=L diL/dtu_L = L\,di_L/dtuL​=LdiL​/dt 同理。

三条推论，做题时全靠它们：

  • 电容电压不能突变 → 换路瞬间电容可以当成一个电压源 uC(0+)u_C(0_+)uC​(0+​)。
  • 电感电流不能突变 → 换路瞬间电感可以当成一个电流源 iL(0+)i_L(0_+)iL​(0+​)。
  • 其它量（电阻电压与电流、电容电流、电感电压）都可以突变——这正是每次都要重新算一遍的部分。

求初始值的标准两步 ​

  1. 先算 0−0_-0−​：用换路前的稳态电路（此时电容开路、电感短路，因为直流稳态下它们就是这样）。
  2. 再画 0+0_+0+​ 的等效电路：把电容换成电压源 uC(0+)u_C(0_+)uC​(0+​)、电感换成电流源 iL(0+)i_L(0_+)iL​(0+​)，其余元件按换路后的接法，然后求其它量。

两步之间唯一连续的桥梁就是那两个状态变量；其它量都要在新电路里重算。

一个 RC 例子：E=10E = 10E=10 V、R=1 kΩR = 1\ \text{k}\OmegaR=1 kΩ、C=1 μFC = 1\ \mu\text{F}C=1 μF，换路前电容未充电。

  • 0−0_-0−​：uC(0−)=0u_C(0_-) = 0uC​(0−​)=0。
  • 0+0_+0+​：电容相当于 0 V 的电压源（就是短路），于是 iC(0+)=(E−0)/R=10i_C(0_+) = (E - 0)/R = 10iC​(0+​)=(E−0)/R=10 mA。
  • 稳态（t→∞t \to \inftyt→∞）：电容相当于开路，iC=0i_C = 0iC​=0、uC=10u_C = 10uC​=10 V。时间常数 τ=RC=1\tau = RC = 1τ=RC=1 ms。

一个 RL 例子：E=10E = 10E=10 V、R=1 kΩR = 1\ \text{k}\OmegaR=1 kΩ、L=10L = 10L=10 mH，换路前 iL(0−)=0i_L(0_-) = 0iL​(0−​)=0。

  • 0+0_+0+​：电感相当于 0 A 的电流源（就是开路），于是一整圈电流为零，RRR 上压降为零，uL(0+)=10u_L(0_+) = 10uL​(0+​)=10 V。
  • 稳态：电感相当于短路，iL=10i_L = 10iL​=10 mA、uL=0u_L = 0uL​=0。时间常数 τ=L/R=10 μ\tau = L/R = 10\ \muτ=L/R=10 μs。

常见误解：以为「电容电流也不能突变」

这是最高频的错。记法很简单：只有储能变量连续。电容电压连续，它的导数（电流）就可以不连续；电感电流连续，它的导数（电压）就可以不连续。你给电容接上一个电阻，瞬间电流就是要跳——这不违反任何守恒，因为储能量没变。

第二个误区：拿换路后的电路去求 0−0_-0−​

求 0−0_-0−​ 必须用换路前的电路，求 0+0_+0+​ 才是换路后的电路。混用会得到「换路前电压就已经是稳态值」的荒唐结论，整道题的初始条件全错。

为什么容易错：因为「能量不能突变」这句正确的话，推不出「这个元件上什么都连着」。它只给出两个等式，两个等式只锁住两个量。

什么时候用得上 ​

正文里凡是见到开关、见到「t=0t = 0t=0 时换路」，第一步就是套这两条——它是三要素法里第一个要素（初始值）的唯一来源。
