变压器变比 ​

卡片 约 4 min升压必然降流；k² 变阻抗别写成 k；直流进变压器等于短路

变压器用同一个铁芯里的交变磁通把能量从原边搬到副边，电压比等于匝数比——所以它升高电压的代价，一定是降低电流。

日常说法与正式定义 ​

日常说法：「小区门口那个变压器把 10 kV 降到 380 V」「手机充电头里也有个变压器，只是工作频率高、体积小」。这些说法对，但漏了一件关键的事：变电压从不免费。

正式定义：两个绕组套在同一个铁芯上，共用一个交变磁通 Φ\PhiΦ。原边匝数 N1N_1N1​、副边匝数 N2N_2N2​，则

U1U2≈N1N2=kI1I2≈1kZin=k2ZL\frac{U_1}{U_2} \approx \frac{N_1}{N_2} = k \qquad \frac{I_1}{I_2} \approx \frac{1}{k} \qquad Z_{in} = k^2 Z_L U2​U1​​≈N2​N1​​=kI2​I1​​≈k1​Zin​=k2ZL​

符号说明：

符号含义说明
N1N_1N1​ / N2N_2N2​原边 / 副边匝数无单位，只数圈数
kkk变比（turns ratio）k>1k>1k>1 降压，k<1k<1k<1 升压
Φ\PhiΦ主磁通穿过两个绕组的公共磁通，单位 Wb
U1U_1U1​ / U2U_2U2​原边 / 副边电压有效值
I1I_1I1​ / I2I_2I2​原边 / 副边电流有效值
ZinZ_{in}Zin​从原边看进去的输入阻抗副边接 ZLZ_LZL​ 时折算过来

三条关系对应三个用途——变电压、变电流、变阻抗。第三条不是新现象，它是前两条合起来的结果：Zin=U1/I1=(kU2)/(I2/k)=k2(U2/I2)=k2ZLZ_{in} = U_1/I_1 = (kU_2)/(I_2/k) = k^2(U_2/I_2) = k^2Z_LZin​=U1​/I1​=(kU2​)/(I2​/k)=k2(U2​/I2​)=k2ZL​。

原理：一个磁通，两个绕组 ​

  • 空载：原边加 u1u_1u1​ → 铁芯里产生交变磁通 Φ\PhiΦ → 两个绕组都感应电动势 e1=−N1 dΦ/dte_1 = -N_1\,d\Phi/dte1​=−N1​dΦ/dt、e2=−N2 dΦ/dte_2 = -N_2\,d\Phi/dte2​=−N2​dΦ/dt。因为同一个 dΦ/dtd\Phi/dtdΦ/dt，所以 U1/U2=N1/N2U_1/U_2 = N_1/N_2U1​/U2​=N1​/N2​。
  • 带载：副边电流 I2I_2I2​ 产生去磁磁动势，主磁通想变小；原边电流 I1I_1I1​ 立刻增大来抵消，把磁通顶回原来的水平。磁通基本不变，于是 I1/I2≈N2/N1I_1/I_2 \approx N_2/N_1I1​/I2​≈N2​/N1​。

算一遍最常用的那组数：N1=1000N_1 = 1000N1​=1000、N2=100N_2 = 100N2​=100，则 k=10k = 10k=10；原边 220 V → 副边 220/10=22220/10 = 22220/10=22 V。

副边接 ZL=8 ΩZ_L = 8\ \OmegaZL​=8 Ω：I2=22/8=2.75I_2 = 22/8 = 2.75I2​=22/8=2.75 A，I1=2.75/10=0.275I_1 = 2.75/10 = 0.275I1​=2.75/10=0.275 A。核对功率：220×0.275=60.5220\times0.275 = 60.5220×0.275=60.5 W，22×2.75=60.522\times2.75 = 60.522×2.75=60.5 W——两侧相等，这就是「变电压必变电流」的意思。

从原边看进去的阻抗：Zin=k2ZL=100×8=800 ΩZ_{in} = k^2Z_L = 100\times8 = 800\ \OmegaZin​=k2ZL​=100×8=800 Ω。原本 8 Ω 的负载，在变压器原边看起来像 800 Ω——这就是音响输出变压器「阻抗匹配」的做法。

常见误解一：以为变压器能变功率

理想变压器两侧功率相等（P1=P2P_1 = P_2P1​=P2​），实际变压器还要扣掉铁损和铜损，副边拿到的一定更少。升压 10 倍，电流就降到 1/10，能量守恒一分不多。看到「升压变压器能省电」这类说法，直接按 P=UIP = UIP=UI 核对一遍。

常见误解二：以为变压器能给直流变压

接直流时磁通恒定不变化，dΦ/dt=0d\Phi/dt = 0dΦ/dt=0，副边没有感应电动势；同时原边绕组只剩很小的电阻，电流只受它限制，很快就过热烧毁。变压器只对交流有效，这也是开关电源要先「逆变」再变压的原因。

常见误解三：ZinZ_{in}Zin​ 写成 kZLk Z_LkZL​

是 k2k^2k2，不是 kkk。因为电压放大 kkk 倍、电流同时缩小 kkk 倍，两个 kkk 乘在一起。写错这一个平方，阻抗匹配整题偏一个数量级。

为什么容易错：因为变比 kkk 是乘法关系，用起来很顺手，容易被顺手推广到所有量上——功率乘 kkk、阻抗乘 kkk。真正的约束只有一条：能量守恒。凡是与能量有关的量（功率、阻抗折算），都要多问一句「两侧是否相等」。

什么时候用得上 ​

正文里凡是出现「220 V 变成 12 V」「远距离输电为什么要先升压」「放大器输出为什么要匹配 8 Ω 喇叭」，都是先写变比三条关系再算；电机那一章的互感、折算也建立在同一组式子上。
