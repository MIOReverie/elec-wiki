布尔代数与化简 ​

卡片 约 4 min德摩根穿过门时「与」「或」要对调，括号错一个意思就反了

数字逻辑只由与、或、非三种运算构成，「非」穿过门时要按德摩根定律把「与」和「或」对调——化简的判据是项数最少，其次每项的字面数最少。

记住这几条 ​

  • 一切数字逻辑只由三种运算构成：与（⋅\cdot⋅）、或（+++）、非（Aˉ\bar AAˉ）。其它门都是这三者的组合。
  • 德摩根定律是唯一必须背熟的公式：A+B‾=Aˉ⋅Bˉ\overline{A+B}=\bar A\cdot\bar BA+B​=Aˉ⋅Bˉ，AB‾=Aˉ+Bˉ\overline{AB}=\bar A+\bar BAB=Aˉ+Bˉ——「非」穿过门时，符号要跟着翻。
  • 化简的三个常用武器：吸收律 A+AB=AA+AB=AA+AB=A、分配律 A+BC=(A+B)(A+C)A+BC=(A+B)(A+C)A+BC=(A+B)(A+C)、冗余项 AB+AˉC+BC=AB+AˉCAB+\bar AC+BC=AB+\bar ACAB+AˉC+BC=AB+AˉC。
  • 最简式的判据是项数最少，其次每项的字面数最少，不是「看起来对称」。
  • 与非门和或非门是全能门：只用其中一种就能搭出任意逻辑函数。

为什么它承重：化简不是应试技巧，而是直接的工程收益——门更少、延迟更低、面积与功耗更小；而德摩根是把「电路图 → 表达式 → 电路图」这条回路接通的唯一钥匙。

典型数值 ​

  • 最小项（minterm：让函数取值为 1 的那一种变量取值组合）最多 2n2^n2n 个：4 变量就是 16 个最小项、16 张卡诺图格子。
  • 常见量级的收益：一个原本要 12 个门实现的监控逻辑，化简后 4 个门，面积与功耗大致按比例下降。
  • 全与非实现并不总最省：与门用 2 个与非、或门用 3 个（非或非），要按手头门型库实际折算，而不是默认「与非最省」。

常见坑 ​

  • 化简后不验算：至少代入几个关键点，确认布尔值与原式完全一致再收工。
  • 把或门的与非写错：A+BA+BA+B 的与非是 AB‾\overline{AB}AB，而 AˉBˉ\bar A\bar BAˉBˉ 是「AAA 与 BBB 的与非」——两者只差一个括号，含义却完全不同。
  • 把冗余项当「多余」删掉。它和原函数完全等价，删掉反而让竞争冒险冒出来。
  • 正式书写一律用  ˉ\bar{\ } ˉ，不要手写 A′A'A′、A′′A''A′′，扫描时容易看错。

例 1 · 化简 Y=A+AˉBC+BCDY = A + \bar{A}BC + BCDY=A+AˉBC+BCD

用 A+AˉX=A+XA+\bar AX=A+XA+AˉX=A+X 得 A+AˉBC=A+BCA+\bar{A}BC=A+BCA+AˉBC=A+BC。再代 BCD=BC⋅DBCD=BC\cdot DBCD=BC⋅D，而 BCBCBC 已含 BBB，故 BC+BCD=BCBC+BCD=BCBC+BCD=BC。

Y=A+BCY = A + BC Y=A+BC

验算：A=0,B=0A=0,B=0A=0,B=0 时原式 0+1⋅0⋅C+0=00+1\cdot0\cdot C+0=00+1⋅0⋅C+0=0，新式 000 ✓；A=0,B=1,C=1,D=1A=0,B=1,C=1,D=1A=0,B=1,C=1,D=1 时原式 0+1+1=10+1+1=10+1+1=1，新式 111 ✓。

为什么这么想 关键是先找能配对的项。AAA 与 AˉBC\bar{A}BCAˉBC 一眼能配成 A+AˉXA+\bar AXA+AˉX；先做完这一步，式子里就只剩三个乘积项，冗余项 BCDBCDBCD 自然被吸收律吃掉。
