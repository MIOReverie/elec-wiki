01 · 电路模型与参考方向 ​

核心 约 35 min这一页的『参考方向』是整门课最容易埋雷的地方

结论先行 ​

  1. 电路模型 = 把实际器件抽象成理想元件（R / L / C / 电源），只关心端口的 uuu-iii 关系。判据是外部行为不变。
  2. 参考方向是人为假设的，算出来为正说明实际方向一致，为负说明相反 —— 大小照抄，符号说明方向。
  3. 关联方向（电流从电压"+"端流入）下 P=UIP = UIP=UI 为吸收功率；P>0P>0P>0 吸收，P<0P<0P<0 发出。
  4. 电源三种状态：有载 I=ER0+RI=\dfrac{E}{R_0+R}I=R0​+RE​，开路 I=0, U=EI=0,\ U=EI=0, U=E，短路 I=ER0I=\dfrac{E}{R_0}I=R0​E​（必须避免）。
  5. 额定值不是工作点：电阻标"100Ω 2W100\Omega\ 2\text{W}100Ω 2W"意思是"接 100Ω 时最大能耗散 2W"，不是"它会主动耗散 2W"。

规律层：先分清「约定」和「定律」

这一页讲的都是约定与方法，没有新的物理定律：电路模型是用理想元件近似真实器件（判据：端口 uuu-iii 行为不变），是一种「受控的近似」；参考方向是你自己画的假设箭头，纯粹是记账——算出的负号会自动告诉你真实方向。真正的定律要到下一页（KCL/KVL）才登场。想通「这一页是约定不是定律」，就不会被「模型到底准不准、方向到底怎么定」这类问题困住。

一、什么算"模型"，什么不算 ​

看着像废话，但它决定了你能不能把物理问题和数学问题干净地分开。

建模的唯一判据：接上任意一个外电路，这个模型的端口电压-电流关系和真实器件一致。

器件真实情况模型丢掉的是什么

交流电源频率/电压波动定频定压的理想源波动与内阻

被丢掉的叫非理想特性，用三个词分类：

  • 线性 / 非线性：RRR 是不是常数。只有线性电路才能用叠加定理。
  • 时变 / 定常：参数是否随时间变。本课只处理定常。
  • 集中 / 分布参数：尺寸是否远小于波长。长线或高频（> λ/10\lambda/10λ/10）必须当分布参数看，那时 KCL/KVL 会失效 —— 概念判断题常在这里下坑。

为什么可以「丢掉」？

因为在题目给定的条件下，丢掉的量远小于保留的量。直流稳态下的电感按理想电感算，50Hz 工频下的变压器铁损按理想变压器算。这是受控的近似，不是"无所谓"。

真要精确时，会在理想元件旁边并一个小的非理想元件来近似（比如给电容并一个 R漏R_{\text{漏}}R漏​）。题目若给了漏电阻，就得老实算进去。

二、参考方向：整门课最重要的一次"约定" ​

电压的参考方向 ​

UabU_{ab}Uab​ 中下标顺序有严格含义：

Uab=Va−Vb,Uab=−UbaU_{ab} = V_a - V_b,\qquad U_{ab} = -U_{ba} Uab​=Va​−Vb​,Uab​=−Uba​

约定"UabU_{ab}Uab​ 的参考方向"就是"电位从 a 变到 b 的降低方向"。所以 UabU_{ab}Uab​ 是沿 a→b 方向电位降低了多少。

这就是新手第一大错：把 UabU_{ab}Uab​ 写成 Vb−VaV_b - V_aVb​−Va​。自检办法只有一个——当减法算一遍：3−5=−23-5=-23−5=−2，所以 Uab=−2VU_{ab}=-2\text{V}Uab​=−2V 就意味着 b 点电位更高。

关联方向（被动符号约定） ​

电流从标"+"的一端流入元件内部 —— 这才叫关联。关联方向下：

U=IR（电阻）,P=UI（功率）U = IR \quad\text{（电阻）},\qquad P = UI \quad\text{（功率）} U=IR（电阻）,P=UI（功率）

非关联方向（电流从"+"端流出）：

U=−IR,P=−UIU = -IR,\qquad P = -UI U=−IR,P=−UI

这两式不需要"看情况"，只需先检查关联性。草稿纸上花 30 秒标个箭头，能省掉一整道题的分数。

符号规则（只需记这一条）

代数上一切按参考方向算，符号自动告诉你答案对不对。

若算得 I=−3AI=-3\text{A}I=−3A，含义是"实际 3A，方向与你假设的相反"。不要重算、不要怀疑电路图，写 −3A-3\text{A}−3A 或换个方向写 3A3\text{A}3A 都行。唯一不能做的是丢掉负号。

它意味着：纯电阻网络里，电流必然从高电位流向低电位，不需要分析方向。因为 I=U/RI=U/RI=U/R 且 R>0R>0R>0，U>0U>0U>0 时 III 一定从"+"流向"−"。
