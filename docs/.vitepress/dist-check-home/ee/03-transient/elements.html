06 · 储能元件与换路定则 ​

核心 约 35 minRC/RL 伏安关系点胶囊即看，这里补的是『换路瞬间到底发生了什么』

结论先行 ​

  1. 电容：i=Cdudti = C\dfrac{du}{dt}i=Cdtdu​，储能 WC=12Cu2W_C = \dfrac12 Cu^2WC​=21​Cu2，电压不能突变
  2. 电感：u=Ldidtu = L\dfrac{di}{dt}u=Ldtdi​，储能 WL=12Li2W_L = \dfrac12 Li^2WL​=21​Li2，电流不能突变
  3. 换路定则：uC(0+)=uC(0−)u_C(0_+) = u_C(0_-)uC​(0+​)=uC​(0−​)，iL(0+)=iL(0−)i_L(0_+) = i_L(0_-)iL​(0+​)=iL​(0−​)
  4. 换路瞬间的等效替换：电容 → 电压源，电感 → 电流源；其余量都可以突变
  5. 直流稳态：电容开路、电感短路

但这五条只是答案。真正的问题不是"记住它们"，而是——

为什么偏偏是电容的电压、电感的电流不能突变，而它们的另一半可以？

这一页要回答的就是这个问题。理解了它，换路定则就不是要背的规矩，而是自然结果。

规律层：一条定律 + 一套方法，别混为一谈

  • 定律（不可违背）：能量不能瞬间增减 → 储能元件的状态量连续，即 uCu_CuC​ 和 iLi_LiL​ 不能突变。
  • 方法（解题工具）：换路定则 uC(0+)=uC(0−)u_C(0_+)=u_C(0_-)uC​(0+​)=uC​(0−​)、iL(0+)=iL(0−)i_L(0_+)=i_L(0_-)iL​(0+​)=iL​(0−​)，以及 t=0+t=0_+t=0+​ 等效电路（电容→电压源、电感→电流源）。 后者只是前者的操作化——真正不能变的只有 uCu_CuC​、iLi_LiL​，其余量（iCi_CiC​、uLu_LuL​、各电阻的电压电流）都可以突变。抓住这条分界，这章就不会错。

一、开关"啪"地合上，电路里发生了什么 ​

设想最简单的一个电路：电源 EEE、电阻 RRR、电容 CCC 串成一个回路，开关 SSS 控制通断。

合闸之前，电容没充电，uC=0u_C = 0uC​=0。合闸的一瞬间，你如果拿示波器去看电容两端，会发现电压不是从 0 瞬间跳到 EEE，而是用一段时间慢慢爬上去。

物理上的原因很朴素：电容是用一块导体和另一块导体夹起来的，导体上能"堆"电荷。 电压就是这块导体堆了多少电荷除以电容决定的。要让电压瞬间从 0 变成 EEE，等于要在零时间内把 q=CEq = CEq=CE 这么多个电荷搬到极板上。搬电荷靠的是电流，i=dq/dti = dq/dti=dq/dt —— 零时间搬完，电流无穷大。

无穷大的电流需要无穷大的电压（电阻上的 u=Riu = Riu=Ri），而电源电压有限。所以做不到。

能量角度更狠：电容储能 W=12CU2W = \dfrac12 CU^2W=21​CU2。电压从 0 瞬间跳到 EEE，能量从 0 瞬间变成 12CE2\dfrac12 CE^221​CE2，而这段时间是零，功率 P=dWdt=∞P = \dfrac{dW}{dt} = \inftyP=dtdW​=∞。没有任何电源能提供无穷大功率，所以这条路被物理堵死了。

对电感完全对称，只是换了角色：

电感的电流不能突变，因为电流建立了磁场、磁场里存着能量 W=12Li2W = \dfrac12 Li^2W=21​Li2。要让电流瞬间跳变，等于让能量瞬间出现/消失，同样要求无穷大功率。

所以记忆口诀不是"电容管电压、电感管电流"，而是：

谁储存能量，谁的状态量就不能突变。 电容存的是"电场"，用电压度量 → 电压连续。 电感存的是"磁场"，用电流度量 → 电流连续。

至于电容的电流和电感的电压，它们是"外界要多大劲才能改变内部状态"的度量——电容电压想变，需要电流去搬电荷；电感电流想变，需要电压去建立磁场。这两个量都是因变量，外界可以强行推着它们跳变（只要你的电源够强）。

最容易错的一点

uCu_CuC​ 连续、iLi_LiL​ 连续，但 iCi_CiC​ 和 uLu_LuL​ 可以无限大地突变。

一个极端例子：用 1V 电源通过 0.1Ω 电阻给 1μF 电容充电，稳态电压 1V。断开后电容保持 1V。现在用一个理想电压源强行加 100V 上去，iC=Cdudti_C = C\dfrac{du}{dt}iC​=Cdtdu​ 的导数可以任意大，实际电流被外部电阻限制为 100/0.1=1000 A100/0.1 = 1000\ \text{A}100/0.1=1000 A。电压从 1V 跳到 100V，完全没有违背换路定则。

二、元件特性的来历 ​

不要背 i=Cdudti = C\dfrac{du}{dt}i=Cdtdu​，它是定义式，来历很直白：

电容定义式：C=quCC = \dfrac{q}{u_C}C=uC​q​。CCC 的单位是法拉（F）= 库仑/伏特 —— "每伏电压能存多少库仑电荷"，本质是个几何量（平行板电容器 C=εS/dC = \varepsilon S/dC=εS/d，跟极板面积成正比、与间距成反比）。

对时间求导：i=dqdt=CduCdti = \dfrac{dq}{dt} = C\dfrac{du_C}{dt}i=dtdq​=CdtduC​​。

电感：L=ψiL = \dfrac{\psi}{i}L=iψ​，ψ=Ni\psi = Niψ=Ni 是磁链，LLL 单位亨利（H）= 韦伯/安培。电感的物理是"线圈通电产生磁场，磁场又产生感应电动势阻碍电流变化"，所以电感的电压正比于电流的变化率，符号为正（阻碍变化）。

三个「稳态等效」的快速推导

不用记，看定义式就能推：

  • 电容在直流稳态下：duC/dt=0du_C/dt = 0duC​/dt=0（电压不变）→ i=0i = 0i=0 → 开路
  • 电感在直流稳态下：diL/dt=0di_L/dt = 0diL​/dt=0（电流不变）→ u=0u = 0u=0 → 短路
  • 电阻：永远是 u=Riu = Riu=Ri，没有"稳态"可言

这个推导在考试里比你背结论快，而且不会记反。

三、换路定则的严格表述与求解流程 ​

换路定律 ​

{uC(0+)=uC(0−)iL(0+)=iL(0−)\begin{cases} u_C(0_+) = u_C(0_-) \\[4pt] i_L(0_+) = i_L(0_-) \end{cases} {uC​(0+​)=uC​(0−​)iL​(0+​)=iL​(0−​)​

注意下标：0−0_-0−​ 是换路前的极限时刻，0+0_+0+​ 是换路后的极限时刻。中间的 t=0t=0t=0 本身不参与运算（是个"数学上不存在的瞬间"）。

标准四步流程 ​

① t = 0₋ ：开关闭合足够久 → 直流稳态 → 电容开路、电感短路
            → 在这个电路里算出 u_C(0₋)、i_L(0₋)
② 换路定则 → u_C(0₊)、i_L(0₊) 直接抄 ① 的结果

④ 在这张图上求其余初始值：i_C(0₊)、u_L(0₊)、各支路电流……

第 ③ 步是整个流程的核心。 很多同学第 ① 步会做，但一到第 ③ 步就懵，原因是把"电容=开路"和"电容=电压源"搞混了：

电感同理：0−0_-0−​ 短路 → 0+0_+0+​ 电流源 → ∞\infty∞ 短路。

一个极好用的检查法

把 t=0+t=0_+t=0+​ 电路画成"电容=电压源、电感=电流源"之后，如果发现电流无穷大或者电压无穷大，一定是某处画错了。

因为在换路瞬间，外界提供的电压有限（电源就那么高），流过电容的电流虽然可以很大（被电阻限制），但不可能无穷大——无穷大意味着电源电压无穷大。同理电感电压也不会无穷大。

六、易错清单 ​

  1. 把"电容开路"用到 0+0_+0+​ 上 → 0+0_+0+​ 电容是电压源，不是开路
  2. τ\tauτ 算错电路：ReqR_{\text{eq}}Req​ 要从储能元件两端看进去，且独立源置零（电压源短路、电流源开路）
  3. 初始值用 0−0_-0−​ 而不是 0+0_+0+​：iC(0+)i_C(0_+)iC​(0+​)、uL(0+)u_L(0_+)uL​(0+​) 必须在 0+0_+0+​ 电路里求
  4. 认为"能量不能突变"就推出"功率不能突变"：能量不能突变是对的，但注意 iCi_CiC​、uLu_LuL​ 可以突变（它们不储能）
  5. 时间常数与初始值无关：RCRCRC 只看电路结构，不看 uC(0+)u_C(0_+)uC​(0+​) 和 EEE 是多少
  6. 三要素法的三个"稳态值"要分清：uC(∞)u_C(\infty)uC​(∞)、uC(0+)u_C(0_+)uC​(0+​) 是"状态量"；i(∞)i(\infty)i(∞)、i(0+)i(0_+)i(0+​) 是"响应量"，必须靠 KCL/KVL 在对应电路里算
