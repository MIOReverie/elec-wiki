05 · 触发器 ​

核心 约 35 min状态方程 + 边沿触发 + 异步端，记忆由此开始

触发器为什么能「恰好」在边沿采到数据，靠的是建立时间与保持时间这两条时间约束，见 。

结论先行 ​

  1. 触发器是有记忆的基本单元：次态 Qn+1Q^{n+1}Qn+1 取决于输入和现态 QnQ^nQn 两者——这是它和组合逻辑（只认当前输入）的本质区别。
  2. D 触发器：Qn+1=DQ^{n+1}=DQn+1=D，最常用，一个时钟沿就把 D 存进 Q。
  3. JK 触发器：Qn+1=JQˉn+KˉQnQ^{n+1}=J\bar Q^n+\bar K Q^nQn+1=JQˉ​n+KˉQn，功能最全；J=K=1J=K=1J=K=1 时每个时钟沿翻转（天然分频器）。
  4. 触发方式演进：电平触发（有空翻）→ 主从触发 → 边沿触发（现代主流，只在跳变瞬间采样）。
  5. 异步端 SˉD,RˉD\bar S_D,\bar R_DSˉD​,RˉD​：不受时钟约束、优先级最高，用来强制置位/清零。

推导脉络：从「记忆」到特性方程 ​

组合逻辑管不了「上一拍」，因为没有任何单元能留住状态。触发器（本质是带正反馈的双稳态电路）解决了这个问题：它有 Q 和 Qˉ\bar QQˉ​ 两个互补输出，掉电前一直保持。

描述它不用真值表，而用特性方程（次态 = f(输入, 现态)）：

触发器特性方程一句话
DQn+1=DQ^{n+1}=DQn+1=D时钟一到，Q 变成 D
JKQn+1=JQˉn+KˉQnQ^{n+1}=J\bar Q^n+\bar K Q^nQn+1=JQˉ​n+KˉQnJ=K=1J=K=1J=K=1 翻转；J=1,K=0J=1,K=0J=1,K=0 置 1；J=0,K=1J=0,K=1J=0,K=1 清 0
TQn+1=TQˉn+TˉQnQ^{n+1}=T\bar Q^n+\bar T Q^nQn+1=TQˉ​n+TˉQnT=1T=1T=1 翻转（JK 令 T=J=KT=J=KT=J=K 即得）
RSQn+1=S+RˉQnQ^{n+1}=S+\bar R Q^nQn+1=S+RˉQn约束 SR=0SR=0SR=0，S、R 不能同时为 1

为什么强调边沿？电平触发的触发器在 CLK=1 期间输入一变、输出就跟着变，容易在一个周期内多次翻转（空翻）。边沿触发只在 CLK 跳变那一瞬间采样，期间输入乱动都不影响——稳定得多。

图解：亲手发几个时钟 ​

拨好 D 或 J/K，点「↑ 发一个时钟脉冲」看 Q 在边沿怎样被重算；再点 SˉD/RˉD\bar S_D/\bar R_DSˉD​/RˉD​ 体会异步端的「说了算」——它们不等人发时钟，立刻强制 Q。注意：只在上升沿那一刻 Q 才更新，CLK 保持时你怎么拨输入都白搭。

典型例题（数字均经计算） ​

例 1 · JK 的翻转功能

设现态 Qn=0Q^n=0Qn=0，输入 J=1,K=1J=1,K=1J=1,K=1。代入特性方程：Qn+1=1⋅0ˉ+1ˉ⋅0=1+0=1Q^{n+1}=1\cdot\bar0+\bar1\cdot0=1+0=1Qn+1=1⋅0ˉ+1ˉ⋅0=1+0=1。现态 Qn=1Q^n=1Qn=1 时再算：Qn+1=1⋅1ˉ+1ˉ⋅1=0+0=0Q^{n+1}=1\cdot\bar1+\bar1\cdot1=0+0=0Qn+1=1⋅1ˉ+1ˉ⋅1=0+0=0。两次都翻——证实 J=K=1J=K=1J=K=1 时每个边沿翻转，这就是 T'（计数）触发器。

例 2 · JK 的置位/清零

现态 Qn=1Q^n=1Qn=1，输入 J=0,K=1J=0,K=1J=0,K=1：Qn+1=0⋅1ˉ+1ˉ⋅1=0+0=0Q^{n+1}=0\cdot\bar1+\bar1\cdot1=0+0=0Qn+1=0⋅1ˉ+1ˉ⋅1=0+0=0 → 清零。输入 J=1,K=0J=1,K=0J=1,K=0 时：Qn+1=1⋅Qˉn+0=1Q^{n+1}=1\cdot\bar Q^n+0=1Qn+1=1⋅Qˉ​n+0=1（无论现态） → 置位。所以 JK 一个器件兼顾置 0、置 1、保持、翻转四种操作。

例 3 · D 触发器的「跟随」与寄存

D=1D=1D=1 时 Qn+1=1Q^{n+1}=1Qn+1=1；D=0D=0D=0 时 Qn+1=0Q^{n+1}=0Qn+1=0。把若干 D 触发器并行摆好，同一个时钟一拍下去，各自把 D 端的数据同时锁存进 Q——这就是寄存器的雏形（下一章详述）。

例 4 · T 触发器做二分频

令 J=K=1J=K=1J=K=1（即 T=1），每来一个时钟 Q 翻转一次。若时钟频率 fff，则 Q 的输出频率是 f/2f/2f/2——一个触发器就是一分频器。级联起来就是计数器（第 6 章 · 计数器与寄存器主角）。

工程实例：边沿 D 触发器消除按键抖动 ​

机械按键松开瞬间会抖动几下，直接进 MCU 会被当成多次触发。把按键接到一个边沿 D 触发器的 D 端、Q 反馈到另一路，或用施密特+触发器锁存，抖动脉冲在时钟沿之外就被忽略，输出只认稳定的那一下——这是触发器「记忆+边沿采样」特性最接地气的应用。

易错清单 + 自检 ​

  • 边沿触发只在跳变瞬间采样：CLK 保持期间改输入，Q 不变；别把电平触发和边沿触发混为一谈。
  • 异步端 SˉD,RˉD\bar S_D,\bar R_DSˉD​,RˉD​ 是低电平有效且优先级最高，接线别画反（横杠意味着低有效）。
  • RS 触发器有约束 SR=0SR=0SR=0，S、R 同为高（或同有效）会让 Q、Qˉ\bar QQˉ​ 同时失效，设计时要避开。
  • JK 的 J=K=1J=K=1J=K=1 翻转是「边沿翻转」，不是「电平期间一直翻」——翻一次只发生在那一个沿。
  • 主从 JK 有「一次变化现象」（在 CLK=1 期间只许输入变一次），边沿 JK 没有；做题先看清是哪一类。
