07 · 信号的运算和处理 ​

核心 约 50 min运放的线性应用三件套（比例/积分/加减）+ 有源滤波 + 比较器，仪表与信号链的核心

本章全部公式都从两条近似规则推出来：。这张卡片读不懂，后面的比例器、积分器、加法器就只能背。

结论先行 ​

  1. 运放 + 负反馈 = 运算电路：比例、加减、积分、微分、对数——全部靠「虚短 + 虚断」把 Z 网络接进反馈通路，输出与输入之间只隔一个阻抗比。
  2. 积分器是「反过来的电阻」：A˙u=−1/(ωRC)\dot A_u=-1/(\omega RC)A˙u​=−1/(ωRC)，频率越低增益越高；方波进去、三角波出来。
  3. 有源滤波 = RC 网络 + 运放：一阶滚降 20 dB/dec，二阶 40 dB/dec；QQQ 决定通带起伏与滚降陡度的交换。
  4. 比较器把运放推向开环或正反馈：输出只有两个状态——波形整形、阈值检测、AD 前端（接数电 08 章）都靠它。
  5. 线性应用看负反馈，非线性应用看开环/正反馈——同一颗运放，两种世界。

推导脉络：从虚短到一切公式 ​

所有线性应用共用一张推导图，规则本身见 ：

虚断：输入电流 = 0 → 电流全部流向反馈网络
虚短：u− = u+ → 输入与输出被 Z 网络「绑」在一起
  ⇒ 输出 = 输入 ×（反馈阻抗 / 输入阻抗）的各种排列组合

比例器是阻抗比；加法器是「多路电流在虚地点相加」；积分器把反馈电阻换成电容（i=C du/dti=C\,du/dti=Cdu/dt，除法变积分）；微分器反过来。记住这个图，公式不用背。

图解①：三类应用的波形现场 ​

三个页签各对应一类应用：积分器把方波「拉」成三角波（幅度随频率升高而缩）；有源低通的幅频曲线展示阶数与 QQQ 的性格；滞环比较器把带噪声的小信号整成方波，注意只有越过反方向阈值才翻转——这就是抗噪的机制。

工程实例：一条传感器信号链 ​

温度变送器把 Pt100 的电阻变化变成 4~20 mA 电流环，串起本章全部器件：

  1. 惠斯通电桥出 mV 级差分信号 → 仪表放大器（电压串联负反馈，第 6 章 · 放大电路中的反馈）放大到 V 级；
  2. 有源低通滤掉 50 Hz 工频与变频干扰（例 2）；
  3. 运放加法器叠加零点校正；
  4. V/I 变换器把电压变成 4~20 mA 恒流输出（电流反馈拓扑，第 6 章 · 放大电路中的反馈表格的「电流·串联」）；
  5. 接收端 250 Ω 采样电阻转回 1~5 V，过阈值由比较器报警。

五个环节没有一个是「分立计算」，全部是虚短虚断的排列组合。

易错清单 + 自检 ​

  • 积分器会饱和：输入有直流偏置时输出单向爬顶，最后被电源轨限幅——实用电路要在反馈电容上并一个大电阻限制直流增益。
  • 微分器恐高频也怕噪声：高频增益 ωRfC\omega R_fCωRf​C 反比例放大，输入端要加小电阻限带宽。
  • 有源滤波的运放不是无限的：f 接近运放 GBD 时「有源」失效，二阶以上滤波器设计必须核对运放带宽余量。
  • 比较器没有虚短：套虚短分析比较器是概念性错误，它是非线性应用。
  • 滞环的阈值与输出摆幅有关：输出被稳压管限幅在 ±Uz，改限幅值就改了阈值，别只调电阻。
