复数与相量运算 ​

卡片 约 5 min加减用代数型、乘除用极坐标；相量的模取有效值而不是峰值，这一处写错整体差 √2 倍

一句话结论：复数有代数型、三角型、指数型三种写法，加减只在代数型里做、乘除只在极坐标里做；把同频正弦量装进复数，就得到相量，而相量的模按电类学科的约定取有效值。

日常说法与正式定义 ​

  • 日常说法：复数像是「带方向的数」——3+j43+j43+j4 说的是「朝某个方向、长度 5 的一个量」。你在平面上看它是一个点：横向 3、纵向 4。
  • 正式定义：复数 A=a+jbA = a+jbA=a+jb 里，aaa 叫实部、bbb 叫虚部，jjj 是虚数单位（j2=−1j^2=-1j2=−1）。

为什么用 jjj 不用 iii：数学课本里虚数单位记作 iii，但在电路里 iii 已经被瞬时电流占用了。一个式子里同时出现电流 iii 和虚数单位 iii 就没法读，所以电类学科统一改用 jjj。这不是新数学，只是换了字母。详见符号与约定 · 虚数单位。

四种写法 ​

A=a+jb=∣A∣(cos⁡φ+jsin⁡φ)=∣A∣ejφ=∣A∣∠φA = a + jb = |A|(\cos\varphi + j\sin\varphi) = |A|e^{j\varphi} = |A|\angle\varphi A=a+jb=∣A∣(cosφ+jsinφ)=∣A∣ejφ=∣A∣∠φ

加减用代数型（a+jba+jba+jb），乘除用极坐标（∣A∣∠φ|A|\angle\varphi∣A∣∠φ）。 选错形式不是「算得慢」，是「根本算不出来」——两个极坐标形式的复数不能直接相加，因为它们的实部虚部没有对齐。

相量 ​

相量（phasor：用复数同时表示同频正弦量的有效值与相位）就是把同频正弦量的有效值当模、初相位当幅角，写成的复数：

U˙=U∠ψ\dot U = U\angle\psi U˙=U∠ψ

字母上方那个点号是全站统一的相量记号（有些书用粗体 U\mathbf UU 或下划线 U‾\underline UU​，含义相同）。三条读法必须记住：

  • U˙\dot UU˙ 的模是有效值，不是峰值——这是电类学科的约定，与数学里「复数模就是幅值」的习惯不同；
  • ∠\angle∠ 后面是初相位（初相角），单位默认度；
  • 相量不是时间函数，它不带 ttt。U˙≠u(t)\dot U \neq u(t)U˙=u(t) 永远不能画等号。

常见误解 ​

  1. 相量的模用峰值 → 结果整体差一个 2\sqrt22​ 倍 → 相量取有效值，瞬时表达式取幅值；去的时候除 2\sqrt22​，回来的时候乘 2\sqrt22​。
  2. 加减也用极坐标直接加模 → 相位丢了、模也不对 → 加减先转代数型，实部加实部、虚部加虚部。
  3. 用 arctan⁡\arctanarctan 算幅角时不分象限 → 实部为负时幅角差 180∘180^\circ180∘ → 先看实部符号，实部为负就把角加（或减）180∘180^\circ180∘。
  4. 把 jjj 读成电流 → 式子读不通 → jjj 是虚数单位，j2=−1j^2=-1j2=−1；电流写 iii 或 I˙\dot II˙。

例题 ​

例 1 · 复数换算与除法

题目：已知 Z=6+j8 ΩZ = 6+j8\ \OmegaZ=6+j8 Ω，电源相量 U˙=220∠0∘\dot U = 220\angle0^\circU˙=220∠0∘ V。求电流相量 I˙=U˙/Z\dot I = \dot U/ZI˙=U˙/Z，并给出它的代数型。

先想什么：这是相量法里最常见的动作——除法必须用极坐标。所以先把 ZZZ 从代数型转成极坐标。

步骤：

  1. 模与幅角：∣Z∣=62+82=10 Ω|Z| = \sqrt{6^2+8^2} = 10\ \Omega∣Z∣=62+82​=10 Ω，φ=arctan⁡86=53.1∘\varphi = \arctan\frac{8}{6} = 53.1^\circφ=arctan68​=53.1∘，所以 Z=10∠53.1∘ ΩZ = 10\angle53.1^\circ\ \OmegaZ=10∠53.1∘ Ω。（为什么先转极坐标：模相除、角相减是除法在极坐标下的形式，代数型下没有对应的除法。）
  2. 相除：I˙=220∠0∘10∠53.1∘=22∠−53.1∘ A\dot I = \dfrac{220\angle0^\circ}{10\angle53.1^\circ} = 22\angle{-53.1^\circ}\ \text{A}I˙=10∠53.1∘220∠0∘​=22∠−53.1∘ A。（角是「相减」：0∘−53.1∘=−53.1∘0^\circ-53.1^\circ=-53.1^\circ0∘−53.1∘=−53.1∘。）
  3. 转回代数型：22cos⁡(−53.1∘)=13.222\cos(-53.1^\circ) = 13.222cos(−53.1∘)=13.2，22sin⁡(−53.1∘)=−17.622\sin(-53.1^\circ) = -17.622sin(−53.1∘)=−17.6，得 I˙=13.2−j17.6 A\dot I = 13.2-j17.6\ \text{A}I˙=13.2−j17.6 A。

验算（反乘回去）：Z⋅I˙=(6+j8)(13.2−j17.6)=79.2+140.8+j(−105.6+105.6)=220+j0Z\cdot\dot I = (6+j8)(13.2-j17.6) = 79.2+140.8 + j(-105.6+105.6) = 220+j0Z⋅I˙=(6+j8)(13.2−j17.6)=79.2+140.8+j(−105.6+105.6)=220+j0，正是电源电压 220∠0∘220\angle0^\circ220∠0∘ ✓。

注意：电流滞后电压 53.1∘53.1^\circ53.1∘，负号表示滞后——这是感性电路的典型特征。
