磁路欧姆定律 ​

卡片 约 5 min形式同构但物性不同：铁磁材料的 μ 不是常数，所以磁阻不是常数；气隙的磁阻往往是铁心的上千倍

一句话结论：磁路和电路形式上完全同构：磁通 Φ\PhiΦ 对应电流 III，磁动势 F=NIF=NIF=NI 对应电动势 EEE，磁阻 RmR_mRm​ 对应电阻 RRR；于是 Φ=F/Rm\Phi = F/R_mΦ=F/Rm​。但铁磁材料的 μ\muμ 是非线性的，所以这个「欧姆定律」只在磁路基本不饱和时好用。

日常说法与正式定义 ​

  • 日常说法：磁通就像电流，磁动势像电压，磁阻像电阻。磁阻大的地方（空气隙）挡住磁通，磁阻小的地方（铁心）让磁通通过。
  • 正式定义：磁路是磁通经过的路径。磁路中：
Φ=FRm=NIlμS\Phi = \frac{F}{R_m} = \frac{NI}{\dfrac{l}{\mu S}} Φ=Rm​F​=μSl​NI​

符号含义单位

一一对应 ​

电路量磁路量
电流 III磁通 Φ\PhiΦ
电动势 EEE磁动势 F=NIF = NIF=NI
电阻 R=l/(γS)R = l/(\gamma S)R=l/(γS)磁阻 Rm=l/(μS)R_m = l/(\mu S)Rm​=l/(μS)
欧姆定律 I=E/RI = E/RI=E/RΦ=F/Rm\Phi = F/R_mΦ=F/Rm​

为什么能这样对应：两者都是「一个推动量 / 一个阻力 = 一个流量」。电流在高电阻的细导线里流得小，磁通在高磁阻的空气隙里也穿得少。

配套定律 ​

  • 安培环路定律（Ampère's law）：∮H dl=∑I\oint H\,dl = \sum I∮Hdl=∑I，即 Hl=NIHl = NIHl=NI
  • B=μHB = \mu HB=μH（磁感应强度 = 磁导率 × 磁场强度）
  • Φ=BS\Phi = BSΦ=BS（磁通 = 磁感应强度 × 截面积）

其中 HHH 是磁场强度（单位 A/m），BBB 是磁感应强度（单位 T，特斯拉）。安培环路定律说的是「磁场强度沿一条闭合回路的积分等于穿过的电流」——它和 KCL 一样是守恒律。

为什么气隙是主角 ​

铁心的 μ\muμ 很大（硅钢片 μr≈1000\mu_r \approx 1000μr​≈1000 甚至更高）→ 磁阻很小 → 磁通集中在铁心内；气隙的 μ\muμ 只有真空的量级（μ0=4π×10−7 H/m\mu_0 = 4\pi\times10^{-7}\ \text{H/m}μ0​=4π×10−7 H/m），所以哪怕只有零点几毫米，气隙也往往是磁阻的主要来源。

算一下就知道差多少：铁心长 0.2 m、截面积 10−4 m210^{-4}\ \text{m}^210−4 m2、气隙 0.5 mm。

Rm,铁=0.21000×1.257×10−6×10−4≈1.59×106 A/WbR_{m,铁} = \frac{0.2}{1000\times1.257\times10^{-6}\times10^{-4}} \approx 1.59\times10^{6}\ \text{A/Wb} Rm,铁​=1000×1.257×10−6×10−40.2​≈1.59×106 A/WbRm,隙=0.5×10−31.257×10−6×10−4≈3.98×106 A/WbR_{m,隙} = \frac{0.5\times10^{-3}}{1.257\times10^{-6}\times10^{-4}} \approx 3.98\times10^{6}\ \text{A/Wb} Rm,隙​=1.257×10−6×10−40.5×10−3​≈3.98×106 A/Wb

0.5 mm 的气隙，磁阻是 0.2 m 铁心的 2.5 倍。 这就是为什么电机、变压器的气隙长度是精密控制量。

常见误解 ​

  1. 把磁阻当成常数 → 算出的磁通偏大 → 铁磁材料的 μ\muμ 随磁场强度变化（磁导率不是常数），磁路饱和后磁阻显著变大。
  2. 以为磁通「走直线最短」 → 以为漏磁可以忽略 → 实际有漏磁通，绕组外面也有磁路；本章公式只算主磁通。
  3. 把 BBB 和 HHH 混为一谈 → 单位写错 → HHH 是 A/m、BBB 是 T，中间隔着 μ\muμ。
  4. 以为气隙可以忽略 → 磁通算得太大 → 恰恰相反，气隙常常是大头。
  5. 以为磁路也遵守「电压降 = 电压升」 → 混淆两个守恒律 → 磁路里对应的是安培环路定律（∮H dl=∑I\oint H\,dl = \sum I∮Hdl=∑I），不是 KVL。

例题 ​

例 1 · 气隙磁路求磁通

题目：一个 U 形铁心上绕 N=1000N=1000N=1000 匝线圈，线圈电流 I=0.5 AI=0.5\ \text{A}I=0.5 A。铁心平均长度 0.2 m，截面积 S=10−4 m2S=10^{-4}\ \text{m}^2S=10−4 m2，相对磁导率 μr=1000\mu_r=1000μr​=1000；铁心中间有一个 0.5 mm 的气隙。求磁通 Φ\PhiΦ 与气隙中的磁感应强度 BBB。

先想什么：气隙是磁阻的主体，所以铁心那一段虽然长，但贡献的磁阻只有气隙的 40% 左右，两者都要算，不能只算一个。

  1. 磁动势：F=NI=1000×0.5=500 A⋅匝F = NI = 1000\times0.5 = 500\ \text{A·匝}F=NI=1000×0.5=500 A⋅匝。（为什么先算 FFF：它是磁路的「电动势」，后面全靠它除以总磁阻。）
