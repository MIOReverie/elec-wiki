正弦量三要素 ​

卡片 约 5 min三个数定死一个正弦量；初相位只在同一时间原点下才有意义

一句话结论：一个正弦量由三个数完全确定——幅值（多大）、角频率（多快）、初相位（从哪儿起步）；换成有效值后，u(t)=2 Usin⁡(ωt+ψ)u(t) = \sqrt2\,U\sin(\omega t + \psi)u(t)=2​Usin(ωt+ψ)。

日常说法与正式定义 ​

  • 日常说法：描述一个摆动（或一个交流电压），得说清三件事——摆多大、摆多快、从哪个位置开始摆。少了任何一件，不同的摆就区分不开。
  • 正式定义：
u(t)=Umsin⁡(ωt+ψ)u(t) = U_m\sin(\omega t + \psi) u(t)=Um​sin(ωt+ψ)

角频率ω\omegaω变化快慢，单位 rad/sω=2πf=2π/T\omega = 2\pi f = 2\pi/Tω=2πf=2π/T

（fff 是频率 Hz，TTT 是周期 s；UUU 是有效值， 那一页讲过它怎么来。）

相位差：谁超前谁 ​

相位差 φ=ψu−ψi\varphi = \psi_u - \psi_iφ=ψu​−ψi​，只有同频的两个量才有意义：

  • φ>0\varphi > 0φ>0：uuu 超前 iii（感性负载，电压先到峰值）。
  • φ<0\varphi < 0φ<0：uuu 滞后 iii（容性负载，电流先到峰值）。
  • φ=0\varphi = 0φ=0：同相；φ=±90∘\varphi = \pm 90^\circφ=±90∘：正交。

常见误解 ​

  1. 「超前就是电压大」 → 超前说的是时间上的先后（谁先到峰值），与幅值无关。
  2. 「相位差可以随便比」 → 只有同频的量才能比相位。异频的两个量，相位差随时间变化，没有一个固定值。
  3. 「初相位是电压的性质」 → 它还取决于时间原点选在哪。同一个电压，换一个时间原点，ψ\psiψ 就变了，但物理过程没变。所以只有相位差是绝对的。
