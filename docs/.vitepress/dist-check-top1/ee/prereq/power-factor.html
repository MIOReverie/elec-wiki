功率因数 cosφ ​

卡片 约 5 mincosφ 是「容量利用率」：同样的变压器容量，cosφ 低就得多拉电流

一句话结论：功率因数 cos⁡φ=P/S\cos\varphi = P/Scosφ=P/S 是设备容量的利用率——同样一台变压器，cos⁡φ\cos\varphicosφ 越低，能送出的有功功率越少、线路电流越大。

日常说法与正式定义 ​

  • 日常说法：你雇了一辆卡车（容量），它拉了半车货（有用功），剩下的半车位置是空的，但车照样得付钱、照样在费油。空着的比例就是功率因数。
  • 正式定义：交流电路中电压与电流的相位差 φ\varphiφ 决定了三种功率的分配：
P=UIcos⁡φ[W]Q=UIsin⁡φ[var]S=UI[VA]P = UI\cos\varphi \quad[\text{W}] \qquad Q = UI\sin\varphi \quad[\text{var}] \qquad S = UI \quad[\text{VA}] P=UIcosφ[W]Q=UIsinφ[var]S=UI[VA]S2=P2+Q2cos⁡φ=PSS^2 = P^2 + Q^2 \qquad \cos\varphi = \frac{P}{S} S2=P2+Q2cosφ=SP​

三种功率的物理意义 ​

功率符号含义谁在用
有功功率PPP真正被消耗掉的（做功、发热）用户的活
无功功率QQQ在电源与储能元件之间来回交换的（建立磁场/电场必需）电感、电容
视在功率SSS电源需要提供的容量变压器铭牌

为什么必须提高 cos⁡φ\cos\varphicosφ ​

PPP 一定时，I=P/(Ucos⁡φ)I = P/(U\cos\varphi)I=P/(Ucosφ)。所以 cos⁡φ\cos\varphicosφ 越低：

  • 电流 III 越大 → 线路损耗 I2RI^2RI2R 越大、压降越大；
  • 视在功率 SSS 越大 → 变压器、导线、开关的容量被白白占掉。

常见误解 ​

  1. 「无功功率是浪费的电」 → 无功不做功，但它建立磁场与电场，是电感电容正常工作必需的。浪费的是容量和线路损耗，不是电能本身。
  2. 「功率因数低了，负载就多耗电了」 → 负载的 PPP 没变，多出来的是电网侧的损耗。责任在电网，但账单会反映出来。
  3. 「功率因数是电抗器的属性」 → 电机、变压器、荧光灯镇流器都是感性负载，天生 cos⁡φ\cos\varphicosφ 低；电容并联进去可以把滞后角抵消掉。

例题 ​

例 1 · 一台设备把功率因数从 0.8 提到 0.95 能省多少电流

题目：某感性负载接在 220 V、50 Hz 电源上，功率因数 0.8，电流 10 A。求有功功率；若并联电容把功率因数提到 0.95，电流变成多少？

先想什么：PPP 由负载决定，加电容前后不变；变的只有电流和容量。所以先算出 PPP，再反推新电流。（先认出「什么量没变」，题目就解了一半。）

步骤：

  1. 有功功率：P=UIcos⁡φ=220×10×0.8=1760 WP = UI\cos\varphi = 220 \times 10 \times 0.8 = 1760\ \text{W}P=UIcosφ=220×10×0.8=1760 W。（为什么先求 P：它是负载真正消耗的功率，也是补偿前后的不变量。）
  2. 补偿后电流：I′=P/(Ucos⁡φ′)=1760/(220×0.95)=8.42 AI' = P/(U\cos\varphi') = 1760/(220 \times 0.95) = 8.42\ \text{A}I′=P/(Ucosφ′)=1760/(220×0.95)=8.42 A。
  3. 线路电流下降 10−8.42=1.58 A10 - 8.42 = 1.58\ \text{A}10−8.42=1.58 A，约减少 16%。

验算：补偿后 S′=220×8.42=1853 VAS' = 220 \times 8.42 = 1853\ \text{VA}S′=220×8.42=1853 VA，小于原来的 2200 VA2200\ \text{VA}2200 VA ✓（容量被释放出来了）。再验算功率：1760=220×8.42×0.95=1759.6 W1760 = 220 \times 8.42 \times 0.95 = 1759.6\ \text{W}1760=220×8.42×0.95=1759.6 W，与补偿前一致 ✓。
