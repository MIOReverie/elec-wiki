串联谐振 ​

卡片 约 5 min谐振时电流最大，但电感和电容上的电压可能远大于电源电压

一句话结论：RLC 串联电路里感抗与容抗大小相等、符号相反、正好抵消，剩下的只有电阻——这就是谐振，电流最大但元件两端电压可能很高。

日常说法与正式定义 ​

  • 日常说法：一辆秋千，推它的力和拉它的力大小一样、方向相反，正好抵消，秋千就自己荡得最大幅。这时推它的人反而最省力，但绳子绷得比平时紧。
  • 正式定义：RLC 串联电路的感抗 XL=ωLX_L = \omega LXL​=ωL（电感对交流的阻碍，单位 Ω）与容抗 XC=1/(ωC)X_C = 1/(\omega C)XC​=1/(ωC)（电容的阻碍）大小相等时，电路发生串联谐振：
ω0=1LCf0=12πLC\omega_0 = \frac{1}{\sqrt{LC}} \qquad f_0 = \frac{1}{2\pi\sqrt{LC}} ω0​=LC​1​f0​=2πLC​1​

（ω0\omega_0ω0​ 是谐振角频率，f0f_0f0​ 是谐振频率；LLL 是电感、CCC 是电容，ω=2πf\omega = 2\pi fω=2πf。）

谐振时的三个特征 ​

  • X=XL−XC=0X = X_L - X_C = 0X=XL​−XC​=0，所以 Z=RZ = RZ=R 最小，电流 I=U/RI = U/RI=U/R 最大。
  • 电压与电流同相，电路整体呈纯阻性。
  • 电感和电容两端的电压 UL=UC=QUU_L = U_C = QUUL​=UC​=QU，可能远高于电源电压（所以又称电压谐振）。

品质因数与选择性 ​

Q=ω0LR=1ω0CR=1RLCBW=f2−f1=f0QQ = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{1}{R}\sqrt{\frac{L}{C}} \qquad BW = f_2 - f_1 = \frac{f_0}{Q} Q=Rω0​L​=ω0​CR1​=R1​CL​​BW=f2​−f1​=Qf0​​

QQQ 越大 → 谐振曲线越尖 → 选择性越好，但通频带越窄。（BWBWBW 是通频带宽度，f1f_1f1​、f2f_2f2​ 是上下限频率。）

常见误解 ​

  1. 「谐振时电源电压等于电感上的电压」 → 不等于。谐振时 UR=UU_R = UUR​=U，而 UL=UC=QUU_L = U_C = QUUL​=UC​=QU，两者在电源电压里互相抵消掉了。
  2. 「谐振时功率最大」 → 电流最大是对的，但有功功率 P=I2RP = I^2RP=I2R 最大这件事只对串联 RLC 成立；并联谐振恰好相反（阻抗最大、电流最小）。
  3. 「Q 越大越好」 → Q 大则选择性好、通频带窄，收音机调台要它；但电力系统的工频谐振电路常常需要窄带，反而要压低 Q。

例题 ​

例 1 · 求谐振频率与谐振时的电感电压

题目：R=10 ΩR = 10\ \OmegaR=10 Ω、L=100 mHL = 100\ \text{mH}L=100 mH 的电感线圈与 C=101.3 μFC = 101.3\ \mu\text{F}C=101.3 μF 的电容串联，接在 10 V10\ \text{V}10 V、50 Hz50\ \text{Hz}50 Hz 的电源上。求谐振频率、品质因数和谐振时电感上的电压。

先想什么：先确认电路已经在谐振点上（XLX_LXL​ 与 XCX_CXC​ 接近相等），然后才用谐振的三个特征。（先判断是否处在谐振，再套特征公式。）

步骤：

  1. 谐振频率：f0=1/(2πLC)=1/(2π0.1×101.3×10−6)≈50.0 Hzf_0 = 1/(2\pi\sqrt{LC}) = 1/(2\pi\sqrt{0.1 \times 101.3\times10^{-6}}) \approx 50.0\ \text{Hz}f0​=1/(2πLC​)=1/(2π0.1×101.3×10−6​)≈50.0 Hz。（为什么先算 f0f_0f0​：要确认工作频率就在谐振点上，否则后面全错。）
  2. 品质因数：Q=ω0L/R=2π×50×0.1/10=3.14Q = \omega_0 L/R = 2\pi \times 50 \times 0.1/10 = 3.14Q=ω0​L/R=2π×50×0.1/10=3.14。
  3. 谐振时电流：I=U/R=10/10=1 AI = U/R = 10/10 = 1\ \text{A}I=U/R=10/10=1 A。
  4. 电感电压：UL=QU=3.14×10=31.4 VU_L = Q U = 3.14 \times 10 = 31.4\ \text{V}UL​=QU=3.14×10=31.4 V。

验算：直接算感抗 XL=ωL=31.4 ΩX_L = \omega L = 31.4\ \OmegaXL​=ωL=31.4 Ω、容抗 XC=1/(ωC)=31.4 ΩX_C = 1/(\omega C) = 31.4\ \OmegaXC​=1/(ωC)=31.4 Ω，两者相等 ✓，确实谐振。谐振时总电压 UR2+(UL−UC)2=102+02=10 V\sqrt{U_R^2 + (U_L - U_C)^2} = \sqrt{10^2 + 0^2} = 10\ \text{V}UR2​+(UL​−UC​)2​=102+02​=10 V，与电源相符 ✓。
