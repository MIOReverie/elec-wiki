15 · 变压器 ​

核心 约 40 min三条关系（变电压、变电流、变阻抗）+ 两种试验（空载、短路）就是全部

这一页要解决什么 ​

你带着「变压器凭什么能改变电压、又不让两边直接连通」的疑问进来。读完你能用三个比例式讲清变电压、变电流、变阻抗，看懂空载试验与短路试验各测出什么损耗，并能在铭牌上直接算出额定电流、效率和电压调整率。

读这页之前

  • 需要会：磁路的磁通势与磁阻（）、交流阻抗与相量（）
  • 这一页用到的符号：kkk、SNS_NSN​、PFeP_{Fe}PFe​、PCuP_{Cu}PCu​、β\betaβ，含义见符号与约定

变压器是磁路知识第一个「能挣钱」的应用：用磁通把能量从一级传到另一级，两边没有电的联系。它把上一页的磁路公式变成了工程上天天用的三件事——变电压、变电流、变阻抗。先把这三件事一次性摆在台面上。

结论先行 ​

U1U2≈N1N2=kI1I2≈1kZin=k2ZL\boxed{\frac{U_1}{U_2}\approx\frac{N_1}{N_2}=k\qquad \frac{I_1}{I_2}\approx\frac{1}{k}\qquad Z_{in}=k^2Z_L} U2​U1​​≈N2​N1​​=kI2​I1​​≈k1​Zin​=k2ZL​​
  1. 变电压、变电流、变阻抗 —— 后者是阻抗匹配和电子电路级联的基础
  2. 只能变交流，不能变直流（靠磁通变化感应电动势）
  3. 空载电流 I0I_0I0​ 很小（只负责励磁）；负载后 I1I_1I1​ 自动跟随 I2I_2I2​（磁动势平衡）
  4. 额定容量 SN=U2NI2NS_N = U_{2N}I_{2N}SN​=U2N​I2N​，单位 VA（视在功率，不是 W）
  5. 效率 η=P2/(P2+PFe+PCu)\eta = P_2/(P_2+P_{Fe}+P_{Cu})η=P2​/(P2​+PFe​+PCu​)，最大效率在铁损 = 铜损处

一、工作原理：先有磁通，后有电压 ​

u₁ → 励磁电流 i₀ → 交变主磁通 Φ（在铁心里闭合）
                        ├→ 原边感应 e₁ = −N₁dΦ/dt
                        └→ 副边感应 e₂ = −N₂dΦ/dt

两边绕组套在同一个铁心上，同一个 Φ\PhiΦ 变化，按法拉第定律感应出与匝数成正比的电动势：

U1≈E1=4.44fN1Φm,U2≈E2=4.44fN2ΦmU_1 \approx E_1 = 4.44fN_1\Phi_m,\qquad U_2 \approx E_2 = 4.44fN_2\Phi_m U1​≈E1​=4.44fN1​Φm​,U2​≈E2​=4.44fN2​Φm​

两式相除：

U1U2≈N1N2=k\frac{U_1}{U_2}\approx\frac{N_1}{N_2}=k U2​U1​​≈N2​N1​​=k

4.44 是哪来的

正弦量 e=−NdΦdte = -N\dfrac{d\Phi}{dt}e=−NdtdΦ​，Φ=Φmsin⁡ωt\Phi = \Phi_m\sin\omega tΦ=Φm​sinωt → e=NωΦmcos⁡ωte = N\omega\Phi_m\cos\omega te=NωΦm​cosωt，幅值 Em=NωΦm=2πfNΦmE_m = N\omega\Phi_m = 2\pi fN\Phi_mEm​=NωΦm​=2πfNΦm​。有效值 E=Em/2=4.44fNΦmE = E_m/\sqrt2 = 4.44fN\Phi_mE=Em​/2​=4.44fNΦm​。

为什么不能变直流 ​

直流下 Φ\PhiΦ 恒定 → dΦdt=0\dfrac{d\Phi}{dt} = 0dtdΦ​=0 → 没有感应电动势。原边加上额定直流电压时，原边电流只受绕组电阻限制（I=U/RaI = U/R_aI=U/Ra​，电阻很小）→ 电流巨大 → 烧毁。这是变压器事故的常见原因。

二、磁动势平衡：电流为什么跟着变 ​

空载时原边只有励磁电流 i0i_0i0​（约为额定电流的 2%~10%）。副边带负载后出现 i2i_2i2​，它产生的磁动势 N2i2N_2i_2N2​i2​ 削弱主磁通；主磁通一削弱，原边感应电动势 e1e_1e1​ 就下降，而 u1u_1u1​ 由电源钉着不变 → i1i_1i1​ 自动增大，补偿 N2i2N_2i_2N2​i2​ 的去磁作用：

N1I˙1+N2I˙2≈N1I˙0N_1\dot I_1 + N_2\dot I_2 \approx N_1\dot I_0 N1​I˙1​+N2​I˙2​≈N1​I˙0​

负载运行时 I0I_0I0​ 很小，忽略：

I1I2≈N2N1=1k\boxed{\frac{I_1}{I_2}\approx\frac{N_2}{N_1}=\frac{1}{k}} I2​I1​​≈N1​N2​​=k1​​

关键图像：副边多要一份功率，原边就自动从电源多取一份 —— 功率（近似）无损传递，U1I1≈U2I2U_1I_1 \approx U_2I_2U1​I1​≈U2​I2​。

三、阻抗变换：电子电路里最常用的一条 ​

副边接负载 ZLZ_LZL​，从原边看进去的等效阻抗：

Zin=U˙1I˙1=kU˙2I˙2/k=k2U˙2I˙2=k2ZLZ_{in} = \frac{\dot U_1}{\dot I_1} = \frac{k\dot U_2}{\dot I_2/k} = k^2\frac{\dot U_2}{\dot I_2} = k^2 Z_L Zin​=I˙1​U˙1​​=I˙2​/kkU˙2​​=k2I˙2​U˙2​​=k2ZL​

为什么需要阻抗匹配

还记得"负载 = 源内阻时传输功率最大"吗？实际信号源内阻往往固定（如天线 75 Ω、话筒 600 Ω），负载侧也是固定的（扬声器 8 Ω）。变压器的 k2k^2k2 就是那个"任意可调的变阻器" —— 不消耗功率，只改变阻抗的表观值。

四、外特性、损耗与效率 ​

从电路看变压器：T 型等效 ​

把副边按变比折算到原边后，一台变压器就变成「两个阻抗串一个励磁支路」——漏阻抗决定电压掉落，励磁支路决定空载电流：

心智模型：折算 —— 把副边「搬」到原边

这是本章隐含的思维切换：副边的 R2、X2、ZLR_2、X_2、Z_LR2​、X2​、ZL​ 按变比折算到原边侧（R2′=k2R2R_2'=k^2R_2R2′​=k2R2​、I2′=I2/kI_2'=I_2/kI2′​=I2​/k），两套绕组就并成一条回路、一个电流，KVL 直接能用。前面的 Zin=k2ZLZ_{in}=k^2Z_LZin​=k2ZL​ 只是这条规则的一个特例；有了它，电压调整率、效率、短路阻抗全都归结到对这张图列方程。

负载后副边电压会掉（原边漏阻抗上的压降）：

ΔU%=U20−U2U20×100%\Delta U\% = \frac{U_{20}-U_2}{U_{20}}\times100\% ΔU%=U20​U20​−U2​​×100%

五、两种试验：不拆变压器就能测出全部参数 ​

试验接线测什么
空载试验副边开路，原边加额定电压铁损 PFeP_{Fe}PFe​、励磁阻抗、变比 kkk
短路试验副边短路，原边加低电压到额定电流铜损 PCuNP_{CuN}PCuN​、短路阻抗、ΔU%\Delta U\%ΔU%

为什么空载试验要在原边做、短路试验要用低压

空载试验测的是铁损，需要额定磁通 → 必须加额定电压（低压侧加更安全，故通常在低压侧做）。短路试验测的是铜损，此时磁通很小、铁损可忽略，只需让电流达到额定 —— 加很低的电压就够（否则电流会烧毁绕组）。

例 1 · 三条关系（基础题）

单相变压器 SN=10S_N = 10SN​=10 kVA，U1N/U2N=6000/230U_{1N}/U_{2N} = 6000/230U1N​/U2N​=6000/230 V。求变比 kkk、额定电流 I1NI_{1N}I1N​、I2NI_{2N}I2N​。

例 2 · 阻抗匹配（电子题）

一只 8 Ω 扬声器要通过变压器接到内阻 200 Ω 的信号源上，实现匹配。求变比。

先想什么：匹配的意思是「让源看到的内阻 = 源自身的电阻」，这样源能输出最大功率。变压器不改变功率，但能把副边的 ZLZ_LZL​ 折算到原边成 k2ZLk^2Z_Lk2ZL​；所以直接令 k2ZL=Rsk^2Z_L = R_sk2ZL​=Rs​，解出 kkk。一句话：把 8 Ω 用 k2k^2k2 放大到 200 Ω，而不是反过来除。

Zin=k2ZL=200 ΩZ_{in} = k^2Z_L = 200\ \Omega Zin​=k2ZL​=200 Ωk2=2008=25  ⇒  k=5k^2 = \frac{200}{8} = 25 \;\Rightarrow\; k = 5 k2=8200​=25⇒k=5

即 N1:N2=5:1N_1:N_2 = 5:1N1​:N2​=5:1（降压，副边接扬声器）。

本题的工程味道

电子电路里讲「匹配」通常就是为了这一条。注意：变压器本身不产生功率，它只是让源「愿意」多送 —— 总效率仍受铁损铜损限制（大信号时约 80%~95%）。

例 4 · 电压调整率（标幺值算法）

一台变压器漏阻抗标幺值 R∗=0.02R_* = 0.02R∗​=0.02、X∗=0.05X_* = 0.05X∗​=0.05，β=1\beta = 1β=1。分别求 cos⁡φ=1\cos\varphi = 1cosφ=1、cos⁡φ=0.8\cos\varphi = 0.8cosφ=0.8（感性）、cos⁡φ=0.8\cos\varphi = 0.8cosφ=0.8（容性）时的电压调整率。

先想什么：电压调整率本质是漏阻抗压降在输出电压上的占比，公式 ΔU∗=β(R∗cos⁡φ+X∗sin⁡φ)\Delta U_*=\beta(R_*\cos\varphi+X_*\sin\varphi)ΔU∗​=β(R∗​cosφ+X∗​sinφ) 里只有 sin⁡φ\sin\varphisinφ 一项随负载性质变号——感性正、容性负。所以三问只是换 sin⁡φ\sin\varphisinφ 的正负，套同一个式子即可，别把容性想成另一套算法。

解

标幺值公式：

负调整率的后果

容性负载会把副边电压抬起来。长线路轻载时（线路电容效应）会出现末端电压升高，这就是为什么有些场合要装并联电抗器吸收无功来压电压。

工程实例 ​

配电变压器半夜为什么「嗡嗡」响还发热？ 工业区夜里负载极低（β→0\beta \to 0β→0），但铁损一分不少 —— 空载损耗占全天损耗的比例反而上升。所以现在推广的非晶合金变压器就是拼命压铁损（空载损耗比硅钢片低 60%~80%）。

家里为什么不能用自耦变压器调 220 V？ 自耦变压器一、二次有电气连接，副边电压调得过低时，「220 V 侧」可能带着火线对地电压出现在旋钮或外壳上 —— 触电风险。调压台架用自耦的场合必须让专业人员操作并可靠接地。
