项目三 · 双轴舵机云台 ​

核心 约 70 min云台的难点不在代码——两个定时器通道就够；难点在「两根独立电源的地连在一起」这一句话上

前两个项目（电源、电机驱动）都是「造一台机器」。这个项目更像「调一台仪器」：舵机内部已经有完整的闭环（位置环），你唯一要负责的是给它一个宽度准确的脉冲、一个扛得住堵转的电源、一个合理的地。这三件事任何一件做歪了，表现出来的都是同一个症状：抖。

舵机的原理、内部结构、PSC/ARR/CCR 换算与烧板原因，在嵌入式 13 · 舵机控制里已经写得极细，本页不重复，只做云台特有的三件事：两路 PWM 怎么共存、两轴坐标怎么映射成角度、以及「已经抖了该怎么排查」。定时器的寄存器层面见 与 。

结论先行 ​

  1. 两轴必须共用同一个定时器的两个通道：频率天然一致（同 ARR），脉宽各自独立（各自的 CCR）。用两个定时器反而要担心频率漂移与相位不一致。
  2. 50 Hz 是硬指标，脉宽 0.5–2.5 ms 是软指标：频率偏 17% 大多数舵机能忍，但脉宽算错 1 µs 就是 0.1°，算错 100 µs 就是 10°。所以代码里只能用「绝对脉宽」，绝不能用「占空比百分比」。
  3. 云台必须独立 5 V 供电，且与 STM32 共地：两路 MG996R 同时堵转能到 5 A，任何开发板 LDO 都扛不住；而不共地时，信号线会成为唯一电流回路，几十毫安灌进 IO 就能烧 MCU。
  4. 校准是三个数字，不是两个：机械限位（不能撞）、脉宽极值（p_min/p_max）、中位（p_mid）。三者不重合时，必须在软件里取交集，否则某个角度上舵机会顶墙堵转，电流飙到 2.5 A。
  5. 坐标到角度是两段 atan2：水平角 α=atan2⁡(x,y)\alpha=\operatorname{atan2}(x, y)α=atan2(x,y)，俯仰角 β=atan2⁡(h,x2+y2)\beta=\operatorname{atan2}(h, \sqrt{x^2+y^2})β=atan2(h,x2+y2​)，再按各自量程线性映射到脉宽。
  6. 抖动 90% 来自供电：3 节 0.1 mm² 杜邦线在 2.5 A 上往返压降就是 0.17 V，加上电源本身的线损与内阻，瞬间跌破 4.8 V → 舵机内部 MCU 复位 → 重新定位。换粗线、加 4700 µF、换大电源，比改任何一行代码都有用。

一、机械结构：两轴的顺序 ​

云台的拓扑有两种：水平轴在下、俯仰轴在上（yaw-on-top），或者俯仰轴在下、水平轴在上（pitch-on-top）。

本页采用的标准结构：

底座 ── ① 水平旋转舵机（pan，绕竖直轴）
          └── ② U 形支架（随 pan 一起转）
                └── ③ 俯仰舵机（tilt，绕水平轴）
                      └── ④ 载荷（摄像头 / 激光笔 / 传感器）

关键权衡：① 号舵机（pan）要承受整个上方结构的重量，② 号（tilt）只需要承受载荷本身的重量。所以：

  • 如果载荷很重（> 500 g），把大扭矩的舵机放在下面；
  • 如果载荷很轻但要求俯仰范围大，俯仰舵机可以被设计在支架两侧双出轴布置，受力对称。

1.1 扭矩要留多少余量 ​

载荷 200 g、重心距俯仰轴 5 cm，静态扭矩：

T=mgr=0.2×9.8×0.05=0.098 N⋅m≈1.0 kg⋅cmT = m g r = 0.2 \times 9.8 \times 0.05 = 0.098\ \text{N·m} \approx 1.0\ \text{kg·cm} T=mgr=0.2×9.8×0.05=0.098 N⋅m≈1.0 kg⋅cm

SG90 标称 1.8 kg·cm（4.8 V），看起来够，但那是堵转扭矩，实际可用不到一半，而且瞬间加速还要额外力矩。因此：

载荷推荐舵机理由
< 100 g（小摄像头、激光笔）SG90 × 21.8 kg·cm 够用，轻
100–400 g（手机、小型传感器）MG996R × 29.4 kg·cm，金属齿轮
> 400 g数字舵机（20 kg·cm 以上）塑料齿轮会被瞬间力矩打滑

1.2 打印 / 加工要点 ​

  • 齿轮轴的受力方向不能垂直于输出轴：舵机输出轴是轴承支撑的，径向受力没问题；轴向外推会压坏齿轮。载荷重心应尽量落在轴线附近；
  • U 形支架的配合间隙 0.2–0.4 mm：太松会晃（抖），太紧会卡（堵转发热）；
  • 舵机用自攻螺丝 + 减振垫，不要只用热熔胶；
  • 走线要留余量：pan 转 180° 时，从底座到 tilt 的线要绕成「螺旋」，否则会被拉断。

二、两路 50 Hz PWM ​

2.1 参数只要一张表 ​

两个通道共享一个定时器、同一个 ARR，脉宽由各自的 CCR 决定。以 1 µs 计数为例（下表是嵌入式 13那张表的展开，三个主频的情况都列上）：

主频（APB1 定时器 ×2 后）PSCfcntf_{cnt}fcnt​ARR周期脉宽步进
72 MHz（F103）711 MHz1999920 ms1 µs = 0.1°
84 MHz（F407 默认）831 MHz1999920 ms1 µs = 0.1°
168 MHz（F407 + HSE）1671 MHz1999920 ms1 µs = 0.1°

验算：72e6/(71+1) = 1e6，1e6/20000 = 50 Hz；84e6/84 = 1e6；168e6/168 = 1e6。三行频率都是 50 Hz ✓。

想要更细的步进：0.5 µs 计数（PSC = 35 / 41 / 167 的一半），ARR = 39999。此时 CCR 的范围是 1000–5000（对应 0.5–2.5 ms）。但舵机本身的死区就有 5–10 µs，再细的脉宽分辨率也没有意义——0.5 µs 只对「多轴同步」有用。

2.2 引脚分配 ​

以 STM32F103C8T6 为例，用 TIM3 的 CH1 与 CH2：

舵机信号STM32 引脚通道
pan（水平）PWM 1PA6TIM3_CH1
tilt（俯仰）PWM 2PA7TIM3_CH2
编码器/别的——注意 PA6/PA7 也被 TIM3 的编码器占用，不能同时用

2.3 代码：两轴接口 ​

c
/* ============ 舵机 PWM：两轴共用 TIM3 ============ */
#define SERVO_PERIOD   19999        /* ARR */
#define P_MIN          500          /* 脉宽下限 0.5 ms（1 µs 计数） */
#define P_MAX          2500         /* 脉宽上限 2.5 ms */
#define P_MID          1500         /* 中位 1.5 ms */

/* 每度对应的 CCR：默认 10 µs/°（即 2000 µs 走 180°） */
static const int16_t s_ccr_per_deg[2] = { 10, 10 };
/* 校准后的限位：单位是 CCR，不是度 */
static int16_t s_lim_lo[2] = { 500, 500 };
static int16_t s_lim_hi[2] = { 2500, 2500 };

/* 把角度钳到机械允许的范围，再换 CCR */
static uint16_t angle_to_ccr(int axis, int16_t deg)
{
    int32_t ccr = P_MID + (int32_t)deg * s_ccr_per_deg[axis];
    if (ccr < s_lim_lo[axis]) ccr = s_lim_lo[axis];
    if (ccr > s_lim_hi[axis]) ccr = s_lim_hi[axis];
    return (uint16_t)ccr;
}

void Servo_Set(int axis, int16_t deg)
{
    if (axis == 0)
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, angle_to_ccr(0, deg));
    else
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, angle_to_ccr(1, deg));
}

/* 上电：先写中位再启输出，避免初始化瞬间输出 0 脉宽让摇臂撞到底 */
void Servo_Init(void)
{
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, P_MID);
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, P_MID);
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_2);
}

平滑：50 Hz 下每 20 ms 才能更新一次

舵机每个周期只认一次脉宽，所以你能做到的最大角速度由舵机本身决定：MG996R 6 V 下 0.17 s 转 60°，90° 需要 0.17×1.5 = 0.255 s，也就是每秒约 353°，每 20 ms 约 7°。如果代码以 100 Hz 写 CCR，多写的几次不会带来任何效果；如果一次跳 90°，舵机会全速冲过去，瞬间电流拉满 → 电源跌落 → 抖动。正确做法是把大角度分成每 20 ms 不超过 7° 的小步。

三、电源：独立 5 V 与共地 ​

3.1 电流账 ​

SG90（4.8–6 V）100–220 mA300–500 mA650 mA

两只 MG996R 同时堵转 = 5 A。这比大多数 5 V 模块的额定电流高一个数量级。选择电源时按「两路堵转之和 × 1.2」：

  • 两只 SG90：0.65×2×1.2=1.56 A0.65\times2\times1.2 = 1.56\ \text{A}0.65×2×1.2=1.56 A → 5 V / 2 A 模块
  • 两只 MG996R：2.5×2×1.2=6 A2.5\times2\times1.2 = 6\ \text{A}2.5×2×1.2=6 A → 5 V / 6 A 以上，不建议用（太贵），改为「一个 5 V 5 A 工业模块」并要求两轴不同时到达限位

实际使用时，舵机很少同时堵转，所以 5 V / 3 A 通常够用——但如果你让两轴同时顶在极限位置，3 A 就不够了。

3.2 接线 ​

5 V 独立电源（≥ 3 A） ─┬── 4700 µF 电解（靠近舵机）
                       ├── 0.1 µF 陶瓷（紧贴舵机电源脚）
                       ├── pan  舵机 VCC
                       ├── tilt 舵机 VCC
                       └── GND ──┬── pan GND
                                 ├── tilt GND
                                 └── STM32 GND（必须连！）

STM32 PA6 ── pan  舵机 信号（橙/黄线）
STM32 PA7 ── tilt 舵机 信号（橙/黄线）

为什么必须共地：舵机内部比较脉宽时，把「高电平」与「它自己的 GND」比较。如果 STM32 的地与舵机的地分开，两者之间可能存在几百毫伏的电位差，脉宽判断会偏移——表现为「角度轻微不准」「偶发乱跳」「一开串口就抖」。

3.3 线材：被低估的 0.17 V ​

杜邦线的导体截面积只有 0.1 mm² 左右。铜的电阻率 1.7×10−8 Ω⋅m1.7\times10^{-8}\ \Omega\cdot\text{m}1.7×10−8 Ω⋅m，20 cm 往返（0.4 m）的电阻：

R=ρ lA=1.7×10−8×0.40.1×10−6=0.068 ΩR = \frac{\rho \, l}{A} = \frac{1.7\times10^{-8}\times0.4}{0.1\times10^{-6}} = 0.068\ \Omega R=Aρl​=0.1×10−61.7×10−8×0.4​=0.068 Ω

2.5 A 堵转时的压降：

ΔU=IR=2.5×0.068=0.17 V\Delta U = I R = 2.5 \times 0.068 = 0.17\ \text{V} ΔU=IR=2.5×0.068=0.17 V

换成 0.5 mm² 的线，同一长度只有 0.034 V。对于一个「最低工作电压 4.8 V」的舵机来说，从 5.0 V 掉到 4.83 V 就已经越线了——只要还叠加一点电源线损与电池内阻，就会跌破。

线材20 cm 往返电阻2.5 A 压降
0.1 mm² 杜邦0.068 Ω0.17 V
0.26 mm²0.026 Ω0.065 V
0.5 mm²0.014 Ω0.034 V

结论：舵机电源线不要用杜邦线。用 0.5 mm² 的硅胶线，焊到电源模块上，长度越短越好。

3.4 电容能顶多久 ​

4700 µF 在 2.5 A 的冲击下，从 5.0 V 放到 4.2 V（0.8 V 余量）能撑：

t=C ΔUI=4700×10−6×0.82.5=1.5 mst = \frac{C\,\Delta U}{I} = \frac{4700\times10^{-6}\times0.8}{2.5} = 1.5\ \text{ms} t=ICΔU​=2.54700×10−6×0.8​=1.5 ms

这只够覆盖 PWM 周期内的电流尖峰（20 ms 内的高频部分），远不够应对启动时的 100 ms 级电流冲击。电容是「补细节」，电源才是「担大梁」。

四、校准：三个数字 ​

4.1 校准的是什么 ​

舵机的规格书写「0.5–2.5 ms 对应 0–180°」，但每一只舵机的实际对应关系都不同：有的中位在 1.48 ms，有的在 1.52 ms；有的打死在 2.35 ms，有的在 2.6 ms；齿轮比差一点、电位器装配偏一点，都会改变。

校准就是为每一只舵机求出三个数字：

参数含义怎么得到
p_min能转到的最小脉宽从 1500 开始每次减 25 µs，直到听到「嗡嗡」电流声（顶墙）为止，退回去两档
p_max能转到的最大脉宽同理往上加
p_mid中位舵机规格书给的中位 ±100 µs 范围内，取「机械对称点」

校准顺序很重要：先用小幅度、慢速度试探，不要一上来就给 500 或 2500——顶墙堵转 2 秒就可能把齿轮磨坏。

4.2 校准代码 ​

c
/* 交互式校准：串口输入脉宽（µs），回车发送 */
void Servo_CalibrateStep(void)
{
    static int16_t pw = 1500;
    char buf[8];
    if (uart_readline(buf, sizeof buf)) {
        int v = atoi(buf);
        if (v == 0) {                       /* 输入 0 = 回中位 */
            pw = 1500;
        } else if (v >= 400 && v <= 2600) { /* 只允许安全窗口 */
            pw = v;
        }
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, pw);
        printf("pw=%d us\n", pw);
    }
}

4.3 校准后的限位与死区 ​

把三个数字写进固件，并且只允许在 [p_min, p_max] 内输出：

c
#define PAN_P_MIN  520      /* 校准值示例 */
#define PAN_P_MAX  2380
#define PAN_P_MID  1480
#define TILT_P_MIN 600      /* tilt 机械范围只有 -20°~+70° */
#define TILT_P_MAX 2200
#define TILT_P_MID 1400

死区是舵机内部的一个容差窗口（典型 5–10 µs）：目标与当前位置的差在死区以内时，电机不动。死区 5 µs 对应 0.5°，10 µs 对应 1°。这是舵机的静态精度极限，再怎么调都调不到 0.1° 的重复定位。

机械限位要独立于脉宽限位

很多云台的支架本身有物理限位（比如 U 形支架挡住 tilt 不能超出 −20°）。软件里的 p_min/p_max 必须比机械限位更保守，否则脉宽还没到舵机的极限、支架已经顶死了——这时候舵机还在加扭矩，电流飙升，齿轮打滑。取三者的交集：舵机限位 ∩ 支架限位 ∩ 载荷不碰底座。

五、坐标到角度：两段 atan2 ​

5.1 模型 ​

设云台底座为原点，xxx 向右、yyy 向前、hhh 向上，目标是 (x,y,h)(x, y, h)(x,y,h)。

  • 水平角（pan）是目标在水平面上的方位角：
α=atan2⁡(x, y)\alpha = \operatorname{atan2}(x,\ y) α=atan2(x, y)
  • 俯仰角（tilt）是目标相对水平面的仰角，需要先求水平距离：
R=x2+y2,β=atan2⁡(h, R)R = \sqrt{x^2 + y^2},\qquad \beta = \operatorname{atan2}(h,\ R) R=x2+y2​,β=atan2(h, R)

用 atan2 而不是 atan(h/R) 是为了同时处理四个象限，而且 R = 0 时不会除零（atan2(h, 0) 直接给 ±90°）。

5.2 算例 ​

例 1 · 把目标点换算成两轴脉宽

题干：目标位于 x=1.5 mx = 1.5\ \text{m}x=1.5 m、y=2.0 my = 2.0\ \text{m}y=2.0 m、h=0.4 mh = 0.4\ \text{m}h=0.4 m。pan 舵机的量程是 ±90°\pm90°±90°（脉宽 600–2400 µs），tilt 舵机的机械限位是 −20°-20°−20° 到 +70°+70°+70°（脉宽 1300–2200 µs）。求两轴的角度与 CCR。

第 1 步：水平角

α=atan2⁡(1.5,2.0)=36.87°\alpha = \operatorname{atan2}(1.5, 2.0) = 36.87° α=atan2(1.5,2.0)=36.87°

第 2 步：水平距离与俯仰角

R=1.52+2.02=6.25=2.5 mR = \sqrt{1.5^2 + 2.0^2} = \sqrt{6.25} = 2.5\ \text{m} R=1.52+2.02​=6.25​=2.5 mβ=atan2⁡(0.4,2.5)=9.09°\beta = \operatorname{atan2}(0.4, 2.5) = 9.09° β=atan2(0.4,2.5)=9.09°

第 3 步：角度换 CCR（10 µs/°，中位 1500）

CCRpan=1500+36.87×10=1868.7⇒1869CCR_{pan} = 1500 + 36.87 \times 10 = 1868.7 \Rightarrow \mathbf{1869} CCRpan​=1500+36.87×10=1868.7⇒1869CCRtilt=1500+9.09×10=1590.9⇒1591CCR_{tilt} = 1500 + 9.09 \times 10 = 1590.9 \Rightarrow \mathbf{1591} CCRtilt​=1500+9.09×10=1590.9⇒1591

第 4 步：检查限位

1869 在 600–2400 内 ✓；1591 在 1300–2200 内 ✓。两个都在安全区，可以直接下发。

node 验算：Math.atan2(1.5,2.0)*180/Math.PI = 36.870，Math.hypot(1.5,2)=2.5，Math.atan2(0.4,2.5)*180/Math.PI = 9.090，1500+36.87*10 = 1868.7。

为什么这么想 把「角度」与「脉宽」分开算、而不是直接在一个大公式里一步到位，是为了能在第 4 步看见限位检查的位置。真实项目里，90% 的舵机损坏发生在「角度算对了、但忘了钳位」的那一刻。

5.3 代码 ​

c
#include <math.h>

typedef struct { float x, y, h; } Point3;

/* 返回 0 成功，-1 表示目标在云台后方、不可达 */
int Gimbal_AimAt(Point3 target)
{
    float R  = sqrtf(target.x * target.x + target.y * target.y);
    float a  = atan2f(target.x, target.y) * 57.29578f;   /* 转成度 */
    float b  = atan2f(target.h, R) * 57.29578f;

    if (target.y < 0.0f) return -1;      /* 目标在云台背后，pan 无法指向 */

    /* 限位取「舵机量程 ∩ 机械限位」 */
    if (a < -90.0f) a = -90.0f;
    if (a >  90.0f) a =  90.0f;
    if (b < -20.0f) b = -20.0f;
    if (b >  70.0f) b =  70.0f;

    Servo_Set(0, (int16_t)lroundf(a));
    Servo_Set(1, (int16_t)lroundf(b));
    return 0;
}

别用 int 做角度运算

atan2f 返回的是浮点数，lroundf 之后再转整型是对的；但如果把 float 直接赋给 int16_t，小数部分会被截断而不是四舍五入，于是 ±0.5° 的系统偏差就出现了。在 10 µs/° 的映射下，0.5° 就是 5 µs 的脉宽误差——刚到死区边缘。

六、抖动与电源跌落排查 ​

6.1 抖动的四种来源 ​

「抖」是云台最常见的故障，但它的成因分属四个完全不同的层次。按「先排除最简单、最可能」的顺序：

层次现象特征排除方法
电源每次加速或到极限时抖，MCU 偶尔复位示波器看 5 V 轨；换粗线、加大电容、加大电源
地一开串口就抖，角度轻微偏量 STM32 GND 与舵机 GND 之间的电压，应 < 10 mV
信号脉宽不准、频率不对示波器看 PWM 引脚，测周期与高电平宽度
机械静止时周期性微抖，载荷晃动加固支架、减小间隙、减重

6.2 一个标准的排查顺序 ​

  1. 断电，量地：万用表直流毫伏档，红表笔 STM32 GND、黑表笔舵机 GND，读数应 ≤ 10 mV。若达到 100 mV，说明两地不在同一个回路上。
  2. 上电，空载测 PWM：示波器接 PA6，测周期 20 ms ± 0.5 ms、高电平 1.5 ms ± 0.1 ms。不对就改 PSC/ARR。
  3. 带载测 5 V：示波器（交流耦合）看电源模块输出，舵机运动时跌落 ≤ 0.2 V。超过就换电源或加电容。
  4. 单轴测试：先只驱动 pan，再只驱动 tilt，观察哪一轴出问题——常常是特定角度堵转。
  5. 拆负载：把载荷取下再测。如果空载不抖、带载才抖，就是扭矩或机械问题，而不是电的问题。

6.3 反直觉的一条：抖的不一定是舵机 ​

舵机内部的控制板会在电压跌落时复位，复位后它重新上电、重新解码脉宽，于是猛跳回中位再走向目标。你看到的「抖」其实是「复位 → 重定位」的循环。所以排查抖动时，先看 5 V 轨有没有掉，而不是先去调 PID 或改代码。

九、调试：四步 ​

第 1 步：空载测 PWM ​

  • 做什么：不装舵机，示波器接 PA6/PA7。
  • 合格判据：周期 20.0 ms ± 0.5 ms；Servo_Set(0, 0) 时高电平 1.5 ms ± 50 µs。
  • 不合格：周期 40 ms → ARR 写成了 39999；周期 10 ms → PSC 少一半；高电平宽度不变 → 两个通道连到了同一个 CCR。

第 2 步：单只舵机、中位 ​

  • 做什么：只接 pan 舵机，上电即 1500。
  • 合格判据：摇臂停在几何中位（目测）、不发热。
  • 不合格：一上电就撞向一端 → 中位脉宽不对或舵机内部中位偏移，需校准；持续发热 → 顶在限位堵转。

第 3 步：手动校准 min/max ​

  • 做什么：按第四节逐 25 µs 试探到极限。
  • 合格判据：记录 p_min/p_max，并写入固件；在极限位置静置 30 s 后舵机外壳温度 ≤ 45 °C。
  • 不合格：极限位置持续发热 → 机械限位比脉宽限位更紧，缩小范围。

第 4 步：带载与坐标映射 ​

  • 做什么：装上载荷，调用 Gimbal_AimAt。
  • 合格判据：指向误差 ≤ 2°（用激光笔照在 3 m 处，偏差 ≤ 10 cm）。
  • 不合格：方向反了 → x/y 的符号或 atan2 的参数顺序错了；偏一个固定角度 → 中位没校准；误差随角度增大 → 脉宽比例 ccr_per_deg 不对。

十二、易错清单 ​

  • [ ] 用「占空比 7.5%」代替绝对脉宽——周期一变角度就偏
  • [ ] 两轴用了两个定时器，频率不一致导致同步抖动
  • [ ] 上电先 PWM_Start 而 CCR 还是 0 → 舵机先撞到底限一次
  • [ ] 校准只做了 p_min/p_max，没检查机械限位
  • [ ] 舵机电源用开发板 5 V 引脚
  • [ ] 不共地，或只共信号线
  • [ ] 电源线用杜邦线
  • [ ] 角度用 int 截断而非四舍五入
  • [ ] 大角度一步到底，导致瞬间电流拉满
  • [ ] 把 atan2 的 (y, x) 写成 (x, y)，全程偏 90°

十三、自检 ​

做完以后，用这四个问题验收：

  1. 把载荷装在 pan 轴最远端，pan 从 −90° 扫到 +90°，5 V 轨最低掉到多少伏？低于 4.8 V 说明电源不合格。
  2. tilt 在 −20° 与 +70° 两个极限位置各停 30 s，舵机外壳温度是多少？超过 45 °C 说明限位没调对。
  3. 给定一个坐标，实际指向与理论角度的偏差多少度？用激光笔量，误差要在 2° 以内。
  4. 拔掉 tilt 舵机的电源，pan 还能正常工作吗？如果 pan 也乱了，说明两轴之间没有做成独立供电回路。

四个问题都答得上来，云台就能上台了。三个项目到这里全部完成——它们串起来的那套「独立电源 + 公共地 + 去耦 + 钳位」纪律，比任何一行代码都值钱。
