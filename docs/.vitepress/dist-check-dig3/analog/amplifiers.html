02 · 基本放大电路 ​

核心 约 60 min全课最高频的错误是「直流通路与交流通路混用」——电容在直流里开路、在交流里短路，这一句话决定 Q 点与增益算得对不对

这一页要解决什么：一颗三极管本身不会放大任何一个「信号」——它只把直流电源的能量按 IBI_BIB​ 的比例搬运到集电极。要做放大器，必须先给它一个稳定的直流站位（静态工作点 Q：无信号时那组确定的 ICQI_{CQ}ICQ​、VCEQV_{CEQ}VCEQ​），再把待放大的交流信号叠加上去。读完你应该能对一个分压偏置共射电路完整地算一遍：静态 Q 点、电压增益 A˙u\dot A_uA˙u​、输入电阻 rir_iri​、输出电阻 ror_oro​、最大不失真输出幅度，并说出 Q 点偏高偏低各会造成哪一种失真。

读这页之前

  • 需要会：KCL 与 KVL（、）、戴维南等效（）、三极管在哪个区该怎么判（）。
  • 这一页用到的符号：小写带下标的直流量用双下标，如 ICQI_{CQ}ICQ​（静态集电极电流，Q 是 Quiescent「静止」的缩写）、VCEQV_{CEQ}VCEQ​；交流量用小写瞬时值 uiu_iui​、ici_cic​，交流有效值相量用 U˙o\dot U_oU˙o​、A˙u\dot A_uA˙u​；rber_{be}rbe​ 是基极-发射极间的动态（交流）电阻；RL′=RC∥RLR_L'=R_C\parallel R_LRL′​=RC​∥RL​ 是交流负载；gmg_mgm​ 是跨导（定义见上一页第七节）；β\betaβ 是电流放大系数。全部约定见符号与约定，首次出现处本页都会就地解释一次。
  • 会用到对数与自然常数：只在解释 rber_{be}rbe​ 与 gmg_mgm​ 来历的一句话里出现，不参与任何例题计算。
  • 先接受一条纪律：这一页的每一步计算都要先问「我现在算的是直流还是交流」。这个提问本身就是本页最重要的方法。

麦克风输出的是几十毫伏的交流电压，喇叭却要十几伏才能推动。中间少了一个环节：把小信号的「形状」复制放大，而能量由直流电源出。三极管做的正是这件事——它像一个由 IBI_BIB​ 控制开度的阀门，用小电流控制从电源流向集电极的大电流。

但这里有个陷阱：三极管在放大之前必须先通上电。IBI_BIB​ 为零时管子是关死的，负半周的交流信号会让基极电位低于零、管子直接截止。所以真实电路里必须让管子在无信号时就站在一个中间位置（静态工作点），交流信号再围着它上下摆动。这个「先直流站位、再交流放大」的双重性，是这一页的全部内容。

结论先行 ​

  1. 放大 = 交直流共存：先算直流（确定 Q 点），再算交流（确定增益）。两套通路分开画——直流通路电容开路，交流通路电容短路 + 直流源接地。
  2. Q 点必须设在中部：偏低截止失真（输出顶部削平），偏高饱和失真（输出底部削平）；分压式偏置靠发射极电阻 RER_ERE​ 的直流负反馈把它稳住。
  3. 共射电路：电压增益 A˙u=−βRL′/rbe\dot A_u=-\beta R_L'/r_{be}A˙u​=−βRL′​/rbe​（负号 = 倒相）、输入电阻 kΩ 级、输出电阻 kΩ 级，电压和电流都能放大。
  4. 共集电极（射极输出器）：A˙u≈1\dot A_u\approx1A˙u​≈1、输入电阻高、输出电阻低，不放大电压，专治「带不动负载」。
  5. 共基极电路：输入电阻低到几十 Ω、高频特性好，适合宽频带与高频前端。

一句话记住本页的动作顺序

拿到一张放大电路图，先画两张图：把电容换成开路得到「直流通路」（求 Q 点），把电容换成短路、直流电源换成接地得到「交流通路」（求增益）。混用这两张图是本课程最高频的错误。后面所有小题都是这两张图的应用。

一、先看主角：一张完整的共射放大电路 ​

这一节只做一件事：认识后文反复要用的那张电路图，并把每个元件的角色说清楚。

四个「新」名词要先说清，不然后面的图读不懂：

  • 耦合电容（C1C_1C1​、C2C_2C2​）：把前级的直流电位挡住、只让交流信号通过，叫作 coupling（耦合）。所以静态分析时它是开路，动态分析时它是短路。
  • 旁路电容（CEC_ECE​）：与 RER_ERE​ 并联，给交流信号提供一条「绕过」RER_ERE​ 的通路。它对直流是开路（RER_ERE​ 照常工作），对交流是短路（RER_ERE​ 被绕过）。

有了这张图，下一步就把它按「直流」和「交流」拆成两张。下一节先画直流那张。

二、直流通路：给管子找一个站位（静态工作点 Q） ​

这一节只回答一个问题：无信号时管子站在哪，怎么算。

规则只有一条：电容开路（C1C_1C1​、C2C_2C2​、CEC_ECE​ 全部断开），于是图上只剩 VCCV_{CC}VCC​、Rb1R_{b1}Rb1​、Rb2R_{b2}Rb2​、RCR_CRC​、RER_ERE​ 和管子本身。得到的三个量——静态基极/集电极电流 IBQI_{BQ}IBQ​、ICQI_{CQ}ICQ​ 与静态管压降 VCEQV_{CEQ}VCEQ​——合称静态工作点 Q（Q 是 Quiescent，意为「静止的、无信号的」）。

估算顺序是固定的三步，每一步只用欧姆定律：VB→VE→IE→VCEV_B\to V_E\to I_E\to V_{CE}VB​→VE​→IE​→VCE​。

三、交流通路：把管子换成一个线性模型 ​

这一节回答两个问题：为什么交流通路里 VCCV_{CC}VCC​ 要「接地」，以及三极管被换成了什么东西。

规则仍然是两条，只是反过来：电容短路（C1C_1C1​、C2C_2C2​、CEC_ECE​ 全部当成导线），直流电压源短路（理想电源内阻为零，对交流而言它是一个交流接地点）。于是 VCCV_{CC}VCC​ 那一端在交流图里等价于接地，RCR_CRC​ 的上端、Rb1R_{b1}Rb1​ 的上端都接到地——这是第一次看交流图时最不适应的一步。

管子的替换是整个分析的转折点。在小信号条件下（交流幅度远小于热电压 VT≈26V_T\approx26VT​≈26 mV——这个数由温度决定，等于 kT/qkT/qkT/q——时管子可近似看作线性），三极管被换成微变等效电路（也称小信号模型 small-signal model）：

  • 基极与发射极之间是一个动态电阻 rber_{be}rbe​；
  • 集电极与发射极之间是一个受控电流源 βib\beta i_bβib​（电流由基极电流线性控制）。

rber_{be}rbe​（读作 r-b-e，基极-发射极间的微变等效电阻）由经验公式给出：

rbe=rbb′+(1+β)VTIEQ≈300+(1+β)26 mVIEQr_{be}=r_{bb'}+(1+\beta)\frac{V_T}{I_{EQ}}\approx300+(1+\beta)\frac{26\ \text{mV}}{I_{EQ}} rbe​=rbb′​+(1+β)IEQ​VT​​≈300+(1+β)IEQ​26 mV​

VT≈26V_T\approx26VT​≈26 mV 是热电压（VT=kT/qV_T=kT/qVT​=kT/q，由温度决定）。这个式子说明一件很重要的事：rber_{be}rbe​ 不是器件的固定参数，它随静态电流 IEQI_{EQ}IEQ​ 变化—— IEI_EIE​ 翻倍，rber_{be}rbe​ 大致减半。这就是工作点会影响增益的原因。

模型有了，把它装回原电路就得到完整的交流通路。这里有一个关键的替代：RCR_CRC​ 与 RLR_LRL​ 在交流图上并联（两者上端都交流接地），所以定义一个组合电阻

RL′=RC∥RL=RCRLRC+RLR_L'=R_C\parallel R_L=\frac{R_CR_L}{R_C+R_L} RL′​=RC​∥RL​=RC​+RL​RC​RL​​

RL′R_L'RL′​ 读作「交流负载」。凡是说到增益，用到的都是它；而 RCR_CRC​ 单独只在算输出电阻时出现。

五、三种接法：同一颗管子的三种性格 ​

这一节做一张横向对比表，并解释为什么多级放大器常常「共射提增益 + 共集做输出」。

所谓三种接法指的是：输入信号加到哪两个极之间、输出又从哪两个极取出。剩下的那个极就是输入输出的公共端，名字由此而来。不是换管子，是换接地方式。

记忆法：共射是全能选手，共集是「和事佬」（电压不放大但谁都带得动），共基是「高速直男」（不挑负载但输入阻抗太低）。

一台示波器的输入衰减 + 前放，就是上面那张电路图的工程放大版：

  • 前级共射放大器提增益，用多级级联（级间直接耦合或电容耦合）达到 1 mV/div1\ \text{mV/div}1 mV/div 的灵敏度；
  • 最后一级射随做缓冲——示波器输入阻抗标称 1 MΩ1\ \text{M}\Omega1 MΩ，没有高阻输入级，探头一接就把被测电路拖垮了；
  • 增益切换用继电器换反馈电阻，本质就是改变闭环增益（第 6 章 · 放大电路中的反馈负反馈的雏形）。

这条链上每一环对应本页的一个结论：Q 点决定会不会失真，A˙u\dot A_uA˙u​ 决定灵敏度，rir_iri​ 决定会不会拖垮被测电路，ror_oro​ 决定能带多大负载。

信号链把四件工具的用途串起来了，接下来按踩坑频率排一遍本页的错法。

易错清单 ​

按踩坑频率从高到低排，每条格式是「错误做法 → 会得到什么 → 正确做法」。

  1. 直流通路与交流通路混用 → 两种错误方向：把 RLR_LRL​ 算进静态（VCEQV_{CEQ}VCEQ​ 偏小），或把 RER_ERE​ 漏在动态之外 → 画两张图，电容在直流里开路、在交流里短路，VCCV_{CC}VCC​ 在交流图里接地。
  2. 把 rber_{be}rbe​ 当定值 → 换了偏置或管子后增益算错一大截 → rbe=300+(1+β)26 mV/IEQr_{be}=300+(1+\beta)26\ \text{mV}/I_{EQ}rbe​=300+(1+β)26 mV/IEQ​，先算静态 IEQI_{EQ}IEQ​ 再算 rber_{be}rbe​。
  3. 丢掉 A˙u\dot A_uA˙u​ 的负号 → 后面判断反馈极性时把负反馈判成正反馈 → 共射输出倒相，符号必须写进结果。
  4. 算静态 Q 点时把 RLR_LRL​ 也算进去 → VCEQV_{CEQ}VCEQ​ 偏小，误判为饱和 → 静态时 RLR_LRL​ 被 C2C_2C2​ 隔断。
  5. 最大不失真输出取 12VCC\frac12V_{CC}21​VCC​ → 高估可用输出 → 取两侧余量的较小值；最优 Q 点让两侧相等。
  6. 以为 AuA_uAu​ 与负载无关 → 接上负载后输出掉一半，误以为电路坏了 → RL′=RC∥RLR_L'=R_C\parallel R_LRL′​=RC​∥RL​，增益显式依赖负载。
  7. 旁路电容失效后乱查短路 → 增益暴跌而静态全正常，是最难查的故障之一 → 先查 CEC_ECE​ 是否虚焊（例 2 的警告区给了定量后果）。
  8. 分压式偏置不校核「够不够硬」 → IRb1/IBQ<5I_{R_{b1}}/I_{BQ}<5IRb1​​/IBQ​<5 时估算失效 → 验流过分压器的电流至少是 IBI_BIB​ 的 5~10 倍。
