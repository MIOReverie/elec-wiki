03 · 串并联与电源等效变换 ​

核心 约 40 min化简是解题第一刀，先化到最简再列方程

一、串并联：判断比计算重要 ​

什么叫"串联" ​

电流处处相同的若干元件。判断方法：把某元件的两端短路/断路，若其他元件中仍有电流通过它，就是串联（严格定义是电流相同）。

什么叫"并联" ​

两端电压相同的若干元件。判断方法：两端直接由导线相连（中间无其他元件）。

最常见的误判

"看起来是串联"不等于串联。 例如"R1R_1R1​ 和 R2R_2R2​ 画在同一段线上，中间没有分支" —— 如果它们之间有别的支路接出，那它们的电流就不同，是混联。

判断口诀：看电流，不看长相。 实在判断不了，就老老实实用 。

二、公式与一个记忆技巧 ​

R串=R1+R2+⋯1R并=∑1RiR_{串} = R_1 + R_2 + \cdots \qquad \frac{1}{R_{并}} = \sum\frac{1}{R_i} R串​=R1​+R2​+⋯R并​1​=∑Ri​1​

两电阻并联速记：

R并=R1R2R1+R2R_{并} = \frac{R_1R_2}{R_1+R_2} R并​=R1​+R2​R1​R2​​

分压分流的「对称性」

U1=R1R1+R2UI1=R2R1+R2IU_1 = \frac{R_1}{R_1+R_2}U \quad\qquad I_1 = \frac{R_2}{R_1+R_2}I U1​=R1​+R2​R1​​UI1​=R1​+R2​R2​​I

两个公式长得不一样，但结构完全对称 —— 分压是"自己除以总和"，分流是"对面除以总和"。

这就是为什么分流公式分子是对面的电阻：R2R_2R2​ 越大，分给 R1R_1R1​ 的电流越大（两个并联电阻共享总电流，阻值大的少分流）。记不住时想一下物理：R2R_2R2​ 越大 → I2I_2I2​ 越小 → I1=I−I2I_1 = I - I_2I1​=I−I2​ 越大 ✓

极值检验法（用来判断答案对不对，30 秒）：

  • R1→0R_1\to0R1​→0：R并→0R_{并}\to0R并​→0；R2→∞R_2\to\inftyR2​→∞：R并→R1R_{并}\to R_1R并​→R1​
  • I1I_1I1​ 一定在 000 与 III 之间

三、电源等效变换 ​

定理：电压源 EEE 串电阻 R0R_0R0​ ⇔ 电流源 ISI_SIS​ 并电阻 R0R_0R0​，其中

IS=ER0,E=ISR0I_S = \frac{E}{R_0},\qquad E = I_SR_0 IS​=R0​E​,E=IS​R0​

R0R_0R0​ 在两种模型里都保持不变 —— 这是最容易漏的一点。

它只是「换一种写法」，没有引入新规律

KCL/KVL 已经能解任何线性电阻电路。电源等效变换不是新武器，只是把「电压源串电阻」和「电流源并电阻」两种对外表现相同的模型互换，方便把多个电源合并。所以判断它「有没有用」很简单：变换后能不能合并电源？能，就用；不能，就别折腾（内阻不同的多个电源变换后并不起来，反而多一步）。

上图把"等效"画成了"左右互换"：左（电压源串 R0R_0R0​）与右（电流源并 R0R_0R0​）对外部电路完全等价——两个端子 A、B 的位置不变，内阻 R0R_0R0​ 原地保留（只是从串联变成并联），EEE 与 ISI_SIS​ 互换。凡是"变了"的只有电源的表达形式，凡是"没变"的是端子和 R0R_0R0​。

变换的适用范围（易考概念题）：

情况能否变换
EEE 串 R0R_0R0​✅ 能，IS=E/R0I_S = E/R_0IS​=E/R0​ 并 R0R_0R0​
理想电压源（R0=0R_0=0R0​=0）⚠️ 得 IS=∞I_S=\inftyIS​=∞，退化为"短路"
EEE 串 R1R_1R1​ 再串 R2R_2R2​⚠️ 只能把 R1R_1R1​ 视作"内阻"，R2R_2R2​ 算外电路

变换什么时候真的有用？

目标是合并电源。两个电压源 + 各自内阻，如果内阻相同，才能用变换把两个电流源并起来，IS总=IS1+IS2I_{S\text{总}} = I_{S1}+I_{S2}IS总​=IS1​+IS2​，R0R_0R0​ 不变 —— 这时电路一下变成简单的并联。

如果内阻不同，变换后无法合并，所以并不省事。考试里若看到"多个电源、内阻相同"，基本就是提示你用等效变换。

四、Y-△（星形-三角形）变换 ​

当网络是电桥结构（既非串联也非并联）时，需要 Y-△ 变换。

R12=R1+R2+R1R2R3R_{12} = R_1 + R_2 + \frac{R_1R_2}{R_3} R12​=R1​+R2​+R3​R1​R2​​R23=R2+R3+R2R3R1R31=R3+R1+R3R1R2\begin{aligned} R_{23} &= R_2 + R_3 + \frac{R_2R_3}{R_1}\\ R_{31} &= R_3 + R_1 + \frac{R_3R_1}{R_2} \end{aligned} R23​R31​​=R2​+R3​+R1​R2​R3​​=R3​+R1​+R2​R3​R1​​​

对称时：R1=R2=R3=RYR_1=R_2=R_3=R_YR1​=R2​=R3​=RY​ → R△=3RYR_\triangle = 3R_YR△​=3RY​（最常考，必须记死）

反向（△→Y\triangle\to Y△→Y）：R1=R12R31R12+R23+R31R_1 = \dfrac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}R1​=R12​+R23​+R31​R12​R31​​（分母是三个之和，分子是相邻两条边之积）

Y-△ 变换的三个易错点

  1. 对称时的 3RY3R_Y3RY​ 是 △\triangle△ 边，不是 YYY 臂 —— 方向搞反就是 3×3\times3× 误差
  2. △→Y\triangle \to Y△→Y 分母是三边之和，不是两边
  3. 变换只改外部行为，R△=3RYR_\triangle = 3R_YR△​=3RY​ 时，YYY 中每个臂是 R△/3R_\triangle/3R△​/3

什么时候用 Y-△：电桥类问题（如惠斯通电桥测电阻、测量继电器线圈状态）几乎必用。

五、负载效应（工程核心） ​

分压器（R1R_1R1​、R2R_2R2​ 串联）在 R2R_2R2​ 两端输出。接上负载 RLR_LRL​ 后：

R2→R2∥RL,UL=R2∥RLR1+R2∥RLER_2 \to R_2 \parallel R_L,\qquad U_L = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L}E R2​→R2​∥RL​,UL​=R1​+R2​∥RL​R2​∥RL​​EULE=R2∥RLR1+R2∥RL\frac{U_L}{E} = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L} EUL​​=R1​+R2​∥RL​R2​∥RL​​

空载时 UL=R2R1+R2EU_L = \dfrac{R_2}{R_1+R_2}EUL​=R1​+R2​R2​​E —— 这是理想值。

带载后电压必然下跌，因为 R2∥RL<R2R_2\parallel R_L < R_2R2​∥RL​<R2​。

为什么分压器不能当电源用

分压器是开路设计的：空载时 R2R_2R2​ 上是想要的电压，但一旦接负载，R2R_2R2​ 被"拉低"，电压立刻下降。

工程对策：

  1. 让 RL≫R1+R2R_L \gg R_1+R_2RL​≫R1​+R2​（浪费电流）
  2. 加缓冲跟随器（运放电压跟随器，Rin→∞R_\text{in}\to\inftyRin​→∞、Rout→0R_\text{out}\to0Rout​→0）—— 这是标准做法

负载效应在所有"高阻抗源驱动低阻抗负载"的场合都会出现，是模拟电路最核心的概念之一。

六、可删元件（化简的"清理"步骤） ​

在化简电路时，除了合并串并联，还有一类元件可以直接删掉：

情况可否删除原因
理想电压源并联的电阻✅ 删电压被源钳住，电阻两端电压恒为 EEE，改动它不影响外电路
理想电流源串联的电阻✅ 删电流被源钳住，电阻怎么变电流都是 ISI_SIS​
电压源串联的电阻❌ 不行会影响电流分配
电流源并联的电阻❌ 不行会影响电压分配

常见误解

"电压源并联的电阻没用了"这句话只在理想电压源时成立。真实电源有内阻 R0R_0R0​，那个 R0R_0R0​ 就是"并联"在输出端的、绝对不能删。

七、解题思路（化简四步） ​

  1. 看有没有纯串联/纯并联 → 直接合并
  2. 看有没有可删元件 → 删掉
  3. 看有没有电桥/混联 → Y-△ 变换
  4. 看有没有多个电源 → 电源等效变换合并
  5. 化不动了 → 上 或
