08 · 数电接口：AD/DA 与脉冲调制 ​

核心 约 50 min最贵的错误不是算错精度，而是在 ADC 前面忘了加抗混叠滤波器

这一页要解决什么：麦克风出来的电压是连续变化的，计算机里处理的却是 0 和 1。这中间的桥怎么搭？采多快才不算「漏掉」信息？采下来的数字怎么变回电压？读完你应该能：说清转换链条的四步、解释混叠为什么一旦发生就无法挽回、算出某位数的 LSB 与量化误差上限、区分四种 ADC 结构的取舍，并会用 PWM 的占空比算出等效电压。

读这页之前

  • 需要会：正弦量的三要素与有效值（）、分压器与 RC 低通（、）。这一页不推电路定律，只用它们算指标。
  • 这一页用到的符号：fsf_sfs​ 是采样频率（sampling rate：每秒取几个样点，单位 Hz）；fmaxf_{max}fmax​ 是信号的最高频率；VrefV_{ref}Vref​ 是参考电压（reference voltage：ADC/DAC 用来定义满量程的那个基准）；NNN 是位数；LSB（least significant bit，最低位，同时指 ADC/DAC 的最小分辨单位，单位与电压相同）；DDD 是占空比（duty cycle：高电平时间占整个周期的比例）。全部约定见符号与约定。
  • 三个词先给一句话：采样（sampling：把连续信号在若干时刻取值，幅度仍然连续）；量化（quantization：把连续幅度归到有限个台阶上）；混叠（aliasing：采样不足时高频信号伪装成低频信号的现象）。正文第一次用到时再展开。
  • 会用到取整与对数：量化用四舍五入（round），位数与精度换算用 log⁡2\log_2log2​。不需要微积分。

你在手机上录了一段 8 kHz 的语音，听着还行；换成 44.1 kHz 录，同样的声音就「有细节」了。采样率翻五倍多，代价是文件大了五倍多——多出来的到底是不是真信息？答案是：大部分时候不是，但也有一部分是。采样率不足时，高频成分会被伪装成低频混进你的录音里，而你听不出来。

同样的陷阱在另一边：数模转换器输出的是一串台阶，不是平滑曲线。要变成能用的模拟信号，台阶后面必须跟一个滤波器。这一页把这两头都讲清楚。

结论先行 ​

  1. 现实世界是模拟的，数字系统只认 0/1，ADC 与 DAC 就是两界之间的桥。转换链条固定：采样（时域离散）→ 保持 → 量化（幅度离散）→ 编码。
  2. 采样定理：fs≥2fmax⁡f_s\ge2f_{\max}fs​≥2fmax​ 才能完整重建；采样不足会产生混叠，一旦发生就无法在后端挽回，防线只能设在采样之前。
  3. 量化误差不可避免：理想 ADC 误差 ≤±12LSB\le\pm\frac12\text{LSB}≤±21​LSB，位数每多 1 位，误差减半、数据量翻倍——精度与成本的交换。
  4. ADC 四大类：并行比较（快而贵）、逐次逼近 SAR（速度价格折中，MCU 内置主流）、双积分（慢而抗干扰，数字电压表）、计数式（最慢已淘汰）；DAC 主流是只用两种阻值的 R-2R 梯形网络。
  5. PWM 用通断比例等效出电压：等效值 = 占空比 × 高电平；配低通滤波得模拟量，是调光、调速、开关电源的基石。

一、转换链条：一个模拟量怎么变成一串数字 ​

这一节只回答一个问题：从模拟电压到数字码，中间到底做了哪几件事。

注意②③的次序不可换：不保持的话，量化还没做完样值就变了。而采样定理是整条链的入口门槛——进来时丢了的信息，后面任何处理都变不回来。

四步链条清楚了，但第一步「采样」有一个硬门槛：采得不够快，后面全白做。下一节看这个门槛。

二、采样定理与混叠 ​

这一节只回答一个问题：采样率低于信号频率时，到底发生了什么。

采样定理（Nyquist-Shannon 采样定理，也叫奈奎斯特采样定理）说：一个最高频率为 fmax⁡f_{\max}fmax​ 的信号，要能由它的样点唯一重建，采样频率必须满足

fs≥2fmax⁡f_s \ge 2f_{\max} fs​≥2fmax​

原因是：一条正弦波每周期被采两次时，你拿到的是一串上下交替的点，这串点既可能来自 1 kHz 的波，也可能来自 3 kHz、5 kHz 的波——它们在这些采样点上完全一样，从样点本身无法分辨。这就是混叠（aliasing：高频信号被折叠成低频信号的现象）的根源。

混叠的别名频率有一个可以直接算的公式：

falias=∣fin−round⁡ ⁣(finfs)fs∣f_{alias} = \left|f_{in} - \operatorname{round}\!\left(\frac{f_{in}}{f_s}\right) f_s\right| falias​=​fin​−round(fs​fin​​)fs​​

即把 finf_{in}fin​ 折叠回 [0, fs/2][0,\,f_s/2][0,fs​/2] 区间。例如 fin=6f_{in}=6fin​=6 kHz、fs=8f_s=8fs​=8 kHz 时，falias=∣6−8∣=2f_{alias}=|6-8|=2falias​=∣6−8∣=2 kHz——你采到的是一个 2 kHz 的假信号。

混叠一旦发生就无法在后端挽回，原因就是上面那张图：样点里的信息已经被抹掉了，软件再聪明也变不出没采到的东西。防线只有两个，而且都必须在 ADC 前面：提高采样率，或在 ADC 前加抗混叠滤波器（低通，截止频率压在 fs/2f_s/2fs​/2 以下）。

三个滑块就是整条链的三个参数。把「采样频率」拖到低于输入频率的 2 倍，红色虚线会冒出来——它才是采样后系统以为的真实信号，频率低得多、波形像得多，这就是混叠的阴险之处：看起来毫无异常。位数滑块则控制量化栅格的粗细，位数越少阶梯越粗。

时间上的坑解决了，幅度上还有一个坑：即使采样率足够，样点的幅度仍是连续的，要塞进有限个数字码就必须「取整」。下一节算这个误差有多大。

三、量化与量化误差 ​

这一节只回答一个问题：量化误差有多大，能不能消掉。

量化就是把连续幅度归到 2N2^N2N 个电平上，每个电平叫一个 LSB（最低有效位，也指相邻电平之间的最小电压差）。满量程 VFSV_{FS}VFS​ 除以台阶数就是 LSB：

LSB=VFS2N\text{LSB} = \frac{V_{FS}}{2^N} LSB=2NVFS​​

理想量化器的输出总是落在最近的电平上，所以误差不会超过半个台阶：

∣e∣≤12LSB=VFS2N+1|e| \le \frac{1}{2}\text{LSB} = \frac{V_{FS}}{2^{N+1}} ∣e∣≤21​LSB=2N+1VFS​​

这个误差不可能消掉——它是「把连续的东西塞进有限格子里」的固有代价。位数的选择就是拿它跟成本换：每多 1 位，误差减半，同时数据量翻倍、转换电路的复杂度大约翻倍。

位数够不够，可以直接用「相对满量程的最大误差」来判断：

最大误差VFS=12N+1\frac{\text{最大误差}}{V_{FS}} = \frac{1}{2^{N+1}} VFS​最大误差​=2N+11​

8 位是 0.195%0.195\%0.195%，10 位是 0.049%0.049\%0.049%，12 位是 0.012%0.012\%0.012%。所以「要 0.1% 以内，至少 10 位」这个结论不是背来的，是 2N+1≥10002^{N+1}\ge10002N+1≥1000 解出来的。

量化讲的是「分得多细」，但没说「按什么办法分」——那是器件结构的事。下一节看 DAC 怎么把码值变回电压。

四、DAC：数字怎么变回电压 ​

这一节回答一个问题：数模转换器的输出电压是怎么算出来的。

DAC 的原理是「用数字码控制一个电压比例」。最朴素的做法是权电阻网络（weighted resistor network：每一位电阻的阻值按二的幂加权，电阻越大贡献的电流越小）：每一位配一个电阻，电阻比是 2:1:4:8:…2:1:4:8:\dots2:1:4:8:…，各位电流相加就是输出。直观，但位数一多就要准备一堆不同阻值的电阻，匹配精度也很难保证。

主流是 R-2R 梯形网络（R-2R ladder network：只用阻值 R 与 2R 两种电阻搭成的梯形）：从梯形的每个节点往右看，等效电阻恒等于 2R，于是每一位的贡献天然按二的幂加权，只需要两种阻值。这是几乎所有商用 DAC 的默认结构。

DAC 的三个关键指标：

指标含义为什么重要
分辨率（resolution）用几位表示，常说「12 位 DAC」决定最小台阶 LSB=VFS/2N\text{LSB}=V_{FS}/2^NLSB=VFS​/2N
建立时间（settling time）从输入码变化到输出稳定所需时间决定最高更新速率
线性度（linearity）实际输出与理想直线的偏差（INL/DNL）决定「台阶是否均匀」，精度需求高时是主项

一个必须记住的特性：NNN 位 DAC 的输出永远到不了满量程 VFSV_{FS}VFS​。满量程码 111…12=2N−1111\dots1_2=2^N-1111…12​=2N−1 的输出是 (2N−1)×LSB=VFS−LSB(2^N-1)\times\text{LSB}=V_{FS}-\text{LSB}(2N−1)×LSB=VFS​−LSB。这不是故障，是结构决定的。

DAC 讲完了，反方向的问题就是 ADC：同样把模拟量变成数字，为什么有快有慢、有便宜有贵。

五、ADC 的四种结构 ​

这一节回答一个问题：同样是 ADC，为什么有快有慢、有便宜有贵。

四种经典结构，差别在于「用什么办法把模拟电压变成数字码」：

结构原理速度成本典型用途
并行比较（flash）用 2N−12^N-12N−1 个比较器一次比出全部位最快最贵、功耗大高速示波器、射频采样
逐次逼近 SAR（successive approximation）从最高位开始，一位一位试探、比较、保留中等中等MCU 内置 ADC 主流
双积分（dual-slope）先积分一段时间，再用参考电压反向积分到零，测时间比最慢低、抗干扰强数字万用表
计数式（counter）从零数到与输入相等，数多少个计数最慢低已淘汰

SAR 的核心是「试探」：NNN 位要比较 NNN 次，每次定一位，从最高位到最低位。它的转换时间固定在 NNN 次比较加一次采样保持，也就是 N+1N+1N+1 个时钟周期——这个「固定」正是它的优点：转换时间可预测，便于定周期采样。

双积分的杀手锏是抗干扰：把积分时间取成工频（50 Hz 或 60 Hz）周期的整数倍，混入的工频干扰在一个积分周期内的平均值为零，被积分器「平均掉」。代价是每次转换要几十到几百毫秒。

四种结构讲完，指标该用数字说话。下面四道题把采样、量化、DAC 与速度各算一遍。

六、例题 ​

这一节的四道题按「采样 → 量化 → DAC → 速度」的顺序排。每题先看「先想什么」——那是方法选择，比算出数字重要。

例 1 · 采样定理验算

先想什么：采样定理只给下限，实际取值要留余量——因为抗混叠滤波器不可能是砖墙，截止频率附近总有过渡带。

例 4 · SAR 与双积分的速度账

题目：SAR 型 8 位 ADC 每次转换要几个时钟？时钟 1 MHz 时每秒能转多少次？双积分型在 50 Hz 工频下为什么不怕干扰？

先想什么：SAR 的转换时间是固定的（NNN 次比较 + 1 次采样保持），这是它能被定周期采样的原因；双积分的转换时间很长，但长恰恰是它抗干扰的来源。

步骤：

  1. SAR 型 8 位 ADC 每次要「采样保持 + 逐位比较 8 回」，至少 9 个时钟。

七、工程实例：从传感器到云端的完整链路 ​

一条物联网温度链走一遍今天的所有概念：

  1. NTC 热敏电阻随温度改变阻值，经分压变成电压（欧姆定律与分压器的老本行）；
  2. 抗混叠滤波器（RC 低通）先把高频噪声挡在采样频率一半以下——没有它，噪声会混叠进有用频段；
  3. SAR ADC（MCU 内置 12 位）把电压变成码值，每秒采几千次；
  4. MCU 算出温度，通过 PWM 控制加热器占空比做恒温——整套系统只靠「比较 + 计数 + 通断」就完成了模拟量的精确处理。

反过来，播放端：存储器里的数字音频经 DAC（R-2R 或 Σ-Δ）重建为阶梯波，再经低通滤波器平滑，才到你耳朵里。你听到的每一段数字音乐，终点都是这一章的电路。

PWM 的等效电压是这条链上最省事的一环：PWM（pulse width modulation，脉冲宽度调制：用通断时间比例来表达一个连续量）本身只有 0 和 1 两种电平，但它的平均值等于占空比乘高电平：

Veq=D×VhighV_{eq} = D \times V_{high} Veq​=D×Vhigh​

例如 555 V 供电、占空比 0.250.250.25，等效电压就是 1.251.251.25 V。要把这个等效值真正变成平滑的模拟电压，后面还要跟一只 RC 低通：截止频率 fc=12πRCf_c=\frac{1}{2\pi RC}fc​=2πRC1​ 要远低于 PWM 频率，台阶才被滤平。

整条链路从传感器到执行器就走完了：从前端的采样与滤波，到中间的 ADC/DAC，再到最后的 PWM 与低通。最后一张清单把这一页最容易踩的坑收拢起来。

八、易错清单（按踩坑频率排序） ​

  1. ADC 前面不加抗混叠滤波器 → 噪声混叠进有用频段，后端无法察觉 → 防线只有两个：提高采样率，或在 ADC 前加抗混叠低通。
  2. 指望软件「修」混叠 → 徒劳 → 混叠是采样时信息就被抹掉了，重建算法也无法凭空造出来。
  3. 认为量化误差是噪声的全部 → 选型时只看位数 → 还有偏置误差、增益误差、非线性（INL/DNL）；datasheet 里找 ENOB（有效位数）才是诚实的做法。
  4. SAR 前没有采样保持 → 高位比完低位时样值已漂移 → 比较期间输入必须被冻住。
  5. 以为 DAC 能输出满量程电压 → 误判为故障 → 满量程码输出的是 VFS−LSBV_{FS}-\text{LSB}VFS​−LSB，永远差一个台阶。
  6. PWM 等效电压当成瞬时值 → 直接驱动运放时出错 → 等效电压是「平均值」概念，对惯性负载有效；要平滑输出必须加低通。
  7. 把「位数」当「精度」 → 选型偏乐观 → 理想上限是 ±12\pm\frac12±21​ LSB，实际受 INL/DNL 影响会更差。
