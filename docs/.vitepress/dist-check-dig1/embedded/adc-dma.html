10 · ADC 与 DMA ​

核心 约 40 min把连续世界接进数字世界；DMA 让数据搬运不再占用 CPU

DMA 的搬运模式与缓存一致性问题的完整说明见 。

结论先行 ​

  1. ADC 把模拟电压变成数字码：code=VinVref×(2n−1)\text{code} = \dfrac{V_{in}}{V_{ref}} \times (2^n - 1)code=Vref​Vin​​×(2n−1)，反算电压则除以同样比例。
  2. 分辨率由位数和参考电压共同决定：1 LSB=Vref/2n\text{1 LSB} = V_{ref} / 2^n1 LSB=Vref​/2n。12 位、3.3 V 参考 → 0.806 mV/LSB。
  3. 量化误差 ±0.5 LSB 是原理性固有的，提高位数只能减小它，不能消除它。
  4. 转换时间 = (采样周期 + 12.5) / ADCCLK；采样周期要匹配信号源阻抗，源阻抗越大就要采越久，否则读数偏低。
  5. 多通道/连续采样必须配 DMA：让 DMA 自动把转换结果搬到内存，CPU 只在收满一批时才被打扰一次。

一、ADC 是怎么把电压变成数字的 ​

STM32 里最常见的是 SAR（逐次逼近）型 ADC，工作过程分两步：

  1. 采样：内部开关闭合，给采样电容充电，让它跟上输入电压（这段时间叫采样时间）；
  2. 保持 + 转换：开关断开，电容上的电压被锁住，然后 SAR 用「二分查找」的方式逐位比较（12 位需要 12 次比较），得出数字码。

关键洞察：转换的精度取决于采样电容有没有充到足够接近输入电压。如果信号源阻抗很大（充电慢），而采样时间又很短，电容没充满就开始转换——读数会偏低，而且是系统性的偏差。

这就是为什么「信号源阻抗大 → 要加大采样周期」：

Rsource 大⇒采样周期要长⇒转换变慢⇒最高采样率下降R_{source}\ \text{大} \Rightarrow \text{采样周期要长} \Rightarrow \text{转换变慢} \Rightarrow \text{最高采样率下降} Rsource​ 大⇒采样周期要长⇒转换变慢⇒最高采样率下降

工程解法：高阻抗信号（如用 100 kΩ 电阻分压出来的电压）要先经过运放跟随器缓冲，再进 ADC。

二、分辨率与参考电压 ​

例 1 · 12 位、3.3 V 参考下的量化

一个 LSB 代表多少电压：

V=20484095×3.3≈1.6504 VV = \frac{2048}{4095} \times 3.3 \approx 1.6504\ \text{V} V=40952048​×3.3≈1.6504 V

与真实值差 +0.4 mV，正好落在理论上限 ±0.5 LSB（±0.403 mV）之内。

要点：分母到底是 4095 还是 4096？转换时用 4095（满量程对应最大码），算 LSB 大小时用 4096（把量程等分成 2n2^n2n 份）。两者混用会带来约 0.024% 的差异，通常可忽略，但写高精度算法时要统一。

怎么选采样周期：查数据手册的公式，由信号源阻抗决定。粗略规则：

  • 源阻抗 < 1 kΩ → 1.5~7.5 周期足够；
  • 源阻抗 10 kΩ 量级（如直接接电位器）→ 28.5 周期以上；
  • 源阻抗 50 kΩ 以上（如高阻分压）→ 必须加运放跟随器，靠加大采样时间救不回来（会拖慢到不可接受）。

多通道时还要乘以通道数：4 个通道轮流转换，每个 21 µs，一轮就要 84 µs——这是很多人「采样率上不去」的真正原因。

三、为什么要配 DMA ​

DMA 搬运的边界、以及带 D-Cache 芯片上必须显式维护缓存的问题，见 。

DMA（Direct Memory Access，直接存储器访问）是一个独立于 CPU 的搬运工：外设（ADC、UART、SPI）数据准备好后，DMA 自动把它搬到内存（或反向），全程不需要 CPU 参与。

不用 DMA 时，ADC 连续采样有两种做法：

方式问题
轮询等待每次转换完成CPU 被完全占用，什么都干不了
每次转换完成进中断若采样率 100 kHz，每秒 10 万次中断，CPU 被中断淹没

用 DMA 后：

ADC 转换完成 → 触发 DMA 请求 → DMA 自动搬运到数组 → 搬满 N 个才产生一次中断

CPU 只在「一批数据收满」时才被打扰一次，其余时间可以做算法、通信、进睡眠。

c
uint16_t adc_buf[4];                     // 4 个通道的结果
HAL_ADC_Start_DMA(&hadc1, (uint32_t *)adc_buf, 4);   // 启动，之后自动循环搬运

void HAL_ADC_ConvCpltCallback(ADC_HandleTypeDef *hadc) {
  // 4 个通道都采完了才进这里一次
  process(adc_buf);
}

DMA 的常见模式：

  • Normal（普通）：搬完指定数量就停，需要重新启动；
  • Circular（循环）：搬完自动回到开头继续，连续采样必备；
  • 双缓冲（Double Buffer）：一半/满仓各触发一次中断，实现「一边采一边处理」的流水线。

四、提高 ADC 精度的工程手段 ​

硬件上：

  1. 干净的参考电压：Vref 上的任何纹波都会直接进到读数里。高精度场合用外部基准（如 TL431、REF3033）而不是直接用 VDD；
  2. 去耦与模拟/数字地分离：ADC 的电源引脚要单独去耦；
  3. 信号调理：加 RC 低通滤掉高频噪声，加运放跟随降低源阻抗；
  4. 避免引脚串扰：ADC 引脚旁边不要走高频数字信号（尤其是 PWM）。

软件上：

  1. 多次平均：对同一信号连续采样 N 次取平均，随机噪声降低 N\sqrt{N}N​ 倍；
  2. 过采样：以 4 倍速率采样并平均，可多得 1 位有效分辨率（4N4^N4N 倍过采样 → 提高 NNN 位）；
  3. 丢弃前几次采样：切换通道后前 1~2 次结果往往不准（采样电容还残留上一个通道的电荷）；
  4. 校准：STM32 内置了 ADC 校准（HAL_ADCEx_Calibration_Start），上电后应执行一次。

例 3 · 用分压测 12 V 电池电压

要测 0~13 V 的电池，但 ADC 量程只有 0~3.3 V，必须用电阻分压。

选阻值：希望 12.6 V（3 串锂电满电）时仍在量程内，并留余量。取 上臂 30 kΩ、下臂 10 kΩ：

两个容易忽略的点：

  1. 分压电阻一直在耗电：12.6 V 时流过 12.6/40k≈0.31512.6/40\text{k} \approx 0.31512.6/40k≈0.315 mA。对电池供电设备，这个电流常年在流，要选尽量大的阻值（但太大又会让源阻抗过高、ADC 采不准——通常取几十 kΩ 到几百 kΩ 的折中，必要时加运放缓冲）。
  2. 电阻精度决定测量精度：普通 1% 电阻会让分压比偏差 1%，测出来就有 1% 的系统误差。要准就得用 0.1% 精密电阻，或者做单点校准（测一个已知电压，把实际分压比算出来存进 Flash）。

例 4 · 平均多少次才够

ADC 读数常带随机噪声（假设单次噪声标准差 σ = 1 LSB）。对同一信号连续采样 N 次取平均，噪声降低为：

σN=σN\sigma_N = \frac{\sigma}{\sqrt{N}} σN​=N​σ​
平均次数 N噪声 σ改善
11.000 LSB—
40.500 LSB2 倍
160.250 LSB4 倍
640.125 LSB8 倍

结论：平均的收益是 N\sqrt{N}N​，边际效益递减——从 16 次加到 64 次只多改善 2 倍，却要多花 4 倍时间。16 次平均是性价比最高的选择。

顺便区分两个概念：

  • 平均（averaging）：降低随机噪声，不增加有效位数（同一信号测多次）；
  • 过采样（oversampling）：以 4N4^N4N 倍速率采样并抽取，真正提高 N 位有效分辨率——前提是信号里存在至少 1 LSB 的白噪声（若信号太干净，需要人为加一点抖动噪声，即 dither）。

五、DMA 的其他典型用途 ​

DMA 不只是给 ADC 用：

场景用法
UART 接收HAL_UARTEx_ReceiveToIdle_DMA，收满或空闲才中断（见 08 章）
SPI 收发大批量读写 Flash / 刷屏时用 DMA，速度提升明显
内存到内存快速搬数组，比 CPU 循环快
DAC 波形输出DMA 循环送数据，硬件自动产生任意波形

DMA 的坑：

  • 缓存一致性（M7 带 Cache 的芯片）：DMA 改了内存而 CPU 的 Cache 里还是旧值，需要手动失效/清理 Cache；
  • 源/目的地址不能越界，数组要足够大；
  • Circular 模式下要小心处理时机：DMA 可能正在写数组的前半段，而你在处理后半段。

六、工程实例 ​

NTC 测温：NTC 热敏电阻与一个固定电阻串联分压，用 ADC 测分压点，再按 NTC 的阻值—温度曲线（通常用 B 值公式或查表）换算成温度。要点是 NTC 的阻值随温度非线性变化，所以分压电阻应取 NTC 在目标温区中点的阻值，这样灵敏度最均匀。

电池电量监测：见例 3。工业做法还会在分压电路里加一个 MOS 管开关——只在采样瞬间导通，避免分压电阻常年耗电，这对纽扣电池供电的产品是必需的。

七、易错清单 + 自检 ​

  • [ ] 信号超过 Vref：读数饱和在满量程，超出部分丢失（还可能损坏引脚）
  • [ ] 信号源阻抗大却用了很短的采样时间：读数系统性偏低
  • [ ] 忘了开 ADC 时钟、忘了校准
  • [ ] 多通道切换后前几次读数不准：丢弃最初 1~2 次采样
  • [ ] 连续采样没用 DMA：用轮询或每转换一次中断，CPU 被拖垮
  • [ ] Circular 模式忘了开：搬完一次就停了
  • [ ] 分压电阻精度不够 / 常年耗电没考虑
  • [ ] 参考电压纹波大：直接反映为读数噪声

自检：12 位、3.3 V 参考时 1 LSB 是多少？信号源阻抗很大时该怎么办？连续采样 4 个通道、每个 21 µs，一轮要多久？（答案：0.806 mV；加大采样周期，或加运放跟随器降低阻抗；84 µs）
