04 · 支路电流法与结点电压法 ​

核心 约 45 min结点电压法是通用解法，建议作为默认武器

结论先行 ​

  1. 支路电流法：以每条支路电流为未知量，列 (n−1)(n-1)(n−1) 个 KCL + (b−n+1)(b-n+1)(b−n+1) 个 KVL。方程多，但直观。
  2. 结点电压法：以结点电压为未知量，只列 (n−1)(n-1)(n−1) 个 KCL。方程最少，最通用。
  3. 网孔电流法：平面电路可用，列 (b−n+1)(b-n+1)(b−n+1) 个 KVL。
  4. 含理想电压源时，结点法要增设该支路电流的未知量（MNA 思想）。
  5. 未知量个数的判据：结点电压法 n−1n-1n−1 个（选参考点后），支路电流法 bbb 个，网孔法 b−n+1b-n+1b−n+1 个。未知量最少的那个最好写。

先厘清：这三种方法不是新规律，是 KCL/KVL 的三种消元策略

上一章说过：KCL 管「点」、KVL 管「回路」。本章的支路电流法、网孔法、结点电压法，底层没有任何新物理——它们只是决定「用哪几个未知量、列哪一类方程最省事」：支路电流法直接列 KCL+KVL；网孔法拿网孔电流当未知量只列 KVL；结点法把支路电流用欧姆定律消掉只列 KVL 化的 KCL。所以学这一章不要背新公式，要理解「为什么这么消元」。

一、为什么要学三种方法 ​

它们本质是同一组方程的三种消元策略：

  • 支路电流法：把 KCL + KVL + VAR 全列出来，未知量是 bbb 个支路电流
  • 网孔电流法：以网孔电流为未知量，用 KVL 列方程，未知量 b−n+1b-n+1b−n+1 个
  • 结点电压法：把支路电流用欧姆定律消掉（I=(Vi−Vj)/RI=(V_i-V_j)/RI=(Vi​−Vj​)/R），只用 KCL，未知量 n−1n-1n−1 个

结点电压法最省，因为"支路电流"这个中间量被彻底消掉了。 这也是现代电路仿真（SPICE 的 MNA）使用的方法。

方法未知量个数适合
支路电流法bbb支路很少（2~3 条），且电路拓扑简单
结点电压法n−1n-1n−1通用，默认首选
网孔电流法b−n+1b-n+1b−n+1平面电路、网孔数少

怎么快速选

  • 数结点数 nnn，数支路数 bbb。
  • 若 n−1<b−n+1n-1 < b-n+1n−1<b−n+1，用结点电压法（一般成立）。
  • 电路是平面且网孔很少（如双环），网孔电流法更快，因为可以直接"看电流方向写方程"。
  • 只有 1~2 条支路时，别列方程了， 或 一秒出答案。

二、结点电压法：从 KCL 推出来 ​

对结点 kkk 列 KCL：流入 = 流出。

每条电阻支路的电流由欧姆定律给出。设结点 kkk 与 jjj 之间电阻 RkjR_{kj}Rkj​：

三个高频错

  1. 互导写正号 → 整个矩阵不再对称，解全错。
  2. 电流源方向搞反 → 记住"流入为正、流出为负"，不是"和电阻一样按箭头"。
  3. 忘记参考结点不列方程：nnn 个结点只列 n−1n-1n−1 个方程，因为 Vref=0V_{\text{ref}}=0Vref​=0 已知。

三、弥尔曼定理（两结点特例） ​

两个结点、单参考点、多个电源并联 —— 这是考试出现频率最高的结点电压问题。

V1=∑kEkRk∑k1Rk\boxed{V_1 = \frac{\sum_k \dfrac{E_k}{R_k}}{\sum_k \dfrac{1}{R_k}}} V1​=∑k​Rk​1​∑k​Rk​Ek​​​​

理解成"电导加权平均"：每个电源贡献 Ek/RkE_k/R_kEk​/Rk​（相当于它单独作用时的电流），总电导是各电导之和。

判断题要点

"电压最高的电源对结点电压贡献最大" —— 错。贡献是 E/RE/RE/R，一个 10V10\text{V}10V 配 1Ω1\Omega1Ω（贡献 10A）比 100V100\text{V}100V 配 10Ω10\Omega10Ω（贡献 10A）还小。

四、含理想电压源的结点法（MNA 思想） ​

理想电压源无法用电导表示，这是结点法的唯一障碍。三种处理：

方法 A：挪动参考点（最优先尝试） ​

如果电压源一端已经接在参考点上，那另一端电压直接已知，该结点方程不必列（或直接写出 V=EV = EV=E）。

选参考点的技巧

遇到多个理想电压源时，选一个"接了最多电压源"的结点作参考点。能省掉好几个方程。

例如 E1E_1E1​、E2E_2E2​ 的公共端连在一起，选这个点为参考，则两个电源另一端电压立即已知。

方法 B：增设支路电流未知量（改进结点法 MNA） ​

若电压源接在两个都不是参考点的结点 a,ba,ba,b 之间：

  1. 把该支路电流 ISI_SIS​ 加进未知量向量
  2. 补一个约束方程：Va−Vb=EV_a - V_b = EVa​−Vb​=E
  3. 原来 VaV_aVa​、VbV_bVb​ 的 KCL 里，加上 ISI_SIS​ 的贡献项

这正是 SPICE 内部用的方法。考试里若电路含多个电压源，用方法 B 最稳。

方法 C：电压源串电阻（工程近似） ​

若题目给的电源模型是 EEE 串 R0R_0R0​，就把 R0R_0R0​ 当普通电阻，根本不构成理想电压源。

最容易漏的一条

与理想电压源并联的电阻，其电流无法由两端电压确定 —— 但它仍然进入自导！这是因为它有真实电阻，只是"被短路"了。

对比：与理想电流源串联的电阻不进入自导，因为该支路电流已知（就是 ISI_SIS​），这个电阻的存在不改变电流。

一句话记忆：理想电压源并联的电阻要计入自导；理想电流源串联的电阻不计入。

五、支路电流法与网孔电流法 ​

支路电流法 ​

bbb 条支路 → bbb 个未知电流，方程来源：

  • (n−1)(n-1)(n−1) 个独立 KCL
  • (b−n+1)(b-n+1)(b−n+1) 个独立 KVL
  • bbb 个支路 VAR（Uk=RkIkU_k = R_k I_kUk​=Rk​Ik​ 或电容电感的微分关系）

共 2b2b2b 个方程、bbb 个未知量，看似冗余（其实有依赖），但对支路少的电路直观、几乎不会出错。

网孔电流法 ​

前提：电路必须是平面图（能画成没有交叉的平面电路）。

  • 网孔数 = b−n+1b-n+1b−n+1（与独立 KVL 数相同）
  • 每个网孔设一个假想电流 I网孔I_{\text{网孔}}I网孔​
  • 在公共支路上：I=I网孔1−I网孔2I = I_{\text{网孔1}} - I_{\text{网孔2}}I=I网孔1​−I网孔2​（方向相同为相加、反向为相减）

网孔法的致命限制

非平面电路不能用。典型非平面电路：立体交叉的连接、某些网络拓扑习题。 识别方法：如果画草图时发现有交叉但又没有"桥"（crossing without node），那就是非平面。

考试遇到复杂拓扑时，用结点电压法，别赌网孔法。

本例真正要记住的

  1. 理想电压源直接接参考点 → 那一点的电压直接已知，不用列方程，也不用增未知量。这是最省事的处理方式。
  2. 给结点3 补一个 R34R_{34}R34​ 是为了让电路可解：电流源不能直接接参考点而没有回路，否则电流无处可去，KCL 不成立。画完电路先检查：每条支路两端是否有通路。
  3. 电流源既可以从高电位流向低电位，也可以反向 —— 只要电源自身提供能量。纯电阻网络里电流只能高→低，含源网络里不一定。

例 3 · 支路电流法：两个电源「互助」的回路

电路：结点 A（上左）经 R1=2 ΩR_1=2\,\OmegaR1​=2Ω 接 E1=12 VE_1=12\,\text{V}E1​=12V（+++ 在上），再下到导轨；结点 B（上右）经 R3=3 ΩR_3=3\,\OmegaR3​=3Ω 接 E2=6 VE_2=6\,\text{V}E2​=6V（+++ 在下，即接导轨一侧），再下到导轨；A、B 之间经 R2=1 ΩR_2=1\,\OmegaR2​=1Ω 相连；两条下轨合并为参考点。求各支路电流。

解

设支路电流（参考方向一律「向下」或「顺环路」）：左支路 I1I_1I1​（向下）、中支路 I2I_2I2​（A→B）、右支路 I3I_3I3​（向下）。

列 KCL（只有 A、B 两个非参考结点）：

A 点： I1+I2=0  ⇒  I1=−I2\text{A 点： } I_1 + I_2 = 0 \;\Rightarrow\; I_1 = -I_2 A 点： I1​+I2​=0⇒I1​=−I2​B 点： −I2+I3=0  ⇒  I3=I2\text{B 点： } -I_2 + I_3 = 0 \;\Rightarrow\; I_3 = I_2 B 点： −I2​+I3​=0⇒I3​=I2​

列 KVL（沿外环顺时针走一圈，各段压降相加为零）：

I2R2+I3R3−I1R1=E1+E2I_2R_2 + I_3R_3 - I_1R_1 = E_1 + E_2 I2​R2​+I3​R3​−I1​R1​=E1​+E2​

注意符号：E2E_2E2​ 的 +++ 在下，顺时针走到它时是从「−-−」端走向「+++」端，属于升势，所以移到等式右边时与 E1E_1E1​ 同号相加——两个电源在这条环路里是互助的，总电势 12+6=18 V12+6=18\,\text{V}12+6=18V。

代入 I1=−I2I_1=-I_2I1​=−I2​、I3=I2I_3=I_2I3​=I2​：

I2(1+3+2)=18  ⇒  I2=3 AI_2(1+3+2) = 18 \;\Rightarrow\; I_2 = 3\,\text{A} I2​(1+3+2)=18⇒I2​=3A

于是 I1=−3 AI_1=-3\,\text{A}I1​=−3A（负号 = 实际向上流），I3=3 AI_3=3\,\text{A}I3​=3A。

验算：

  • KCL@A：流入 3 A3\,\text{A}3A（左支路实际向上）= 流出 3 A3\,\text{A}3A（中支路）✓
  • KCL@B：流入 3 A3\,\text{A}3A = 流出 3 A3\,\text{A}3A ✓
  • 功率：E1E_1E1​ 发出 12×3=36 W12\times3=36\,\text{W}12×3=36W，E2E_2E2​ 发出 6×3=18 W6\times3=18\,\text{W}6×3=18W；电阻吸收 9×2+9×1+9×3=54 W9\times2+9\times1+9\times3=54\,\text{W}9×2+9×1+9×3=54W。∑P=0\sum P=0∑P=0 ✓

本题的收获：支路电流法方程多但几乎不用判断电流方向——全设成一个参考方向，让符号去说话。算完负的就是反了，物理世界不会因为参考方向而改变。

例 4 · 理想电压源桥接两个非参考结点（必须用 MNA）

电路：结点 A 经 R1=2 ΩR_1=2\,\OmegaR1​=2Ω 接参考点；结点 B 经 R3=2 ΩR_3=2\,\OmegaR3​=2Ω 接参考点；理想电压源 Es=8 VE_s=8\,\text{V}Es​=8V（+++ 接 A）直接桥接 A、B；另有理想电流源 2 A2\,\text{A}2A 从参考点注入结点 A。求 VAV_AVA​、VBV_BVB​ 与电压源支路电流。

解

第一步：判断障碍。 电压源两端都不是参考点 → 方法 A 用不了，上方法 B（MNA）。

第二步：设未知量。 VAV_AVA​、VBV_BVB​，外加电压源支路电流 IVI_VIV​（参考方向 A→B）。

第三步：两个 KCL + 一个约束。

A 点：VA2+IV=2（右端是注入的 2A）\text{A 点：}\quad \frac{V_A}{2} + I_V = 2 \qquad\text{（右端是注入的 2A）} A 点：2VA​​+IV​=2（右端是注入的 2A）B 点：VB2−IV=0（IV 到达 B，故取负）\text{B 点：}\quad \frac{V_B}{2} - I_V = 0 \qquad\text{（$I_V$ 到达 B，故取负）} B 点：2VB​​−IV​=0（IV​ 到达 B，故取负）约束：VA−VB=8\text{约束：}\quad V_A - V_B = 8 约束：VA​−VB​=8

第四步：解。 由 B 点方程 IV=VB/2I_V=V_B/2IV​=VB​/2，代入 A 点：

VA+VB2=2  ⇒  VA+VB=4\frac{V_A+V_B}{2}=2 \;\Rightarrow\; V_A+V_B=4 2VA​+VB​​=2⇒VA​+VB​=4

与约束联立：VA=6 VV_A=6\,\text{V}VA​=6V，VB=−2 VV_B=-2\,\text{V}VB​=−2V，代回 IV=−1 AI_V=-1\,\text{A}IV​=−1A（负号 = 实际从 B 流向 A，1 A1\,\text{A}1A）。

第五步：验算。

  • 电阻电流：IR1=6/2=3 AI_{R_1}=6/2=3\,\text{A}IR1​​=6/2=3A（A→地），IR3=−2/2=−1 AI_{R_3}=-2/2=-1\,\text{A}IR3​​=−2/2=−1A（实际地→B，1 A1\,\text{A}1A）
  • KCL@A：注入 2 A2\,\text{A}2A + 源支路送来 1 A1\,\text{A}1A = R1R_1R1​ 流走 3 A3\,\text{A}3A ✓
  • KCL@B：R3R_3R3​ 送来 1 A1\,\text{A}1A = 源支路流走 1 A1\,\text{A}1A ✓
  • 功率：EsE_sEs​ 发出 8×1=8 W8\times1=8\,\text{W}8×1=8W；电流源把 2 A2\,\text{A}2A 从 0 V0\,\text{V}0V 推到 6 V6\,\text{V}6V，发出 12 W12\,\text{W}12W；R1R_1R1​ 吸收 32×2=18 W3^2\times2=18\,\text{W}32×2=18W，R3R_3R3​ 吸收 12×2=2 W1^2\times2=2\,\text{W}12×2=2W。8+12=18+28+12=18+28+12=18+2 ✓

两个值得记住的现象：

  1. VB=−2 VV_B=-2\,\text{V}VB​=−2V：浮接的电压源完全可以把结点拉到参考点以下——参考点只是「记高度用的海平面」，不是地板。
  2. 电流源也在做功：它把电流从低电位推向高电位，和电池一样是「源」。判断电源发没发功率，看电流从它的哪个端子流出，别看它是不是「电池」。

易错点 ​

  • 自导恒正、互导恒负，符号写反解全错
  • 电流源流入结点取正、流出取负
  • 理想电流源串联的电阻不进入自导；理想电压源并联的电阻仍要进入自导
  • 电压源直接接参考点时，该点电位已知，不要重复列方程
  • 电流源支路若没有回路，电路无解 —— 先检查通路
  • 网孔法只适用平面电路，复杂拓扑别赌它
