14 · 磁路基础 ​

核心 约 45 min全书最容易卡住的一章：公式像电路，但磁路不能照搬电路的算法

结论先行 ​

  1. 安培环路定律：∮H dl=∑NI\oint H\,dl = \sum NI∮Hdl=∑NI —— 这是恒成立的，是磁路计算的地基
  2. 磁路欧姆定律：Φ=NIl/(μS)\Phi = \dfrac{NI}{l/(\mu S)}Φ=l/(μS)NI​ —— 只在 μ\muμ 为常数时成立，是近似
  3. B=μHB = \mu HB=μH、Φ=BS\Phi = BSΦ=BS、μ=μ0μr\mu = \mu_0\mu_rμ=μ0​μr​
  4. 铁磁材料的 BBB-HHH 曲线非线性且有磁滞，所以磁路题几乎都要查曲线
  5. 铁损 = 磁滞损耗 + 涡流损耗；硅钢片叠压是为了切断涡流回路

这一章的核心矛盾只有一句话：

电路的 γ\gammaγ（电导率）是常数，磁路的 μ\muμ（磁导率）不是。 所以电路题可以纯算，磁路题必须看曲线。

一、三个量，先分清楚 ​

初学磁路最常见的混乱，是 Φ\PhiΦ、BBB、HHH 三个量混着说。其实它们的关系只有两句话：

B=μHΦ=BSB = \mu H \qquad \Phi = B S B=μHΦ=BS
量名称单位是什么类比电路
HHH磁场强度A/m由电流（安匝）产生的，是"因"电压降 U=E−IRU = E - IRU=E−IR 中的"驱动力"
BBB磁感应强度T（特斯拉）磁介质中的实际磁通密度，是"果"电流密度
Φ\PhiΦ磁通Wb（韦伯）穿过一个面的磁通总量，Φ=BS\Phi = BSΦ=BS电流
μ\muμ磁导率H/m材料的"磁通透性"电导率 γ\gammaγ
F=NIF = NIF=NI磁动势A（安匝）线圈产生的磁化能力的度量电动势 EEE

关键在最后一行。 电流 III 是"通过量"，NININI 是"产生磁化的能力"。安匝数是磁路的"电压源"，Φ\PhiΦ 是"电流"。

为什么要引入 HHH？ 因为电流 III 是与材料无关的物理量，而 BBB 强烈依赖材料。拆成 B=μHB = \mu HB=μH 后，HHH 就变成一个"纯几何/电流决定的量"，可以在各种材料之间比较。工程上（比如设计一个电磁铁要多大电流）我们关心的是 HHH，因为 HHH 才对应我们能控制的安匝数。

HHH 和 BBB 的实用差别

  • 问"要多大的励磁电流" → 求 HHH（A/m）
  • 问"铁心会不会饱和" → 看 BBB（T），硅钢片饱和点约 1.6∼2 T1.6\sim2\text{ T}1.6∼2 T
  • 问"铁心能传多少磁通" → 求 Φ\PhiΦ（Wb）

永磁材料、电磁材料厂商给的规格书也是按这个分法列的。

二、安培环路定律：唯一能无脑用的公式 ​

安培环路定律（安培环路定理）：

∮CH dl=∑C内I\oint_C H\,dl = \sum_{C内} I ∮C​Hdl=C内∑​I

对单线圈绕 NNN 匝、磁路平均长度 lll（各处 HHH 相同）：

Hl=NI⟹H=NIlHl = NI \quad\Longrightarrow\quad H = \dfrac{NI}{l} Hl=NI⟹H=lNI​

这条定律永远成立，不管磁路里是铁、是空气、还是非线性材料。

最容易踩的坑

"磁场强度 HHH 只由电流和几何尺寸决定，与磁介质的 μ\muμ 无关"——这句话不完全对。

正确说法：安培环路定律给的是 ∮H dl\oint H\,dl∮Hdl，是沿程的积分。如果磁路各段材质不同，HHH 在各段是不同的：

∑iHili=NI\sum_i H_i l_i = NI i∑​Hi​li​=NI

比如一个有铁心段和一个气隙的磁路：H铁l铁+H气l气=NIH_{铁}l_{铁} + H_{气}l_{气} = NIH铁​l铁​+H气​l气​=NI。因为 μ气≪μ铁\mu_{气} \ll \mu_{铁}μ气​≪μ铁​，同样大小的 HHH 在气隙里产生的 BBB 远小于铁心，所以气隙段的 HHH 会大得多，占据了绝大部分的安匝。

这就是为什么电机和交流接触器的铁心必须有气隙，而气隙大小直接决定励磁电流大小的原因。

三、磁阻与磁路欧姆定律 ​

μ0=4π×10−7 H/m\mu_0 = 4\pi\times 10^{-7}\ \text{H/m}μ0​=4π×10−7 H/m（真空磁导率），硅钢片 μr∼1000∼10000\mu_r \sim 1000\sim10000μr​∼1000∼10000，空气 μr≈1\mu_r \approx 1μr​≈1。

心智模型：磁路题的固定动作 —— 分段、查曲线、累加安匝

拿到任何磁路题，按这个顺序走就不会乱：① 沿磁路分段（铁心段、气隙段，截面积/材质/长度相同的并成一段）；② 每段用 Φ=BS\Phi=BSΦ=BS 和该段 BBB-HHH 曲线（或 μ\muμ）建立 HHH-BBB 关系；③ 用恒成立的安培环路定律 ∑Hili=NI\sum H_il_i = NI∑Hi​li​=NI 把所有段串起来解。磁路欧姆定律只是把 ③ 包装成欧姆定律的样子，μ\muμ 一变就不准——真正的地基永远是安培环路定律。

气隙为什么"很贵" ​

磁阻 Rm=l/(μS)R_m = l/(\mu S)Rm​=l/(μS)。空气的 μ0\mu_0μ0​ 比铁心的 μ\muμ 小三到四个数量级，所以同样 lll、SSS 的空气段，磁阻是铁心段的几千倍。

结论：磁路里哪怕只有 0.1 mm 的气隙，它承担的磁阻可能超过整个铁心。

工程推论：

  • 变压器叠片之间要压紧、涂绝缘漆不是为绝缘电，而是减少气隙（减少励磁电流）
  • 电机气隙是设计中最关键的尺寸：气隙大 → 励磁电流大、功率因数低、启动转矩下降
  • 电磁铁吸合时气隙消失 → 励磁电流大幅下降，这是直流电磁铁吸合"不费电"的原因

磁路计算的两种方法

方法一（近似法，用于初步估算）：假设铁心 μr\mu_rμr​ 很大 → 铁心磁阻可忽略 → 全部安匝落在气隙上：

NI≈H气l气=B气μ0l气⟹B气≈μ0NIl气NI \approx H_{气}l_{气} = \dfrac{B_{气}}{\mu_0}l_{气} \quad\Longrightarrow\quad B_{气} \approx \dfrac{\mu_0 NI}{l_{气}} NI≈H气​l气​=μ0​B气​​l气​⟹B气​≈l气​μ0​NI​

这个式子极其好用——很多电机/电磁铁的估算题就靠它。

方法二（精确法，用 BBB-HHH 曲线）：查硅钢片的 BBB-HHH 曲线得到 H铁H_{铁}H铁​，再逐段累加安匝。设计变压器、电机时必须这么做。

四、铁磁材料的 BBB-HHH 曲线 ​

三个必须记住的特征 ​

  1. 非线性 + 饱和：BBB 到 1.6~2 T 后再怎么加 HHH 都不怎么涨。工程上绝不会让铁心工作在饱和区（电流白涨、发热剧增、效率骤降）
  2. 剩磁 BrB_rBr​：HHH 降到 0 时 BBB 还有残留。剩磁大 → 变压器空载时"通电不放"、电表 remanent 偏转
  3. 矫顽力 HcH_cHc​：要让 BBB 回到 0 需要反向加一个不小的 HHH。HcH_cHc​ 小 → 材料"软"（易磁化易退磁，用于变压器铁心）；HcH_cHc​ 大 → 材料"硬"（剩磁强，用于永磁材料）

回线面积 = 每周期损耗

磁滞损耗 Ph=fVkhBmnP_h = f V k_h B_m^nPh​=fVkh​Bmn​（n≈1.6n \approx 1.6n≈1.6）。回线围的面积正比于每周期损耗，频率 fff 决定每秒循环多少次。

所以 Ph∝f⋅Bm1.6P_h \propto f \cdot B_m^{1.6}Ph​∝f⋅Bm1.6​——电压升高（BmB_mBm​ 升）会让铁损以接近平方的速度暴涨。这就是变压器不能过电压运行的原因。

涡流损耗与叠片 ​

交变磁通在铁心里会感生涡流（闭合的环形电流），涡流造成的损耗 Pe∝Bm2f2t2/ρP_e \propto B_m^2 f^2 t^2 / \rhoPe​∝Bm2​f2t2/ρ。

Pe∝Bm2f2d2ρ铁P_e \propto \frac{B_m^2 f^2 d^2}{\rho_{\text{铁}}} Pe​∝ρ铁​Bm2​f2d2​
  • 与 Bm2B_m^2Bm2​、f2f^2f2 成正比 → 升频特别致命
  • 与片厚 d2d^2d2 成正比 → 减薄最有效

所以硅钢片要叠成 0.35 mm 薄片，片间涂绝缘漆切断涡流回路。高频场合进一步用更薄的 0.2 mm、0.1 mm 或非晶合金。

一个有用的判断：50 Hz 用 0.35 mm 硅钢片；400 Hz（航空、 military）要用 0.2 mm 以下；几千 Hz（开关电源）通常干脆不用硅钢片，改用铁氧体或纳米晶。

例 3 · 为什么交流电磁铁卡住会烧

题干：某交流接触器线圈额定 220 V220\text{ V}220 V、50 Hz50\text{ Hz}50 Hz。正常吸合时励磁电流 I1=30 mAI_1 = 30\text{ mA}I1​=30 mA。问：铁心被卡住、气隙保持 2 mm 不闭合时，电流约为多少？

解答

第一性思考：交流电磁铁是什么在决定磁通？

U≈E=4.44 fNΦmU \approx E = 4.44\,f N \Phi_m U≈E=4.44fNΦm​Φm=U4.44fN\Phi_m = \frac{U}{4.44 fN} Φm​=4.44fNU​

气隙大 → 磁阻大 → 要维持同样的 Φm\Phi_mΦm​ 需要更大的 HHH → 更大的励磁电流。

安培环路定律：H气=NIδH_{气} = \dfrac{NI}{\delta}H气​=δNI​，而 B气=ΦmSB_{气} = \dfrac{\Phi_m}{S}B气​=SΦm​​ 固定，所以 H气=B气μ0H_{气} = \dfrac{B_{气}}{\mu_0}H气​=μ0​B气​​ 也是固定的。

于是：

20 倍！ 线圈匝数是按 30 mA30\text{ mA}30 mA 选的，铜损按 I2RI^2RI2R 算，现在电流大 20 倍 → 铜损大 400 倍 → 几分钟内线圈烧毁。

这是真实事故

工业现场"接触器吸不上、嗡嗡响、然后烧了"就是这个原理。处理办法：

  1. 先查机械卡涩（铁锈、异物、油污、弹簧失效）
  2. 选型时保证线圈额定电压与电源一致（有的厂商标 220 V 的用在 380 V 网上，直接导致长期过励磁）
  3. 电子式接触器 / 软启动器可规避

对比直流电磁铁：恒磁动势 F=NIF = NIF=NI，电流由电阻决定，与气隙几乎无关。吸合后气隙消失 → 磁路磁阻下降 → 但电流不变 → 吸力反而因为磁通增大而增大。所以直流电磁铁吸合后"更省电"，交流电磁铁吸合前后电流基本不变。

答：卡住时电流约为 0.6 A0.6\text{ A}0.6 A，是正常值的约 20 倍。 :::

例 4 · 铁损估算

题干：一台变压器铁心用 0.35 mm 硅钢片叠成，工作在 Bm=1.2 TB_m = 1.2\text{ T}Bm​=1.2 T、50 Hz50\text{ Hz}50 Hz。若改用 0.2 mm 硅钢片，只考虑涡流损耗，涡流损耗大约降低多少？

解答

涡流损耗与片厚平方成正比：

Pe2Pe1=(d2d1)2=(0.20.35)2=(0.571)2≈0.327\frac{P_{e2}}{P_{e1}} = \left(\frac{d_2}{d_1}\right)^2 = \left(\frac{0.2}{0.35}\right)^2 = (0.571)^2 \approx 0.327 Pe1​Pe2​​=(d1​d2​​)2=(0.350.2​)2=(0.571)2≈0.327

涡流损耗降低到原来的 33%，即降低约 67%。

但注意：总铁损不只看涡流。还有磁滞损耗 Ph∝fBm1.6P_h \propto fB_m^{1.6}Ph​∝fBm1.6​，它与片厚无关。

所以总铁损的降低幅度小于 67%。如果原来涡流占总铁损的 40%，那总铁损降低：

0.4×67%=27%0.4\times 67\% = 27\% 0.4×67%=27%

为什么这么想 这道题考的是"你知不知道磁滞和涡流对片厚的依赖不同"。 实际工程中：如果铁损主要是磁滞（比如工频、低硅钢片），减薄片厚收益有限；如果是高频（开关变压器），涡流占比高，减薄/换材料收益巨大。 另外片数增加会带来新的损耗——片间绝缘不良会形成新的涡流回路，这就是硅钢片涂层质量这么重要的原因。

答：涡流损耗降低约 67%；总铁损降幅更小，取决于两种损耗的占比。

六、易错清单 ​

  1. 磁路欧姆定律当精确公式用：μ\muμ 不常数，必须查 BBB-HHH 曲线
  2. 气隙磁阻被忽略：0.1 mm 气隙的磁阻可能等于 1 m 的铁心
  3. 单位换算：1 cm2=10−4 m21\text{ cm}^2 = 10^{-4}\text{ m}^21 cm2=10−4 m2、1 mm=10−3 m1\text{ mm} = 10^{-3}\text{ m}1 mm=10−3 m、μ0=4π×10−7\mu_0 = 4\pi\times10^{-7}μ0​=4π×10−7
  4. 交流电磁铁按直流思路算：交流是恒磁通不是恒磁动势，气隙大 → 电流暴涨
  5. 认为 Φ\PhiΦ 与电流成正比：只在未饱和、μ\muμ 近常数时成立
  6. 铁心饱和：BmB_mBm​ 超过 1.6~2 T 后电流剧增、发热、波形畸变（设计铁心要工作在膝部）
