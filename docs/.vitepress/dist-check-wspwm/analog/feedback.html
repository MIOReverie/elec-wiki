06 · 放大电路中的反馈 ​

核心 约 50 min反馈类型判别 + 深度负反馈估算 + 增益换带宽 + 自激条件，模电的分水岭

负反馈能成立的前提是运放在线性区工作，也就是虚短虚断那两条法则，见 。

结论先行 ​

  1. 反馈 = 把输出的一部分送回输入端比较。送回的信号削弱净输入是负反馈，增强是正反馈——负反馈稳、正反馈振。
  2. 四种负反馈拓扑：电压/电流（采样什么）× 串联/并联（怎么比较）。判别法一句话：输出端短路法判电压/电流，输入端分解法判串联/并联。
  3. 深度负反馈的估算法宝：1+AF≫11+AF\gg11+AF≫1 时 A˙f≈1/F\dot A_f\approx1/FA˙f​≈1/F——增益只由反馈网络决定，与管子参数脱钩，这是模拟集成电路精度的根基。
  4. 负反馈四买四卖：买来增益稳定性、线性度、带宽、可控的输入输出电阻；卖掉了增益本身，且可能卖出自激。
  5. 自激条件：环路附加相移达到 ±180° 且 ∣AF∣≥1|AF|\ge1∣AF∣≥1。相位裕度 PM>0PM>0PM>0 才稳，工程留 45° 以上。

推导脉络：从反馈方程到一切应用 ​

反馈之所以能「按公式算」，前提是运放在闭环里仍工作在线性区；判据见 。

A˙f=A˙1+A˙F˙,1+A˙F˙ 叫「反馈深度\dot A_f=\frac{\dot A}{1+\dot A\dot F},\qquad 1+\dot A\dot F\ \text{叫「反馈深度} A˙f​=1+A˙F˙A˙​,1+A˙F˙ 叫「反馈深度

同一个方程解释全部现象：

  • 1+AF1+AF1+AF 大 → A˙f→1/F\dot A_f\to1/FA˙f​→1/F，增益稳定：dAf/AfdA/A=11+AF\dfrac{dA_f/A_f}{dA/A}=\dfrac{1}{1+AF}dA/AdAf​/Af​​=1+AF1​，开环抖 10%，闭环只抖千分之几；
  • 负反馈把增益换成了带宽、线性度、想要的输入输出电阻（见下表）；
  • 但高频段额外相移可能让负反馈翻正 → 自激，于是有了补偿与相位裕度。

图解①：四种拓扑与深度估算 ​

「闭环增益估算」页签：切换四种拓扑，拖 AAA 和 FFF，看 1+AF1+AF1+AF 涨起来之后 A˙f\dot A_fA˙f​ 如何钉死在 1/F1/F1/F 上，以及 rir_iri​、ror_oro​ 各自被推向哪个方向——想要低阻输出就选电压反馈，想要恒流就选电流反馈。

「自激与相位裕度」页签：三级放大器各贡献最多 −90°-90°−90° 相移，环路增益 ∣AF∣|AF|∣AF∣ 的曲线穿越 0 dB 时如果相移已经超过 −180°-180°−180°，负反馈就翻正了——把 FFF 从小往大拖，看 PMPMPM 何时掉到 0 以下，这就是运放数据手册里「单位增益稳定」的来历。

工程实例：反馈在真实系统中的四张面孔 ​

  • 仪表放大器：三运放结构，第一级电压串联负反馈把输入电阻推到 GΩ 级，差模增益用一颗电阻设定——生物电、 strain gauge 前端的标准件；
  • 射极跟随器：分立版的电压串联负反馈（100% 反馈），带喇叭、带长电缆，第 2 章 · 基本放大电路例 4 的 34 Ω 输出就是反馈的功劳；
  • 开关电源的误差放大器：输出采样 → 与基准比 → 调 PWM 占空比，一整环跨模拟与数电接口的负反馈，环路设计（补偿网络）直接决定电源会不会啸叫；
  • 自激的现场版：音响开大声就尖叫、运放输出直流跑飞——都是环路相移越界。老工程师的第一动作是加补偿电容、降低反馈深度，而不是先怀疑管子坏。

易错清单 + 自检 ​

  • 先判类型再套公式：把电流反馈当成电压反馈估 ror_oro​，结论会完全反过来。
  • 正反馈也有用：振荡器（第 8 章 · 波形的发生和变换）、施密特触发器靠它，别一听反馈就想到负的。
  • 深度负反馈的近似有条件：1+AF≫11+AF\gg11+AF≫1（一般 >10 才算「深度」），浅反馈必须回到 A/(1+AF)A/(1+AF)A/(1+AF)。
  • 自激判据是两条同时成立：相位 180° 且 ∣AF∣≥1|AF|\ge1∣AF∣≥1。只满足一条不会自激。
  • 多级级联相移累加：每级最多 90°，三级就有翻正的风险，两级单靠相移通常翻不了正。
