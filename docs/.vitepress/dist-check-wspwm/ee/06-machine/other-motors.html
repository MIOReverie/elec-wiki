18 · 直流电机与单相电机 ​

可跳过 约 30 min直流电机正在退场，但它的机械特性曲线是理解『调速』最好的标本；单相电机满屋子都是

结论先行 ​

  1. 直流电机：U=E+IaRaU = E+I_aR_aU=E+Ia​Ra​、E=KeΦnE = K_e\Phi nE=Ke​Φn、T=KTΦIaT = K_T\Phi I_aT=KT​ΦIa​ —— 三个公式推出全部结论
  2. 三种励磁：他励/并励（硬特性，调速好）、串励（软特性，严禁空载）、复励（折中）
  3. 起动时 E=0E=0E=0 → 电枢电流 =U/Ra= U/R_a=U/Ra​ 极大（可达 20 倍额定）→ 必须串电阻或降压
  4. 单相绕组产生脉动磁场 → 起动转矩为 0；靠电容/电阻分相"造出"旋转磁场才能起动
  5. 同步电动机转速恒定、功率因数可调（同步调相机）

规律层：所有电机只差在「磁场怎么来」

不管单相、三相、直流还是同步，电机做功都靠磁场与电流相互作用，转矩永远形如 T∝Φ⋅I⋅(有功分量)T \propto \Phi\cdot I\cdot(\text{有功分量})T∝Φ⋅I⋅(有功分量)。它们真正的差别只有一件事——磁场是不是旋转的、怎么让它旋转：三相靠空间/时间都差 120° 直接生出旋转磁场；单相只有脉动磁场（= 两个反向旋转磁场叠加），得靠分相「造」出旋转；直流则靠换向器把转矩方向逐個「掰」正。抓住这条，四种电机就不用分开背。

一、单相异步电动机：脉动磁场怎么变成旋转磁场 ​

单相绕组通交流电，产生的是脉动磁场（沿本相轴线、大小按正弦变化、不旋转）：B(θ,t)=Bmsin⁡ωt⋅cos⁡θB(\theta,t) = B_m\sin\omega t\cdot\cos\theta B(θ,t)=Bm​sinωt⋅cosθ

用三角恒等式把它拆开：

Bmsin⁡ωtcos⁡θ=Bm2sin⁡(ωt−θ)+Bm2sin⁡(ωt+θ)B_m\sin\omega t\cos\theta = \frac{B_m}{2}\sin(\omega t-\theta) + \frac{B_m}{2}\sin(\omega t+\theta) Bm​sinωtcosθ=2Bm​​sin(ωt−θ)+2Bm​​sin(ωt+θ)

物理意义：脉动磁场 = 两个幅值减半、转向相反的旋转磁场的叠加。

  • 转子不转时：两个磁场产生的转矩大小相等、方向相反 → 合成起动转矩 = 0（这就是单相电机"不推不转"的原因）
  • 转子一旦往某个方向转动：顺着转向的那个磁场转差率变小（转矩大），逆着的那个转差率变大（转矩小）→ 顺着转向的转矩占优 → 继续转

所以单相电机只需"推一下"就能转起来。 但工业生产不能靠手推 —— 要靠分相：

类型分相办法特点
电容分相副绕组串电容 → 电流超前 → 近似两相旋转磁场起动转矩较大，最常见（风扇、洗衣机、空调风机）
电阻分相副绕组电阻做得大 → 电流相位差小转矩小，成本最低
罩极式磁极上短路环使部分磁通滞后结构最简单，转矩很小（小风扇、老式仪器）

离心开关去哪了

电容分相电机的副绕组只在起动时用。转速到 75% 左右，离心开关把副绕组切除 —— 单靠主绕组的"优势方向转矩"就能继续跑。如果离心开关粘住不切断，副绕组长期发热会烧掉。

二、直流电动机：三个公式 ​

他励（并励）直流电机的电路方程：

U=E+IaRa,E=KeΦn,T=KTΦIaU = E + I_aR_a,\qquad E = K_e\Phi n,\qquad T = K_T\Phi I_a U=E+Ia​Ra​,E=Ke​Φn,T=KT​ΦIa​

把 E=KeΦnE = K_e\Phi nE=Ke​Φn 代入电压方程，得到转速公式：

n=U−IaRaKeΦ\boxed{n = \frac{U-I_aR_a}{K_e\Phi}} n=Ke​ΦU−Ia​Ra​​​

三种励磁方式 ​

类型励磁绕组接法特性注意
他励独立电源供电硬，nnn 随负载略降调速性能最好，可控
并励与电枢并联（同一电源）硬，与他励接近最常见；励磁绕组严禁断开
串励与电枢串联软，n∝1/Tn\propto 1/Tn∝1/T严禁空载/皮带传动（飞车）
复励并励 + 串励折中兼顾起动转矩与稳定性

串励电机为什么严禁空载

n=U−IaRaKeΦn = \dfrac{U-I_aR_a}{K_e\Phi}n=Ke​ΦU−Ia​Ra​​，串励时 Φ∝Ia\Phi \propto I_aΦ∝Ia​。负载一轻 → IaI_aIa​ 小 → Φ\PhiΦ 小 → 分母变小 → 转速冲向极高，转子可能因离心力散架。所以串励电机必须直接连负载，不能用皮带（皮带断了就等于空载）。

并励/他励的对应禁忌：运行时励磁绕组严禁断开 —— Φ→0\Phi\to0Φ→0 同样导致转速飞升。

调速：两条路 ​

n∝UΦn \propto \frac{U}{\Phi} n∝ΦU​
  1. 调压（UUU 从 0 到额定）：nnn 近似成正比，最常用，需可调直流电源（晶闸管/开关电源）
  2. 调磁（减小 Φ\PhiΦ，弱磁升速）：nnn 反比于 Φ\PhiΦ，但转矩 T=KTΦIaT = K_T\Phi I_aT=KT​ΦIa​ 随之下降 —— 恒功率调速，只能往额定转速以上调
  3. 电枢串电阻：简单但能耗大、特性软，已基本淘汰

起动：为什么必须串电阻 ​

n=0n = 0n=0 时 E=KeΦn=0E = K_e\Phi n = 0E=Ke​Φn=0，电压方程变成 U=IaRaU = I_aR_aU=Ia​Ra​：

Ist=URaI_{st} = \frac{U}{R_a} Ist​=Ra​U​

RaR_aRa​ 通常只有零点几欧，IstI_{st}Ist​ 可达额定的 10~20 倍 —— 换向器火花、绕组烧毁。所以直流电机绝不允许直接加额定电压起动，必须串起动电阻（或降压），把 IstI_{st}Ist​ 限制在 (1.5∼2.5)IN(1.5\sim2.5)I_N(1.5∼2.5)IN​。

电枢离心力 ∝ n2n^2n2，转速翻倍离心力变 4 倍 —— 转子绕组可能甩出、换向器损坏、轴承飞裂。所以：

  • 串励电机必须直接耦合负载，严禁皮带/链条传动（断了 = 空载）
  • 起动时也要串电阻（同样因为 n=0n=0n=0 时 E=0E=0E=0）

例 3 · 单相电机为什么推一下才转

用"两个反向旋转磁场"模型解释：(a) 为什么静止时起动转矩为 0；(b) 为什么推动之后能继续转。

解

(a) 脉动磁场分解为两个幅值 Bm2\dfrac{B_m}{2}2Bm​​、转向相反的旋转磁场。转子不动时，两个磁场对转子的转差率都是 1（相对转速都是同步转速），产生的转矩大小相等、方向相反：

T+=T−  ⇒  Tst=T+−T−=0T_+ = T_- \;\Rightarrow\; T_{st} = T_+ - T_- = 0 T+​=T−​⇒Tst​=T+​−T−​=0

(b) 设转子被推向正方向，转速为 nnn（s=(n0−n)/n0s = (n_0-n)/n_0s=(n0​−n)/n0​）：

  • 正向磁场与转子相对转速变小 → 转差率 s+=s<1s_+ = s < 1s+​=s<1 → 转矩 T+T_+T+​ 较大
  • 反向磁场与转子相对转速变大 → 转差率 s−=(2n0−n)/n0=2−s>1s_- = (2n_0-n)/n_0 = 2-s > 1s−​=(2n0​−n)/n0​=2−s>1 → 转矩 T−T_-T−​ 较小
T=T+−T−>0(与转向相同)T = T_+ - T_- > 0 \quad(\text{与转向相同}) T=T+​−T−​>0(与转向相同)

于是转子加速，sss 继续减小，T+T_+T+​ 越来越大 —— 自己把自己"牵"进稳定运行。

推论：s=1s = 1s=1 是临界点。若负载使转速掉到 0，两个转矩又相等了，电机停转。

这也解释了罩极式的原理

罩极式电机的短路环让一部分磁通滞后，相当于在磁极内部制造了一个"弱旋转分量"，起动转矩小但非零。电容分相则用外接电容把副绕组电流移相 90°，两个方向的磁场差异更大，起动转矩也就大得多。

:::

工程实例 ​

直流电机退场了吗？ 在调速性能要求极高、或需要大起动转矩的场合仍在用：起重机（串励，吊重物时自动慢、空钩时快）、电车（串励）、精密伺服（他励 + 闭环，调速范围可达 1:10000）。但主流已被交流 + 变频取代 —— 因为直流电机有换向器和电刷这个机械磨损件，是维护量的主要来源。

同步调相机是什么？ 一台不带机械负载的同步电动机，专门用来调节无功功率：过励磁时向电网送无功（抬电压），欠励磁时吸收无功（压电压）。电网需要它来稳住电压，尤其在长距离轻载线路上。

易错清单 ​

  1. 直流电机起动时 E=0E = 0E=0，直接加额定电压 → I=U/RaI = U/R_aI=U/Ra​ 可达 20 倍 → 必须串电阻/降压
  2. 串励严禁空载（Φ→0\Phi\to0Φ→0 → 飞车）；并励/他励严禁励磁绕组断开（同样飞车）
  3. 单相电机起动转矩为 0（两个反向磁场的转矩抵消）；推一下能转是因为顺向转矩占优
  4. 电磁功率是 EIaEI_aEIa​，不是 UIUIUI；轴上功率还要扣机械损耗
  5. 弱磁升速是恒功率调速（转矩下降），不是恒转矩
  6. T=KTΦIaT = K_T\Phi I_aT=KT​ΦIa​ 里 Φ\PhiΦ 是每极磁通，串励时 Φ\PhiΦ 随 IaI_aIa​ 变，不是常数
