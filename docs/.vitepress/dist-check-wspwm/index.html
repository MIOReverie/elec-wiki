这个 wiki 怎么用 ​

三条最常用的入口

  • 系统学一遍：从电工学路线图进入，按 01 → 22 顺序读；每章前面有前置知识胶囊兜底。
  • 只差考前突击：直接翻公式速查表和每章末尾的「易错点 / 考点速记」。
  • 查某个概念：点右上角搜索（或按 Ctrl + K），中文按 2-gram 分词，输「戴维南」「转差率」都能命中。

这里有什么，没有什么 ​

有：四门课的正文、可以自己拖的演示、前置知识卡片、公式速查、依赖图谱，以及一份由脚本生成的内容状态表——哪些章节能当教材读、哪些还只是提纲，写得很直白。

没有：不做教材替代，不覆盖全部考纲，不承诺每道题都有标准答案。正文是学习笔记，引用与勘误见关于本站。

内容基于秦曾煌《电工学》等教材整理，仅供个人学习使用
