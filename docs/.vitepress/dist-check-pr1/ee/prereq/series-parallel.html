电阻串并联等效 ​

卡片 约 5 min串联看电流相同，并联看电压相同；串多了变大，并多了变小

一句话结论：串联电流相同所以电阻相加，并联电压相同所以电阻的倒数相加——化简电路的第一刀，就是看能不能把网络拆成纯串联或纯并联。

日常说法与正式定义 ​

  • 日常说法：一根水管接了三段管子，每段都有阻力，接起来总阻力是三段相加（因为水在每段里流过的量一样）；把三根管子并排接，两端压力一样，每根分到的流量就少了。
  • 正式定义：
    • 串联（电流相同）：R=R1+R2+⋯R = R_1 + R_2 + \cdotsR=R1​+R2​+⋯，分压 Uk=Rk∑R UU_k = \dfrac{R_k}{\sum R}\,UUk​=∑RRk​​U。
    • 并联（电压相同）：1R=1R1+1R2+⋯\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdotsR1​=R1​1​+R2​1​+⋯，分流 Ik=Gk∑G II_k = \dfrac{G_k}{\sum G}\,IIk​=∑GGk​​I（G=1/RG = 1/RG=1/R 是电导）。

两个电阻并联速记：R=R1R2R1+R2R = \dfrac{R_1R_2}{R_1+R_2}R=R1​+R2​R1​R2​​（「积除以和」）。

两条方向相反的规律 ​

  • 串联电阻越多，总电阻越大，且总电阻大于任一个。
  • 并联电阻越多，总电阻越小，且总电阻小于任一个。

常见误解 ​

  1. 「并联电阻要相加」 → 并联的是倒数相加，不是阻值相加。1/R1/R1/R 才是相加的那个量。
  2. 「只要画得整齐就能串并联化简」 → 图形整齐不代表拓扑可化简。电桥（四个电阻围成方框加一条对角线）就不能用串并联化简，必须换方法。
  3. 「串联分压一定能用」 → 分压公式要求各电阻中流过同一个电流。有一路被旁路（并联了一条支路）之后，分压关系就要重新推。

例题 ​

例 1 · 化简并求总电流

题目：R1=4 ΩR_1 = 4\ \OmegaR1​=4 Ω、R2=8 ΩR_2 = 8\ \OmegaR2​=8 Ω 串联后，再与 R3=6 ΩR_3 = 6\ \OmegaR3​=6 Ω 并联，接在 12 V 电源上。求总电阻与总电流。

先想什么：先判断拓扑能不能拆——能。顺序是先串后并，从最内层开始。（化简顺序错了会把自己绕进去，先内层后外层永远没错。）

步骤：

  1. 串联段：R12=4+8=12 ΩR_{12} = 4 + 8 = 12\ \OmegaR12​=4+8=12 Ω。
  2. 与 R3R_3R3​ 并联：R=12×612+6=7218=4 ΩR = \dfrac{12 \times 6}{12 + 6} = \dfrac{72}{18} = 4\ \OmegaR=12+612×6​=1872​=4 Ω。
  3. 总电流：I=U/R=12/4=3 AI = U/R = 12/4 = 3\ \text{A}I=U/R=12/4=3 A。

验算：4 Ω4\ \Omega4 Ω 小于并联支路里的每一个（12 和 6）✓，符合「并联变小」。再验算支路：串联段电流 12/12=1 A12/12 = 1\ \text{A}12/12=1 A，R3R_3R3​ 支路电流 12/6=2 A12/6 = 2\ \text{A}12/6=2 A，两者相加 1+2=3 A1 + 2 = 3\ \text{A}1+2=3 A = 总电流 ✓（KCL 在结点处闭合）。
