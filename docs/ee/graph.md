# 知识依赖图谱

## 怎么读这张图

- **每一层**是一批可以并行学的内容
- **箭头从 A 指向 B**：学 B 之前应该先看 A
- 没有箭头连进来的节点 = 可以任意时刻开始

## 几条主要路径

| 路径 | 节点 |
| --- | --- |
| **直流主线**（最基础，必须先走完） | 01 → 02 → 03 → 04 → 05 |
| **动态主线** | 02 → 06 → 07 → 22（整流滤波） |
| **交流主线** | 02 → 08 → 09 → 10 → 11 |
| **三相与电机** | 10 → 12 → 13；12 + 14 → 16 → 17 |
| **磁路与变压器** | 01 → 14 → 15 |
| **强电控制** | 02 → 19；23 → 20 |
| **数字电路** | 23 → 24 → 25 |

## 速通建议

如果时间只够一半，按下面这条**最短路径**走，其余靠公式速查表兜底：

```
01 → 02 → 05（戴维南）→ 08（相量）→ 09（阻抗）→ 12（三相）→ 16/17（电机）→ 19（控制）
```

- 03、04 可以只在做题卡住时回头补
- 06、07 用到 RC/RL 前置知识（正文胶囊即点即看），重点只需记住**三要素公式**
- 11、13、14、18、21 属于"了解档"，扫一眼结论即可
- 22～25 与电子课程重叠，学过可整段跳过
