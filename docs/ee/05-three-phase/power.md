# 13 · 三相功率与测量

<Meta time="25 min" level="核心" note="一个公式 + 一种测量方法就够用了，但两者的细节都容易丢分" />

## 结论先行

1. 对称三相总有功功率：$P = 3U_pI_p\cos\varphi = \sqrt3\,U_lI_l\cos\varphi$ —— **Y 接和 △ 接形式完全相同**
2. 公式里的 $\varphi$ 是**相电压与相电流的相位差**，**不是**线电压与线电流的
3. $Q = \sqrt3\,U_lI_l\sin\varphi$，$S = \sqrt3\,U_lI_l$，且 $S^2 = P^2+Q^2$
4. 测量：**两表法**（三线制，最常用）、**三表法**（四线制）
5. 两表读数是**代数和**；$\cos\varphi < 0.5$ 时有一表读数为负
6. 由两表读数可反推 $\tan\varphi = \sqrt3\dfrac{W_C-W_A}{W_A+W_C}$（大减小）

## 一、从瞬时功率出发：为什么是 $\dfrac32$

<Prereq id="rms" /> 单相时 $p(t) = u(t)i(t)$ 以两倍频率脉动，平均值 $P = UI\cos\varphi$。三相则完全不同 —— [第 12 章 · 三相电路](circuit.md)那张图已经看过：三个错开 120° 的脉动功率相加，脉动正好抵消：

$$
p(t) = p_A+p_B+p_C = \frac32\,U_pI_p\cos\varphi = \text{常量}
$$

**平均功率 = 瞬时功率**（因为已经不脉动了）：

$$
P = \frac32\,U_pI_p\cos\varphi
$$

这里 $U_p$、$I_p$ 是**幅值**（峰值）。换成有效值（$U = U_m/\sqrt2$、$I = I_m/\sqrt2$）：

$$
\boxed{P = 3U_pI_p\cos\varphi}
$$

::: tip $\dfrac32$ 这个因数的来历
$\dfrac32 U_mI_m\cos\varphi = \dfrac32(\sqrt2 U)(\sqrt2 I)\cos\varphi = 3UI\cos\varphi$。
记不住就用"三相各贡献一份，共 3 份"来记 —— 但要知道 $\dfrac32$ 的存在意味着**三相机器的利用率比单相高**，这是三相省铜的数学根源。
:::

## 二、统一成线电压线电流

Y 接：$U_p = U_l/\sqrt3$，$I_p = I_l$ → $P = 3\cdot\dfrac{U_l}{\sqrt3}\cdot I_l\cos\varphi = \sqrt3\,U_lI_l\cos\varphi$

△ 接：$U_p = U_l$，$I_p = I_l/\sqrt3$ → $P = 3\cdot U_l\cdot\dfrac{I_l}{\sqrt3}\cos\varphi = \sqrt3\,U_lI_l\cos\varphi$

**两种接法殊途同归** —— 这就是公式统一的原因。无功和视在功率同理：

$$
Q = 3U_pI_p\sin\varphi = \sqrt3\,U_lI_l\sin\varphi,\qquad
S = 3U_pI_p = \sqrt3\,U_lI_l
$$

::: tip 规律层：为什么两种接法公式一模一样
Y 接把电压除 $\sqrt3$、电流不变；△ 接把电流除 $\sqrt3$、电压不变——一个乘在电压上、一个乘在电流上，$3\cdot\dfrac{1}{\sqrt3}$ 殊途同归都化成 $\sqrt3$。所以记一个公式 $P=\sqrt3\,U_lI_l\cos\varphi$ 就够，接法只影响你「求相量」那一步。
:::

::: warning 两个「φ」别搞混
- 公式里的 $\varphi$ = **相电压与相电流**的相位差 = 每相负载的阻抗角
- 线电压与线电流之间还隔着 30°（Y 接）或 −30°（△ 接）

所以"线电压与线电流的夹角"**不是** $\varphi$。只有 Y 接且负载对称时，两者数值才恰好相等（因为 30° 的偏移在相量图上是固定的，而 $\varphi$ 是负载的阻抗角 —— 严格说它们本来就不是一回事）。
:::

## 三、两表法（二瓦计法）

**适用场合**：三相三线制（没有中性线），对称或不对称负载都行。

**接法**：两个功率表的**电流线圈分别串入 A、C 两根火线**，两个**电压线圈的另一端都接第三条火线 B**。

- $W_A$：测 $U_{AB}$ 与 $I_A$ → $W_A = U_lI_l\cos(\varphi+30^\circ)$
- $W_C$：测 $U_{CB}$ 与 $I_C$ → $W_C = U_lI_l\cos(\varphi-30^\circ)$
- 总功率：$P = W_A + W_C$（**代数和**）

::: tip 心智模型：两表法 —— 两根火线 + 一块「隐含」的第三线
这是一种新的测量思路：三线制只有三根火线、没有中性线，却只用**两块**表。第三根火线不必测——它的电流由 KCL 决定（$\dot I_B = -(\dot I_A+\dot I_C)$），所以两表读数就携带了全部三相的功率信息。
**操作规则**：总功率取两表**代数和** $P = W_A + W_C$；反推功率因数用 $\tan\varphi = \sqrt3\dfrac{W_C-W_A}{W_A+W_C}$（**大减小**）。$\cos\varphi<0.5$ 时 $W_A$ 会翻负——不是表坏，把它的电流线圈反接后按负值代入即可。
:::

### 加起来为什么正好是 $\sqrt3\cos\varphi$

$$
W_A+W_C = U_lI_l\big[\cos(\varphi+30^\circ)+\cos(\varphi-30^\circ)\big]
= U_lI_l\cdot2\cos30^\circ\cos\varphi
= \sqrt3\,U_lI_l\cos\varphi ✓
$$

### 一只表为什么会反偏

从图上看得很清楚：$W_A = \cos(\varphi+30^\circ)$ 在 $\varphi = 60^\circ$ 时过零，之后变负；而 $W_C = \cos(\varphi-30^\circ)$ 一直到 $\varphi = 120^\circ$ 才过零（常规负载到不了）。

::: danger 读到负值怎么办
**不是表坏了，也不是接错了。** 负载功率因数很低（$\cos\varphi < 0.5$，例如空载变压器、轻载电机）时必然出现。处理办法：把那只表的电流线圈两个端钮对调（或扳到极性开关），读数记为**负值**代入 $P = W_A+W_C$。
:::

### 反推功率因数

$$
\tan\varphi = \sqrt3\,\frac{W_C-W_A}{W_A+W_C}
$$

（用**大的减小的**，保证结果为正；分母是两表代数和。）

## 四、三表法

**适用场合**：三相四线制（有中性线），尤其负载不对称时 —— 每相接一个功率表：

$$
P = W_A+W_B+W_C
$$

::: warning 两表法 vs 三表法的分界线
| | 两表法 | 三表法 |
| --- | --- | --- |
| 接线 | 三线制（无中性线） | 四线制（有中性线） |
| 表数 | 2 | 3 |
| 不对称负载 | 可以 | 可以 |
| 四线制不对称 | **不行** | 必须用 |

**原因**：四线制有中性线电流 $I_N$，两表法只测了两根火线的电流，$I_N$ 那条路的功率漏掉了。
:::

## 例题

::: tip 例 1 · 读铭牌（最常见的题型）
一台三相异步电动机铭牌：$P_N = 5.5$ kW、$U_N = 380$ V、$I_N = 11.6$ A、$n_N = 1440$ r/min、$\cos\varphi_N = 0.84$。求额定输入功率和效率。

**解**

**输入功率**（注意用**线**电压线电流）：

$$
P_{1N} = \sqrt3\,U_NI_N\cos\varphi_N
= \sqrt3\times380\times11.6\times0.84
= 6.41\ \text{kW}
$$

**效率**（铭牌功率是**轴上输出机械功率**）：

$$
\eta_N = \frac{P_N}{P_{1N}} = \frac{5.5}{6.41} = 85.8\%
$$

与铭牌标注一致 ✓（这验证了公式用对了）。

**顺带**：$n_0 = 60f/p = 60\times50/2 = 1500$ r/min（$p=2$ 由 1440 推断），转差率 $s = (1500-1440)/1500 = 0.04$。

::: warning 本题的陷阱
铭牌上的 $P_N$ 是**输出**机械功率，$U_N$、$I_N$ 是**线**电压线电流。三件事必须同时用对：公式才不会错。若误把 5.5 kW 当输入功率去求 $\cos\varphi$，会算出 0.72 —— 与铭牌 0.84 差一大截。
:::
:::

::: tip 例 2 · 两表法读数求总功率与功率因数
三相三线制，两表读数 $W_A = 1200$ W、$W_C = 600$ W。求总有功功率、无功功率和功率因数。

**解**

**总有功功率**（代数和，这里两表都正，直接加）：

$$
P = W_A+W_C = 1800\ \text{W}
$$

**功率因数**：

$$
\tan\varphi = \sqrt3\,\frac{W_C-W_A}{P} = \sqrt3\times\frac{600}{1800} = 0.577
$$

$$
\varphi = 30^\circ,\qquad \cos\varphi = 0.866
$$

**无功功率**：

$$
Q = P\tan\varphi = 1800\times0.577 = 1039\ \text{var}
$$

**验算**（用 $S^2 = P^2+Q^2$）：$S = \sqrt{1800^2+1039^2} = 2078$ VA，$\sqrt3U_lI_l$ 若成立需 $U_lI_l = 1200$ ✓（$2078/\sqrt3 = 1200$）

::: tip 两表读数的信息量
两表读数不仅给出 $P$，还能定出 $\cos\varphi$ —— 所以现场没有功率因数表时，接两块功率表就够用了。$W_A = W_C$ 时 $\varphi = 0$（纯阻）；$W_A = 0$ 时 $\varphi = 60^\circ$（$\cos\varphi = 0.5$）。
:::
:::

::: tip 例 3 · 一表翻负（低功率因数负载）
同一电路，负载变成 $\cos\varphi = 0.4$。设 $U_lI_l = 1000$ VA，求两表读数。

**解**

$\varphi = \arccos 0.4 = 66.4^\circ$

$$
W_A = 1000\times\cos(66.4^\circ+30^\circ) = 1000\times\cos96.4^\circ = -111\ \text{W}
$$

$$
W_C = 1000\times\cos(66.4^\circ-30^\circ) = 1000\times\cos36.4^\circ = 804\ \text{W}
$$

**总功率**：

$$
P = W_A+W_C = -111+804 = 693\ \text{W}
$$

**验算**：$\sqrt3\,U_lI_l\cos\varphi = \sqrt3\times1000\times0.4 = 693$ W ✓

::: danger 本例的操作要点
$W_A$ 是负的。实际接线时要把 $W_A$ 的电流线圈反接（否则指针反偏，模拟表会打坏），然后**按 −111 W 代入求和**。若有人把 111 当正数加进去，会得到 915 W —— 错得离谱。
:::
:::

::: tip 例 4 · 反问题：已知功率求电流
某三相负载 $P = 30$ kW、$U_l = 380$ V、$\cos\varphi = 0.75$。求线电流。

**解**

$$
I_l = \frac{P}{\sqrt3\,U_l\cos\varphi}
= \frac{30000}{\sqrt3\times380\times0.75}
= 60.8\ \text{A}
$$

**这题为什么常考**：它是选电线、选开关、选接触器的第一步 —— 所有配电计算都从"电流"开始，而现场最容易测/最常给的是**功率**。

::: tip 顺带一个估算技巧
380 V 三相系统：$I_l \approx \dfrac{P(\text{kW})}{0.66\times\cos\varphi}$（因为 $\sqrt3\times380 \approx 658$）。$\cos\varphi = 0.8$ 时 **每千瓦约 1.9 A**，现场估电流够用了。
:::
:::

## 工程实例

**为什么供电局考核功率因数？** 从 $I_l = P/(\sqrt3U_l\cos\varphi)$ 看，$\cos\varphi$ 越低，输送同样的有功功率需要的电流越大，线路损耗 $I^2R$ 按平方涨。$\cos\varphi = 0.5$ 时的线损是 $\cos\varphi = 1$ 时的 **4 倍** —— 这部分损耗由供电部门承担，所以要考核、要罚款（详见 <Prereq id="power-factor" />）。

**一块功率表能不能测三相功率？** 能，用"一表法"测三相对称负载：只测一相再乘 3。条件是负载严格对称。现场三相三线制更常用两表法，四线制用三表法 —— 因为现场负载几乎不可能严格对称。

## 易错清单

1. **$\varphi$ 是相电压与相电流的夹角**，不是线电压与线电流的夹角
2. 两表读数是**代数和**；$\cos\varphi < 0.5$ 时一表为负，**不能取绝对值相加**
3. **两表法只适用于三线制**；四线制不对称负载必须用三表法
4. $\tan\varphi$ 公式里是 **大减小**，别把顺序写反
5. 铭牌功率是**轴上输出**，求输入功率要除以效率；$U$、$I$ 是**线**量
6. $380 = \sqrt3\times220$ 只是近似（实际 $\sqrt3\times220 = 381$），算题时按题目给的数走，别纠结末位

## 考点速记

| 题型 | 公式 |
| --- | --- |
| 求总有功功率 | $P = \sqrt3U_lI_l\cos\varphi$ |
| 已知 $P$ 求电流 | $I_l = P/(\sqrt3U_l\cos\varphi)$ |
| 两表读数求 $\varphi$ | $\tan\varphi = \sqrt3(W_C-W_A)/(W_A+W_C)$ |
| 无功功率 | $Q = P\tan\varphi$ |
| 铭牌题 | 区分输入/输出功率、线量/相量 |
