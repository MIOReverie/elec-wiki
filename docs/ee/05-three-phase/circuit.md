# 12 · 三相电路

<Meta time="40 min" level="核心" note="这是电工学里最像『工程』的一章：所有结论都能从单相知识推出来，但必须先分清『线』和『相』" />

## 结论先行

1. 对称三相电源：幅值相同、频率相同、**相位互差 120°**，且 $\sum \dot U = 0$
2. **Y 接**：$U_l = \sqrt3\,U_p$，$I_l = I_p$，$\dot U_{AB}$ **超前** $\dot U_A$ 30°
3. **△ 接**：$U_l = U_p$，$I_l = \sqrt3\,I_p$
4. 对称三相电路 → **归结为一相计算**，其余两相把相位旋转 ∓120° 即可
5. **中性线的作用是把中性点钉死在 0 电位**；断开 + 负载不对称 → 中性点位移 → 轻载相电压飙升
6. 我国工频：相电压 220 V、线电压 380 V（$380 = \sqrt3\times220$）

::: tip 本章唯一要背的口诀
**「Y 起压，△ 起流」** —— Y 接时是**电压**相差 $\sqrt3$ 倍，△ 接时是**电流**相差 $\sqrt3$ 倍，另一个量两种接法下相等。
:::

## 一、为什么用三相，而不是单相

三个理由，一个比一个硬：

1. **瞬时功率恒定**。单相电路的 $p(t)$ 以两倍频率脉动（<Prereq id="power-factor" />），电机会抖；三相合成后 $p = \dfrac32U_pI_p\cos\varphi$ 是一条平线。
2. **旋转磁场**。三个空间上互差 120° 的绕组通入互差 120° 的电流，自然产生旋转磁场 —— 这是所有交流电机的地基。
3. **省铜**。同样输送功率、同样损耗，三相比单相省 25% 的导线。

## 二、三相电源与线/相电压

三相发电机的三个绕组（A-X、B-Y、C-Z）在空间上互差 120°，产生

$$
u_A = U_m\sin\omega t,\qquad u_B = U_m\sin(\omega t-120^\circ),\qquad u_C = U_m\sin(\omega t+120^\circ)
$$

**任一时刻 $u_A+u_B+u_C = 0$** —— 所以三根火线就能构成回路，不需要回线。

<FigBox title="三相对称电流：任一时刻和为零" kind="曲线" note="三条曲线围成的正、负面积始终相等。这个「和为零」是三线制（省一根中性线）的全部依据。">
<WavePreset kind="threephase" />
</FigBox>

### Y 接：$\sqrt3$ 和 30° 是怎么来的

电源 Y 接时，三个绕组的末端 X、Y、Z 接在一起成为中性点 N，首端 A、B、C 引出：

- **相电压** $\dot U_A、\dot U_B、\dot U_C$：首端到中性点，有效值 $U_p = 220$ V
- **线电压** $\dot U_{AB}、\dot U_{BC}、\dot U_{CA}$：两根火线之间，$U_l = 380$ V

用 KVL 直接推 $\dot U_{AB} = \dot U_A - \dot U_B$：

$$
\dot U_{AB} = U_p\angle 0^\circ - U_p\angle(-120^\circ)
= U_p\big[(1+0.5) + j\,0.866\big]
= \sqrt3\,U_p\angle 30^\circ
$$

**两个结论一次到手**：幅值 $\sqrt3$ 倍，相位超前 30°。B-C、C-A 同理（超前 30°，依次滞后 120°）。

<FigBox title="线电压是两个相电压之差" kind="曲线" note="灰虚线是相电压，三条实线是相电压两两相减得到的线电压：幅值 √3 倍、相位超前 30°。">
<WavePreset kind="threewire" />
</FigBox>

::: warning 最容易丢分的地方
$\sqrt3$ 关系**只对 Y 接的电源**成立。负载 Y 接时，如果中性线完好，负载相电压仍是 220 V；**一旦中性线断开且负载不对称**，负载相电压就不再是 220 V 了（见第五节）。
:::

### △ 接

三个绕组首尾相接成三角形：$U_l = U_p$（线电压就是相电压）。但线电流是相邻两个相电流之差：

$$
\dot I_A = \dot I_{AB} - \dot I_{CA} = \sqrt3\,I_p\angle(-30^\circ)
$$

即 $I_l = \sqrt3\,I_p$，线电流**滞后**对应相电流 30°。

## 三、对称三相负载 → 归结为一相

::: tip 心智模型：一相计算法 —— 对称三相 → 只算一相，其余旋转 ±120°
这是一种「降维」技巧，不是新规律。为什么成立？对称负载下 $\dot U_A、\dot U_B、\dot U_C$ 只是同一组量旋转 120° 的结果，而电路对三相完全对称（旋转对称性）——B、C 的一切结论都能从 A 相「转」出来，不必重算。
**操作顺序不能颠倒**：判断接法 → 定相电压 → 只算 A 相 → 把 A 相相量旋转 ∓120° 得 B、C → 最后才用线量关系（$I_l=I_p$ 或 $\sqrt3I_p$）。一上来就找「线电流怎么算」，最容易把自己绕晕。
:::

这是本章最实用的工具。条件：**负载对称 + 有中性线（或三线制对称）**，此时中性点电位为 0，三相彼此独立：

```
① 取出 A 相，按单相交流电路算（Z、I、P 全会）
② B 相：把 A 相的所有相量旋转 −120°
③ C 相：把 A 相的所有相量旋转 +120°
④ 中性线电流 I_N = I_A + I_B + I_C = 0
```

**为什么能这样算？** 因为 $\dot U_A、\dot U_B、\dot U_C$ 只是同一组量旋转 120° 的结果，而电路对三相完全对称 —— 数学上叫"旋转对称性"，工程上叫"一相计算法"。

## 四、中性点位移：三相版的分压器

<Prereq id="potential" /> 还记得单相的分压器吗？负载一变，分点电位就漂。三相 Y 接负载在**中性线断开**时，就是三组分压器共用同一个分点：

$$
\dot U_{N'N} = \frac{\dfrac{\dot U_A}{Z_A}+\dfrac{\dot U_B}{Z_B}+\dfrac{\dot U_C}{Z_C}}{\dfrac{1}{Z_A}+\dfrac{1}{Z_B}+\dfrac{1}{Z_C}}
\qquad
\dot U'_{A} = \dot U_A - \dot U_{N'N}\ \text{（B、C 同理）}
$$

**物理图像**：$Z_C$ 越小（负载越重），中性点 $N'$ 被 $C$ 相"吸"得越靠近 $C$ 电源端，于是 $C$ 相电压越低、另两相被抬得越高。

<FigBox title="中性点位移：一相变化如何连累另外两相" kind="曲线" note="横轴是 C 相负载阻抗的相对大小（对数刻度）。k=1 完全对称；k→0 是 C 相短路；k→∞ 是 C 相开路。">
<WavePreset kind="neutraldisp" />
</FigBox>

::: danger 中性点位移的三个后果
| 情形 | A/B 相 | C 相 | 后果 |
| --- | --- | --- | --- |
| 对称（$k=1$） | 220 V | 220 V | 正常 |
| C 相轻载（$k$ 大） | 被压低 | 升高（可到 1.5 倍） | C 相设备过压 |
| C 相短路（$k\to0$） | **冲到 380 V** | 0 | A/B 相设备瞬间烧毁 |
| C 相开路（$k\to\infty$） | 掉到 190 V | 升到 330 V | A/B 欠压、C 过压 |

所以：**三相四线制的中性线上严禁装开关、严禁装熔断器**。它断开的瞬间，负载轻的那相就会过压烧毁。
:::

## 例题

::: tip 例 1 · Y 接对称负载（一相计算法）
三相四线制，线电压 380 V。每相负载 $Z = 8+j6\,\Omega$（感性）。求相电流、线电流、中性线电流和总有功功率。

**解**

Y 接 + 有中性线 → 负载相电压 = 电源相电压 = $380/\sqrt3 = 220$ V。

**第一步：只算 A 相。**

$$
|Z| = \sqrt{8^2+6^2} = 10\,\Omega,\qquad \cos\varphi = \frac{8}{10} = 0.8,\qquad \varphi = 36.9^\circ
$$

$$
\dot I_A = \frac{220\angle 0^\circ}{10\angle 36.9^\circ} = 22\angle(-36.9^\circ)\ \text{A}
$$

**第二步：推另外两相。** 阻抗角不变，只是电源相量旋转：

$$
\dot I_B = 22\angle(-156.9^\circ)\ \text{A},\qquad \dot I_C = 22\angle 83.1^\circ\ \text{A}
$$

**第三步：Y 接 $I_l = I_p$。**

$$
I_l = I_p = 22\ \text{A}
$$

**第四步：中性线电流。** 三个相电流大小相等、相位互差 120° → 相量和为零：

$$
\dot I_N = \dot I_A+\dot I_B+\dot I_C = 0
$$

**第五步：功率。**

$$
P = \sqrt3\,U_lI_l\cos\varphi = \sqrt3\times380\times22\times0.8 = 11.58\ \text{kW}
$$

**验算**（用一相功率乘 3）：$P = 3\times220\times22\times0.8 = 11.58$ kW ✓

::: warning 本题的思路含量
**一相计算法的顺序不能颠倒**：先判断接法 → 定相电压 → 算一相 → 旋转推其余 → 最后才用线量关系。很多人一上来就找"线电流怎么算"，反而把自己绕晕。
:::
:::

::: tip 例 2 · 同一负载改成 △ 接（功率差 3 倍）
把例 1 的负载 $Z = 8+j6\,\Omega$ 改接成 △，仍接 380 V 线电压。求相电流、线电流、总功率。

**解**

△ 接时**负载相电压 = 线电压 = 380 V**（这是关键的第一步判断）。

**相电流：**

$$
I_p = \frac{380}{10} = 38\ \text{A}
$$

**线电流**（$I_l = \sqrt3 I_p$，且滞后相电流 30°）：

$$
I_l = \sqrt3\times38 = 65.8\ \text{A}
$$

**功率：**

$$
P = \sqrt3\times380\times65.8\times0.8 = 34.7\ \text{kW}
$$

**对比**：同一个阻抗，△ 接的功率是 Y 接的 **3 倍**（$34.7 / 11.58 = 3$）。

**为什么正好是 3 倍？** 两步叠加：相电压涨了 $\sqrt3$ 倍 → 相电流涨 $\sqrt3$ 倍；同时线电流又多一个 $\sqrt3$ 倍。而 $P \propto U_p I_p$，于是 $\sqrt3\times\sqrt3 = 3$。

::: tip 记住这个结论，第 17 章直接用
**正常 △ 接运行的电机，启动时改接成 Y，启动电流和启动转矩都降到 1/3。** 这就是 Y-△ 降压启动的全部依据。
:::
:::

::: tip 例 3 · 断中性线 + 不对称负载（中性点位移实算）
三相四线制给三盏白炽灯供电：A、B 相各 220 V/100 W，C 相 220 V/40 W。中性线断开后，各灯电压变成多少？哪盏灯危险？

**解**

**第一步：把灯变成电阻。**

$$
R_A = R_B = \frac{220^2}{100} = 484\,\Omega,\qquad R_C = \frac{220^2}{40} = 1210\,\Omega
$$

**第二步：用中性点位移公式。** 三相对称电源相量（有效值 220 V）代入：

$$
\dot U_{N'N} = \frac{\dfrac{\dot U_A}{484}+\dfrac{\dot U_B}{484}+\dfrac{\dot U_C}{1210}}{\dfrac{1}{484}+\dfrac{1}{484}+\dfrac{1}{1210}}
$$

分子、分母都是复数相量和。算出来（取 $\dot U_A = 220\angle0^\circ$）：

$$
|\dot U_{N'N}| = 55\ \text{V}
$$

**第三步：各相负载电压 = 电源相电压 − 中性点位移。**

$$
U'_A = U'_B \approx 198\ \text{V},\qquad U'_C \approx 275\ \text{V}
$$

**第四步：判断后果。**

- 100 W 的灯：$P = 198^2/484 = 81$ W，**变暗**（欠压 10%）
- 40 W 的灯：$P = 275^2/1210 = 62.5$ W，**过压 25%**，很快烧毁

::: warning 本例反直觉的地方
粗看会以为"电阻小的相电压低"，方向对；但**轻载那相的电压会超过额定电压**（275 V > 220 V）。中性线断开的瞬间，先烧的往往是**功率小、电阻大**的那一路 —— 老楼里"灯总是一齐坏"常和这个有关。
:::
:::

::: tip 例 4 · 中性线电流：什么时候不为零
三相四线制，$U_p = 220$ V，$Z_A = 20\angle0^\circ\,\Omega$、$Z_B = 20\angle(-30^\circ)\,\Omega$、$Z_C = 20\angle30^\circ\,\Omega$。求各相电流和中性线电流。

**解**

有中性线 → 每相独立，相电压都是 220 V：

$$
\dot I_A = \frac{220\angle0^\circ}{20\angle0^\circ} = 11\angle0^\circ\ \text{A}
$$

$$
\dot I_B = \frac{220\angle(-120^\circ)}{20\angle(-30^\circ)} = 11\angle(-90^\circ)\ \text{A}
$$

$$
\dot I_C = \frac{220\angle120^\circ}{20\angle30^\circ} = 11\angle90^\circ\ \text{A}
$$

**中性线电流**（KCL，注意是**相量和**不是算术和）：

$$
\dot I_N = \dot I_A+\dot I_B+\dot I_C = 11 + (-j11) + (j11) = 11\angle0^\circ\ \text{A}
$$

本例 $\dot I_B$ 与 $\dot I_C$ 的虚部正好抵消，剩下与 $\dot I_A$ 同相的 11 A。

**一般规律**：
- 负载**对称**（三相阻抗完全相同）→ $\dot I_N = 0$，可以省掉中性线（三相三线制）
- 负载**不对称** → $\dot I_N \ne 0$，**必须**有中性线；否则进入中性点位移，见例 3

::: tip 判断口诀
"**对称可省线，不对称必须留**"。注意"对称"指三相**阻抗完全相同**（大小和阻抗角都要一样），不是"功率相同"。
:::
:::

## 工程实例

**为什么家里是 220 V，工厂动力是 380 V？** 都是从同一套 Y 接系统引出来的：火线到中性点 220 V（相电压）供照明和家用电器；两根火线之间 380 V（线电压）接三相电机。三相电机内部是三相绕组，本来就需要三相电源；而单相设备取一根火线加中性线即可 —— **一套系统，两种用法**。

**中性线为什么不能断？** 居民楼是典型的不对称负载（各家电器不同时开）。物业检修时若误断中性线，轻载的那几户电压飙升，电视机、空调率先烧毁。因此规范要求中性线截面不小于火线，且不得加开关/熔断器。

## 易错清单

1. **$\sqrt3$ 只对 Y 接成立**，△ 接是 $U_l = U_p$；搞反接法是本章第一大错
2. **Y 接的 30° 是"线电压超前相电压"**，△ 接是"线电流滞后相电流 30°"—— 一个在电压侧，一个在电流侧，别记混
3. **相量运算不能直接用有效值相加**：$\dot U_{AB} = \dot U_A - \dot U_B$ 是相量差，不是 $220-220$
4. **一相计算法的前提是"对称 + 中性点不位移"**；不对称三线制必须先算中性点位移
5. **中性线电流是相量和**，三个 10 A 的相电流其中线电流可能是 0，也可能是 17 A
6. 铭牌上的 380 V / 220 V 是**线**电压，电机内部每相承受的是 220 V（Y 接时）

## 考点速记

| 题型 | 第一步 |
| --- | --- |
| 已知 $U_l$ 求负载相电压 | 先判断 Y / △，再决定乘 $\sqrt3$ 还是不变 |
| 求线电流 | 一相算完再推其余，最后用 $I_l = I_p$（Y）或 $\sqrt3I_p$（△） |
| 断中性线 / 不对称 | 用中性点位移公式，逐相算 $\dot U_\text{相}-\dot U_{N'N}$ |
| 求中性线电流 | KCL：$\dot I_N = \dot I_A+\dot I_B+\dot I_C$（相量和） |
| 同一负载 Y 改 △ | 功率 ×3、电流 ×3 |
