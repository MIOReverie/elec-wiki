# 05 · 叠加定理 · 戴维南 · 最大功率

<Meta time="50 min" level="核心" note="戴维南定理是本章最值钱的工具，多数综合大题的第一步都是它" />

一个盒子，从外面看只有两个端子，里面是一团含源的网络。不拆盒子，你凭什么知道它对负载等效成什么？

这个问题工程上天天遇到：一块板子、一个传感器、一段前级电路，你只关心它从两个端子往外能给出多少电压、多大内阻。三件工具分别回答三个层面的问题：多个源时怎么拆开算，整个盒子怎么缩成一个电源加一个电阻，负载取多大才能拿到最多功率。

::: tip 读这页之前
电阻串并联（<Prereq id="series-parallel" />）、电源等效变换（<Prereq id="source-transform" />）、结点电压法（<Prereq id="nodal" />），戴维南和叠加都建在这三样上面。

本页符号：$U_{OC}$（开路电压，端子不接负载时的端电压）、$I_{SC}$（短路电流）、$R_{eq}$（等效内阻），受控源的控制量写作 $U_x$ 或 $I_x$。全部约定见[符号与约定](../../guide/notation.md)。

三个词先各给一句话：**受控源**是输出由电路中别处的电压或电流控制的电源，它不属于独立源，叠加时不能关掉；**戴维南等效**是把含源二端网络缩成「一个开路电压串一个内阻」；**诺顿等效**是同一个网络的「短路电流并内阻」版本。
:::

## 一、叠加定理

线性电路里，几个独立源共同作用产生的响应，等于它们各自单独作用时响应的代数和。

道理不复杂。所有源同时乘以常数 $k$，全电路响应也乘 $k$，这叫齐次性；源相加时响应也相加，这叫可加性。两条合起来就是叠加。

用之前先确认三件事，缺一条都不行：

1. 电路是线性的，所有元件满足齐次性和可加性。
2. 只对独立源做分解。
3. 受控源永远保留，它不是独立源。

::: warning 三步操作
```
① 保留一个独立源，其余独立源置零：
   电压源 → 短路（理想电压源 U=0 就是一根导线）
   电流源 → 开路（理想电流源 I=0 就是断路）
   ★ 受控源 → 原样保留，绝不置零
② 单独求目标响应（电流或电压）
③ 代数相加（注意方向：同向相加，反向相减）
```

最高频的错误，是把电压源置零时画成「去掉电源」。电压源置零是短接一根线，不是断开；电流源置零才是断开。这两件事搞反，后面每一步都白算。
:::

<CircuitFig kind="superpose" title="叠加：每次只留一个源" />

<FigBox title="叠加不是包络，是逐点相加" kind="曲线" note="绿线（和）是蓝线与橙线的逐点代数和。注意某些时刻两条分量同号，相加后比任何一条都大；某些时刻反号，叠加后互相抵消。">

</FigBox>

**功率不能叠加**，这条要单独说。$P=UI$ 里 $U$ 和 $I$ 各自由多个源贡献，乘起来会多出交叉项：

$$
P = UI,\quad U = U_1+U_2,\quad I=I_1+I_2
$$

$$
UI = (U_1+U_2)(I_1+I_2) = \underbrace{U_1I_1 + U_2I_2}_{\text{分开算}} + \underbrace{U_1I_2+U_2I_1}_{\text{交叉项，漏掉了！}}
$$

把 $U=U_1+U_2$ 与 $I=I_1+I_2$ 同时代进去，展开后除了各自那一项，还会多出两个交叉项 $U_1I_2$ 与 $U_2I_1$。所以：

$$
\boxed{P \ne P_1+P_2}
$$

功率与电流是平方关系（$P \propto I^2$），平方之后没有任何线性可言。电阻上白掉的功率是 $I^2R$，它跟电流的平方成正比，两个源各贡献一点电流，合起来的发热绝不只是两笔发热相加。正确做法是先用叠加求出总电压或总电流，再算功率。

## 二、戴维南定理：切一刀，再接回去

**戴维南定理**（Thévenin's theorem）给黑盒子一个标准答案：任何线性二端网络，对外部电路来说，都等效于一个电压源 $U_{OC}$ 串一个电阻 $R_{eq}$。$U_{OC}$ 是端口空载时的端电压，$R_{eq}$ 是盒内独立源全部置零后从端口看进去的等效电阻。

<CircuitFig kind="thevenin" title="戴维南：在端口处把电路切开" />

::: tip 心智模型：切割，然后看网孔
1. 切割：在端口 A、B 处把待求支路（负载）和网络 N 切开。N 对外只剩 A、B 两个端点。
2. A、B 上的数值由网孔决定：$U_{OC}$、$R_{eq}$ 不是凭空来的，它们取决于 N 内部那一个或几个回路。求 $U_{OC}$ 的实质，是先把切割后回路的电流算出来，再用 KVL 把 A、B 两点间的电压写下来。
3. 切割可以做好几次：N 内部还复杂就再切一刀，拆成几个子网络，各自先求等效再拼回去。串联就电压相加、电阻相加，并联就电流相加、电阻并联。
:::

### 第 1 步：求 $U_{OC}$

断开负载，量端口 A、B 之间的开路电压。按上面的心智模型，这一步的实质是：把切割后剩下的回路电流先算出来，再用 KVL 把 A、B 间的电压表达出来。

三种求法，按可靠性排序：

1. 用 <Prereq id="nodal" /> 或 KVL 直接求
2. 用叠加定理分源求，多个电源时看得更清楚
3. 用 <Prereq id="y-delta" /> 先化简再求

有一点必须记牢：$U_{OC}$ 与负载无关，它只由网络内部决定。换一个负载接上去，$U_{OC}$ 一个数都不会变，变的是端电压。

### 第 2 步：求 $R_{eq}$

不含受控源时最省事：把所有独立源置零，电压源的电压取 $0$、电流源的电流取 $0$，于是电压源短路、电流源开路，然后直接求端口 A、B 间的等效电阻。

含受控源时只能用外加电源法。在端口 A、B 外加一个电压 $U$，求流进端口的电流 $I$：

$$
R_{eq} = \frac{U}{I}
$$

外加的电压和流进来的电流要用同一个参考方向，约定 $I$ 流入 A 端为正。

还有一个万能式子，前提是开路和短路都存在：

$$
R_{eq} = \frac{U_{OC}}{I_{SC}}
$$

端口开路时电流无界（$I_{SC}=\infty$），或者短路时电压无界，这个式子就失效了，必须回到前面两种。

### 第 3 步：接回负载

$$
I = \frac{U_{OC}}{R_{eq}+R_L},\qquad U_L = \frac{R_L}{R_{eq}+R_L}U_{OC}
$$

$$
P_L = \frac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2
$$

这三个量里，$U_{OC}$ 和 $R_{eq}$ 是网络自己的属性，$R_L$ 是你接上去的。同一块电路换负载，只改 $R_L$，$U_{OC}$ 与 $R_{eq}$ 一个都不动。很多人算错就错在这儿：把 $R_L$ 混进了 $R_{eq}$ 里。

### 诺顿定理与两者的关系

**诺顿定理**（Norton's theorem）是戴维南的电流源版本：$I_{SC}$ 并 $R_{eq}$。这里的 $I_{SC}$ 是端口直接短接时流过的电流。

两者是同一件事的两种画法，换算关系就一条：

$$
I_{SC} = \frac{U_{OC}}{R_{eq}}
$$

反过来写也一样，$U_{OC} = I_{SC}R_{eq}$。记住这一个式子，两个定理就不用分开背。

::: tip 什么时候用戴维南、什么时候用诺顿
端口串联别的电路，用戴维南（电压源串电阻）自然；端口并联别的电路，用诺顿（电流源并电阻）自然；要算功率，用戴维南更省事，$P_L$ 的式子简洁。

口诀：戴维南求串联，诺顿求并联。
:::

## 三、含受控源怎么求 $R_{eq}$

以一个含电压控制电流源（VCCS，voltage-controlled current source）的电路为例：一个 $R_1$ 与 VCCS（$\beta V_1$）并联，再串一个 $R_2$。在端口外加电压 $U$，看流进去多少电流，也就是求 $I = U/R_{eq}$。

三步：

1. 在端口加测试电压 $U$。
2. 用 <Prereq id="nodal" /> 或 KCL 求出 $I$，把受控源的控制量用测试电压表示。控制电压 $V_1$ 通常就取自 $R_1$ 两端的电压。
3. 算 $R_{eq} = U/I$。

受控源在这一步必须保留，它对外等效电阻是有贡献的。

### 特殊情况：$R_{eq} = 0$ 或 $R_{eq} = \infty$

三种极端情形，都别套常规公式，得回到定义：

- 端口被理想电压源直接短路，$R_{eq}=0$
- 端口被理想电流源直接开路，$R_{eq}=\infty$
- 负阻电路，$R_{eq} < 0$，比如隧道二极管、有源滤波器

::: warning $R_{eq}$ 可以是负数
含受控源的电路里，$R_{eq}$ 可能算出负值。无源电路不可能出现这种结果，因为电阻必为正。

真实存在这种电路的：放大器反馈网络、隧道二极管。工程上的应用是负阻振荡器和隧道二极管放大器。
:::

## 四、最大功率传输

对 $P_L = \dfrac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2$ 求导，令导数为零：

$$
\frac{dP_L}{dR_L} = 0 \;\Rightarrow\; \boxed{R_L = R_{eq}}
$$

$$
\boxed{P_{max} = \frac{U_{OC}^2}{4R_{eq}}}
$$

效率是负载功率占总功率的比例：

$$
\eta = \frac{P_L}{P_{总}} = \frac{R_L}{R_{eq}+R_L}
$$

匹配时 $P_{max} = \dfrac{U_{OC}^2}{4R_{eq}}$，而 $\eta = 50\%$。

把这句话翻译成大白话：负载电阻等于电源内阻（$R_L=R_{eq}$）时，负载拿到的功率最大，代价是能量有一半（50%）烧在电源自己身上。求极值时令 $dP_L/dR_L$ 为零，解出来正是 $R_L=R_{eq}$，这个条件和平常见到的分压比没有关系，它只跟 $R_{eq}$ 有关。

<FigBox title="功率曲线与效率曲线" kind="曲线" note="功率最大时效率恰好 50%：R_L = R₀ 时负载拿到的功率刚好等于被浪费的功率。电力系统绝不这样匹配——因为远距离输电中线损比负载功率更重要。">
<WavePreset kind="maxpower" :p="0.08" />
</FigBox>

::: tip 为什么电力系统不追求最大功率传输
电力传输的主要成本是线损 $I^2R$。$R_L$ 很小意味着电流很大，线损跟着涨。实际策略是让负载电流尽量小，用升压、降压变压器把负载折算到远大于线阻的状态，此时效率接近 1（$\eta \to 1$），代价是负载电压电流偏离额定值。

所以最大功率匹配用于低功率信号电路（功放、天线），最大效率匹配用于电力传输。
:::

说到匹配条件，得把 $R_L = R_{eq}$ 这句话读准：等号右边是电源的等效内阻，不是负载自身的一部分。换到交流情形，这个条件还要再改。

交流电路里，最大平均功率的条件是共轭匹配：

$$
Z_L = Z_{eq}^* \quad\text{（共轭）}
$$

即 $R_L = R_{eq}$ 且 $X_L = -X_{eq}$，虚部取反。详见 <Prereq id="impedance" /> 与交流篇。

## 五、互易定理

在纯电阻网络里，若从端口 1 注入电流 $I$ 使端口 2 产生电压 $U$，那么从端口 2 注入同样的电流 $I$，端口 1 上会产生同样的 $U$。写成一条式子就是 $R_{12}=R_{21}$，两个端口互换位置，比值不变。

$$
\boxed{R_{12} = R_{21}}
$$

三条注意事项：只适用于纯电阻线性网络，不含受控源、不含电源；「同一电流」这个前提很关键；这个概念题很常见，判断题里常拿来设陷阱。

先想一句：两个源并联，直接解要列好几个方程。先切负载、用叠加求 $U_{OC}$（每个源单独作用，另一个短路），再把源置零按并联求 $R_{eq}$，最后接回 $R_L$ 一步分压。戴维南把「两个源加内阻」压成一个 $U_{OC}$ 串 $R_{eq}$，负载支路只剩最简分压。

第 1 步，求 $U_{OC}$。断开 $R_L$，两个电源带内阻并联输出，用叠加：

- 只看 $E_1$（把 $E_2$ 短路、保留 $R_{02}=3\Omega$）：$U_{oc1} = \dfrac{12}{2+3}\times3 = 7.2\text{V}$，$E_1$ 经 $R_{01}$ 给 $R_{02}$ 分压
- 只看 $E_2$（把 $E_1$ 短路、保留 $R_{01}=2\Omega$）：$U_{oc2} = \dfrac{6}{3+2}\times2 = 2.4\text{V}$
- 叠加，两个源极性相同、都把输出端往上抬：$U_{OC} = 7.2+2.4 = 9.6\text{V}$

第 2 步，求 $R_{eq}$。两个电压源都短路，$R_{01}$ 与 $R_{02}$ 都接地，从端口看是并联：

$$
R_{eq} = 2\parallel3 = \frac{6}{5} = 1.2\Omega
$$

第 3 步，接负载。

$$
I_L = \frac{9.6}{1.2+6} = \frac{9.6}{7.2} = 1.333\text{A}
$$

$$
U_L = I_L \times 6 = 8\text{V}
$$

回代验证，用弥尔曼定理再算一遍。两个电源极性相同，$+$ 都朝外：

$$
V = \frac{12/2 + 6/3}{1/2+1/3} = \frac{6+2}{0.8333} = 9.6\text{V}\quad(\text{这是 } U_{OC}) ✓
$$

带载时 $R_{eq}=1.2\Omega$ 串 $R_L=6\Omega$：

$$
I = \frac{9.6}{7.2}=1.333\text{A},\quad U_L = 1.333\times6 = 8\text{V}
$$

两条路的结果完全一致 ✓

工程意义：两个电源并联、$E_1 > E_2$ 时，$E_2$ 其实在被充电，它的电流方向是流回自己内部。真实电源的内阻不会这么小，并联时必须保证电压一致，否则形成大环流。
:::

::: tip 例 1+ · 多次切割：网络内部再切一刀
两级电源级联供电：前级 $E_1 = 10\text{V}$（内阻 $R_1 = 2\Omega$），后级 $E_2 = 6\text{V}$（内阻 $R_2 = 3\Omega$），两者串联，前级的输出接后级的输入。求从最右端看进去、对负载 $R_L$ 的戴维南等效。

先想一句：每一级本身就是戴维南形，串联时电压相加、电阻相加。先给每块单独算等效，再拼回去，和从最右端硬求是同一件事，但省太多。戴维南等效在端口对外成立，块与块之间在端口相接，串联组合的参数就是各自参数之和。

第 1 刀，在端口 A、B 切开，得到整个网络 N。

第 2 刀，N 内部还能再切，它本身就是前级等效块串后级等效块。每块已经是戴维南形：

- 前级：$U_{OC1} = E_1 = 10\text{V}$，$R_{eq1} = R_1 = 2\Omega$
- 后级：$U_{OC2} = E_2 = 6\text{V}$，$R_{eq2} = R_2 = 3\Omega$

拼回去，串联就电压相加、电阻相加：

$$U_{OC} = U_{OC1} + U_{OC2} = 10 + 6 = 16\text{V},\qquad R_{eq} = R_{eq1} + R_{eq2} = 2 + 3 = 5\Omega$$

验算，直接算：原电路总电动势 $10+6=16\text{V}$、总内阻 $2+3=5\Omega$，带 $R_L$ 时 $I = \dfrac{16}{5+R_L}$，与等效电路一致 ✓。

这就是可多次切割的意思：先切端口得到 N，N 内部再切，每块各自求等效，再组合。网络越复杂，这种由内向外的逐层等效越省事。
:::

::: tip 例 2 · 含受控源电路的 $R_{eq}$（外加电源法）
电路：一个 $R_1$，阻值 $5\Omega$，并联 VCCS（$\beta V_1$，$\beta=2\text{S}$，方向流入），另一支路 $R_2=10\Omega$ 串联。端口 A 接并联那一侧，B 接 $R_2$ 另一侧（参考）。求从 A-B 看进去的 $R_{eq}$。

先想一句：含受控源不能用「源置零再化简」，只能外加一个测试电压 $U$、用结点法求出灌入端口的电流 $I$，再算 $R_{eq}=U/I$。算完把 $\beta$ 设成 0 验一下，应该回到纯电阻并联值。为什么非要加测试源：受控源让端口呈现的电阻取决于内部的电流电压关系，只有外加激励才能量出这个比值。

第 1 步，外加测试电压。在 A-B 间加测试电压 $U$（A 为正）。

第 2 步，用结点电压法。设参考点为 B（$V_B=0$），则 $V_A = U$。控制电压 $V_1$ 取自 $R_1$ 两端的电压，也就是 A 点电位，$V_1 = U$。

题目这段描述是含糊的，含糊到你没法判断 $R_1$ 的另一端接在哪里。这种时候别硬算，先画草图。按最常见的读法，$R_1$、VCCS、$R_2$ 三条支路都接在 A 与 B 之间。

第 3 步，求流入端口的电流 $I$，方向从 B 流向 A，也就是从外部灌入。三条支路的电流都要算：$R_1$ 是 $5\Omega$，$R_2$ 是 $10\Omega$，VCCS 给出 $2U$。

先算容易错的那一条。有人想当然地写 $R_1$ 上的电流是 $\dfrac{U - V_1}{R_1} = 0$，理由是控制电压 $V_1 = V_A = U$。这个式子错在把控制量当成了结点电位：$V_1$ 是受控源的输入信号，不是 $R_1$ 另一端的电位。$R_1$ 的另一端接的是参考点 $0$，两端电压就是 $U$。

一条一条来：

- 经 $R_1$ 流出：端点从 $U$ 到 $0$，电流是 $\dfrac{U-0}{5}=\dfrac{U}{5}$，也就是 $\dfrac{U}{5} = 0.2U$
- 经 $R_2$ 流出：同样从 A 到 B，$\dfrac{U}{10} = 0.1U$，按流出为正记 $+0.1U$
- 经 VCCS 流出：它是一个大小 $2U$ 的电流源，箭头标着流入 A，按流出为正就记 $-2U$

对结点 A 列 KCL，约定流出为正：

$$
\underbrace{\frac{U}{R_1}}_{\text{经}R_1} + \underbrace{\beta\cdot U}_{\text{VCCS流出（正流入为负）}} + \underbrace{\frac{U}{R_2}}_{\text{经}R_2} - \underbrace{I}_{\text{流入A的外部电流}} = 0
$$

$$
\frac{U}{5} + 2U + \frac{U}{10} = I
$$

$$
I = U\left(0.2 + 2 + 0.1\right) = 2.3U
$$

第 4 步，求等效电阻。

$$
R_{eq} = \frac{U}{I} = \frac{U}{2.3U} = \frac{1}{2.3} \approx 0.435\Omega
$$

验一下极限：若没有 VCCS（$\beta=0$），$R_1$ 与 $R_2$ 就退化成纯并联，$R_{eq} = \dfrac{1}{0.2+0.1} = 3.33\Omega = 5\parallel10$ ✓。加了 VCCS 之后 $R_{eq}$ 降到 0.435，说明它在帮着往端口里灌电流，端口看到的等效电阻跟着变小。

::: tip 本例真正要掌握的
1. 画草图。题目的文字描述一定有歧义，画了图才列得对方程。
2. 外加电源法的核心：把端口当电压源，列一次 KCL 求 $I$，然后 $R_{eq} = U/I$。
3. 受控源保留，控制量用测试电压表示（$V_1 = U$）。
4. 算完回过头看 $\beta\to0$ 的极限，应该回到纯电阻并联值。这一步能查出大部分计算错误。
:::
:::

::: tip 例 3 · 最大功率传输（含效率分析）
用例 1 的等效电路：$U_{OC}=9.6\text{V}$、$R_{eq}=1.2\Omega$。求：(a) $R_L$ 取何值时负载功率最大？最大值多少？(b) 此时效率多少？

先想一句：直接套最大功率条件 $R_L=R_{eq}$，再用 $P_{max}=U_{OC}^2/4R_{eq}$ 求值；效率用 $\eta=R_L/(R_{eq}+R_L)$，在匹配点必然是 50%。为什么恰好一半：匹配时内阻和负载分到的功率相等，送进去的能量一半发热，一半给了负载。

(a) 最大功率条件：$R_L = R_{eq} = 1.2\Omega$

$$
P_{max} = \frac{U_{OC}^2}{4R_{eq}} = \frac{9.6^2}{4\times1.2} = \frac{92.16}{4.8} = 19.2\text{W}
$$

(b) 效率：

$$
\eta = \frac{R_L}{R_{eq}+R_L} = \frac{1.2}{1.2+1.2} = 50\%
$$

看一下物理图像：此时负载电流 $I = \dfrac{9.6}{2.4}=4\text{A}$，负载功率 $= I^2R_L = 16\times1.2=19.2\text{W}$，而内阻上损耗 $I^2R_{eq}=16\times1.2=19.2\text{W}$。送进去的 $9.6\times4=38.4\text{W}$，一半变成了内阻发热。

换个高效率的方案对比：若 $R_L = 24\Omega$，也就是 $20\times R_{eq}$：

- $I = \dfrac{9.6}{25.2}=0.381\text{A}$
- $P_L = 0.381^2\times24 = 3.48\text{W}$，功率更小
- $\eta = \dfrac{24}{25.2}=95.2\%$，效率更高

功率最大和效率最高，是两个完全不同的优化目标。做题前先看清题目问哪个。
:::

## 考点速查

| 题型 | 第一步 |
| --- | --- |
| 求某电阻的电流电压，电路复杂 | 把其余部分做戴维南等效 |
| $R_L$ 为何值时功率最大 | $R_L = R_{eq}$ |
| 多个电源、求一条支路 | 叠加定理 |
| 含受控源求等效电阻 | 外加电源法，或 $U_{OC}/I_{SC}$ |
| 交流最大功率 | 共轭匹配 $Z_L = Z_{eq}^*$ |
| 求两电阻是否等效 | <Prereq id="y-delta" /> 或直接化简 |

## 易错点（按踩坑频率排序）

1. 受控源不能置零。求 $R_{eq}$ 时受控源要保留，用外加电源法。
2. 电压源置零等于短路，接一根线；电流源置零等于开路，断开。别搞反。
3. 功率不能叠加，$P_1+P_2 \ne P$，要先叠加出总电流再算功率。
4. 叠加时每个独立源单独作用，要画独立的电路图，别在一张图上改来改去。
5. 戴维南等效只对端口外成立，求网络内部的功率必须回到原电路。
6. 最大功率匹配时效率只有 50%，电力系统从不这么工作。
7. $R_{eq}$ 可能是负数，含受控源时会出现。
8. $U_{OC}/I_{SC}$ 法在 $I_{SC}=\infty$ 或 $U_{OC}=\infty$ 时失效。
9. 互易定理只适用于纯电阻线性网络，不含受控源和电源。
