# 05 · 叠加定理 · 戴维南 · 最大功率

<Meta time="50 min" level="核心" note="戴维南定理是本章最值钱的工具，几乎每道综合大题的第一步都是它" />

## 结论先行

1. **叠加定理**：线性电路中，各独立源单独作用之和 = 共同作用。不作用的电压源短路、电流源开路，**受控源保留**。
2. **戴维南定理**：含源线性二端网络 = $U_{OC}$ 串 $R_{eq}$；诺顿 = $I_{SC}$ 并 $R_{eq}$；$U_{OC} = I_{SC}R_{eq}$。
3. **最大功率传输**：$R_L = R_{eq}$ 时 $P_{max} = \dfrac{U_{OC}^2}{4R_{eq}}$，但效率只有 50%。
4. **功率不能叠加**（$P \propto I^2$），也不存在"频率相关"的等效 —— 戴维南等效是**纯电阻**的等效，仅对直流/单频正弦有效。
5. **互易定理**（补充）：线性电阻网络中，$R_{12}=R_{21}$（单端口等效电阻），常考判断题。

## 一、叠加定理：为什么成立

**线性电路的响应 = 各独立源单独作用的响应之和。**

证明思路（了解即可）：若所有源同时乘以常数 $k$，全电路响应也乘 $k$（齐次性）；若源相加，响应相加（可加性）。这两个性质合起来就是叠加。

**三个必要条件**，缺一不可：

1. 电路是**线性**的（所有元件满足齐次性 + 可加性）
2. 只对**独立源**做分解
3. **受控源永远保留**（它不是独立源）

::: warning 叠加定理的三步操作
```
① 保留一个独立源，其余独立源置零：
   电压源 → 短路（理想电压源 U=0 就是一根导线）
   电流源 → 开路（理想电流源 I=0 就是断路）
   ★ 受控源 → 原样保留，绝不置零
② 单独求目标响应（电流或电压）
③ 代数相加（注意方向：同向相加，反向相减）
```

**最高频错误：把电压源置零时画成"去掉电源"** —— 电压源短路就是短接一根线，不是断开！电流源开路才是断开。
:::

<CircuitFig kind="superpose" title="叠加：每次只留一个源" />

<FigBox title="叠加不是包络，是逐点相加" kind="曲线" note="绿线（和）是蓝线与橙线的逐点代数和。注意某些时刻两条分量同号，相加后比任何一条都大；某些时刻反号，叠加后互相抵消。">
<WavePreset kind="superpose" />
</FigBox>

**功率为什么不能叠加**：

$$
P = UI,\quad U = U_1+U_2,\quad I=I_1+I_2
$$

$$
UI = (U_1+I_2)(I_1+I_2) = \underbrace{U_1I_1 + U_2I_2}_{\text{分开算}} + \underbrace{U_1I_2+U_2I_1}_{\text{交叉项，漏掉了！}}
$$

所以：

$$
\boxed{P \ne P_1+P_2}
$$

**正确做法**：用叠加求出总电压或总电流，再算功率。

## 二、戴维南定理：三步法

**定理**：任何线性二端网络（从外部看只有两个端子），对外部电路而言，等效于一个电压源 $U_{OC}$ 串一个电阻 $R_{eq}$。

<CircuitFig kind="thevenin" title="戴维南：在端口处把电路切开" />

::: tip 心智模型：戴维南是「切割 + 看网孔」，不是死记三步
1. **切割**：在端口 A、B 处把待求支路（负载）和网络 N 切开。N 对外部只剩 A、B 两个端点。
2. **A、B 的数值由网孔决定**：$U_{OC}$、$R_{eq}$ 不是凭空来的——它们取决于 N 内部那一个（或几个）网孔回路。所以**求 $U_{OC}$ 的实质**是：先把切割回路的电流算出来，再用 KVL 把 A、B 两点间的电压写下来。
3. **切割可以多次**：N 内部若还复杂，就再切一刀，把 N 拆成几个子网络，各自先求等效，再拼回去（串则电压相加、电阻相加；并则电流相加、电阻并联）。
:::

### 第 1 步：求 $U_{OC}$（切一刀，算切割回路电流，KVL 写 U_AB）

断开负载，从端口 A、B 测量开路电压。**对应心智模型第 2 步**：这一步的本质是——把切割后剩下的回路电流先算出来，再用 KVL 把 A、B 两点间的电压表达出来（参见上面的「切割」图）。

**三种方法**（按可靠性排序）：
1. 用 <Prereq id="nodal" /> 或 KVL 直接求
2. 用叠加定理分源求（多个电源时更清晰）
3. 用 <Prereq id="y-delta" /> 先化简

**注意**：$U_{OC}$ 一定**与负载无关**，只由网络内部决定。

### 第 2 步：求 $R_{eq}$

**方法 A（不含受控源）**：把所有独立源置零 → 电压源短路、电流源开路 → 直接求端口 A、B 间的等效电阻。

**方法 B（含受控源）**：**外加电源法**

在端口 A、B 外加一个电压 $U$，求流入端口的电流 $I$：

$$
R_{eq} = \frac{U}{I}
$$

注意：**外加的电压和流进来的电流**，要用同一个参考方向（$I$ 流入 A 端为正）。

**方法 C（万能但要求开路/短路都存在）**：

$$
R_{eq} = \frac{U_{OC}}{I_{SC}}
$$

**限制**：如果端口开路时电流无界（$I_{SC}=\infty$）或短路时电压无界，这个公式失效，必须回到方法 A/B。

### 第 3 步：接回负载

$$
I = \frac{U_{OC}}{R_{eq}+R_L},\qquad U_L = \frac{R_L}{R_{eq}+R_L}U_{OC}
$$

$$
P_L = \frac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2
$$

### 诺顿定理与两者的关系

诺顿：$I_{SC}$ 并 $R_{eq}$。它和戴维南只是同一件事的两种画法：

$$
I_{SC} = \frac{U_{OC}}{R_{eq}}
$$

::: tip 什么时候用戴维南、什么时候用诺顿
- 端口**串联**其他电路 → 用戴维南（电压源串电阻）自然
- 端口**并联**其他电路 → 用诺顿（电流源并电阻）自然
- 求功率 → 戴维南更方便（$P_L$ 公式简洁）

**口诀：戴维南求串联，诺顿求并联。**
:::

## 三、含受控源时求 $R_{eq}$（难点）

### 外加电源法的标准流程

以一个含电压控制电流源（VCCS）的电路为例：

- 电路：一个 $R_1$ 并联 VCCS（$\beta V_1$），$R_2$ 串联
- 在端口外加电压 $U$，求 $I = U/R_{eq}$

**步骤**：
1. 在端口加测试电压 $U$
2. 用 <Prereq id="nodal" /> 或 KCL 求出 $I$（把受控源的控制量用测试电压表示）
3. $R_{eq} = U/I$

**关键点**：受控源在**这一步必须保留**，因为它对外等效电阻有贡献。

### 特殊情况：$R_{eq} = 0$ 或 $R_{eq} = \infty$

- 端口被理想电压源直接短路 → $R_{eq}=0$
- 端口被理想电流源直接开路 → $R_{eq}=\infty$
- 负阻电路 → $R_{eq} < 0$（如隧道二极管、有源滤波器）

::: warning $R_{eq}$ 可以是负数！
如果电路含受控源，$R_{eq}$ 可能是**负值** —— 这在无源电路里不可能（电阻必为正）。这种情况出现在有源电路（放大器反馈网络、隧道二极管）中。

负阻的实际应用：负阻振荡器、隧道二极管放大器。
:::

## 四、最大功率传输

对 $P_L = \dfrac{R_L}{(R_{eq}+R_L)^2}U_{OC}^2$ 求导，令导数为零：

$$
\frac{dP_L}{dR_L} = 0 \;\Rightarrow\; \boxed{R_L = R_{eq}}
$$

$$
\boxed{P_{max} = \frac{U_{OC}^2}{4R_{eq}}}
$$

效率：

$$
\eta = \frac{P_L}{P_{总}} = \frac{R_L}{R_{eq}+R_L}
$$

当 $R_L=R_{eq}$ 时，$\eta = 50\%$。

<FigBox title="功率曲线与效率曲线" kind="曲线" note="功率最大时效率恰好 50%：R_L = R₀ 时负载拿到的功率刚好等于被浪费的功率。电力系统绝不这样匹配——因为远距离输电中线损比负载功率更重要。">
<WavePreset kind="maxpower" :p="0.08" />
</FigBox>

::: tip 为什么电力系统不追求最大功率传输？
电力传输的成本主要是**线损** $I^2R$。若 $R_L$ 很小（短路电流大），线损 $I^2R$ 会剧增。实际策略是**让负载电流尽可能小**，用**升压-降压变压器**把负载"匹配"到远小于线阻的高电阻状态 —— 此时效率高（$\eta \to 1$），代价是负载电压/电流偏离额定。

**所以"最大功率匹配"用于低功率信号电路（功放、天线），"最大效率匹配"用于功率传输。**
:::

**交流情形（共轭匹配）**：在交流电路里，最大平均功率的条件不是 $R_L=R_{eq}$，而是

$$
Z_L = Z_{eq}^* \quad\text{（共轭）}
$$

即 $R_L = R_{eq}$ 且 $X_L = -X_{eq}$（虚部相反）。详见 <Prereq id="impedance" /> 与交流篇。

## 五、互易定理（补充了解）

**定理**：在**纯电阻网络**中，若从端口 1 注入电流 $I$ 在端口 2 产生电压 $U$，则从端口 2 注入同一电流 $I$ 在端口 1 产生同样的 $U$。

$$
\boxed{R_{12} = R_{21}}
$$

**注意**：
- 只适用于**纯电阻**线性网络（不含受控源、不含电源）
- "同一电流"很关键
- 常出概念判断题

## 例题

::: tip 例 1 · 戴维南三步法（标准考题）
电路：$E_1 = 12\text{V}$（内阻 $R_{01}=2\Omega$）、$E_2 = 6\text{V}$（内阻 $R_{02}=3\Omega$）并联供电，负载 $R_L=6\Omega$ 接在输出端。求负载电流与电压。

**解**

**第一步：求 $U_{OC}$。** 断开 $R_L$，两个电源带内阻并联输出。用叠加：

- 只看 $E_1$（把 $E_2$ 短路、保留 $R_{02}=3\Omega$）：$U_{oc1} = \dfrac{12}{2+3}\times3 = 7.2\text{V}$（$E_1$ 经 $R_{01}$ 给 $R_{02}$ 分压）
- 只看 $E_2$（把 $E_1$ 短路、保留 $R_{01}=2\Omega$）：$U_{oc2} = \dfrac{6}{3+2}\times2 = 2.4\text{V}$
- 叠加（极性相同，都抬高输出端）：$U_{OC} = 7.2+2.4 = 9.6\text{V}$

**第二步：求 $R_{eq}$。** 两个电压源都短路 → $R_{01}$ 与 $R_{02}$ 都接地 → 从端口看是并联：

$$
R_{eq} = 2\parallel3 = \frac{6}{5} = 1.2\Omega
$$

**第三步：接负载。**

$$
I_L = \frac{9.6}{1.2+6} = \frac{9.6}{7.2} = 1.333\text{A}
$$

$$
U_L = I_L \times 6 = 8\text{V}
$$

**验证（直接用弥尔曼）**：两个电源极性相同（$+$ 都朝外）：

$$
V = \frac{12/2 + 6/3}{1/2+1/3} = \frac{6+2}{0.8333} = 9.6\text{V}\quad(\text{这是 } U_{OC}) ✓
$$

带载时：$R_{eq}=1.2\Omega$ 串 $R_L=6\Omega$：

$$
I = \frac{9.6}{7.2}=1.333\text{A},\quad U_L = 1.333\times6 = 8\text{V}
$$

**结果完全一致 ✓**

**工程意义**：两个电源并联时（$E_1 > E_2$），$E_2$ 实际上在被充电 —— 它的电流方向是**流回自己内部**。真实电源内阻不会这么小，并联时必须保证电压一致，否则形成大环流。
:::

::: tip 例 1+ · 多次切割：网络内部再切一刀
两级电源级联供电：前级 $E_1 = 10\text{V}$（内阻 $R_1 = 2\Omega$），后级 $E_2 = 6\text{V}$（内阻 $R_2 = 3\Omega$），两者**串联**（前级的输出接后级的输入）。求从最右端看进去、对负载 $R_L$ 的戴维南等效。

**解**

**第一刀：在端口 A、B 切开**，得到整个网络 N。

**第二刀：N 内部还能再切**——它本身就是「前级等效块」串「后级等效块」。每块本身已经是戴维南形：
- 前级：$U_{OC1} = E_1 = 10\text{V}$，$R_{eq1} = R_1 = 2\Omega$
- 后级：$U_{OC2} = E_2 = 6\text{V}$，$R_{eq2} = R_2 = 3\Omega$

**拼回去（串联：电压相加、电阻相加）**：

$$U_{OC} = U_{OC1} + U_{OC2} = 10 + 6 = 16\text{V},\qquad R_{eq} = R_{eq1} + R_{eq2} = 2 + 3 = 5\Omega$$

**验算（直接算）**：原电路总电动势 $10+6=16\text{V}$、总内阻 $2+3=5\Omega$；带 $R_L$ 时 $I = \dfrac{16}{5+R_L}$，与等效电路一致 ✓。

**这就是「可多次切割」**：先切端口得到 N，N 内部再切，每块各自先求等效，再组合。网络越复杂，这种「由内向外逐层等效」越是省事。
:::

::: tip 例 2 · 含受控源电路的 $R_{eq}$（外加电源法）
电路：一个 $5\Omega$ 电阻 $R_1$ 并联 VCCS（$\beta V_1$，$\beta=2\text{S}$，方向流入），另一支路 $R_2=10\Omega$ 串联。端口 A 接 $R_1$ 与 VCCS 并联的一侧，B 接 $R_2$ 另一侧（参考）。求从 A-B 看进去的 $R_{eq}$。

**解**

**第一步，外加测试电压。** 在 A-B 间加测试电压 $U$（A 为正）。

**第二步，用结点电压法。** 设参考点为 B（$V_B=0$），则 $V_A = U$。

$V_1$（控制电压）就是 A 点电位：$V_1 = U$。

**第三步，求流入端口的电流 $I$（从 B 流向 A，即从外部灌入）。**

对结点 A 列 KCL。用流出为正的约定：

- 经 $R_1$ 流出 A 的电流：$\dfrac{U - V_1}{R_1} = 0$（因为 $V_1 = V_A = U$，同一结点，电位差为 0）

⚠️ 这里 $R_1$ 的另一端接在哪？题目说"$R_1$ 并联 VCCS"，意思是 $R_1$ 和 VCCS 都接在 A 与参考之间。那 $R_1$ 两端电位都是 $U$ 和 $0$，电流不为零！

修正：$R_1$ 接在 A 与 B（参考）之间，电流 $\dfrac{U-0}{5}=\dfrac{U}{5}$ 从 A 流出。

- 经 $R_1$ 流出：$\dfrac{U}{5} = 0.2U$
- 经 VCCS 流出：VCCS 是电流源 $2U$，方向"流入 A"，所以流出为 $-2U$
- 经 $R_2$（A 到 B）：$\dfrac{U}{10} = 0.1U$，流出为 $+0.1U$

等等，需要重新审视拓扑。题目描述模糊，**这本身就是教训**：**画草图**。假设标准拓扑是：$R_1$、VCCS、$R_2$ 三者并联在 A 与 B 之间。

对结点 A 列 KCL（流出 = 0）：

$$
\underbrace{\frac{U}{R_1}}_{\text{经}R_1} + \underbrace{\beta\cdot U}_{\text{VCCS流出（正流入为负）}} + \underbrace{\frac{U}{R_2}}_{\text{经}R_2} - \underbrace{I}_{\text{流入A的外部电流}} = 0
$$

$$
\frac{U}{5} + 2U + \frac{U}{10} = I
$$

$$
I = U\left(0.2 + 2 + 0.1\right) = 2.3U
$$

**第四步：求等效电阻。**

$$
R_{eq} = \frac{U}{I} = \frac{U}{2.3U} = \frac{1}{2.3} \approx 0.435\Omega
$$

**注意**：如果没有 VCCS（$\beta=0$），则 $R_{eq} = \dfrac{1}{0.2+0.1} = 3.33\Omega = 5\parallel10$ ✓。加了 VCCS 后，$R_{eq}$ 降到 0.435 —— 说明 **VCCS 在"帮助"电流流入端口，等效电阻变小**。

::: tip 本例真正要掌握的
1. **画草图**。题目文字描述拓扑一定有歧义，必须画图才能列对方程。
2. **外加电源法的核心**：把端口当电压源，列一次 KCL 求 $I$，然后 $R_{eq} = U/I$。
3. **受控源保留**，且控制量用测试电压表示（$V_1 = U$）。
4. 算完 $R_{eq}$ 后，**再验证一下没有受控源时的极限情况**（$\beta\to0$ 应该回到纯电阻并联值），能查出大部分计算错误。
:::

::: tip 例 3 · 最大功率传输（含效率分析）
上题例 1 的等效电路：$U_{OC}=9.6\text{V}$、$R_{eq}=1.2\Omega$。求：(a) $R_L$ 取何值时负载功率最大？最大值多少？(b) 此时效率多少？

**解**

**(a) 最大功率条件**：$R_L = R_{eq} = 1.2\Omega$

$$
P_{max} = \frac{U_{OC}^2}{4R_{eq}} = \frac{9.6^2}{4\times1.2} = \frac{92.16}{4.8} = 19.2\text{W}
$$

**(b) 效率**：

$$
\eta = \frac{R_L}{R_{eq}+R_L} = \frac{1.2}{1.2+1.2} = 50\%
$$

**物理图像**：此时负载电流 $I = \dfrac{9.6}{2.4}=4\text{A}$，负载功率 $= I^2R_L = 16\times1.2=19.2\text{W}$。而内阻上损耗 $I^2R_{eq}=16\times1.2=19.2\text{W}$。**送进去的 $9.6\times4=38.4\text{W}$ 中，一半变成了内阻发热**。

**对比高效率方案**：若 $R_L = 24\Omega$（$20\times R_{eq}$）：
- $I = \dfrac{9.6}{25.2}=0.381\text{A}$
- $P_L = 0.381^2\times24 = 3.48\text{W}$（更小）
- $\eta = \dfrac{24}{25.2}=95.2\%$（更高）

**结论**：**功率最大与效率最高，是两个完全不同的优化目标。**

:::

## 考点速记

| 题型 | 第一步 |
| --- | --- |
| 求某电阻的电流/电压，电路复杂 | 把其余部分**戴维南等效** |
| $R_L$ 为何值时功率最大 | $R_L = R_{eq}$ |
| 多个电源、求一条支路 | **叠加定理** |
| 含受控源求等效电阻 | **外加电源法** 或 $U_{OC}/I_{SC}$ |
| 交流最大功率 | 共轭匹配 $Z_L = Z_{eq}^*$ |
| 求两电阻是否等效 | <Prereq id="y-delta" /> 或直接化简 |

## 易错点（按踩坑频率排序）

1. **受控源不能置零！** 求 $R_{eq}$ 时受控源要保留，用外加电源法
2. **电压源置零 = 短路（接一根线）**，电流源置零 = 开路（断开）—— 别搞反
3. **功率不能叠加**：$P_1+P_2 \ne P$，要先用叠加求出总电流再算功率
4. 叠加时每个独立源单独作用要画**独立的电路图**，别在一张图上改
5. 戴维南等效**只对端口外成立**，求网络内部功率必须回到原电路
6. 最大功率匹配时效率仅 50%，电力系统从不这样工作
7. $R_{eq}$ 可能是**负数**（含受控源时）
8. $U_{OC}/I_{SC}$ 法在 $I_{SC}=\infty$ 或 $U_{OC}=\infty$ 时失效
9. 互易定理只适用于**纯电阻**线性网络，不含受控源和电源
