# 03 · 串并联与电源等效变换

<Meta time="40 min" level="核心" note="化简是解题第一刀，先化到最简再列方程" />

你桌上有三个电阻、一节电池，想点亮一盏灯。直接把灯接上去，灯很暗；把三个电阻先串起来再接，亮度又变了。同一个电池，接法不同，结果完全不同。

问题不在电池，也不在灯，而在这几个电阻合起来到底等于多大一个。化简干的就是这件事：把复杂的连接先缩成一个数，再用最简单的公式出答案。

::: tip 读这页之前
欧姆定律、参考方向（<Prereq id="ohm" />），KCL 与 KVL（<Prereq id="kcl" />、<Prereq id="kvl" />），这页的工具全架在它们上面。

本页符号：$R$（电阻）、$R_0$（电源内阻）、$E$（电源电动势，也就是开路电压）、$I_S$（电流源电流）、$\parallel$（并联等效，$R_2\parallel R_L$ 就是两个电阻并联后的值）。全部约定见[符号与约定](../../guide/notation.md)。

两个词先给一句话：分压是多个电阻串联时，每个电阻分走总电压的一部分；分流是多个电阻并联时，总电流分到每条支路去。
:::

## 一、串并联：先看电流，别看长相

这两个词判断起来比算起来难。

串联是几个元件流过同一个电流。判断办法：把某个元件的两端短接，若其他元件里的电流没变，那它就是串联中的一员；更干脆的办法是顺着电流走一遍，中途没有分岔，就是串联。

并联是几个元件两端电压相同。判断办法：它们的两端由导线直接连在一起，中间没有别的元件。

::: warning 最常见的误判
画在同一条直线上不等于串联。$R_1$ 和 $R_2$ 并排画着，中间要是接了别的支路出去，它们的电流就不一样，这叫**混联**。

口诀四个字：看电流，不看长相。实在判断不了，老老实实用 <Prereq id="nodal" /> 列方程，比猜快得多。
:::

## 二、分压与分流

串联时电流相同，各电阻分到的电压与阻值成正比，阻值大的分压多；并联时电压相同，各支路分到的电流与阻值成反比，阻值大的分流少。下面所有公式都从这两句话来。

**分压**（voltage division）与**分流**（current division）说的就是这两件事，写成式子：串联 $R = \sum R_i$，分压 $U_k = \dfrac{R_k}{\sum R}U$；并联 $\dfrac{1}{R} = \sum\dfrac{1}{R_i}$，分流 $I_1 = \dfrac{R_2}{R_1+R_2}I$。

$$
R_{串} = R_1 + R_2 + \cdots
\qquad
\frac{1}{R_{并}} = \sum\frac{1}{R_i}
$$

两电阻并联还有个速记式，比倒数相加快：

$$
R_{并} = \frac{R_1R_2}{R_1+R_2}
$$

::: tip 分压分流的对称性
$$U_1 = \frac{R_1}{R_1+R_2}U \quad\qquad I_1 = \frac{R_2}{R_1+R_2}I$$

两个公式长得不一样，结构完全对称：分压是「自己除以总和」，分流是「对面除以总和」。

分流的分子为什么是对面的电阻？因为 $R_2$ 越大，$I_2$ 越小，而 $I_1 = I - I_2$ 就越大。记不住时想想这个物理过程：$R_2$ 越大 → $I_2$ 越小 → $I_1$ 越大 ✓
:::

::: tip 30 秒的极值检验
- $R_1\to0$：$R_{并}\to0$；$R_2\to\infty$：$R_{并}\to R_1$
- $I_1$ 一定在 $0$ 与 $I$ 之间

两电阻并联的等效值永远小于较小的那一个。答案要是比 $R_1$ 还大，不用往下算，一定错了。
:::

## 三、电源等效变换

一个电压源串一个电阻，对外和某个电流源并同一个电阻完全一样，两者可以互换：

$$
I_S = \frac{E}{R_0},\qquad E = I_SR_0
$$

说成一句话：电压源 $E$ 串 $R_0$，换成电流源 $I_S = E/R_0$ 并 $R_0$。$R_0$ 在两种模型里都不变，这是最容易漏的一点。

验证这一点有个笨办法：变换前后各算一次开路电压和短路电流。电压源模型开路电压是 $E$、短路电流是 $E/R_0$；电流源模型开路电压是 $I_SR_0$、短路电流是 $I_S$。两对数对上了，说明 $R_0$ 与 $E$、$I_S$ 的对应关系没搞错。

<CircuitFig kind="source-transform" title="电源等效变换：什么变、什么不变" />

图上看就明白：左边那对端子 A、B 与右边那对是同一对端子，内阻 $R_0$ 留在原地，只是从串联改成并联，$E$ 与 $I_S$ 互换。变的是电源的表达形式，不变的是端子和内阻。

::: tip 它只是换一种写法
KCL、KVL 已经能解任何线性电阻电路。电源等效变换不是新武器，只是把两种对外表现相同的模型互换，方便把多个电源合并。判断它有没有用也就很简单：变换后能不能合并电源？能就换，不能就别折腾。内阻不同的多个电源，变换后并不到一起，反而多一步。
:::

适用范围是概念题的常客：

| 情况 | 能否变换 |
| --- | --- |
| $E$ 串 $R_0$ | ✅ 能，$I_S = E/R_0$ 并 $R_0$ |
| 理想电压源（$R_0=0$） | ⚠️ 得 $I_S=\infty$，退化为短路 |
| $E$ 串 $R_1$ 再串 $R_2$ | ⚠️ 只能把 $R_1$ 视作内阻，$R_2$ 算外电路 |

这里最容易出错的地方，几乎都落在 $R_0$ 上：忘了 $R_0$ 是跟着模型走的，它既在电压源那边串着，也在电流源那边并着；或者把外电路的电阻误当成 $R_0$。判断标准很硬：$R_0$ 是电源内部的那一段，接在端子 A、B 以内；端子以外的东西都不是 $R_0$。

::: tip 什么时候真的有用
目标是合并电源。两个电压源各带内阻，内阻相同时才能用变换把两个电流源并起来，$I_{S\text{总}} = I_{S1}+I_{S2}$，$R_0$ 不变，电路一下变成简单的并联。

内阻不同就别试了，变换完并不到一起。考卷上看到「多个电源、内阻相同」这种条件，基本就是在提示你用等效变换。
:::

## 四、Y-△（星形-三角形）变换

网络是电桥结构时，既非串联也非并联，串并联和电源变换都化不动，这时才轮到 Y-△。它把星形（$Y$）的三个臂换成三角形（$\triangle$）的三条边，或者反过来。

$$
R_{12} = R_1 + R_2 + \frac{R_1R_2}{R_3}
$$

$$
\begin{aligned}
R_{23} &= R_2 + R_3 + \frac{R_2R_3}{R_1}\\
R_{31} &= R_3 + R_1 + \frac{R_3R_1}{R_2}
\end{aligned}
$$

对称时 $R_1=R_2=R_3=R_Y$，于是 $R_\triangle = 3R_Y$。这条最常考，值得记死。记的时候把两个名字分清：$3R_Y$ 里的下标是臂，算出来的是边；反着问「由边求臂」，答案是除以三。

反向（$\triangle\to Y$）：$R_1 = \dfrac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}$，分母是三个之和，分子是相邻两条边之积。

::: warning Y-△ 的三个易错点
1. 对称时的 $R_\triangle = 3R_Y$ 说的是边等于三倍的臂，不是臂等于三倍的边，方向搞反就是 $3\times$ 误差。
2. $\triangle \to Y$ 的分母是三边之和，不是两边。
3. 变换只改外部行为。$R_\triangle = 3R_Y$ 时，$Y$ 里每个臂是 $R_\triangle/3$。
:::

电桥类问题（惠斯通电桥测电阻、测继电器线圈状态）几乎必用这一手。除此之外，串并联能解决的题不要碰它，公式长，算错概率高。

## 五、负载效应：一分压就跌

**负载效应**说的是同一件事：输出端接上东西，原本算好的电压就变了。分压器由 $R_1$、$R_2$ 串联而成，从 $R_2$ 两端取输出。空载时输出多少，多数人会算；一接上负载 $R_L$，事情就变了：

$$
R_2 \to R_2 \parallel R_L,\qquad
U_L = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L}E
$$

$$
\frac{U_L}{E} = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L}
$$

空载时 $U_L = \dfrac{R_2}{R_1+R_2}E$，这是理想值。带载后电压必跌，因为 $R_2\parallel R_L < R_2$：串联分压里它占的份额就小了。写成一行的替换关系就是 $R_2\to R_2\parallel R_L$，以后看到分压器带载，先把这句写下来。

</FigBox>

::: tip 为什么分压器不能当电源用
分压器是按开路设计的：空载时 $R_2$ 上正好是想要的电压，一接负载，$R_2$ 被拉低，电压立刻下降。

工程上有两条对策。一是让 $R_L \gg R_1+R_2$，代价是空载电流白流；二是加一级缓冲跟随器，也就是运放电压跟随器，输入电阻 $R_\text{in}\to\infty$、输出电阻 $R_\text{out}\to0$，这是标准做法。

负载效应在所有「高阻抗源驱动低阻抗负载」的场合都会出现，是模拟电路最核心的概念之一。
:::

## 六、可以删掉的元件

化简时除了合并串并联，还有一类元件可以直接从图上抹掉：

| 情况 | 可否删除 | 原因 |
| --- | --- | --- |
| 理想电压源并联的电阻 | ✅ 删 | 电压被源钳住，电阻两端电压恒为 $E$，改动它不影响外电路 |
| 理想电流源串联的电阻 | ✅ 删 | 电流被源钳住，电阻怎么变电流都是 $I_S$ |
| 电压源串联的电阻 | ❌ 不行 | 会影响电流分配 |
| 电流源并联的电阻 | ❌ 不行 | 会影响电压分配 |

::: warning 常见误解
「电压源并联的电阻没用了」这句话只在理想电压源时成立。真实电源有内阻 $R_0$，那个 $R_0$ 就并接在输出端上，绝对不能删。
:::

## 例题

::: tip 例 1 · 并联电阻的快速化简
三个电阻并联：$R_1=4\Omega$、$R_2=6\Omega$、$R_3=12\Omega$，总电流 $I=10\text{A}$。求总电阻与各支路电流。

先想一句：并联总电阻一定比最小的那个还小，因为多开了一条通路。所以先求 $R_{并}$，再用分流公式把 $10\text{ A}$ 按「对面电阻」分回每条支路。总电流已知，必须先拿到等效电阻才能分流，直接硬算各支路会绕远。

第 1 步，并联用倒数相加，不是电阻相加：

$$
\frac{1}{R_{并}} = \frac{1}{4}+\frac{1}{6}+\frac{1}{12} = \frac{3+2+1}{12} = \frac{6}{12}=\frac{1}{2}
$$

$$
R_{并} = 2\Omega
$$

第 2 步，用分流公式 $I_1 = \dfrac{R_2R_3}{R_1R_2+R_1R_3+R_2R_3}I$，这是三电阻并联的通用分流式：

$$
I_1 = \frac{6\times12}{4\times6+4\times12+6\times12}\times10 = \frac{72}{24+48+72}\times10 = \frac{72}{144}\times10 = 5\text{A}
$$

$$
I_2 = \frac{4\times12}{144}\times10 = \frac{48}{144}\times10 = \frac{10}{3}\approx3.33\text{A}
$$

$$
I_3 = \frac{4\times6}{144}\times10 = \frac{24}{144}\times10 = \frac{5}{3}\approx1.67\text{A}
$$

第 3 步，验算：$5 + 3.33 + 1.67 = 10$ ✓

回代看合理性：$R$ 最小的电流最大（$4\Omega$ → $5\text{A}$ ✓），$R$ 最大的电流最小（$12\Omega$ → $1.67\text{A}$ ✓）。
:::

::: tip 例 2 · 电源等效变换（照着上面的图走一遍）
一个实际电压源 $E = 12\text{V}$（内阻 $R_0 = 4\Omega$）给负载 $R_L = 8\Omega$ 供电。分别用原模型和变换后的电流源模型求负载电流 $I_L$，验证两者一致。

先想一句：两个模型对负载完全等效，两种算法算出的 $I_L$ 必须是同一个数，这正是验算的抓手。变换只改电源的表达形式，不动端子 A、B 与内阻 $R_0$，所以负载看到的 $U_L$ 和 $I_L$ 不变。

(a) 原模型，电压源串电阻。全串联，一步出结果：

$$I_L = \frac{E}{R_0 + R_L} = \frac{12}{4 + 8} = 1\text{A},\qquad U_L = I_L R_L = 8\text{V}$$

(b) 变换后的模型，电流源并电阻。按上图右半边：先算 $I_S = E/R_0 = 12/4 = 3\text{A}$，它与 $R_0 = 4\Omega$ 并联；负载 $R_L = 8\Omega$ 也并接在同一对端子 A、B 上。用分流公式，分子是对面那个电阻：

$$I_L = I_S \cdot \frac{R_0}{R_0 + R_L} = 3 \times \frac{4}{4 + 8} = 1\text{A},\qquad U_L = 8\text{V}$$

两个模型结果完全一样 ✓ 这就是「对外等效」的含义：对负载来说，它分不清自己接的是左边那个盒子还是右边那个。

关键对照，回看那张图：变换时 A、B 两个端子原地不动，内阻 $R_0$ 留在原地，只是从串联变成并联，$E$ 与 $I_S$ 互换。变的自始至终只有电源的表达形式。
:::

先想一句：这题有两套思路。它平衡就白送，$b$、$d$ 等电位、桥无电流；不平衡才轮到 Y-△。所以第一步永远是先判平衡，别上来就动变换。平衡是 Y-△ 的退化情形，一旦发现桥无电流，整道题降维成两个分压支路并联，最麻烦的一步直接省掉。

第 1 步，判断是否平衡电桥。条件就是 $\dfrac{R_1}{R_2} = \dfrac{R_3}{R_4}$。本题 $10/10 = 10/10$，平衡。

第 2 步，用平衡的结论。桥中点 $b$、$d$ 等电位，桥中无电流，把桥当开路还是当短路都一样。

第 3 步，求 $U_{bd}$。$b$、$d$ 等电位，故 $U_{bd}=0$。

第 4 步，验证一下这个结论。把桥断开，剩下两个分压支路并联：

- 左支路：$R_1$、$R_2$ 串联 $=10+10=20\Omega$，中点电压 $=12\times\dfrac{10}{20}=6\text{V}$
- 右支路：同样 $=6\text{V}$

两中点同电位，确实没有电流过桥。反过来说，若把 $R_4$ 改成别的值，桥上就有电流，那时必须用 Y-△ 化简来算。

补充一句对称化简：本题四臂相等，若从桥中点做 Y 化简，三个臂都 $=10\Omega$，则 $R_\triangle=3\times10=30\Omega$。但既然是平衡电桥，这一步用不上。

这题真正要考的是「平衡电桥」这个概念：工业电桥（惠斯通电桥）就是利用平衡时中点电压为零、与电源内阻无关这一点来精确测量未知电阻的。
:::

::: tip 例 4 · 分压器带负载后电压跌多少
分压器 $E = 12\text{ V}$，$R_1 = 2\text{ k}\Omega$、$R_2 = 4\text{ k}\Omega$，从 $R_2$ 两端输出。先算空载，再分别接 $R_L = 4\text{ k}\Omega$ 和 $R_L = 40\text{ k}\Omega$，看输出电压怎么变。

先想一句：空载时 $R_2$ 独享分压；一带载，$R_2$ 就被 $R_L$ 并掉一部分，等效电阻变小，分压点的电压跟着跌。所以每算一种负载，先把 $R_2$ 换成 $R_2\parallel R_L$ 再分压。跌是必然的，并联只会让等效电阻更小，除非 $R_L$ 远大于 $R_2$。

空载（$R_L \to \infty$，直接分压）：

$$U_L = \frac{R_2}{R_1+R_2}E = \frac{4}{2+4}\times 12 = 8\text{ V}$$

带载 $R_L = 4\text{ k}\Omega$：$R_2$ 先与负载并联，$R_2 \parallel R_L = \dfrac{4\times4}{4+4} = 2\text{ k}\Omega$，再分压：

$$U_L = \frac{2}{2+2}\times 12 = 6\text{ V}$$

跌了 2 V，跌幅 25%。负载与 $R_2$ 一样大时，输出直接掉四分之一。此时总电流 $I = \dfrac{12}{2+2} = 3\text{ mA}$，比空载时的 $\dfrac{12}{6}=2\text{ mA}$ 还大，多出来的电流全消耗在 $R_1$ 上。

带载 $R_L = 40\text{ k}\Omega$（负载是 $R_2$ 的 10 倍）：$R_2 \parallel R_L = \dfrac{4\times40}{4+40} \approx 3.64\text{ k}\Omega$，

$$U_L = \frac{3.64}{2+3.64}\times 12 \approx 7.74\text{ V}$$

跌幅只有 $0.26\text{ V}$（3.2%），已经接近空载值。

规律很清楚：要让分压器带载不跌，必须 $R_L \gg R_1 + R_2$，代价是空载电流更大。要又准又省电，就得加运放电压跟随器缓冲，这就是负载效应的工程解法。
:::

## 化简的先后

拿到图先别写方程，按这个顺序扫一遍：

1. 有没有纯串联或纯并联，能合并就合并。
2. 有没有可删元件，能删就删。
3. 有没有电桥或混联，那是 Y-△ 的活。
4. 有没有多个电源，试试等效变换能不能并成一个。
5. 都化不动了，上 <Prereq id="nodal" /> 或 <Prereq id="thevenin" /> 列方程。

顺序不必死守，第 5 步却永远是兜底。化简是为了少写方程，不是为了绕开方程。

## 易错点速查

| 点 | 说明 |
| --- | --- |
| 分流公式 | 分子是对面的电阻，几乎人人错一次 |
| 并联用倒数 | $\dfrac{1}{R}=\sum\dfrac{1}{R_i}$，不是电阻相加 |
| $R_\triangle = 3R_Y$ | 是 $\triangle$ 的边等于 $Y$ 的臂的三倍，方向别搞反 |
| $\triangle\to Y$ | 分母是三边之和，分子是相邻两边的积 |
| 理想电源互换 | $R_0=0$ 或 $\infty$ 的极端情形不能作常规变换 |
| 可删元件 | 只删理想电压源并联的电阻、理想电流源串联的电阻 |
| 负载效应 | $R_2 \to R_2\parallel R_L$，带载电压必跌 |
| 电源等效变换 | 只换单个电源的表示，不改变拓扑 |
