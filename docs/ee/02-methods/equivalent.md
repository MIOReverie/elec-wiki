# 03 · 串并联与电源等效变换

<Meta time="40 min" level="核心" note="化简是解题第一刀，先化到最简再列方程" />

## 结论先行

1. **串联**：$R = \sum R_i$，分压 $U_k = \dfrac{R_k}{\sum R}U$
2. **并联**：$\dfrac{1}{R} = \sum\dfrac{1}{R_i}$，分流 $I_1 = \dfrac{R_2}{R_1+R_2}I$（**分子是对面那个**）
3. **电源等效变换**：$E$ 串 $R_0$ ⇄ $I_S = E/R_0$ 并 $R_0$，**只对外等效**
4. **Y-△**：对称时 $R_\triangle = 3R_Y$（最常考）
5. **负载效应**：分压器接上负载后输出会跌落，$R_2$ 变成 $R_2 \parallel R_L$
6. **删元件规则**：理想电压源并联的电阻、理想电流源串联的电阻，对外电路无影响

## 一、串并联：判断比计算重要

### 什么叫"串联"

**电流处处相同**的若干元件。判断方法：把某元件的两端短路/断路，若其他元件中仍有电流通过它，就是串联（严格定义是电流相同）。

### 什么叫"并联"

**两端电压相同**的若干元件。判断方法：两端直接由导线相连（中间无其他元件）。

::: warning 最常见的误判
**"看起来是串联"不等于串联。** 例如"$R_1$ 和 $R_2$ 画在同一段线上，中间没有分支" —— 如果它们之间有别的支路接出，那它们的电流就不同，是**混联**。

判断口诀：**看电流，不看长相。** 实在判断不了，就老老实实用 <Prereq id="nodal" />。
:::

## 二、公式与一个记忆技巧

$$
R_{串} = R_1 + R_2 + \cdots
\qquad
\frac{1}{R_{并}} = \sum\frac{1}{R_i}
$$

两电阻并联速记：

$$
R_{并} = \frac{R_1R_2}{R_1+R_2}
$$

::: tip 分压分流的「对称性」
$$U_1 = \frac{R_1}{R_1+R_2}U \quad\qquad I_1 = \frac{R_2}{R_1+R_2}I$$

两个公式长得不一样，但结构完全对称 —— **分压是"自己除以总和"，分流是"对面除以总和"**。

这就是为什么分流公式**分子是对面的电阻**：$R_2$ 越大，分给 $R_1$ 的电流越大（两个并联电阻共享总电流，阻值大的少分流）。记不住时想一下物理：$R_2$ 越大 → $I_2$ 越小 → $I_1 = I - I_2$ 越大 ✓
:::

**极值检验法**（用来判断答案对不对，30 秒）：

- $R_1\to0$：$R_{并}\to0$；$R_2\to\infty$：$R_{并}\to R_1$
- $I_1$ 一定在 $0$ 与 $I$ 之间

## 三、电源等效变换

**定理**：电压源 $E$ 串电阻 $R_0$ ⇔ 电流源 $I_S$ 并电阻 $R_0$，其中

$$
I_S = \frac{E}{R_0},\qquad E = I_SR_0
$$

**$R_0$ 在两种模型里都保持不变** —— 这是最容易漏的一点。

::: tip 它只是「换一种写法」，没有引入新规律
KCL/KVL 已经能解任何线性电阻电路。电源等效变换不是新武器，只是把「电压源串电阻」和「电流源并电阻」两种**对外表现相同**的模型互换，方便把多个电源合并。所以判断它「有没有用」很简单：**变换后能不能合并电源？能，就用；不能，就别折腾**（内阻不同的多个电源变换后并不起来，反而多一步）。
:::

<CircuitFig kind="source-transform" title="电源等效变换：什么变、什么不变" />

上图把"等效"画成了"左右互换"：左（电压源串 $R_0$）与右（电流源并 $R_0$）对外部电路完全等价——**两个端子 A、B 的位置不变，内阻 $R_0$ 原地保留（只是从串联变成并联），$E$ 与 $I_S$ 互换**。凡是"变了"的只有电源的表达形式，凡是"没变"的是端子和 $R_0$。

**变换的适用范围**（易考概念题）：

| 情况 | 能否变换 |
| --- | --- |
| $E$ 串 $R_0$ | ✅ 能，$I_S = E/R_0$ 并 $R_0$ |
| 理想电压源（$R_0=0$） | ⚠️ 得 $I_S=\infty$，退化为"短路" |
| $E$ 串 $R_1$ 再串 $R_2$ | ⚠️ 只能把 $R_1$ 视作"内阻"，$R_2$ 算外电路 |

::: tip 变换什么时候真的有用？
**目标是合并电源**。两个电压源 + 各自内阻，如果**内阻相同**，才能用变换把两个电流源并起来，$I_{S\text{总}} = I_{S1}+I_{S2}$，$R_0$ 不变 —— 这时电路一下变成简单的并联。

**如果内阻不同**，变换后无法合并，所以并不省事。考试里若看到"多个电源、内阻相同"，基本就是提示你用等效变换。
:::

## 四、Y-△（星形-三角形）变换

当网络是**电桥**结构（既非串联也非并联）时，需要 Y-△ 变换。

$$
R_{12} = R_1 + R_2 + \frac{R_1R_2}{R_3}
$$

$$
\begin{aligned}
R_{23} &= R_2 + R_3 + \frac{R_2R_3}{R_1}\\
R_{31} &= R_3 + R_1 + \frac{R_3R_1}{R_2}
\end{aligned}
$$

**对称时**：$R_1=R_2=R_3=R_Y$ → $R_\triangle = 3R_Y$（**最常考，必须记死**）

反向（$\triangle\to Y$）：$R_1 = \dfrac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}$（**分母是三个之和，分子是相邻两条边之积**）

::: warning Y-△ 变换的三个易错点
1. **对称时的 $3R_Y$ 是 $\triangle$ 边，不是 $Y$ 臂** —— 方向搞反就是 $3\times$ 误差
2. **$\triangle \to Y$ 分母是三边之和**，不是两边
3. 变换只改**外部行为**，$R_\triangle = 3R_Y$ 时，$Y$ 中每个臂是 $R_\triangle/3$
:::

**什么时候用 Y-△**：电桥类问题（如惠斯通电桥测电阻、测量继电器线圈状态）几乎必用。

## 五、负载效应（工程核心）

分压器（$R_1$、$R_2$ 串联）在 $R_2$ 两端输出。**接上负载 $R_L$ 后**：

$$
R_2 \to R_2 \parallel R_L,\qquad
U_L = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L}E
$$

$$
\frac{U_L}{E} = \frac{R_2\parallel R_L}{R_1+R_2\parallel R_L}
$$

**空载时** $U_L = \dfrac{R_2}{R_1+R_2}E$ —— 这是理想值。

**带载后电压必然下跌**，因为 $R_2\parallel R_L < R_2$。

<FigBox title="分压器的负载效应" kind="曲线" note="R_L 远大于 R₁ 时才接近空载值。要得到「稳定电压」，必须让 R₁ ≪ R_L —— 这正是运放电压跟随器的用法（R₁→0）。">
<WavePreset kind="loadline" :p="0.85" />
</FigBox>

::: tip 为什么分压器不能当电源用
分压器是**开路设计**的：空载时 $R_2$ 上是想要的电压，但一旦接负载，$R_2$ 被"拉低"，电压立刻下降。

**工程对策**：
1. 让 $R_L \gg R_1+R_2$（浪费电流）
2. **加缓冲跟随器**（运放电压跟随器，$R_\text{in}\to\infty$、$R_\text{out}\to0$）—— 这是标准做法

负载效应在所有"高阻抗源驱动低阻抗负载"的场合都会出现，是模拟电路最核心的概念之一。
:::

## 六、可删元件（化简的"清理"步骤）

在化简电路时，除了合并串并联，还有一类元件可以**直接删掉**：

| 情况 | 可否删除 | 原因 |
| --- | --- | --- |
| **理想电压源**并联的电阻 | ✅ 删 | 电压被源钳住，电阻两端电压恒为 $E$，改动它不影响外电路 |
| **理想电流源**串联的电阻 | ✅ 删 | 电流被源钳住，电阻怎么变电流都是 $I_S$ |
| 电压源串联的电阻 | ❌ 不行 | 会影响电流分配 |
| 电流源并联的电阻 | ❌ 不行 | 会影响电压分配 |

::: warning 常见误解
"电压源并联的电阻没用了"这句话**只在理想电压源时成立**。真实电源有内阻 $R_0$，那个 $R_0$ 就是"并联"在输出端的、**绝对不能删**。
:::

## 七、解题思路（化简四步）

1. 看有没有**纯串联/纯并联** → 直接合并
2. 看有没有**可删元件** → 删掉
3. 看有没有**电桥/混联** → Y-△ 变换
4. 看有没有**多个电源** → 电源等效变换合并
5. 化不动了 → 上 <Prereq id="nodal" /> 或 <Prereq id="thevenin" />

## 例题

::: tip 例 1 · 并联电阻的快速化简
三个电阻并联：$R_1=4\Omega$、$R_2=6\Omega$、$R_3=12\Omega$，总电流 $I=10\text{A}$。求总电阻与各支路电流。

**解**

**第一步，并联用倒数相加（不是电阻相加）**：

$$
\frac{1}{R_{并}} = \frac{1}{4}+\frac{1}{6}+\frac{1}{12} = \frac{3+2+1}{12} = \frac{6}{12}=\frac{1}{2}
$$

$$
R_{并} = 2\Omega
$$

**第二步，用分流公式 $I_1 = \dfrac{R_2R_3}{R_1R_2+R_1R_3+R_2R_3}I$**（三电阻并联的通用分流式）：

$$
I_1 = \frac{6\times12}{4\times6+4\times12+6\times12}\times10 = \frac{72}{24+48+72}\times10 = \frac{72}{144}\times10 = 5\text{A}
$$

$$
I_2 = \frac{4\times12}{144}\times10 = \frac{48}{144}\times10 = \frac{10}{3}\approx3.33\text{A}
$$

$$
I_3 = \frac{4\times6}{144}\times10 = \frac{24}{144}\times10 = \frac{5}{3}\approx1.67\text{A}
$$

**第三步，验算：** $5 + 3.33 + 1.67 = 10$ ✓

**极值检验**：$R$ 最小电流最大（$4\Omega$ → $5\text{A}$ 最大 ✓），$R$ 最大电流最小（$12\Omega$ → $1.67\text{A}$ 最小 ✓）。
:::

::: tip 例 2 · 电源等效变换（照着上面的图走一遍）
一个实际电压源 $E = 12\text{V}$（内阻 $R_0 = 4\Omega$）给负载 $R_L = 8\Omega$ 供电。分别用「原模型」和「变换后的电流源模型」求负载电流 $I_L$，验证两者一致。

**解**

**(a) 原模型（电压源串电阻）。** 全串联，一步出结果：

$$I_L = \frac{E}{R_0 + R_L} = \frac{12}{4 + 8} = 1\text{A},\qquad U_L = I_L R_L = 8\text{V}$$

**(b) 变换后的模型（电流源并电阻）。** 按上图右半边：先算 $I_S = E/R_0 = 12/4 = 3\text{A}$，它与 $R_0 = 4\Omega$ **并联**；负载 $R_L = 8\Omega$ 也并接在同一对端子 A、B 上。用**分流公式**（分子是对面那个电阻）：

$$I_L = I_S \cdot \frac{R_0}{R_0 + R_L} = 3 \times \frac{4}{4 + 8} = 1\text{A},\qquad U_L = 8\text{V}$$

**两模型结果完全一样 ✓** —— 这就是「对外等效」的含义：对负载来说，它分不清自己接的是左边还是右边的盒子。

**关键对照（回看上图）**：变换时 A、B 两个端子**原地不动**，内阻 $R_0$ **留在原地**（只是从串联变成并联），$E$ 与 $I_S$ 互换。变的只有电源的表达形式，端子与 $R_0$ 都没变。
:::

::: tip 例 3 · Y-△ 变换（对称电桥）
电桥电路：$E=12\text{V}$（接在 $a$-$c$ 两端），$R_1=R_2=R_3=R_4=10\Omega$（四臂），$b$、$d$ 是桥中点。求 $b$-$d$ 间电压 $U_{bd}$ 和流过桥的电流（若无桥则 $I_{\text{桥}}=0$）。

**解**

**第一步，判断是否平衡电桥。**

电桥平衡条件：$\dfrac{R_1}{R_2} = \dfrac{R_3}{R_4}$。本题 $10/10 = 10/10$，平衡。

**第二步：平衡电桥的结论。** 桥中点 $b$、$d$ 等电位，桥中无电流（相当于开路/短路都一样）。

**第三步：求 $U_{bd}$。** $b$、$d$ 等电位，故 $U_{bd}=0$。

**第四步：为什么平衡电桥要用 Y-△ 化简？** 直接把桥"断开"，剩下两个分压支路并联：

- 左支路：$R_1$、$R_2$ 并联 $=10\parallel10=5\Omega$，中点电压 $=6\text{V}$
- 右支路：同 $=6\text{V}$

两中点同电位，无电流经桥。**但若要让桥上"有电流"时（如把 $R_4$ 改为不同值），就必须 Y-△ 化简来算。**

**补充对称化简（Y-Δ）**：本题四臂相等，Y 形看中心点，三个臂都 $=10\Omega$（若从桥中点 Y 化简），则 $R_\triangle=3\times10=30\Omega$。但因是平衡电桥，用不上。

**这道题真正要考的是"平衡电桥"这个概念**：工业电桥（惠斯通电桥）就是利用"平衡时中点电压为零、与电源内阻无关"来**精确测量未知电阻**。
:::

::: tip 例 4 · 分压器带负载后电压跌多少
分压器 $E = 12\text{ V}$，$R_1 = 2\text{ k}\Omega$、$R_2 = 4\text{ k}\Omega$，从 $R_2$ 两端输出。先算空载，再分别接 $R_L = 4\text{ k}\Omega$ 和 $R_L = 40\text{ k}\Omega$，看输出电压怎么变。

**解**

**空载**（$R_L \to \infty$，直接分压）：

$$U_L = \frac{R_2}{R_1+R_2}E = \frac{4}{2+4}\times 12 = 8\text{ V}$$

**带载 $R_L = 4\text{ k}\Omega$**：$R_2$ 先与负载并联，$R_2 \parallel R_L = \dfrac{4\times4}{4+4} = 2\text{ k}\Omega$，再分压：

$$U_L = \frac{2}{2+2}\times 12 = 6\text{ V}$$

**跌了 2 V，跌幅 25%**——负载与 $R_2$ 一样大时，输出直接掉四分之一。此时电路总电流 $I = \dfrac{12}{2+2} = 3\text{ mA}$，比空载时的 $\dfrac{12}{6}=2\text{ mA}$ 还大，多出来的电流全消耗在 $R_1$ 上。

**带载 $R_L = 40\text{ k}\Omega$**（负载是 $R_2$ 的 10 倍）：$R_2 \parallel R_L = \dfrac{4\times40}{4+40} \approx 3.64\text{ k}\Omega$，

$$U_L = \frac{3.64}{2+3.64}\times 12 \approx 7.74\text{ V}$$

跌幅只有 $0.26\text{ V}$（3.2%），已接近空载值。

**规律**：要让分压器"带载不跌"，必须 $R_L \gg R_1 + R_2$；但这意味着更大的空载电流。要**又准又省电**，就得加运放电压跟随器缓冲（下一章展开）——这就是「负载效应」的工程解法。
:::

## 考点 / 易错点

| 点 | 说明 |
| --- | --- |
| 分流公式 | **分子是对面的电阻**，几乎必错一次 |
| 并联用倒数 | $\dfrac{1}{R}=\sum\dfrac{1}{R_i}$，不是电阻相加 |
| $R_\triangle = 3R_Y$ | 是$\triangle$ **边**等于$Y$ **臂**的三倍，方向别搞反 |
| $\triangle\to Y$ | 分母是三边之和，分子是相邻两边的积 |
| 理想电源互换 | $R_0=0$ 或 $\infty$ 的极端情形不能作常规变换 |
| 可删元件 | 只删"理想电压源并联电阻"和"理想电流源串联电阻" |
| 负载效应 | $R_2 \to R_2\parallel R_L$，带载电压必跌 |
| 电源等效变换 | 只换单个电源表示，不改变拓扑 |
