# 04 · 支路电流法与结点电压法

<Meta time="45 min" level="核心" note="结点电压法是通用解法，建议作为默认武器" />

**这一页要解决什么**：电路一大，串并联和等效变换就化不动了——比如一个网络里有五六个结点、三四个电源。这种时候你需要的不是再化简，而是「设什么当未知数、列几类方程最省事」。这一页讲三套通用解法（支路电流法、结点电压法、网孔电流法），并证明它们底层都是 KCL/KVL，只是消元方式不同。读完你应该能：对任意电路数出该列几个未知量、选对最省的方法，并用结点电压法完整解出来。

::: tip 读这页之前
- **需要会**：欧姆定律与参考方向（<Prereq id="ohm" />）、电阻串并联（<Prereq id="series-parallel" />）、KCL/KVL（<Prereq id="kcl" />、<Prereq id="kvl" />）。这三种方法只是它们的消元策略。
- **这一页用到的符号**：$n$（结点数）、$b$（支路数）、$V_k$（第 $k$ 个结点的电位，即相对参考点的结点电压）、$I_S$（电流源电流）。全部约定见[符号与约定](../../guide/notation.md)。
- **一个术语先给一句话**：**结点电压**是某结点相对「参考点」（你任意指定的零电位点）的电位差，选好参考点后，整个电路只差 $n-1$ 个结点电压就定下来了。正文第一次用到再展开。
:::

## 结论先行

1. **支路电流法**：以每条支路电流为未知量，列 $(n-1)$ 个 KCL + $(b-n+1)$ 个 KVL。方程多，但直观。
2. **结点电压法**：以结点电压为未知量，只列 $(n-1)$ 个 KCL。**方程最少，最通用**。
3. **网孔电流法**：平面电路可用，列 $(b-n+1)$ 个 KVL。
4. 含理想电压源时，结点法要**增设该支路电流的未知量**（MNA 思想）。
5. **未知量个数的判据**：结点电压法 $n-1$ 个（选参考点后），支路电流法 $b$ 个，网孔法 $b-n+1$ 个。**未知量最少的那个最好写。**

::: tip 先厘清：这三种方法不是新规律，是 KCL/KVL 的三种消元策略
上一章说过：KCL 管「点」、KVL 管「回路」。本章的支路电流法、网孔法、结点电压法，**底层没有任何新物理**——它们只是决定「用哪几个未知量、列哪一类方程最省事」：支路电流法直接列 KCL+KVL；网孔法拿网孔电流当未知量只列 KVL；结点法把支路电流用欧姆定律消掉只列 KVL 化的 KCL。所以**学这一章不要背新公式，要理解「为什么这么消元」**。
:::

## 一、为什么要学三种方法

它们本质是**同一组方程的三种消元策略**：

- 支路电流法：把 **KCL + KVL + VAR** 全列出来，未知量是 $b$ 个支路电流
- 网孔电流法：以**网孔电流**为未知量，用 KVL 列方程，未知量 $b-n+1$ 个
- 结点电压法：把支路电流用**欧姆定律消掉**（$I=(V_i-V_j)/R$），只用 KCL，未知量 $n-1$ 个

**结点电压法最省，因为"支路电流"这个中间量被彻底消掉了。** 这也是现代电路仿真（SPICE 的 MNA）使用的方法。

| 方法 | 未知量个数 | 适合 |
| --- | --- | --- |
| 支路电流法 | $b$ | 支路很少（2~3 条），且电路拓扑简单 |
| **结点电压法** | $n-1$ | **通用，默认首选** |
| 网孔电流法 | $b-n+1$ | 平面电路、网孔数少 |

::: tip 怎么快速选
- 数结点数 $n$，数支路数 $b$。
- 若 $n-1 < b-n+1$，用**结点电压法**（一般成立）。
- 电路是**平面**且网孔很少（如双环），**网孔电流法**更快，因为可以直接"看电流方向写方程"。
- 只有 **1~2 条支路**时，别列方程了，<Prereq id="series-parallel" /> 或 <Prereq id="thevenin" /> 一秒出答案。
:::

## 二、结点电压法：从 KCL 推出来

### 推导：为什么方程长这样

对结点 $k$ 列 KCL：**流入 = 流出**。

每条电阻支路的电流由欧姆定律给出。设结点 $k$ 与 $j$ 之间电阻 $R_{kj}$：

$$
I_{k\to j} = \frac{V_k - V_j}{R_{kj}}
$$

把结点 $k$ 上所有支路电流加起来（流出为正），加上电流源：

$$
\sum_j \frac{V_k - V_j}{R_{kj}} = I_{S,\text{流入 }k}
$$

**提取 $V_k$**，它出现在每一项里：

$$
V_k\sum_j \frac{1}{R_{kj}} \;-\; \sum_{j\ne k} \frac{V_j}{R_{kj}} \;=\; I_{S,k}
$$

这就是标准形式。定义：

$$
\begin{aligned}
G_{kk} &= \sum_{j\ne k}\frac{1}{R_{kj}} &&\text{（自导）}\\
G_{kj} &= -\frac{1}{R_{kj}} &&\text{（互导）}
\end{aligned}
$$

得 $\sum_j G_{kj}V_j = I_{S,k}$。

### 标准形式与三个符号规则

**自导（self-conductance）** 是「结点 $k$ 自己连出去的所有电导之和」，恒正；**互导（mutual conductance）** 是「结点 $k$ 与 $j$ 之间那根电导」，恒负——负号来自前面欧姆定律 $I=(V_k-V_j)/R$ 里减 $V_j$ 的那一项。把 $n-1$ 个 KCL 方程按结点排成矩阵，就是结点电压法的标准形状：

$$
\begin{bmatrix}
G_{11} & G_{12} & \cdots\\
G_{21} & G_{22} & \cdots\\
\vdots&\vdots&\ddots
\end{bmatrix}
\begin{bmatrix}V_1\\V_2\\\vdots\end{bmatrix}
=
\begin{bmatrix}I_{S1}\\I_{S2}\\\vdots\end{bmatrix}
$$

| 项 | 规则 | 记忆法 |
| --- | --- | --- |
| **自导** $G_{kk}$ | 连到结点 $k$ 的**所有**电导之和，**恒正** | 自己的，攒起来 |
| **互导** $G_{kj}$ | 结点 $k,j$ 之间的电导之和，**恒负** | 别人的，带负号 |
| 右端 $I_{S,k}$ | **流入**结点 $k$ 的电流源代数和 | 流入为正 |

::: warning 三个高频错
1. **互导写正号** → 整个矩阵不再对称，解全错。
2. **电流源方向搞反** → 记住"流入为正、流出为负"，不是"和电阻一样按箭头"。
3. **忘记参考结点不列方程**：$n$ 个结点只列 $n-1$ 个方程，因为 $V_{\text{ref}}=0$ 已知。
:::

## 三、弥尔曼定理（两结点特例）

**弥尔曼定理（Millman's theorem）** 是结点电压法在「只有两个结点、多个支路并联」时的闭式解：不用列方程，直接套一个加权平均公式。**它本质就是两结点情形下 $G\mathbf{V}=\mathbf{I}$ 的现成答案。**

两个结点、单参考点、多个电源并联 —— 这是考试出现频率最高的结点电压问题。

$$
\boxed{V_1 = \frac{\sum_k \dfrac{E_k}{R_k}}{\sum_k \dfrac{1}{R_k}}}
$$

**理解成"电导加权平均"**：每个电源贡献 $E_k/R_k$（相当于它单独作用时的电流），总电导是各电导之和。

::: tip 判断题要点
"电压最高的电源对结点电压贡献最大" —— **错**。贡献是 $E/R$，一个 $10\text{V}$ 配 $1\Omega$（贡献 10A）比 $100\text{V}$ 配 $10\Omega$（贡献 10A）还小。
:::

## 四、含理想电压源的结点法（MNA 思想）

**理想电压源无法用电导表示**，这是结点法的唯一障碍。三种处理：

### 方法 A：挪动参考点（最优先尝试）

**如果电压源一端已经接在参考点上**，那另一端电压直接已知，**该结点方程不必列**（或直接写出 $V = E$）。

::: tip 选参考点的技巧
遇到多个理想电压源时，**选一个"接了最多电压源"的结点作参考点**。能省掉好几个方程。

例如 $E_1$、$E_2$ 的公共端连在一起，选这个点为参考，则两个电源另一端电压立即已知。
:::

### 方法 B：增设支路电流未知量（改进结点法 MNA）

若电压源接在两个**都不是**参考点的结点 $a,b$ 之间：

1. 把该支路电流 $I_S$ 加进未知量向量
2. **补一个约束方程**：$V_a - V_b = E$
3. 原来 $V_a$、$V_b$ 的 KCL 里，**加上 $I_S$ 的贡献项**

这正是 SPICE 内部用的方法。**考试里若电路含多个电压源，用方法 B 最稳。**

### 方法 C：电压源串电阻（工程近似）

若题目给的电源模型是 $E$ 串 $R_0$，就把 $R_0$ 当普通电阻，**根本不构成理想电压源**。

::: warning 最容易漏的一条
**与理想电压源并联的电阻，其电流无法由两端电压确定** —— 但它**仍然进入自导**！这是因为它有真实电阻，只是"被短路"了。

对比：**与理想电流源串联的电阻不进入自导**，因为该支路电流已知（就是 $I_S$），这个电阻的存在不改变电流。

一句话记忆：**理想电压源并联的电阻要计入自导；理想电流源串联的电阻不计入。**
:::

## 五、支路电流法与网孔电流法

### 支路电流法

$b$ 条支路 → $b$ 个未知电流，方程来源：

- $(n-1)$ 个独立 KCL
- $(b-n+1)$ 个独立 KVL
- $b$ 个支路 VAR（$U_k = R_k I_k$ 或电容电感的微分关系）

**共 $2b$ 个方程、$b$ 个未知量**，看似冗余（其实有依赖），但对**支路少**的电路直观、几乎不会出错。

### 网孔电流法

**网孔（mesh）** 是平面电路里「最里面那一圈」的回路——它内部不含其他支路，像一个窗户格子。**网孔电流法**给每个网孔设一个假想环流当未知量，这样相邻的公共支路电流自动等于两个网孔电流之差，从而只用列 KVL。

**前提：电路必须是平面图**（能画成没有交叉的平面电路）。

- 网孔数 = $b-n+1$（**与独立 KVL 数相同**）
- 每个网孔设一个假想电流 $I_{\text{网孔}}$
- 在公共支路上：$I = I_{\text{网孔1}} - I_{\text{网孔2}}$（方向相同为相加、反向为相减）

::: warning 网孔法的致命限制
**非平面电路不能用**。典型非平面电路：立体交叉的连接、某些网络拓扑习题。
识别方法：如果画草图时发现有交叉但又没有"桥"（crossing without node），那就是非平面。

考试遇到复杂拓扑时，**用结点电压法，别赌网孔法**。
:::

## 例题

::: tip 例 1 · 弥尔曼定理（最常考）
电路：结点 $1$ 通过 $R_1=2\Omega$ 接电源 $E_1=12\text{V}$（$+$ 接结点1），通过 $R_2=3\Omega$ 接电源 $E_2=6\text{V}$（$+$ 也接结点1）。求 $V_1$ 与各支路电流。

**先想什么**：两电源负极共点，天然就是弥尔曼的两结点结构，直接套加权公式得 $V_1$，再反推各支路电流。*（为什么能反推：每条支路是纯电阻串理想电压源，支路电流 = (E_k − V_1)/R_k，算完用 KCL 和功率守恒两道验算。）*

**解**

**第一步：选参考点。** 两电源的负极相连，选该点为参考，$V_{\text{ref}}=0$。

**第二步：用弥尔曼定理。** 两电源"极性相同"（都把 $+$ 端接向结点1），所以**电动势代数相加**：

$$
V_1 = \frac{\dfrac{12}{2}+\dfrac{6}{3}}{\dfrac{1}{2}+\dfrac{1}{3}} = \frac{6+2}{0.5+0.333} = \frac{8}{0.8333} = 9.6\text{V}
$$

**第三步：算各支路电流。**

$$
I_1 = \frac{E_1 - V_1}{R_1} = \frac{12-9.6}{2} = 1.2\text{A} \quad\text{（从电源流向结点1）}
$$

$$
I_2 = \frac{E_2 - V_1}{R_2} = \frac{6-9.6}{3} = -1.2\text{A}
$$

**$I_2$ 是负的**，说明实际电流 $1.2\text{A}$ 是**从结点1流向 $E_2$ 的正极** —— $E_2$ 成了被充电的负载。这非常合理：$V_1=9.6\text{V}$ 高于 $E_2=6\text{V}$，两个电源反并联，$E_1$ 在给 $E_2$ 充电。

**第四步：验算 KCL。** 结点1 净流入 $= I_1 + I_2 = 1.2-1.2 = 0$ ✓（没有其他支路）

**功率验算**：

| 元件 | $P$ |
| --- | --- |
| $E_1$ | $-12\times1.2 = -14.4\text{W}$（发出） |
| $E_2$ | $-6\times(-1.2) = +7.2\text{W}$（吸收，被充电） |
| $R_1$ | $I^2R = 1.44\times2=2.88\text{W}$ |
| $R_2$ | $1.44\times3 = 4.32\text{W}$ |

$\sum P = -14.4+7.2+2.88+4.32 = 0$ ✓

**工程提示**：两个电源反并联且一个电压更高时，**电压低的被充电**，这是"直流系统并列运行"必须避免的情况（电压差大时形成环流）。

:::

**先想什么**：结点 2 被电压源直接钉在参考点上方 $10\text{V}$，这点已知、不必列方程；剩下结点 1、3 各列一个 KCL。*（为什么这样降维：理想电压源直接接参考点 → 该结点电压已知，这是「挪动参考点」思想的特例，能省掉最麻烦的支路电流未知量。）*

**解**

**第一步：把电流源改成电阻形式。** $2\text{A}$ 从参考点（$0\text{V}$）流入结点 3。等效为在结点3 与参考点之间接一个电压源 $E_3 = I_S \times R$（取大 $R$）。但更简单是**直接对结点 3 列方程时，右侧加 $2\text{A}$**。

**第二步：结点 1 的方程。** 与结点 1 相连的：$R_{12}$（到结点2）、$R_{14}$（到参考点）。

自导 $G_{11} = \dfrac{1}{3}+\dfrac{1}{9} = \dfrac{4}{9}$，互导 $G_{12} = -\dfrac{1}{3}$，$V_4=0$ 不出现在左端。

$$
\frac{4}{9}V_1 - \frac{1}{3}V_2 = 0
$$

**第三步：结点 2 的方程。** 与结点 2 相连：$R_{12}$（到1）、$R_{23}$（到3）、$R_{24}$（到参考点）、电压源 $E$（到参考点，$+$ 接结点2）。

自导 $G_{22} = \dfrac{1}{3}+\dfrac{1}{6}+\dfrac{1}{12} = \dfrac{4+2+1}{12} = \dfrac{7}{12}$

**注意**：电压源不贡献自导（它不是电导）。但电压源 $E=10\text{V}$ 会通过 $R_{24}$ 影响结点2吗？不会 —— 电压源直接接在结点2和参考点之间，它只是"把结点2 顶在 $10\text{V}$"。

更严格地说，电压源在结点2 的方程里**只通过一条"电流"出现**（电压源电流 $I_{E}$，未知）。所以应该用**方法 B**（MNA）：

方程组：

$$
\begin{cases}
\dfrac{4}{9}V_1 - \dfrac{1}{3}V_2 = 0 & \text{(结点1)}\\[6pt]
-\dfrac{1}{3}V_1 + \dfrac{7}{12}V_2 - \dfrac{1}{6}V_3 = I_E & \text{(结点2)}\\[6pt]
-\dfrac{1}{6}V_2 + \left(\dfrac{1}{6}+G_{34}\right)V_3 = 2 & \text{(结点3)}
\end{cases}
$$

加上约束方程 $V_2 - 0 = 10$（**电压源直接接参考点 → 该结点电压已知，可直接写出，不用增未知量！**）

**第四步：用已知条件简化。** 由约束方程，$V_2 = 10\text{V}$。

结点1 方程：

$$
\frac{4}{9}V_1 = \frac{1}{3}\times10 \;\Rightarrow\; V_1 = \frac{10\times3}{4} = 7.5\text{V}
$$

结点3：题目说"电流源注入结点 3"，但结点3 与参考点之间**没有电阻**（我没给 $R_{34}$），所以电流源无法流入 —— **这个电路不成立**。修正：给结点3 与参考点加 $R_{34}=4\Omega$。

那么结点3：

自导 $G_{33} = \dfrac{1}{6} + \dfrac{1}{4} = \dfrac{5}{12}$

$$
-\frac{1}{6}V_2 + \frac{5}{12}V_3 = 2
$$

$$
-\frac{1}{6}\times10 + \frac{5}{12}V_3 = 2 \;\Rightarrow\; \frac{5}{12}V_3 = 2+1.667=3.667 \;\Rightarrow\; V_3 = 8.8\text{V}
$$

**第五步：验证合理性。**

- $V_3 = 8.8\text{V}$ 高于 $V_2 = 10\text{V}$？不，$8.8 < 10$，合理。
- 电流源 $2\text{A}$ 从参考点（$0\text{V}$）流向结点3（$8.8\text{V}$）？**电位升高方向是逆向流动** —— 说明电流源在做功（吸收功率），它靠自身把电流"推"过来。可行，因为理想电流源可以。

::: warning 本例真正要记住的
1. **理想电压源直接接参考点 → 那一点的电压直接已知**，不用列方程，也不用增未知量。这是最省事的处理方式。
2. **给结点3 补一个 $R_{34}$** 是为了让电路可解：电流源不能直接接参考点而没有回路，否则电流无处可去，KCL 不成立。**画完电路先检查：每条支路两端是否有通路。**
3. **电流源既可以从高电位流向低电位，也可以反向** —— 只要电源自身提供能量。纯电阻网络里电流只能高→低，含源网络里不一定。
:::

::: tip 例 3 · 支路电流法：两个电源「互助」的回路
电路：结点 A（上左）经 $R_1=2\,\Omega$ 接 $E_1=12\,\text{V}$（$+$ 在上），再下到导轨；结点 B（上右）经 $R_3=3\,\Omega$ 接 $E_2=6\,\text{V}$（$+$ 在**下**，即接导轨一侧），再下到导轨；A、B 之间经 $R_2=1\,\Omega$ 相连；两条下轨合并为参考点。求各支路电流。

**先想什么**：只有两个非参考结点，KCL 直接给出 $I_1=-I_2$、$I_3=I_2$，只剩一个未知量；再走一圈 KVL 把 $E_1$、$E_2$ 同号相加解出。*（为什么叫互助：两个电源在回路里都是升势，顺向叠加成 18V，支路电流法不怕方向，让符号说话。）*

**解**

**设支路电流**（参考方向一律「向下」或「顺环路」）：左支路 $I_1$（向下）、中支路 $I_2$（A→B）、右支路 $I_3$（向下）。

**列 KCL**（只有 A、B 两个非参考结点）：

$$
\text{A 点： } I_1 + I_2 = 0 \;\Rightarrow\; I_1 = -I_2
$$

$$
\text{B 点： } -I_2 + I_3 = 0 \;\Rightarrow\; I_3 = I_2
$$

**列 KVL**（沿外环顺时针走一圈，各段压降相加为零）：

$$
I_2R_2 + I_3R_3 - I_1R_1 = E_1 + E_2
$$

注意符号：$E_2$ 的 $+$ 在**下**，顺时针走到它时是从「$-$」端走向「$+$」端，属于**升势**，所以移到等式右边时与 $E_1$ **同号相加**——两个电源在这条环路里是**互助**的，总电势 $12+6=18\,\text{V}$。

代入 $I_1=-I_2$、$I_3=I_2$：

$$
I_2(1+3+2) = 18 \;\Rightarrow\; I_2 = 3\,\text{A}
$$

于是 $I_1=-3\,\text{A}$（负号 = 实际**向上**流），$I_3=3\,\text{A}$。

**验算**：
- KCL@A：流入 $3\,\text{A}$（左支路实际向上）= 流出 $3\,\text{A}$（中支路）✓
- KCL@B：流入 $3\,\text{A}$ = 流出 $3\,\text{A}$ ✓
- 功率：$E_1$ 发出 $12\times3=36\,\text{W}$，$E_2$ 发出 $6\times3=18\,\text{W}$；电阻吸收 $9\times2+9\times1+9\times3=54\,\text{W}$。$\sum P=0$ ✓

**本题的收获**：支路电流法方程多但**几乎不用判断电流方向**——全设成一个参考方向，让符号去说话。算完负的就是反了，物理世界不会因为参考方向而改变。
:::

::: tip 例 4 · 理想电压源桥接两个非参考结点（必须用 MNA）
电路：结点 A 经 $R_1=2\,\Omega$ 接参考点；结点 B 经 $R_3=2\,\Omega$ 接参考点；理想电压源 $E_s=8\,\text{V}$（$+$ 接 A）直接桥接 A、B；另有理想电流源 $2\,\text{A}$ 从参考点**注入**结点 A。求 $V_A$、$V_B$ 与电压源支路电流。

**先想什么**：电压源两端都不是参考点，结点法啃不动——必须加一个「电压源支路电流」当未知量，再补一个约束 $V_A-V_B=8$，和两条 KCL 一起解。*（为什么是 MNA：理想电压源无法用电导表示，增未知量 + 约束方程是 SPICE 的标准解法，也是这类题唯一稳的写法。）*

**解**

**第一步：判断障碍。** 电压源两端都不是参考点 → 方法 A 用不了，上**方法 B**（MNA）。

**第二步：设未知量。** $V_A$、$V_B$，外加电压源支路电流 $I_V$（参考方向 A→B）。

**第三步：两个 KCL + 一个约束。**

$$
\text{A 点：}\quad \frac{V_A}{2} + I_V = 2
\qquad\text{（右端是注入的 2A）}
$$

$$
\text{B 点：}\quad \frac{V_B}{2} - I_V = 0
\qquad\text{（$I_V$ 到达 B，故取负）}
$$

$$
\text{约束：}\quad V_A - V_B = 8
$$

**第四步：解。** 由 B 点方程 $I_V=V_B/2$，代入 A 点：

$$
\frac{V_A+V_B}{2}=2 \;\Rightarrow\; V_A+V_B=4
$$

与约束联立：$V_A=6\,\text{V}$，$V_B=-2\,\text{V}$，代回 $I_V=-1\,\text{A}$（负号 = 实际从 B 流向 A，$1\,\text{A}$）。

**第五步：验算。**
- 电阻电流：$I_{R_1}=6/2=3\,\text{A}$（A→地），$I_{R_3}=-2/2=-1\,\text{A}$（实际地→B，$1\,\text{A}$）
- KCL@A：注入 $2\,\text{A}$ + 源支路送来 $1\,\text{A}$ = $R_1$ 流走 $3\,\text{A}$ ✓
- KCL@B：$R_3$ 送来 $1\,\text{A}$ = 源支路流走 $1\,\text{A}$ ✓
- 功率：$E_s$ 发出 $8\times1=8\,\text{W}$；电流源把 $2\,\text{A}$ 从 $0\,\text{V}$ 推到 $6\,\text{V}$，发出 $12\,\text{W}$；$R_1$ 吸收 $3^2\times2=18\,\text{W}$，$R_3$ 吸收 $1^2\times2=2\,\text{W}$。$8+12=18+2$ ✓

**两个值得记住的现象**：
1. **$V_B=-2\,\text{V}$**：浮接的电压源完全可以把结点拉到参考点**以下**——参考点只是「记高度用的海平面」，不是地板。
2. **电流源也在做功**：它把电流从低电位推向高电位，和电池一样是「源」。判断电源发没发功率，看电流从它的哪个端子流出，别看它是不是「电池」。
:::

## 考点速记

| 情况 | 关键处理 |
| --- | --- |
| 两结点多电源 | 弥尔曼定理，注意电动势**极性代数** |
| 电压源直接接参考点 | 该结点电压已知，方程可省 |
| 电压源跨两个非参考结点 | **MNA**：增支路电流未知量 + 补 $V_a - V_b = E$ |
| 含电流源 | 右侧项按"流入为正"填 |
| 求功率 | 先求全部 $V$、$I$，再 $P = UI$，最后 $\sum P=0$ 验算 |
| 大规模网络 | 结点电压法 + 分块/稀疏（现代仿真方法） |

## 易错点

- 自导**恒正**、互导**恒负**，符号写反解全错
- 电流源**流入**结点取正、**流出**取负
- **理想电流源串联的电阻不进入自导**；**理想电压源并联的电阻仍要进入自导**
- 电压源直接接参考点时，该点电位**已知**，不要重复列方程
- 电流源支路若没有回路，电路无解 —— 先检查通路
- 网孔法**只适用平面电路**，复杂拓扑别赌它
