# 19 · 继电接触器控制

<Meta time="25 min" level="了解" note="重点：自锁、互锁、保护环节；看懂主电路与控制电路两张图" />

**这一页要解决什么**：一个几百瓦的电机，凭什么用手指按下一个小按钮就能让它转、松手还能继续转，而且正反转切换不会把电源短路？这一页给出答案的全部零件与接线：接触器、按钮、自锁、互锁、三道保护。读完你应该能看懂一张电机控制图、说出每个电器管什么故障、并画出起保停与正反转电路。

::: tip 读这页之前
- **需要会**：三相电路的线电压与相电压（<Prereq id="three-phase-source" />）、直流电路模型（<Prereq id="circuit-model" />，知道线圈通电带动触点即可）。
- **这一页用到的代号**：QS（刀开关）、FU（熔断器）、QF（断路器）、KM（接触器）、FR（热继电器）、SB（按钮）、SQ（行程开关）、M（电动机）——图纸文字符号，同一电器不管画在哪、画几个触点，都用同一个字母。
- **符号与约定**：单位与电压记号见[符号与约定](../../guide/notation.md)。
- **四个词先给一句话**：**线圈**是电磁铁的绕组，通电产生吸力；**触点**是被吸力带动的开关片；**常开触点**线圈没电时断开、得电才闭合；**常闭触点**相反，没电时闭合、得电就断开。读懂本页一切电路的前提。
:::

车间里最普通的一幕：电机 4 kW，工人按一下绿色按钮，电机转起来；手松开，电机**不停**；再按红色按钮才停。按钮回路里只有零点几安的小电流，却能支配 380 V 主电路里好几安的大电流——中间隔着的东西叫**接触器**（contactor：用线圈电磁力带动大电流触点的开关电器，「以小控大」的中介）。这一页就讲这套机构怎么搭、怎么坏、怎么修。

## 结论先行

1. 控制电路的全部招式，本质只有一招：**用触点去控制线圈，再用线圈去带动别的触点**
2. **自锁**：把接触器自己的常开辅助触点**并联**在起动按钮两端 —— 松手后电流改走这条「捷径」，电机继续转
3. **互锁**：把对方的常闭辅助触点**串联**进自己的线圈回路 —— 从线路上杜绝两个接触器同时吸合（正反转的命门）
4. 保护分工：**熔断器**管短路、**热继电器**管过载、**接触器**管失压/欠压 —— 三者不能互相替代
5. 看电路图先分两半：**主电路**（大电流，决定电机转不转）和**控制电路**（小电流，决定主电路何时通）

## 常用低压电器

这一节把控制柜里会遇到的七个电器一次列全，并说清每个管什么故障——后面自锁互锁的所有电路都由它们拼出来。

| 电器 | 符号特征 | 作用 | 选型依据 |
| --- | --- | --- | --- |
| 刀开关 QS | 三极联动 | 隔离电源，明显断开点 | 额定电流 ≥ 电机额定电流 |
| 熔断器 FU | 矩形/波浪 | **短路**保护（瞬时） | $1.5\sim2.5$ 倍电机额定电流 |
| 断路器 QF | 方框 + 触点 | 短路 + 过载 + 欠压，可重复用 | 同熔断器 |
| 接触器 KM | 线圈 + 主/辅触点 | 频繁通断主电路 | 主触点电流 ≥ 电机额定电流 |
| 热继电器 FR | 双金属片 + 常闭触点 | **过载**保护（有热惯性） | 整定值 ≈ 电机额定电流 |
| 按钮 SB | 常开/常闭 | 发出指令 | — |
| 行程开关 SQ | 滚轮/杠杆 | 位置控制、限位 | — |

::: tip 熔断器和热继电器为什么必须同时存在
熔断器靠「电流大→迅速熔断」保护**短路**，但它有熔断误差，略过载时可能长期不动作；热继电器靠双金属片受热弯曲，动作慢（秒级），正好补上**过载**这一段。反过来，短路电流（几十倍额定）会在热继电器动作之前就把电机烧了，所以必须靠熔断器先切断。

**一句话：熔断器管「突然的大电流」，热继电器管「慢慢变大的电流」。**
:::

七个电器认全了，其中接触器是主角。下面两个基本环节——自锁与互锁——全都围绕它的线圈与辅助触点展开。

## 基本环节一：自锁（长动控制）

这一节只回答一个问题：松开按钮之后，电机凭什么继续转。

如果只把按钮直接串在线圈回路里，那就是**点动**——手按着电机转，一松手就停。要「按一下就一直转」，必须让接触器自己把自己接上：

```
按下 SB2 ──→ KM 得电 ──→ 主触点闭合（电机转）
                          └→ 辅助常开闭合 ──┐
松开 SB2 ─────────────────────────────────┘（电流改走辅助触点，线圈继续得电）
```

关键在于这条并联的「捷径」：**按钮只管「点火」，点火之后由 KM 自己的触点续上**。按 SB1（停止）切断整条回路，KM 失电，辅助触点断开，「捷径」消失，下次起动还要重新按 SB2。

先看静态接线——自锁触点只跨接在起动按钮 SB2 两端：

<CircuitFig kind="relay-lock" title="电动机自锁（起保停）控制电路：KM 辅助触点并联在起动按钮上" />

::: danger 画自锁的头号错误：把停止按钮也框进并联支路
自锁触点只能**跨接在起动按钮 SB2 两端**，绝不能在 SB2 靠电源侧取线、把 SB1 停止按钮一起并进去。一旦并联支路跨过了停止触点，按 SB1 时电流仍能从并联支路绕过去，KM 线圈不断电——**停止失灵**。判断口诀：停止按钮必须单独串在并联支路的**上游**，让所有电流都先过它这一关。
:::

::: warning 为什么「松开按钮还继续转」这件事值得专门看一眼
新手最常见的困惑是：按钮都松开了，电路凭什么还通？答案就在这张时序图上——**KM 线圈的导通条件在 t=2s 那一刻发生了转移**：从「SB2 闭合」变成了「KM 自己的常开触点闭合」。条件是同一个（回路闭合），只是提供这个条件的东西换了。

工程上这条捷径也带来一个性质：**掉电后不会自起动**。停电时 KM 失电、自锁解除；复电后必须重新按 SB2，电机才会转。这叫「失压保护」，是接触器控制相对闸刀开关的一大优势。
:::

自锁解决「一只接触器自己保持」，可一旦电路里有两只接触器要抢同一台电机——正转与反转——新的危险就出现了，解决办法是互锁。

## 基本环节二：互锁（正反转）

这一节只回答一个问题：怎么从线路上保证正反转两个接触器永远不会同时吸合。

要让电机反转，办法是**对调两根火线**。于是用两个接触器：KM1 直接送电（正转），KM2 交叉送电（反转）。问题是——如果两个接触器同时吸合，两相火线会通过它们的主触点直接短接，**相间短路**。

互锁就是把对方线圈回路的「门」锁上：

```
KM1 线圈回路：… — KM2 常闭 — KM1 线圈
KM2 线圈回路：… — KM1 常闭 — KM2 线圈
```

KM1 一吸合，它的常闭辅助触点就断开，于是 KM2 的回路必然断开——**即使有人误按了反转按钮也没用**。

<DemoBox title="正反转控制电路" hint="点 SB2 正转、SB3 反转、SB1 停止。注意主电路里 KM2 组把 L1、L2 换接；控制电路里两条支路互相串着对方的常闭触点。">
  <RelayCircuit mode="reverse" />
</DemoBox>

::: tip 正转直接按反转按钮会怎样
什么都不会发生——KM2 的回路被 KM1 的常闭互锁触点断着。**必须先按停止，再按反转**。现场如果要求「直接切换」，那就要在程序/电路里加「先停后动」的时序（用 PLC 做很轻松，[第 20 章 · PLC 与梯形图](plc.md)会看到）。

有的电路还额外加**按钮互锁**（把对方的常闭按钮串进自己回路）和**机械互锁**（两接触器滑块互相挡住），构成双重甚至三重保险。考试里只要求画出电气互锁那一对常闭触点。
:::

## 其它常见环节

这一节把剩下的六个常用环节收进一张表——它们全是自锁、互锁两个动作的变体，看清这一点就不用逐个背接线。

| 环节 | 做法 | 典型用途 |
| --- | --- | --- |
| 点动 | 不给自锁，按钮直接串线圈 | 机床对刀、试车 |
| 顺序控制 | 前一级的常开触点串进后一级线圈回路 | 主轴转起来才能开冷却泵 |
| 多地控制 | 起动按钮**并联**、停止按钮**串联** | 车间两头都能起停 |
| 行程控制 / 限位 | 行程开关常闭串入线圈回路 | 到位置自动停、越位保护 |
| 自动往复 | 两个行程开关 + 自锁配合 | 工作台往返 |
| 时间控制 | 时间继电器触点延时动作 | 星—三角起动、顺序延时 |

多地控制是最容易被做反的一个：**起动并联（任一地点都能起动）、停止串联（任一地点都能停止）**。写成逻辑式就是 $(SB_A \lor SB_B)\cdot(SB_C \land SB_D)$。

环节认全了，剩下的问题是：拿到一张陌生图纸，按什么顺序看。下面是看图四步法。

## 看图方法（四步）

这一节给一个固定的读图顺序——先主后控、先静后动，任何电机控制图都按这四步走。

1. **先看主电路**：从左到右，电源 → QS → FU → KM 主触点 → FR 热元件 → 电机。粗线、大电流。
2. **再看控制电路**：从上到下，控制电源 → 保护元件 → 按钮/触点组合 → 线圈。细线、小电流。
3. **同一字母 = 同一电器**：KM 的线圈、主触点、辅助触点虽然画在不同位置，动作是同时的。
4. **触点画的是常态**：图上所有触点都是「线圈未得电」时的状态。分析之前要先判断：通电后哪些线圈会得电？得电后哪些触点会动作？

4. **触点画的是常态**：图上所有触点都是「线圈未得电」时的状态。分析之前要先判断：通电后哪些线圈会得电？得电后哪些触点会动作？

方法有了，接下来用四道例题把它用起来：一道选型计算，三道电路分析。

## 例题

四道题按「算 → 拆 → 判 → 拼」排：例 1 算额定电流并选电器，例 2 拆一个丢自锁的故障，例 3 判互锁缺失的后果，例 4 拼自动往复电路。每题都先看「先想什么」。

::: tip 例 1 · 电器选型
一台 4 kW、380 V 三相异步电动机（异步电动机：转子转速略低于旋转磁场转速的交流电机，工矿最常用），$\cos\varphi = 0.85$、$\eta = 0.87$（$\eta$ 是效率，输出功率与输入电功率之比），直接起动。选择熔断器、热继电器、接触器的规格。

**先想什么**：选型的一切基准是**额定电流**——三个电器的选型依据全挂在它上面，所以第一步必须把 $I_N$ 算准，公式里 $\cos\varphi$ 与 $\eta$ 一个都不能丢。

**步骤**：

1. 算电机额定电流。*（为什么用这个公式：三相功率 $P=\sqrt3 U I\cos\varphi$，再除以效率才是输出功率，倒推回来输入电流要乘回去。）*

$$
I_N = \frac{P_N}{\sqrt3\,U_N\cos\varphi\,\eta}
= \frac{4000}{\sqrt3\times380\times0.85\times0.87}
= \frac{4000}{486.7} = 8.22\ \text{A}
$$

2. 三件电器按各自口径选：*（为什么口径不同：熔断器要躲开起动电流所以取 1.5~2.5 倍，热继电器要贴着额定值整定否则误动作，接触器主触点只要求不小于额定电流。）*

- **熔断器**：取 $(1.5\sim2.5)I_N$，即 $12.3\sim20.6$ A → 选 **20 A**（要经得起起动电流，又不能太大会失去保护意义）
- **热继电器**：整定值按 $I_N$ 取 → 选 **8~10 A 可调**规格，调到 8.2 A 附近
- **接触器**：主触点额定电流 ≥ $I_N$ → 选 **10 A 或 16 A** 等级（留裕量），线圈电压与控制电源一致（220 V 或 380 V）

**验算**：若误按 $\cos\varphi = 1$、$\eta = 1$ 估算，会得到 $I_N = 4000/(\sqrt3\times380) = 6.1$ A，热继电器整定就偏小，电机正常运行就会误动作。**选型必须用额定电流，不能用「功率除以电压」这种粗算。**——验算方法是把漏掉的系数逐个补回来看偏差，这是功率类公式的通用自查法。
:::

::: tip 例 2 · 电路分析：少了自锁会怎样
下图是一个「三相异步电动机直接起动控制电路」，但运行人员反映：**电动机只能点动，一松手就停**。电路其它部分完好，故障在哪？

<CircuitFig kind="relay-lock" title="起保停控制电路：故障就在自锁触点那对端子上" note="KM 辅助常开触点本应并联在 SB2 两端。若这对触点没接（或接错到常闭），线圈得电的唯一条件就是 SB2 被按着——表现正是点动。" />

**先想什么**：症状是「松手即停」，这在结构上只有一种可能——松手后线圈回路没有别的通路。而「松手后仍通电」的唯一提供者就是自锁触点，所以嫌疑高度集中。

**步骤**：

1. 写出控制回路链条：L — FU — FR常闭 — SB1(停止) — SB2(起动) — KM线圈 — N。*（为什么先写链条：把并联支路漏掉的问题暴露成一条串联回路，缺什么一目了然。）*
2. 对照起保停的标准结构，缺少的是**与 SB2 并联的那对 KM 常开辅助触点**（自锁触点）。
3. 验证症状：没有它，线圈得电的唯一条件就是「SB2 被按着」；手一松，回路立即断开，KM 失电、主触点分开，电机停转——表现正是点动 ✓。

**验算**：修复后松手能保持运行、按 SB1 能停，自锁回路闭合条件复原 ✓（与例题开头的故障机理互为反证）。

::: tip 例 3 · 电路分析：正反转互锁
一台机床要求主轴能正反转。图纸上 KM1、KM2 各自线圈回路都完整，但**没有互锁触点**。运行一段时间后发生了相间短路（两根火线经低阻通路直接短接）。解释原因，并说明至少两种补救措施。

**先想什么**：故障不在「正常操作」里，而在「误操作」里——问自己一句：两个接触器同时吸合时主电路会变成什么样？答案（两相火线短接）就是找原因的方向。

**步骤**：

1. 复现操作序列：操作人员先按了正转（KM1 吸合），未按停止就直接按了反转。*（为什么从这里下手：互锁缺失只在交叉操作时暴露。）*
2. 此时 KM2 的线圈回路是通的，KM2 也吸合；两组主触点同时闭合，L1、L2 两相火线通过 KM1、KM2 的主触点形成低阻通路 → **相间短路**，熔断器熔断（如果选得合适）或烧毁触点。*（为什么是短路：两个接触器的主触点一个把 L1 送到电机、一个把 L2 送到电机的同一相端子，两根火线之间只隔了触点接触电阻。）*
3. 补救（按可靠性排序）：

1. **电气互锁（必须）**：把 KM1 的常闭辅助触点串进 KM2 线圈回路，KM2 的常闭串进 KM1 回路。此后 KM1 吸合时 KM2 回路必然断开，误按反转按钮也不会动作。
2. **按钮互锁（推荐）**：用带常闭触点的复合按钮，把反转按钮的常闭触点串进正转回路。按下反转时先断开正转，再接通反转。
3. **机械互锁（辅助）**：两个接触器安装连锁机构，一个吸合时物理挡住另一个的衔铁。

**顺带一个设计细节**：互锁用的是接触器的**常闭辅助触点**，不是主触点——主触点粗、电流大，但它吸合时也是闭合的，起不到「互锁」作用。

**验算**：加上电气互锁后重演第 1 步的误操作——KM1 吸合时其常闭触点已断开 KM2 回路，按反转按钮线圈不得电，短路路径不存在 ✓。
:::

::: tip 例 4 · 行程开关自动往复
工作台由电机驱动，要求在 A、B 两点之间自动往返。说明需要哪些电器、怎么接线。

**先想什么**：这是「行程控制 + 自锁」的组合题。拆解目标：往复 = 两个方向各有一套自锁回路 + 每个终点有一个既能「停当前方向」又能「起反方向」的开关——行程开关的常闭、常开两组触点正好一分为二。

**步骤**：

1. 列器件清单：两个接触器（KM1 前进、KM2 返回）、两个行程开关（SQ_A 装在 A 点、SQ_B 装在 B 点）、起动按钮 SB2、停止按钮 SB1。*（为什么行程开关要两个：A、B 各管一个方向的换向，共用一个会在返回时重新触发自己。）*
2. 接线思路（这是「行程控制 + 自锁」的组合）：

- 正转（前进）支路：SB2 起动 → KM1 自锁 → **SQ_B 常闭** → KM1 线圈
- 反转（返回）支路：KM1 的常开触点（或 SQ_A 的常开）起动 → KM2 自锁 → **SQ_A 常闭** → KM2 线圈

工作过程：按 SB2，KM1 得电，工作台前进；到 B 点撞下 SQ_B，其常闭断开 → KM1 失电停车，同时 SQ_B 常开闭合 → KM2 得电，工作台返回；到 A 点撞下 SQ_A → KM2 失电、KM1 得电，如此往复。按 SB1 停车。

**注意 SQ_A、SQ_B 的接线方向**：每一个行程开关都要「到位时切断当前方向的接触器、接通反方向的接触器」，接反了就会一直朝一个方向跑到底。

**验算**：按逻辑式走一个完整循环——前进支路导通条件含 SQ_B 常闭（到 B 必断），返回支路导通条件含 SQ_A 常闭（到 A 必断），两个方向互锁还应保留对方的常闭触点，任一时刻只有一只接触器可能吸合 ✓（KCL 层面：每条线圈回路的通断条件两两互斥）。
:::

例题走完，最后看一个真实的控制柜把所有环节装在一起。

## 工程实例：一台机床的控制柜里有什么

这一节把前面的零件、环节、看图方法落到一台真实车床上，形成整体图景。

以最常见的 CA6140 车床为例，打开电气柜你会看到：

- **进线**：三相四线（三根火线 + 一根零线）经刀开关或断路器引入
- **主电路**：断路器 → 两个接触器（主轴正反转）→ 热继电器 → 主轴电机；另一路给冷却泵电机（顺序控制：主轴转了才允许开冷却泵）
- **控制电路**：取两根线作 220 V 控制电源（一根火线 + 一根零线，或两根火线之间取 380 V），往下是熔断器 → 热继电器常闭 → 各按钮与接触器触点 → 各线圈
- **指示灯**：电源、运行、故障三色指示——**控制电路本身也能驱动指示灯**，这就是「用小电流控制大电流」思想的延伸

现场排故的第一反应应该是：先看接触器有没有吸合（听声音、看指示），没吸合就往控制回路查（熔断器、热继电器是否动作、按钮触点是否接触不良），吸合了但电机不转就往主回路查（主触点烧蚀、电机断相）。

硬接线讲完了，但现代控制柜里这套逻辑越来越多被 PLC 取代——自锁、互锁的思路不变，实现方式从铜线变成了程序，下一章专门讲。

## 易错清单

按踩坑频率排序，格式是「错误做法 → 会得到什么 → 正确做法」。

1. **把自锁触点并联时跨过了停止按钮** → 按 SB1 停不下来（停止失灵） → 自锁触点只跨 SB2 两端，所有电流先过 SB1。
2. **画正反转忘了互锁常闭触点** → 误操作时相间短路 → KM1、KM2 常闭辅助触点互相串进对方线圈回路。
3. **触点画的是常态当成了当前状态** → 电路分析从第一步就错 → 分析前先判断哪些线圈会得电。
4. **热继电器用常开触点串进线圈回路** → 正常运行时线圈回路就断着，电机无法起动 → 用**常闭**触点；动作后要**手动复位**。
5. **熔断器当过载保护、热继电器当短路保护** → 短路时热继电器来不及动作烧毁电机 / 略过载时熔断器长期不动作 → 两者各司其职、不能互相替代。
6. **同一接触器当成多个电器** → 以为线圈和触点可以分开动作 → 线圈、主触点、辅助触点**动作同时**，只是画在不同位置。
7. **多地控制做反** → 一地按下、另一地松开就把电机停了 → 起动**并联**、停止**串联**。
8. **选型用功率粗除电压** → 整定值偏小约 25%，正常运行误动作 → 用**额定电流**（$P_N/\sqrt3 U_N\cos\varphi\eta$）。

## 自检

1. 自锁触点为什么必须并联在 SB2 两端、而不是并到 SB1 上？画出错误的接法并说明按停止时电流的路径。
2. 互锁用常闭触点、自锁用常开触点——两种触点各利用了线圈得电后的哪个动作？
3. 熔断器、热继电器、接触器（失压保护）各管什么故障？为什么任何一个都替代不了另外两个？
