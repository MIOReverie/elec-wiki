# 01 · 电路模型与参考方向

<Meta time="35 min" level="核心" note="这一页的『参考方向』是整门课最容易埋雷的地方" />

## 结论先行

1. **电路模型** = 把实际器件抽象成理想元件（R / L / C / 电源），只关心端口的 $u$-$i$ 关系。判据是**外部行为不变**。
2. **参考方向是人为假设的**，算出来为正说明实际方向一致，为负说明相反 —— 大小照抄，符号说明方向。
3. **关联方向**（电流从电压"+"端流入）下 $P = UI$ 为吸收功率；$P>0$ 吸收，$P<0$ 发出。
4. 电源三种状态：有载 $I=\dfrac{E}{R_0+R}$，开路 $I=0,\ U=E$，短路 $I=\dfrac{E}{R_0}$（**必须避免**）。
5. **额定值不是工作点**：电阻标"$100\Omega\ 2\text{W}$"意思是"接 100Ω 时最大能耗散 2W"，不是"它会主动耗散 2W"。

::: tip 规律层：先分清「约定」和「定律」
这一页讲的都是**约定与方法**，没有新的物理定律：**电路模型**是用理想元件近似真实器件（判据：端口 $u$-$i$ 行为不变），是一种「受控的近似」；**参考方向**是你自己画的假设箭头，纯粹是记账——算出的负号会自动告诉你真实方向。真正的定律要到下一页（KCL/KVL）才登场。想通「这一页是约定不是定律」，就不会被「模型到底准不准、方向到底怎么定」这类问题困住。
:::

## 一、什么算"模型"，什么不算

看着像废话，但它决定了你能不能把物理问题和数学问题干净地分开。

**建模的唯一判据**：接上任意一个外电路，这个模型的**端口电压-电流关系**和真实器件一致。

| 器件 | 真实情况 | 模型 | 丢掉的是什么 |
| --- | --- | --- | --- |
| 电阻 | 温度升高 → $R$ 变大 | 理想电阻 $R$（常数） | 温度效应 |
| 电感 | 有绕组电阻、有寄生电容 | 理想电感 $L$ | 损耗、高频特性 |
| 电容 | 有漏电、有 ESR | 理想电容 $C$ | 损耗、频率上限 |
| 干电池 | $E$ 随放电逐渐下降 | $E$ 串 $R_0$ | $E$ 的漂移 |
| 交流电源 | 频率/电压波动 | 定频定压的理想源 | 波动与内阻 |

被丢掉的叫**非理想特性**，用三个词分类：

- **线性 / 非线性**：$R$ 是不是常数。**只有线性电路才能用叠加定理**。
- **时变 / 定常**：参数是否随时间变。本课只处理定常。
- **集中 / 分布参数**：尺寸是否远小于波长。**长线或高频（> $\lambda/10$）必须当分布参数看**，那时 KCL/KVL 会失效 —— 概念判断题常在这里下坑。

::: tip 为什么可以「丢掉」？
因为在**题目给定的条件下**，丢掉的量远小于保留的量。直流稳态下的电感按理想电感算，50Hz 工频下的变压器铁损按理想变压器算。这是**受控的近似**，不是"无所谓"。

真要精确时，会在理想元件旁边**并一个小的非理想元件**来近似（比如给电容并一个 $R_{\text{漏}}$）。题目若给了漏电阻，就得老实算进去。
:::

## 二、参考方向：整门课最重要的一次"约定"

### 电压的参考方向

$U_{ab}$ 中下标顺序有严格含义：

$$
U_{ab} = V_a - V_b,\qquad U_{ab} = -U_{ba}
$$

约定"$U_{ab}$ 的参考方向"就是"电位从 a 变到 b 的**降低**方向"。所以 $U_{ab}$ 是沿 a→b 方向电位降低了多少。

**这就是新手第一大错**：把 $U_{ab}$ 写成 $V_b - V_a$。自检办法只有一个——当减法算一遍：$3-5=-2$，所以 $U_{ab}=-2\text{V}$ 就意味着 b 点电位更高。

### 关联方向（被动符号约定）

**电流从标"+"的一端流入元件内部** —— 这才叫关联。关联方向下：

$$
U = IR \quad\text{（电阻）},\qquad P = UI \quad\text{（功率）}
$$

非关联方向（电流从"+"端**流出**）：

$$
U = -IR,\qquad P = -UI
$$

这两式不需要"看情况"，只需**先检查关联性**。草稿纸上花 30 秒标个箭头，能省掉一整道题的分数。

::: warning 符号规则（只需记这一条）
**代数上一切按参考方向算，符号自动告诉你答案对不对。**

若算得 $I=-3\text{A}$，含义是"实际 3A，方向与你假设的相反"。**不要重算、不要怀疑电路图**，写 $-3\text{A}$ 或换个方向写 $3\text{A}$ 都行。唯一不能做的是**丢掉负号**。
:::

## 三、功率：三件套必须自洽

$$
P = UI \quad\text{（关联，任意元件）}
$$

$$
P_R = I^2R = \frac{U^2}{R} \ge 0 \quad\text{（纯电阻，永远吸收）}
$$

$$
\begin{aligned}
\text{电阻} &\to \text{纯耗散}\\
\text{电感/电容} &\to \text{储能，来回交换，}P\text{ 可正可负}\\
\text{理想电压源} &\to \text{只有 } I=0 \text{ 时 } P=0\\
\text{实际电源} &\to \text{发出，} P<0
\end{aligned}
$$

**全电路功率平衡**：$\sum P = 0$。这是最有用的验算手段 —— 算完所有支路把 $P$ 加一遍，应该正好为零（允许浮点误差）。**不平衡就说明符号搞错了**，比重新解一遍方程快得多。

::: tip 为什么「纯电阻 $P\ge0$」值得记？
它意味着：**纯电阻网络里，电流必然从高电位流向低电位**，不需要分析方向。因为 $I=U/R$ 且 $R>0$，$U>0$ 时 $I$ 一定从"+"流向"−"。

但含电源的网络不能这样想 —— 电流可能从低电位流向高电位（电源内部就是如此），此时是电源在**推动**电流。判断某支路电流的真方向，只能算完看符号。
:::

## 四、电源模型与外特性

理想电压源 $U=E$ 恒定，外特性是**水平线**。但电池用久了没劲、$R$ 发热阻值变大，都源于内阻 $R_0$。

模型：$E$ 串 $R_0$。接负载 $R_L$：

$$
I = \frac{E}{R_0+R_L},\qquad U_L = E - IR_0 = \frac{ER_L}{R_0+R_L}
$$

外特性方程（$U$ 对 $I$）是直线，**两个截距直接可读**：

$$
U = E - IR_0 \quad\Longrightarrow\quad \text{纵截距} = U_{oc}=E,\qquad \text{横截距} = I_{sc}=\frac{E}{R_0}
$$

**内阻越大，外特性越"软"** —— 带负载能力越差。这是电源最重要的品质指标。

<FigBox title="电源外特性与负载线的交点" kind="直线" note="工作点是两条直线的交点。R₀ 越大外特性越倾斜；R_L 越大交点越靠左上。短路时电流冲到 E/R₀，这就是导线短路会烧保险丝的原因。">

### 三种状态的物理意义

| 状态 | $I$ | $U$ | 功率去向 |
| --- | --- | --- | --- |
| 开路 $R_L\to\infty$ | $0$ | $E$ | 0 |
| 有载 | $\dfrac{E}{R_0+R_L}$ | $<E$ | $UI$ 给负载 |
| **短路** $R_L\to0$ | $\dfrac{E}{R_0}$ | $0$ | 全部烧在 $R_0$ 上 |

短路电流只由 $R_0$ 决定，**与外部线路无关** —— 这就是"取错保险丝"会让设备烧毁而不只是不工作的原因。

::: warning 反过来的例子：电流源
电流源开路时理论上电压无界、**短路时电流无界**。实用电流源都串大电阻来限制。
:::

## 五、工程实例：LED 为什么要串限流电阻

LED 是**电流控制器件**，不是电压控制器件。3mm 红 LED 正向压降约 $1.8\sim2.2\text{V}$，但 $U-I$ 曲线极陡：电压从 $1.9$ 变到 $2.0$，电流可能从 $1\text{mA}$ 冲到 $50\text{mA}$。

用上面外特性的思路反过来看：把 LED 当成 $U_{oc}\approx2\text{V}$ 的电源，导通电阻 $R_d$ 很小（十几欧）。若直接接 $5\text{V}$：

$$
I = \frac{5-2}{R_d},\quad R_d=15\Omega \Rightarrow I\approx 200\text{mA}
$$

LED 额定电流是 10~20mA —— **超了十几倍，几秒烧毁**。加 $R=(5-2)/0.015\approx200\Omega$ 的限流电阻，工作点被压回 15mA。

::: tip 工程化简
**估算法**：假设压降 2V、目标电流 15mA，$R=(V_{CC}-2)/0.015$，取标准阻值。
**精确法**：把 LED 实际 $U-I$ 曲线与负载线联立求交点 —— 就是上面那张图的求法。
:::

## 例题

::: tip 例 1 · 电源模型与额定值（概念辨析）
一个"$12\text{V},\ 1\text{A}$"的直流电源，接一个 $12\Omega$ 灯泡。灯泡亮不亮？电源内部损耗多少？

**解**

**第一步，先别算，先问"$1\text{A}$"是什么意思。**

它是**额定电流**：长期工作不烧坏的电流上限，由散热能力决定。**不是**接到任何负载都会流过的电流。

**第二步，画等效模型。** $E=12\text{V}$。内阻 $R_0=E/I_{\text{额}}=12/1=12\Omega$。（这个 $R_0$ 是在输出端短路、电流恰为额定值时推出来的。）

**第三步，接负载。** $R_L=12\Omega$：

$$
I = \frac{E}{R_0+R_L} = \frac{12}{12+12} = 0.5\text{A}
$$

$$
U_L = IR_L = 0.5\times12 = 6\text{V}\quad\text{（只有一半！）}
$$

**为什么只有 6V？** 因为 $R_0 = R_L$，两个一样大，$E$ 被平分了。

**第四步，亮不亮？** $P_L = U_LI = 3\text{W}$，比额定状态下（$12\text{W}$）暗一半，但远超可见亮度阈值，肉眼"正常亮"。

**第五步，电源内部损耗**（最易忽略）：

$$
P_{\text{内}} = I^2R_0 = 0.25\times12 = 3\text{W}
$$

**损耗竟和灯泡一样大**，效率只有 50%。

**验算**：$\sum P = -EI + P_{\text{内}}+P_L = -6+3+3=0$ ✓

:::

::: tip 例 2 · 含理想源的功率记账（易错点密集）
电路：$12\text{V}$ 理想电源串 $4\Omega$，再串 $6\Omega$，最后接一个理想电流源 $I_S=1\text{A}$（箭头指向电源负极）。求各元件功率并验算。

**解**

**第一步，标方向。** 设回路电流 $I$ 沿"电源$+$ → $4\Omega$ → $6\Omega$ → 电流源 → 回电源$-$"流动。

**第二步，列 KCL。** 看 $6\Omega$ 与电流源的连接点：流进来的 $I$ 被电流源全部抽走：

$$
I = I_S = 1\text{A}
$$

于是 $4\Omega$ 与 $6\Omega$ 上电流都是 $1\text{A}$。

**第三步，求电流源两端的电压。** 沿回路列 KVL：

$$
12 - 4\times1 - 6\times1 - U_S = 0 \;\Rightarrow\; U_S = 2\text{V}
$$

**第四步，逐个记功率（先判关联性）。**

| 元件 | $P$ | 性质 |
| --- | --- | --- |
| $4\Omega$ | $I^2R = 4\text{W}$ | 吸收 |
| $6\Omega$ | $I^2R = 6\text{W}$ | 吸收 |
| 电压源 $12\text{V}$ | $-UI = -12\text{W}$ | 发出 |
| 电流源 $1\text{A}$ | $?$ | 需仔细判 |

电流源的功率是本题唯一的坑。电流从 $6\Omega$ 一侧**流出电流源**、流入电源负极。而 $N$ 点电位 $=12-4-6=2\text{V}$，高于负极的 $0\text{V}$ —— 即电流在电流源内部是从**高电位流向低电位**，属于**关联方向**（从"+"端流入）：

$$
P_{I_S} = +U_S I_S = +2\text{W}\quad\text{（吸收）}
$$

直觉解释：理想电流源在这里"搬运"了 $2\text{W}$ —— 电压源送出的 $12\text{W}$ 中，有 $2\text{W}$ 被电流源吸走并送回另一侧。

**第五步，验算。**

$$
\sum P = -12 + 4 + 6 + 2 = 0 \quad✓
$$

**教训**：负号不是"负数"，它表示**方向相反**。判断符号的唯一可靠方法是**先确认电流实际从哪个端进出**，再看 $UI$ 或 $I^2R$ 的形式。别在"发"和"收"上凭感觉。

:::

::: tip 例 3 · 参考方向标反了会怎样（符号的物理意义）
一段串联支路：电流 $I=2\,\text{A}$，参考方向从 $\text{a}$ 流向 $\text{b}$，$R_1=3\,\Omega$（a→b 段）、$R_2=5\,\Omega$（b→c 段）。求 $U_{ab}$、$U_{bc}$、$U_{ac}$。如果把电流参考方向改成从 $\text{b}$ 流向 $\text{a}$，结果怎么变？物理世界变了吗？

**解**

**按原标注（电流 a→b，与电压降方向一致）：**

$$
U_{ab}=IR_1=2\times3=6\text{V},\qquad U_{bc}=IR_2=2\times5=10\text{V}
$$

**逐段相加得总电压**（KVL 的电压形式）：

$$
U_{ac}=U_{ab}+U_{bc}=6+10=16\text{V}
$$

**改标参考方向（b→a）后**：计算时 $I=-2\,\text{A}$，于是 $U_{ab}=-6\,\text{V}$、$U_{bc}=-10\,\text{V}$、$U_{ac}=-16\,\text{V}$。

**物理世界一点没变**——电流还是那样流，电压还是那样降。变的只是**符号**：负号在说「实际方向与你标的相反」。

**功率不受标注影响**：

$$
P=I^2(R_1+R_2)=4\times8=32\,\text{W}
$$

$I^2$ 把符号平方掉了——所以「电阻永远吸收功率」这句话与参考方向无关，这也是 $P=I^2R$ 永远为正的原因。

**记法**：参考方向是**给方程用的坐标系**，不是对电路的判决。标错方向不会算错物理，只会得到一堆负号；但**同一个题里必须全程用同一套标注**，中途换标注等于换坐标系，必错。
:::

::: tip 例 4 · 黑盒电源：两次测量定参数（实验方法）
一个黑盒直流电源（未知 $E$、$R_0$）。接 $R_1=10\,\Omega$ 时端电压 $20\,\text{V}$；换接 $R_2=5\,\Omega$ 时端电压 $15\,\text{V}$。求 $E$、$R_0$、最大输出功率及此时效率。

**解**

**列外特性方程**：端电压 $U=E\cdot\dfrac{R_L}{R_0+R_L}$，两次测量代入：

$$
E\cdot\frac{10}{R_0+10}=20 \;\Rightarrow\; E=2R_0+20
$$

$$
E\cdot\frac{5}{R_0+5}=15 \;\Rightarrow\; E=3R_0+15
$$

**联立**：$2R_0+20=3R_0+15$ → $R_0=5\,\Omega$，代回得 $E=30\,\text{V}$。

**验算**：$30\times10/15=20\,\text{V}$ ✓；$30\times5/10=15\,\text{V}$ ✓。

**最大输出功率**（匹配条件 $R_L=R_0$）：

$$
P_{\max}=\frac{E^2}{4R_0}=\frac{900}{20}=45\,\text{W}
$$

验算：$R_L=5\,\Omega$ 时 $I=30/10=3\,\text{A}$，$P=I^2R_L=9\times5=45\,\text{W}$ ✓。

**效率**：匹配时电源内部损耗与输出相等（各 45 W），总发电 90 W，效率 **50%**——所以「最大功率传输」和「高效率」是矛盾的：匹配条件用于**信号传输**（要信号不要效率），电力传输绝不用匹配（要用效率）。

**工程注脚**：真实电池的 $R_0$ 随电量、温度变化，所以这两次测量在旧电池上会「对不上」。测电源参数要快，且负载变化别太大。
:::

## 考点 / 易错点

| 点 | 说明 |
| --- | --- |
| 参考方向不是实际方向 | 算完看符号，负号只表示"反了" |
| $U_{ab}$ 的下标顺序 | a 减 b，写反全题错；用减法验算一遍 |
| 开路 vs 短路 | 开路 $I=0$ 但 $U$ 可能很大；短路 $U=0$ 但 $I$ 极大 |
| 额定值 ≠ 工作点 | "$12\text{V}1\text{A}$"是上限，不是接到哪都是 12V/1A |
| 内阻是等效出来的 | $R_0 = U_{oc}/I_{sc}$，不是某个具体元件的阻值 |
| 功率符号 | 先判关联性再套 $P=\pm UI$；算完必须 $\sum P=0$ 验算 |
| 理想电流源短路 | 电流无界，比电压源短路更危险 |
| 分布参数电路 | 长线/高频下 KCL/KVL 失效，属传输线范畴 |
