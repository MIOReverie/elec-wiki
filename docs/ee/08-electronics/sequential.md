# 25 · 触发器与时序电路

## 结论先行

1. **触发器**有记忆：$Q^{n+1}$ 取决于输入**和**原状态 $Q^n$
2. **D 触发器**：$Q^{n+1} = D$（边沿触发）—— 最常用
3. **JK 触发器**：$Q^{n+1} = J\bar Q^n + \bar K Q^n$ —— 功能最全，$J=K=1$ 时**翻转**
4. 时序电路 = 组合电路 + 存储电路；分**同步**（共用一个时钟）和**异步**
5. 分析三步：写**驱动方程** → 代入**特性方程**得状态方程 → 列**状态表/时序图**

::: tip 规律层：时序逻辑的命门是「有记忆」
判断时序逻辑也只问一句：**输出受不受「原状态 $Q^n$」影响？** 受，就是时序——$Q^{n+1}$ 由输入和现态共同决定，时钟负责让状态「翻页」。所以分析时序电路永远是三步：写驱动方程 → 代入特性方程得状态方程 → 列状态表 / 画时序图。触发器是「一位记忆」，寄存器是「一组记忆」，计数器是「记忆 + 反馈计数」——一步步都从这条展开。
:::

## 触发器特性方程

| 触发器 | 特性方程 | 说明 |
| --- | --- | --- |
| **D** | $Q^{n+1} = D$ | 跟随输入 |
| **JK** | $Q^{n+1} = J\bar Q^n + \bar K Q^n$ | $J=K=1$ 翻转 |
| T | $Q^{n+1} = T\bar Q^n + \bar T Q^n$ | $T=1$ 翻转 |
| T' | $Q^{n+1} = \bar Q^n$ | 恒翻转（计数） |
| RS | $Q^{n+1} = S + \bar R Q^n$，$SR = 0$ | **约束：$S$、$R$ 不能同时为 1** |

触发方式：**电平触发**（有"空翻"问题）→ **主从触发** → **边沿触发**（现代主流，上升沿 / 下降沿）。

异步端 $\bar R_D$、$\bar S_D$：**不受时钟约束**，优先级最高，用于清零/置位。

## 时序电路分析方法

```
① 写各触发器的驱动方程（每个输入端 = 输入和现态的函数）
② 把驱动方程代入触发器的特性方程 → 得到状态方程 Qⁿ⁺¹
③ 写输出方程
④ 列状态转换表 / 状态图
⑤ 画时序图，归纳功能
```

::: tip 例 1 · JK 触发器：给一串 J、K，画出 Q 的波形
下降沿触发的 JK 触发器，初始态 $Q^n = 0$，时钟逐个来临时的 $(J, K)$ 依次为 $(1,0) \to (1,1) \to (0,1) \to (1,1) \to (0,0)$。求每个时钟沿之后的 $Q$。

**解**

用特性方程 $Q^{n+1} = J\bar Q^n + \bar K Q^n$ 逐拍算（**只在时钟沿瞬间采样**，边沿之后输入怎么变都不影响）：

| 时钟沿 | $(J,K)$ | $Q^n$ | 代入特性方程 | $Q^{n+1}$ |
| --- | --- | --- | --- | --- |
| 1 | (1, 0) | 0 | $1\times1 + 1\times0 = 1$ | **1**（置 1） |
| 2 | (1, 1) | 1 | $1\times0 + 0\times1 = 0$ | **0**（翻转） |
| 3 | (0, 1) | 0 | $0\times1 + 0\times0 = 0$ | **0**（保持 0） |
| 4 | (1, 1) | 0 | $1\times1 + 0\times0 = 1$ | **1**（翻转） |
| 5 | (0, 0) | 1 | $0\times0 + 1\times1 = 1$ | **1**（保持 1） |

所以 $Q$ 的变化是 $0 \to 1 \to 0 \to 0 \to 1 \to 1$。两步记忆法对照：$J=1, K=0$ 置 1；$J=0, K=1$ 清 0；$J=K=1$ **翻转**；$J=K=0$ **保持**——四种情况各出现一次，这就是 JK「功能最全」的来历。
:::

## 常用时序器件

### 寄存器

并行输入/并行输出的 D 触发器组，用来暂存数据；**移位寄存器**可左移/右移（串并转换）。

### 计数器

| 类型 | 特点 |
| --- | --- |
| **异步（行波）计数器** | 低位输出触发高位时钟，**有累积延迟**，简单但慢 |
| **同步计数器** | 所有触发器共用时钟，**速度快**，需要进位逻辑 |
| 集成 74LS161 | 4 位同步二进制加计数，带**异步清零**、**同步置数**、使能端 |

**任意进制计数器**（常考）：

- **清零法（复位法）**：计到 $N$ 时产生清零信号 → 构成 $N$ 进制
- **置数法（置位法）**：计到某值时同步置入初值 → 构成 $M$ 进制

例：用 74LS161 构成十进制：计到 1010（10）时令 $\bar R_D = 0$ 异步清零 → 0~9 循环。

::: tip 例 2 · 用 74LS161 构成十进制计数器
74LS161 是 4 位同步二进制加计数（$0000 \to 1111$ 共 16 态），带**异步清零**端 $\bar R_D$。要构成十进制（$N = 10$），数一下状态：$0000 \sim 1001$ 正好 10 个，所以**计到 1010 的瞬间就要清零**。

**解**

**反馈逻辑**：用一个与非门检测 1010——1010 里为 1 的位是 $Q_3$ 和 $Q_1$，所以接 $Q_3 Q_1$，两者同时为 1 时与非门输出 0，接到 $\bar R_D$。

**状态序列**：$0000 \to 0001 \to \cdots \to 1001 \to$ （下一个计数脉冲到来，状态刚要变成 1010，$\bar R_D$ 立刻变 0）$\to 0000$。

注意 1010 是一个**窄脉冲状态**（出现后立即被清掉），稳定循环里只有 $0 \sim 9$。

**关键对比（异步 vs 同步清零）**：

- **异步清零**（74161 是这种）：检测到 $N = 1010$ 就清——因为清零不看时钟，说清就清；
- **同步清零**（如 74163）：要检测 $N-1 = 1001$，等**下一个时钟沿**才生效，同样得到 $0 \sim 9$。

两种接法差 1：**异步用 $N$ 译码，同步用 $N-1$ 译码**。考试画错这一位，整个状态数就多一个或少一个。
:::

### 555 定时器（选学要点）

- **单稳态**：触发后输出一个固定宽度脉冲，$t_W = 1.1RC$
- **多谐振荡器**：自激振荡输出方波，$T = 0.7(R_1+2R_2)C$，$f = \dfrac{1.43}{(R_1+2R_2)C}$
- **施密特触发**：波形整形、消抖

## 考点速记

| 考法 | 关键 |
| --- | --- |
| 画时序图 | 先画 CLK，按边沿逐个更新 Q（注意是**边沿**不是电平） |
| 判断触发器类型 | 看是否有 $J$、$K$、$D$、$T$ 输入 |
| 异步 / 同步清零 | 异步立刻生效，同步要等下一个时钟边沿 |
| 构成 N 进制 | 清零法（异步清零用 $N$，同步清零用 $N-1$） |
| 555 频率计算 | $f = \dfrac{1.43}{(R_1+2R_2)C}$ |

::: warning 易错点
- **边沿触发**只在时钟跳变瞬间采样，CLK 保持期间输入变化**不影响**输出
- 异步清零端是**低电平有效**（$\bar R_D$），接线别搞反
- 同步清零法计到 $N-1$ 就要产生清零信号（等下一个边沿才清零）；异步清零法计到 $N$ 立刻清零 —— **差 1**
- 主从 JK 触发器存在"**一次变化现象**"，边沿触发没有
:::
