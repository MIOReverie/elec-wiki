先看一个具体的麻烦。你按下墙上的电灯开关，灯亮了。可如果开关的触点在闭合那一瞬间弹了两下（机械开关几乎都会），单片机就会读到「按、松、按」——一次按键被当成两次，计数器多加一次。在软件里加个延时也不行：延时期间若正好来了一次真正的新按键，就被吞掉了。

第二个麻烦是实验课上的常见困惑：同一个 D 触发器，把 $D$ 直接接开关，时钟接信号源。结果发现**时钟保持高电平的整段时间里**，$D$ 一变输出就跟着变——这哪像记忆元件？两个麻烦指向同一件事：**「记住一位」与「什么时候允许它改」是两件不同的事**。这一页先讲前者，再讲后者。

## 结论先行

1. 触发器之所以能记一位，是因为两个反相器首尾相接形成**双稳态**：只有两个稳定状态，中间那个平衡点不稳定。
2. 次态由「输入 + 现态」共同决定，写成一句话就是**特性方程**：D 型 $Q^{n+1}=D$，JK 型 $Q^{n+1}=J\overline{Q^n}+\overline{K}Q^n$。
3. 触发方式决定「什么时候看输入」：电平触发会在时钟高电平期间反复翻转（空翻），边沿触发只在跳变瞬间采样一次——现代电路一律用边沿触发。
4. 时序电路 = 组合电路 + 存储；分析固定三步：写**驱动方程** → 代入特性方程得**状态方程** → 列状态表 / 画时序图。
5. 现成器件分三类：寄存器（暂存与移位）、计数器（模 $N$ 循环，任意进制靠清零法或置数法，异步与同步差一个数）、定时器（555 给脉宽与频率）。

::: tip 规律层：时序逻辑的命门是「有记忆」
判断时序逻辑也只问一句：**输出受不受「原状态 $Q^n$」影响？** 受，就是时序——$Q^{n+1}$ 由输入和现态共同决定，时钟负责让状态「翻页」。触发器是「一位记忆」，寄存器是「一组记忆」，计数器是「记忆 + 反馈计数」，三者都从这一条展开。
:::

## 一、为什么能记住一位：双稳态

这一节只回答一个问题：两个反相器首尾相接，凭什么能把一位存住。

**双稳态**（bistable）的意思是电路只有两个稳定平衡点。把两个非门接成一个环：$Q$ 经过一个非门变成 $\overline{Q}$，$\overline{Q}$ 再经过一个非门变回 $Q$——这一圈刚好自洽两次。于是有两种自洽情形：$Q=1$、$\overline{Q}=0$，或者 $Q=0$、$\overline{Q}=1$。两种都能无限维持，因为它们**互相证明**。

这个环有一个隐患：如果两个门的延迟差别大，环会在两个状态之间来回「摇」很久才停下。工程上的解决办法是把它做成受控的——加一个「许可信号」，只有在许可的那一瞬间才允许它改。这个许可信号就是时钟。

能存一位之后，问题变成「什么时候允许它改」。下一节先给四种触发器的账本，再讨论时间。

## 二、四种触发器：特性方程就是一张表

这一节只做一件事：把「下一拍是什么」写成输入与现态的函数，并列出四种触发器各自的写法。

**特性方程**（characteristic equation）是触发器的全部行为描述：给定输入和现态，算出次态。它不含时间、不含电路细节，就是一张对照表。四种常见触发器如下：

| 触发器 | 特性方程 | 说明 |
| --- | --- | --- |
| **D** | $Q^{n+1} = D$ | 跟随输入，最常用 |
| **JK** | $Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n$ | 功能最全，$J=K=1$ 时翻转 |
| T | $Q^{n+1} = T\overline{Q^n} + \overline{T}Q^n$ | $T=1$ 翻转、$T=0$ 保持 |
| T′ | $Q^{n+1} = \overline{Q^n}$ | 恒翻转，最简的二分频器 |
| RS | $Q^{n+1} = S + \overline{R}Q^n$ | **约束：$S$、$R$ 不能同时为 1** |

JK 把四种操作都装进一个器件，值得单独记：$J=1,K=0$ 置 1；$J=0,K=1$ 清 0；$J=K=1$ **翻转**；$J=K=0$ **保持**。这四种操作分别对应「置位 / 复位 / 取反 / 保持」——所以它「功能最全」。

RS 的约束不是设计缺陷，而是逻辑必然：$S$、$R$ 同时为 1 意味着「既要置 1 又要清 0」，次态无法定义。JK 就是在它上面把「同时为 1」这个非法组合重新定义成翻转，从而消掉了约束。

特性方程只说「下一拍是什么」，没说「什么时候算这一拍」。时间这件事，下一节专门处理。

## 三、触发方式：电平、主从、边沿

这一节只回答一个问题：时钟的什么形态才算「许可」，不同许可方式会各出什么错。

三种方式，按历史顺序也是按优劣排：

- **电平触发**（level-triggered）：时钟为高（或为低）的**整段时间**都允许改。问题是**空翻**——时钟高电平期间若输入变了多次，输出就翻转多次，一个时钟周期里状态可能翻好几下，这个电路就没法按拍分析了。
- **主从触发**（master-slave）：用两级锁存器串起来，前级在时钟高电平期间接数据、后级在低电平期间接前级的结果，从而在一个周期内只更新一次。它解决了空翻，但仍有「一次变化现象」：时钟高电平期间输入变化可能被后级记住。
- **边沿触发**（edge-triggered）：只在时钟**跳变的那一瞬间**采样，上升沿（↑）或下降沿（↓）。现代芯片几乎全是这一种——它保证了一个时钟周期内状态只可能变一次，于是「一拍一步」可以严格推算。

**异步端**是另一条时间通道：$\overline{R_D}$（清零）与 $\overline{S_D}$（置位）**不受时钟约束**，一按就生效，优先级高于一切同步输入。它们的作用是「开机时把状态摆到已知位置」，代价是把「一切都在沿上发生」这个前提破坏掉——所以正常工作时应当接无效电平，只在复位瞬间动它。

还有一种更隐蔽的时间限制：数据必须在时钟沿之前稳定一段时间（**建立时间** $t_{su}$）、在沿之后还要稳一段时间（**保持时间** $t_h$），否则触发器会进入既不是 0 也不是 1 的**亚稳态**。这两条由工艺决定，构成「这个电路最快能跑多快」的约束，完整推导见数字电路课 [05 · 触发器](../../digital/flip-flops.md) 与 <Prereq id="setup-hold" />。

触发方式定了「什么时候看输入」，接下来就可以把时间切成拍，一拍一拍地推。下一节把这件事固定成三步。

## 四、时序电路分析三步

这一节做一件事：给你一个含触发器的电路，按固定三步推出它的全部状态变化。

先给三个词的准确含义，它们就是三步的产物：

- **驱动方程**（drive equation）：每个触发器输入端等于什么（输入变量与现态的函数）。它是「线路图」翻译成「方程」的第一步。
- **状态方程**：把驱动方程代入特性方程，得到 $Q_i^{n+1}=f(\text{输入},Q^n)$。它才是真正描述「下一拍」的式子。
- **状态转换表 / 状态图 / 时序图**：同一个结果的三种画法。状态表是「现态 → 次态」的表格；状态图把状态画成圆圈、转移画成箭头；时序图把 CLK 与各 $Q$ 按时间轴排成波形，**同一竖直位置就是同一时刻**。

步骤固定为五小步（前三步是主线）：

```
① 写各触发器的驱动方程（每个输入端 = 输入和现态的函数）
② 把驱动方程代入触发器的特性方程 → 得到状态方程 Qⁿ⁺¹
③ 写输出方程（如果输出不是直接取自 Q）
④ 列状态转换表 / 状态图
⑤ 画时序图，归纳功能
```

为什么必须按这个顺序：时序电路里有环（输出回到输入），不能像组合电路那样「从输入一路算到输出」。唯一能算的方向是**时间**——用 $Q^n$ 算出 $Q^{n+1}$，再把 $Q^{n+1}$ 当新的现态。第 ① 步写驱动方程，是为了让每一拍的代数运算能机械地重复。

分析完电路，再看看现成的时序器件都替你做了什么。下一节按「寄存器 → 计数器 → 定时器」走一遍。

## 五、常用时序器件

这一节做一件事：认识三类现成器件，并记住它们各自解决什么问题。

**寄存器**（register）是一组共用一个时钟的触发器：时钟沿一到，整组同时存下当前输入，于是它能「暂存一个字」。**移位寄存器**把前一级的输出接后一级的输入，沿一拍移一位，用于串行 ↔ 并行转换（比如把串行收到的 8 位拼成一个字节）。

**计数器**（counter）是「每来一个时钟，输出按固定规律变一次」的电路，最常用的规律是数数。它的全部信息是**模**（modulus，记作 $N$）：一个循环里有几个状态。

| 类型 | 特点 |
| --- | --- |
| **异步（行波）计数器** | 低位输出触发高位时钟，**延迟累积**，简单但慢 |
| **同步计数器** | 所有触发器共用时钟，**速度快**，需要额外进位逻辑 |
| 集成 74LS161 | 4 位同步二进制加计数，带**异步清零**、**同步置数**、使能端 |

**任意进制计数器**是考试重点，只有两条路：

- **清零法（复位法）**：计到某个值时产生清零信号，硬把它拉回 0。**异步清零要检测 $N$**——因为「说清就清」，检测到 $N$ 时它还没真的停在 $N$ 上。
- **置数法（置位法）**：计到某个值时同步装入一个初值，从初值继续数。**同步置数要检测 $N-1$**——因为要等下一个时钟沿才生效。

两种接法只差一个数，却是最常失分的地方：**异步清零用 $N$ 译码，同步清零 / 置数用 $N-1$ 译码**。

**555 定时器**（选学，但公式要背）是「模拟电路怎么变成时钟源」的经典答案：内部两个比较器加一个 RS 触发器，靠外部 RC 充放电定时。

- **单稳态**：来一个触发脉冲，输出一个固定宽度的脉冲，$t_W=1.1RC$；
- **多谐振荡器**：自激振荡输出方波，$T=0.7(R_1+2R_2)C$，$f=\dfrac{1.43}{(R_1+2R_2)C}$；
- **施密特触发**：把缓慢变化的波形整形成陡边沿，也用来给按键消抖。

器件会用了，但「会接」和「会算」是两件事。下一节用两道题把三步分析法和清零法各走一遍。

## 六、例题

**步骤**：用特性方程 $Q^{n+1}=J\overline{Q^n}+\overline{K}Q^n$ 逐拍算（只在时钟沿瞬间采样，边沿之后输入怎么变都不影响）：

| 时钟沿 | $(J,K)$ | $Q^n$ | 代入特性方程 | $Q^{n+1}$ |
| --- | --- | --- | --- | --- |
| 1 | (1, 0) | 0 | $1\times1+1\times0=1$ | **1**（置 1） |
| 2 | (1, 1) | 1 | $1\times0+0\times1=0$ | **0**（翻转） |
| 3 | (0, 1) | 0 | $0\times1+0\times0=0$ | **0**（保持 0） |
| 4 | (1, 1) | 0 | $1\times1+0\times0=1$ | **1**（翻转） |
| 5 | (0, 0) | 1 | $0\times0+1\times1=1$ | **1**（保持 1） |

*（为什么第 1 拍能置 1：$J=1$ 时式子里 $J\overline{Q^n}=1$，第二项恒为 0，所以次态与现态无关，直接被钉成 1。）*

**验算（两条独立路径）**：

1. **用四种操作口诀复核**：$J=1,K=0$ 置 1 ✓；$J=K=1$ 翻转，从 1 翻成 0 ✓；$J=0,K=1$ 清 0，本来就是 0 ✓；$J=K=1$ 翻转，从 0 翻成 1 ✓；$J=K=0$ 保持 1 ✓。五拍全对。
2. **检查图的形状**：Q 只在五条竖虚线处变化，虚线之间是水平段；若画成「斜着变」或「跟着 J 变」，就是把边沿触发错当成了电平触发 ✗。

**这一节最该带走的一句**：画时序图时先画 CLK 与采样虚线，再一格一格填 Q——只要 Q 在虚线之间动过，就是画错了。

1. **定状态与模**：稳定状态 $0000\sim1001$ 共 10 个，故 $N=10$，需要 4 位触发器（$2^3=8<10\le16=2^4$）。
2. **写反馈逻辑**：检测 1010——这一码里为 1 的位是 $Q_3$ 与 $Q_1$，所以取 $Q_3$、$Q_1$ 接与非门（$Q_3Q_1$ 同时为 1 时输出 0），输出接 $\overline{R_D}$。*（为什么只接两位就够：从 0000 递增时，$Q_3=Q_1=1$ 第一次出现恰好是 1010；1011、1110、1111 都在清零之后才可能出现，来不及被用上。所以不必做全译码，省门。）*
3. **确认清零类型**：74LS161 的 $\overline{R_D}$ 是**异步**的——不看时钟，一有效立刻清 0。所以检测 $N=1010$ 本身，而不是 $N-1$。
4. **画出序列**：$0000\to0001\to\cdots\to1001\to$（下一拍刚要变 1010，$\overline{R_D}$ 立刻拉低）$\to0000$。

**验算**：

- **数状态**：$0\sim9$ 一共 10 个，与要求的模 10 一致 ✓。
- **对差一错误**：若误按同步清零的思路检测 1001，则计到 9 就清零，循环只剩 $0\sim8$ 共 9 个状态——模 9，少一个。这就是「异步用 $N$、同步用 $N-1$」这句话的来历。
- **检查约束**：161 共 16 态，$N=10\le16$，可行；若 $N>16$ 就要两片级联。

**关键对比（异步 vs 同步清零）**：

- **异步清零**（74161）：检测到 $N$ 就清——因为清零不看时钟，说清就清；
- **同步清零**（如 74163）：要检测 $N-1$，等**下一个时钟沿**才生效，同样得到 $0\sim9$。

## 考点速记

| 考法 | 关键 |
| --- | --- |
| 画时序图 | 先画 CLK 与采样虚线，按**边沿**逐个更新 Q（不是按电平） |
| 判断触发器类型 | 看是否有 $J$、$K$、$D$、$T$ 输入；看特性方程的形状 |
| 异步 / 同步清零 | 异步立刻生效（检测 $N$），同步要等下一个时钟沿（检测 $N-1$） |
| 构成 N 进制 | 清零法（异步清零用 $N$，同步清零用 $N-1$）或置数法 |
| 555 频率计算 | $f=\dfrac{1.43}{(R_1+2R_2)C}$，单稳脉宽 $t_W=1.1RC$ |
| 判断组合 / 时序 | 看输出受不受原状态 $Q^n$ 影响 |

## 易错清单

按踩坑频率从高到低排，格式是「错误做法 → 会得到什么 → 正确做法」。

1. **把电平触发当边沿触发** → 时序图在时钟高电平期间画了多次翻转，按拍推算时状态对不上 → 边沿触发只在跳变瞬间变一次，Q 的水平段必须横跨整个时钟周期。
2. **异步清零接 $N-1$，或同步清零接 $N$** → 状态数差一个，模 N 变成模 N±1 → 记死「异步 $N$、同步 $N-1$」。
3. **异步清零端当成高有效** → 接反后芯片一直处于清零状态，永远数不上去 → $\overline{R_D}$ 的横线表示低有效，写 0 才起作用。
4. **把 $Q^{n+1}$ 的上标当指数** → 误以为 $Q^2=Q\times Q$，式子读不通 → 上标只是第几拍的编号。
5. **列状态表时漏掉「现态」这一列** → 每个输入都算出两个可能的次态，无法判断 → 状态表的行必须包含现态 $Q^n$。
6. **主从 JK 的「一次变化现象」当成边沿触发** → 高电平期间输入变化被记住，结果与手册不符 → 主从不是边沿；现代器件用边沿触发。
7. **默认异步清零「想什么时候按都行」** → 在时钟沿附近清零会引发竞争，状态不确定 → 异步端只在系统复位瞬间用，正常工作时接无效电平。
8. **移位寄存器方向搞反**（左移 / 右移）→ 串并转换的位序颠倒 → 先确认哪一端是「低位先入」。
