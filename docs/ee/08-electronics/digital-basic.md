## 结论先行

1. **数制**：二进制 ↔ 十进制 ↔ 十六进制；$16 = 2^4$，所以 hex 一位对应 bin 四位
2. **BCD 码**：用 4 位二进制表示 1 位十进制（0000~1001），常用于数码显示
3. **逻辑门**：与/或/非 → 与非/或非/异或；**与非、或非是"全能门"**
4. **布尔代数**：德摩根定律 + 吸收律，用于化简
5. **TTL / CMOS**：TTL 速度快、CMOS 功耗低、CMOS 输入**不能悬空**

## 数制转换

**十进制 → 二进制**：除 2 取余，倒序排列
**二进制 → 十进制**：按权展开
**二进制 ↔ 十六进制**：**每 4 位一组**直接换

$$
(1011\,0110)_2 = (\text{B}6)_{16} = 182_{10}
$$

**BCD 码**：$182_{10} = (0001\,1000\,0010)_{BCD}$（注意：这不是 182 的二进制）

::: tip 例 1 · 同一个 182，四种长相
把 $(182)_{10}$ 写成二进制、十六进制和 BCD 码，并说明为什么 BCD 和二进制差那么远。

**解**

- **十转二**（除 2 取余，倒序）：$182 = 128+32+16+4+2$，即 $(1011\,0110)_2$；
- **二转十六进制**（每 4 位一组）：$(1011\,0110)_2 = (\text{B}6)_{16}$——没有经过十进制，直接查表；
- **BCD**（每位十进制单独编 4 位）：$1 \to 0001$，$8 \to 1000$，$2 \to 0010$，得 $(0001\,1000\,0010)_{BCD}$，一共用了 12 位。

二进制只用了 8 位就表示到 182，BCD 却用了 12 位——**BCD 浪费位数换来的是「一眼读出十进制」**，数码管显示就靠它。所以看到 `0001 1000 0010` 要立刻反应：这是 BCD 的 182，绝不是二进制的 280。
:::

## 逻辑门

| 门 | 表达式 | 口诀 |
| --- | --- | --- |
| 与 | $Y = AB$ | 全 1 出 1 |
| 或 | $Y = A+B$ | 有 1 出 1 |
| 非 | $Y = \bar A$ | 取反 |
| 与非 | $Y = \overline{AB}$ | **有 0 出 1** |
| 或非 | $Y = \overline{A+B}$ | **有 1 出 0** |
| 异或 | $Y = A\bar B + \bar A B = A\oplus B$ | 相异出 1 |
| 同或 | $Y = \overline{A\oplus B}$ | 相同出 1 |

## 布尔代数

**德摩根定律**（最重要）：

$$
\overline{A+B} = \bar A \cdot \bar B \qquad \overline{AB} = \bar A + \bar B
$$

**常用公式**：

$$
A + AB = A \quad A(A+B) = A \quad A + \bar A B = A + B
$$
$$
AB + \bar A C + BC = AB + \bar A C \quad (\text{冗余项可消})
$$

## 逻辑函数化简

**公式法** → 熟练度高才能用；**卡诺图** → 直观可靠，考试推荐。

卡诺图步骤：

```
① 画 2ⁿ 格卡诺图，按格雷码排列（相邻格只有一位不同）
② 真值表/表达式 → 填 1
③ 圈 1：圈必须是 2ᵏ 个相邻格，圈越大越好、圈数越少越好
④ 每个圈写成一个"与项"，变量取值不变的保留，变化的消去
⑤ 各圈相"或"
```

**无关项**（don't care，记 ×）可以当 1 也可以当 0，用来把圈画大。

::: tip 例 2 · 卡诺图化简 $Y = \sum m(1,3,5,7)$
三变量函数，最小项为 $m_1, m_3, m_5, m_7$。画卡诺图（行 $AB$ 按格雷码 00/01/11/10，列 $C$ 按 0/1），填 1：

| $AB \backslash C$ | 0 | 1 |
| --- | --- | --- |
| 00 | 0 | **1** ← $m_1$ |
| 01 | 0 | **1** ← $m_3$ |
| 11 | 0 | **1** ← $m_7$ |
| 10 | 0 | **1** ← $m_5$ |

**解**

四个 1 全在 $C = 1$ 那一列，且行方向按格雷码排列正好首尾相接（00 和 10 也是相邻的！），可以**一口气圈成一个大圈**（4 格 $= 2^2$，合规）。圈内 $C$ 始终为 1，$A$、$B$ 都在变 → 消去，只剩：

$$Y = C$$

**验算**：$m_1 = 001$、$m_3 = 011$、$m_5 = 101$、$m_7 = 111$——四个最小项的共同点就是 $C = 1$，与答案一致。这题考两件事：**格雷码排列让列的两端也相邻**；**圈越大消去变量越多**，四格圈比两个两格圈简得多。
:::

## 器件常识

| | TTL | CMOS |
| --- | --- | --- |
| 电源 | 5 V（严格） | 3~18 V（宽） |
| 速度 | 快 | 较慢（现代已很快） |
| 功耗 | 大 | **极小** |
| 输入 | 悬空视为高电平 | **严禁悬空**（会感应、可能损坏） |
| 抗干扰 | 一般 | 强 |

**OC/OD 门**（集电极/漏极开路）：必须**外接上拉电阻**才能输出高电平；可直接"线与"。

**三态门**：输出有 0 / 1 / **高阻 Z** 三态，用于**总线**（多个设备共用一条线，同一时刻只允许一个驱动）。

::: warning 易错点
- CMOS 多余输入端**不能悬空**：多余与/与非端接高电平，多余或/或非端接地
- TTL 多余输入端悬空等效高电平，但抗干扰差，最好也接固定电平
- BCD 码与二进制不是一回事（$(12)_{10}$ 的 BCD 是 `0001 0010`，二进制是 `1100`）
- 卡诺图必须按**格雷码**排（00 / 01 / 11 / 10）；照二进制顺序 00 / 01 / 10 / 11 排，相邻格就不止差一位，圈出来的项会错
:::
