# 磁路欧姆定律

磁路与电路**形式同构**（但铁磁材料的 $\mu$ 非线性）：

$$
\Phi = \frac{F}{R_m} = \frac{NI}{\dfrac{l}{\mu S}}
$$

| 电路量 | 磁路量 |
| --- | --- |
| 电流 $I$ | 磁通 $\Phi$ |
| 电动势 $E$ | 磁动势 $F = NI$ |
| 电阻 $R = l/(\gamma S)$ | 磁阻 $R_m = l/(\mu S)$ |
| 欧姆定律 $I = E/R$ | $\Phi = F/R_m$ |

配套定律：

- **安培环路定律**：$\oint H\,dl = \sum I$，即 $Hl = NI$
- $B = \mu H$，$\Phi = BS$

要点：铁心的 $\mu$ 很大 → 磁阻很小 → 磁通集中在铁心内；**气隙**的 $\mu_0$ 小得多，气隙往往是磁阻的主要来源。
