# 转差率 s

异步电机的转子转速 $n$ **永远低于**旋转磁场的同步转速 $n_0$（否则没有相对运动、没有感应电流、没有转矩）：

$$
s = \frac{n_0 - n}{n_0} \qquad n_0 = \frac{60f}{p}
$$

（$p$ = 极对数；$f=50$Hz 时：$p=1 \to 3000$，$p=2 \to 1500$，$p=3 \to 1000$ r/min）

| 状态 | $s$ | 说明 |
| --- | --- | --- |
| 理想空载 | 0 | $n = n_0$，无转矩 |
| 额定运行 | 0.02 ~ 0.06 | 效率最高区 |
| 堵转（起动瞬间） | 1 | $n=0$，电流最大 |

转子频率：$f_2 = s f_1$，起动时 $f_2 = f_1$，额定运行时 $f_2$ 只有 1~3 Hz。
