# 转差率 s

<Meta time="5 min" level="卡片" note="s 不是损耗，它是异步机能出转矩的根本原因" />

铭牌上写着额定转速 1440 r/min，多数人的第一反应是「同步转速大概也是 1440」。不是，同步转速是 1500。差的那 60 r/min，就是这台电机能转起来的原因。

转子要是追平了旋转磁场，就没有相对运动，没有感应电流，也就没有转矩。

## 定义

风车的比喻很贴切：叶片跑得和风一样快，风就贴着叶片过去，什么都推不动。转子必须落后于旋转磁场，才会被拖着走。

同步转速 $n_0$ 是旋转磁场的转速；转差率 $s$ 是转子转速 $n$ 与同步转速 $n_0$ 的相对差：

$$
s = \frac{n_0 - n}{n_0} \qquad n_0 = \frac{60f}{p}
$$

$p$ 是极对数，$f$ 是电源频率 Hz，$n_0$、$n$ 的单位是 r/min。

## 常用取值

$f = 50\ \text{Hz}$ 时：$p = 1 \to 3000$ r/min，$p = 2 \to 1500$ r/min，$p = 3 \to 1000$ r/min。

| 状态 | $s$ | 说明 |
| --- | --- | --- |
| 理想空载 | 0 | $n = n_0$，无转矩 |
| 额定运行 | 0.02 ~ 0.06 | 效率最高区 |
| 堵转（起动瞬间） | 1 | $n = 0$，电流最大 |

## 转子频率

$$
f_2 = s f_1
$$

起动时 $s = 1$，所以 $f_2 = f_1$；额定运行时 $s$ 只有 0.02～0.06，$f_2$ 就只有 1～3 Hz。$f_1$ 是电源频率，$f_2$ 是转子电流频率。

## 三个误解

1. 把 $s$ 当成电机的损耗比例。$s$ 是转速差的比例。转子铜耗确实与 $s$ 成正比，所以 $s$ 大时效率低，但这两件事本身不是一回事。
2. 以为 $s$ 可以取 0 或负数。同步电机可以超同步运行，那时 $s$ 为负；异步电机靠感应工作，转速必须低于 $n_0$，所以 $0 \le s \le 1$。
3. 以为起动时 $s$ 很小、电机已经转起来了。起动瞬间 $n = 0$，$s = 1$，是全程最大值。转子串电阻、降压起动，都是为了在 $s = 1$ 附近拿到更大的转矩。

## 例题

::: tip 例 1 · 从转速反推转差率
题目：一台四极（$p = 2$）异步电动机接在 50 Hz 电源上，额定转速 1440 r/min。求同步转速、转差率与转子电流频率。

先想什么：三步顺序不能乱，先由极数和频率定 $n_0$，再由 $n_0$ 与 $n$ 定 $s$，最后由 $s$ 定 $f_2$。*（$s$ 是中间量，两头都靠它。）*

步骤：

1. 同步转速：$n_0 = 60f/p = 60 \times 50/2 = 1500\ \text{r/min}$。*（为什么先算 $n_0$：$s$ 的分母是它，不知道 $n_0$ 就没法算 $s$。）*
2. 转差率：$s = (1500 - 1440)/1500 = 60/1500 = 0.04$。
3. 转子频率：$f_2 = s f_1 = 0.04 \times 50 = 2\ \text{Hz}$。

验算：$s = 0.04$ 落在额定区间 0.02～0.06 ✓。再反推：$n = n_0(1 - s) = 1500 \times 0.96 = 1440\ \text{r/min}$ ✓，与题给一致。

一个直观检查：额定转速总是略低于同步转速，看到 1440 就该想到 1500，这条经验规则很好用。
:::
