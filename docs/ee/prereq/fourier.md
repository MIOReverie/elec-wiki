# 傅里叶级数

<Meta time="5 min" level="卡片" note="傅里叶级数不是近似，它精确等于原波形，只是需要无穷多项" />

方波拆开以后，只剩 1、3、5、7 这些奇次谐波，偶次的呢。答案是根本不存在：对称性把它们抵消掉了。

波形拆解这件事，一半靠公式，一半靠看形状。

## 拆成什么样

日常说法最好懂：一段难看的周期波形，方波、三角波、锯齿波、整流后的脉动波，都可以看成「一个直流加很多个不同频率的正弦波」叠出来。就像一支曲子能拆成很多单音。

傅里叶级数（Fourier series）就是把周期为 $T$ 的周期函数 $f(t)$ 展开成正弦与余弦分量之和：

$$
f(t)=a_0+\sum_{k=1}^{\infty}\Big(a_k\cos k\omega t+b_k\sin k\omega t\Big),\qquad \omega=\frac{2\pi}{T}
$$

其中 $a_0$ 是直流分量，也就是一个周期内的平均值；$\omega$ 是基波角频率；$k=1$ 的分量叫基波，$k\ge2$ 的分量叫谐波。

系数 $a_k$、$b_k$ 怎么算，正文那一页直接给结果，这里不要求你会积分。

## 三个典型数值

方波只有奇次谐波，没有偶次，也没有直流分量。三角波同样只有奇次谐波，但系数衰减快得多，按 $1/k^2$ 走，所以三角波听起来、看起来都比方波「干净」。

整流后的脉动波正相反，它有明显的直流分量，这正是整流要的东西。

工程上算非正弦量，取前几项就够：高次谐波的幅值已经小到不影响结果。

## 三条常错

1. 说「傅里叶级数只是近似」。它是精确相等，把无穷多项全加起来就完全等于原波形。平时只用前几项，那叫截断，不叫近似。
2. 以为方波里什么频率都有。方波只有奇次谐波（1、3、5、7…次），偶次和直流都是 0。
3. 以为系数必须会积分才算得出来。工科做题时，方波、三角波这些标准波形的系数直接查表，或者用对称性判断即可。
