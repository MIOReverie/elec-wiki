# 傅里叶级数

<Meta time="5 min" level="卡片" note="傅里叶级数不是「近似」，它精确等于原波形，只是需要无穷多项" />

一句话结论：**任何周期波形都能拆成「直流分量 + 基波 + 各次谐波」的正弦分量之和，这一串正弦波精确地重新拼回原波形；我们实际只用前几项，是因为高次谐波的贡献往往很小。**

## 日常说法与正式定义

- 日常说法：把一段难看的周期波形（方波、三角波、锯齿波、整流后的脉动波），看成是「一个直流 + 很多个不同频率的正弦波」叠出来的。就像一支曲子能拆成很多个单音，波形也能拆成很多个正弦分量。
- 正式定义：**傅里叶级数**（Fourier series）是把周期为 $T$ 的周期函数 $f(t)$ 展开成正弦（与余弦）分量之和：

$$
f(t)=a_0+\sum_{k=1}^{\infty}\Big(a_k\cos k\omega t+b_k\sin k\omega t\Big),\qquad \omega=\frac{2\pi}{T}
$$

其中 $a_0$ 是**直流分量**（一个周期内的平均值），$\omega$ 是**基波角频率**；$k=1$ 的分量叫**基波**，$k\ge2$ 的分量叫**谐波**。

（本页只讲怎么用它，系数 $a_k$、$b_k$ 怎么算在正文那一页直接给结果，不要求你会积分。）

## 常见误解

1. **「傅里叶级数只是近似」** → 它是**精确相等**——只要把无穷多项全加起来就完全等于原波形。我们平时只用前几项，那是「截断」，不是「近似本身」。
2. **「方波只有基波没有别的」** → 方波只有**奇次谐波**（1、3、5、7…次），没有偶次谐波、也没有直流分量；三角波同样只有奇次谐波，但系数衰减快得多（按 $1/k^2$）。
3. **「系数必须会积分才算得出来」** → 工科做题时，方波、三角波这些标准波形的系数直接查表或用对称性判断即可，正文那一页把前 3 项都列好了。
