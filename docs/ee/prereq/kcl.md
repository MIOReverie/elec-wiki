# 基尔霍夫电流定律 KCL

任一节点，任一时刻：

$$
\sum I = 0 \quad \Longleftrightarrow \quad \sum I_{入} = \sum I_{出}
$$

本质是**电荷守恒**（节点不能堆积电荷），与元件性质无关，线性/非线性、直流/交流都成立。

推广形式：**广义节点**——把电路里任意一块区域（闭合面）看作一个节点，穿过这个面的电流代数和也为 0。

::: warning 易错点
KCL 用的是**参考方向下的代数值**。$\sum I=0$ 里的每个 $I$ 都带符号，不是绝对值相加。
:::
