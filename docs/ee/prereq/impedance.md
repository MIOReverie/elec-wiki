# 阻抗与导纳

<Meta time="5 min" level="卡片" note="电感是「电压超前」，电容是「电流超前」——两个 90° 方向相反，这一句错了后面谐振、功率因数全部反向" />

一句话结论：**阻抗 $Z$ 是「电压 ÷ 电流」这个复数：电阻是纯实数、电感是 $+j$、电容是 $-j$；所以电感的电压超前电流 90°、电容的电流超前电压 90°，两者方向相反。**

## 日常说法与正式定义

- 日常说法：直流下电阻「挡路」，电感「短路」，电容「断路」；到了交流，电感和电容开始「挡路」，而且挡的方式很特别——它们不让电流变小，只是让电压和电流**错开一个角度**。
- 正式定义：正弦稳态下元件两端的**相量**电压与**相量**电流之比称为**阻抗**：

$$
Z = \frac{\dot U}{\dot I} = R + jX = |Z|\angle\varphi
$$

它的倒数称为**导纳**：

$$
Y = \frac{1}{Z} = G + jB
$$

**符号逐个读**：

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $Z$ | 阻抗 | $\Omega$ |
| $Y$ | 导纳 | S（西门子） |
| $R$ | 阻抗的实部，就是纯电阻 | $\Omega$ |
| $X$ | 阻抗的虚部，叫**电抗** | $\Omega$ |
| $G$ | 导纳的实部，叫**电导** | S |
| $B$ | 导纳的虚部，叫**电纳** | S |
| $\omega$ | 角频率，$\omega=2\pi f$ | rad/s |
| $\varphi$ | 阻抗的幅角，即电压与电流的相位差 | ° |

::: warning 中文术语提醒
导纳的虚部 $B$ 叫**电纳**（不是「电抗」）；电抗是 $X$。两个名字只差一个字，指的却是互为倒数的两个量，读题时要看清楚是 $X$ 还是 $B$。
:::

## 三个基本元件的阻抗

| 元件 | 阻抗 | 大小 | 相位 |
| --- | --- | --- | --- |
| $R$ | $R$ | $R$ | 同相 |
| $L$ | $j\omega L$ | $X_L = \omega L$ | **电压超前 90°** |
| $C$ | $\dfrac{1}{j\omega C} = -\dfrac{j}{\omega C}$ | $X_C = \dfrac{1}{\omega C}$ | **电流超前 90°** |

**为什么是这个方向**：电感的时域关系是 $u=L\dfrac{di}{dt}$，求一次导 → 电压超前电流 90°；电容是 $i=C\dfrac{du}{dt}$，求一次导 → 电流超前电压 90°。两个 90° 一来一去，正好相反。

## 串联时怎么加

串联电路里电流相同，所以各元件的阻抗直接相加：

$$
Z = R + j(X_L - X_C),\quad |Z| = \sqrt{R^2+X^2},\quad \varphi = \arctan\frac{X_L-X_C}{R}
$$

于是：

- $X_L > X_C$ → **感性**（电流滞后电压）
- $X_L < X_C$ → **容性**（电流超前电压）
- $X_L = X_C$ → **阻性**（谐振，$Z = R$ 最小）

::: tip 一句口诀
**电感在「上」，电流滞后；电容在「下」，电流超前。** 记忆办法：电感的阻抗是 $+j\omega L$，正号在上方。
:::

## 直流极限：电感短路、电容开路

当 $\omega=0$（直流）时：

- 电感：$Z_L = j\omega L = 0$ → **短路**（电压为零，电流可以任意大）
- 电容：$Z_C = \dfrac{1}{j\omega C} \to \infty$ → **开路**（电流为零）

这两条不是「特例规定」，而是从公式里自然掉出来的：直流下电感里的电流不随时间变（导数为 0，所以没有电压），电容两端电压不变（所以没有电流）。

## 常见误解

1. **把「阻抗」当成「电阻」** → 用 $|Z|$ 直接当阻值算功率 → 阻抗是复数，实部 $R$ 才是耗能的部分，$P = I^2R$ 用的是它。
2. **说成「电容的电压超前 90°」** → 阻抗三角形的方向全反 → 电容是**电流**超前电压 90°（等价说法：电容电压滞后 90°）。
3. **用电阻的直觉理解电抗** → 以为电流被「挡住」变小 → 电抗不改变电流的**大小**，只改变**相位**。
4. **在直流下还用电抗公式** → 算出除零 → 直流直接用「电感短路、电容开路」这两句。
5. **以为电感电容是「阻抗小/大」** → 以为 $X_C$ 随频率升高而变大 → $X_C = 1/(\omega C)$ 随频率**升高而变小**；$X_L = \omega L$ 随频率升高而变大。

## 例题

::: tip 例 1 · 串联 RLC 的总阻抗
**题目**：$R = 6\ \Omega$、$L = 44.6\ \text{mH}$、$C = 530\ \mu\text{F}$ 串联，接在 $220\ \text{V}$、$50\ \text{Hz}$ 电源上。求总阻抗、电流有效值，并判断电路性质。

**先想什么**：串联电路电流相同，所以三个阻抗直接相加——先算两个电抗，再合成。

**步骤**：

1. 角频率：$\omega = 2\pi f = 2\pi\times50 = 314\ \text{rad/s}$。*（为什么先算 $\omega$：两个电抗的公式里都有它。）*
2. 感抗：$X_L = \omega L = 314\times44.6\times10^{-3} = 14\ \Omega$。
3. 容抗：$X_C = \dfrac{1}{\omega C} = \dfrac{1}{314\times530\times10^{-6}} = 6\ \Omega$。
4. 总阻抗：

$$
Z = 6 + j(14-6) = 6 + j8\ \Omega = 10\angle53.1^\circ\ \Omega
$$

*（为什么虚部是相减：电感的 $+j$ 向上、电容的 $-j$ 向下，在虚轴上互相抵消一部分。）*

5. 电流：$I = \dfrac{U}{|Z|} = \dfrac{220}{10} = 22\ \text{A}$，相位上**滞后**电压 $53.1^\circ$。

**验算（用几何法独立算一遍）**：$\sqrt{6^2+8^2}=\sqrt{100}=10\ \Omega$ ✓；$\arctan(8/6)=53.1^\circ$ ✓。再验相位性质：$X_L=14 > X_C=6$，电抗为正 → 感性 → 电流滞后 ✓，与 $53.1^\circ$ 为正一致。

**注意**：$X_L>X_C$，所以是感性电路；若换成 $C=1060\ \mu\text{F}$，则 $X_C=3\ \Omega$，$X=11$，阻抗变大、电流变小——频率再往高处，电抗差的走向会反过来。
:::
