# 阻抗与导纳

<Meta time="5 min" level="卡片" note="电感让电压超前，电容让电流超前，两个 90° 方向相反；这一句记错，后面的谐振与功率因数会全线反向" />

「电容的电压超前电流 90°」这句话，每年都有人背反。背反的后果不止错一道题：阻抗三角形的方向、功率因数的正负、谐振时谁超前，全都跟着反过来。

记住一个动作就够了。电感的时域关系是 $u=L\dfrac{di}{dt}$，对电流求一次导，电压跑到前面去；电容是 $i=C\dfrac{du}{dt}$，对电压求一次导，电流跑到前面去。

## 阻抗是复数，不是电阻

正弦稳态下，元件两端的相量电压与相量电流之比叫阻抗：

$$
Z = \frac{\dot U}{\dot I} = R + jX = |Z|\angle\varphi
$$

它的倒数叫导纳：

$$
Y = \frac{1}{Z} = G + jB
$$

阻抗 $Z$ 说到底就是「电压除以电流」这个复数。电感贡献 $+j$，电容贡献 $-j$，两者落在同一根虚轴的上下两端。

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $Z$ | 阻抗 | $\Omega$ |
| $Y$ | 导纳 | S（西门子） |
| $R$ | 阻抗的实部，就是纯电阻 | $\Omega$ |
| $X$ | 阻抗的虚部，叫电抗 | $\Omega$ |
| $G$ | 导纳的实部，叫电导 | S |
| $B$ | 导纳的虚部，叫电纳 | S |
| $\omega$ | 角频率，$\omega=2\pi f$ | rad/s |
| $\varphi$ | 阻抗的幅角，即电压与电流的相位差 | ° |

::: warning 中文术语提醒
导纳的虚部 $B$ 叫电纳，不是电抗；电抗是 $X$。两个名字只差一个字，指的却是互为倒数的两个量，读题时看清是 $X$ 还是 $B$。
:::

## 三个元件，三条相位

| 元件 | 阻抗 | 大小 | 相位 |
| --- | --- | --- | --- |
| $R$ | $R$ | $R$ | 同相 |
| $L$ | $j\omega L$ | $X_L = \omega L$ | 电压超前 90° |
| $C$ | $\dfrac{1}{j\omega C} = -\dfrac{j}{\omega C}$ | $X_C = \dfrac{1}{\omega C}$ | 电流超前 90° |

两个 90° 一来一去，方向正好相反。这就是电感与电容能互相抵消的全部来历。

90° 这个数要背成条件反射：电感的电压超前电流 90°，电容的电流超前电压 90°；倒过来讲也成立，电感电流滞后电压 90°，电容电压滞后电流 90°。

## 串联就相加，然后看谁大

串联电路里电流相同，各元件的阻抗直接相加：

$$
Z = R + j(X_L - X_C),\quad |Z| = \sqrt{R^2+X^2},\quad \varphi = \arctan\frac{X_L-X_C}{R}
$$

于是判断电路性质只剩比大小这一件事：

- $X_L > X_C$，感性，电流滞后电压
- $X_L < X_C$，容性，电流超前电压
- $X_L = X_C$，阻性，就是谐振，$Z = R$ 最小

::: tip 一句口诀
电感在「上」，电流滞后；电容在「下」，电流超前。记不住的时候就写一遍 $+j\omega L$，正号在上方。
:::

## 直流下退化成什么

当 $\omega=0$（直流）时：

- 电感：$Z_L = j\omega L = 0$，短路，电压为零而电流可以任意大
- 电容：$Z_C = \dfrac{1}{j\omega C} \to \infty$，开路，电流为零

这两条不是特例规定，是从公式里自然掉出来的。直流下电感里的电流不随时间变，导数为 0，所以没有电压；电容两端电压不变，所以没有电流。

## 五处最常翻车

1. 把阻抗当电阻，用 $|Z|$ 直接当阻值算功率。阻抗是复数，实部 $R$ 才耗能，$P = I^2R$ 用的是它。
2. 说成「电容的电压超前 90°」。整个三角形方向全反。电容是电流超前电压 90°，等价说法是电容电压滞后 90°。
3. 用电阻的直觉理解电抗，以为电流被挡住变小了。电抗不改电流的大小，只改相位。
4. 直流下还往电抗公式里代，算出除零。直流直接用「电感短路、电容开路」这两句。
5. 以为 $X_C$ 随频率升高而变大。$X_C = 1/(\omega C)$ 随频率升高而变小；$X_L = \omega L$ 随频率升高而变大，两者刚好相反。

## 例题

::: tip 例 1 · 串联 RLC 的总阻抗
题目：$R = 6\ \Omega$、$L = 44.6\ \text{mH}$、$C = 530\ \mu\text{F}$ 串联，接在 $220\ \text{V}$、$50\ \text{Hz}$ 电源上。求总阻抗、电流有效值，并判断电路性质。

先想什么：串联电路电流相同，三个阻抗直接相加，先算两个电抗再合成。

步骤：

1. 角频率：$\omega = 2\pi f = 2\pi\times50 = 314\ \text{rad/s}$。*（为什么先算 $\omega$：两个电抗的公式里都有它。）*
2. 感抗：$X_L = \omega L = 314\times44.6\times10^{-3} = 14\ \Omega$。
3. 容抗：$X_C = \dfrac{1}{\omega C} = \dfrac{1}{314\times530\times10^{-6}} = 6\ \Omega$。
4. 总阻抗：

$$
Z = 6 + j(14-6) = 6 + j8\ \Omega = 10\angle53.1^\circ\ \Omega
$$

*（为什么虚部是相减：电感的 $+j$ 向上、电容的 $-j$ 向下，在虚轴上互相抵消一部分。）*

5. 电流：$I = \dfrac{U}{|Z|} = \dfrac{220}{10} = 22\ \text{A}$，相位上滞后电压 $53.1^\circ$。

验算，用几何法独立算一遍：$\sqrt{6^2+8^2}=\sqrt{100}=10\ \Omega$ ✓；$\arctan(8/6)=53.1^\circ$ ✓。再验相位性质：$X_L=14 > X_C=6$，电抗为正，所以感性，电流滞后 ✓，与 $53.1^\circ$ 为正一致。

注意：$X_L>X_C$，所以是感性电路；若换成 $C=1060\ \mu\text{F}$，则 $X_C=3\ \Omega$，$X=11$，阻抗变大、电流变小。频率再往高处走，电抗差的走向还会反过来。
:::
