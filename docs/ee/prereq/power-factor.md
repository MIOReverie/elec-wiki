# 功率因数 cosφ

$$
P = UI\cos\varphi \quad[\text{W}]
\qquad
Q = UI\sin\varphi \quad[\text{var}]
\qquad
S = UI \quad[\text{VA}]
$$

$$
S^2 = P^2 + Q^2 \qquad \cos\varphi = \frac{P}{S}
$$

三种功率的物理意义：

- **有功 $P$**：真正消耗掉的（做功、发热）
- **无功 $Q$**：在电源与储能元件之间来回交换的（建立磁场/电场必需）
- **视在 $S$**：电源需要提供的容量（设备铭牌、变压器容量按 $S$ 标）

为什么要提高 $\cos\varphi$：$P$ 一定时，$\cos\varphi$ 越低 → $I = P/(U\cos\varphi)$ 越大 → 线路损耗 $I^2R$ 越大、压降越大、设备容量被浪费。
