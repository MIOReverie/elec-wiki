# 触发器

触发器是**具有记忆功能**的基本单元，输出不仅取决于输入，还取决于**原来的状态** $Q^n$。

**D 触发器**（最常用，边沿触发）：

$$
Q^{n+1} = D \quad(\text{时钟上升沿/下降沿到来时})
$$

**JK 触发器**（功能最全）：

$$
Q^{n+1} = J\bar Q^n + \bar K Q^n
$$

- $J=K=0$：保持；$J=K=1$：翻转（计数）
- $J=1,K=0$：置 1；$J=0,K=1$：置 0

概念区分：

- **同步**触发器：时钟到来才动作
- **异步**置位/复位端（$\bar R_D$、$\bar S_D$）：不受时钟约束，优先级最高
