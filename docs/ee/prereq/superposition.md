# 叠加定理

<Meta time="4 min" level="卡片" note="能叠加的只有电压和电流；功率是二次量，一叠加就错" />

在线性电路里，几个独立源共同产生的某条支路电流，等于把其余电源一个个关掉、每次只留一个时，该支路电流的代数和。

一条支路、两个电源的题，用叠加往往比列方程更快。但这条定理有两个前提，漏掉哪个都会算错。

## 加法成立的前提

日常说法是「几个力一起作用，效果等于各自效果相加」。力学里叫合力，电路里叫叠加。它有个前提常被忽略：系统必须是线性的。推力加倍、位移也加倍，才谈得上相加。

正式定义：若电路的每个响应（某支路电压或电流）与各独立源之间满足线性关系，则

$$
\text{响应} = \sum_{k} \text{（只留第 } k \text{ 个独立源时的响应）}
$$

这里的代数和不是绝对值相加，而是按参考方向带正负号相加：算出的某个分量为负，就带着负号参与求和。

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| 独立源 | 电压源 $E$、电流源 $I_S$，其值不受电路其它部分影响 | 受控源不属于此类 |
| 响应 | 待求的支路电压或电流 | 只能是被求的 $U$、$I$ |
| 代数和 | 带符号求和 | 符号跟着参考方向走 |

## 关掉一个电源，具体做什么

让某个独立源不作用，就是让它的输出变成零。零值在电路里的表现分别是：

- 不作用的电压源变成短路（$U = 0$ 就是一根导线）；
- 不作用的电流源变成开路（$I = 0$ 就是断开）；
- 受控源必须保留，不能置零。它属于「跟着别处的量走」的元件，不是激励源，关掉它等于改了电路的结构。

<CircuitFig kind="superpose" title="把两个电源拆成两张图分别算，再相加" note="左：只留电压源，电流源断开。中：只留电流源，电压源短接成导线。右：把两次的结果按参考方向相加。三张图的电阻连接方式完全没变，变的只是哪个电源在起作用。" />

拿一个具体电路走一遍。结点 a 上接三条路：$R_1 = 2\ \Omega$ 通向 $E = 12$ V，$R_2 = 4\ \Omega$ 通向地，另有一个 $I_S = 2$ A 的电流源注入 a。求 $V_a$。

1. 只留 $E$（$I_S$ 开路）：$R_1$、$R_2$ 串联分压，$V_a' = 12\times\dfrac{4}{2+4} = 8$ V。
2. 只留 $I_S$（$E$ 短接）：$R_1 \parallel R_2 = \dfrac{2\times4}{6} = 1.333\ \Omega$，$V_a'' = 2\times1.333 = 2.667$ V。
3. 相加：$V_a = 8 + 2.667 = 10.667$ V。

用结点法一次算完验算：$\dfrac{V_a - 12}{2} + \dfrac{V_a}{4} = 2$，解得 $V_a = 10.667$ V ✓。

::: warning 常见误解：把功率也叠加
同一个例子里，$R_2$ 上的功率：

- 只留 $E$ 时 $8^2/4 = 16$ W；
- 只留 $I_S$ 时 $2.667^2/4 = 1.78$ W；
- 两者相加 $17.78$ W。

而真实值是 $10.667^2/4 = 28.44$ W。差了 10.7 W，正好是交叉项：$P = I^2R = (I_1+I_2)^2R = I_1^2R + I_2^2R + 2I_1I_2R$，最后那一项不属于任何一个「单独作用」。

所以功率不能叠加，只能先用叠加求出总电压或总电流，再回头算功率。
:::

::: tip 为什么容易错
电压、电流、功率都是「响应的样子」，看上去是同一类东西。区别在次数：$U$、$I$ 与激励成一次关系，可以拆项相加；$P$ 是二次关系，拆开会出现交叉项。判断标准很干脆：式子里有没有平方，或者两个量相乘。
:::

::: warning 还有两个常踩的
- 受控源置零。一置零，电路的放大关系就没了，结果与真值不符。受控源永远按原样保留。
- 以为叠加对非线性电路也成立。二极管、饱和铁芯这些元件不满足线性，叠加定理直接失效。
:::

## 什么时候用得上

两个以上独立源、又只问某一条支路的量，叠加常常是最省事的路。它也是推导戴维南定理的基础，用来解释为什么可以把复杂电路拆成几个简单电路。
