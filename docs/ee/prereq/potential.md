# 电位与参考点

**电位**是某点相对参考点的电压；**电压**是两点电位之差。

$$
V_a = U_{a0} \quad(\text{0 为参考点}) \qquad U_{ab} = V_a - V_b
$$

关键性质：

- 换参考点，**所有点的电位都变**，但**任意两点间的电压不变**
- 参考点电位规定为 0，通常选电源负极或电路的公共端（"地"）
- 电子电路中常把"地"作为参考点，于是可以只写 $V_a$ 而不写 $U_{a0}$

::: tip 计算技巧
求某点电位：从该点出发沿任意路径"走"到参考点，把路上所有电压降代数相加即可。
:::
