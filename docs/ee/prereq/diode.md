# 二极管单向导电

- **正向偏置** → 导通，硅管压降约 **0.7V**（锗管 0.3V），工程上常近似为 0.7V 恒压降或理想短路
- **反向偏置** → 截止，电流近似为 0（有微小漏电流）
- 反向电压超过 $U_{BR}$ → **反向击穿**（稳压二极管反而是利用这一点）

整流应用：

| 电路 | $U_{dc}$ | 说明 |
| --- | --- | --- |
| 半波 | $0.45U_2$ | 只用一个二极管，纹波大 |
| 桥式全波 | $0.9U_2$ | 四个二极管，最常用 |
| 全波 + 电容滤波 | 接近 $U_m$，随负载变化 | $RC \gg T/2$ 才平滑 |

（$U_2$ 为变压器副边**有效值**）
