# 二极管单向导电

<Meta time="5 min" level="卡片" note="0.7 V 是硅管的「门槛」，不是固定损耗；整流输出电压算的是平均值，不是有效值，也不是峰值" />

一句话结论：**二极管只让电流朝一个方向走；硅管一旦导通，电压被抬到约 0.7 V 左右；用它做整流时，输出的是**平均值**，所以半波约 $0.45U_2$、桥式约 $0.9U_2$（$U_2$ 为副边有效值）。**

## 日常说法与正式定义

- 日常说法：二极管像一只「单向阀」——水只能从一边流到另一边，回头会被堵住。电路里常用它把交流「掰」成只朝一个方向的那一半。
- 正式定义：二极管是**非线性**器件，伏安特性不满足 $u=Ri$（阻值不是常数）。它工作在两个状态：
  - **正向偏置**（阳极电位高于阴极）→ **导通**，硅管压降约 **0.7 V**（锗管 0.3 V）；工程上常近似为「0.7 V 恒压降」或极端点「理想短路」；
  - **反向偏置**（阳极电位低于阴极）→ **截止**，电流近似为 0（只有很小的漏电流）。

**符号逐个读**：

| 符号 | 含义 |
| --- | --- |
| $U_{BR}$ | 反向击穿电压（breakdown voltage），反向电压超过它就击穿 |
| $U_2$ | 变压器副边电压的**有效值** |
| $U_m$ | 副边电压的**幅值**（峰值），$U_m=\sqrt2 U_2$ |
| $U_{dc}$ | 整流输出电压的**平均值** |
| 硅管 / 锗管 | 半导体材料不同，导通压降不同 |

::: tip 0.7 V 到底是什么
它不是「损耗」，是**导通门槛**——PN 结内部要建立起让多数载流子大量通过的电场，需要这么点电压。所以工程上把硅二极管近似成一个「0.7 V 的电池加一只开关」。压降随电流增大而略增，锗管只有 0.3 V 左右。
:::

## 反向击穿与稳压二极管

反向电压超过 $U_{BR}$ 后，**反向击穿**：电流急剧增大而电压几乎不变。稳压二极管（齐纳二极管）**故意**工作在击穿区，利用「电压被钉住」这一特性做稳压；普通二极管到了 $U_{BR}$ 就可能损坏。

## 整流应用

| 电路 | $U_{dc}$ | 说明 |
| --- | --- | --- |
| 半波 | $0.45U_2$ | 只用一个二极管，纹波大 |
| 桥式全波 | $0.9U_2$ | 四个二极管，最常用 |
| 全波 + 电容滤波 | 接近 $U_m$，随负载变化 | $RC \gg T/2$ 才平滑 |

（$U_2$ 为变压器副边**有效值**）

**这三个数为什么是这个数**：$0.45U_2$ 与 $0.9U_2$ 都是**平均值**。半波整流的平均值是 $\dfrac{1}{2\pi}\int_0^\pi U_m\sin\theta\,d\theta = \dfrac{U_m}{\pi} \approx 0.318U_m = 0.45U_2$；桥式把两个半波都留下来，平均值翻倍成 $0.636U_m \approx 0.9U_2$。

<CircuitFig kind="bridge-rectifier" title="桥式整流：交流进、直流出" note="正半周电流走 D₁、D₃，负半周走 D₂、D₄；无论输入正负，流过负载的电流方向始终一样，这就是「整流」二字的意思。" />

## 常见误解

1. **把整流输出当成有效值** → 算出 12 V 的直流，实际只有约 5.4 V（半波）→ 整流输出是**平均值**；若后面接的是发热负载，才用有效值算热。
2. **用峰值 $U_m$ 去比 $0.9U_2$** → 数值对不上 → $U_m=\sqrt2 U_2$，两者差 1.414 倍。
3. **以为二极管是理想开关** → 算出的电压偏高 0.7 V → 硅管导通压降必须算进去，尤其在小信号或低压场合。
4. **以为反向偏置就绝对安全** → 反压超过 $U_{BR}$ 就击穿 → 选二极管时要看**最大反向工作电压**。
5. **滤波后输出就恒等于 $U_m$** → 空载时才接近 → 带载后电容会放电，输出随负载下降。

## 例题

::: tip 例 1 · 桥式整流的输出电压
**题目**：变压器副边有效值 $U_2 = 12\ \text{V}$，频率 50 Hz。用桥式整流加电容滤波，估算输出直流电压（空载）并选出滤波电容的量级。

**先想什么**：先分清三个数：副边有效值 12 V、峰值 $U_m$、整流平均电压。滤波电容的取值要用**周期**，不是用平均值。

**步骤**：

1. 副边峰值：$U_m = \sqrt2\times12 = 17.0\ \text{V}$。*（为什么先算峰值：电容充到的是峰值。）*
2. 桥式整流（不带滤波）的平均输出：$U_{dc} \approx 0.9U_2 = 10.8\ \text{V}$。
3. **加电容滤波后**，输出被充到接近峰值（工程上按 $U_{dc}\approx1.2U_2$ 估）：

$$
U_{dc} \approx 1.2\times12 = 14.4\ \text{V}
$$

4. 周期：$T = 1/f = 1/50 = 20\ \text{ms}$；整流后纹波频率加倍，$T_r = 10\ \text{ms}$。若负载电流取 100 mA，要求纹波峰峰不超过 0.5 V，则

$$
C \geq \frac{I}{f_r\Delta U} = \frac{0.1}{100\times0.5} = 2000\ \mu\text{F}
$$

取标准值 **2200 µF / 25 V**（耐压要高于 14.4 V，留余量）。

**验算**：$U_{dc}=14.4$ V 与峰值 17.0 V 之间差 2.6 V，这就是电容充不到峰值的原因（充电时间不够 + 二极管压降）——数量级合理 ✓。若误把 $U_2$ 当峰值用，$C$ 的估算会差 1.414 倍。

**注意**：桥式整流里每半周有两只二极管同时导通，所以导通压降是 $2\times0.7=1.4$ V，不是 0.7 V——上面的 17.0 V 减 1.4 V 得 15.6 V，与 14.4 V 同量级 ✓。
:::
