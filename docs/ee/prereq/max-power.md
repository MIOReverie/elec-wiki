# 最大功率传输

<Meta time="5 min" level="卡片" note="匹配点上效率恰好 50%：负载拿到的功率和白白耗在源内阻上的功率一样多，这就是「最大功率」与「最高效率」不能兼得的根源" />

「阻抗匹配是为了效率最高」，这句话把两件事说反了。匹配点上负载拿到的功率最大，效率却恰好卡在一半。

所以老工程师会先反问一句：你要的是功率，还是要效率。

## 条件与最大值

负载 $R_L$ 从含源二端网络获得最大功率的条件，是阻抗匹配：

$$
R_L = R_{eq} \qquad P_{max} = \frac{U_{OC}^2}{4R_{eq}}
$$

其中 $U_{OC}$ 是含源网络的开路电压，$R_{eq}$ 是它的戴维南等效电阻（把独立源置零后从端口看进去的电阻）。一句话版本：$R_L = R_{eq}$ 时 $P_{max} = U_{OC}^2/(4R_{eq})$，效率 50%。

| 符号 | 含义 |
| --- | --- |
| $R_L$ | 负载电阻 |
| $R_{eq}$ | 含源网络的等效内阻（戴维南电阻） |
| $U_{OC}$ | 开路电压（把负载拿掉，两端的电压） |
| $\eta$ | 效率，负载得到的功率占电源发出的功率的比例 |

日常那句话说得很贴切：手电筒的电池和灯泡要配套。电池内阻太大，灯泡不亮；内阻太小，电池自己发热。总有一个刚刚好的搭配。

## 效率为什么只有一半

匹配点上 $R_L = R_{eq}$，流过内阻的电流和流过负载的电流一样大，于是内阻损耗和负载得到的功率相等：

$$
P_L = I^2R_L = I^2R_{eq} = P_{内阻}
$$

$$
\eta = \frac{P_L}{P_L + P_{内阻}} = \frac{1}{2} = 50\%
$$

最大功率和最高效率不可兼得，这句话值得抄在书皮上。匹配点的效率 50% 是个死数，只要 $R_L = R_{eq}$ 就绕不过去。

## 两种场景，两种选法

| 场景 | 目标 | 做法 |
| --- | --- | --- |
| 电力系统（输电、变压器） | 效率高、发热少 | $R_L \gg R_{eq}$，几乎不匹配 |
| 信号/通信电路（天线、功放输出） | 从源取到的功率最大 | $R_L = R_{eq}$，做阻抗匹配 |

电力系统不匹配，是因为输电线本身有电阻。电流一变大，$I^2R$ 的损耗跟着涨，宁可少取一点功率也要把线路损耗压下去。高压输电的道理也在这里：它要的不是送更多电，是送同样的电时让电流更小。

信号电路要匹配，是因为发射机功放输出级本来效率就不高，它的任务是把有限的射频功率尽可能塞进天线，天线就是负载。这时 $R_L=R_{eq}$ 的含义是不浪费信号。

## 交流里要共轭匹配

到了交流电路，条件升级成共轭匹配：

$$
Z_L = Z_{eq}^* \qquad \text{即} \qquad R_L = R_{eq}\ \text{且}\ X_L = -X_{eq}
$$

$Z^*$ 读作 $Z$ 的共轭复数：实部不变、虚部变号。直观理解是负载的电抗要抵消源的漏抗，否则电流被拉偏，功率反而上不去。

## 五个误区

1. 以为最大功率总是好事，把电源配到 50% 效率。先问一句：这是输电还是送信号？
2. 以为匹配点也是效率最高点，算效率时套错公式。匹配时效率恰好 50%，效率最高在 $R_L \to \infty$。
3. 把 $U_{OC}$ 当成带载时的电压，最大功率算错。$U_{OC}$ 是开路电压，带载后端电压只有它的一半。
4. 交流里只匹配电阻部分。虚部不抵消，电流被漏抗拉偏，功率上不去。
5. 以为戴维南等效电阻 $R_{eq}$ 就是电源内阻。网络里还有别的元件时，$R_{eq}$ 要把独立源置零后从端口看进去。

## 例题

::: tip 例 1 · 求最大负载功率
题目：某含源二端网络的开路电压 $U_{OC}=12\ \text{V}$，戴维南等效电阻 $R_{eq}=3\ \Omega$。接一个可调负载 $R_L$，求：(a) $R_L$ 取何值时负载功率最大？(b) 最大功率是多少？(c) 此时效率是多少？

先想什么：三个问号其实是同一个式子的三层，所以先把 $P_L$ 写成 $R_L$ 的函数。

步骤：

1. 电流：$I = \dfrac{U_{OC}}{R_{eq}+R_L}$。
2. 负载功率：

$$
P_L = I^2R_L = \frac{U_{OC}^2R_L}{(R_{eq}+R_L)^2} = \frac{144\,R_L}{(3+R_L)^2}
$$

*（为什么先写成函数：要找的是「$R_L$ 取多少时这个函数最大」，不是背下来的那个结论。）*

3. 求极大值：对 $R_L$ 求导并令导数为零，得 $R_L = R_{eq} = 3\ \Omega$。*（也可以用均值不等式：把 $P_L$ 改写成 $P_L = \dfrac{U_{OC}^2}{R_{eq}^2/R_L + 2R_{eq} + R_L}$，分母里 $R_{eq}^2/R_L$ 与 $R_L$ 之和 $\ge 2R_{eq}$，等号在 $R_L=R_{eq}$ 时成立，所以分母最小、功率最大。）*
4. 最大功率：

$$
P_{max} = \frac{U_{OC}^2}{4R_{eq}} = \frac{144}{12} = 12\ \text{W}
$$

*（为什么分母是 4：$R_{eq}=R_L=3$ 时 $I = 12/6 = 2\ \text{A}$，$P_L = 2^2\times3 = 12\ \text{W}$。）*

5. 效率：$\eta = \dfrac{R_L}{R_{eq}+R_L} = \dfrac{3}{6} = 50\%$。

验算，换个负载试试：取 $R_L = 6\ \Omega$，$I = 12/9 = 1.333\ \text{A}$，$P_L = 1.333^2\times6 = 10.67\ \text{W}$ < 12 W ✓（偏离匹配点，功率下降）。取 $R_L = 1.5\ \Omega$，$I = 12/4.5 = 2.667\ \text{A}$，$P_L = 2.667^2\times1.5 = 10.67\ \text{W}$ < 12 W ✓（对称地下降，说明匹配点确实是极大值）。

注意：功率曲线关于 $R_L=R_{eq}$ 对称，$R_L=1.5$ 与 $R_L=6$ 给出同一个 10.67 W。估算时很好用：负载偏离匹配点多少，功率就掉多少。
:::
