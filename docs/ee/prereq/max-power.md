# 最大功率传输

负载 $R_L$ 从含源网络获得最大功率的条件（**阻抗匹配**）：

$$
R_L = R_{eq} \qquad P_{max} = \frac{U_{OC}^2}{4R_{eq}}
$$

注意：

- 此时**效率只有 50%**（一半功率耗在内阻上）
- 电力系统追求高效率，绝不会工作在匹配点（$R_L \gg R_{eq}$）
- 信号/通信电路追求最大功率传输，才做阻抗匹配

交流推广（共轭匹配）：$Z_L = Z_{eq}^*$，即 $R_L = R_{eq}$ 且 $X_L = -X_{eq}$。
