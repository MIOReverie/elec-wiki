# 星形 ⇄ 三角形变换

<Meta time="5 min" level="卡片" note="两组公式方向别用反；Y 臂与端子一一对应，配错端子就全错" />

**星形（Y）和三角形（△）是同一个三端网络的两种画法，用一组公式可以互换——它的用处只有一个：把既非串联也非并联的电路，改造成能串并联合并的样子。**

## 日常说法与正式定义

日常说法：「三个电阻围成一圈，叫三角形；三个电阻从一个中心点散出三条，叫星形。」电路图上这两种画法长得完全不一样，可只要三个端子对外的行为一致，工程师就有权换着用。

正式定义：**三端网络**指只有三个出线端子的电阻网络。三个电阻首尾相接成环、从三个接点引出端子，就是三角形；三个电阻一端共点（中性点）、另一端各引出一个端子，就是星形。

符号要按端子对齐，这是这一页最容易出错的地方：

| 符号 | 含义 | 对应关系 |
| --- | --- | --- |
| $R_1, R_2, R_3$ | 星形的三条臂 | $R_1$ 连端子 1，$R_2$ 连端子 2，$R_3$ 连端子 3 |
| $R_{12}, R_{23}, R_{31}$ | 三角形的三条边 | $R_{12}$ 接在端子 1 与 2 之间，其余同理 |
| 对面 | 与某条边不相连的那条星臂 | $R_{12}$ 的对面是 $R_3$ |

**Y → △**（记：每个 △ 边 = 两两积之和 ÷ 对面的 Y 臂）：

$$
R_{12} = R_1 + R_2 + \frac{R_1R_2}{R_3} \quad(\text{其余同理})
$$

**△ → Y**（记：每个 Y 臂 = 相邻两 △ 边之积 ÷ 三边之和）：

$$
R_1 = \frac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}}
$$

**对称特例**（三臂相等，最常考）：

$$
R_\triangle = 3R_Y \qquad R_Y = \frac{1}{3}R_\triangle
$$

对称特例值得单独记：三条臂一样时，Y→△ 就是把每条乘 3。验算一遍：$R_Y = 3\ \Omega$ 代入通式，$R_{12} = 3+3+\dfrac{3\times3}{3} = 9 = 3R_Y$ ✓。

## 换算一次，再验算一次

拿不对称的一组数走一遍，验证「对外真的等效」。取 $\triangle$ 三边 $R_{12} = 3$、$R_{23} = 6$、$R_{31} = 9\ \Omega$，三边之和 18 Ω：

$$
R_1 = \frac{3\times9}{18} = 1.5\ \Omega \quad R_2 = \frac{3\times6}{18} = 1\ \Omega \quad R_3 = \frac{6\times9}{18} = 3\ \Omega
$$

验算只需量一个端口：端子 1 与 2 之间的电阻。

- 三角形：$R_{12}$ 与「$R_{23}+R_{31}$」并联，$\dfrac{3\times15}{18} = 2.5\ \Omega$。
- 星形：$R_1$ 与 $R_2$ 串联（$R_3$ 悬空不起作用），$1.5+1 = 2.5\ \Omega$ ✓。

两边一样，所以从端子看进去确实分不出用的是哪一种画法。

::: warning 常见误解一：两组公式用反
判别方法有两个，都不用背公式：

- **数量级**：Y→△ 结果一定比原来的臂**大**（对称时正好 3 倍），△→Y 结果一定**小**。算出「△ 变 Y 之后电阻变大」就知道反了。
- **端子对应**：$R_{12}$ 的对面是 $R_3$（唯一不接端子 1、2 的臂）。把「对面」认错，公式再对结果也错。
:::

::: warning 常见误解二：把对称特例当成万能
$R_\triangle = 3R_Y$ 只在**三条臂完全相等**时成立。电桥、三相负载不对称时用它，误差可以达到几倍。只有三臂相等（或题目明说对称）才准用。
:::

::: warning 常见误解三：以为变换后电路内部也等效
和电源等效变换一样，Y-△ 变换只保证**三个端子对外**的电压电流关系不变。变换后各电阻里的电流、各电阻上的功率都与原来不同，要算这些量就得变回原电路。
:::

**为什么容易错**：因为两组公式长得像——都是「乘积除以和」的形状，只差分子是一个积还是「两两积之和」。真正记住它们的办法不是背，而是抓住一句：**Y 只有一个中心点，所以换到 △ 时每条边都要多背一个「对面的臂」；△ 有一个环，所以换到 Y 时每个臂都要除以三边之和。**

## 什么时候用得上

正文里遇到电桥这类既非串联也非并联的网络时，先看能不能用 Y-△ 变换化成串并联；三相电路里负载的 Y 与 △ 互换、以及对称分量法，用的也是同一组公式。
