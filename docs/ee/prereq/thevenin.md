# 戴维南 / 诺顿定理

任何**含源线性二端网络**，对外都可以等效成：

- **戴维南**：电压源 $U_{OC}$ 串联 $R_{eq}$
- **诺顿**：电流源 $I_{SC}$ 并联 $R_{eq}$
- 两者关系：$U_{OC} = I_{SC}R_{eq}$

求法三步：

1. **$U_{OC}$**：断开待求支路，求端口开路电压
2. **$R_{eq}$**：独立源置零（电压源短路、电流源开路），求端口等效电阻；含受控源时用**外加电源法** $R_{eq} = U/I$
3. 接回待求支路求解

::: warning 最常踩的坑
受控源**不能**像独立源那样置零求 $R_{eq}$！必须用外加电源法或 $R_{eq} = U_{OC}/I_{SC}$。
:::
