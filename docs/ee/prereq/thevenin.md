# 戴维南 / 诺顿定理

<Meta time="4 min" level="卡片" note="等效只对端口之外成立；含受控源时不能把源置零求电阻" />

**任何含源的线性二端网络，对外电路的行为都等价于「一个电压源 $U_{OC}$ 串一个电阻 $R_{eq}$」——于是求某一条支路的问题，可以先把其余部分压缩成一块电池。**

## 日常说法与正式定义

日常说法：「墙上的插座里到底有什么，你不必知道。它对外只表现成两件事——空载时是 220 V，带载时会掉一点。」这两句话恰好就是戴维南等效的两个参数。

正式定义：对任意一个**含源线性二端网络**（两个出线端子，内部有电源和线性元件），它的端口伏安特性是一条直线

$$
U = U_{OC} - I R_{eq}
$$

其中 $U_{OC}$ 是端口**开路**时的电压，$R_{eq}$ 是端口看进去的等效电阻。既然是一条直线，就只需要两个数就能定死——这就是为什么「一个电压源串一个电阻」足够描述它。

两种等价模型与符号：

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $U_{OC}$ | 开路电压（open-circuit voltage），端口断开时量到的电压 | V |
| $I_{SC}$ | 短路电流（short-circuit current），端口短接时流过的电流 | A |
| $R_{eq}$ | 端口等效电阻 | Ω |
| 戴维南模型 | 电压源 $U_{OC}$ 串联 $R_{eq}$ | — |
| 诺顿模型 | 电流源 $I_{SC}$ 并联 $R_{eq}$ | — |

两者关系：$U_{OC} = I_{SC}R_{eq}$。求出一个，另一个就出来了。

## 三步求法

1. **求 $U_{OC}$**：把待求支路断开，算端口上的开路电压。
2. **求 $R_{eq}$**：把所有**独立源**置零（电压源短路、电流源开路），从端口看进去求等效电阻；**含受控源时改用外加电源法** $R_{eq} = U/I$（在端口加一个测试电压，量流入的电流）。
3. **接回待求支路**，用这个「电池 + 内阻」算出答案。

拿一个分压器走一遍：$E = 12$ V 经 $R_1 = 6\ \text{k}\Omega$ 与 $R_2 = 3\ \text{k}\Omega$ 分压，从 $R_2$ 两端取输出，接 $R_L = 2\ \text{k}\Omega$。

- 断开 $R_L$：$U_{OC} = 12\times\dfrac{3}{6+3} = 4$ V。
- 置零 $E$（短路）：从输出端看，$R_1$ 与 $R_2$ 并联，$R_{eq} = \dfrac{6\times3}{9} = 2\ \text{k}\Omega$。
- 接回负载：$U_L = 4\times\dfrac{2}{2+2} = 2$ V。

验算：$I_{SC} = U_{OC}/R_{eq} = 4/2000 = 2$ mA，回代 $U_{OC} = I_{SC}R_{eq} = 2\times10^{-3}\times2000 = 4$ V ✓。

::: warning 常见误解：把受控源也一起置零
受控源不是激励，它的大小由电路别处的电压或电流决定。把它置零，等于删掉了电路的一条约束，$R_{eq}$ 必然算错。含受控源时，正确做法只有两条：**外加电源法** $R_{eq} = U/I$，或**开路短路法** $R_{eq} = U_{OC}/I_{SC}$。
:::

::: warning 还有三个高频错法
- **$R_{eq}$ 里把负载也算进去**：负载是被切出去的那一半，绝不能进等效电阻。
- **把某个元件上的电压当成 $U_{OC}$**：$U_{OC}$ 是**端口两端**的电压，端口断开后电路可能已经变了，要重算。
- **以为等效对内部也成立**：和电源等效变换一样，戴维南只保证端口电压电流一致；内部功率、内部电流全都不等效。
:::

**为什么这一步容易错**：因为「把一整块电路换成一个电源」听起来像魔法，容易忘记它只承诺端口上的那一条伏安特性。另外第 2 步的动作（置零）和第 1 步的动作（断开）方向相反，手一忙就容易把两步的电路画混。

## 什么时候用得上

正文里凡是「电路很大、但只要算其中一条支路」的题，第一步就该想戴维南：把其余部分压成一个源加一个电阻，剩下的是一阶方程。最大功率传输那一节也全靠它——负载拿到最大功率的条件正是 $R_L = R_{eq}$。
