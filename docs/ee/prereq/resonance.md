# 串联谐振

<Meta time="5 min" level="卡片" note="谐振时电流最大，但电感和电容上的电压可能远大于电源电压" />

电源 10 V，线圈两端量到 31 V，第一反应是表坏了或者电路接错了。都没错，这是谐振。

串联谐振时，电感和电容上的电压会互相顶牛，各自都能高过电源。

## 条件：两个电抗打平

RLC 串联电路的感抗 $X_L = \omega L$（电感对交流的阻碍，单位 Ω）与容抗 $X_C = 1/(\omega C)$（电容的阻碍）大小相等时，电路发生串联谐振：

$$
\omega_0 = \frac{1}{\sqrt{LC}} \qquad f_0 = \frac{1}{2\pi\sqrt{LC}}
$$

$\omega_0$ 是谐振角频率，$f_0$ 是谐振频率；$L$ 是电感、$C$ 是电容，$\omega = 2\pi f$。

秋千那个比喻很贴切：推力与拉力大小一样、方向相反，正好抵消，秋千自己荡到最大幅度。这时推的人最省力，绳子却绷得比平时紧。

## 谐振时的三个特征

- $X = X_L - X_C = 0$，所以 $Z = R$ 最小，电流 $I = U/R$ 最大。
- 电压与电流同相，电路整体呈纯阻性。
- 电感和电容两端的电压 $U_L = U_C = QU$，可能远高于电源电压，所以又叫电压谐振。

## Q 与通频带

$$
Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{1}{R}\sqrt{\frac{L}{C}}
\qquad
BW = f_2 - f_1 = \frac{f_0}{Q}
$$

$Q$ 大，谐振曲线就尖，选择性好，但通频带窄。$BW$ 是通频带宽度，$f_1$、$f_2$ 是上下限频率。

## 三个误解

1. 以为谐振时电源电压等于电感上的电压。不相等。谐振时 $U_R = U$，而 $U_L = U_C = QU$，这两个大电压在电源回路里互相抵消掉了。
2. 以为谐振时功率最大。电流最大是对的，但有功功率 $P = I^2R$ 最大这件事只对串联 RLC 成立；并联谐振恰好相反，阻抗最大、电流最小。
3. 以为 Q 应当尽量大。Q 大则选择性好、通频带窄，收音机调台要它；但电力系统里有些场合反而要压低 Q，把带宽让出来。

## 例题

::: tip 例 1 · 求谐振频率与谐振时的电感电压
题目：$R = 10\ \Omega$、$L = 100\ \text{mH}$ 的电感线圈与 $C = 101.3\ \mu\text{F}$ 的电容串联，接在 $10\ \text{V}$、$50\ \text{Hz}$ 的电源上。求谐振频率、品质因数和谐振时电感上的电压。

先想什么：先确认电路就在谐振点上（$X_L$ 与 $X_C$ 接近相等），然后才用谐振的三个特征。*（先判断是否处在谐振，再套特征公式。）*

步骤：

1. 谐振频率：$f_0 = 1/(2\pi\sqrt{LC}) = 1/(2\pi\sqrt{0.1 \times 101.3\times10^{-6}}) \approx 50.0\ \text{Hz}$。*（为什么先算 $f_0$：要确认工作频率就在谐振点上，否则后面全错。）*
2. 品质因数：$Q = \omega_0 L/R = 2\pi \times 50 \times 0.1/10 = 3.14$。
3. 谐振时电流：$I = U/R = 10/10 = 1\ \text{A}$。
4. 电感电压：$U_L = Q U = 3.14 \times 10 = 31.4\ \text{V}$。

验算：直接算感抗 $X_L = \omega L = 31.4\ \Omega$、容抗 $X_C = 1/(\omega C) = 31.4\ \Omega$，两者相等 ✓，确实谐振。谐振时总电压 $\sqrt{U_R^2 + (U_L - U_C)^2} = \sqrt{10^2 + 0^2} = 10\ \text{V}$，与电源相符 ✓。

这道题最该带走的一句：电源只有 10 V，线圈两端却有 31.4 V，所以电感和电容的耐压必须按 31.4 V 以上选。
:::
