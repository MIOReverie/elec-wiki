# 换路定则

换路（开关动作）瞬间 $t = 0$：

$$
u_C(0_+) = u_C(0_-) \qquad i_L(0_+) = i_L(0_-)
$$

理由：电容电压、电感电流对应**储能**（$W_C = \tfrac12 Cu_C^2$、$W_L = \tfrac12 Li_L^2$），能量不能突变。

推论：

- 电容电压不能突变 → 换路瞬间电容可视为**电压源** $u_C(0_+)$
- 电感电流不能突变 → 换路瞬间电感可视为**电流源** $i_L(0_+)$
- **其它量（电阻电压/电流、电容电流、电感电压）都可以突变**

求初始值的步骤：先由换路前的稳态求 $u_C(0_-)$、$i_L(0_-)$（换路前电容开路、电感短路），再画 $t=0_+$ 的等效电路求其它量。
