# 变压器变比

<Meta time="4 min" level="卡片" note="升压必然降流；k² 变阻抗别写成 k；直流进变压器等于短路" />

**变压器用同一个铁芯里的交变磁通把能量从原边搬到副边，电压比等于匝数比——所以它升高电压的代价，一定是降低电流。**

## 日常说法与正式定义

日常说法：「小区门口那个变压器把 10 kV 降到 380 V」「手机充电头里也有个变压器，只是工作频率高、体积小」。这些说法对，但漏了一件关键的事：**变电压从不免费**。

正式定义：两个绕组套在同一个铁芯上，共用一个交变磁通 $\Phi$。原边匝数 $N_1$、副边匝数 $N_2$，则

$$
\frac{U_1}{U_2} \approx \frac{N_1}{N_2} = k \qquad \frac{I_1}{I_2} \approx \frac{1}{k} \qquad Z_{in} = k^2 Z_L
$$

符号说明：

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| $N_1$ / $N_2$ | 原边 / 副边匝数 | 无单位，只数圈数 |
| $k$ | 变比（turns ratio） | $k>1$ 降压，$k<1$ 升压 |
| $\Phi$ | 主磁通 | 穿过两个绕组的公共磁通，单位 Wb |
| $U_1$ / $U_2$ | 原边 / 副边电压 | 有效值 |
| $I_1$ / $I_2$ | 原边 / 副边电流 | 有效值 |
| $Z_{in}$ | 从原边看进去的输入阻抗 | 副边接 $Z_L$ 时折算过来 |

三条关系对应三个用途——**变电压、变电流、变阻抗**。第三条不是新现象，它是前两条合起来的结果：$Z_{in} = U_1/I_1 = (kU_2)/(I_2/k) = k^2(U_2/I_2) = k^2Z_L$。

## 原理：一个磁通，两个绕组

- **空载**：原边加 $u_1$ → 铁芯里产生交变磁通 $\Phi$ → 两个绕组都感应电动势 $e_1 = -N_1\,d\Phi/dt$、$e_2 = -N_2\,d\Phi/dt$。因为**同一个 $d\Phi/dt$**，所以 $U_1/U_2 = N_1/N_2$。
- **带载**：副边电流 $I_2$ 产生去磁磁动势，主磁通想变小；原边电流 $I_1$ 立刻增大来抵消，把磁通顶回原来的水平。磁通基本不变，于是 $I_1/I_2 \approx N_2/N_1$。

<CircuitFig kind="transformer-eq" title="变压器等效：一个铁芯，两个绕组" note="原边接电源、副边接负载，能量只通过磁通传递，两侧没有电的直接连接——这也是变压器能用来隔离的原因。变比只看匝数比，与导线粗细、铁芯大小无关（那些只决定它能过多大电流、多大功率）。" />

算一遍最常用的那组数：$N_1 = 1000$、$N_2 = 100$，则 $k = 10$；原边 220 V → 副边 $220/10 = 22$ V。

副边接 $Z_L = 8\ \Omega$：$I_2 = 22/8 = 2.75$ A，$I_1 = 2.75/10 = 0.275$ A。核对功率：$220\times0.275 = 60.5$ W，$22\times2.75 = 60.5$ W——两侧相等，这就是「变电压必变电流」的意思。

从原边看进去的阻抗：$Z_{in} = k^2Z_L = 100\times8 = 800\ \Omega$。原本 8 Ω 的负载，在变压器原边看起来像 800 Ω——这就是音响输出变压器「阻抗匹配」的做法。

::: warning 常见误解一：以为变压器能变功率
理想变压器两侧功率相等（$P_1 = P_2$），实际变压器还要扣掉铁损和铜损，副边拿到的一定更少。**升压 10 倍，电流就降到 1/10**，能量守恒一分不多。看到「升压变压器能省电」这类说法，直接按 $P = UI$ 核对一遍。
:::

::: warning 常见误解二：以为变压器能给直流变压
接直流时磁通恒定不变化，$d\Phi/dt = 0$，副边没有感应电动势；同时原边绕组只剩很小的电阻，电流只受它限制，很快就过热烧毁。**变压器只对交流有效**，这也是开关电源要先「逆变」再变压的原因。
:::

::: warning 常见误解三：$Z_{in}$ 写成 $k Z_L$
是 $k^2$，不是 $k$。因为电压放大 $k$ 倍、电流同时缩小 $k$ 倍，两个 $k$ 乘在一起。写错这一个平方，阻抗匹配整题偏一个数量级。
:::

**为什么容易错**：因为变比 $k$ 是乘法关系，用起来很顺手，容易被顺手推广到所有量上——功率乘 $k$、阻抗乘 $k$。真正的约束只有一条：**能量守恒**。凡是与能量有关的量（功率、阻抗折算），都要多问一句「两侧是否相等」。

## 什么时候用得上

正文里凡是出现「220 V 变成 12 V」「远距离输电为什么要先升压」「放大器输出为什么要匹配 8 Ω 喇叭」，都是先写变比三条关系再算；电机那一章的互感、折算也建立在同一组式子上。
