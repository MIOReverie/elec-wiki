# 电功率与电能

关联参考方向下：

$$
P = UI \quad[\text{W}] \qquad W = Pt \quad[\text{J}]
$$

- $P > 0$ → 元件**吸收**功率（负载）
- $P < 0$ → 元件**发出**功率（电源）
- 整个电路 **$\sum P = 0$**（功率守恒，可用来验算）

电阻恒吸收：$P = I^2R = \dfrac{U^2}{R} \ge 0$。

**额定值**：$U_N$、$I_N$、$P_N$ 是长期安全工作的上限，实际值可以低于它，超过就会烧毁。
