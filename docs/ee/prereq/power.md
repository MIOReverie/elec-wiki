# 电功率与电能

<Meta time="5 min" level="卡片" note="P 的正负只由参考方向决定，不表示功率有正负之分" />

算出 $P_E = -24$ W，有人把负号一划，写上 24 W，理由是「功率不能为负」。

功率当然可以为负号所修饰，它说明的是这个元件在往外送电。划掉负号，账就对不平了。

## 一个式子，两个信息

日常说法很直白：这个元件在吃电（吸收功率，做功发热），还是在送电（发出功率，比如电源）。

正式定义：元件在关联参考方向下的瞬时功率 $p = ui$，平均值就是有功功率 $P = UI$。$P$ 的单位是瓦特（W），$1\ \text{W} = 1\ \text{J}/\text{s}$；电能 $W = Pt$，单位焦耳（J）。

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $P$ | 有功功率 | W |
| $W$ | 电能 | J |
| $U$、$I$ | 电压、电流的有效值（交流时）或瞬时值（直流时） | V、A |

## 正负号只说明谁在吸收

在关联参考方向下，$P = UI$ 的正负就是全部信号，读它只需认两件事：
- $P > 0$，元件吸收功率，是负载。
- $P < 0$，元件发出功率，是电源。
- 整个电路 $\sum P = 0$：吸收的总和等于发出的总和，能量守恒。*（这条是验算利器，见下面的例 1。）*

电阻恒吸收功率：$P = I^2R = U^2/R \ge 0$，不可能为负，因为电流与电压的参考方向对它永远是关联的。

## 三个误解

1. 说「功率是负的，这个元件有问题」。电源算出来就是负的，它本来就发出功率。负号只反映谁在吸收、谁在发出。
2. 以为 $P = UI$ 对任何元件都一样。这条式子只适用于直流或纯电阻。交流下要用 $P = UI\cos\varphi$；电感、电容本身不消耗有功功率。
3. 以为实际功率可以超过额定功率一会儿。电阻类元件几乎不能超，超了就是温度失控。$U_N$、$I_N$、$P_N$ 是长期安全工作的上限，不是建议值。

## 例题

::: tip 例 1 · 用功率守恒验算一个串联回路
题目：$E = 12\ \text{V}$ 电源（内阻 $R_0 = 1\ \Omega$）带 $R = 5\ \Omega$ 的负载。求电流、负载功率，并用 $\sum P = 0$ 验算。

先想什么：这道题真正的考点是验算，不是求电流。先用欧姆定律算出电流和功率，再用功率守恒把整个电路的账对平。*（先定要验什么，比直接套公式省时间。）*

步骤：

1. 电流：$I = E/(R_0 + R) = 12/6 = 2\ \text{A}$。
2. 电源发出功率：$P_E = -EI = -12 \times 2 = -24\ \text{W}$（负号表示发出）。
3. 内阻消耗：$P_{R_0} = I^2 R_0 = 4 \times 1 = 4\ \text{W}$。
4. 负载消耗：$P_R = I^2R = 4 \times 5 = 20\ \text{W}$。

验算：$\sum P = -24 + 4 + 20 = 0$ ✓（发出的正好等于消耗的，能量没凭空消失也没凭空产生）。

顺带一个结论：24 W 里只有 20 W 到了负载，4 W 在电源内阻上变成了热。内阻越小，效率越高。
:::
