# 基尔霍夫电压定律 KVL

任一回路，任一时刻：

$$
\sum U = 0 \quad \Longleftrightarrow \quad \sum U_{升} = \sum U_{降}
$$

本质是**能量守恒**（电场力做功与路径无关）。同样与元件性质无关。

用法：先指定回路**绕行方向**，沿方向走——电位降低记 $+$，电位升高记 $-$，代数和为 0。

推广形式：**假想回路**——KVL 对任意闭合路径成立，不一定要有实际元件（常用于求开路电压）。
