# 基尔霍夫电压定律 KVL

<Meta time="5 min" level="卡片" note="绕行方向一旦选定，全程不能改；中途改方向等于给自己换了一套符号，方程必然自相矛盾" />

有人绕一个回路走一圈，把碰到的电压全按大小加起来，得到 24 V，愣在那里。回路走完应该回到原点，怎么会多出 24 V。

因为 KVL 加的是代数和，不是绝对值。正负号来自你选的绕行方向。

## 走一圈，回到原地

日常那句话说得很准：从某点出发绕一圈回到原地，高度必须回到原值，不可能凭空多出一截。电位就是这个高度。

任一回路、任一时刻，沿回路按选定方向走一周，各段电压的代数和为零：

$$
\sum U = 0 \quad \Longleftrightarrow \quad \sum U_{升} = \sum U_{降}
$$

本质是能量守恒，电场力做功与路径无关。同样与元件性质无关，电阻、电容、电源、非线性器件一视同仁。

| 符号 | 含义 |
| --- | --- |
| $U$ | 某一段元件两端的电压 |
| $U_{升}$、$U_{降}$ | 沿绕行方向走时的电位升、电位降 |
| 绕行方向 | 你自己选的行走方向，顺时针或逆时针都行 |

## 边走边记账

先任意指定一个绕行方向，顺时针逆时针都行，然后沿这个方向走：

- 经过电阻，从「+」走到「−」（顺着电流方向）：记 $+IR$，这是电位降
- 经过电阻，从「−」走到「+」：记 $-IR$，这是电位升
- 经过电源，从「−」走到「+」：记 $+E$，这是电位升
- 经过电源，从「+」走到「−」：记 $-E$，这是电位降

全程代数和为零：

$$
\sum U=0\qquad\text{例如}\qquad E-IR_1-IR_2-IR_3=0
$$

::: warning 唯一的纪律
绕行方向一旦选定，全程不要改。中途改方向等于给自己换了一套符号，同一条支路会出现两个相反的符号，方程必然自相矛盾。这和「参考方向全程不换」是同一条纪律的两种说法。
:::

## 两种列法，看题目挑

1. 全电压式：沿圈把每个元件的 $u$ 都写出来。串联回路一步到位。
2. 电位式：只写电源，用「电位升 = 电位降」把电阻项挪到另一边。多电源又要问各点电位时用它，因为串联分压可以直接写成电位差。

题目要「求各点电位」，第二种通常少写一半符号。

## 假想回路：开路电压就靠它

KVL 对任意闭合路径成立，不一定要有实际元件。两个点之间可以「假想」一条路径，把两端的电压写出来，这叫假想回路。求开路电压最常用：开路处电流为零，假想回路里补进一条支路也不影响结果。

## 五条要提防的

1. 中途改绕行方向。同一条支路出现两个相反的符号，方程自相矛盾。
2. 把「经过电源」一律记正。电源符号搞反，方程无解或解出负电流。记号只看方向：从「−」到「+」记 $+E$，从「+」到「−」记 $-E$。
3. 以为 KVL 必须有实际元件才能列，于是不会求开路电压。假想回路随时可用。
4. 以为 KVL 依赖元件性质，碰到电容电感就不敢用。它只依赖连接方式；带电抗的交流电路照样列 KVL，只是把 $u$ 换成相量 $\dot U$。
5. 沿回路把电压全按绝对值加起来，结果不为零。这是代数和，每一项都带正负。

## 例题

::: tip 例 1 · 单回路 KVL
题目：一个回路里，电源 $E = 12$ V 与三个电阻 $R_1=2\ \Omega$、$R_2=2\ \Omega$、$R_3=4\ \Omega$ 串联，电源与电阻串成一个圈。求回路电流 $I$ 与 $R_3$ 上的功率。

先想什么：只有一个回路、只有一条支路电流，列一条 KVL 就够。

步骤：

1. 定绕行方向：顺时针，设回路电流 $I$ 顺时针流动。
2. 沿方向逐段记账：从电源的「−」端出发，经电源从「−」到「+」，记 $+E$；经 $R_1$（顺着电流方向，从「+」到「−」），记 $-IR_1$；经 $R_2$ 记 $-IR_2$；经 $R_3$ 记 $-IR_3$；回到起点。
3. 列方程：

$$
E - IR_1 - IR_2 - IR_3 = 0
$$

4. 代入数值：

$$
12 - I(2+2+4) = 0 \;\Rightarrow\; I = \frac{12}{8} = 1.5\ \text{A}
$$

5. $R_3$ 的功率：$P_3 = I^2R_3 = 1.5^2\times4 = 9\ \text{W}$（电阻恒吸收功率）。

验算，用功率守恒：电源发出 $P_E = EI = 12\times1.5 = 18$ W；三个电阻吸收 $I^2(R_1+R_2+R_3) = 1.5^2\times8 = 18$ W。$18-18=0$ ✓（全电路 $\sum P = 0$）。

再验一次 KVL 自身：$12 - 1.5\times2 - 1.5\times2 - 1.5\times4 = 12-3-3-6 = 0$ ✓。
:::
