# 基尔霍夫电压定律 KVL

<Meta time="5 min" level="卡片" note="绕行方向一旦选定，全程不能改；中途改方向等于给自己换了一套符号，方程必然自相矛盾" />

一句话结论：**任一回路，任一时刻，沿回路走一圈各段电压的代数和为零——因为能量守恒；而代数和怎么算，取决于你选的绕行方向，选定后就不能改。**

## 日常说法与正式定义

- 日常说法：从某点出发绕一圈回到原地，你的「高度」（电位）必须回到原值，不可能走完一圈凭空多出一截高度差。
- 正式定义：任一**回路**、任一时刻，沿回路按选定方向走一周，各段电压的**代数和为零**：

$$
\sum U = 0 \quad \Longleftrightarrow \quad \sum U_{升} = \sum U_{降}
$$

本质是**能量守恒**（电场力做功与路径无关）。同样与元件性质无关：电阻、电容、电源、非线性器件一视同仁。

**符号逐个读**：

| 符号 | 含义 |
| --- | --- |
| $U$ | 某一段元件两端的电压 |
| $U_{升}$、$U_{降}$ | 沿绕行方向走时的电位升、电位降 |
| 绕行方向 | 你自己选的行走方向，顺时针或逆时针都行 |

## 怎么用：先定绕行方向

先任意指定一个**绕行方向**（顺时针或逆时针），然后沿这个方向走，边走边记账：

- 经过电阻，从「+」走到「−」（顺着电流方向）：记 $+IR$（电位降）
- 经过电阻，从「−」走到「+」：记 $-IR$（电位升）
- 经过电源，从「−」走到「+」：记 $+E$（电位升）
- 经过电源，从「+」走到「−」：记 $-E$（电位降）

全程代数和为零：

$$
\sum U=0\qquad\text{例如}\qquad E-IR_1-IR_2-IR_3=0
$$

::: warning 唯一的纪律
**绕行方向一旦选定，全程不要改。** 中途改方向等于给自己换了一套符号，同一条支路会出现两个相反的符号，方程必然自相矛盾。这与「参考方向全程不换」是同一条纪律的两种说法。
:::

## 两种列法

1. **全电压式**：沿圈把每个元件的 $u$ 都写出来。适合串联回路，一步到位。
2. **电位式**：只写电源，用「电位升 = 电位降」把电阻项挪到另一边。适合多电源、又要问各点电位的题，因为串联分压可以直接写成电位差。

考试里若题目要「求各点电位」，第二种通常少写一半符号。

## 推广形式：假想回路

KVL 对**任意闭合路径**成立，不一定要有实际元件——可以在两个点之间「假想」一条路径，把两端的电压写出来。这叫**假想回路**，常用于求开路电压：开路处电流为零，假想回路里补进一条支路也不影响结果。

## 常见误解

1. **中途改绕行方向** → 同一条支路出现两个相反的符号，方程自相矛盾 → 选定后全程不改。
2. **把「经过电源」一律记正** → 电源符号搞反时方程无解或解出负电流 → 记号只看方向：从「−」到「+」记 $+E$，从「+」到「−」记 $-E$。
3. **以为 KVL 必须有实际元件才能列** → 不会求开路电压 → 假想回路随时可用。
4. **以为 KVL 依赖元件性质** → 遇到电容电感就不敢用 → KVL 只依赖连接方式；带电抗的交流电路照样列 KVL，只是把 $u$ 换成相量 $\dot U$。
5. **沿回路把电压全按绝对值加起来** → 结果不为零 → KVL 是**代数**和，每一项都有正负。

## 例题

::: tip 例 1 · 单回路 KVL
**题目**：一个回路里，电源 $E = 12$ V 与三个电阻 $R_1=2\ \Omega$、$R_2=2\ \Omega$、$R_3=4\ \Omega$ 串联，电源与电阻串成一个圈。求回路电流 $I$ 与 $R_3$ 上的功率。

**先想什么**：只有一个回路、只有一条支路电流，列一条 KVL 就够。

**步骤**：

1. 定绕行方向：**顺时针**，设回路电流 $I$ 顺时针流动。
2. 沿方向逐段记账：从电源的「−」端出发 → 经电源从「−」到「+」，记 $+E$；经 $R_1$（顺着电流方向，从「+」到「−」），记 $-IR_1$；经 $R_2$ 记 $-IR_2$；经 $R_3$ 记 $-IR_3$；回到起点。
3. 列方程：

$$
E - IR_1 - IR_2 - IR_3 = 0
$$

4. 代入数值：

$$
12 - I(2+2+4) = 0 \;\Rightarrow\; I = \frac{12}{8} = 1.5\ \text{A}
$$

5. $R_3$ 的功率：$P_3 = I^2R_3 = 1.5^2\times4 = 9\ \text{W}$（电阻恒吸收功率）。

**验算（功率守恒）**：电源发出 $P_E = EI = 12\times1.5 = 18$ W；三个电阻吸收 $I^2(R_1+R_2+R_3) = 1.5^2\times8 = 18$ W。$18-18=0$ ✓（全电路 $\sum P = 0$）。

**验算（KVL 自身）**：$12 - 1.5\times2 - 1.5\times2 - 1.5\times4 = 12-3-3-6 = 0$ ✓。
:::

## 在正文里什么时候用得上

> 完整内容见 [02 · 基尔霍夫定律与电位](../01-basics/kcl-kvl.md)

KVL 是结点电压法、支路电流法、戴维南定理求 $U_{OC}$ 的另一半。交流章节里它是相量域的 $\sum \dot U = 0$——形式一个字没改，变的只是每个符号上多了一个点、每个运算从实数变成复数。
