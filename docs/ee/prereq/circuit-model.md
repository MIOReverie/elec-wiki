# 电路模型与理想元件

<Meta time="5 min" level="卡片" note="模型只管端口对外的关系：电压源钉电压，电流源钉电流，两个不能同时钉死" />

新买的干电池，万用表量着 1.6 V，接上一只小灯泡立刻掉到 1.3 V。电池坏了吗。没坏，是「1.5 V」这句话少了个条件：它说的是电动势，不是端电压。

电路模型干的就是把少掉的那一半写进公式。

## 抽象掉什么，留下什么

电路模型 = 把实际器件抽象成几个理想元件的连接，只保留端口的 $u$-$i$ 关系。所谓端口关系，就是「进去的电流和两端的电压之间怎么换算」，与 $u$-$i$ 无关的东西一律丢掉：化学过程、绕了几圈、介质配方。

理想元件分两类：有源的能往外送电（电源），无源的不能自己发电（电阻、电感、电容）。

## 五种元件的端口关系，一张表查

| 理想元件 | 端口关系 | 能量性质 | 一句话 |
| --- | --- | --- | --- |
| 电阻 $R$ | $u = Ri$ | 耗能 | 电压正比于电流，比例系数是阻值 |
| 电感 $L$ | $u = L\dfrac{di}{dt}$ | 储能（磁场） | 电压正比于电流的变化率 |
| 电容 $C$ | $i = C\dfrac{du}{dt}$ | 储能（电场） | 电流正比于电压的变化率 |
| 理想电压源 | $u = U_S$（由外电路决定 $i$） | 供能 | 电压被钉死，电流由外面决定 |
| 理想电流源 | $i = I_S$（由外电路决定 $u$） | 供能 | 电流被钉死，电压由外面决定 |

符号不熟时对照这张：

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| $u$、$i$ | 元件两端的电压、流过元件的电流（**瞬时值**，随时间变） | V、A |
| $R$ | 电阻值 | $\Omega$ |
| $L$ | 电感量 | H |
| $C$ | 电容量 | F |
| $U_S$、$I_S$ | 理想电压源电压、理想电流源电流 | V、A |

能不能退这一步，看题目问什么。算稳态、算偏置、算等效电路，退到理想源通常没事；算带载能力、算效率、算短路电流，内阻一步都不能省。

## 实际电源 = 理想源 + 内阻

- 实际电压源 = 理想电压源 $E$ 串内阻 $R_0$
- 实际电流源 = 理想电流源 $I_S$ 并内阻 $R_0$

内阻 $R_0$ 不是零件脏了。电源内部的导体、电解液、绕组本来就导电，它和负载分同一份电压，所以带载后端电压必掉。

::: tip 分工只需记一句
电压源是「电压给足，电流随你」，电流源是「电流给足，电压随你」。记住这一句，就不会在「这个电源到底输出多少」上绕圈子。
:::

## 四个常踩的坑

1. 给电压源标一个确定的电流值。电压源只钉死电压，电流完全由外电路决定；换作理想电流源，钉死的换成电流。
2. 把 $u = L\dfrac{di}{dt}$ 里的 $L$ 当成「电感两端的电压」。$L$ 是电感量，单位 H，它回答的是「电流变化多快才撑起这么高的电压」。
3. 以为模型越简单越好，一律用理想源。算出「电源电压恒为 12 V」，一接负载结论就失效。
4. 以为 $R$、$L$、$C$ 是三种不同的电阻。它们只是三种端口关系：正比于电流、正比于电流变化率、正比于电压变化率。

## 例题

::: tip 例 1 · 实际电源带载：端电压掉了多少
题目：一个标称 6 V 的电池（电动势 $E=6$ V，内阻 $R_0=0.2\ \Omega$）接一个 $R_L=2.8\ \Omega$ 的负载。求电流、负载端电压，以及电源内阻上白白消耗的功率。

先想什么：题目给的是「标称 6 V」，那其实是开路电压，带载后端电压要掉。所以第一步不是套欧姆定律，而是先认清用的是哪个模型。

步骤：

1. 电流：$I = \dfrac{E}{R_0+R_L} = \dfrac{6}{0.2+2.8} = 2\ \text{A}$。*（为什么分母要加 $R_0$：内阻与负载串在同一条回路上，流过的是同一个电流。）*
2. 负载端电压：$U = IR_L = 2\times2.8 = 5.6\ \text{V}$。*（为什么用 $IR_L$ 而不是 $E$：端电压是「到手的那一份」。）*
3. 内阻上的损耗：$P_0 = I^2R_0 = 2^2\times0.2 = 0.8\ \text{W}$。

验算，用功率守恒：电源发出 $P = EI = 6\times2 = 12$ W；负载吸收 $P_L = I^2R_L = 2^2\times2.8 = 11.2$ W，内阻吸收 0.8 W。$12 = 11.2+0.8$ ✓（全电路 $\sum P = 0$）。

注意：负载拿到的 5.6 V 已经比标称的 6 V 低了近 7%，这就是「标称电压」与「实际电压」的差别，也是电源内阻存在的直接后果。
:::
