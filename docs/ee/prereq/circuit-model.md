# 电路模型与理想元件

**电路模型** = 把实际器件抽象成若干**理想元件**的连接，只关心端口的 $u$-$i$ 关系。

| 理想元件 | 端口关系 | 能量 |
| --- | --- | --- |
| 电阻 $R$ | $u = Ri$ | 耗能 |
| 电感 $L$ | $u = L\dfrac{di}{dt}$ | 储能（磁） |
| 电容 $C$ | $i = C\dfrac{du}{dt}$ | 储能（电） |
| 理想电压源 | $u = U_S$（由外电路决定 $i$） | 供能 |
| 理想电流源 | $i = I_S$（由外电路决定 $u$） | 供能 |

实际电源模型 = 理想源 + 内阻：电压源串 $R_0$，电流源并 $R_0$。
