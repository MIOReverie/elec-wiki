# 电压电流的参考方向

参考方向是**人为任意假设**的，计算结果为正说明实际方向一致，为负说明相反。

- $U_{ab}$ = a 点电位 − b 点电位，故 $U_{ab} = -U_{ba}$
- **关联（被动）方向**：电流从电压参考方向的 "+" 端流入

$$
\text{关联：} U = RI \qquad \text{非关联：} U = -RI
$$

::: tip 为什么要先假设？
电路里电流往哪流常常一眼看不出来（尤其多电源电路）。先随便标一个，让方程的符号告诉你答案——这是电路分析最省力的一步。
:::
