# 电阻串并联等效

**串联**（电流相同）：

$$
R = R_1 + R_2 + \cdots \qquad U_k = \frac{R_k}{\sum R}\,U
$$

**并联**（电压相同）：

$$
\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots \qquad I_k = \frac{G_k}{\sum G}\,I
$$

两个电阻并联速记：$R = \dfrac{R_1R_2}{R_1+R_2}$（"积除以和"）。

- 串联电阻越多，总电阻越大，且**总电阻大于任一个**
- 并联电阻越多，总电阻越小，且**总电阻小于任一个**
