# 结点电压法

<Meta time="5 min" level="卡片" note="自导恒正、互导恒负：只要记住这两条，方程的符号就不会错；未知量选结点电压，方程数从 b 降到 n−1" />

一句话结论：**把各结点对参考点的电压当作未知量，只列 KCL：一个 $n$ 结点的电路只要 $n-1$ 个方程，比支路电流法少得多——所以它是最通用的方法。**

## 日常说法与正式定义

- 日常说法：不问「每条支路里流多少电」，而问「每个点有多高」。点的高度定了，电流自己就定了。
- 正式定义：以**结点电压**（各结点对参考点的电压）为未知量，对每个非参考结点列一条 KCL，整理成线性方程组。

**符号逐个读**：

| 符号 | 含义 |
| --- | --- |
| $V_k$ | 结点 $k$ 对参考点的电压 |
| $G_{kk}$ | **自导**：与结点 $k$ 相连的所有电导之和，恒正 |
| $G_{kj}$ | **互导**：结点 $k$、$j$ 之间电导之和的**负值**，恒负 |
| $I_{Sk}$ | 流入结点 $k$ 的电流源代数和 |
| $R$、$G$ | 电阻与电导，$G = 1/R$ |

## 方程长什么样

$$
\begin{cases}
G_{11}V_1 + G_{12}V_2 = I_{S11} \\
G_{21}V_1 + G_{22}V_2 = I_{S22}
\end{cases}
$$

三条读法：

- $G_{kk}$：与结点 $k$ 相连的所有电导之和（**自导，恒正**）
- $G_{kj}$：结点 $k$、$j$ 之间电导之和的负值（**互导，恒负**）
- 右端：流入该结点的电流源代数和

::: tip 为什么符号总是「自导正、互导负」
这是把 KCL 从「电流」改写成「电压」的结果。KCL 写成：$\sum_j (V_k - V_j)G_{kj} = I_{Sk}$，把含 $V_k$ 的项并到左边、含别人的项移到右边，$V_k$ 的系数是**自己这一串电导之和**（正），别人的系数带一个**负号**（因为从「$V_k-V_j$」里把 $-V_j$ 移过去变成 $+V_j$ 到右边、再整体搬回来时变号）。
:::

**为什么这是最通用的方法**：$n$ 个结点只需 $n-1$ 个方程，比支路电流法（$b$ 个方程）省得多。$n-1$ 这个数是拓扑决定的：$n$ 个结点的 KCL 加起来恒等于 $0=0$，所以有一条能被其余推出。

## 两结点特例：弥尔曼定理

当只有两个结点时，方程可以手算出来，这就是**弥尔曼定理**（Millman's theorem）：

$$
V_1 = \frac{\dfrac{E_1}{R_1} + \dfrac{E_2}{R_2}}{\dfrac{1}{R_1}+\dfrac{1}{R_2}}
$$

**它的含义是「加权平均」**：每个电源按自己的电导大小投票——电导越大（电阻越小），这一路的贡献越大。

## 常见误解

1. **把互导写成正的** → 方程解出来的电压反了号 → 记住：自导正、互导负。
2. **在参考结点上列方程** → 多出一个恒等式 $0=0$ → 参考结点电位恒为 0，不列方程。
3. **把电流源当电压源处理** → 方程右端写错 → 流入结点的电流源记正、流出记负；电压源则通过它串的电阻变成电流源再进方程。
4. **以为「自导」就是那一条支路的电导** → 系数算小 → 自导是**所有**接在该结点上的支路电导之和。
5. **以为结点电压法只适合大电路** → 小电路嫌麻烦 → 两结点时手算就是弥尔曼定理，比解方程组快。

## 例题

::: tip 例 1 · 三支路结点的结点电压
**题目**：结点 1 上接三条支路：支路 1 是 $E_1=10\ \text{V}$ 串 $R_1=4\ \Omega$，支路 2 是 $E_2=6\ \text{V}$ 串 $R_2=6\ \Omega$，支路 3 是电阻 $R_3=2\ \Omega$ 直接接地。求结点电压 $V_1$ 与各支路电流。

**先想什么**：一个非参考结点 → 只需一条 KCL → 一个一次方程。

**步骤**：

1. 对结点 1 列 KCL（电流从结点流到各支路为正）：$\dfrac{V_1-E_1}{R_1}+\dfrac{V_1-E_2}{R_2}+\dfrac{V_1}{R_3}=0$。*（为什么写成「$V_1-E$」：每条支路上流过的电流是「结点电压减电源电压」再除以电阻。）*
2. 代入数值：

$$
\frac{V_1-10}{4}+\frac{V_1-6}{6}+\frac{V_1}{2}=0
$$

3. 通分：$(3)(V_1-10) + (2)(V_1-6) + (6)(V_1) = 0$（公分母 12），得 $3V_1-30+2V_1-12+6V_1=0$，即 $11V_1 = 42$：

$$
V_1 = \frac{42}{11} \approx 3.82\ \text{V}
$$

4. 各支路电流：$I_1 = \dfrac{10-3.82}{4} = 1.545\ \text{A}$，$I_2 = \dfrac{6-3.82}{6} = 0.364\ \text{A}$，$I_3 = \dfrac{3.82}{2} = 1.909\ \text{A}$。

**验算（KCL 闭合）**：$I_3 = I_1 + I_2$？$1.909 = 1.545+0.364 = 1.909$ ✓（两条电源支路都向结点送电，电流全部经 $R_3$ 流回地）。

**验算（用系数的形式再解一次）**：自导 $G_{11} = \frac14+\frac16+\frac12 = \frac{11}{12}$，互导不存在（只有一个未知结点），右端 $I_{S1} = \frac{10}{4}+\frac{6}{6} = 3.5$ A，于是 $V_1 = 3.5 / (11/12) = 42/11 \approx 3.82\ \text{V}$ ✓，与第 3 步一致。

**注意**：$V_1 = 3.82\ \text{V}$ 低于两个电源电压——因为两条电源支路都串了电阻，都往「拉高」的方向出力，但拉不到 6 V 以上。这正是「加权平均」：$R_2=6\ \Omega$ 那一路电导小，话语权低。
:::

## 在正文里什么时候用得上

> 完整内容见 [04 · 支路电流法与结点电压法](../02-methods/nodal.md)

凡是电路「接了几个电源、想知道某点的电压」，结点电压法都是首选。它也是电子电路里列节点方程（模电的基尔霍夫节点法）的基础——模电里说的「节点电压法」几乎是同一件事，只是符号用 $v$。
