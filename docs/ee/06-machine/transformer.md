# 16 · 变压器

<Meta time="40 min" level="核心" note="三条关系（变电压、变电流、变阻抗）+ 两种试验（空载、短路），变压器就这些" />

变压器凭什么能改变电压，又不让两边直接连通？上一页其实已经给出了一半答案：磁路能把磁通从一处送到另一处，而电可以不连。

它是磁路知识里第一个「能挣钱」的应用。那些磁路公式落到工程上，就是三件事：变电压、变电流、变阻抗。三个比例式记牢，铭牌上的额定电流、效率、电压调整率都能自己算出来。

::: tip 读这页之前
只要会磁路的磁通势与磁阻（<Prereq id="magnetic-circuit" />）、交流阻抗与相量（<Prereq id="impedance" />），三条比例式就推得出来。

符号不多：$k$ 是变比，$S_N$ 是额定容量，$P_{Fe}$ 是铁损，$P_{Cu}$ 是铜损，$\beta$ 是负载率，约定见[符号与约定](../../guide/notation.md)。
:::

## 一、先有磁通，后有电压

```
u₁ → 励磁电流 i₀ → 交变主磁通 Φ（在铁心里闭合）
                        ├→ 原边感应 e₁ = −N₁dΦ/dt
                        └→ 副边感应 e₂ = −N₂dΦ/dt
```

两边绕组套在同一个铁心上，同一个 $\Phi$ 在里面变化，按法拉第定律就感应出与匝数成正比的电动势，匝数比就是**变比** $k$：

$$
U_1 \approx E_1 = 4.44fN_1\Phi_m,\qquad U_2 \approx E_2 = 4.44fN_2\Phi_m
$$

两式相除：

$$
\frac{U_1}{U_2}\approx\frac{N_1}{N_2}=k
$$

::: tip 4.44 是哪来的
正弦量 $e = -N\dfrac{d\Phi}{dt}$，$\Phi = \Phi_m\sin\omega t$，于是 $e = N\omega\Phi_m\cos\omega t$，幅值 $E_m = N\omega\Phi_m = 2\pi fN\Phi_m$。取有效值 $E = E_m/\sqrt2 = 4.44fN\Phi_m$。
:::

### 为什么不能变直流

直流下 $\Phi$ 恒定，$\dfrac{d\Phi}{dt} = 0$，没有感应电动势。原边加上额定直流电压时，原边电流只受绕组电阻限制（$I = U/R_a$，这个电阻很小），电流会大得离谱，直接烧毁。变压器事故里这一条很常见。

## 二、磁动势平衡：电流为什么跟着变

空载时原边只有励磁电流 $i_0$，约为额定电流的 2%~10%，它的有效值记作 $I_0$。副边一带负载就出现 $i_2$，有效值 $I_2$，原边电流随之变成 $I_1$。$i_2$ 产生的磁动势 $N_2i_2$ 会削弱主磁通。主磁通一削弱，原边感应电动势 $e_1$ 就下降，而 $u_1$ 被电源钉着不动，于是 $i_1$ 自动增大，去补偿 $N_2i_2$ 的去磁作用：

$$
N_1\dot I_1 + N_2\dot I_2 \approx N_1\dot I_0
$$

负载运行时 $I_0$ 很小，可以忽略：

$$
\boxed{\frac{I_1}{I_2}\approx\frac{N_2}{N_1}=\frac{1}{k}}
$$

副边多要一份功率，原边就自动从电源多取一份，功率（近似）无损传递，$U_1I_1 \approx U_2I_2$。这张图像比公式好记。

## 三、阻抗变换：电子电路里最常用的一条

副边接负载 $Z_L$，从原边看进去的等效阻抗：

$$
Z_{in} = \frac{\dot U_1}{\dot I_1}
= \frac{k\dot U_2}{\dot I_2/k}
= k^2\frac{\dot U_2}{\dot I_2}
= k^2 Z_L
$$

三条关系到这里凑齐了，摆在一起看：

$$
\boxed{\frac{U_1}{U_2}\approx\frac{N_1}{N_2}=k\qquad
\frac{I_1}{I_2}\approx\frac{1}{k}\qquad
Z_{in}=k^2Z_L}
$$

变电压、变电流、变阻抗，第三条是阻抗匹配和电子电路级联的基础。

::: tip 为什么需要阻抗匹配
<Prereq id="max-power" /> 还记得「负载等于源内阻时传输功率最大」吗？实际信号源内阻往往固定（天线 75 Ω、话筒 600 Ω），负载侧也是固定的（扬声器 8 Ω）。变压器的 $k^2$ 就是那个任意可调的变阻器：不消耗功率，只改变阻抗的表观值。
:::

## 四、外特性、损耗与效率

### 从电路看变压器：T 型等效

把副边按变比折算到原边之后，一台变压器就变成「两个阻抗串一个励磁支路」。漏阻抗决定电压掉落，励磁支路决定空载电流：

<CircuitFig kind="transformer-eq" title="变压器 T 型等效电路：漏阻抗 + 励磁支路 + 折算副边" />

::: tip 心智模型：折算，把副边「搬」到原边
本页最有用的一次思维切换：副边的 $R_2、X_2、Z_L$ 按变比折算到原边侧（$R_2'=k^2R_2$、$I_2'=I_2/k$），两套绕组就并成一条回路、一个电流，KVL 直接能用。前面的 $Z_{in}=k^2Z_L$ 只是这条规则的一个特例；有了它，电压调整率、效率、短路阻抗全都归结到对这张图列方程。
:::

### 电压调整率

负载之后副边电压会掉，掉的是原边漏阻抗上的那部分压降：

$$
\Delta U\% = \frac{U_{20}-U_2}{U_{20}}\times100\%
$$

</FigBox>

### 两种损耗

| 损耗 | 来源 | 随负载变化 |
| --- | --- | --- |
| 铁损 $P_{Fe}$ | 磁滞 + 涡流（硅钢片叠压就是为减小它） | 近似不变（只与电压/频率有关） |
| 铜损 $P_{Cu}$ | 绕组电阻发热 $I^2R$ | 按负载率平方 $P_{Cu} = \beta^2P_{CuN}$ |

严格说还有第 3 类，杂散损耗，通常是额定容量的 1% 上下，估算时一般忽略。

### 效率与最优点

效率的定义式还是纯算术：$\eta = P_2/(P_2+P_{Fe}+P_{Cu})$，式里的 $S_N$ 是额定容量、$\beta$ 是负载率，麻烦只在铜损随负载变。

$$
\eta = \frac{P_2}{P_2+P_{Fe}+P_{Cu}}
= \frac{\beta S_N\cos\varphi}{\beta S_N\cos\varphi+P_{Fe}+\beta^2P_{CuN}}
$$

<FigBox title="效率曲线：最高点不在满载" kind="曲线" note="铁损恒定、铜损按 β² 涨，两者相等处就是效率最高点（β* = √(P_Fe/P_CuN)）。曲线在 β* 附近有一小段很平，到满载反而往下拐。">
<WavePreset kind="traeff" />
</FigBox>

对 $\beta$ 求导令其为零，得

$$
\boxed{\beta^* = \sqrt{\frac{P_{Fe}}{P_{CuN}}}}
$$

一般变压器 $\beta^* \approx 0.5\sim0.7$。工程含义很实在：选容量时不必按满载配，留 20%~30% 余量反而运行在经济点。

## 五、两种试验：不拆变压器就能测出全部参数

| 试验 | 接线 | 测什么 |
| --- | --- | --- |
| 空载试验 | 副边开路，原边加额定电压 | 铁损 $P_{Fe}$、励磁阻抗、变比 $k$ |
| 短路试验 | 副边短路，原边加低电压到额定电流 | 铜损 $P_{CuN}$、短路阻抗、$\Delta U\%$ |

::: tip 为什么空载试验在低压侧做、短路试验只加低压
**空载试验**测的是铁损，得让铁心达到额定磁通，必须加额定电压；加在低压侧更安全，所以通常就在低压侧做。**短路试验**测的是铜损，这时磁通很小、铁损可忽略，只要电流达到额定就行，加很低的电压就够，加高了会把绕组烧掉。
:::

## 六、特殊变压器

| 类型 | 要点 |
| --- | --- |
| 自耦变压器 | 一、二次共用一部分绕组，省铜；但没有电气隔离 |
| 电流互感器 CT | 副边额定电流通常是 5 A 或 1 A；副边严禁开路：开路时 $I_2=0$，失去去磁作用，铁心磁通骤增，感应高压加上铁心过热 |
| 电压互感器 PT | 副边严禁短路；铁心与外壳必须接地 |
| 三相变压器 | 高压/低压均可 Y 或 △ 接，注意联结组别（如 Y,d11，数字是钟点数，表示相位差） |

## 七、例题

4 道题从最基础的三条关系一直排到标幺值算法，每道都先给判断、再算、最后回代验算。

::: tip 例 1 · 三条关系（基础题）
单相变压器 $S_N = 10$ kVA，$U_{1N}/U_{2N} = 6000/230$ V。求变比 $k$、额定电流 $I_{1N}$、$I_{2N}$。

先想什么：三个量里 $k$ 是纽带，先求它。额定容量就是 $S_N = U_{2N}I_{2N}$，原副边共用（理想变压器功率守恒），两边额定电流各拿 $S_N$ 除以自己的额定电压就行。别用 $k$ 互相推，容易把方向搞反。

解

$$
k = \frac{U_{1N}}{U_{2N}} = \frac{6000}{230} = 26.1
$$

额定电流用副边额定值算更贴近带载计算：

$$
I_{2N} = \frac{S_N}{U_{2N}} = \frac{10000}{230} = 43.5\ \text{A}
$$

$$
I_{1N} = \frac{S_N}{U_{1N}} = \frac{10000}{6000} = 1.67\ \text{A}
$$

验算，用电流比：$I_{1N} = I_{2N}/k = 43.5/26.1 = 1.67$ A ✓

::: warning $k$ 的方向别搞反
$k = N_1/N_2 = U_1/U_2$，永远是「原边比副边」。降压变压器 $k > 1$，升压变压器 $k < 1$。搞反了 $k^2$ 就错 4 倍以上，这是最贵的失误。
:::
:::

::: tip 例 2 · 阻抗匹配（电子题）
一只 8 Ω 扬声器要通过变压器接到内阻 200 Ω 的信号源上，实现匹配。求变比。

先想什么：匹配的意思是让源看到的内阻等于源自身的电阻，这样源才能输出最大功率。变压器不改变功率，但能把副边的 $Z_L$ 折算到原边成 $k^2Z_L$，所以直接令 $k^2Z_L = R_s$，解出 $k$。一句话：把 8 Ω 用 $k^2$ 放大到 200 Ω，别反过来除。

解

Z_{in} = k^2Z_L = 200\ \Omega
$$

k^2 = \frac{200}{8} = 25 \;\Rightarrow\; k = 5
$$

验算：设源电动势 $E = 10$ V，副边电压 $= 10/5 = 2$ V，副边电流 $= 2/8 = 0.25$ A，负载功率 $= 0.5$ W。不匹配直接接时 $I = 10/208 = 0.048$ A，负载功率 $= 0.048^2\times8 = 0.018$ W。匹配之后功率传到 28 倍。

::: tip 本题的工程味道

:::

::: tip 例 3 · 效率与最经济负载率
一台三相变压器 $S_N = 100$ kVA，$P_{Fe} = 600$ W，$P_{CuN} = 1700$ W。求 $\beta = 0.75$、$\cos\varphi = 0.8$ 时的效率，以及最经济负载率。

先想什么：效率等于输出除以「输出加损耗」，而损耗只有两类，铁损固定、铜损随负载平方变。所以先算输出 $P_2=\beta S_N\cos\varphi$，再分别取铁损原值和铜损按 $\beta^2$ 折减，三项一除就完。最经济点是让两条损耗相等（$\beta^*=\sqrt{P_{Fe}/P_{CuN}}$），这是边际相等，不是套板。

解

输出功率：

$$
P_2 = \beta S_N\cos\varphi = 0.75\times100\times0.8 = 60\ \text{kW}
$$

铜损按 $\beta^2$ 折减：

$$
P_{Cu} = \beta^2P_{CuN} = 0.75^2\times1700 = 956\ \text{W}
$$

效率：

$$
\eta = \frac{60000}{60000+600+956} = \frac{60000}{61556} = 97.5\%
$$

最经济负载率：

$$
\beta^* = \sqrt{\frac{P_{Fe}}{P_{CuN}}} = \sqrt{\frac{600}{1700}} = 0.59
$$

此时

$$
\eta_{max} = \frac{0.59\times100\times0.8}{0.59\times100\times0.8+600+0.59^2\times1700}
= \frac{47.2}{47.2+0.6+0.6} = 97.5\%
$$

具体结论：这台变压器长期运行在 60% 负载左右最省电，满载反而略差，多出来的铜损超过了多送的功率。

::: tip 为什么满载不是最优点
铁损 600 W 是固定开销，铜损则随负载平方涨。$\beta = 1$ 时铜损 1700 W，是铁损的近 3 倍，多送的功率被自己的发热吃掉了一截。
:::

验算：总损耗 $= P_{Fe}+P_{Cu}=600+956=1556$ W，输入 $=P_2+损耗=60000+1556=61556$ W，$\eta=60000/61556=97.5\%$（能量守恒复核）；最经济点令 $P_{Fe}=P_{Cu}^*$ 即 $\beta^*=\sqrt{600/1700}=0.59$，两条损耗相等 ✓。
:::

::: tip 例 4 · 电压调整率（标幺值算法）
一台变压器漏阻抗标幺值 $R_* = 0.02$、$X_* = 0.05$，$\beta = 1$。分别求 $\cos\varphi = 1$、$\cos\varphi = 0.8$（感性）、$\cos\varphi = 0.8$（容性）时的电压调整率。

先想什么：电压调整率本质是漏阻抗压降在输出电压上的占比，公式 $\Delta U_*=\beta(R_*\cos\varphi+X_*\sin\varphi)$ 里只有 $\sin\varphi$ 这一项随负载性质变号，感性为正、容性为负。三问只是换 $\sin\varphi$ 的正负，套同一个式子，别把容性想成另一套算法。

解

标幺值公式：

$$
\Delta U_* = \beta\,(R_*\cos\varphi + X_*\sin\varphi)
$$

① 纯电阻（$\cos\varphi = 1$，$\sin\varphi = 0$）：

$$
\Delta U = 0.02 = 2\%
$$

② 感性 0.8（$\sin\varphi = 0.6$）：

$$
\Delta U = 0.02\times0.8+0.05\times0.6 = 0.016+0.03 = 0.046 = 4.6\%
$$

③ 容性 0.8（$\sin\varphi = -0.6$）：

$$
\Delta U = 0.016-0.03 = -0.014 = -1.4\%
$$

副边电压反而升高 1.4%。

::: warning 负调整率的后果
容性负载会把副边电压抬起来。长线路轻载时线路电容效应明显，末端电压会升高，这就是有些场合要装并联电抗器吸收无功来压电压的原因。
:::

验算：用同一公式复核三种性质，$\cos\varphi=1$ 时无无功项，仅剩 $R_*=2\%$；感性 0.8 加上正的 $X_*\sin\varphi$ 得 4.6%；容性 0.8 该项变负得 $-1.4\%$（电压调整率公式 $\Delta U_*=\beta(R_*\cos\varphi+X_*\sin\varphi)$ 复核）✓。
:::

## 八、工程实例

配电变压器半夜为什么「嗡嗡」响还发热？工业区夜里负载极低（$\beta \to 0$），铁损却一分不少，空载损耗占全天损耗的比例反而上升。现在推广非晶合金变压器，就是拼命压铁损，空载损耗能比硅钢片低 60%~80%。

家里为什么不能用自耦变压器调 220 V？自耦变压器一、二次有电气连接，副边电压调得过低时，220 V 侧可能带着火线对地电压出现在旋钮或外壳上，触电风险。调压台架用自耦的场合，必须专业人员操作并可靠接地。

## 九、易错清单

1. $k = N_1/N_2 = U_1/U_2$，永远是原边比副边；$Z_{in} = k^2Z_L$ 方向别反。
2. 不能变直流。没有感应电动势，原边电流巨大，直接烧毁。
3. 额定容量是 VA 不是 W；铭牌功率不能直接当有功功率用。
4. CT 副边严禁开路（高压），PT 副边严禁短路（过热、短路电流）。
5. 效率最高点在 $\beta^*=\sqrt{P_{Fe}/P_{CuN}}$，不在满载。
6. 电压调整率在容性负载时为负，电压反而升高。
7. $4.44fN\Phi_m$ 里的 $\Phi_m$ 是最大值，别拿有效值往里代。
