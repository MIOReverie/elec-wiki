# 17 · 机械特性 · 起动 · 调速

<Meta time="45 min" level="核心" note="起动方式是本章最常考的内容；调速则是变频器时代的看家本领" />

## 结论先行

1. **固有机械特性** $T$-$n$（或 $T$-$s$）曲线由 $T_{max}$ 和 $s_m$ 两个参数完全确定
2. 实用公式（Kloss）：$T = \dfrac{2T_{max}}{s/s_m+s_m/s}$，$s_m = \dfrac{R_2}{X_{20}}$，$T_{max}\propto\dfrac{U_1^2}{2X_{20}}$
3. **过载能力** $\lambda = T_{max}/T_N \approx 2.0\sim2.2$；$T_{max}$ 与 $R_2$ **无关**
4. 起动四法：**直接**（小容量）、**Y-△**（轻载）、**自耦补偿**（较大容量）、**转子串电阻**（绕线式重载）
5. 调速看 $n = \dfrac{60f}{p}(1-s)$：**变频最优**、变极有级、变转差率耗能

<Prereq id="slip" /> 上一章给出了转矩的物理表达式，本章把它变成一张能"查"的曲线，并解决两个工程问题：**怎么起**、**怎么调**。

## 一、机械特性曲线

<Prereq id="three-phase-source" /> 由 $T = K\dfrac{sR_2U_1^2}{R_2^2+(sX_{20})^2}$ 可整理成只用两个参数表达的形式：

$$
\boxed{T = \frac{2T_{max}}{\dfrac{s}{s_m}+\dfrac{s_m}{s}}}
\qquad
s_m = \frac{R_2}{X_{20}},\qquad
T_{max} = K\frac{U_1^2}{2X_{20}}
$$

**三个特征点**：

| 点 | $s$ | 转矩 | 说明 |
| --- | --- | --- | --- |
| 同步点 | 0 | 0 | 理想空载，无转矩 |
| 最大转矩 | $s_m$ | $T_{max}$ | 临界点，过载能力 $\lambda = T_{max}/T_N$ |
| 起动点 | 1 | $T_{st}$ | $T_{st} = \dfrac{2T_{max}s_m}{1+s_m^2}$ |

<FigBox title="T-s 特性曲线：两条曲线怎么被参数掰弯" kind="曲线" note="橙线是固有特性。蓝线：R₂ 增大 → s_m 右移，T_max 不动但起动转矩从 0.29 涨到 0.80。紫虚线：降压 → 整条曲线按平方衰减。">
<WavePreset kind="torslip" />
</FigBox>

**曲线形状的记忆法**：$s$ 很小时 $\dfrac{s_m}{s}$ 项主宰分母 → $T \approx \dfrac{2T_{max}}{s_m}s$，**近似直线**（这就是额定工作区"特性硬"的原因：转差率略变，转矩线性跟随）；$s$ 大时 $\dfrac{s}{s_m}$ 项主宰 → $T \approx \dfrac{2T_{max}s_m}{s}$，**双曲线**。

### 稳定运行区在哪

$T$-$s$ 曲线以 $s_m$ 分界：
- $0 < s < s_m$：**稳定区**（负载转矩变大 → $s$ 变大 → 电磁转矩变大去平衡它，自收敛）
- $s_m < s < 1$：**不稳定区**（负载变大 → $s$ 变大 → 转矩反而变小 → 越来越转不动，直到堵转）

工程上电机永远运行在 $s \ll s_m$ 的那一段，所以转速随负载只掉几个百分点。

::: tip 心智模型：机械特性 = 一张「可查」的曲线
把整章归结成一句：**一台异步电机的全部行为都画在 $T$-$s$ 这一张曲线上**，而这条曲线只由 $T_{max}$、$s_m$ 两个参数决定。所以每道题的起手式都一样——先在曲线上定位当前工作点（由 $n$ 或 $s$ 算出），再判断它在稳定区（$s<s_m$，自收敛）还是不稳定区（$s>s_m$，直到堵转）。起动、调速、制动，本质都是问「怎么把这条曲线或工作点掰到我想去的地方」。
:::

## 二、人为特性：三种"掰弯"曲线的方法

| 手段 | 对曲线的影响 | 用途 |
| --- | --- | --- |
| 降电压 $U_1$ | $T_{max}\propto U_1^2$，整条曲线按平方衰减，$s_m$ 不变 | 调速（小功率风机）、软启动 |
| 转子串电阻 $R_2$ | $s_m = R_2/X_{20}$ 右移，**$T_{max}$ 不变**，$T_{st}$ 增大 | 绕线式重载启动、串级调速 |
| 改极对数 $p$ | 换接绕组，$n_0 = 60f/p$ 变 | 变极调速（有级） |

## 三、起动：四种方法

<FigBox title="起动电流/转矩都按 k² 衰减" kind="曲线" note="横轴是加到电机上的电压比 k。电流和转矩沿同一条 k² 曲线下降：Y-△ 相当于 k = 1/√3 → 1/3；自耦变压器用抽头得到不同的 k。">
<WavePreset kind="startcurve" />
</FigBox>

| 方法 | 起动电流（电网侧） | 起动转矩 | 适用场合 |
| --- | --- | --- | --- |
| 直接启动 | $I_{st}=(5\sim7)I_N$ | $T_{st}=(1\sim2)T_N$ | 小容量（通常 $\le$ 变压器容量的 20%） |
| **Y-△ 降压** | $\dfrac13I_{st}$ | $\dfrac13T_{st}$ | 正常运行 **△ 接**、空载/轻载启动 |
| 自耦补偿 | $k^2I_{st}$ | $k^2T_{st}$ | 较大容量，抽头 65%/80% 可选 |
| 转子串电阻 | 减小 | **增大** | **绕线式**电机，重载启动（起重机） |

### Y-△ 为什么是 1/3（两步推导）

设电机额定 △ 接：

**第一步，相电压。** Y 接时每相电压 $U_p' = U_l/\sqrt3$，是 △ 接时（$U_p = U_l$）的 $1/\sqrt3$ 倍 → $k = 1/\sqrt3$。

**第二步，电流。** 电机侧相电流 ∝ 电压 → 降为 $1/\sqrt3$；而 Y 接的线电流 = 相电流（△ 接时线电流 = $\sqrt3$ 相电流），于是电网侧线电流：

$$
\frac{I'_{st}}{I_{st}} = \frac{1}{\sqrt3}\times\frac{1}{\sqrt3} = \frac13
$$

**转矩** $\propto U_p^2$ → 降为 $(1/\sqrt3)^2 = \dfrac13$。**电流和转矩同步降为 1/3**，这就是那张 $k^2$ 图上 Y-△ 那个点的坐标。

::: warning Y-△ 启动的两个前提
1. 电机**正常运行必须是 △ 接**（△ 接才能达到额定转速和功率）
2. 负载必须**轻**：$T_{st}/3 > T_L$ 才行。重载起不来，只会"嗡嗡"响并过热
:::

## 四、调速：三条路线

$$
n = n_0(1-s) = \frac{60f}{p}(1-s)
$$

| 方法 | 改哪个量 | 特点 | 今日地位 |
| --- | --- | --- | --- |
| **变频调速** | $f$（同时保持 $U/f$ 恒定） | 平滑无级、效率高、范围宽 | **绝对主流** |
| 变极调速 | $p$（换接绕组） | 有级（2/4/8 极）、简单便宜 | 廉价的机床档位 |
| 变转差率 | $R_2$（绕线式串电阻/串级） | 简单但**能耗大**、特性软 | 起重机、风机节能改造 |
| 调压调速 | $U_1$ | 范围小（$T\propto U^2$） | 小功率风机 |

### 变频为什么必须同时调压

由 $U_1 \approx 4.44f_1N_1\Phi_m$：若只降 $f_1$ 不改 $U_1$，则 $\Phi_m \propto 1/f_1$ 会上升 → 铁心**饱和** → 励磁电流暴增 → 电机烧毁。所以变频调速的规矩是：

$$
\boxed{\frac{U_1}{f_1} = \text{常数}}
$$

（额定频率以上则不再升压，进入"弱磁升速"区，转矩相应下降。）

## 五、制动

| 方式 | 做法 | 特点 |
| --- | --- | --- |
| 能耗制动 | 断开交流、定子通直流 | 平稳，需直流电源 |
| 反接制动 | 对调两根火线 | 冲击大，要及时切断 |
| 回馈制动 | $n > n_0$（起重机下放重物） | 能量回电网，最经济 |

## 例题

::: tip 例 1 · 用 Kloss 公式算特性点
某电机 $T_{max} = 400$ N·m、$s_m = 0.15$、$n_0 = 1500$ r/min。求 $s = 0.04$（额定）和 $s = 1$（起动）时的转矩，并求过载能力。

**解**

$$
T(s) = \frac{2T_{max}}{\dfrac{s}{s_m}+\dfrac{s_m}{s}}
$$

**$s = 0.04$：**

$$
T = \frac{2\times400}{\dfrac{0.04}{0.15}+\dfrac{0.15}{0.04}}
= \frac{800}{0.267+3.75}
= \frac{800}{4.017} = 199.2\ \text{N·m}
$$

**$s = 1$：**

$$
T_{st} = \frac{2\times400\times0.15}{1+0.15^2}
= \frac{120}{1.0225} = 117.4\ \text{N·m}
$$

**过载能力**（以 199.2 为额定转矩）：

$$
\lambda = \frac{T_{max}}{T_N} = \frac{400}{199.2} = 2.01
$$

符合"$\lambda \approx 2.0\sim2.2$"的常识 ✓

::: tip 顺带一个对比
这台电机的 $T_{st}/T_N = 117.4/199.2 = 0.59$ —— **起动转矩比额定转矩还小**！低转差率的标准电机就是这样，所以只要负载接近额定，就必须上降压启动之外的考虑（换高滑差电机或绕线式）。
:::
:::

::: tip 例 2 · Y-△ 启动能不能带得动
上题电机（$I_{st} = 6.5I_N$、$T_{st} = 117.4$ N·m）改为 Y-△ 启动。若负载转矩 $T_L = 60$ N·m，能否起动？

**解**

**Y 接时的起动转矩：**

$$
T'_{st} = \frac{T_{st}}{3} = \frac{117.4}{3} = 39.1\ \text{N·m}
$$

**判断**：$39.1 < 60$ → **起不来**。

**若换成轻载** $T_L = 30$ N·m：$39.1 > 30$ → 可以起动，且起动电流只有 $6.5/3 = 2.17$ 倍的 $I_N$。

::: warning 这道题的判断逻辑
**先算降压后的起动转矩，再和负载转矩比** —— 这是所有启动方式选择题的唯一判据。转矩够（$T'_{st} > T_L$）才谈得上选哪种；不够就要换方法（自耦抽头调高、或绕线式串电阻）。
:::
:::

::: tip 例 3 · 自耦补偿抽头的选取
上题电机若用自耦变压器启动，要求起动转矩 $\ge 60$ N·m、电网起动电流尽可能小。选哪个抽头？

**解**

需要 $k^2T_{st} \ge 60$：

$$
k^2 \ge \frac{60}{117.4} = 0.511 \;\Rightarrow\; k \ge 0.715
$$

标准抽头有 65% 和 80%。**65% 不够**（$0.65^2\times117.4 = 49.6$ N·m < 60），选 **80%**：

$$
T'_{st} = 0.8^2\times117.4 = 75.1\ \text{N·m} > 60\ \text{✓}
$$

$$
I'_{st} = 0.8^2\times6.5I_N = 4.16\,I_N
$$

**对比 Y-△**（$39.1$ N·m、$2.17I_N$）：Y-△ 电流更小但转矩不够；自耦 80% 转矩够但电流大一些。**自耦的优势在于 k 可调**，Y-△ 只有 1/3 一档。

::: tip 为什么自耦比 Y-△ 贵还在用
因为它的 $k$ 连续可调，能在"起动电流"和"起动转矩"之间找平衡点；Y-△ 只有 $k=1/\sqrt3$ 一个档，且要求电机正常运行时是 △ 接。
:::
:::

::: tip 例 4 · 稳态转速：用特性曲线反解
上题电机带 $T_L = 0.8T_N = 159.4$ N·m 稳定运行，求转速。

**解**

稳态时电磁转矩 = 负载转矩：

$$
\frac{800s\cdot0.15}{s^2+0.15^2} = 159.4
\;\Rightarrow\;
120s = 159.4(s^2+0.0225)
$$

整理成二次方程：

$$
159.4s^2 - 120s + 3.586 = 0
$$

$$
s = \frac{120\pm\sqrt{120^2-4\times159.4\times3.586}}{2\times159.4}
= \frac{120\pm110.1}{318.8}
$$

两个根：$s_1 = 0.72$（不稳定区，舍去）、$s_2 = 0.031$（稳定区，取它）

$$
n = n_0(1-s) = 1500\times(1-0.031) = 1453\ \text{r/min}
$$

::: warning 为什么舍去大根
$s = 0.72 > s_m = 0.15$ 落在**不稳定区**：任何扰动都会让转速继续下滑直到堵转。数学上二次方程给两个解，工程上只有一个能稳定运行 —— **永远取小于 $s_m$ 的那个根**。
:::
:::

## 工程实例

**变频器怎么让一台老电机"起死回生"？** 风机、水泵改成变频驱动后，流量用转速调而不是用阀门挡 —— 省掉的正是被阀门消耗的那部分功率（功率 ∝ 转速³，流量减半时功率只剩 1/8）。这是目前最大的电机节能市场。

**软启动器是什么？** 晶闸管调压的启动装置，本质上就是"连续可调的降压启动"，按斜坡把电压升上去，起动电流限制在 2~3 倍 $I_N$。比 Y-△ 平滑，比变频器便宜，适合不需要调速但要软起/软停的场合（水泵、压缩机）。

## 易错清单

1. $T_{max}$ 与 $R_2$ **无关** —— $R_2$ 只移动它的位置（$s_m$）
2. 降压启动降的是**转矩的平方**，重载一定起不来
3. Y-△ 启动的前提：电机正常运行是 **△ 接** + 负载**轻**
4. 变频调速**必须同时调压**保持 $U/f$，否则低频磁通过饱和
5. Kloss 公式解出的两个 $s$ 根，**取小于 $s_m$ 的**
6. 起动电流大 ≠ 起动转矩大（$\cos\varphi_2$ 的锅，见第 16 章）
7. 串励/绕线式转子串电阻是"**既限流又增矩**"的唯一方法，但只适用于绕线式

## 考点速记

| 题型 | 关键 |
| --- | --- |
| 求 $T_{max}$、$T_{st}$、$s_m$ | Kloss 公式，$s_m = R_2/X_{20}$ |
| 判断能否启动 | 降压后 $T'_{st} > T_L$ |
| 选启动方式 | 轻载 Y-△；可调选自耦；重载绕线式串电阻 |
| 求稳态转速 | 令 $T(s) = T_L$，取 $s < s_m$ 的根 |
| 变频调速 | $n_0 = 60f/p$，保持 $U/f$ 恒定 |
