# 07 · 三要素法：RC / RL

<Meta time="45 min" level="核心" note="一阶电路的万能公式，背下它这章就结束了" />

**这一页要解决什么**：上一页说了「换路瞬间」怎么算，但换路之后那条曲线长什么样、任意时刻的电压电流是多少？这一页给一阶电路一个万能解法：只要求出三个数（起点、终点、时间常数），整条曲线就被唯一确定。读完你应该能对任意只含一个储能元件的电路，求出任意响应 $f(t)$，并说清每个数是从哪张电路里来的。

::: tip 读这页之前
- **需要会**：换路定则与 $t=0_+$ 等效电路（<Prereq id="switching-rule" />）、稳态等效（电容开路、电感短路，见上一页）、串联与并联（<Prereq id="series-parallel" />）、分压（<Prereq id="voltage-divider" />）。
- **这一页用到的符号**：$f(t)$（要 求的**响应量**，随时间变化的任一电压或电流）、$f(0_+)$、$f(\infty)$、$\tau$（时间常数，单位秒）、$R_{eq}$（**等效电阻**：从储能元件端口看进去、独立源置零后测到的电阻，单位 Ω）、$u_C$、$i_L$。全部约定见[符号与约定](../../guide/notation.md)。
- **会用到的数学**：指数函数 $e^{-t/\tau}$ 与自然对数 $\ln$（求「达到某值要多久」时要用 $\ln$，即 $e^x$ 的反函数）。
:::

你给一个电路，只有一个电容和一个电阻。电源是 12 V，电阻是 2 kΩ，电容是 100 μF。合闸后电容电压要多久才充到 6 V？——这道题要算的量出现在一个指数里，而指数的三个参数来自三个**不同的电路**：起点来自换路瞬间那张图，终点来自最终稳态那张图，速度来自把电源短路的第三张图。这一页要做的，就是把「一个指数」翻译成「三张电路 + 三个数」。

## 结论先行

1. **一阶电路**（只含一个储能元件）的任何响应都只有一个指数，写成同一个式子：$f(t) = f(\infty) + \big[f(0_+) - f(\infty)\big]e^{-t/\tau}$。
2. 起点 $f(0_+)$：先用换路定则拿 $u_C(0_+)$ 或 $i_L(0_+)$，再在 $t=0_+$ 等效电路上求目标量。
3. 终点 $f(\infty)$：换路后的**稳态**——电容开路、电感短路，按纯电阻电路算。
4. 时间常数 $\tau$：RC 电路 $\tau = R_{eq}C$，RL 电路 $\tau = L/R_{eq}$；$R_{eq}$ 是**从储能元件端口看进去**的等效电阻。
5. 三个特例（RC 充电、RC 放电、RL 接通）都只是这个通式填数的产物，不需要单独背。

::: tip 三要素法 = 先定点、再连线
把三要素法当成一个固定套路，顺序就是纪律：① 先用换路定则钉住**起点** $f(0_+)$ → ② 用稳态（C 开路 / L 短路）钉住**终点** $f(\infty)$ → ③ 从储能元件端口看进去求 $\tau$ → ④ 才代公式。三个点一钉，中间那条指数曲线就被唯一确定了——所以「先求三要素、后写表达式」的顺序不能乱，跳步最容易在 $f(\infty)$ 和 $\tau$ 上翻车。
:::

## 一、这章为什么可以这么短

这一节只回答一个问题：为什么一阶电路的解能被压缩成三个数。

因为**一阶电路的解是唯一的**，不管电路多复杂，全部信息都压缩在三个数里：

- 起点 $f(0_+)$：电路「从哪开始」
- 终点 $f(\infty)$：电路「到哪结束」
- 时间常数 $\tau$：电路「走多快」

**整条曲线就是这三点决定的**。所以本章不推公式，只教你**怎么把这三个数求对**。

## 二、三要素逐一求法

这一节把三要素法拆成三个动作，每个动作都点明「在哪种电路上算」。第 1 要素最容易出错，第 3 要素最容易算错。

### 第 1 要素：$f(0_+)$

**核心：用换路定则拿到 $u_C(0_+)$ 或 $i_L(0_+)$，再在 $t=0_+$ 的等效电路上算目标量。**

$t=0_+$ 等效电路的画法：
- **电容**：电压已知 → 用**电压源**替代（$u_C(0_+)$）
- **电感**：电流已知 → 用**电流源**替代（$i_L(0_+)$）

::: warning 最常见的错：目标量不是储能元件时忘了重算
如果题目要求的是 $u_{R_1}(t)$（电阻两端电压），它**在 $t=0_+$ 可能突变**。必须**在 $t=0_+$ 等效电路上重新算**，不能靠 $u_C$ 直接推。

举个例子：$E$ 经 $R_1$ 串 $R_2$ 串 $C$。求 $u_{R_1}$：
- $t=0_-$：$C$ 未充电，$u_C=0$ → $u_{R_1}=u_{R_2}=E/2$
- $t=0_+$：$u_C=0$（未突变）→ $u_{R_1}=u_{R_2}=E/2$（一样）

但如果是**开关直接接到 $C$ 两端**，此时 $u_{R_1}$ 会瞬间从 0 跳到 $E$，而 $u_C$ 从 $E$ 跳到 0。这种题必须画 $t=0_+$ 等效电路，不能用「$u_C$ 不突变」倒推。
:::

### 第 2 要素：$f(\infty)$

**稳态三句话**：

$$
\text{直流稳态} \;\Rightarrow\; \begin{cases}\text{电容} \to \text{开路 }(i_C=0)\\ \text{电感} \to \text{短路 }(u_L=0)\end{cases}
$$

然后就是纯电阻电路，用 <Prereq id="series-parallel" /> 或 <Prereq id="nodal" /> 算。

::: tip 为什么稳态是「电容开路、电感短路」？
物理上：稳态时电容充满电后不再有电流通过；电感电流恒定后不再有感应电动势。这不是「近似」，而是 $\dfrac{du_C}{dt}=0$ 和 $\dfrac{di_L}{dt}=0$ 的直接推论。

对直流而言，这意味着**电容相当于一个断开的开关，电感相当于一根导线**。
:::

### 第 3 要素：$\tau$

$$
\tau_{RC} = R_{eq}C,\qquad \tau_{RL} = \frac{L}{R_{eq}}
$$

**$R_{eq}$ 的求法（关键）**：把独立源置零（电压源短路、电流源开路），然后**从储能元件的两个端子看进去**的等效电阻。

三个要素各自从哪张电路来，现在都清楚了。接下来要回答一个问题：这三个数凭什么就能定死整条曲线。

## 三、时间常数的物理意义

这一节只回答一件事：$\tau$ 这个数到底在说什么。

$\tau$ 的量纲是秒。它告诉你**电路的「记性」有多长**：$t=\tau$ 时过渡过程走完 63.2%，$t=3\tau$ 时走完 95%。

| $t$ | 完成度 $1-e^{-t/\tau}$ | 剩余 |
| --- | --- | --- |
| $\tau$ | 63.2% | 36.8% |
| $2\tau$ | 86.5% | 13.5% |
| $3\tau$ | 95.0% | 5.0% |
| $5\tau$ | 99.3% | 0.7%（认为完成） |
| $\infty$ | 100% | 0% |

::: tip 工程速算
**「5τ 规则」**：任何一阶电路，经过 $5\tau$ 就认为进入稳态。这个规则在**滤波器截止频率**、**开关电源环路稳定性**、**继电器动作延时**估算里都用得上。
:::

### 影响 $\tau$ 的因素

$$
\begin{aligned}
\tau_{RC} &\propto R_{eq}\cdot C &&\text{电阻大、电容大 → 变化慢}\\
\tau_{RL} &\propto \frac{L}{R_{eq}} &&\text{电感大、电阻小 → 变化慢}
\end{aligned}
$$

**工程含义**：
- 要让电路**快速响应** → 减小 $\tau$（RC 减小 $R$ 或 $C$）
- 要让电路**滤除慢变化** → 增大 $\tau$（RC 加大 $R$ 或 $C$，低通滤波）

到这里，起点、终点、速度三个数都有了意义。下一节把它们组装成一套固定的操作顺序，让你在考场上不会跳步。

## 四、解题步骤（套公式）

这一节把三要素法变成一个四步清单，每一步都点明「在哪张电路上算」。

```
① 求 f(0₊)   —— 换路定则 + t=0₊ 等效电路
② 求 f(∞)    —— 稳态电路（C 开路、L 短路）
③ 求 R_eq    —— 从 C/L 端口看进去的等效电阻（独立源置零）
④ 代入 f(t) = f(∞) + [f(0₊) − f(∞)]e^(−t/τ)
```

**万能步骤**：不管电路多复杂，只要是一阶（**只有一个储能元件**），这四步一定能搞定。

::: tip 判断是否一阶
数储能元件个数：**1 个 → 一阶**，用三要素法；**2 个 → 二阶**，必须列微分方程或用拉普拉斯变换/算子法。
:::

## 五、三个特例（背下来）

这一节把通式代进去，导出三个最常考的形状——你会发现它们不需要背。

**RC 充电**（零状态，$u_C(0)=0$，充到 $E$）：

$$
u_C = E\left(1 - e^{-t/\tau}\right)
$$

就是这个电路在充电（闭合 S 后，$u_C$ 沿指数从 0 爬到 $E$）：

<CircuitFig kind="rc-charge" title="RC 充电电路：闭合开关后 u_C 按指数趋近 E" note="零状态的意思是：换路前电容上一点电荷都没有，所以起点是 0。" />

**RC 放电**（零输入，$u_C(0)=U_0$，放向 0）：

$$
u_C = U_0 e^{-t/\tau}
$$

**RL 接通直流**（零状态，$i_L(0)=0$，升到 $E/R$）：

$$
i_L = \frac{E}{R}\left(1 - e^{-t/\tau}\right)
$$

::: tip 特例怎么从三要素推出来（不要死记）
把三要素法的 $f(0_+)$、$f(\infty)$ 填进通用公式，立刻得到特例。以 RC 充电为例：

- $f(0_+) = u_C(0^+) = 0$（电容电压不突变）
- $f(\infty) = E$（稳态电容充满）
- 代入：$u_C(t) = E + (0-E)e^{-t/\tau} = E(1-e^{-t/\tau})$ ✓

**所以三个特例不需要背，只需要会填三要素。**
:::

## 典型例题

这一节四道题按「电路复杂程度」排：例 1 是最基本的 RC 充电，例 2 是 RL 接通并顺手求时间，例 3 是没有电源的放电过程（能量去哪了），例 4 是换路加并联电阻——考 $R_{eq}$ 到底该从哪看。每题都先看「先想什么」。

::: tip 例 1 · RC 充电：$u_C(t)$、$i(t)$ 与「到某值要多久」
**题干**：电路如图：$E=12\,\text{V}$、$R=2\,\text{k}\Omega$、$C=100\,\mu\text{F}$ 串联，开关闭合前电容未充电。求 $u_C(t)$、$i(t)$，以及 $u_C$ 升到 6 V 需要多久。

<CircuitFig kind="rc-charge" title="RC 充电：E、R、C 串联，开关 S 在 t=0 闭合" note="τ 只由 R 和 C 决定；开关在哪个位置不影响 τ，只影响起点。" />

**先想什么**：目标是「电容电压」，而 $u_C$ 恰好就是储能元件的状态量——起点可以直接由换路定则得到，不用另算。至于「多久到 6 V」，那是把已得的 $u_C(t)$ 反解出 $t$，不是新的电路问题。*（先分清哪些量要新电路、哪些量是解方程。)*

**解：按四步套路走。**

**① $f(0_+)$**：换路定则，$u_C(0_+)=u_C(0_-)=0$（未充电）。

**② $f(\infty)$**：稳态电容开路，$u_C(\infty)=E=12\,\text{V}$。

**③ $\tau$**：只有一个储能元件，一阶。从电容端口看进去（独立源置零后）$R_{eq}=R=2\,\text{k}\Omega$：

$$
\tau = RC = 2\times10^3 \times 100\times10^{-6} = 0.2\,\text{s}
$$

**④ 代入**：

$$
u_C(t) = 12 + (0-12)e^{-t/0.2} = 12\left(1-e^{-5t}\right)\,\text{V}
$$

电流用欧姆定律在现电路上求（不是套公式！）：

$$
i(t) = \frac{E-u_C(t)}{R} = \frac{12e^{-5t}}{2000} = 6e^{-5t}\,\text{mA}
$$

**验算（查三个点）**：$t=0$ 时 $i=6\,\text{mA}$（全部电压加在电容上）✓；$t=\tau=0.2\,\text{s}$ 时 $u_C=12\times0.632=7.59\,\text{V}$，正好 63.2% ✓；$t\to\infty$ 时 $i\to0$、$u_C\to12$ V ✓。另外在任意时刻 $u_C + iR = 12$ V（KVL 闭合）✓。

**求时间**：$6=12(1-e^{-5t})$ → $e^{-5t}=0.5$ → $t=\dfrac{\ln 2}{5}=0.139\,\text{s}$。
:::

**先想什么**：目标是电流 $i_L$，它正好是电感的状态量，起点直接由换路定则给出。另一个目标 $u_L(t)$ 是「响应量」而不是状态量——它要靠 $u_L = L\dfrac{di_L}{dt}$ 从 $i_L(t)$ 求出来，**不能**套三要素法。*（先看清目标是状态量还是响应量，决定了要不要另算一条。）*

**解：**

**① $i_L(0_+)=0$**（换路定则，电感电流不突变）。

**② $i_L(\infty)=E/R=10/100=0.1\,\text{A}$**（稳态电感短路）。

**③ $\tau=L/R=0.2/100=2\,\text{ms}$。**

**④** $i_L(t)=0.1\left(1-e^{-t/0.002}\right)=0.1\left(1-e^{-500t}\right)\,\text{A}$。

电感电压：$u_L=L\dfrac{di_L}{dt}=0.1\times500\,e^{-500t}\times0.2=10e^{-500t}\,\text{V}$。

**关键对比**：$i_L$ 和 $u_L$ 用**同一个 $\tau$**，但一个按指数上升、一个按指数衰减——$t=0_+$ 瞬间电感相当于**开路**（$u_L=E=10\,\text{V}$，电流还为零），稳态相当于**短路**（$u_L=0$）。

**验算（KVL + 两端点）**：任意时刻 $u_R + u_L = i_L R + u_L = 0.1(1-e^{-500t})\times100 + 10e^{-500t} = 10$ V $=E$ ✓；$t=0$ 时 $u_L = 10$ V、$i_L=0$ ✓；$t\to\infty$ 时 $u_L\to0$、$i_L\to0.1$ A ✓。

**求时间**：$0.05=0.1(1-e^{-500t})$ → $t=\dfrac{\ln 2}{500}=1.386\,\text{ms}$，正好是 $\tau$ 的一半不到（$0.693\tau$，因为目标是 50% 而非 63.2%）。
:::

**先想什么**：这题没有电源，所以「稳态」不是靠电容开路推出来的，而是**没有能量来源**——电容只能放到零为止。另外题目问「能量去哪了」，这是要你用能量守恒做一次验算，不是额外要算的东西。*（能量账就是这道题的验算。）*

**解：**

**① $u_C(0_+)=10\,\text{V}$；② $u_C(\infty)=0$**（没有电源，放到零为止）。

**③ $\tau=RC=10^4\times20\times10^{-6}=0.2\,\text{s}$。**

**④** $u_C(t)=0+(10-0)e^{-t/0.2}=10e^{-5t}\,\text{V}$。

- $t=0.1\,\text{s}$（半个 $\tau$）：$u_C=10e^{-0.5}=6.07\,\text{V}$。
- 降到 1 V：$e^{-5t}=0.1$ → $t=\dfrac{\ln 10}{5}=0.461\,\text{s}$，约 $2.3\tau$。

**能量账（这就是验算）**：电容初始储能 $W=\dfrac{1}{2}CU_0^2=\dfrac{1}{2}\times20\,\mu\text{F}\times100=1\,\text{mJ}$。随着 $t\to\infty$，$u_C\to0$，这 1 mJ **全部转化为电阻上的焦耳热**——放电过程就是电容储能在电阻里耗光的过程，这也解释了「为什么放电到零不需要外部做功」。

可以再核一次：初始电流 $i(0_+) = u_C(0_+)/R = 10/10\,000 = 1\,\text{mA}$，放电回路里的总热量 $W = \int_0^\infty i^2R\,dt = i_0^2R\tau/2 = 10^{-6}\times10^4\times0.2/2 = 1$ mJ ✓，与初始储能相等。
:::

**解：先画 $t\ge0$ 电路**：电源 $E$ → $R_1$ → 结点，结点下端并着 $R_2$ 和 $C$。

**先想什么**：这题有两个目标量，其中只有 $u_C$ 能套三要素法；$i_{R_1}$ 是响应量，必须回到电路现算。另外本题的真正考点是 $\tau$：$R_{eq}$ 要从**电容端口**看进去，而不是随手抓一个电阻。*（先把目标量分类，再决定每一项去哪张电路上算。）*

**① $u_C(0_+)=4\,\text{V}$**（换路定则，与位置 1 的稳态值相同）。

**② $u_C(\infty)$**：稳态电容开路，结点电压由 $R_1$、$R_2$ 分压决定：

$$
u_C(\infty)=E\cdot\frac{R_2}{R_1+R_2}=12\times\frac{2}{4}=6\,\text{V}
$$

**③ $\tau$**（本题的坑）：把电压源置零（短路）后，从电容两端看进去，$R_1$ 与 $R_2$ 是**并联**：

$$
R_{eq}=R_1\parallel R_2=\frac{2\times2}{2+2}=1\,\text{k}\Omega,\qquad \tau=R_{eq}C=10^3\times100\times10^{-6}=0.1\,\text{s}
$$

注意 $\tau$ 里用的是 1 kΩ，**不是** $R_1$ 或 $R_2$ 的 2 kΩ——从储能元件端口看进去，两个电阻都通向被短路的电源，所以并排。

**④ 代入**：

$$
u_C(t)=6+(4-6)e^{-t/0.1}=6-2e^{-10t}\,\text{V}
$$

**求 $i_{R_1}(t)$**：目标量不是储能元件，不能直接套公式，回到电路现算：

$$
i_{R_1}(t)=\frac{E-u_C(t)}{R_1}=\frac{12-(6-2e^{-10t})}{2000}=\left(3+e^{-10t}\right)\,\text{mA}
$$

**验算两个端点 + 一次 KCL**：$t=0_+$ 时 $i_{R_1}=(12-4)/2\,\text{k}=4\,\text{mA}$ ✓（此时 $i_{R_2}=4/2\,\text{k}=2\,\text{mA}$，剩下 2 mA 全灌进电容）；$t=\infty$ 时 $i_{R_1}=12/4\,\text{k}=3\,\text{mA}$ ✓（电容开路，$R_1$、$R_2$ 串联）；$t=0_+$ 的 KCL：流入 4 mA = $i_{R_2}$ 2 mA + $i_C$ 2 mA ✓。

**本题三个坑全踩了一遍**：$f(0_+)$ 由换路定则来、$f(\infty)$ 靠分压、$\tau$ 的 $R_{eq}$ 必须从电容端口看。少看一个，答案就错。

## 六、微分电路与积分电路（工程应用）

这一节讲三要素法的两个副产品：同一套电路，取输出电压的位置不同，就变成微分器或积分器。

| | 条件 | 输出取自 | 公式 | 波形变换 |
| --- | --- | --- | --- | --- |
| **微分电路** | $\tau \ll t_p$（脉冲宽度） | **电阻**两端 | $u_o \approx RC\dfrac{du_i}{dt}$ | 方波 → 尖脉冲 |
| **积分电路** | $\tau \gg t_p$ | **电容**两端 | $u_o \approx \dfrac{1}{RC}\int u_i dt$ | 方波 → 三角波 |

**为什么会这样**：

- **微分**电路：输出取自电阻 $u_R = RC\dfrac{du_C}{dt} \approx RC\dfrac{du_i}{dt}$。当 $\tau$ 远小于脉冲宽度时，电容两端电压几乎等于输入（电容「跟着」输入变），电流 $\dfrac{C\,du_i}{dt}$ 只在**边沿**上有尖峰 → 输出窄脉冲。
- **积分**电路：输出取自电容。当 $\tau$ 远大于脉冲宽度时，电容「来不及」充满，$u_C \approx \dfrac{1}{RC}\int u_i dt$ → 方波积出三角波。

::: tip 常见应用
- **微分**：边沿检测（数字电路里的单稳态/施密特触发器输入级）
- **积分**：PWM 生成、模拟-数字转换、脉冲宽度测量
:::

## 七、二阶电路预告（RLC 串联）

这一节只做一个预告：为什么三要素法不能用在 RLC 上。

当电路有 **2 个储能元件**（如 RLC 串联），三要素法失效，必须看**阻尼类型**：

| 阻尼 | 条件 | 响应 |
| --- | --- | --- |
| **过阻尼** $\zeta>1$ | $R>2\sqrt{L/C}$ | 两个指数，无振荡 |
| **临界** $\zeta=1$ | $R=2\sqrt{L/C}$ | 临界阻尼，最快无振荡 |
| **欠阻尼** $\zeta<1$ | $R<2\sqrt{L/C}$ | 衰减振荡 |

<FigBox title="欠阻尼衰减振荡" kind="曲线" note="RCL 串联中 R 越小越容易振荡（R 减小 → 阻尼减小 → 振荡加剧）。振幅按 e^(-ζωt) 衰减。">
<WavePreset kind="damped" :p="1.2" />
</FigBox>

**关键理解**：$R$ 越大越「迟钝」（过阻尼），$R$ 越小越「活泼」（欠阻尼振荡）。这与直觉相反 —— 很多人以为大电阻阻尼大，实际上**电阻消耗能量，阻尼能量来自 $R$**。

RLC 串联的交流分析（阻抗、谐振、品质因数）放在[第 09 章 · RLC 串联与阻抗](../04-ac/rlc.md)与[第 11 章 · 谐振与频率特性](../04-ac/resonance.md)。

这一节把本章最容易考的题型和它的第一步列在一起，考前扫一遍。

| 题型 | 关键 |
| --- | --- |
| 给定电路求 $u_C(t)$ 或 $i_L(t)$ | 直接三要素法 |
| 求「经过多久达到某值」 | $t = -\tau\ln\dfrac{f(t)-f(\infty)}{f(0_+)-f(\infty)}$ |
| 判断参数对快慢的影响 | 看 $\tau$（$R_{eq}$ 是从储能元件端口看的） |
| 求 $t=0_+$ 时的其他电压/电流 | **必须在 $t=0_+$ 等效电路上重算** |
| 开关接通瞬间的「冲击电流」 | $C=\to0$ 相当于短路；$L=\to\infty$ 相当于开路 |
| 判断是否一阶 | 数储能元件：1 个是一阶 |

## 易错点

按踩坑频率排序，每条给出「错误做法 → 会得到什么 → 正确做法」。

- $R_{eq}$ 必须是**从储能元件两端看进去**的等效电阻，不是随便抓一个电阻 → $\tau$ 差好几倍。
- $f(\infty)$ 是**换路后**的稳态，不是换路前 → 起点终点颠倒，曲线方向反了。
- 求 $f(0_+)$ 时如果目标量不是 $u_C$/$i_L$，它**可能突变**，必须在 $t=0_+$ 电路上重新算。
- 三要素法**只适用于一阶电路**（一个储能元件）；二阶（RLC）必须列微分方程。
- 电容放电时若 $\tau$ 太大，实际会因漏电流而比公式慢。
- 「开关接通瞬间电容相当于短路、电感相当于开路」—— 这说的是**电流/电压**的极端值，不是元件消失。
