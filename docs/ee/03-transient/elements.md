# 06 · 储能元件与换路定则

<Meta time="35 min" level="核心" note="RC/RL 的伏安关系点胶囊即看，这里补的是换路那一瞬间到底发生了什么" />

你在配电箱前拉下总闸，楼上空调的压缩机嗡嗡声停了，可你还听到一声很轻的「啪」，那是触点之间跳了个火花。同一时刻，手机充电器的指示灯闪了一下才彻底熄灭。火花从哪来？断开电源之后，充电器的灯为什么还会亮一下？这两件事都不是元件坏了，它们都是「换路瞬间」这个物理事实的后果。合闸、拉闸、拨开关，只要电路的连接方式突然变了，这类现象就跟着来。

要算清这些量，得会画 $t=0_-$ 与 $t=0_+$ 两张等效电路，也就是换路前后各画一张，中间那一瞬间被单独拎出来处理。

::: tip 读这页之前
会欧姆定律、会写基尔霍夫电压定律的回路方程、分得清电位与参考方向，换路前后那两张等效电路就画得出来（<Prereq id="ohm" />、<Prereq id="kvl" />、<Prereq id="potential" />）。数学只用求导和一个指数函数 $e^{-t/\tau}$；$e^x$ 是自然对数的反函数，知道它会递减就够了。

符号沿用全站约定（[符号与约定](../../guide/notation.md)）：

- $u_C$ 是电容两端电压，$i_L$ 是电感中电流，这两个是本页反复要盯的**状态量**。
- $E$ 电源电动势、$R$ 电阻、$C$ 电容（单位法拉 F）、$L$ 电感（单位亨利 H）、$W$ 能量（单位 J）。
- $0_-$ 是换路前的极限时刻，$0_+$ 是换路后的极限时刻。这两个下标是这一整页的主角。
- $\tau$（时间常数）的约定见[符号与约定](../../guide/notation.md#四、常用符号速查)，第四节会重新解释，因为它决定整条曲线的快慢。
:::

## 一、合闸那一瞬间，电压为什么跳不上去

设想最简单的一个电路：电源 $E$、电阻 $R$、电容 $C$ 串成一个回路，开关 $S$ 控制通断。合闸之前电容没充电，$u_C = 0$。合闸那一下，如果你拿示波器盯住电容两端，看到的不是从 0 跳到 $E$ 的一条竖线，而是一段慢慢爬上去的坡。

<FigBox title="电容电压为什么爬不上去" kind="直觉" note="把开关看作在 0 时刻突然闭合。注意曲线在起点不是竖直的——如果能瞬间跳到 E，那需要的电流是无穷大。">
<WavePreset kind="rc" :p="3" />
</FigBox>

物理上的原因很朴素：电容就是两块导体夹一层绝缘，导体上能「堆」电荷，而电压取决于堆了多少电荷、电容量有多大，$u_C = q/C$。要让电压在 0 时间里从 0 变成 $E$，等于要把 $q = CE$ 这么多个电荷一起搬上极板。搬电荷靠电流，$i = dq/dt$，0 时间搬完，电流就是无穷大。

无穷大的电流需要无穷大的电压（电阻上的 $u = Ri$），而电源 $E$ 的电压是有限的。这条路走不通。

能量这条线更硬。电容储能 $W_C = \dfrac12 Cu^2$，把端电压记作 $U$，同一个式子就是 $W = \dfrac12 CU^2$。电压从 0 跳到 $E$，能量要在 0 时间里从 0 变成 $\dfrac12 CE^2$，对应的功率 $P = \dfrac{dW}{dt} = \infty$。没有哪种电源能供出无穷大功率，这条物理上的路被堵死了。

电感是同一件事的镜像，只是角色换了。电感的电流建立了磁场，磁场里存着能量 $W = \dfrac12 Li^2$，写成状态量的形式就是 $W_L = \dfrac12 Li^2$。要让电流瞬间跳变，等于让这份能量瞬间出现或者瞬间消失，同样要求无穷大功率。

所以好用的口诀跟「电容管电压、电感管电流」这个说法不太一样：

> 谁储存能量，谁的状态量就不能突变。
> 电容存的是电场，用电角度量，所以电压连续；电感存的是磁场，用电流度量，所以电流连续。

至于电容的电流、电感的电压，它们量的是「外界要使多大劲才能改变内部状态」：电容电压想变，得靠电流搬电荷；电感电流想变，得靠电压建磁场。这两个量都是因变量，外界可以强行推着它们跳，只要电源够强。

::: warning 最容易错的一点
$u_C$ 连续、$i_L$ 连续，但 $i_C$ 和 $u_L$ 可以任意大地突变。

一个极端例子：用 1V 电源通过 0.1Ω 电阻给 1μF 电容充电，稳态电压 1V。断开后电容保持 1V。现在用一个理想电压源强行加 100V 上去，$i_C = C\dfrac{du}{dt}$ 的导数可以任意大，实际电流被外部电阻限制为 $100/0.1 = 1000\ \text{A}$。电压从 1V 跳到 100V，完全没有违背换路定则。
:::

「不能突变」的来源清楚了，下一步该问：这条规矩是怎么从元件本身的定义里长出来的。

## 二、三个元件的关系式从哪来

电容的 $i = C\dfrac{du}{dt}$ 不必背，它是个定义式，来历直白。

电容 $C$ 的定义是 $C = \dfrac{q}{u_C}$。$C$ 的单位法拉（F）等于库仑每伏，「每伏电压能存多少库仑电荷」，本质上是个几何量：平行板电容器 $C = \varepsilon S/d$，跟极板面积成正比、与极板间距成反比。对时间求导，电荷的变化率就是电流：$i = \dfrac{dq}{dt} = C\dfrac{du_C}{dt}$。

把 $i = C\dfrac{du}{dt}$ 再读一遍：电压变得越快，电流越大；电压停住不动，电流就是零。这句话后面反复要用。

电感 $L$ 那边也从一个定义出发：$L = \dfrac{\psi}{i}$，其中 $\psi = Ni$ 是磁链（线圈匝数 $N$ 乘以电流），$L$ 的单位亨利（H）等于韦伯每安培。它的物理是「线圈通电产生磁场，磁场变化又产生感应电动势阻碍电流变化」，所以电感的电压 $u = L\dfrac{di}{dt}$ 正比于电流的变化率，符号取正，表示它在阻碍变化。

| | 电阻 $R$ | 电容 $C$ | 电感 $L$ |
| --- | --- | --- | --- |
| 关系 | $u = Ri$ | $i = C\dfrac{du}{dt}$ | $u = L\dfrac{di}{dt}$ |
| 储能 | 无（耗散） | $\dfrac12 Cu^2$ | $\dfrac12 Li^2$ |
| 直流量纲 | 欧姆 | 法拉 | 亨利 |
| 直流稳态 | 通路 | 开路（$du/dt = 0 \Rightarrow i = 0$） | 短路（$di/dt = 0 \Rightarrow u = 0$） |
| 不能突变 | — | $u_C$ | $i_L$ |
| 常见直觉 | 「阻碍电流」 | 「阻碍电压变化」 | 「阻碍电流变化」 |

表里「直流稳态」那一行指的是：电路接在恒定电源上，而且已经过了足够长的时间，所有的量都不再变化。此时 $du/dt=0$、$di/dt=0$，那两格就是从定义式一步推出来的。电容那一行的 $i = C\dfrac{du}{dt}$ 与电感那一行的 $u = L\dfrac{di}{dt}$ 结构完全对称，都是「某一个量对时间求导」，只是求导的对象换了一个。

::: tip 三个「稳态等效」自己推一遍
不用记，看定义式：

- 电容在直流稳态下 $du_C/dt = 0$（电压不变），于是 $i = 0$，等效成开路。
- 电感在直流稳态下 $di_L/dt = 0$（电流不变），于是 $u = 0$，等效成短路。
- 电阻永远是 $u = Ri$，没有「稳态」可言。

考场上现推比背结论快，而且不会把两个记反。
:::

元件关系式齐了，下一步是把它们组装成一套能照着走的流程：从换路前一路推到换路后的各个量。

## 三、换路定则与求解流程

换路指电路连接方式发生改变的那一刻，开关闭合、断开、换档都算。求换路瞬间各个量的顺序是固定的：先算换路前的稳态，再用换路定则搬过去，最后在换路后的电路里求其余量。

**换路定则**只有两条，写成等式就是 $u_C(0_+) = u_C(0_-)$、$i_L(0_+) = i_L(0_-)$：

$$
\begin{cases}
u_C(0_+) = u_C(0_-) \\[4pt]
i_L(0_+) = i_L(0_-)
\end{cases}
$$

注意下标：$0_-$ 是换路前的极限时刻，$0_+$ 是换路后的极限时刻，中间的 $t=0$ 本身不参与运算，它是数学上不存在的那个瞬间。

::: tip 一条定律和一套方法，别混成一件事
真正不可违背的只有一条：能量不能瞬间增减，于是储能元件的状态量连续，即 $u_C$ 和 $i_L$ 不能突变。换路定则 $u_C(0_+)=u_C(0_-)$、$i_L(0_+)=i_L(0_-)$ 是把这条物理事实写成可操作的形式，而 $t=0_+$ 等效电路（电容换电压源、电感换电流源）是它的下一步操作。

抓住这条分界，这章就不会走偏：真正不能变的只有 $u_C$、$i_L$，其余量（$i_C$、$u_L$、各电阻上的电压电流）都可以在换路瞬间跳一下。
:::

### 标准四步

```
① t = 0₋ ：开关闭合足够久 → 直流稳态 → 电容开路、电感短路
            → 在这个电路里算出 u_C(0₋)、i_L(0₋)
② 换路定则 → u_C(0₊)、i_L(0₊) 直接抄 ① 的结果
③ 画 t = 0₊ 等效电路：电容 → 电压源 u_C(0₊)，电感 → 电流源 i_L(0₊)
④ 在这张图上求其余初始值：i_C(0₊)、u_L(0₊)、各支路电流……
```

第 ③ 步是整套流程的重心。很多人第 ① 步做得漂亮，一到第 ③ 步就卡住，原因几乎都是把「电容 = 开路」和「电容 = 电压源」混成了一句。第 ① 步里那句「足够久」的实际含义是：电容已经充到 $E$，电感电流已经稳在 $E/R$，此刻的电路退化成纯电阻电路，才好在上面做除法。

同一个电容在三个时刻有三种身份，对不上号就会乱：

| 时刻 | 电容等效成 | 理由 |
| --- | --- | --- |
| $t = 0_-$、直流稳态 | 开路 | 电流为零 |
| $t = 0_+$ 瞬间 | 电压源 $u_C(0_+)$ | 电压被「冻结」了 |
| $t \to \infty$ 稳态 | 开路 | 电流重新为零 |

电感完全同理：$0_-$ 短路，$0_+$ 换成电流源，$\infty$ 又回到短路。

::: tip 一个很好用的检查法
把 $t=0_+$ 电路画成「电容 = 电压源、电感 = 电流源」之后，如果算出来的电流或者电压是无穷大，那一定是哪处画错了。

道理很简单：换路瞬间外界提供的电压有限，电源就那么高；流过电容的电流可以很大，但被电阻限着，不可能无穷大。无穷大意味着电源电压无穷大，而它并不是。反过来，算出来正好是 0 倒不一定是错，纯 RL 接通那一瞬间 $u_L(0_+)$ 就是 0，那是真的。
:::

流程到这里就齐了。四道题走一遍，覆盖 RC 充电、RL 断电、RL 接通，以及带初始值的全响应。

## 四、例题

四道题按难度递进：例 1 是最标准的 RC 充电，例 2 是最容易出事故的 RL 断电，例 3 考一个反直觉的特例，例 4 把初值和稳态一起用上。每道题都要画两张图，$t=0_-$ 的稳态电路和 $t=0_+$ 的等效电路，两张图里的电阻组合常常不一样。每题的「先想什么」都是方法选择，比算出数字重要。

::: tip 例 1 · RC 充电电路的完整过程
题干：$E = 12\text{ V}$，$R = 2\,\text{k}\Omega$，$C = 10\,\mu\text{F}$。$t=0$ 时开关从「接 $E$」拨到「接另一个电压」，初值 $u_C(0_-) = 3\text{ V}$。求 $t=0_+$ 时的电流 $i(0_+)$、稳态电流、稳态电压，以及时间常数。

<CircuitFig kind="rc-charge" title="RC 充电回路：E、R、C 串联，S 在 t=0 时刻动作" note="先把电容当成电压源 u_C(0₊) 放进回路，再算初始电流；时间常数则要从电容端口看进去求等效电阻。" />

先想什么：题目问两件不同的事。「$t=0_+$ 的电流」要在 $0_+$ 的瞬时电路上算，「时间常数」却只由换路之后的电路结构决定，与 $u_C(0_+)$ 和 $E$ 的数值都无关。*（先把这两件事分开，就不会把初值也算进 $\tau$ 里。）*

解答

第 1 步：求 $t = 0_-$ 的电路状态

开关动作前电路已达直流稳态，电容开路，回路里没有电流，电阻上也就没有压降。

$$
u_C(0_-) = 3\ \text{V},\qquad i(0_-) = 0
$$

> **为什么这么想**
> 这里最容易犯的错是「电容开路」之后还去算电流。电容开路的含义就是它把回路切断了，回路电流必然为 0，开路不等于短路。
> 另外注意 $u_C(0_-) = 3\text{V}$ 是题目直接给的条件（初始储能），不用算。如果题目给的是「开关在 $t<0$ 接 $E_0=3$V」这种绕一层的说法，那才要回到那个电路去求。

第 2 步：换路定则

$$
u_C(0_+) = u_C(0_-) = 3\ \text{V}
$$

第 3 步：画 $t = 0_+$ 等效电路，求初始电流

把电容换成 $3\text{ V}$ 的电压源，也就是 $u_C(0_+)$，接上新回路的 $E = 12\text{ V}$ 和 $R = 2\,\text{k}\Omega$。

$$
i(0_+) = \frac{E - u_C(0_+)}{R} = \frac{12 - 3}{2000} = 4.5\ \text{mA}
$$

方向：电流从电源正极流出，给电容充电，因为 $E > u_C$。如果 $u_C(0_+) > E$，这个电流会是负的，说明电容在放电。符号会自动告诉你方向，不需要另外讨论。

第 4 步：时间常数

时间常数 $\tau$（time constant，时间常数：过渡过程按指数规律衰减到剩余 36.8% 所需的时间，单位秒）由换路之后电路的等效结构决定，与初始值无关：

$$
\tau = R_{\text{eq}} C
$$

$R_{\text{eq}}$ 是从电容端口看进去的等效电阻：把独立电压源短路、电流源开路之后，在电容两个端子之间量到的电阻。

从电容两端看进去，独立电压源被短路，只剩 $R$，所以 $R_{\text{eq}} = R = 2\,\text{k}\Omega$：

$$
\tau = 2000 \times 10\times 10^{-6} = 0.02\ \text{s} = 20\ \text{ms}
$$

第 5 步：稳态值

$t \to \infty$ 又回到直流稳态，电容开路，电流为 0，电阻压降也就为 0：

$$
i(\infty) = 0,\qquad u_C(\infty) = E = 12\ \text{V}
$$

第 6 步：写出全过程的表达式

$u_C$ 从 3 V 指数上升到 12 V：

$$
u_C(t) = u_C(\infty) + \big[u_C(0_+) - u_C(\infty)\big]e^{-t/\tau} = 12 - 9e^{-50t}\ \text{V}
$$

电流：

$$
i(t) = \frac{E - u_C(t)}{R} = \frac{9e^{-50t}}{2000} = 4.5e^{-50t}\ \text{mA}
$$

**验算（用换路定则与端点各查一次）**：$t=0$ 时 $u_C = 12-9 = 3$ V ✓，等于 $u_C(0_-)$，符合换路定则；$t \to \infty$ 时 $u_C = 12$ V ✓，等于稳态值；电流从 4.5 mA 衰减到 0 ✓。三条都对得上，答案才算站住。

**答**：$i(0_+) = 4.5\ \text{mA}$（充电方向），$i(\infty) = 0$，$u_C(\infty) = 12\text{V}$，$\tau = 20\ \text{ms}$。
:::

先想什么：这题的难点在认清电流往哪流，不在计算。断电前电流由电源推着走，断电后电源没了，电流不会凭空消失（$i_L$ 不能突变），它只能沿着新回路绕回来。所以 $i_L$ 的方向不变，$u_L$ 的极性却可能翻转，而 $u_L(0_+)$ 的符号正是第三问的关键。*（先定方向、再算数值，否则符号会错。$\tau$ 只跟换路之后的回路有关，与断电前无关。）*

解答

第 1 步：$t = 0_-$ 稳态

电感短路，回路里只剩 $R$：

$$
i_L(0_-) = \frac{E}{R} = \frac{12}{20} = 0.6\ \text{A},\qquad u_L(0_-) = 0
$$

第 2 步：换路定则

$$
i_L(0_+) = 0.6\ \text{A}
$$

注意电流方向：断电前电流由电源提供，方向是「电源 → R → L」。断电后电源没了，电流要衰减，但方向不变，电感会强迫它继续按原方向流，靠 $R_2$ 把储存的能量吃掉。所以 $i_L(t) = 0.6e^{-t/\tau}$ 始终为正。

第 3 步：$t = 0_+$ 电压

把电感换成 $0.6\text{A}$ 的电流源，此时回路里只有 $R_2$：

$$
u_L(0_+) = i_L(0_+) \times R_2 = 0.6 \times 50 = 30\ \text{V}
$$

::: danger 这里藏着工程事故
电源是 12 V，断电瞬间电感上却冒出 30 V，是电源电压的 2.5 倍，而且电流从 0.6 A 开始衰减，功率正处在最大处。

实际中开关触点断开时，这 30 V 会全部加在触点间隙上：触点分离，起电弧，触点烧蚀，严重时着火。继电器线圈、电磁铁这类感性负载必须并联一个续流二极管（一个只允许电流单向通过的半导体器件，给电流提供一条不经过开关的衰减通路），把 $u_L$ 钳位到 $0.7\text{V}$ 左右。

工程里给感性负载加续流二极管，全部理由就在这里：这不是标准规定的仪式，是换路定则的必然结果。
:::

第 4 步：时间常数与稳态

$$
\tau = \frac{L}{R_{\text{总}}} = \frac{0.1}{20 + 50} = \frac{0.1}{70} \approx 1.43\ \text{ms}
$$

$t \to \infty$ 时电感放电完毕：$i_L(\infty) = 0$，$u_L(\infty) = 0$。

$$
i_L(t) = 0.6\,e^{-t/1.43\text{ms}}\ \text{A},\qquad u_L(t) = 30\,e^{-t/1.43\text{ms}}\ \text{V}
$$

第 5 问：$R_2 = 1\,\text{k}\Omega$

$$
u_L(0_+) = 0.6 \times 1000 = 600\ \text{V}
$$

电源还是 12 V，只把电阻换大，电感上就冒出 600 V。这个倍数关系 $u_L(0_+) = i_L(0_+)R_2$ 就是继电器触点被击穿的直接原因。

**验算（用能量守恒查一次）**：断电瞬间电感里存着 $W_L = \tfrac12 Li^2 = \tfrac12\times0.1\times0.36 = 18$ mJ。放电回路的 $R_{\text{总}} = 70\ \Omega$，初始电流 0.6 A，全部能量最终都变成电阻上的热：$W = \int_0^\infty i^2R\,dt = 0.36\times0.1/2 = 18$ mJ ✓（这里用到 $\int_0^\infty (I_0e^{-t/\tau})^2 R\,dt = \tfrac12 LI_0^2$）。另外 $u_L(0_+) = 30$ V 由 $i_L(0_+)\times R_2$ 得到，与电阻上的压降对得上 ✓。

**答**：$i_L(0_+)=0.6\text{A}$、$u_L(0_+)=30\text{V}$、$\tau\approx1.43\text{ms}$；换成 $1\text{k}\Omega$ 时 $u_L(0_+)=600\text{V}$。
:::

::: tip 例 3 · RL 接通瞬间 $u_L$ 到底多大
题干：$E = 10\text{V}$、$R = 100\,\Omega$、$L = 1\text{H}$。求 $u_L(0_+)$、$u_R(0_+)$、$i(0_+)$、$u_L(\infty)$。

<FigBox title="RL 接通：电流从 0 爬到 E/R，电感电压从 E 落回 0" kind="曲线" note="两条曲线共用同一个时间常数 τ = L/R。一条上升一条下降，起点和终点正好互换——这就是「电压电阻独吞、电流慢慢建立」的样子。">
<WavePreset kind="rl" :p="1.2" />
</FigBox>

先想什么：题眼是「刚合上开关的那一瞬间，电流还没来得及建立」。$i_L$ 不能突变，所以合闸瞬间电流仍然是 0，电源电压全部落在电阻上。*（先判断电流有没有建立起来，比套公式快得多。）*

解答

$t=0_+$：电感是 $i(0_+)=E/R=0.1\text{A}$ 的电流源。

$$
u_L(0_+) = E - i(0_+)R = 10 - 0.1\times 100 = 10 - 10 = 0
$$

注意这里答案是 0。而 $u_R(0_+) = i(0_+)R = 0.1\times100 = 10\text{V}$，全部电压加在电阻上，电感两端 $u_L(0_+) = 0$。

这是纯 RL 电路接通时的特例：电流不能突变，初始电流为 0，所以电感瞬间完全不反抗，电压全给了电阻。等电流建立起来，$u_L$ 才逐渐升上去，稳态时又衰减为 0。

> **这个特例值得单独记**：纯 RL 接通瞬间，$u_R(0_+) = E$、$u_L(0_+) = 0$；纯 RC 接通瞬间，$u_C(0_+) = 0$（若初始无电荷）、$u_R(0_+) = E$。两句话说的是同一件事，电阻独吞了全部电压。

$\tau = L/R = 1/100 = 10\ \text{ms}$，稳态 $i(\infty) = E/R = 0.1\text{A}$、$u_L(\infty) = 0$。

**验算（用伏安关系查一次）**：$t=0_+$ 时回路里 $u_R + u_L = 10 + 0 = 10$ V $=E$ ✓，KVL 闭合；$t \to \infty$ 时 $u_R = iR = 10$ V、$u_L = 0$，加起来还是 10 V ✓。
:::

::: tip 例 4 · 综合：含初始值的全响应
题干：$t<0$ 时开关接在 $E_1 = 6\text{V}$ 上已达稳态；$t=0$ 时开关转到 $E_2 = 10\text{V}$（同向串联，$R = 1\,\text{k}\Omega$、$C = 1\,\mu\text{F}$）。求 $u_C(t)$ 与 $i(t)$，并求 $t = 5\text{ms}$ 时的 $u_C$。

<CircuitFig kind="rc-charge" title="换路后的 RC 回路：换路后只有 E₂、R、C 三件" note="时间常数只看换路之后的结构：把 E₂ 短路，从电容端口看进去就是 R 一个电阻，与换路前的 E₁ 无关。" />

先想什么：这题最容易错的地方是把「$t<0$ 的稳态」和「$t\to\infty$ 的稳态」混成一个：前者是起点 6 V，后者是终点 10 V。中间还夹着一个容易漏的细节，$\tau$ 要从 $R_{eq}$ 算，而 $R_{eq}$ 要把两个电源都置零。*（起点、终点、速度分别来自三张不同的电路，别互相借用。）*

解答

$t=0_-$：电容开路，无电流，无压降，所以 $u_C(0_-) = E_1 = 6\text{V}$。

换路：$u_C(0_+) = 6\text{V}$。

时间常数：从电容看进去，$E_1$、$E_2$ 都短路，$R_{\text{eq}} = R = 1\,\text{k}\Omega$：

$$
\tau = RC = 10^3 \times 10^{-6} = 1\ \text{ms}
$$

稳态：$u_C(\infty) = E_2 = 10\text{V}$，$i(\infty) = 0$。

全响应：

$$
u_C(t) = 10 + (6 - 10)e^{-t/1\text{ms}} = 10 - 4e^{-1000t}\ \text{V}
$$

$$
i(t) = \frac{E_2 - u_C(t)}{R} = \frac{4e^{-1000t}}{1000} = 4e^{-1000t}\ \text{mA}
$$

求 $t = 5\text{ms}$：此时 $t/\tau = 5$，过程基本走完了：

$$
u_C(5\text{ms}) = 10 - 4e^{-5} = 10 - 4\times 0.0067 = 9.97\ \text{V}
$$

> **为什么 5τ 就当成完成**
> $e^{-5} = 0.0067$，即还差 0.67%。工程上误差小于 1% 就算稳态，所以「5τ 后过程结束」是个够用的工程判据。考试里若选项是「10 → 9.8 → 9.97 → 10」，选 9.97。

**验算（查两个端点和一条 KVL）**：$t=0_+$ 时 $u_C = 10-4 = 6$ V ✓，等于 $u_C(0_-)$；$t\to\infty$ 时 $u_C = 10$ V ✓；任意时刻 $u_C + iR = 10$ V ✓，KVL 闭合。
:::

四道题走完，换路那一瞬间的账你应该能自己算了。最后把工程上真会碰到的几种现象对回这张表。

## 五、工程上碰到的那几种现象

| 场景 | 现象 | 换路定则的解释 | 解决办法 |
| --- | --- | --- | --- |
| 开关断开感性负载 | 触点电弧、烧蚀 | $i_L$ 不能突变，电压飙升到 $i_L R_2$ | 并联续流二极管 / RC 吸收 / 压敏电阻 |
| 开关接通大电容 | 触点抖动、熔丝烧断 | 瞬间短路电流 $E/R_{\text{内阻}}$ | 串联限流电阻、预充电电路、软启动 |
| 电容放电回路 | 残余电压伤人 | 电容存了 $\tfrac12 CU^2$ | 泄放电阻 + 断电后等待 5τ |
| DC-DC 输出突然断电 | 输出电容放电，负载掉电 | 电容电压衰减 | 保持时间由 $RC$ 决定 |
| 变压器副边开路 | 一次侧电流剧增 | 副边电流突变 → 磁通突变 → 一次侧涌流 | 励磁涌流，负载投入前需预磁化 |

表里第一行那个电弧，就是开头拉总闸时听到的那声「啪」。第三行说的泄放电阻，是检修电工拆机前必须先等几分钟的原因：电容上的电不会因为你拔了插头就消失，它得通过电阻慢慢放掉，放够 5τ 残压已经不到 1%，但严格说永远到不了 0，所以规程上要求的是「等够时间」，而不是「看一眼指示灯灭没灭」。

## 六、容易踩的坑

按踩坑频率排，每条给「错误做法 → 会得到什么 → 正确做法」。

1. 把「电容开路」用到 $0_+$ 上 → 需要求的初始电流算成 0 → $0_+$ 时电容是电压源，不是开路。
2. $\tau$ 算错电路 → 数量级差好几倍 → $R_{\text{eq}}$ 要从储能元件两端看进去，且独立源置零（电压源短路、电流源开路），置零之后那条支路上的电压就是 0，它不再影响等效电阻。
3. 初始值用 $0_-$ 而不是 $0_+$ → 求出的 $i_C(0_+)$、$u_L(0_+)$ 全错 → 这两个量必须在 $0_+$ 电路里求。
4. 以为「能量不能突变」能推出「功率也不能突变」 → 误判 $i_C$、$u_L$ 也不能跳变 → 能量不能突变是对的，但 $i_C$、$u_L$ 不储能，它们在 $0_+$ 与 $0_-$ 的值本来就可以不同。
5. 把初始值算进时间常数 → 以为换路前电压高一点，过程就会慢一点 → $RC$ 只看电路结构，与 $u_C(0_+)$ 和 $E$ 的大小无关。
