# 06 · 储能元件与换路定则

<Meta time="35 min" level="核心" note="RC/RL 伏安关系点胶囊即看，这里补的是『换路瞬间到底发生了什么』" />

## 结论先行

1. **电容**：$i = C\dfrac{du}{dt}$，储能 $W_C = \dfrac12 Cu^2$，**电压不能突变**
2. **电感**：$u = L\dfrac{di}{dt}$，储能 $W_L = \dfrac12 Li^2$，**电流不能突变**
3. **换路定则**：$u_C(0_+) = u_C(0_-)$，$i_L(0_+) = i_L(0_-)$
4. 换路瞬间的等效替换：电容 → 电压源，电感 → 电流源；**其余量都可以突变**
5. 直流稳态：电容**开路**、电感**短路**

但这五条只是答案。真正的问题不是"记住它们"，而是——

> **为什么偏偏是电容的电压、电感的电流不能突变，而它们的另一半可以？**

这一页要回答的就是这个问题。理解了它，换路定则就不是要背的规矩，而是自然结果。

::: tip 规律层：一条定律 + 一套方法，别混为一谈
- **定律（不可违背）**：能量不能瞬间增减 → 储能元件的**状态量**连续，即 $u_C$ 和 $i_L$ 不能突变。
- **方法（解题工具）**：换路定则 $u_C(0_+)=u_C(0_-)$、$i_L(0_+)=i_L(0_-)$，以及 $t=0_+$ 等效电路（电容→电压源、电感→电流源）。
后者只是前者的**操作化**——真正不能变的只有 $u_C$、$i_L$，其余量（$i_C$、$u_L$、各电阻的电压电流）都可以突变。抓住这条分界，这章就不会错。
:::

## 一、开关"啪"地合上，电路里发生了什么

设想最简单的一个电路：电源 $E$、电阻 $R$、电容 $C$ 串成一个回路，开关 $S$ 控制通断。

合闸之前，电容没充电，$u_C = 0$。合闸的一瞬间，你如果拿示波器去看电容两端，会发现电压**不是从 0 瞬间跳到 $E$**，而是用一段时间慢慢爬上去。

<FigBox title="电容电压为什么爬不上去" kind="直觉" note="把开关看作在 0 时刻突然闭合。注意曲线在起点不是竖直的——如果能瞬间跳到 E，那需要的电流是无穷大。">
<WavePreset kind="rc" :p="3" />
</FigBox>

物理上的原因很朴素：**电容是用一块导体和另一块导体夹起来的，导体上能"堆"电荷。** 电压就是这块导体堆了多少电荷除以电容决定的。要让电压瞬间从 0 变成 $E$，等于要在零时间内把 $q = CE$ 这么多个电荷搬到极板上。搬电荷靠的是电流，$i = dq/dt$ —— 零时间搬完，电流无穷大。

**无穷大的电流需要无穷大的电压**（电阻上的 $u = Ri$），而电源电压有限。所以做不到。

**能量角度更狠**：电容储能 $W = \dfrac12 CU^2$。电压从 0 瞬间跳到 $E$，能量从 0 瞬间变成 $\dfrac12 CE^2$，而这段时间是零，功率 $P = \dfrac{dW}{dt} = \infty$。**没有任何电源能提供无穷大功率**，所以这条路被物理堵死了。

对电感完全对称，只是换了角色：

电感的电流不能突变，因为电流建立了磁场、磁场里存着能量 $W = \dfrac12 Li^2$。要让电流瞬间跳变，等于让能量瞬间出现/消失，同样要求无穷大功率。

**所以记忆口诀不是"电容管电压、电感管电流"，而是：**

> **谁储存能量，谁的状态量就不能突变。**
> 电容存的是"电场"，用电压度量 → 电压连续。
> 电感存的是"磁场"，用电流度量 → 电流连续。

至于电容的**电流**和电感的**电压**，它们是"外界要多大劲才能改变内部状态"的度量——电容电压想变，需要电流去搬电荷；电感电流想变，需要电压去建立磁场。这两个量都是**因变量**，外界可以强行推着它们跳变（只要你的电源够强）。

::: warning 最容易错的一点
$u_C$ 连续、$i_L$ 连续，但 **$i_C$ 和 $u_L$ 可以无限大地突变**。

一个极端例子：用 1V 电源通过 0.1Ω 电阻给 1μF 电容充电，稳态电压 1V。断开后电容保持 1V。现在用一个理想电压源强行加 100V 上去，$i_C = C\dfrac{du}{dt}$ 的导数可以任意大，实际电流被外部电阻限制为 $100/0.1 = 1000\ \text{A}$。电压从 1V 跳到 100V，完全没有违背换路定则。
:::

## 二、元件特性的来历

不要背 $i = C\dfrac{du}{dt}$，它是**定义式**，来历很直白：

电容定义式：$C = \dfrac{q}{u_C}$。$C$ 的单位是法拉（F）= 库仑/伏特 —— "每伏电压能存多少库仑电荷"，本质是个几何量（平行板电容器 $C = \varepsilon S/d$，跟极板面积成正比、与间距成反比）。

对时间求导：$i = \dfrac{dq}{dt} = C\dfrac{du_C}{dt}$。

电感：$L = \dfrac{\psi}{i}$，$\psi = Ni$ 是磁链，$L$ 单位亨利（H）= 韦伯/安培。电感的物理是"线圈通电产生磁场，磁场又产生感应电动势阻碍电流变化"，所以**电感的电压正比于电流的变化率**，符号为正（阻碍变化）。

| | 电阻 $R$ | 电容 $C$ | 电感 $L$ |
| --- | --- | --- | --- |
| 关系 | $u = Ri$ | $i = C\dfrac{du}{dt}$ | $u = L\dfrac{di}{dt}$ |
| 储能 | 无（耗散） | $\dfrac12 Cu^2$ | $\dfrac12 Li^2$ |
| 直流量纲 | 欧姆 | 法拉 | 亨利 |
| 直流稳态 | 通路 | **开路**（$du/dt = 0 \Rightarrow i = 0$） | **短路**（$di/dt = 0 \Rightarrow u = 0$） |
| 不能突变 | — | $u_C$ | $i_L$ |
| 常见直觉 | "阻碍电流" | "阻碍电压变化" | "阻碍电流变化" |

::: tip 三个「稳态等效」的快速推导
不用记，看定义式就能推：

- 电容在直流稳态下：$du_C/dt = 0$（电压不变）→ $i = 0$ → **开路**
- 电感在直流稳态下：$di_L/dt = 0$（电流不变）→ $u = 0$ → **短路**
- 电阻：永远是 $u = Ri$，没有"稳态"可言

这个推导在考试里比你背结论快，而且不会记反。
:::

## 三、换路定则的严格表述与求解流程

### 换路定律

$$
\begin{cases}
u_C(0_+) = u_C(0_-) \\[4pt]
i_L(0_+) = i_L(0_-)
\end{cases}
$$

注意下标：$0_-$ 是换路**前**的极限时刻，$0_+$ 是换路**后**的极限时刻。中间的 $t=0$ 本身不参与运算（是个"数学上不存在的瞬间"）。

### 标准四步流程

```
① t = 0₋ ：开关闭合足够久 → 直流稳态 → 电容开路、电感短路
            → 在这个电路里算出 u_C(0₋)、i_L(0₋)
② 换路定则 → u_C(0₊)、i_L(0₊) 直接抄 ① 的结果
③ 画 t = 0₊ 等效电路：电容 → 电压源 u_C(0₊)，电感 → 电流源 i_L(0₊)
④ 在这张图上求其余初始值：i_C(0₊)、u_L(0₊)、各支路电流……
```

**第 ③ 步是整个流程的核心。** 很多同学第 ① 步会做，但一到第 ③ 步就懵，原因是把"电容=开路"和"电容=电压源"搞混了：

| 时刻 | 电容等效成 | 理由 |
| --- | --- | --- |
| $t = 0_-$、直流稳态 | **开路** | 电流为零 |
| $t = 0_+$ 瞬间 | **电压源** $u_C(0_+)$ | 电压被"冻结"了 |
| $t \to \infty$ 稳态 | **开路** | 电流重新为零 |

电感同理：$0_-$ 短路 → $0_+$ 电流源 → $\infty$ 短路。

::: tip 一个极好用的检查法
**把 $t=0_+$ 电路画成"电容=电压源、电感=电流源"之后，如果发现电流无穷大或者电压无穷大，一定是某处画错了。**

因为在换路瞬间，外界提供的电压有限（电源就那么高），流过电容的电流虽然可以很大（被电阻限制），但不可能无穷大——无穷大意味着电源电压无穷大。同理电感电压也不会无穷大。
:::

## 四、例题

::: tip 例 1 · RC 充电电路的完整过程
**题干**：$E = 12\text{ V}$，$R = 2\,\text{k}\Omega$，$C = 10\,\mu\text{F}$。$t=0$ 时开关从"接 $E$"拨到"接另一个电压"，初值 $u_C(0_-) = 3\text{ V}$。求 $t=0_+$ 时的电流 $i(0_+)$、稳态电流、稳态电压，以及时间常数。

**解答**

**第 1 步：求 $t = 0_-$ 的电路状态**

开关动作前电路已达直流稳态 → 电容开路 → **回路中没有电流** → 电阻上没有压降。

$$
u_C(0_-) = 3\ \text{V},\qquad i(0_-) = 0
$$

> **为什么这么想**
> 这里最容易犯的错是"电容开路"之后还去算电流。电容开路的含义就是：它把回路切断了，回路电流必然为 0。开路 ≠ 短路。
> 另外注意 $u_C(0_-) = 3\text{V}$ 是题目**直接给的条件**（初始储能），不用算。如果题目给的是"开关在 $t<0$ 接 $E_0=3$V"这样，就要回到那个电路去求。

**第 2 步：换路定则**

$$
u_C(0_+) = u_C(0_-) = 3\ \text{V}
$$

**第 3 步：画 $t = 0_+$ 等效电路并求初始电流**

把电容换成 $3\text{ V}$ 的电压源，接上新回路的 $E = 12\text{ V}$ 和 $R = 2\,\text{k}\Omega$。

$$
i(0_+) = \frac{E - u_C(0_+)}{R} = \frac{12 - 3}{2000} = 4.5\ \text{mA}
$$

**方向**：电流从电源正极流出、给电容充电（因为 $E > u_C$）。如果 $u_C(0_+) > E$，这个电流会是负的——说明电容在**放电**，符号自动告诉你方向，不需要额外讨论。

**第 4 步：时间常数**

时间常数由 $t=0_+$ 之后电路的**等效结构**决定，与初始值无关：

$$
\tau = R_{\text{eq}} C
$$

从电容两端看进去，把独立电压源短路，$R_{\text{eq}} = R = 2\,\text{k}\Omega$：

$$
\tau = 2000 \times 10\times 10^{-6} = 0.02\ \text{s} = 20\ \text{ms}
$$

**第 5 步：稳态值**

$t \to \infty$ 又是直流稳态 → 电容开路 → 电流为 0 → 电阻压降为 0：

$$
i(\infty) = 0,\qquad u_C(\infty) = E = 12\ \text{V}
$$

**第 6 步：写出全过程的表达式**

$u_C$ 从 3 V 指数上升到 12 V：

$$
u_C(t) = u_C(\infty) + \big[u_C(0_+) - u_C(\infty)\big]e^{-t/\tau} = 12 - 9e^{-50t}\ \text{V}
$$

电流：

$$
i(t) = \frac{E - u_C(t)}{R} = \frac{9e^{-50t}}{2000} = 4.5e^{-50t}\ \text{mA}
$$

**核对**：$t=0$ 时 $u_C = 3$ ✓，$t \to \infty$ 时 $u_C = 12$ ✓，电流从 4.5 mA 衰减到 0 ✓。三条都对上了。

**答**：$i(0_+) = 4.5\ \text{mA}$（充电方向），$i(\infty) = 0$，$u_C(\infty) = 12\text{V}$，$\tau = 20\ \text{ms}$。
:::

::: tip 例 2 · RL 电路断电瞬间
**题干**：线圈 $L = 100\ \text{mH}$、$R = 20\,\Omega$ 接在 $E = 12\text{V}$ 上已达稳态。$t=0$ 断开电源，但线圈还通过一个 $R_2 = 50\,\Omega$ 的电阻构成回路。求：

1. $i_L(0_+)$、$i_L(\infty)$、$u_L(0_+)$、$u_L(\infty)$
2. 时间常数
3. 如果 $R_2$ 换成 $1\,\text{k}\Omega$，$u_L(0_+)$ 变成多少

**解答**

**第 1 步：$t = 0_-$ 稳态**

电感短路 → 回路里只剩 $R$：

$$
i_L(0_-) = \frac{E}{R} = \frac{12}{20} = 0.6\ \text{A},\qquad u_L(0_-) = 0
$$

**第 2 步：换路定则**

$$
i_L(0_+) = 0.6\ \text{A}
$$

**注意电流方向**：断电前电流由电源提供，方向是"电源 → R → L"。断电后电源没了，电流要衰减，但它**方向不变**——电感会强迫电流继续按原方向流动，靠 $R_2$ 消耗掉储存的能量。所以 $i_L(t) = 0.6e^{-t/\tau}$ 始终为正。

**第 3 步：$t = 0_+$ 电压**

把电感换成 $0.6\text{A}$ 的电流源。此时回路只有 $R_2$：

$$
u_L(0_+) = i_L(0_+) \times R_2 = 0.6 \times 50 = 30\ \text{V}
$$

::: danger 这里藏着工程事故
电源是 12 V，断电瞬间电感上却冒出 30 V —— **电压是电源的 2.5 倍**，而且电流从 0.6 A 开始衰减，功率最大。

实际中开关触点断开时，这 30 V 会全部加在触点间隙上：触点分离 → 电弧 → 触点烧蚀、火灾。继电器线圈、电磁铁这类感性负载**必须并联一个续流二极管**，给电流提供一条不经过开关的衰减通路，把 $u_L$ 钳位到 $0.7\text{V}$ 左右。

**这就是"工程里为什么要给感性负载加续流二极管"的全部理由**——不是标准规定，是换路定则的必然结果。
:::

**第 4 步：时间常数与稳态**

$$
\tau = \frac{L}{R_{\text{总}}} = \frac{0.1}{20 + 50} = \frac{0.1}{70} \approx 1.43\ \text{ms}
$$

$t \to \infty$ 时电感放电完毕：$i_L(\infty) = 0$，$u_L(\infty) = 0$。

$$
i_L(t) = 0.6\,e^{-t/1.43\text{ms}}\ \text{A},\qquad u_L(t) = 30\,e^{-t/1.43\text{ms}}\ \text{V}
$$

**第 5 问：$R_2 = 1\,\text{k}\Omega$**

$$
u_L(0_+) = 0.6 \times 1000 = 600\ \text{V}
$$

**同样 12 V 的电源，换个大电阻就冒出 600 V。** 这个倍数关系 $u_L(0_+) = i_L(0_+)R_2$ 就是继电器触点被击穿的直接原因。

**答**：$i_L(0_+)=0.6\text{A}$、$u_L(0_+)=30\text{V}$、$\tau\approx1.43\text{ms}$；换成 $1\text{k}\Omega$ 时 $u_L(0_+)=600\text{V}$。
:::

::: tip 例 3 · RL 接通瞬间 u_L 到底多大
**题干**：$E = 10\text{V}$、$R = 100\,\Omega$、$L = 1\text{H}$。求 $u_L(0_+)$、$u_R(0_+)$、$i(0_+)$、$u_L(\infty)$。

**解答**

$t=0_+$：电感是 $0.6\text{A}$（本例 $i(0_+)=E/R=0.1\text{A}$）的电流源。

$$
u_L(0_+) = E - i(0_+)R = 10 - 0.1\times 100 = 10 - 10 = 0
$$

**注意这里答案是 0！** 而且 $u_R(0_+) = i(0_+)R = 0.1\times100 = 10\text{V}$ —— 全部电压加在电阻上，电感两端是 0。

**这是纯 RL 电路接通时的特例**：电流不能突变，初始电流为 0，所以瞬间电感完全"不反抗"，全部电压都给了电阻，$u_L(0_+) = 0$。等到电流建立起来，$u_L$ 才逐渐升到 $E$，稳态时衰减为 0。

> **这个特例值得单独记**：纯 RL 接通瞬间，$u_R(0_+) = E$、$u_L(0_+) = 0$；纯 RC 接通瞬间，$u_C(0_+) = 0$（若初始无电荷）、$u_R(0_+) = E$。**都是"电阻独吞全部电压"**。

$\tau = L/R = 1/100 = 10\ \text{ms}$，稳态 $i(\infty) = E/R = 0.1\text{A}$、$u_L(\infty) = 0$。
:::

::: tip 例 4 · 综合：含初始值的全响应
**题干**：$t<0$ 时开关接在 $E_1 = 6\text{V}$ 上已达稳态；$t=0$ 时开关转到 $E_2 = 10\text{V}$（同向串联，$R = 1\,\text{k}\Omega$、$C = 1\,\mu\text{F}$）。求 $u_C(t)$ 与 $i(t)$，并求 $t = 5\text{ms}$ 时的 $u_C$。

**解答**

**$t=0_-$**：电容开路 → 无电流 → 无压降 → $u_C(0_-) = E_1 = 6\text{V}$。

**换路**：$u_C(0_+) = 6\text{V}$。

**时间常数**：从电容看进去，$E_1$、$E_2$ 都短路，$R_{\text{eq}} = R = 1\text{k}\Omega$：

$$
\tau = RC = 10^3 \times 10^{-6} = 1\ \text{ms}
$$

**稳态**：$u_C(\infty) = E_2 = 10\text{V}$，$i(\infty) = 0$。

**全响应**：

$$
u_C(t) = 10 + (6 - 10)e^{-t/1\text{ms}} = 10 - 4e^{-1000t}\ \text{V}
$$

$$
i(t) = \frac{E_2 - u_C(t)}{R} = \frac{4e^{-1000t}}{1000} = 4e^{-1000t}\ \text{mA}
$$

**求 $t = 5\text{ms}$**：此时 $t/\tau = 5$，已经基本完成：

$$
u_C(5\text{ms}) = 10 - 4e^{-5} = 10 - 4\times 0.0067 = 9.97\ \text{V}
$$

> **为什么 5τ 就当成完成**
> $e^{-5} = 0.0067$，即还差 0.67%。工程上误差小于 1% 就算稳态，所以"5τ 后过程结束"是个够用的工程判据。考试里若选项是"10 → 9.8 → 9.97 → 10"，选 9.97。
:::

## 五、工程实例速览

| 场景 | 现象 | 换路定则的解释 | 解决办法 |
| --- | --- | --- | --- |
| 开关断开感性负载 | 触点电弧、烧蚀 | $i_L$ 不能突变，电压飙升到 $i_L R_2$ | 并联续流二极管 / RC 吸收 / 压敏电阻 |
| 开关接通大电容 | 触点抖动、熔丝烧断 | 瞬间短路电流 $E/R_{\text{内阻}}$ | 串联限流电阻、预充电电路、软启动 |
| 电容放电回路 | 残余电压伤人 | 电容存了 $\tfrac12 CU^2$ | 泄放电阻 + 断电后等待 5τ |
| DC-DC 输出突然断电 | 输出电容放电，负载掉电 | 电容电压衰减 | 保持时间由 $RC$ 决定 |
| 变压器副边开路 | 一次侧电流剧增 | 副边电流突变 → 磁通突变 → 一次侧涌流 | 励磁涌流，负载投入前需预磁化 |

## 六、易错清单

1. **把"电容开路"用到 $0_+$ 上** → $0_+$ 电容是电压源，不是开路
2. **$\tau$ 算错电路**：$R_{\text{eq}}$ 要从**储能元件两端**看进去，且**独立源置零**（电压源短路、电流源开路）
3. **初始值用 $0_-$ 而不是 $0_+$**：$i_C(0_+)$、$u_L(0_+)$ 必须在 $0_+$ 电路里求
4. **认为"能量不能突变"就推出"功率不能突变"**：能量不能突变是对的，但注意 $i_C$、$u_L$ 可以突变（它们不储能）
5. **时间常数与初始值无关**：$RC$ 只看电路结构，不看 $u_C(0_+)$ 和 $E$ 是多少
6. **三要素法的三个"稳态值"要分清**：$u_C(\infty)$、$u_C(0_+)$ 是"状态量"；$i(\infty)$、$i(0_+)$ 是"响应量"，必须靠 KCL/KVL 在对应电路里算

- [ ] 能说清 $t = 0_-$ 与 $t = 0_+$ 电路该怎么画，两者差别在哪
- [ ] 给一个 RC/RL 电路，能立刻报出 $\tau$ 并说清 $\tau$ 从哪看进去算
