# 电工学

<Meta time="3 min" level="指南" note="先花 3 分钟看清全局，比直接开读省 2 小时" />

电工学管的是「电从发电厂走到用电设备」这一路：电路定律 → 交流稳态 → 三相 → 磁路与变压器 → 电机 → 继电器与 PLC 控制。它以强电与工程视角为主线，不碰器件与放大，后者分别由[模拟电子](../analog/)和[数字电路](../digital/)承担。

## 读完能做什么

- 拿到一张直流电路图，能判断该用什么方法解（等效化简、结点电压、戴维南），并算对功率与方向；
- 遇到一阶动态电路，能用三要素法一次写出 $u_C(t)$、$i_L(t)$，包括换路前后的初值；
- 正弦稳态下把电路翻译成相量、阻抗与功率三角形，解释清楚功率因数为什么重要；
- 对称三相电路里熟练使用 $\sqrt 3$ 与 30° 的关系，知道中性点位移为什么会烧设备；
- 看懂变压器与异步电动机的铭牌、机械特性，以及继电接触器/PLC 的自锁互锁逻辑。

## 与电子课程的分工

| 与电子课程重叠（速通过） | 电工学主场（深做） |
| --- | --- |
| 相量 / 频率响应 / 阻抗 | 三相电路（对称性思维） |
| RC/RL 一阶响应 | 磁路与变压器（电 → 磁 → 电） |
| 器件级分析 | 电机（旋转磁场与机械特性） |
| 运放 / 放大 | 功率与功率因数（工程视角） |
| 二极管整流 | 继电接触器 / PLC（强电控制逻辑） |

学过电子课程的同学，右列才是要补的。零基础则从 01 顺序读到 26 最稳，前置知识都有胶囊兜底，遇到不懂的点开就看，不用跳走查资料。

## 相关实验与专题

电工学大部分结论都能在桌面上用两台仪器验一遍，所以它和实验板块、项目专题的接点最多：

- 可调实验电源（[/topics/power-supply](../topics/power-supply)）：第 23 章整流滤波稳压讲了一半，另一半在这里。变压器变比、纹波 $\Delta U \approx I_L/(fC)$、功率管的热阻，全都要落到选型参数上。做完这台电源，第 16 章变压器与第 23 章才真正长在手上。
- 万用表（[/lab/multimeter](../lab/multimeter)）：第 03 章串并联等效、第 10 章功率与功率因数的结论，用一块表就能验证。反过来，它也会告诉你纸面为什么是理想值，接触电阻、表内阻分压这些误差源在那里讲得最细。
- 实验台与安全（[/lab/bench](../lab/bench)）：第 22 章安全用电的工程版，强电弱电分区、保险丝与限流、电容放电的顺序。做任何带 220 V 的项目之前先读这一页。
- 直流电机驱动（[/topics/motor-drive](../topics/motor-drive)）：第 13 章三相电路与第 17–19 章电机章节在纸面上算的是稳态，这里可以看到真实的电机怎么起停、续流与堵转电流怎么处理。
