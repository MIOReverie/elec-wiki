# 电工学

<Meta time="3 min" level="指南" note="先花 3 分钟看清全局，比直接开读省 2 小时" />

电工学解决的是「电从发电厂走到用电设备」这一路的问题：电路定律 → 交流稳态 → 三相 → 磁路与变压器 → 电机 → 继电器 / PLC 控制。它以**强电与工程视角**为主线，不是器件与放大——后者分别由[模拟电子](../analog/)和[数字电路](../digital/)承担。

## 学完能得到什么

- 拿到任何一张直流电路图，能判断用什么方法解（等效化简 / 结点电压 / 戴维南），并算对功率与方向；
- 遇到一阶动态电路，能用三要素法一次写出 $u_C(t)$、$i_L(t)$，包括换路前后的初值；
- 正弦稳态下把电路翻译成相量、阻抗与功率三角形，解释「功率因数为什么重要」；
- 对称三相电路里熟练使用 $\sqrt 3$ 与 30° 的关系，知道中性点位移为什么会烧设备；
- 看懂变压器与异步电动机的铭牌、机械特性，以及继电接触器/PLC 的自锁互锁逻辑。

## 与电子课程的分工

| 与电子课程重叠（速通过） | 电工学主场（深做） |
| --- | --- |
| 相量 / 频率响应 / 阻抗 | **三相电路**（对称性思维） |
| RC/RL 一阶响应 | **磁路与变压器**（电 → 磁 → 电） |
| 器件级分析 | **电机**（旋转磁场与机械特性） |
| 运放 / 放大 | **功率与功率因数**（工程视角） |
| 二极管整流 | **继电接触器 / PLC**（强电控制逻辑） |

学过电子课程的同学，右列才是要补的；零基础则从 01 顺序读到 22 最稳——前置知识全都有胶囊兜底，遇到不懂的点开就看，不用跳走查资料。

## 三档优先级

- 🔴 **核心**：必看 + 必做演示，约占全部时间的 70%
- 🟡 **了解**：看结论和公式即可，10 分钟过一页
- 🟢 **可跳过**：与电子课程重叠或偏专题，学过直接跳，考前回来看易错清单即可

## 三条学习路径

| 路径 | 顺序 | 适合谁 |

| **速通**（约 6.5 h） | 01 → 02 → 05 → 08 → 09 → 12 → 16 → 17 → 19 | 考前一周、只求建立骨架 |

## 三条主线（记住这个骨架就不会迷路）

```
直流电阻电路  →  一阶动态电路  →  正弦稳态（相量）  →  三相  →  磁路/变压器  →  电机
   KCL/KVL        换路定则          相量法          √3 关系    电→磁→电     旋转磁场
   等效化简        三要素法          阻抗/功率        对称性     变比 k       转差率 s
```
