# 11 · 谐振与频率特性

<Meta time="35 min" level="了解" note="Q 值是全章的主角：选择性好和通频带宽是一对矛盾" />

## 结论先行

1. **串联谐振条件**：$X_L = X_C$ → $\omega_0 = \dfrac{1}{\sqrt{LC}}$。此时 $Z = R$ 最小、$I$ 最大、$U$ 与 $I$ 同相
2. $U_L = U_C = QU$ —— 可能远高于电源电压（**电压谐振**，可击穿元件）
3. $Q = \dfrac{\omega_0 L}{R} = \dfrac{1}{\omega_0 C R} = \dfrac{1}{R}\sqrt{\dfrac{L}{C}}$，$BW = \dfrac{f_0}{Q}$（精确成立，非近似）
4. $Q$ 大 → 选择性好但通频带窄；$Q$ 小 → 反之。**这是全章唯一的矛盾**
5. **并联谐振**：阻抗最大（$=R$）、总电流最小，支路电流 $I_L \approx I_C = QI$（**电流谐振**）

::: tip 规律层：谐振的本质只有一句话
谐振 = 感抗与容抗恰好抵消、电路整体退化成纯电阻的那一个频率点。所有「高 $Q$」「窄带宽」「电压 / 电流谐振」都是这句话的推论，不是独立的新规律。先记住 $\omega_0 = 1/\sqrt{LC}$（只由 $L$、$C$ 决定，与 $R$ 无关），其余都是围绕它的展开。
:::

## 一、串联谐振：电抗归零的那一刻

RLC 串联的阻抗 $Z = R + j(X_L - X_C)$。当

$$
X_L = X_C \;\Rightarrow\; \omega_0 L = \frac{1}{\omega_0 C} \;\Rightarrow\; \boxed{\omega_0 = \frac{1}{\sqrt{LC}}, \quad f_0 = \frac{1}{2\pi\sqrt{LC}}}
$$

谐振瞬间，电抗部分整体消失，电路退化成一个纯电阻：

| 量 | 谐振时 | 说明 |
| --- | --- | --- |
| 电抗 $X$ | $0$ | 电感电容互相抵消 |
| 阻抗 $\vert Z\vert$ | $R$（**最小**） | 全频段最低点 |
| 电流 $I_0$ | $U/R$（**最大**） | 曲线顶点 |
| 相位 | 同相（$\varphi = 0$） | 纯阻性 |
| $U_L$、$U_C$ | $QU$ | 单个元件电压可达电源 $Q$ 倍 |
| $P$ | $U^2/R$（最大） | 电源输出全部变成热 |

谐振频率 $f_0$ 只由 $L$ 和 $C$ 决定，**与电阻无关** —— $R$ 只影响曲线的「尖」与「钝」。

### 通用谐振曲线

把电流归一化，$f_0$ 和 $R$ 都被约掉，得到一条只含 $Q$ 的曲线：

$$
\boxed{\frac{I}{I_0} = \frac{1}{\sqrt{1 + Q^2\left(\eta - \dfrac{1}{\eta}\right)^2}}, \qquad \eta = \frac{f}{f_0}}
$$

## 二、品质因数 Q：一个数字决定全部

$$
Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 C R} = \frac{1}{R}\sqrt{\frac{L}{C}}
$$

三个表达式等价（用 $\omega_0^2 = 1/LC$ 互推），考题里已知条件不同就换着用。$Q$ 的物理意义有两层：

1. **电压放大倍数**：$U_L = U_C = Q U$。谐振时电感（或电容）上的电压是电源的 $Q$ 倍
2. **能量保持能力**：$Q = 2\pi \times \dfrac{\text{储能}}{\text{每周期耗能}}$。$Q$ 越大，能量在回路里「存活」的周期数越多

::: warning 电力系统为什么怕串联谐振
$U_L = QU$ 意味着 $Q = 30$ 的回路里，电容或电感要承受 30 倍额定电压 —— 绝缘直接击穿。所以电力系统中**串联谐振是要预防的事故**（铁磁谐振过电压），而无线电里**是主动利用的工具**。同一个物理现象，立场决定态度。
:::

## 三、通频带：半功率点与 BW

工程上定义 **半功率点**：电流降到 $I_0/\sqrt2$ 的频率（此处 $P = I^2R$ 也降到 $P_{max}/2$，功率减半）。两个半功率点 $f_1$、$f_2$ 之间就是通频带：

$$
BW = f_2 - f_1
$$

代入通用曲线，令 $I/I_0 = 1/\sqrt2$：

$$
Q^2\left(\eta - \frac{1}{\eta}\right)^2 = 1 \;\Rightarrow\; \eta_{1,2} = \frac{\mp\,1/Q + \sqrt{1/Q^2 + 4}}{2}
$$

$$
\eta_2 - \eta_1 = \frac{1}{Q} \;\Rightarrow\; \boxed{BW = \frac{f_0}{Q}}
$$

注意这个结果是**精确的**（不是高 $Q$ 近似），$Q$ 高达几百时误差才需要考虑。于是：

- $Q$ 翻倍 → 曲线尖一倍 → 选择性好一倍，但通频带窄一倍
- $Q$ 减半 → 通频带宽一倍，但邻台也漏进来一倍

::: tip 同一个 Q，两种相反的需求
- **收音机选台**：要 $Q$ 大。中频 465 kHz、带宽 10 kHz，$Q = 46.5$ —— 专门把邻台摁掉
- **音频放大**：要 $Q$ 小。20 Hz – 20 kHz 全通过，$Q$ 甚至不需要「谐振」这个概念
- **示波器探头**：$Q$ 要精确补偿到 1 附近，否则方波过冲振铃 —— 这就是探头上的补偿电容要拿螺丝刀调的原因
:::

## 四、并联谐振：阻抗的峰

RLC **并联**（理想元件），用导纳分析更自然：

$$
Y = \frac{1}{R} + j\left(\omega C - \frac{1}{\omega L}\right)
$$

谐振条件 $B = \omega C - 1/(\omega L) = 0$ —— 同一个 $\omega_0$。此时：

- 导纳模最小：$|Y| = 1/R$
- **阻抗模最大**：$|Z| = R$
- **总电流最小**：$I_0 = U/R$
- 支路电流 $I_L \approx I_C = QI$（$Q = R/\omega_0 L$），可能远大于总电流

<WavePreset kind="parares" />

| | 串联谐振 | 并联谐振 |
| --- | --- | --- |
| 阻抗 | **最小**（$= R$） | **最大**（$= R$） |
| 总电流 | **最大** | **最小** |
| 支路量 | $U_L = U_C = QU$ | $I_L \approx I_C = QI$ |
| 名字 | 电压谐振 | 电流谐振 |
| 典型应用 | 选频、接收机输入回路 | 阻波器、振荡器负载、中频抑制 |

工程实际中并联谐振多考虑**含线圈电阻**的模型（电感支路不是纯电感），谐振频率略低于 $1/\sqrt{LC}$ —— 这是模电/高频的内容，这里先记住理想结论。

## 例题

::: tip 例 1 · 串联谐振标准计算
$R = 5\,\Omega$、$L = 100\,\text{mH}$、$C = 10\,\mu\text{F}$ 串联，接 $U = 10$ V。求 $f_0$、$Q$、谐振电流、$U_L$、$U_C$ 和通频带。

**解**

**谐振频率**（与 $R$ 无关）：

$$
f_0 = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{0.1 \times 10\times10^{-6}}} = \frac{1}{2\pi \times 10^{-3}} = 159.2\ \text{Hz}
$$

**品质因数**：

$$
Q = \frac{\omega_0 L}{R} = \frac{2\pi \times 159.2 \times 0.1}{5} = \frac{100}{5} = 20
$$

（验证另两个表达式：$\dfrac{1}{\omega_0 C R} = \dfrac{1}{1000 \times 10^{-5} \times 5} = 20$ ✓；$\dfrac{1}{R}\sqrt{\dfrac{L}{C}} = \dfrac{1}{5}\sqrt{\dfrac{0.1}{10^{-5}}} = \dfrac{1}{5} \times 100 = 20$ ✓）

**谐振电流**（阻抗最小，只有 $R$）：

$$
I_0 = \frac{U}{R} = \frac{10}{5} = 2\ \text{A}
$$

**元件电压**：

$$
U_L = U_C = Q U = 20 \times 10 = 200\ \text{V}
$$

**通频带**：

$$
BW = \frac{f_0}{Q} = \frac{159.2}{20} = 7.96\ \text{Hz}, \quad f_1 = 155.2\ \text{Hz},\ f_2 = 163.2\ \text{Hz}
$$

::: warning 本题最震撼的数字
电源只有 10 V，电容/电感上却有 **200 V**（20 倍）！如果元件耐压按 10 V 选，谐振时必炸。

实际系统中 $Q$ 达几十很常见（电感线圈电阻很小），所以**电力电容器必须按可能出现的谐振过电压选型**，不能按额定电压选。
:::
:::

::: tip 例 2 · 反问题：已知带宽求参数
收音机中频放大器的中心频率 $f_0 = 465$ kHz，要求通频带 $BW = 10$ kHz。回路电阻 $R = 10\,\Omega$，求所需 $Q$、$L$、$C$。

**解**

**第一步，由带宽求 Q**（$BW = f_0/Q$）：

$$
Q = \frac{f_0}{BW} = \frac{465}{10} = 46.5
$$

**第二步，求 L**（用 $Q = \omega_0 L/R$）：

$$
\omega_0 = 2\pi \times 465\times10^3 = 2.92\times10^6\ \text{rad/s}
$$

$$
L = \frac{QR}{\omega_0} = \frac{46.5 \times 10}{2.92\times10^6} = 1.59\times10^{-4}\ \text{H} = 159\ \mu\text{H}
$$

**第三步，求 C**（用 $f_0 = 1/2\pi\sqrt{LC}$）：

$$
C = \frac{1}{\omega_0^2 L} = \frac{1}{(2.92\times10^6)^2 \times 1.59\times10^{-4}} = 7.36\times10^{-10}\ \text{F} \approx 736\ \text{pF}
$$

**验算**：$f_0 = \dfrac{1}{2\pi\sqrt{1.59\times10^{-4} \times 7.36\times10^{-10}}} = \dfrac{1}{2\pi \times 3.42\times10^{-7}} = 465$ kHz ✓

**工程注脚**：737 pF 靠可变电容（调电台）微调，159 μH 是中频变压器（中周）的初级 —— 老式收音机里那颗可以拿螺丝刀拧的磁芯，调的就是 $L$。
:::

::: tip 例 3 · 并联谐振
$R = 1\,\text{k}\Omega$、$L = 1\,\text{mH}$、$C = 1\,\mu\text{F}$ 并联，接 $U = 100$ V。求 $f_0$、谐振时的总电流和支路电流。

**解**

**谐振频率**（串并联同一公式）：

$$
f_0 = \frac{1}{2\pi\sqrt{LC}} = \frac{1}{2\pi\sqrt{10^{-9}}} = 5033\ \text{Hz}
$$

**谐振时总电流**（阻抗最大 $= R$，所以电流最小）：

$$
I_0 = \frac{U}{R} = \frac{100}{1000} = 0.1\ \text{A} = 100\ \text{mA}
$$

**支路电流**（先求并联 $Q$）：

$$
Q = \frac{R}{\omega_0 L} = \frac{1000}{2\pi \times 5033 \times 10^{-3}} = \frac{1000}{31.6} = 31.6
$$

$$
I_L \approx I_C = Q I_0 = 31.6 \times 0.1 = 3.16\ \text{A}
$$

（直接算：$I_L = \dfrac{U}{\omega_0 L} = \dfrac{100}{31.6} = 3.16$ A ✓）

::: warning 元件选型按支路电流
电源只供出 100 mA，电感/电容里却流过 3.16 A（31.6 倍）！所以并联谐振回路里，电感和电容要按**支路电流**选型，熔断器/导线也按支路电流配 —— 按总电流配会在谐振时烧毁。

「电流谐振」的名字就是这么来的：大电流在 L、C 之间来回晃，电源几乎不出力。
:::
:::

## 工程实例

- **收音机选台**：天线回路 + 可变电容组成串联谐振回路，$Q$ 做到几十，只让目标电台的信号「起振」进放大器，邻台被抑制。转动旋钮改变 $C$ → 改变 $f_0$ → 选台。
- **中频放大器**：超外差接收机把各电台统一搬到 465 kHz 中频，中周（中频变压器）就是 465 kHz 的谐振回路，负责筛出中频、抑制邻近频率。
- **阻波器**：电力线上并联谐振回路串在载波通信里，对 50 Hz 呈高阻抗（不挡工频电流），对高频通信信号呈低阻抗（让高频通过）。
- **铁磁谐振过电压（事故）**：电网中电感（变压器、互感器）与电容（电缆、断口）偶然构成串联谐振，$U_L$ 过电压数倍，烧毁设备。防止办法：破坏谐振条件（接入阻尼电阻）或避免中性点直接接地运行方式。
- **石英晶体谐振器**：$Q$ 值高达 $10^4 \sim 10^6$，频率稳定度远胜 LC 回路 —— 所有精密时钟（单片机晶振、手表）都靠它。

## 易错点（按踩坑频率排序）

1. 谐振频率 $f_0$ **与 $R$ 无关**，只由 $L$、$C$ 决定
2. $Q$ 公式里 $R$ 是**回路总电阻**（含电感线圈自身电阻），不只是外接电阻
3. 串联谐振 $U_L = QU$ 很大 → 元件耐压按 $QU$ 选，不是按 $U$
4. 并联谐振支路电流 $= QI$ → 元件按**支路电流**选型，不是总电流
5. $BW = f_0/Q$ 是**精确**结果，不是高 $Q$ 近似
6. 串联谐振 $Z$ 最小、并联谐振 $Z$ 最大 —— 说反了整个应用全反
7. 电力系统**防**谐振，无线电**用**谐振 —— 应用场景别搞混
8. 并联谐振若考虑线圈电阻，谐振频率略低于 $1/\sqrt{LC}$（理想公式的前提要知道）

## 考点速记

| 题型 | 公式 |
| --- | --- |
| 求谐振频率 | $f_0 = 1/(2\pi\sqrt{LC})$ |
| 求 $Q$ | $Q = \omega_0 L/R = 1/(\omega_0 C R)$ |
| 谐振时电流/阻抗 | 串联 $I_0 = U/R$；并联 $I_0 = U/R$、$\vert Z\vert = R$ |
| 元件电压/电流 | 串联 $U_L = U_C = QU$；并联 $I_L = I_C = QI$ |
| 通频带 | $BW = f_0/Q$ |
| 已知 $BW$ 求 $Q$ | $Q = f_0/BW$ |
| 判断选择性 | $Q$ 越大曲线越尖、选择性越好、带宽越窄 |
