# 09 · RLC 串联与阻抗

<Meta time="45 min" level="核心" note="阻抗三角形和电压三角形是全章的核心图像" />

## 结论先行

1. 三种元件的复数阻抗：$Z_R = R$、$Z_L = j\omega L$、$Z_C = \dfrac{1}{j\omega C} = -j\dfrac{1}{\omega C}$
2. RLC 串联：$Z = R + j(X_L - X_C)$，$|Z| = \sqrt{R^2 + X^2}$，$\varphi = \arctan\dfrac{X_L - X_C}{R}$
3. **电压三角形与阻抗三角形相似**：各边同乘电流 $I$ 即得
4. $U_L$ 与 $U_C$ **可能远大于总电压**（二者反相、互相抵消）—— 不是算错
5. $X_L > X_C$ 感性、$X_L < X_C$ 容性；**同一电路，低频呈容性、高频呈感性**
6. 阻抗的模**不能直接相加**：$|Z_1 + Z_2| \ne |Z_1| + |Z_2|$；并联要用复数算

## 一、复阻抗：一个符号统一三种元件

把 <Prereq id="complex-number" /> 的相量关系 $\dot U = Z\dot I$ 中的 $Z$ 定义为**复阻抗**：

| 元件 | 相量关系 | 复阻抗 $Z$ | 电抗 $X$ |
| --- | --- | --- | --- |
| 电阻 | $\dot U = R\dot I$ | $R$ | 0 |
| 电感 | $\dot U = j\omega L\dot I$ | $j\omega L$ | $X_L = \omega L$ |
| 电容 | $\dot U = \dfrac{1}{j\omega C}\dot I$ | $-j\dfrac{1}{\omega C}$ | $X_C = \dfrac{1}{\omega C}$ |

$$
Z = R + jX = |Z|\angle\varphi, \qquad |Z| = \sqrt{R^2 + X^2},\quad \varphi = \arctan\frac{X}{R}
$$

- **模 $|Z|$**：电压幅值 ÷ 电流幅值，单位 Ω
- **辐角 $\varphi$**：电压超前电流的角度 —— **阻抗角就是相位差**
- 电抗可正（感性）可负（容性），电阻永远非负

于是「求一个正弦交流电路的响应」和直流电路完全同构：先算复阻抗，再 $\dot I = \dot U / Z$，最后拆实部虚部。这就是 <Prereq id="impedance" /> 讲的全部内容。

::: tip 心智模型：复阻抗是「统一写法」，不是新规律
R、L、C 本来就是三种不同的伏安关系（电阻是乘、电感是求导、电容是积分）。复阻抗 $Z$ 把它们统一成同一个形式 $\dot U = Z\dot I$——于是交流电路和直流电路在形式上完全同构：先算 $Z$，再 $\dot I = \dot U / Z$。「阻抗」不是一个新物理量，它只是把频率 $\omega$ 卷进了电阻里。
:::

## 二、RLC 串联：阻抗三角形

串联电流相同，选 $\dot I$ 为参考相量：

<CircuitFig kind="rlc-series" title="RLC 串联电路：同一个电流流过三者" />

$$
\dot U = \dot U_R + \dot U_L + \dot U_C = R\dot I + j\omega L\dot I + \frac{1}{j\omega C}\dot I
$$

$$
\boxed{Z = R + j(X_L - X_C), \qquad X = X_L - X_C}
$$

各段电压的幅值：

$$
U_R = IR, \qquad U_L = IX_L, \qquad U_C = IX_C, \qquad U = I|Z| = I\sqrt{R^2 + (X_L-X_C)^2}
$$

<FigBox title="电压三角形与阻抗三角形" kind="曲线" note="以 İ 为参考：U_R 水平、U_L 竖直向上、U_C 竖直向下，总电压是它们的矢量和。整个三角形各边同除以 I 就得到阻抗三角形 —— 两个三角形相似，这是全章最值钱的图像。">
<WavePreset kind="phasorref" />
</FigBox>

把 $\dot U_R$、$\dot U_L$、$\dot U_C$、$\dot U$ 画出来，得到一个**直角三角形**：

- 水平边：$U_R = IR$（永远和电流同相）
- 竖直边：$U_L - U_C = I(X_L - X_C)$（电感向上、电容向下，**先抵消再合成**）
- 斜边：$U = I|Z|$

$$
U = \sqrt{U_R^2 + (U_L - U_C)^2}
$$

两个三角形（电压的、阻抗的）**相似**：同除以 $I$ 就互相转化。所以只要记住一个，另一个是送的。

### 电路性质怎么判断

| 条件 | 性质 | 相位 | 形象说法 |
| --- | --- | --- | --- |
| $X_L > X_C$ | 感性 | $\varphi > 0$，电压超前电流 | 电感占上风 |
| $X_L < X_C$ | 容性 | $\varphi < 0$，电压滞后电流 | 电容占上风 |
| $X_L = X_C$ | 阻性 | $\varphi = 0$，同相 | 谐振（[第 11 章 · 谐振与频率特性](resonance.md)主角） |

### 一个反直觉的事实：电抗随频率反转

<FigBox title="同一个电路，低频容性、高频感性" kind="曲线" note="X_L 随频率正比上升，X_C 随频率反比下降，交点就是谐振频率。横轴用 f/f₀ 归一化后，交点恒在 1 —— 与 L、C 具体取值无关。">
<WavePreset kind="reactance" />
</FigBox>

**记住这张图**：$X_L = \omega L$ 随频率涨，$X_C = 1/(\omega C)$ 随频率跌。所以**同一组 R、L、C**，低频时 $X_C$ 大（容性），高频时 $X_L$ 大（感性），中间某频率两者相等。这个「性质随频率反转」的现象是选频电路（滤波器、谐振器）的全部基础，也是[第 11 章 · 谐振与频率特性](resonance.md)的入口。

## 三、阻抗的串并联

串联就是复数直接相加，并联推荐用**导纳** $Y = 1/Z$：

$$
Z_{串} = Z_1 + Z_2, \qquad Y_{并} = Y_1 + Y_2 = \frac{1}{Z_1} + \frac{1}{Z_2}, \qquad Z_{并} = \frac{Z_1Z_2}{Z_1+Z_2}
$$

**阻抗分压**（串联时各元件电压）：

$$
\dot U_k = \frac{Z_k}{Z_1 + Z_2}\dot U \qquad (\text{复数形式})
$$

::: warning 分压公式的两个坑
1. 必须用**复数**除，不能拿 $|Z_k| / (|Z_1|+|Z_2|)$ 算 —— 分母的模不等于模的和
2. 算出来的 $\dot U_k$ 是相量，取模才是电压幅值

工程上经常出现「串联两个阻抗，每个都没超额定，总电压却把其中一个顶爆」的事故，根源都是把模当电阻直接分了。
:::

## 例题

::: tip 例 1 · RLC 串联标准计算（必考题型）
$R = 30\,\Omega$、$L = 127\,\text{mH}$、$C = 40\,\mu\text{F}$ 串联，接 $U = 220$ V、$f = 50$ Hz 电源。求 $I$、各元件电压、$\cos\varphi$，并判断电路性质。

**解**

**第一步，算电抗。**

$$
X_L = \omega L = 2\pi \times 50 \times 0.127 = 39.9\,\Omega
$$

$$
X_C = \frac{1}{\omega C} = \frac{1}{2\pi \times 50 \times 40\times10^{-6}} = 79.6\,\Omega
$$

**第二步，算总阻抗。**

$$
X = X_L - X_C = 39.9 - 79.6 = -39.7\,\Omega
$$

$$
|Z| = \sqrt{30^2 + (-39.7)^2} = \sqrt{900 + 1576} = 49.7\,\Omega
$$

$$
\varphi = \arctan\frac{-39.7}{30} = -52.9°
$$

$X < 0$、$\varphi < 0$ → **容性电路**。

**第三步，算电流和各电压。**

$$
I = \frac{220}{49.7} = 4.42\ \text{A}
$$

$$
U_R = 4.42 \times 30 = 132.7\ \text{V}, \quad U_L = 4.42 \times 39.9 = 176.5\ \text{V}, \quad U_C = 4.42 \times 79.6 = 351.9\ \text{V}
$$

$$
\cos\varphi = \frac{R}{|Z|} = \frac{30}{49.7} = 0.604
$$

**验算**：$U = \sqrt{132.7^2 + (351.9 - 176.5)^2} = \sqrt{17609 + 30777} = 220.0$ V ✓

::: warning 本题最值得注意的数字
$U_L + U_C = 528$ V，是电源电压 220 V 的 **2.4 倍**！

如果按「电压各段相加」理解，非乱套不可。真相：$U_L$ 与 $U_C$ **反相**，先抵消（$351.9 - 176.5 = 175.4$ V）再和 $U_R$ 合成 220 V。

工程后果：电容要按 352 V 选耐压，不能按 220 V —— 这就是「元件耐压按自身电压算，不按电源电压算」。
:::

**反过来问**（变式）：若 $X_L = X_C$（谐振），$|Z| = R = 30\,\Omega$，$I = 220/30 = 7.33$ A，$U_L = U_C = 7.33 \times 39.9 = 292$ V —— 比电源还高。[第 11 章 · 谐振与频率特性](resonance.md)专门收拾这个现象。
:::

::: tip 例 2 · 阻抗串联分压（专治「模直接相加」）
$Z_1 = 8 + j6\ \Omega$、$Z_2 = 12 - j16\ \Omega$ 串联接 $\dot U = 220\angle 0°$ V。求总电流、各阻抗电压。

**解**

**先看两个阻抗的模**：$|Z_1| = 10\,\Omega$、$|Z_2| = 20\,\Omega$。

**错误做法**（先立个靶子）：$|Z| = 10 + 20 = 30\,\Omega$ → $I = 7.33$ A、$U_1 = 73.3$ V、$U_2 = 146.7$ V。**全错**，因为两个阻抗一个感性一个容性，相位相反，模要相减不是相加。

**正确做法**：

$$
Z = Z_1 + Z_2 = (8 + 12) + j(6 - 16) = 20 - j10\ \Omega
$$

$$
|Z| = \sqrt{20^2 + 10^2} = 22.36\,\Omega, \qquad \varphi = \arctan\frac{-10}{20} = -26.6°
$$

$$
\dot I = \frac{220\angle0°}{22.36\angle{-26.6°}} = 9.84\angle 26.6°\ \text{A}
$$

$$
\dot U_1 = \dot I Z_1 = 9.84\angle26.6° \times 10\angle36.9° = 98.4\angle63.5°\ \text{V}
$$

$$
\dot U_2 = \dot I Z_2 = 9.84\angle26.6° \times 20\angle{-53.1°} = 196.8\angle{-26.5°}\ \text{V}
$$

**注意**：$U_1 + U_2 = 98.4 + 196.8 = 295.2$ V ≠ 220 V —— 又是相量抵消。验算：总电压 = $\dot I \cdot Z = 9.84 \times (20 - j10)$，即水平分量 196.8 V、竖直分量 −98.4 V，则

$$
U = \sqrt{196.8^2 + 98.4^2} = 220.2\ \text{V} ✓
$$

（末位差来自四舍五入）

::: tip 本例的口诀
**模不可加，相角不可减。** 复阻抗只有一条路：拆成实部虚部，加减在代数型里做，乘除在极坐标里做。
:::
:::

::: tip 例 3 · 阻抗并联（两个 5 Ω 并联不是 2.5 Ω）
$Z_1 = 3 + j4\ \Omega$、$Z_2 = 4 - j3\ \Omega$ 并联，求等效阻抗。

**解**

$$
Z = \frac{Z_1Z_2}{Z_1 + Z_2}
$$

分子：

$$
Z_1Z_2 = (3+j4)(4-j3) = 12 - j9 + j16 + 12 = 24 + j7
$$

分母：

$$
Z_1 + Z_2 = 7 + j1
$$

$$
Z = \frac{24+j7}{7+j1} = \frac{(24+j7)(7-j1)}{(7+j1)(7-j1)} = \frac{175 + j25}{50} = 3.5 + j0.5\ \Omega
$$

$$
|Z| = \sqrt{3.5^2 + 0.5^2} = 3.54\,\Omega
$$

::: warning 这个结果反直觉，但完全正确
两个**模都是 5 Ω** 的阻抗并联，等效是 **3.54 Ω**，不是 2.5 Ω（电阻并联公式），也不是 5 Ω。

原因：一个感性一个容性，并联后互相补偿，等效阻抗反而**大于**同值电阻并联。若 $X_L = X_C$（谐振），等效阻抗可达最大（[第 11 章 · 谐振与频率特性](resonance.md)并联谐振）。

**并联阻抗永远用复数算**，这是铁律。
:::
:::

::: tip 例 4 · 概念题（判断题高频）
判断：(a) 频率升高时，RLC 串联电路一定从感性变容性。(b) $U_L > U$ 说明计算错误。(c) 阻抗角就是电压与电流的相位差。

**解**

**(a) 对。** 由电抗频率特性图：频率升高 → $X_L$ 涨、$X_C$ 跌 → 净电抗 $X = X_L - X_C$ 由负转正 → 电路由容性变感性。注意方向是「容 → 感」不是「感 → 容」。

**(b) 错。** $U_L = IX_L$ 只由电流和感抗决定，与总电压没有大小关系。只要 $U_C$ 与 $U_L$ 反向抵消得厉害，$U_L$ 或 $U_C$ 单独超过总电压完全正常 —— 例 1 里 $U_C = 351.9$ V 就已经超过电源电压 220 V 了。

**(c) 对。** 阻抗角 $\varphi = \arctan(X/R)$ 的定义就是 $\dot U$ 超前 $\dot I$ 的角度，二者是同一个东西的两种说法。
:::

## 工程实例

- **日光灯电路**：灯管（电阻性）+ 镇流器（电感）串联，$\cos\varphi$ 只有 0.5 左右。在电源侧并联电容把 $\cos\varphi$ 补到 0.9 以上 —— [第 10 章 · 功率与功率因数](power.md)的标准案例，也是各高校实验室的保留实验。
- **扬声器分频器**：电感串低音单元（通低频、阻高频），电容串高音单元（通高频、阻低频）。利用的正是「$X_L$ 随频率涨、$X_C$ 随频率跌」这张图。
- **电源 EMI 滤波**：开关电源输入端的共模电感 + Y 电容，靠电抗的频率特性把高频噪声「挡」在电网侧。
- **变频器与电机**：变频器输出频率变化时，电机电流随之变化 —— 因为 $X_L = \omega L$ 随频率线性变化，低频时感抗小、电流大，这就是变频调速「低频要降压补偿」的原因。

## 易错点（按踩坑频率排序）

1. **阻抗的模不能直接相加**：$|Z_1+Z_2| \ne |Z_1|+|Z_2|$
2. 并联阻抗拿电阻并联公式硬算 —— 必须用复数
3. 算完 $X = X_L - X_C$ 忘了**带符号**，感性容性判断反
4. $U_L + U_C \gg U$ 不是错误，是相量抵消
5. 电容的 $Z_C = 1/(j\omega C)$ 忘了化成 $-j/(\omega C)$，加减时出错
6. $\arctan$ 值域只有 $(-90°, 90°)$，$R < 0$ 或跨象限时辐角要手工修正
7. 直流稳态（$\omega = 0$）下电感短路、电容开路 —— 交流公式不能直接套

## 考点速记

| 题型 | 第一步 |
| --- | --- |
| 已知 $R$、$L$、$C$、$f$ 求 $I$ 和各电压 | 算 $X_L$、$X_C$ → $Z$ → $\dot I = \dot U/Z$ |
| 判断电路性质 | 比较 $X_L$ 与 $X_C$ 的大小 |
| 求相位差 | $\varphi = \arctan(X/R)$ |
| 阻抗串联 | 复数直接相加 |
| 阻抗并联 | 用导纳或 $Z_1Z_2/(Z_1+Z_2)$ |
| 画相量图 | 串联以 $\dot I$ 为参考，并联以 $\dot U$ 为参考 |
| 元件耐压选型 | 按**元件自身电压**，不按电源电压 |
