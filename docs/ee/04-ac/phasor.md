# 08 · 正弦量与相量法

<Meta time="40 min" level="核心" note="相量法是交流电路的『编译器』：把微积分变成复数代数" />

## 结论先行

1. 正弦量三要素：**幅值 $U_m$、角频率 $\omega$、初相位 $\psi$** —— 三者确定，正弦量唯一确定
2. **有效值** $U = U_m/\sqrt2$（仪表读数、设备铭牌默认都是有效值，由热效应定义）
3. **相量** = 携带幅值和相位的复数：$\dot U = U\angle\psi$（模用有效值）
4. 相量法的威力：把**微分方程**变成**复数代数方程**，且 KCL/KVL 形式不变
5. 同频正弦量合成：幅值 $U_m = \sqrt{U_{1m}^2 + U_{2m}^2 + 2U_{1m}U_{2m}\cos\varphi}$ —— **有效值不能直接相加**
6. 只有**同频率**的正弦量才能画在同一张相量图上；相量是**复数不是时间函数**

::: tip 心智模型：相量法是一台「微积分 → 代数」的编译器
它没有改变任何物理规律——KCL、KVL 照样成立。它只是把「对正弦量求导 / 积分」这件事，翻译成「复数乘 $j\omega$ / 除 $j\omega$」。所以相量域里你直流电路的全部解题动作（串并联、分压、节点法……）原封不动地可用。记住一句话：**频率已被「同频假设」定死，剩下要解的只有幅值和相位两个数——恰好是一个复数的两个自由度**。
:::

## 一、为什么要用相量：把微积分变成代数

直流电路里电阻的伏安关系是 $u = Ri$，一个乘法。而电感和电容是**微积分关系**：

$$
u_L = L\frac{di_L}{dt}, \qquad i_C = C\frac{du_C}{dt}
$$

列出来的 KCL/KVL 是**微分方程**，解起来很痛苦。但有一个关键的数学事实：

> 线性电路中，如果所有电源都是**同频率**的正弦量，那么全电路各处的响应也都是**同频率**的正弦量。

频率不用求解了，剩下要定的只有**幅值**和**相位**两个数。而一个复数恰好有两个自由度 —— 让复数的模扛幅值、辐角扛相位，正弦量的全部信息就压缩成一个数。进一步有：

- 求导 $\frac{d}{dt}$ → 乘以 $j\omega$（幅值乘 $\omega$、相位转 90°）
- 积分 $\int dt$ → 除以 $j\omega$（幅值除 $\omega$、相位转 −90°）

于是微分方程退化成了复数代数方程。**KCL、KVL 的形式原封不动**：

$$
\sum \dot I = 0, \qquad \sum \dot U = 0
$$

这就是相量法的全部魔法：**换了一套符号，解题动作和直流电路一模一样**。

::: tip 旋转相量：相量的几何来历
让一个复数 $\dot U = U_m\angle\psi$ 以角速度 $\omega$ 逆时针旋转，它**在虚轴上的投影**就是正弦瞬时值：

$$
\mathcal{Im}\left[U_m e^{j(\omega t+\psi)}\right] = U_m\sin(\omega t+\psi) = u(t)
$$

所以「相量」这个词很诚实：它就是旋转矢量的快照。同一张相量图上并排画几个相量，它们之间的夹角就是相位差。
:::

## 二、三要素与有效值

$$
u(t) = U_m\sin(\omega t + \psi), \qquad \omega = 2\pi f = \frac{2\pi}{T}
$$

| 量 | 符号 | 单位 | 说明 |
| --- | --- | --- | --- |
| 幅值（最大值） | $U_m$ | V / A | 波形偏离零线的最大距离 |
| 角频率 | $\omega$ | rad/s | 每秒转过的弧度，$\omega = 2\pi f$ |
| 周期 / 频率 | $T$ / $f$ | s / Hz | $T = 1/f$，工频 50 Hz → $T = 20$ ms |
| 初相位 | $\psi$ | rad 或 ° | $t=0$ 时刻的相位，与计时起点有关 |

**有效值**不是随手定义的，它是**热效应等效**的结果：让交流电和直流电分别通过同一个电阻，一个周期内产生**相同热量**的那个直流值，就叫交流的有效值。

$$
\int_0^T \frac{u^2}{R}dt = \frac{U^2}{R}T \;\Rightarrow\; U = \sqrt{\frac{1}{T}\int_0^T u^2\,dt}
$$

对正弦量代入积分：

$$
\boxed{U = \frac{U_m}{\sqrt2} \approx 0.707\,U_m}
$$

::: warning 为什么处处用有效值
万用表测出来的、电机铭牌上印的、配电网说的「220 V」，**全是有效值**。所以相量的模默认用有效值 —— 这样 $P = UI\cos\varphi$ 直接成立，不用到处除 $\sqrt2$。只有画波形图、谈击穿绝缘时才用幅值。
:::

## 三、复数工具箱

相量运算法则和普通复数完全一样，只有一条实用经验：**加减用代数型，乘除用极坐标**。

$$
A = a + jb = |A|\angle\varphi, \qquad |A| = \sqrt{a^2+b^2},\quad \varphi = \arctan\frac{b}{a}
$$

四个必须背下来的恒等式：

$$
j = 1\angle 90^\circ, \qquad \frac{1}{j} = -j, \qquad j^2 = -1, \qquad e^{j90^\circ} = j
$$

**$j$ 的几何意义是「逆时针转 90°」**：任何相量乘 $j$ 就是相位超前 90°，除 $j$（即乘 $-j$）就是滞后 90°。电抗的正负号全靠它解释。

## 四、同频正弦量相加：有效值不能直接加

两个同频正弦量 $u_1$、$u_2$ 相加，频率不变，合成幅值由**相位差** $\varphi$ 决定：

$$
\boxed{U_m = \sqrt{U_{1m}^2 + U_{2m}^2 + 2U_{1m}U_{2m}\cos\varphi}}
$$

<FigBox title="相位差如何决定合成幅值" kind="曲线" note="拖动相位差：同相时合成幅值最大（2U），反相时完全抵消（0），正交（90°）时是 √2U 而不是 2U。绿线是两条虚线的逐点代数和。">
<WavePreset kind="sinesum" :p="0.5" />
</FigBox>

三种最特殊的情况值得单独记住：

| 相位差 | 合成幅值 | 有效值 |
| --- | --- | --- |
| $\varphi = 0$（同相） | $U_{1m}+U_{2m}$ | $U_1+U_2$ |
| $\varphi = 180°$（反相） | $\vert U_{1m}-U_{2m}\vert$ | $\vert U_1-U_2\vert$ |
| $\varphi = 90°$（正交） | $\sqrt{U_{1m}^2+U_{2m}^2}$ | $\sqrt{U_1^2+U_2^2}$ |

::: warning 最高频错误
把两个同频正弦量的**有效值直接相加**。除非同相，否则一定错。正确做法只有一条路：**各自写成相量 → 复数相加 → 取模**。

比如两个 10 V 有效值、相位差 90° 的电压串联，总电压有效值是 $\sqrt{10^2+10^2} = 14.14$ V，不是 20 V。
:::

**相量法求合成的标准三步**：

```
① 各量写成统一形式（都用有效值或都用幅值，别混用）
② 转成代数型 a + jb，实部虚部分别相加
③ 结果转回极坐标：取模 = 幅值，辐角 = 初相位
```

## 五、相量图与元件伏安关系

**画相量图的规则**：只有同频正弦量才能画在同一张图上；通常选一个**参考相量**（串联选电流，并联选电压）画在水平方向，其余相量按与它的相位差摆放。

<FigBox title="三种元件的相位关系（以电流为参考）" kind="曲线" note="电阻：电压电流同相。电感：电压超前电流 90°（因为求了一次导）。电容：电压滞后电流 90°（因为积分了一次）。电感和电容的相位永远相反 —— 这是它们能互相抵消的原因。">
<WavePreset kind="phasorref" />
</FigBox>

| 元件 | 时域关系 | 相量关系 | 相位 |
| --- | --- | --- | --- |
| $R$ | $u = Ri$ | $\dot U = R\dot I$ | 同相 |
| $L$ | $u = L\dfrac{di}{dt}$ | $\dot U = j\omega L\,\dot I$ | **电压超前 90°** |
| $C$ | $i = C\dfrac{du}{dt}$ | $\dot U = \dfrac{1}{j\omega C}\dot I = -j\dfrac{1}{\omega C}\dot I$ | **电压滞后 90°** |

电容的推导值得跟一遍（电感留作练习）：

$$
i = C\frac{du}{dt} \;\Rightarrow\; u = \frac{1}{C}\int i\,dt = \frac{1}{C}\int \sqrt2 I\sin(\omega t+\psi_i)\,dt
$$

$$
u = \frac{\sqrt2 I}{\omega C}\sin(\omega t + \psi_i - 90^\circ)
$$

$$
\boxed{\dot U = \frac{I}{\omega C}\angle(\psi_i - 90^\circ) = \frac{1}{j\omega C}\dot I}
$$

幅值除 $\omega$、相位退 90° —— 和「除以 $j\omega$」的代数效应完全一致。

## 例题

::: tip 例 1 · 瞬时表达式 ↔ 相量（必会互换）
(a) 已知 $i(t) = 10\sqrt2\sin(314t - 60°)$ A，写相量。(b) 已知 $\dot U = 220\angle 30°$ V、$f = 50$ Hz，写瞬时表达式。

**解**

**(a)** 对照 $i = \sqrt2 I\sin(\omega t + \psi_i)$：$I_m = 10\sqrt2$、$\omega = 314$、$\psi_i = -60°$。

$$
\dot I = I\angle\psi_i = 10\angle{-60°}\ \text{A}
$$

（模取有效值 $10\sqrt2/\sqrt2 = 10$ A，角照抄。）

**(b)** 相量模已是有效值，还原时前面要补 $\sqrt2$：

$$
u(t) = \sqrt2 \times 220\sin(2\pi \times 50\,t + 30°) = 311\sin(314t + 30°)\ \text{V}
$$

**易错点**：相量写瞬时值时**必须补 $\sqrt2$**；瞬时值写相量时**必须除 $\sqrt2$**。漏一步就差 1.414 倍。
:::

::: tip 例 2 · 同频正弦量求和（相量法标准考题）
$u_1 = 10\sin(\omega t + 30°)$ V、$u_2 = 10\sin(\omega t - 60°)$ V，求 $u = u_1 + u_2$。

**解**

**第一步，写相量（这里用幅值做模，因为题给的是幅值）：**

$$
\dot U_{1m} = 10\angle 30° = 8.66 + j5.00, \qquad \dot U_{2m} = 10\angle{-60°} = 5.00 - j8.66
$$

**第二步，代数型相加：**

$$
\dot U_m = (8.66 + 5.00) + j(5.00 - 8.66) = 13.66 - j3.66
$$

**第三步，转回极坐标：**

$$
|\dot U_m| = \sqrt{13.66^2 + 3.66^2} = 14.14\ \text{V}, \qquad \psi = \arctan\frac{-3.66}{13.66} = -15°
$$

$$
u = 14.14\sin(\omega t - 15°)\ \text{V}
$$

**为什么不能直接加**：$10 + 10 = 20$ V，与正确答案 14.14 V 差了 41%。两者的相位差是 90°，属于「正交」情形，合成幅值是 $\sqrt{10^2+10^2} = 14.14$ —— 与相量法结果一致 ✓

**验证（用余弦定理）**：$U_m = \sqrt{10^2 + 10^2 + 2\times10\times10\cos90°} = 10\sqrt2 = 14.14$ ✓
:::

::: tip 例 3 · 从波形读三要素（工程读图题）
示波器测得某电压：波峰 100 V，周期 10 ms，$t=0$ 时 $u=50$ V 且正在上升。写瞬时表达式和相量。

**解**

**三要素**：

- 幅值 $U_m = 100$ V → 有效值 $U = 100/\sqrt2 = 70.7$ V
- $T = 10$ ms → $f = 100$ Hz → $\omega = 2\pi f = 628$ rad/s
- 初相位：$u(0) = 100\sin\psi = 50 \Rightarrow \sin\psi = 0.5$，正在上升说明取 $\psi = 30°$（另一个解 150° 是下降段）

$$
u(t) = 100\sin(628t + 30°)\ \text{V}, \qquad \dot U = 70.7\angle 30°\ \text{V}
$$

**为什么上升能定相位**：$\sin\psi = 0.5$ 有两个解（30° 和 150°），导数的符号（$\cos\psi > 0$）才能区分 —— 这就是「初相位必须配合变化趋势才有意义」的原因。
:::

::: tip 例 4 · 概念辨析（判断题高频）
判断下列说法对错，并说明理由。

**(a)** 两个正弦电压频率不同，也可以画在同一张相量图上比较相位。
**(b)** 相量 $\dot U$ 是一个随时间旋转的矢量。
**(c)** 相量等于瞬时值，只是写法不同。

**解**

**(a) 错。** 相量图上相量之间的夹角代表相位差，而不同频率的两个量**相位差本身随时间变化**，没有固定值可画。相量图只对同频量有意义。

**(b) 错。** 相量是**复数**（一对固定的数：模和辐角）。「旋转相量」是理解其来历的教学模型 —— 真正旋转的是 $U_me^{j\omega t}$，而相量只是它 $t=0$ 时刻的快照。所以 $\dot U \ne u(t)$，两者永远不相等，只是一个对应两种写法。

**(c) 错。** 同 (b)。相量携带的是幅值 + 相位，丢失了「随时间变化」这部分信息 —— 因为频率已经被同频假设定死了，不需要再携带。
:::

## 工程实例

- **仪表读数**：交流电压表、电流表读的都是有效值。用它们测 220 V 单相电机时，$U = 220$ V 就是有效值，绝缘和耐压按幅值 311 V 考核。
- **电网频率**：中国电网 $f = 50$ Hz，$\omega = 314$ rad/s，$T = 20$ ms。这个数字在后面每一章都会反复出现，建议形成条件反射：看到 314 就想到 50 Hz。
- **示波器测相位**：双通道示波器是唯一能直接看到 $\psi$ 的仪器 —— 数格数 × 每格时间 × 360° = 相位差。相量法算出来的相位，最终要靠示波器验证。
- **音频频段**：人耳 20 Hz – 20 kHz，对应角频率 125 – 125660 rad/s。同一个电容在 20 Hz 和 20 kHz 下的容抗差 1000 倍 —— 这就是分频器能工作的原因。

## 易错点（按踩坑频率排序）

1. **有效值不能直接相加**（除非同相）——必须走相量
2. 相量写瞬时值**漏乘 $\sqrt2$**，或瞬时值写相量**漏除 $\sqrt2$**
3. **不同频率的正弦量不能画在同一张相量图上**
4. 相量是复数不是时间函数，$\dot U \ne u(t$
5. 加减法忘记转成代数型，直接拿极坐标的模做加减
6. $\arctan$ 的值域是 $(-90°, 90°)$，实部为负时要**手工加/减 180°** 才是真正的辐角
7. 电感电压超前电流 90°、电容电压滞后电流 90° —— 说反会导致后面所有结论反向

## 考点速记

| 考法 | 做法 |
| --- | --- |
| 瞬时表达式 → 相量 | 模除 $\sqrt2$，角照抄 |
| 相量 → 瞬时表达式 | 模乘 $\sqrt2$，$u = \sqrt2 U\sin(\omega t+\psi)$ |
| 判断超前滞后 | 比较 $\psi_u$ 与 $\psi_i$；波形上谁先到最大谁超前 |
| 同频量求和 | 相量相加（代数型），不能直接加有效值 |
| 复数运算 | 加减转代数型，乘除用极坐标 |
| 已知 $u(0)$ 求 $\psi$ | $\sin\psi = u(0)/U_m$，用上升/下降定唯一解 |
