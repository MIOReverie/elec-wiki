# 07 · 定时器与 PWM

<Meta time="45 min" level="核心" note="MCU 里最有用的外设：定时、输出 PWM、测量频率，全靠同一个计数器" />

## 结论先行

1. **定时器本质上是一个可配置的计数器**：时钟经 PSC 分频后驱动 CNT 计数，数到 ARR 就溢出并产生更新事件。周期 = $(PSC+1)(ARR+1)/f_{TIM}$。
2. **三个核心寄存器**：`PSC`（预分频，决定计数快慢）、`ARR`（自动重装载，决定周期）、`CCR`（捕获/比较，决定占空比或触发点）。**公式里全都有 +1**。
3. **PWM 靠「CNT 与 CCR 比较」产生**：CNT < CCR 时输出一种电平，超过就翻转。改 CCR 就是改占空比，改 ARR 就是改频率。
4. **输入捕获**是 PWM 的逆过程：外部信号的边沿触发时把 CNT 的值锁存下来，两次锁存之差就是周期——用来测频率、测脉宽。
5. **分辨率与频率此消彼长**：ARR 越大占空比越精细，但 PWM 频率越低。选型时要先定频率，再看剩下多少分辨率。

## 一、定时器的三个组成部分

| 部分 | 寄存器 | 作用 |
| --- | --- | --- |
| **时基单元** | `PSC`、`ARR`、`CNT` | 产生基本的时间基准（多久数一次、数到多少溢出） |
| **捕获/比较通道** | `CCRx` | 输出 PWM（比较）或测量外部信号（捕获） |
| **时钟与触发** | 内部时钟 / 外部时钟 / 其他定时器 | 决定计数来源，可实现级联和同步 |

计数模式：

- **向上计数**（最常用）：CNT 从 0 数到 ARR，溢出后回 0，产生更新事件（可触发中断）；
- **向下计数**、**中心对齐**（先上后下）：中心对齐用于电机控制，因为 PWM 对称、谐波更小。

**频率与周期公式**（记住 +1）：

$$f_{cnt} = \frac{f_{TIM}}{PSC + 1},\qquad T_{更新} = \frac{(ARR + 1)}{f_{cnt}} = \frac{(PSC+1)(ARR+1)}{f_{TIM}}$$

::: tip 例 1 · 用 72 MHz 定时器做 1 ms 定时中断
定时器时钟 72 MHz（F103 经典配置，APB1 定时器已 ×2）。

**第一步**：选预分频，让计数频率是个好算的数。取 PSC = 71：

$$f_{cnt} = \frac{72\ \text{MHz}}{71 + 1} = 1\ \text{MHz} \quad(\text{即 1 } \mu\text{s 数一次})$$

**第二步**：1 ms = 1000 µs，所以数 1000 次，取 ARR = 999：

$$T = \frac{999 + 1}{1\ \text{MHz}} = 1\ \text{ms}$$

代码：

```c
htim2.Instance = TIM2;
htim2.Init.Prescaler = 71;          // PSC
htim2.Init.Period = 999;            // ARR
htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
HAL_TIM_Base_Init(&htim2);
HAL_TIM_Base_Start_IT(&htim2);      // 带中断启动

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
  if (htim->Instance == TIM2) {
    HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);   // 每 1 ms 翻转一次 → 500 Hz 方波
  }
}
```

**常见错误**：把 ARR 写成 1000（想「数 1000 次」），结果周期变成 1001 µs。硬件是「数到 ARR 值再溢出」，所以要 **−1**。
:::

## 三、PWM 输出

PWM（Pulse Width Modulation，脉宽调制）用「高电平占比」来等效地输出一个模拟量：

- **频率**由 ARR 决定：$f_{PWM} = f_{cnt} / (ARR+1)$
- **占空比**由 CCR 决定：$\text{duty} = CCR / (ARR+1)$
- **等效电压**：$V_{avg} = V_{CC} \times \text{duty}$（经 RC 滤波后就是真正的直流电压）

配置要点（HAL）：

```c
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);      // 启动 PWM 输出
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 300);   // 改 CCR（占空比）
__HAL_TIM_SET_AUTORELOAD(&htim3, 999);               // 改 ARR（频率）
```

**PWM 模式 1 vs 模式 2**：模式 1 是「CNT < CCR 时输出有效电平」，模式 2 相反。所谓「有效电平」由极性配置决定（`TIM_OCPOLARITY_HIGH/LOW`）。**占空比反了就调这两处**。

::: tip 例 2 · 驱动舵机：50 Hz、90°
舵机的控制信号是 **50 Hz**（周期 20 ms）的 PWM，靠**绝对脉宽**决定角度：

| 角度 | 脉宽 | 占空比 |
| --- | --- | --- |
| 0° | 0.5 ms | 2.5% |
| **90°** | **1.5 ms** | **7.5%** |
| 180° | 2.5 ms | 12.5% |

用 1 MHz 计数频率（PSC = 71）：

$$\text{ARR} + 1 = \frac{1\ \text{MHz}}{50\ \text{Hz}} = 20000 \ \Rightarrow\ \text{ARR} = 19999$$
$$\text{CCR}(90°) = 1.5\ \text{ms} \times 1\ \text{MHz} = 1500$$

同理 0° → CCR = 500，180° → CCR = 2500。

**要点**：舵机**只认脉宽不认占空比**，所以必须先把频率固定在 50 Hz，再调 CCR。如果 ARR 改了（频率变了），同样的 CCR 就对应不同的角度——这也是「舵机角度不准」的常见原因。
:::

::: tip 例 3 · 用输入捕获测频率
把输入捕获配成「上升沿捕获」，两次捕获的 CNT 差值就是信号周期。设计数频率 1 MHz：

| 捕获差值 | 周期 | 频率 |
| --- | --- | --- |
| 1000 | 1.000 ms | **1000 Hz** |
| 500 | 0.500 ms | 2000 Hz |
| 2000 | 2.000 ms | 500 Hz |

$$\text{周期} = \frac{\Delta CNT}{f_{cnt}},\qquad f = \frac{f_{cnt}}{\Delta CNT}$$

**分辨率问题**：1 MHz 计数下，1 kHz 附近相邻两个计数值对应的频率差约 **1 Hz**（$10^6/1000 - 10^6/1001 \approx 1$）。测 1 kHz 时相对分辨率 0.1%，够用；但测 100 kHz 时 $\Delta CNT = 10$，差一个计数就是 10 kHz 的跳变（10% 误差），此时应**降低 PSC**（提高计数频率）或改用**测频法**（在固定闸门时间内数脉冲个数）。

**溢出处理**：若被测信号周期很长，CNT 可能在两次捕获之间溢出多次，需要记录溢出次数一起计算——这是输入捕获的进阶坑。
:::

::: tip 例 4 · PWM 分辨率与频率的取舍
同一个计数器，ARR 越大 → 分辨率越高，但频率越低：

| ARR | 频率（1 MHz 计数） | 占空比步进 |
| --- | --- | --- |
| 99 | 10 kHz | **1%**（100 级） |
| 999 | 1 kHz | **0.1%**（1000 级） |
| 9999 | 100 Hz | 0.01%（10000 级） |

$$\text{步进} = \frac{1}{ARR + 1}$$

**怎么选**：

- **LED 调光**：1 kHz、ARR = 999（0.1% 步进）足够，人眼看不出台阶；
- **舵机**：频率被锁死 50 Hz，ARR = 19999 → 步进 0.005%，分辨率非常富裕；
- **音频/超声波**：需要 20 kHz 以上，ARR 被迫变小，分辨率下降——此时要**提高计数频率**（减小 PSC）来补偿。

记住这个关系式：$f_{PWM} \times \text{级数} = f_{cnt}$。在计数频率固定的情况下，频率和分辨率是**此消彼长**的。
:::

## 四、编码器接口

正交编码器输出 A、B 两相脉冲（相位差 90°）。定时器配成编码器模式后**硬件自动根据两相的相位关系判断方向并增减 CNT**，不需要软件干预——电机测速、旋钮输入都靠它。

- 通常配成 **TI1 和 TI2 双边沿计数**（4 倍频），即编码器转一圈的计数 = 物理线数 × 4；
- CNT 溢出由 ARR 决定，读速度时用「两次读数之差」并处理溢出回绕。

## 五、高级定时器（TIM1/TIM8）的额外能力

- **互补输出 + 死区**：输出一对互补的 PWM（驱动 H 桥的上下管），并插入死区时间防止两管直通短路。这是电机控制和开关电源的必需功能。
- **刹车输入**（BKIN）：外部故障信号可直接硬件关断输出，响应速度比软件快得多。
- **重复计数器**：让 PWM 周期是更新周期的若干倍。

## 六、工程实例

**呼吸灯**：用 PWM 调光，让 CCR 从 0 平滑增加到 ARR 再减回 0，人眼看到的就是亮度渐变。注意**亮度感知是非线性的**（人眼对暗部变化更敏感），直接用线性 ramp 会觉得「前半段变化快、后半段慢」，实际产品里要用 gamma 校正（如按平方或指数曲线调整）。

**直流电机调速**：用 PWM 控制电机平均电压。频率选择很关键——太低（<1 kHz）会听到线圈的啸叫并出现抖动，太高（>20 kHz）开关损耗增大；**常用 10~20 kHz**，既能避开人耳听觉范围，开关损耗也可接受。

## 七、易错清单 + 自检

- [ ] **PSC / ARR 忘了 +1**（或反过来多减了 1）
- [ ] **定时器时钟忘了 ×2**：APB 分频 ≠ 1 时定时器时钟会翻倍（见 [04 章](./clock.md)）
- [ ] **改了 ARR 却没同步改 CCR**：占空比会跟着变（舵机角度漂移就是这个原因）
- [ ] **PWM 输出没配成复用模式**（或没开 AFIO 时钟）→ 引脚无信号
- [ ] **占空比反了**：调 PWM 模式（模式 1/2）或输出极性
- [ ] **输入捕获测高频时分辨率不够**：降低 PSC 提高计数频率
- [ ] **编码器模式没设 4 倍频**：分辨率少 4 倍
- [ ] **在中断里做耗时计算**：定时中断里只置标志

**自检**：72 MHz 定时器要产生 1 ms 中断，PSC 和 ARR 各取多少？舵机 90° 在 50 Hz、1 MHz 计数下的 CCR 是多少？ARR 从 999 改到 99，PWM 频率和占空比分辨率分别怎么变？（答案：PSC=71、ARR=999；CCR=1500；频率从 1 kHz 升到 10 kHz，分辨率从 0.1% 降到 1%）
