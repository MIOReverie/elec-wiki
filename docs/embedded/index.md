# 嵌入式开发

<Meta time="8 min" level="指南" note="从「会算电路」到「让芯片干活」：MCU 架构、外设、RTOS 一条线打通" />

前面三门课让你**看懂**电路与信号：电工学讲连续量，数电讲逻辑状态，模电讲模拟器件的微观机理。但它们停在了原理——你还没真的让一个芯片去**读一个按键、发一串串口、控一台电机**。

嵌入式开发就是这最后一步：**把物理世界和数字世界连起来，让 MCU 按你的程序跑起来**。本课程以 **STM32（ARM Cortex-M 内核）** 为载体——工业与教学里最主流的 32 位单片机，资料多、生态全；但讲的概念（时钟树、GPIO、中断、定时器、UART/SPI/I²C、ADC/DMA、RTOS）是**所有 MCU 通用的**，换到 ESP32、GD32、NXP 也只差寄存器名字。

## 学完能得到什么

- 从零建一个 STM32 工程，独立完成编译、下载、断点调试与串口打印；
- 读懂时钟树，算清 PLL 与 AHB/APB 分频，知道「外设为什么不工作」的第一嫌疑是没开时钟；
- 把 GPIO 四种模式、上下拉、开漏/推挽与实际接法对应起来，写出不抖的按键检测；
- 配置中断与 NVIC 优先级，解释抢占、子优先级、咬尾与晚到；
- 用定时器做 PWM、输入捕获与编码器测速，用 UART/SPI/I²C 与传感器通信；
- 用 ADC + DMA 采数据、做滤波；用 FreeRTOS 把裸机 super-loop 拆成任务；
- 做一次完整的低功耗设计，知道 Sleep/Stop/Standby 的代价与唤醒源；
- 用定时器 PWM 驱动一个真实执行器（舵机），算清 PSC/ARR/CCR，并且知道抖动与烧板大多出在供电和地上。

### 关于第 13 章

**13 · 舵机控制：从 PWM 脉宽到角度** 是本课的「第一个真正动起来的项目」：它把 07 章的定时器 PWM 落到一个具体器件上，并且是**唯一一节把电源与接线当成主线讲**的章节——舵机堵转电流是开发板 LDO 的十倍量级，「代码全对但一直抖/一直复位」的根因几乎都在这里。建议在学完 07 章后立刻读，配合一个 SG90 和一块外部 5 V 电源动手；如果要扩展成多路机械臂，再去读 11 章用 RTOS 做任务调度。

如果只想要**结论清单**：50 Hz、0.5–2.5 ms、1.5 ms 中位、72 MHz → PSC 71 / ARR 19999 / CCR 500~2500、84 MHz → PSC 83；舵机必须独立 5 V 供电且与 STM32 共地。

## 和前三门课的关系（以及两种读法）

- **电工学**：推挽/开漏输出、上下拉电阻、电平标准（TTL/CMOS）——在 GPIO 章直接复用，不用重学；13 章的电源估算本质上是一次直流电源与线路压降的计算——堵转电流 × 回路电阻 = 你实际送到舵机上的电压，这和[电工学 · 等效电路](../ee/02-methods/equivalent)里的戴维南模型是同一件事。
- **数字电路**：寄存器、时序、总线仲裁（三态/开漏总线）——UART/SPI/I²C 的帧和波形，本质是数电时序的工业版。
- **模拟电子**：ADC 把模拟电压量化成数字码、运放做信号调理、PWM 滤波出模拟量——模电的「模拟↔数字接口」在这里闭环；13 章里舵机内部的「电位器反馈 + 误差驱动电机」则是这套模拟接口在机电系统里的原型。

两种读法：

- **有电路基础**：跳过「为什么推挽」「为什么上拉」这类铺垫，直奔「寄存器怎么配、HAL 怎么用、坑在哪」。
- **零基础直接来**：每章都从「这个器件/概念在物理上是什么」讲起，依赖的电路知识用前置知识胶囊兜底。

## 暂不涉及的内容

以下不是不学，而是明确**不在这一版课程里**：CAN/LIN 总线、USB、以太网、嵌入式 Linux（Cortex-A）、LVGL 图形界面、OTA/固件安全、MISRA-C 规范；舵机只讲标准模拟舵机（PWM 接口），不讲串行总线数字舵机（RS485/CAN 舵机）的协议层。先把手脚（MCU 外设 + RTOS + 一个能动的执行器）练熟，再选赛道深挖。
