# 01 · 半导体器件

<Meta time="50 min" level="核心" note="二极管/稳压管/三极管/场效应管四种积木的特性、参数与直流分析" />

## 结论先行

1. **本征半导体掺杂成 P / N 型**，PN 结的单向导电性（正偏导通、反偏截止）派生出二极管、稳压管、三极管、场效应管全部器件——**四种器件共享同一个结**。
2. **二极管近似模型三档**：理想（0 V 导通）、恒压（硅 0.7 V / 锗 0.2 V）、折线（死区 + 导通电阻）。工程估算用恒压模型，精度要求高时用指数特性。
3. **稳压管工作在反向击穿区**：电压几乎不随电流变。限流电阻必须同时满足「$I_Z$ 不小于维持电流」和「$I_Z$ 不超过最大功耗」，两头都要算。
4. **三极管是电流控制器件**：$I_C=\beta I_B$、$I_E=I_B+I_C$。三种接法（共射/共集/共基）不是换管子，是换「哪个极接地」。
5. **场效应管是电压控制器件**：$I_D=g_mV_{GS}$，输入电阻极高。增强型 MOS 有开启电压 $V_{GS(th)}$，低于它完全截止——这就是「CMOS 输入不能悬空」的根源。

## 推导脉络：从一块硅到一个器件

```
本征硅（载流子很少，不爱导电）
  │ 掺五价元素 → N 型（多电子）
  │ 掺三价元素 → P 型（多空穴）
  ▼
P 型 + N 型 → PN 结
  │ 空间电荷区（耗尽层）形成内电场
  │ 正偏：外电场削弱内电场 → 多子扩散 → 导通
  │ 反偏：外电场加强内电场 → 少数载流子漂移 → 截止
  ▼
三种命运：
  只用单向导电性 ──────────────► 二极管 / 稳压管
  两个背靠背的结 + 薄基区 ─────► 三极管（用 IB 控制 IC）
  用电场控制沟道宽度 ──────────► 场效应管（用 VGS 控制 ID）
```

## 图解②：三极管的三个区与偏置

| 发射结 | 集电结 | 状态 | 特征 |
| --- | --- | --- | --- |
| 正偏 | 反偏 | **放大区** | $I_C=\beta I_B$，$V_{CE}$ 随 $I_B$ 增大而减小 |
| 正偏 | 正偏 | **饱和区** | $I_C$ 到顶（受 $V_{CC}/R_C$ 限制），$V_{CE}\approx0.3\,\text{V}$，c-e 当开关用 |
| 反偏 | 反偏 | **截止区** | $I_B\le0$、$I_C\approx0$，c-e 当断开用 |

「放大」是线性区，「饱和/截止」是开关区——第 2 章用放大区，数字电路的驱动、继电控制（[电工学 19-21 章](../ee/07-control/relay.md)）用开关区。

## 典型例题（数字均经计算）

::: tip 例 1 · 二极管限幅电路
输入 $u_i=10\sin\omega t\,\text{V}$，经一只硅二极管（恒压模型 0.7 V）限幅。正半周二极管导通，输出被钳在 $10-0.7=9.3\,\text{V}$；负半周截止，输出 0。若去掉二极管直接整流，输出峰值 10 V——**限幅的用途就是把后级电压摁在安全线内**。硅管 0.7 V 与锗管 0.2 V 的差异在信号很小（mV 级）时不可忽略，高频检波电路至今偏爱锗管或肖特基管正是这个原因。
:::

::: tip 例 2 · 稳压管限流电阻的设计
$V_S=12\,\text{V}$（允许 ±10% 波动）、$V_Z=6\,\text{V}$、负载 $R_L=1\,\text{k}\Omega\sim\infty$。限流电阻的电流要被稳压管和负载分走：$I_R=I_Z+I_L$。
- 最坏情况在「输入最低 + 负载最重」：$I_{R\min}=(10.8-6)/R$、$I_{L\max}=6\,\text{mA}$；
- 要稳压管始终维持击穿（$I_Z\ge5\,\text{mA}$），需 $R\le(10.8-6)/(5+6)=436\,\Omega$；
- 取 $R=360\,\Omega$：$I_Z$ 在 $13.33-6=7.33\,\text{mA}$ 到 $20\,\text{mA}$ 之间；
- 功耗校核：电阻最大 $(13.2-6)^2/360\approx144\,\text{mW}$（选 0.5 W），稳压管最大 $6\times20=120\,\text{mW}$（选 0.5 W）。
- **失效模式**：若负载跌到 $300\,\Omega$，$I_L=20\,\text{mA}>I_{R\min}=13.33\,\text{mA}$，稳压管被「饿死」退出击穿，稳压失败——限流电阻必须按最坏工况算，不能只算标称值。
:::

::: tip 例 3 · 三极管的电流分配与工作区判断
$\beta=100$、$I_B=20\,\mu\text{A}$，则 $I_C=\beta I_B=2.0\,\text{mA}$、$I_E=(1+\beta)I_B=2.02\,\text{mA}$——注意 $I_E$ 略大于 $I_C$，差别就在那 $20\,\mu\text{A}$ 的基极电流。若 $V_{CC}=12\,\text{V}$、$R_C=3\,\text{k}\Omega$，临界饱和电流 $=12/3=4\,\text{mA}>2\,\text{mA}$，管子在**放大区**；若 $I_B$ 增大到 $60\,\mu\text{A}$，需求 $6\,\text{mA}>4\,\text{mA}$，管子**饱和**，$V_{CE}$ 被摁在 0.3 V 附近，不再 obey $I_C=\beta I_B$。**判断方法：先算 $I_C=\beta I_B$，再算 $V_{CC}/R_C$ 这个天花板，谁小听谁的。**
:::

::: tip 例 4 · 增强型 MOS 管的恒流区计算
N 沟道增强型 MOS，$V_{GS(th)}=2\,\text{V}$，跨导参数 $K=0.5\,\text{mA/V}^2$。$V_{GS}=4\,\text{V}$ 时过驱动电压 $V_{ov}=2\,\text{V}$，饱和电流 $I_D=KV_{ov}^2=2.0\,\text{mA}$。预夹断点在 $V_{DS}=V_{GS}-V_{th}=2\,\text{V}$，实际 $V_{DS}=6\,\text{V}>2\,\text{V}$，确认在恒流区。跨导 $g_m=2KV_{ov}=2.0\,\text{mS}$——它是[第 2 章](./amplifiers.md)放大倍数的核心参数。若 $V_{GS}$ 掉到 1.5 V（低于开启电压），$I_D=0$，管子彻底关断。
:::

## 工程实例：一块电路板上的四种管子

打开一台普通开关电源适配器，四种器件都在：

- **整流桥里的四个二极管**：把交流切成单向（见[电工学 22 章](../ee/08-electronics/rectifier.md)），工作在开关区；
- **功率三极管/MOS**：高频开关，饱和与截止两态切换（[PWM 调速](../digital/ad-da.md)同一思想）；
- **稳压管或 TL431**：采样反馈回路的基准电压源（例 2 的实际应用）；
- **运放**：误差放大器，比较输出采样与基准——一个运放内部就有十几对差分管（第 5 章主角）。

## 易错清单 + 自检

- **二极管导通压降的方向**：电流从阳极进才降压 0.7 V，方向搞反会把一个 0.7 V 的电源当成断路。
- **稳压管不能反接当普通二极管用**：它设计的工作点就在击穿区，正偏时反倒像个普通二极管。
- **三极管的 $\beta$ 不是常数**：随 $I_C$ 和温度明显变化，精确设计必须留余量（$\beta$ 可能腰斩）。
- **饱和区的 $I_C\ne\beta I_B$**：这是最常见的分析错误——先判区，再选公式。
- **MOS 是绝缘栅**：手指一抹就是一层静电荷场，焊接时必须先放电——双极型三极管没这么娇气，但 MOS 拆封就得小心。
- 自检：在 <DiodeCurveDemo /> 三极管页签，把 $I_{BQ}$ 从 0 拖到 50 μA——Q 点是不是沿负载线一路上爬、$I_C$ 到 $V_{CC}/R_C$ 就不再涨？是，说明「负载线封顶 = 饱和」你已经在曲线上看明白了。
