# 02 · 基本放大电路

<Meta time="60 min" level="核心" note="静态工作点估算 + Au/ri/ro 三大动态参数 + 三种接法对比，全课程的承重墙" />

本章的承重概念有两个：静态工作点与负载线（<Prereq id="q-point-loadline" />），以及管子究竟工作在哪一个区（<Prereq id="bjt-regions" />）。

## 结论先行

1. **放大 = 交直流共存**：直流管「站在哪」（静态工作点 Q），交流管「放大谁」（动态信号）。先算直流、再算交流，两套图分开画——**直流通路电容开路，交流通路电容短路 + 直流源接地**。
2. **Q 点必须设在中部**：偏低截止失真（顶削平），偏高饱和失真（底削平）。固定偏置电路 Q 点随 $\beta$ 漂移，分压式偏置用 $R_E$ 的直流负反馈把它稳住。
3. **共射放大电路**：电压增益 $A_u=-\beta R_L'/r_{be}$（负号 = 倒相）、输入电阻 $r_{be}$ 级（kΩ）、输出电阻 $R_C$ 级（kΩ）——**电压电流都能放大**。
4. **共集电极（射极输出器）**：$A_u\approx1$、输入电阻很高、输出电阻很低——不放大电压，专治「带不动负载」。
5. **共基极电路**：输入电阻低到几十 Ω、高频特性好—— radio 前端的老将。

## 推导脉络：一个共射放大电路的分析全过程

以分压偏置共射电路为例（$V_{CC}=12\,\text{V}$，$R_{b1}=20\,\text{k}\Omega$，$R_{b2}=10\,\text{k}\Omega$，$R_C=2\,\text{k}\Omega$，$R_E=2\,\text{k}\Omega$，$R_L=3\,\text{k}\Omega$，$\beta=60$）：

**第一步 静态（直流）**：电容开路，只剩电阻网络。
$$V_B\approx V_{CC}\frac{R_{b2}}{R_{b1}+R_{b2}}=4\,\text{V},\quad V_E=V_B-0.7=3.3\,\text{V},\quad I_E=\frac{V_E}{R_E}=1.65\,\text{mA}$$
$$I_C\approx I_E=1.65\,\text{mA},\quad V_{CE}=V_{CC}-I_C(R_C+R_E)=5.4\,\text{V}\ (\approx\tfrac12 V_{CC}\ \checkmark)$$

**第二步 检查分压稳定性**：流过 $R_{b1}$ 的电流 $600\,\mu\text{A}$ 应是 $I_B$（$27.5\,\mu\text{A}$）的 5~10 倍以上——比值 22，分压器不会被基极电流拖垮，估算成立。

**第三步 动态（交流）**：电容短路、$V_{CC}$ 接地，三极管换成小信号模型（$r_{be}$ + 受控源 $\beta i_b$）。
$$r_{be}=300+(1+\beta)\frac{26\,\text{mV}}{I_E}\approx1.26\,\text{k}\Omega,\quad R_L'=R_C//R_L=1.2\,\text{k}\Omega$$
$$\dot A_u=\frac{\dot U_o}{\dot U_i}=-\frac{\beta R_L'}{r_{be}}=-57$$

**第四步 输入输出电阻**：$r_i=R_{b1}//R_{b2}//r_{be}\approx1.06\,\text{k}\Omega$，$r_o=R_C=2\,\text{k}\Omega$。

**第五步 源增益**：若信号源内阻 $R_S=1\,\text{k}\Omega$，信号先在 $R_S$ 和 $r_i$ 上分掉一半，$\dot A_{us}=-57\times\dfrac{1.06}{1.06+1}\approx-29$——**放大电路不是孤立器件，增益永远是对「源」而言的**。

拖动 $R_{b2}$ 直接搬动 Q 点，输入幅度不变，看输出波形哪一侧先塌——这就是「截止失真 / 饱和失真」的现场。再加大输入幅度，波形从某一侧开始削顶，**边界永远先撞向靠近的那一侧**。面板同时实时给出 $A_u$、$r_i$、$r_o$ 和最大不失真峰值，四个参数随偏置联动的趋势一眼可见。

## 图解②：三种接法的性格对比

| | 共射 | 共集（射随） | 共基 |
| --- | --- | --- | --- |
| 电压增益 | 大（几十~几百） | ≈1（略小于 1） | 大（同共射数量级） |
| 电流增益 | $\beta$ | $1+\beta$ | ≈$\alpha\approx1$ |
| 输入电阻 | 中（kΩ 级） | **高**（几十 kΩ 以上） | **低**（几十 Ω） |
| 输出电阻 | 高（$R_C$） | **低**（几十 Ω） | 高（$R_C$） |
| 相位 | 倒相 | 同相 | 同相 |
| 典型用途 | 电压放大主力 | **缓冲 / 阻抗匹配** | 高频、宽频带 |

记忆法：**共射是全能选手，共集是「和事佬」（电压不放大但谁都带得动），共基是「高速直男」（不挑负载但输入阻抗太低）**。多级放大器的经典搭配：共射提增益 + 共集做输出级。

## 典型例题（数字均经计算）

::: tip 例 1 · 静态工作点估算（上文电路完整版）
分压式估算三步：$V_B\to V_E\to I_E\to V_{CE}$。结果 $I_C=1.65\,\text{mA}$、$V_{CE}=5.4\,\text{V}$、$I_B=27.5\,\mu\text{A}$。检查：$I_{R_{b1}}=600\,\mu\text{A}\approx22 I_B$ ✓；$V_{CE}=5.4\,\text{V}$ 接近 $\frac{V_{CC}}2$ ✓。若把 $R_E$ 从 $2\,\text{k}\Omega$ 误读成旁路后短路，$I_E$ 会从 1.65 mA 暴涨到十几 mA、$V_{CE}$ 掉到 0 附近——**$R_E$ 上有没有并电容，是静态与动态分析最容易分心的地方**。
:::

::: tip 例 2 · 动态参数计算（上文电路完整版）
$r_{be}=1.26\,\text{k}\Omega$，$R_L'=R_C//R_L=1.2\,\text{k}\Omega$。
$$\dot A_u=-\frac{\beta R_L'}{r_{be}}=-\frac{60\times1.2\,\text{k}}{1.26\,\text{k}}\approx-57$$
$$r_i=R_{b1}//R_{b2}//r_{be}\approx1.06\,\text{k}\Omega,\qquad r_o=R_C=2\,\text{k}\Omega$$
若旁路电容 $C_E$ 开路（坏了），$R_E$ 串进发射极，$\dot A_u=-\dfrac{\beta R_L'}{r_{be}+(1+\beta)R_E}=-\dfrac{60\times1.2\,\text{k}}{1.26\,\text{k}+122\,\text{k}}\approx-9.8$——**从 −57 暴跌到 −9.8，而电路照样「通」**。放大倍数凭空变小、查不出短路时，先怀疑旁路电容。
:::

::: tip 例 3 · 最大不失真输出电压
静态 $V_{CEQ}=5.4\,\text{V}$、$I_{CQ}=1.65\,\text{mA}$。往两个方向能走的余量：
- 饱和侧：$5.4-0.3=5.1\,\text{V}$；
- 截止侧：$I_{CQ}\times R_L'=1.65\,\text{mA}\times1.2\,\text{k}\Omega=1.98\,\text{V}$。

取小者：**最大不失真峰值 1.98 V**（有效值 1.40 V，峰峰值 3.96 V）——这个电路是「截止侧先到」，想提高输出得抬高 $I_{CQ}$ 或减小 $R_C$，但 $I_{CQ}$ 抬高又会让饱和侧余量变小，**最优 Q 点让两侧余量相等**。
:::

::: tip 例 4 · 共集电极（射极输出器）：阻抗匹配的算术
同一偏置，$R_E=2\,\text{k}\Omega$ 直接接地当负载。$g_m=I_E/26\,\text{mV}\approx63.5\,\text{mS}$：
$$\dot A_u=\frac{g_mR_E}{1+g_mR_E}=\frac{127}{128}\approx0.992$$
$$r_i=R_{b1}//R_{b2}//[r_{be}+(1+\beta)R_E]=6.67\,\text{k}//123\,\text{k}\approx6.3\,\text{k}\Omega$$
$$r_o=R_E//\frac{r_{be}+(R_S//R_{b1}//R_{b2})}{1+\beta}\approx34\,\Omega\quad(R_S=1\,\text{k}\Omega)$$
电压增益不到 1，但输入 $6.3\,\text{k}\Omega$、输出 $34\,\Omega$——**把高阻信号源接到低阻负载的经典桥**。传感器、麦克风、电缆驱动，全是它的活。
:::

## 工程实例：示波器前级的信号链

一台示波器的输入衰减 + 前放，就是[第 2 章 · 基本放大电路](amplifiers.md)电路的工程放大版：

- 探头衰减 10:1，把几百伏的信号压到示波器量程；
- 前级共射放大器提增益，用**多级级联**（级间直接耦合或电容耦合）达到 $1\,\text{mV/div}$ 的灵敏度；
- 最后一级射随做缓冲——示波器输入阻抗标称 $1\,\text{M}\Omega$，没有高阻输入级，探头一接就把被测电路拖垮了；
- 增益切换用继电器换反馈电阻，本质就是改 $\dot A_u$（[第 6 章 · 放大电路中的反馈](feedback.md)负反馈的雏形）。

## 易错清单 + 自检

- **直流通路与交流通路必须分开**：电容在直流是开路、交流是短路，混用是最高频错误。
- **$R_L$ 只在动态出现**：静态算 $V_{CE}$ 不带 $R_L$，动态算 $\dot A_u$ 必须带 $R_L'$。
- **$r_{be}$ 是「动态电阻」不是定值**：它随 $I_E$ 变（$I_E$ 翻倍，$r_{be}$ 大致减半），所以 $\dot A_u$ 也随工作点漂移。
- **负号别丢**：共射输出倒相，$\dot A_u<0$。只写大小不写符号，后面反馈极性（[第 6 章 · 放大电路中的反馈](feedback.md)）一定错。
- **最大不失真输出取两侧余量的较小值**，不是简单等于 $\frac12V_{CC}$。
- 自检：在 <AmpDemo /> 里把输入幅度拉到 60 mV，然后慢慢拖小 $R_{b2}$——输出底部先削的是不是伴随 $I_{CQ}$ 变大？把这个因果关系说给自己听，工作点与失真的关系就再也忘不掉了。
