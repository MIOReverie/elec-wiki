# 08 · 波形的发生和变换

<Meta time="45 min" level="核心" note="正弦振荡的相位/幅值两条件 + RC/LC/石英三代 + 非正弦波发生器" />

## 结论先行

1. **振荡 = 正反馈 + 选频 + 稳幅**。两个条件缺一不可：**相位条件**（环路相移 0°，正反馈）与**幅值条件**（环路增益 ≥1）。只满足相位条件叫「谐振」，不振荡。
2. **文氏桥 RC 振荡器**：$f_0=1/(2\pi RC)$，起振要求同相放大器增益 $>3$（$R_f>2R_1$）；频率低（Hz~百 kHz）、频率稳定度差（$10^{-3}\sim10^{-2}$），适合音频。
3. **LC 振荡器**：$f_0=1/(2\pi\sqrt{LC})$，频率高（百 kHz~百 MHz）、稳定度 $10^{-4}\sim10^{-5}$，无线电的主力。
4. **石英晶体**：等效 $Q$ 高达 $10^4\sim10^6$，稳定度 $10^{-6}$ 以上——**一切数字系统时钟的祖宗**（见[数电 06 章 555](../digital/counters.md)的对照）。
5. **非正弦波发生器**（方波/三角波/锯齿波）= 滞回比较器 + 积分器，[第 7 章](./signal-processing.md)两个方块一接就成。

## 推导脉络：从自激（坏）到振荡器（好）

[第 6 章](./feedback.md)里自激是要防的病害：相移 180° + $|AF|\ge1$ → 寄生振荡。同一章反着读就是振荡器设计：**主动把相移凑成 0°（或 360°），把增益设到刚好过 1**。区别只在于「选频网络」：放大器的相移随频率乱跑，选频网络只在一个频率上恰好满足相位条件，于是振荡频率被钉死。

```
正反馈环路 ─► [ 选频网络：只在 f0 处相移为 0 ] ─► [ 放大器：增益略大于 1 ]
                                                        │
                       稳幅环节 ◄─── 输出太大时自动压低增益 ─┘
```

稳幅必须非线性（二极管、热敏电阻、灯丝、AJC 自动增益控制）：线性元件增益恒定，振幅会一路涨到饱和，波形削成平顶。

## 图解①：三类正弦振荡器的分工

| | 文氏桥 RC | LC 变压器反馈 | 石英晶体 |
| --- | --- | --- | --- |
| 频率公式 | $f_0=1/2\pi RC$ | $f_0=1/2\pi\sqrt{LC}$ | 由切片厚度决定（标称值） |
| 典型频段 | 1 Hz ~ 数百 kHz | 数百 kHz ~ 数百 MHz | 32.768 kHz ~ 100 MHz+ |
| 稳定度 | $10^{-3}\sim10^{-2}$ | $10^{-4}\sim10^{-5}$ | $10^{-6}\sim10^{-8}$ |
| 成本/体积 | 最低 | 中 | 低（但需专用振荡电路） |
| 用途 | 音频信号源、报警音 | 收音机本振、射频 | 单片机时钟、通信基准 |

三个页签分别把上表最难「想出来」的部分变成可拖动的：文氏桥起振的包络增长/衰减、方波-三角波的峰値与频率各归各管、LC 谐振曲线随 Q 变尖。

## 典型例题（数字均经计算）

::: tip 例 1 · 文氏桥振荡器的设计
$R=10\,\text{k}\Omega$、$C=0.01\,\mu\text{F}$：$f_0=1/(2\pi RC)=1591.5\,\text{Hz}\approx1.59\,\text{kHz}$。RC 串并联网络在 $f_0$ 处相移为 0、反馈系数 $F=1/3$，所以后级同相放大器必须 $1+R_f/R_1>3$，即 $R_f>2R_1$；取 $R_1=10\,\text{k}\Omega$、$R_f=22\,\text{k}\Omega$（增益 3.2）留起振余量。起振后靠一对二极管（或热敏电阻）把增益自动压回 3，稳定等幅。**若把 $R_f$ 调到刚好 2 倍，理论上能振荡实际上不起振**——元件公差会让环路增益小于 1。
:::

::: tip 例 2 · LC 振荡器与谐振阻抗
$L=100\,\mu\text{H}$、$C=0.01\,\mu\text{F}$：$f_0=1/(2\pi\sqrt{LC})=159.2\,\text{kHz}$。特性阻抗 $\rho=\sqrt{L/C}=100\,\Omega$；若线圈 $Q=100$，谐振时并联阻抗 $=Q\rho=10\,\text{k}\Omega$——**LC 回路在谐振频率上「变」成一个高阻选频器**，负载接上去会显著降低 Q、拉偏频率，所以实际电路用部分接入（抽头）减小负载影响。
:::

::: tip 例 3 · 石英晶体为什么准
石英片的压电效应把它变成一个机械谐振子，等效电路中 $L$ 极大（几十 mH~几 H）、$C$ 极小、$R$ 极小，$Q$ 值达 $10^5$ 量级。串联谐振频率
$$f_s=\frac{1}{2\pi\sqrt{L_qC_q}},\qquad f_p=f_s\sqrt{1+\frac{C_q}{C_0}}$$
$f_s$ 与 $f_p$ 之间只有约 0.3% 的频率窗口，晶体要么当串联谐振器（$f_s$）要么当电感（$f_s\sim f_p$）。对比 RC 的 $10^{-3}$：**石英把频率不确定度压小了三个数量级**，所以 32.768 kHz 手表晶振一天误差不到一秒，而 RC 音频振荡器按小时漂移。
:::

::: tip 例 4 · 方波/三角波发生器
滞回比较器（阈值 $\pm U_Z\dfrac{R_1}{R_1+R_2}$）+ 反相积分器（$R$、$C$）闭环相接：比较器输出 $\pm U_Z$ 驱动积分器，积分器输出反过来越过阈值触发比较器翻转，循环往复。频率
$$f=\frac{R_1+R_2}{4R_1RC}$$
取 $R_1=R_2=R=10\,\text{k}\Omega$、$C=0.1\,\mu\text{F}$：$f=\dfrac{20\,\text{k}}{4\times10\,\text{k}\times10\,\text{k}\times0.1\,\mu}=500\,\text{Hz}$。改变 $C$ 一个数量级就换一个频段——函数信号器的核心级就是这么干的，三角波再过一级折线近似就是正弦波。
:::

## 工程实例：一块单片机板上的三种振荡

- **16 MHz 石英 + 反相器**：CPU 主时钟，$10^{-6}$ 级稳定度保证串口波特率不错帧；
- **32.768 kHz 石英**：RTC 实时时钟，2<sup>15</sup> 分频正好得 1 s（[数电 06 章](../digital/counters.md)计数器的经典用法）；
- **RC 振荡（内部）**：看门狗和上电延时，$10^{-2}$ 稳定度无所谓，省一个晶振钱；
- **没有振荡器的场合**：PWM 调速（[数电 08 章](../digital/ad-da.md)）直接用定时器时钟分频——频率精度跟着主时钟，不需要选频网络。

## 易错清单 + 自检

- **两个条件都要查**：相位 0° 但增益 0.5 → 不起振；增益 3 但相移不对 → 不起振或乱振。上电第一件事用示波器看波形，别只看频率计读数。
- **起振增益要略大于 1，稳态增益必须等于 1**：前者靠设计余量，后者靠非线性稳幅，两者是不同机制。
- **文氏桥的 F=1/3 别忘了**：所以后级要 3 倍，直接接射随（增益 1）永远不振。
- **LC 回路别直接挂重负载**：Q 被拉崩、频率漂移，用抽头或射随隔离。
- **石英有静电损伤与驱动功率上限**：驱动过大频漂甚至振裂，数据手册的 $P_{max}$ 不是装饰。
- 自检：把例 1 的 $R_f$ 从 22 kΩ 想象中调到 20 kΩ——理论上环路增益 1.0，实际呢？再调到 30 kΩ，波形会削顶（稳幅环节忙不过来）。**起振余量与稳幅能力是一对矛盾**，这就是振荡器调试的全部手感。
