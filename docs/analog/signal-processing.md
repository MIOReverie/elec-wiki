# 07 · 信号的运算和处理

<Meta time="50 min" level="核心" note="运放的线性应用三件套（比例/积分/加减）+ 有源滤波 + 比较器，仪表与信号链的核心" />

本章全部公式都从两条近似规则推出来：<Prereq id="virtual-short" />。这张卡片读不懂，后面的比例器、积分器、加法器就只能背。

## 结论先行

1. **运放 + 负反馈 = 运算电路**：比例、加减、积分、微分、对数——全部靠「虚短 + 虚断」把 Z 网络接进反馈通路，输出与输入之间只隔一个阻抗比。
2. **积分器是「反过来的电阻」**：$\dot A_u=-1/(\omega RC)$，频率越低增益越高；方波进去、三角波出来。
3. **有源滤波 = RC 网络 + 运放**：一阶滚降 20 dB/dec，二阶 40 dB/dec；$Q$ 决定通带起伏与滚降陡度的交换。
4. **比较器把运放推向开环或正反馈**：输出只有两个状态——波形整形、阈值检测、AD 前端（接[数电 08 章](../digital/ad-da.md)）都靠它。
5. **线性应用看负反馈，非线性应用看开环/正反馈**——同一颗运放，两种世界。

## 推导脉络：从虚短到一切公式

所有线性应用共用一张推导图，规则本身见 <Prereq id="virtual-short" />：

```
虚断：输入电流 = 0 → 电流全部流向反馈网络
虚短：u− = u+ → 输入与输出被 Z 网络「绑」在一起
  ⇒ 输出 = 输入 ×（反馈阻抗 / 输入阻抗）的各种排列组合
```

比例器是阻抗比；加法器是「多路电流在虚地点相加」；积分器把反馈电阻换成电容（$i=C\,du/dt$，除法变积分）；微分器反过来。**记住这个图，公式不用背**。

三个页签各对应一类应用：积分器把方波「拉」成三角波（幅度随频率升高而缩）；有源低通的幅频曲线展示阶数与 $Q$ 的性格；滞环比较器把带噪声的小信号整成方波，注意**只有越过反方向阈值才翻转**——这就是抗噪的机制。

## 典型例题（数字均经计算）

::: tip 例 1 · 积分器：方波变三角波
$R=10\,\text{k}\Omega$、$C=0.1\,\mu\text{F}$、输入 $\pm2\,\text{V}$ 方波、$f=500\,\text{Hz}$（周期 2 ms）：
$$i_C=\frac{u_i}{R}=0.2\,\text{mA},\quad \frac{du_o}{dt}=-\frac{i_C}{C}=-2\,\text{V/ms}$$
每半周（1 ms）输出变化 $-2\,\text{V}$，于是得到峰峰值 4 V 的三角波。若输入改成 $1\,\text{kHz}$ 正弦，增益 $|A_u|=1/(\omega RC)=1/(2\pi\times1000\times10^3\times10^{-7})=0.16$——**频率越高增益越低，这就是积分器「恐高」的原因**，高频下它退化成普通小增益放大器。
:::

::: tip 例 2 · 有源一阶低通与截止频率
$R=10\,\text{k}\Omega$、$C=0.01\,\mu\text{F}$：$f_0=1/(2\pi RC)=1.59\,\text{kHz}$。$f_0$ 处增益降到 0.707（−3 dB）；$10\,\text{kHz}$ 处只剩 0.157（约 −16 dB）。一阶的滚降斜率只有 −20 dB/dec，滤不干净邻频干扰；想要 −40 dB/dec 就上二阶（Sallen-Key 或无限增益多路反馈）。二阶 $Q=0.707$（巴特沃斯）通带最平坦，$Q$ 越大 $f_0$ 附近越耸、滚降越陡——**通带起伏换阻带衰减**。
:::

::: tip 例 3 · 滞回比较器（施密特触发器）
稳压管 $U_Z=6\,\text{V}$、$R_1=10\,\text{k}\Omega$、$R_2=20\,\text{k}\Omega$：阈值
$$V_{th}=\pm U_Z\frac{R_1}{R_1+R_2}=\pm2\,\text{V}$$
回差宽度 4 V。输入是 $3\,\text{V}$ 幅值叠 $0.8\,\text{V}$ 噪声的正弦：简单比较器会在每个过零点因噪声抖十几次，滞环版本只在信号明确越过 $\mp2\,\text{V}$ 时才翻转，输出是干净方波。**回差是抗噪的代价交换**：回差越大越稳，但小信号检测能力越差——光电对射、水位开关都用它。
:::

::: tip 例 4 · 精密整流与绝对值电路
普通二极管 0.7 V 死区让小信号整流完全失真（[第 1 章 · 半导体器件](semiconductor.md)例 1）。把二极管放进运放反馈环：虚短保证导通点被精确补偿，死区消失，mV 级信号也能整流。绝对值电路（全波整流）用两个运放，输出 $u_o=|u_i|$——交流电压表的有效值检波、AGC 包络检测都是它的后代。**运放没有创造新器件，它把老器件的缺陷关进了反馈环里**。
:::

## 工程实例：一条传感器信号链

温度变送器把 Pt100 的电阻变化变成 4~20 mA 电流环，串起本章全部器件：

1. **惠斯通电桥**出 mV 级差分信号 → **仪表放大器**（电压串联负反馈，[第 6 章 · 放大电路中的反馈](feedback.md)）放大到 V 级；
2. **有源低通**滤掉 50 Hz 工频与变频干扰（例 2）；
3. **运放加法器**叠加零点校正；
4. **V/I 变换器**把电压变成 4~20 mA 恒流输出（电流反馈拓扑，[第 6 章 · 放大电路中的反馈](feedback.md)表格的「电流·串联」）；
5. 接收端 250 Ω 采样电阻转回 1~5 V，过阈值由**比较器**报警。

五个环节没有一个是「分立计算」，全部是虚短虚断的排列组合。

## 易错清单 + 自检

- **积分器会饱和**：输入有直流偏置时输出单向爬顶，最后被电源轨限幅——实用电路要在反馈电容上并一个大电阻限制直流增益。
- **微分器恐高频也怕噪声**：高频增益 $\omega R_fC$ 反比例放大，输入端要加小电阻限带宽。
- **有源滤波的运放不是无限的**：f 接近运放 GBD 时「有源」失效，二阶以上滤波器设计必须核对运放带宽余量。
- **比较器没有虚短**：套虚短分析比较器是概念性错误，它是非线性应用。
- **滞环的阈值与输出摆幅有关**：输出被稳压管限幅在 ±Uz，改限幅值就改了阈值，别只调电阻。
- 自检：在 <FilterDemo /> 积分器页签把 C 从 0.01 μF 拖到 1 μF，三角波幅度是否缩到 1/100？再把频率拖到 2 kHz，是不是又缩一半？——$1/\omega RC$ 的两个变量你都亲手验证过了。
