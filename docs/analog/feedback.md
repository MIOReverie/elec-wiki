# 06 · 放大电路中的反馈

<Meta time="50 min" level="核心" note="反馈类型判别 + 深度负反馈估算 + 增益换带宽 + 自激条件，模电的分水岭" />

**这一页要解决什么**：把输出的一部分引回输入端，看起来只是「让电路自己管自己」，可这一个动作同时买到四样东西：增益更稳、失真更小、带宽更宽、输入输出电阻能按需整形；代价是增益本身被卖掉，而且在高频段还可能把放大器变成振荡器。这一页要把这笔交换算清楚——先判类型，再估增益，最后问稳定。

读完你应该能做两个动作：对着一张电路图说出它属于四种负反馈拓扑里的哪一种，并用 $1+AF\gg1$ 一句话估出闭环增益（也知道这个近似什么时候失效）；反过来，给定一个多级放大器，算出反馈系数 $F$ 深到什么程度就开始自激、相位裕度要留多少才安全。后面几章的运放电路、稳压环、功放，都是这两个动作的组合。

::: tip 读这页之前
- **需要会**：运放的线性区与两条近似法则「虚短、虚断」（<Prereq id="virtual-short" />）——反馈能按公式算，前提是电路仍在线性区；以及共射放大电路的增益、输入电阻、输出电阻怎么算（[第 2 章 · 基本放大电路](amplifiers.md)）。
- **这一页用到的符号**：$\dot A$（开环增益：不加反馈时放大器自己的放大倍数，字母上的点表示它是复数，同时带着幅值与相位）、$\dot F$（反馈系数：输出量被送回输入端的比例，纯电阻网络下是一个小于 1 的实数）、$1+\dot A\dot F$（**反馈深度**，正文会解释它衡量什么）、$\dot A_f$（闭环增益：接上反馈之后的放大倍数）、$PM$（相位裕度，单位是度）。全部约定见[符号与约定](../guide/notation.md)。
- **会用到复数与相移**：判断自激要看环路增益在复平面上转了多少度，只需要「乘 $j$ 等于逆时针转 90°」这一条；没学过复数的话 <Prereq id="complex-number" /> 有 5 分钟版本。
- **前一页**：折点、−3 dB 与波特图的读法在[第 3 章 · 频率响应](frequency.md)，这一页的自激判据直接用它的那张图。

负反馈能成立的前提是运放在线性区工作，也就是虚短虚断那两条法则——本页所有估算都默认这一点成立。

## 结论先行

1. **反馈 = 把输出的一部分送回输入端比较**。送回的信号削弱净输入是**负反馈**，增强是**正反馈**——负反馈稳、正反馈振。
2. **四种负反馈拓扑**：电压/电流（采样什么）× 串联/并联（怎么比较）。判别法一句话：**输出端短路法判电压/电流，输入端分解法判串联/并联**。
3. **深度负反馈的估算法宝**：$1+AF\gg1$ 时 $\dot A_f\approx1/F$——**增益只由反馈网络决定，与管子参数脱钩**，这是模拟集成电路精度的根基。
4. **负反馈四买四卖**：买来增益稳定性、线性度、带宽、可控的输入输出电阻；卖掉了增益本身，且可能**卖出自激**（self-oscillation：没有输入信号时电路自己持续振荡，因为高频段的附加相移把负反馈翻成了正反馈）。
5. **自激条件**：**环路增益** $AF$（信号绕反馈环走一圈的净放大倍数）的附加相移达到 ±180° 且 $|AF|\ge1$。相位裕度 $PM>0$ 才稳，工程留 45° 以上。

## 推导脉络：从反馈方程到一切应用

反馈之所以能「按公式算」，前提是运放在闭环里仍工作在线性区，判据就是虚短与虚断。

$$\dot A_f=\frac{\dot A}{1+\dot A\dot F},\qquad 1+\dot A\dot F\ \text{叫「反馈深度」}$$

分母里的两个名字先定下来，后面全篇都要用：**反馈深度**（return difference，$1+AF$）是「反馈有多深」的倍数——它越大，闭环增益越贴近 $1/F$，也越不受管子参数摆布；**环路增益**（loop gain，$AF$）是信号绕反馈环走一圈的净放大倍数，它管的是稳定：$|AF|$ 在相移走到 $-180^\circ$ 时仍不小于 1，负反馈就翻正、电路自激。

同一个方程解释全部现象：

- $1+AF$ 大 → $\dot A_f\to1/F$，**增益稳定**：$\dfrac{dA_f/A_f}{dA/A}=\dfrac{1}{1+AF}$，开环抖 10%，闭环只抖千分之几；
- 负反馈把增益换成了带宽、线性度、想要的输入输出电阻（见下表）；
- 但高频段额外相移可能让负反馈翻正 → **自激**，于是有了补偿与相位裕度。

「闭环增益估算」页签：切换四种拓扑，拖 $A$ 和 $F$，看 $1+AF$ 涨起来之后 $\dot A_f$ 如何钉死在 $1/F$ 上，以及 $r_i$、$r_o$ 各自被推向哪个方向——**想要低阻输出就选电压反馈，想要恒流就选电流反馈**。

「自激与相位裕度」页签：三级放大器各贡献最多 $-90°$ 相移，环路增益 $|AF|$ 的曲线穿越 0 dB 时如果相移已经超过 $-180°$，负反馈就翻正了——把 $F$ 从小往大拖，看 $PM$ 何时掉到 0 以下，这就是运放数据手册里「单位增益稳定」的来历。

## 四种负拓扑速查

| 拓扑 | 典型电路 | 稳定什么 | $r_i$ | $r_o$ |
| --- | --- | --- | --- | --- |
| 电压串联 | 同相放大器、射随 | 输出电压 | 增大 | 减小 |
| 电压并联 | 反相放大器 | 输出电压 | 减小 | 减小 |
| 电流串联 | 共射带 $R_E$ 不并电容 | 输出电流 | 增大 | 增大 |
| 电流并联 | 并流式反馈级联 | 输出电流 | 减小 | 增大 |

判别口诀：**负载短路后反馈没了 → 电压反馈；负载开路后反馈没了 → 电流反馈**。输入侧把反馈信号与输入接成串联比较（电压相减）是串联；并到一点（电流相减）是并联。

## 典型例题（数字均经计算）

::: tip 例 1 · 深度负反馈的精度账
同相放大器 $R_1=1\,\text{k}\Omega$、$R_f=99\,\text{k}\Omega$，则 $F=0.01$、理想 $\dot A_{uf}=1/F=100$。设运放开环 $A=10^5$（100 dB）：
$$1+AF=1+1000=1001,\qquad \dot A_f=\frac{10^5}{1001}=99.90$$
与理想的偏差 0.1%——**深反馈下「电阻比」就是增益**，管子换一批、温度变 50 °C，增益照样稳。若反馈深度不足（比如 $AF=9$），$\dot A_f=A/10$ 就成了 A 的函数，设计精度无从谈起。
:::

::: tip 例 2 · 增益灵敏度：负反馈的第一卖点
承例 1，$1+AF=1001$：$\dfrac{dA_f/A_f}{dA/A}=\dfrac{1}{1+AF}$。开环增益因换管、温升变化 **10%** 时，闭环增益只变化 $\dfrac{10\%}{1001}\approx0.01\%$。工程意义：**分立电路调增益靠挑元件，深反馈电路调增益靠电阻比**——后者可以买到 0.01% 精度，前者做不到。
:::

::: tip 例 3 · 输入输出电阻的「整形」
电压串联负反馈（同相放大器）配 $r_{id}=1\,\text{M}\Omega$、$r_o=100\,\Omega$ 的运放、$1+AF=1001$：
$$r_{if}=r_{id}(1+AF)\approx1\,\text{G}\Omega,\qquad r_{of}=\frac{r_o}{1+AF}\approx0.1\,\Omega$$
输入接近「只取电压不取电流」，输出接近「内阻为零的电压源」——**这就是仪器放大器、射随的物理本质**。反过来，电流反馈能把输出内阻推到很高，得到恒流特性，用在传感器激励和 LED 驱动。
:::

::: tip 例 4 · 自激的相位账与相位裕度
三级放大，每级一个极点 $f_p=100\,\text{kHz}$，$A=10^5$、$F=0.01$（$AF=1000$）。找 $|AF|=1$ 的穿越频率：需要总衰减 1000 倍，三级滚降 $(f/f_p)^3=1000$ → $f=10f_p=1\,\text{MHz}$。该处每级相移 $\arctan(10)=84.3°$，总 $252.9°$，超过 $180°$ → **负反馈已经翻正，电路自激**。把 $F$ 降到 $10^{-4}$：$f=2.15f_p$，总相移 $129.6°$，相位裕度 $PM=180-129.6=50.4°$ → 稳定。**F 每加深一档，自激风险就逼近一步**，深反馈的代价在这里显形。
:::

## 工程实例：反馈在真实系统中的四张面孔

- **仪表放大器**：三运放结构，第一级电压串联负反馈把输入电阻推到 GΩ 级，差模增益用一颗电阻设定——生物电、 strain gauge 前端的标准件；
- **射极跟随器**：分立版的电压串联负反馈（100% 反馈），带喇叭、带长电缆，[第 2 章 · 基本放大电路](amplifiers.md)例 4 的 34 Ω 输出就是反馈的功劳；
- **开关电源的误差放大器**：输出采样 → 与基准比 → 调 PWM 占空比，一整环跨模拟与[数电接口](../digital/ad-da.md)的负反馈，环路设计（补偿网络）直接决定电源会不会啸叫；
- **自激的现场版**：音响开大声就尖叫、运放输出直流跑飞——都是环路相移越界。老工程师的第一动作是加补偿电容、降低反馈深度，而不是先怀疑管子坏。

## 易错清单 + 自检

- **先判类型再套公式**：把电流反馈当成电压反馈估 $r_o$，结论会完全反过来。
- **正反馈也有用**：振荡器（[第 8 章 · 波形的发生和变换](oscillators.md)）、施密特触发器靠它，别一听反馈就想到负的。
- **深度负反馈的近似有条件**：$1+AF\gg1$（一般 >10 才算「深度」），浅反馈必须回到 $A/(1+AF)$。
- **自激判据是两条同时成立**：相位 180° **且** $|AF|\ge1$。只满足一条不会自激。
- **多级级联相移累加**：每级最多 90°，三级就有翻正的风险，两级单靠相移通常翻不了正。
- 自检：在 <FeedbackDemo /> 里把拓扑切到「电流·串联」，看 $r_i$、$r_o$ 是否同时标着「提高」；再把 $F$ 从 0.001 拖到 0.5，看误差百分比怎么缩到万分之一以下——然后切到「自激」页签把同一个 $F$ 塞进去，看相位裕度的变化。**同一个 F，一边送稳定一边送自激**，这个张力就是反馈设计的全部艺术。
