# 05 · 集成运算放大电路

<Meta time="50 min" level="核心" note="差分放大 + 电流源 + 理想运放两条法则——分立到集成的跃迁" />

## 结论先行

1. **集成运放的输入级几乎都是差分放大**：利用电路的对称性放大「差」、抑制「共」——这就是它能同时干两件事的原因：放大有用信号，无视两输入端同向窜入的干扰。
2. **抑制共模靠「长尾」**：公共发射极电阻（或恒流源）把共模电流顶回去。恒流源的交流电阻可达 100 kΩ 以上，把 CMRR 推到 70 dB 量级。
3. **偏置不靠笨电阻，靠电流源**：镜像/微电流源用一路基准电流复制出多路静态电流，硅片面积小、精度高、对电源起伏不敏感。
4. **理想运放两条法则**：虚短（$u_+=u_-$）+ 虚断（$i_+=i_-=0$）。这两条是第 7 章所有应用的分析起点，条件只是「开环增益足够大 + 负反馈闭环」。
5. **实际运放的边界**：开环增益有限（100 dB 左右）、带宽有限（GBD）、输入/输出有摆幅限制、有失调与温漂——精度设计时逐条对账。

## 推导脉络：从分立放大到单片运放

第 2 章的分立电路每级都要自己设计偏置，元器件一多，温漂和失配就难压。集成的思路是把整个放大系统做进一片硅：

```
直接耦合级联（无大电容，硅片上做不出大电容）
   │
   ├─ 差分输入级：高增益 + 高 CMRR + 抑制温漂
   ├─ 中间级：高增益电压放大（有源负载提增益）
   ├─ 输出级：甲乙类互补（第 4 章）+ 过流保护
   └─ 全级偏置：镜像/微电流源链（本章）
```

差分对 + 有源负载 + 互补输出，就是 $\mu\text{A}741$ 以来的经典三段式，理解它等于理解一切运放的内部。

## 图解①：差分放大的本质——「只看差值」

差分电路的两个输入 $u_{I1}$、$u_{I2}$ 分解成一对搭档：

$$u_{ID}=u_{I1}-u_{I2}\ (\text{差模}),\qquad u_{IC}=\frac{u_{I1}+u_{I2}}{2}\ (\text{共模})$$

- 差模信号让两管电流一增一减，在集电极产生反向压降 → **双端输出得到 $\beta R_C/r_{be}$ 量级的增益**；
- 共模信号让两管电流同增同减，$R_E$（或恒流源）上的压降同步顶高发射极电位 → 被「负反馈」摁回去 → **双端输出共模增益≈0**。

共模抑制比 $\text{CMRR}=\left|\dot A_d/\dot A_c\right|$ 是差分电路的灵魂指标：运放标称 80~120 dB，意味着有用差模信号比同相干扰优先放大 1 万倍到 100 万倍——这就是「干扰同时加在两输入端却不怕」的数学根据。

## 典型例题（数字均经计算）

::: tip 例 1 · 长尾差分电路的增益与 CMRR
恒流源 $I_O=2\,\text{mA}$（每管 $I_{CQ}=1\,\text{mA}$）、$\beta=100$、$R_C=10\,\text{k}\Omega$：
$$r_{be}=300+(1+\beta)\frac{26\,\text{mV}}{1\,\text{mA}}\approx2.93\,\text{k}\Omega$$
- 双端输出：$\dot A_d=-\beta R_C/r_{be}=-341.8$；
- 单端输出（从一管集电极取）：$\dot A_d=-\dfrac{\beta R_C}{2r_{be}}=-170.9$；
- 共模：恒流源等效交流电阻 $r_o=100\,\text{k}\Omega$，单端共模增益 $\dot A_c=-\dfrac{R_C}{2r_o}=-0.05$；
- $\text{CMRR}=|A_d/A_c|=3418\approx71\,\text{dB}$。

**对比实验**：若把恒流源换成普通 $R_E=10\,\text{k}\Omega$，CMRR 掉到约 51 dB——长尾的「尾」越理想，共模抑制越强。这就是运放输入级非用恒流源不可的原因。
:::

::: tip 例 2 · 镜像电流源与微电流源
$V_{CC}=15\,\text{V}$、$R=15\,\text{k}\Omega$ 的镜像电流源：$I_{C1}=(15-0.7)/15\,\text{k}=0.953\,\text{mA}$，于是 $I_{C2}\approx0.953\,\text{mA}$——一路基准电流被「复制」给各级偏置。考虑基极电流的分流，精确值 $I_{C2}=I_{C1}/(1+2/\beta)$，$\beta=100$ 时为 $0.934\,\text{mA}$（误差 2%）。若需要小电流（μA 级供输入级），用微电流源：$R=100\,\Omega$ 时解 $V_T\ln(I_{C1}/I_{C2})=I_{C2}R$ 得 $I_{C2}\approx300\,\mu\text{A}$，$R=500\,\Omega$ 时降到 $112\,\mu\text{A}$——**电阻大一点，电流小一截，硅片上只花一点点面积**。
:::

::: tip 例 3 · 虚短虚断的两条应用
反相放大器（$R_1=10\,\text{k}\Omega$、$R_f=100\,\text{k}\Omega$、$u_i=1\,\text{V}$）：虚地 $u_-=0$，$i_1=u_i/R_1=0.1\,\text{mA}$；虚断使 $i_1$ 全部流过 $R_f$，$u_o=-i_1R_f=-10\,\text{V}$，即 $\dot A_{uf}=-R_f/R_1=-10$。
同相放大器（同样电阻）：虚短使 $u_-=u_i$，分压关系给出 $\dot A_{uf}=1+R_f/R_1=11$。
加法器（$R_1=R_2=10\,\text{k}$、$R_f=20\,\text{k}$、$u_{i1}=1\,\text{V}$、$u_{i2}=2\,\text{V}$）：两路电流在虚地点汇合，$u_o=-(u_{i1}+u_{i2})R_f/R_1=-6\,\text{V}$——**加法不过就是「电流相加」**。
:::

::: tip 例 4 · 理想与现实的差距账
理想运放假设 $A_{od}\to\infty$、$r_{id}\to\infty$、$r_o\to0$、带宽无限。真实 $\mu\text{A}741$：$A_{od}\approx2\times10^5$（106 dB）、$r_{id}=2\,\text{M}\Omega$、$r_o=75\,\Omega$、GBD$=1\,\text{MHz}$、失调电压 $1\,\text{mV}$ 量级。影响：反相放大 10 倍时，有限增益使实际增益偏差约 $1/(1+AF)\approx0.05\%$；驱动 $2\,\text{k}\Omega$ 负载时，$r_o$ 分压使增益再降约 3.6%。**精密测量要么选低失调型号，要么调零，要么斩波稳零**。
:::

## 工程实例：运放是怎样被「设计」出来的

一片运放的版图，就是本章四块内容的拼装：

- **输入级**：PNP 差分对（耐压高、输入范围宽）或 NPN，尾端一个恒流源——例 1、例 2 的硅片版；
- **电平移位**：直接耦合会把电位越抬越高，用 PNP 或电流源搬回中线；
- **中间级**：达林顿 + 有源负载，一级拿下 60 dB 以上增益；
- **输出级**：甲乙类互补 + 限流保护，附过温关断；
- **频率补偿**：内部一颗 30 pF 电容做主极点（[第 3 章](./frequency.md)的波特图 + [第 6 章](./feedback.md)的稳定性），保证单位增益闭环不自激——这就是 741 不敢开深反馈还稳如老狗的秘密。

## 易错清单 + 自检

- **虚短的前提是负反馈 + 深反馈**：开环或正反馈时不存在虚短，此时运放工作在饱和区（比较器，第 7 章）。
- **虚短 ≠ 两地**：$u_+=u_-$ 只是电压相等，电流为零，不能当成同一点接导线分析。
- **双端/单端输出的增益差 2 倍**：从一管取信号，另一半变化被浪费，别套错公式。
- **镜像电流源的精度受 $\beta$ 和 $V_{BE}$ 匹配限制**，高精度场合用威尔逊电流源或外接精密电阻。
- **共模输入范围**：差分对不是万能的，共模电压太高会把尾管推饱和——选型看输入共模范围包含你的信号摆幅。
- 自检：把例 1 的参数代入 <AmpDemo /> 的三极管页签（$\beta=100$、$I_{BQ}=10\,\mu\text{A}$、$R_C=10\,\text{k}$、$V_{CC}=12\,\text{V}$），看 $I_C$ 是否稳定在 1 mA 附近——那就是差分对每半边的工作电流，差分电路的静态分析可以整个借走单管工具。
