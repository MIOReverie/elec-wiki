# 03 · 门电路与集成器件

<Meta time="28 min" level="核心" note="TTL / CMOS、开漏、三态、竞争冒险——从『门』到『能用』" />

**这一页要解决什么**：单个逻辑门只是「数学上的与或非」，真要做成能用的电路，你还得知道它到底能带几个负载、信号在门之间跑要等多久、以及怎么让多个设备共用一条线而不打架。这一页把门电路从「原理图」推进到「工程器件」：讲清扇出、噪声容限、传输延迟这些时间/负载约束，再落到开漏、三态、总线仲裁和竞争冒险四个实战坑。

- **本页前置**：两个承重概念——输出能带几个输入（扇出）、信号传递的时间约束（建立/保持）。

本页的两个承重概念：输出到底能带多少个输入（**扇出，fan-out** = 一个输出端能可靠驱动的同型号输入端数目，取高电平方向和低电平方向两者中的较小值），以及信号在门之间传递时的时间约束（**传输延迟** = 信号从输入端变化到输出端稳定所需的时间；**噪声容限** = 输入允许叠加多大干扰还不误判的电平余量）。

## 结论先行

1. **门电路是用二极管 / 三极管搭出来的开关网络**：与、或靠二极管，非靠三极管反相。
2. **TTL 快但耗电，CMOS 省电但输入不能悬空**——选型时按这个取舍。
3. **多余输入端不能任其悬空**：CMOS 悬空会感应电荷、可能损坏；应接固定电平。
4. **OC / OD 门**必须外接**上拉电阻**（把线拉向电源）才能输出高电平，好处是能「线与」、能驱动不同电压。
5. **三态门**输出 0 / 1 / 高阻 Z，是高阻那态让多条设备能共用一条总线。
6. **竞争冒险**：门延迟不同会在瞬间冒出毛刺，需加冗余项或滤波消除。

## 一、门电路内部是怎么实现的

这一节先回答「门不是魔法，是开关」——早期的**二极管-三极管逻辑（DTL）**用二极管做与/或，再用三极管反相得到与非/或非。以**与非门**为例：输入全高时二极管截止、三极管饱和导通 → 输出低；任一输入低时二极管导通钳位、三极管截止 → 输出高。可见「非」这一步靠三极管，「与/或」靠二极管。

今天的芯片里单个门早已是微米级的 CMOS 结构，但**「与或非靠开关网络」这个本质没变**。理解了这一点，后面所有「电平兼容」「多余端处理」都能推导出来。

## 二、TTL 与 CMOS 对照

这一节给出选型的硬事实表，并点出最容易漏的一项——**扇出在不同电平方向不一样**。

| | TTL（如 74LS 系列） | CMOS（如 74HC 系列） |
| --- | --- | --- |
| 电源电压 | 严格 5 V | 宽（3 ~ 18 V） |
| 速度 | 较快 | 现代已很快 |
| 静态功耗 | 较大 | **极小**（近乎 0） |
| 输入悬空 | 等效高电平（但抗干扰差） | **严禁悬空**（感应电荷可损坏） |
| 抗干扰 | 一般 | 强 |
| 驱动能力 | 强（拉/灌电流大） | 一般 |

**结论**：电池供电、低功耗场合选 CMOS；要驱动大电流负载、或 legacy 5 V 系统里选 TTL。两者逻辑兼容（都是高≈供电、低≈0），但电平阈值不完全一致，混用时注意 $V_{IH}/V_{IL}$（输入高/低电平阈值）。

选型之前还有一件事必须先算：**这个输出到底能带几个输入**。TTL 的高电平扇出往往比低电平扇出小得多，这是选型时最容易漏的一项，详见 <Prereq id="gate-fanout" text="扇出：取高/低电平两方向中较小者" />。

**为什么**：查手册——
- 74LS 输出高电平最低 $V_{OH(\min)} = 2.7\text{ V}$；
- 74HC 在 $V_{CC}=5\text{ V}$ 时要求输入高电平最低 $V_{IH(\min)} = 0.7 \times 5 = 3.5\text{ V}$。

高电平段 $2.7 < 3.5$，**不满足**——74HC 可能把 2.7 V 判成中间电平，行为不确定。再看低电平段：$V_{OL(\max)} = 0.5\text{ V} \le V_{IL(\max)} = 0.3\times5 = 1.5\text{ V}$，反而没问题。所以问题只出在「高的一端不够高」。

两种解法：
1. 输出侧加上拉电阻把高电平抬到 5 V（用 OC 缓冲如 7407 推动）；
2. 换 **74HCT** 系列——它的输入阈值按 TTL 设计，$V_{IH(\min)} = 2.0\text{ V} \le 2.7\text{ V}$，直接兼容。

反过来 74HC 驱动 74LS 则没问题（$V_{OH}\approx4.4\text{ V} \ge 2.0\text{ V}$）。**结论：TTL→CMOS 要查电平，CMOS→TTL 一般放心。**

## 三、多余输入端怎么处理

这一节把「悬空为什么危险」讲清，并给出接法口诀。

- **与门 / 与非门**的多余端：接**高电平**（接 1 不影响「全 1 才…」的判定）。
- **或门 / 或非门**的多余端：接**低电平**（接地）。
- 原则：**让多余端处于「不拉低输出有效性」的电平**，同时固定它以免引入噪声（CMOS 悬空会累积感应电荷，轻则误触发、重则击穿）。

## 四、OC / OD 门（开漏 / 开集电极）

这一节区分「推挽」和「开漏」，并算出上拉电阻的取值区间——这是开漏唯一必须算的一步。

普通 CMOS 输出是**推挽**（有上拉管和下拉管，能主动拉高也能拉低）。**OD（Open-Drain，开漏）门**只有下拉管，要输出高电平必须**外接上拉电阻**到电源（让电阻把线拉向高电平）。代价是上升沿变慢，收益是两大绝活：

1. **线与（wired-AND）**：多个 OD 门输出直接并接，任一拉低则整线为低——天然实现「与」。
2. **电平转换**：上拉到 5 V 就能和 5 V 器件通信，上拉到 3.3 V 就接 3.3 V 系统。

某 OD 门驱动 4 个同类输入，参数：$V_{CC}=5\text{ V}$，$V_{OH(\min)}=2.4\text{ V}$（高电平下限），最大拉电流 $I_{OH}=0.4\text{ mA}$；低电平时最大灌电流 $I_{OL(\max)}=16\text{ mA}$，每个负载输入漏电流 $I_{IL}=0.4\text{ mA}$。

- 输出高时电流经 $R_p$ 流向上拉源，$R_p$ 不能太大否则压降过大：

$$R_{p(\max)} = \frac{V_{CC} - V_{OH(\min)}}{I_{OH}} = \frac{5 - 2.4}{0.4\text{ mA}} = 6.5\text{ k}\Omega$$

- 输出低时 $R_p$ 要把灌电流分流给负载，不能太小否则灌不过来：

$$R_{p(\min)} = \frac{V_{CC} - V_{OL(\max)}}{I_{OL(\max)} - n I_{IL}} = \frac{5 - 0.4}{16 - 4\times 0.4}\text{ k}\Omega \approx 0.32\text{ k}\Omega = 319\ \Omega$$

所以 **$R_p$ 取 $319\ \Omega \sim 6.5\text{ k}\Omega$ 之间**，工程上常用 $1\text{ k}\Omega$ 或 $4.7\text{ k}\Omega$。选太大上升沿钝、选太小功耗大。
:::

## 五、三态门与总线

这一节讲清「高阻态」是什么、为什么它能让多个设备共享一条线。

三态门比普通门多一个**使能端 $\overline{EN}$**（上划线表示低有效：引脚为低时使能有效）：使能有效时正常输出 0/1；无效时输出**高阻 Z**（既不拉高也不拉低，相当于「断开」）。

**总线**就是一条被多个设备共享的线。规则：**同一时刻只能有一个设备使能有效**（输出 0 或 1），其余都必须是高阻，否则两个设备一个拉高一个拉低会短路。这正是计算机里地址总线、数据总线的仲裁基础。

两种共享方式的规则完全不同：**三态门**靠「高阻」断开，必须外加仲裁保证只有一个驱动；**开漏门**根本输出不了高，多个设备拉低也不冲突，靠上拉电阻得到「线与」——I²C 用的就是后者。

::: tip 例 3 · 三态总线冲突
三条设备挂在一条数据线上，若设备 A 使能有效输出 1、设备 B 也使能有效输出 0，则线上既被上拉又被下拉，结果是不确定的中间电平，还可能过流。正确做法是控制器保证「任意时刻至多一个 $\overline{EN}$ 有效」——这层逻辑叫**总线仲裁**。

（用上面的演示复现：点「A、B 冲突驱动」，看总线变红、读端报警；再点「仅 A 驱动」对比正常情况。注意「A、B 同电平驱动」虽然不过流，依然违反仲裁规则。）
:::

## 六、竞争冒险

这一节用时间轴把「毛刺怎么来的」画出来，并给出修法。

信号经过不同路径的门，延迟不同，可能在输出端冒出一个**不该出现的窄脉冲（毛刺）**。典型特征：表达式里同一变量以原变量和反变量同时出现（如 $Y = A + \bar A$ 型）。这里的**传输延迟**（每级门的固有延时）是毛刺宽度的直接来源。

**消除三招**：
1. 加**滤波电容**（最简单，但拖慢边沿）
2. 增加**冗余项**（在卡诺图里多圈一个圈，堵住冒险点）
3. 加**选通脉冲**（等电路稳定后再去采样输出）

电路 $Y = AB + \bar{A}C$，设 $B = C = 1$ 不变。静态分析：$A = 1$ 时 $AB = 1$，输出为 1；$A = 0$ 时 $\bar{A}C = 1$，输出还是 1——**输出本该恒为 1**。

设每个门延迟都是 10 ns。当 $A$ 从 1 跳变为 0：
- 乘积项 $AB$ 经过 1 个与门，第 10 ns 时变为 0；
- 乘积项 $\bar{A}C$ 要先过非门再过与门，第 20 ns 时才变为 1。

于是第 10 ~ 20 ns 之间两个乘积项**同时为 0**，输出出现一个宽 10 ns 的负向毛刺——这就是竞争冒险。

用卡诺图看更清楚：$AB$ 圈覆盖 $m_6, m_7$，$\bar{A}C$ 圈覆盖 $m_1, m_3$；$A$ 跳变对应从 $m_7$ 到 $m_3$，这两个相邻格分属**不同的圈**，圈与圈交接处就是冒险点。修法是把交接处再圈一个**冗余项** $BC$（覆盖 $m_3, m_7$）：

$$Y = AB + \bar{A}C + BC$$

逐格枚举验证：加 $BC$ 前后真值表完全一致（都是 `01010011`），逻辑功能没变；但 $B=C=1$ 时 $BC$ 恒为 1，输出被它托住，毛刺消失。
:::

## 七、工程实例

**I²C 总线**就是 OD 结构的经典应用：SDA/SCL 两根线靠外部上拉电阻，所有从设备都是开漏输出，靠「线与」仲裁谁在说话。理解 OC/OD 和总线仲裁，才看得懂为什么 I²C 能挂这么多设备还不会打架。

**按键消抖**常用施密特触发（迟滞）输入或软件去抖——本质都是对付「信号在阈值附近反复横跳」这类噪声，和竞争冒险同源（都跟噪声容限、边沿抖动有关）。

## 八、易错清单 + 自检

- [ ] CMOS 多余输入端**严禁悬空**；TTL 悬空虽等效高但抗干扰差，最好也固定
- [ ] 与/与非的多余端接高，或/或非的多余端接低——**别接反**
- [ ] OC/OD 门**必须接上拉电阻**否则输出不了高电平；它靠「线与」工作，不能直接并推挽输出
- [ ] 三态总线：**同一时刻只许一个驱动**，其余高阻
- [ ] 竞争冒险看「$A+\bar A$ 型」，不是所有毛刺都叫冒险
