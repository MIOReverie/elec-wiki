# 08 · 数电接口：AD/DA 与脉冲调制

<Meta time="45 min" level="核心" note="采样定理、量化误差、DAC/ADC 四大结构、PWM——模拟世界与数字世界的最后一道桥" />

## 结论先行

1. **现实世界是模拟的，数字系统只认 0/1**，ADC 与 DAC 就是两界之间的桥。转换链条固定：**采样（时域离散）→ 保持 → 量化（幅度离散）→ 编码**。
2. **采样定理**：$f_s\ge2f_{\max}$ 才能完整重建；采样不足会产生**混叠**——高频信号伪装成低频，一旦发生就无法在后端挽回，必须在采样前用抗混叠滤波器挡住。
3. **DAC 两大经典结构**：权电阻网络直观但电阻档位多；**R-2R 梯形网络只用两种阻值**，是主流。指标看分辨率（位数）、建立时间、线性度。
4. **ADC 四大类**：并行比较（快而贵）、**逐次逼近 SAR（速度价格折中，MCU 内置主流）**、双积分（慢而抗干扰，数字电压表）、计数式（最慢已淘汰）。
5. **量化误差不可避免**：理想 ADC 误差 ≤ ±½ LSB，位数每多 1 位，误差减半、数据量翻倍——精度与成本的交换。
6. **PWM** 用通断比例等效出电压：等效值 = 占空比 × 高电平；配低通滤波得模拟量。开关管两态工作损耗小，是调光、调速、开关电源的基石。

## 推导脉络：一个模拟量怎么变成一串数字

```
温度/声音/电压（连续）
   │  ① 采样：按 fs 周期性取值        ← 采样定理在这里把关
   ▼
一串离散的样点（幅度还是连续的）
   │  ② 保持：样值稳住，等量化
   ▼
   │  ③ 量化：幅度归到邻近的电平栅格  ← 误差在这里产生
   ▼
   │  ④ 编码：电平编号写成二进制
   ▼
数字码流 ──► 数字系统处理 ──► DAC ──► 模拟世界
```

注意②③的次序不可换：不保持的话，量化还没做完样值就变了。而**采样定理是整条链的入口门槛**——进来时丢了的信息，后面任何处理都变不回来。

## 典型例题（数字均经计算）

::: tip 例 1 · 采样定理验算
语音信号频率上限 $4\,\text{kHz}$，则 $f_s\ge2\times4=8\,\text{kHz}$——电话系统正是取 $8\,\text{kHz}$。CD 音质上限 $20\,\text{kHz}$，理论下限 $40\,\text{kHz}$，实际取 $44.1\,\text{kHz}$（约 2.21 倍余量），既防混叠又给滤波器过渡带留空间。若偷懒用 $8\,\text{kHz}$ 采 $6\,\text{kHz}$ 的信号，混叠出 $|8-6|=2\,\text{kHz}$ 的假信号——耳朵听到的是错的东西。
:::

::: tip 例 2 · DAC 分辨率
8 位 DAC、参考电压 $10\,\text{V}$：$\text{LSB}=10/2^8=39.06\,\text{mV}$。输入码 $10000001_2=129$，输出 $=129\times39.06\,\text{mV}\approx5.039\,\text{V}$。满量程码 $11111111_2=255$ 只输出 $9.961\,\text{V}$（= 量程 − 1 LSB），**永远到不了 10 V**——这是 DAC 的固有特性，别当成故障。同量程 12 位 LSB 降到 $2.441\,\text{mV}$，分辨率提升 16 倍。
:::

::: tip 例 3 · ADC 量化误差
8 位 ADC、量程 $0\sim5\,\text{V}$，LSB $=19.53\,\text{mV}$。输入 $3.300\,\text{V}$，量化码 $=\text{round}(3.300/0.01953)=169=10101001_2$，重建值 $3.3008\,\text{V}$，误差仅 $-0.8\,\text{mV}$（≤ ½ LSB $=9.8\,\text{mV}$）。这次误差小是运气；最坏情况误差接近 ½ LSB，折合满量程的 0.2%。**位数决定误差下限**：要 0.1% 以内，至少得 10 位以上。
:::

::: tip 例 4 · SAR 与双积分的速度账
SAR 型 8 位 ADC 每次要「采样保持 + 逐位比较 8 回」，至少 9 个时钟。时钟 $1\,\text{MHz}$ 时转换时间约 $9\,\mu\text{s}$，每秒可完成约 111 k 次转换——这就是 MCU 内置 ADC 的典型速度。双积分型反过来：积分时间取工频周期的整数倍（$20\,\text{ms}$ 的整数倍），$50\,\text{Hz}$ 干扰在一个积分周期内平均为零，抗干扰能力理论上无穷大，代价是每秒只能转几十次。**要快用 SAR，要稳用双积分**，数字万用表里常见后者。
:::

## 工程实例：从传感器到云端的完整链路

一条物联网温度链走一遍今天的所有概念：

1. **NTC 热敏电阻**随温度改变阻值，经分压变成电压（[欧姆定律与分压器](../ee/01-basics/model-reference.md)的老本行）；
2. **抗混叠滤波器**（RC 低通）先把高频噪声挡在采样频率一半以下——没有它，噪声会混叠进有用频段；
3. **SAR ADC**（MCU 内置 12 位）把电压变成码值，每秒采几千次；
4. MCU 算出温度，通过 **PWM** 控制加热器占空比做恒温——整套系统只靠「比较 + 计数 + 通断」就完成了模拟量的精确处理。

反过来，播放端：存储器里的数字音频经 **DAC**（R-2R 或 Σ-Δ）重建为阶梯波，再经低通滤波器平滑，才到你耳朵里。**你听到的每一段数字音乐，终点都是这一章的电路。**

## 易错清单 + 自检

- **混叠不可恢复**：指望软件「修」混叠是徒劳，防线只有两个——提高采样率，或在 ADC 前加抗混叠低通。
- **量化误差 ≠ 噪声的全部**：还有偏置误差、增益误差、非线性（INL/DNL）。选型时别只看位数。
- **½ LSB 是理想下限**：实际 ADC 的积分/微分非线性会让有效位数（ENOB）低于标称位数， datasheet 里找 ENOB 才是诚实的做法。
- **SAR 前必须有采样保持**：比较期间输入不能变，否则高位比完低位时样值已漂移。
- **PWM 等效电压是「平均值」概念**：对惯性负载（电机、LED 视觉、加热丝）有效；对「认瞬时值」的负载（如想直接驱动运放）必须先滤波。
- 自检：在 <AdcDemo /> 里把输入频率拖到 15、采样频率拖到 20（比值 1.33 < 2），看红色混叠波的频率是不是 $|20-15|=5$？再把采样频率拖过 30，混叠警告是否消失？这两个动作做一遍，采样定理就刻进直觉了。
