# 07 · 存储器与可编程逻辑

<Meta time="45 min" level="核心" note="ROM/RAM 的组织与扩展、DRAM 刷新、PLD 谱系到 FPGA——数字系统的『内存』与『可塑硬件』" />

## 结论先行

1. **存储器 = 存储矩阵 + 地址译码 + 读写控制**。容量一律写成「字数 × 位数」，如 $1\text{K}\times8$ = 1024 个字、每字 8 位；地址线条数 $=\log_2(\text{字数})$。
2. **ROM 家族掉电不丢**（PROM 一次写、EPROM 紫外线擦、$\text{E}^2\text{PROM}$/Flash 电擦）；**RAM 掉电即失**：SRAM 用触发器（快、贵、不刷新），DRAM 用电容（慢、廉、**必须定时刷新**）。
3. **容量不够就扩展**：位不够用「位扩展」（片并接、数据线拼高低位）；字不够用「字扩展」（高位地址经译码器做片选）。片数 = 目标容量 ÷ 单片容量，先拆位再拆字。
4. **可编程逻辑（PLD）谱系**：PAL → GAL → CPLD → FPGA。共同思想是把「与或阵列 + 触发器」做成可配置的硅片，用硬件描述语言（HDL）画电路而不是焊电路。
5. **FPGA = LUT + 触发器 + 布线资源**。开发流程固定：写 HDL → 综合 → 布局布线 → 下载配置，改逻辑不用改板子。

## 推导脉络：从 1 个触发器到一座存储器

回想[触发器](./flip-flops.md)：一个 D 触发器存 1 位。要存 8 个字 × 4 位，就把 32 个触发器排成 8 行 4 列的矩阵——问题只剩一个：**每次操作到底对准哪一行？**

答案就是**地址译码**：3 根地址线 $A_2A_1A_0$ 经 3-8 译码器产生 8 根「字选线」，只有被选中的那一行能和数据线连通。这就是所有存储器的骨架：

```
A2A1A0 ──► [3-8译码器] ──► 字选线 W0..W7（一根只选中一行）
                              │
                    ┌─────────┴─────────┐
                    │  8行 × 4列 存储矩阵 │
                    └─────────┬─────────┘
D3..D0（双向）◄─────  读写控制（WE=1 写 / WE=0 读）
```

再往下分两条路：**触发器保持**（SRAM，不断电就一直在）与**电容保持**（DRAM，电荷会漏，于是有了刷新）。ROM 则更简单——数据在制造或编程时就固定，只有读通道。

## 图解②：DRAM 为什么必须刷新

SRAM 的触发器是一个双稳态环路，只要供电就自己保持；DRAM 的每一位只是 MOS 管栅电容上的电荷，漏电流会让它在毫秒量级内流光。所以 DRAM 控制器要在刷新周期内（通常 $15\sim64\,\mu\text{s}$ 刷一行、整个存储体数 ms 内刷完一遍）不断「读出→放大→写回」。

这就是分工：**SRAM 快（几 ns）但贵，做缓存；DRAM 慢（几十 ns）但便宜，做主存**。价格差一位数，速度差一位数，各取所需。

## 典型例题（数字均经计算）

::: tip 例 1 · 位扩展与字扩展：用 2114（$1\text{K}\times4$）搭 $4\text{K}\times8$
目标容量 ÷ 单片容量 = 总片数，先拆位再拆字：
- **位扩展**：$8\div4=2$ 片并接——地址线并在一起，两片的数据线分别拼成高 4 位和低 4 位，同时读写，得到 $1\text{K}\times8$；
- **字扩展**：$4\text{K}\div1\text{K}=4$ 组——把上面这一对当成一个「组」，用高位地址选组。

总片数 $=2\times4=8$ 片。总字数 $4\text{K}=4096$ 需要 12 根地址线，片内用低 10 根（$A_9\sim A_0$），剩下 $A_{11}A_{10}$ 送译码器产生 4 个片选。
:::

::: tip 例 2 · 地址线与数据线：$8\text{K}\times8$ 的芯片有多少引脚方向
字数 $8192=2^{13}$ → **13 根地址线**（$A_{12}\sim A_0$）；每字 8 位 → **8 根数据线**（双向）。再加片选 $\overline{CS}$、读写 $\overline{WE}$、电源——一根根数出来，就知道为什么大容量存储器的封装越做越大。容量换算：$8\text{K}\times8=65536$ 位 = 8 KB。
:::

::: tip 例 3 · 用 74LS138 做片选：4 片 $2\text{K}\times8$ 组成 $8\text{K}\times8$
总容量 8 K 字需 13 根地址线：低 11 根 $A_{10}\sim A_0$ 直接并接到各片的片内地址端，**高位 $A_{12}A_{11}$ 送 3-8 译码器**（138 的 $C$ 接 $A_{12}$、$B$ 接 $A_{11}$、$A$ 接地，只用到 $\bar Y_0\sim\bar Y_3$ 四个输出）：
- $A_{12}A_{11}=00$ → 片 0（地址 $0000\sim07\text{FF}$）
- $=01$ → 片 1（$0800\sim0\text{FFF}$）
- $=10$ → 片 2（$1000\sim17\text{FF}$）
- $=11$ → 片 3（$1800\sim1\text{FFF}$）

CPU 送出的地址被「劈成两半」：低半部在片内选字，高半部在片间选片，互不打架。若 138 的使能端没接好，会出现**多片同时选中**——数据线冲突，这是硬件调试的经典故障。
:::

::: tip 例 4 · DRAM 刷新与带宽
一片 $4\text{M}\times1$ 的 DRAM，内部排成 1024 行。设刷新周期 $64\,\text{ms}$，则平均每行刷新间隔 $=64\,\text{ms}\div1024\approx62.5\,\mu\text{s}$——只要保证每行在这个间隔内被轮到一次，数据就不丢。若存储周期 $60\,\text{ns}$，则突发带宽 $=1/60\,\text{ns}\approx16.7\,\text{M}$ 次/s。×1 芯片一次只出 1 位，把 8 片并联成 1 字节宽度时每次传 8 位，突发带宽约 $133\,\text{Mbit/s}\approx16.7\,\text{MB/s}$。**刷新期间存储器「没空接待」CPU**，所以 DRAM 控制器要挑空闲时刻插刷新，这也是 DRAM 延迟抖动的来源之一。
:::

## PLD：把电路「写」进芯片

前面几章的组合、时序逻辑，我们都是拿现成门电路和触发器在面包板上搭。PLD 换了个思路：**芯片内部就是一大堆可配置的「与或阵列 + 触发器」，配置数据由你下载**，逻辑改一版只要重新烧一次，不动烙铁。

| 类型 | 结构特点 | 可重复编程 | 典型规模 | 一句话定位 |
| --- | --- | --- | --- | --- |
| PAL | 与或阵列，输出固定 | 否（熔丝） | 数百门 | PLD 的开山之作 |
| GAL | 与或阵列 + 输出宏单元可定义 | **是**（电擦） | 数百门 | 实验室常客，一片顶多片 |
| CPLD | 多个 PAL 块 + 全局布线 | 是 | 数千～数万门 | 延时确定，适合控制类逻辑 |
| FPGA | **LUT + 触发器** 阵列 + 丰富布线 | 是（多数） | 数万～数百万门 | 数字系统的主力，能装下整个 CPU |

**LUT（查找表）是 FPGA 的灵魂**：一个 4 输入 LUT 内部存着 16 位配置数据，等于一张「真值表」——外部给 4 位输入，它按表查出 1 位输出。换句话说，**任何 4 变量组合函数，改数据就能改逻辑**。把几十万个 LUT 配上触发器、RAM 块和布线，就是一片 FPGA。

LUT 里那张「真值表」正是卡诺图的老故事：逻辑被拆成与项、或项，再映射到硬件。回头看 <Prereq id="kmap" /> 就明白，PLD 的与或阵列和 LUT 不过是布尔化简的硬件实现。

开发流程也是固定的五步：**用 Verilog/VHDL 写 HDL → 综合成门级网表 → 布局布线映射到具体芯片 → 生成配置比特流 → 下载（掉电丢失的还要外挂 Flash/EEPROM 启动加载）**。

## 工程实例：一块单片机最小系统里的三兄弟

打开 STM32 最小系统板，你会同时看到三种「可编程的硅」：

- **Flash（$\text{E}^2\text{PROM}$ 家族）**：存你的程序，掉电不丢，所以上电 CPU 有码可跑；
- **SRAM**：存运行时的变量和栈，读写快、不用刷新，容量小所以贵；
- **芯片本体**：整个 MCU 内核本身就是一片巨大的 PLD 产物——厂商把处理器、总线、外设控制器全「写」进了 FPGA 类的硅面积里。

这就是存储器和可编程逻辑的真实分工：**ROM 类存「不变的」，RAM 类存「变化的」，PLD 存「你设计的逻辑」**。

## 易错清单 + 自检

- **位扩展 ≠ 字扩展**：位扩展是「几片同时工作、拼宽数据」；字扩展是「一次只选中一片」。地址线接反（把高位给了片内）是最常见错误。
- **异步/同步片选的时机**：片选要在地址稳定后才有效，否则会在错误的片里写一下子——很多初学者测出的「数据偶尔错」都源于此。
- **DRAM 刷新不是改写**：刷新只是续电荷，数据内容不变；「刷新 = 清空」是常见误解。
- **138 译码器的使能端**：$S_1S_2\bar S_3$ 三个使能端必须都满足，很多初学者只接了一个，片选永远不使能。
- **LUT 输入个数**决定它能实现几变量函数：4 输入 LUT 实现 4 变量函数，函数变量超了就要多个 LUT 级联——这就是「资源估算」的起点。
- 自检：在 <MemoryDemo /> 里往 5 号单元写个 `1011`，拖到 7 号写个别的，再拖回 5——读出的是不是 `1011`？是，说明「地址选行、行列交叉定单元」你已经建立了物理图像。
