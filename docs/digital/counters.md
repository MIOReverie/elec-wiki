# 06 · 计数器与寄存器

<Meta time="40 min" level="核心" note="74LS161 任意进制 + 移位寄存器 + 555 定时，时序器件三件套" />

## 结论先行

1. **时序电路 = 组合电路 + 存储电路（触发器）**；分析套路固定：写**驱动方程** → 代入**特性方程**得**状态方程** → 列**状态表/时序图**。
2. 计数器分两类：**异步（行波）**低位触发高位，简单但有累积延迟；**同步**共用一时钟，快但要进位逻辑。
3. 集成 74LS161 是 4 位同步二进制计数器，带**异步清零**、**同步置数**、使能端——用「清零法/置数法」就能拼出任意 N 进制。
4. **寄存器**是 D 触发器组；**移位寄存器**能左/右移，完成串并转换。一个触发器级联 = 分频器。
5. **555 定时器**：单稳态出定宽脉冲 $t_W=1.1RC$；多谐出方波 $f=\dfrac{1.43}{(R_1+2R_2)C}$。

## 推导脉络：时序电路怎么分析

拿到一个时序电路，别慌，五步走：

```
① 写各触发器的驱动方程（每个输入端 = 外部输入和现态 Qⁿ 的函数）
② 把驱动方程代入触发器特性方程 → 得到状态方程 Qⁿ⁺¹
③ 写输出方程
④ 列状态转换表 / 画状态图
⑤ 画时序图，归纳功能
```

**异步 vs 同步**的关键差别在时钟：异步计数器里，低位 Q 的变化沿去触发高位的 CLK，所以高位要「等」低位翻完才动——位数越多、末尾延迟越大；同步计数器所有触发器共一个 CLK，同一拍内靠组合逻辑同时决定各自次态，速度快。

## 典型例题（数字均经计算）

::: tip 例 1 · 用 74LS161 构成十进制
十进制要循环 0~9，计到 10 时清零。10 的二进制是 $1010_2$，所以检测 $Q_3Q_2Q_1Q_0=1010$ 时令 $\bar R_D=0$ 异步清零。注意：**异步清零是「一旦等于 N 立刻清零」**，所以计数序列是 0,1,…,9,（瞬间 10）→0，实际只显示 0~9。
:::

::: tip 例 2 · 4 位异步（行波）计数器的最高工作频率
每位触发器传输延迟 $t_{pd}=20\,\text{ns}$。异步计数器里第 4 位要等前 3 位逐级翻完，最不利路径延迟 $=4\times20=80\,\text{ns}$。若时钟 $f=1\,\text{MHz}$（周期 $1000\,\text{ns}$），$80\ll1000$，安全；若想跑到 $10\,\text{MHz}$（周期 $100\,\text{ns}$），80 ns 已逼近极限，必须改同步结构。结论：**异步结构频率上限受级数拖累**。
:::

::: tip 例 3 · 4 位右移寄存器串入 1011
初态 `0000`，数据从高位到低位逐拍移入：

```
拍1 入1 → 0001
拍2 入0 → 0010
拍3 入1 → 0101
拍4 入1 → 1011
```

4 拍后并行输出端正好是 `1011`——这就是**串并转换**，串口通信、ADC 采样都靠它。
:::

::: tip 例 4 · 555 多谐振荡器算频率
取 $R_1=R_2=10\,\text{k}\Omega,\ C=0.1\,\mu\text{F}$，则
$$f=\frac{1.43}{(R_1+2R_2)C}=\frac{1.43}{(10\text{k}+20\text{k})\times0.1\mu}=476.7\,\text{Hz}$$
若改接成单稳态，触发后输出脉宽 $t_W=1.1RC=1.1\times10\text{k}\times0.1\mu=1.10\,\text{ms}$。555 因此既能做时钟源（多谐），也能做定时（单稳）。
:::

## 工程实例：用 74LS161 + 门 做电子秒表个位

秒表个位要 0~9 循环（十进制），正好是例 1 的清零法。把 161 的 $Q_3\sim Q_0$ 接到共阴数码管（经 BCD-七段译码器 74LS48），$\bar R_D$ 由「$Q_3Q_1$ 同时为 1 即 1010」经一个与非门给出——每计到 10 瞬间归零，数码管就稳稳显示 0~9 并向上一位进位。移位寄存器那套则用在 SPI 这类串行外设里做收发缓冲。

## 易错清单 + 自检

- **同步 / 异步清零差 1**：异步清零「一出现 N 立刻清」，所以接 N；同步清零「出现 N−1 时就准备好、下一拍才清」，接 N−1。混了会多数或少数一个。
- 边沿触发只在跳变采样；画时序图先画 CLK，再按边沿逐个更新 Q，**别在电平期间也翻**。
- 异步计数器有累积延迟，高速场合换同步；但同步要额外进位逻辑，面积和功耗更大——按需取舍。
- 移位寄存器「串入」时数据位的**先后次序**别搞反：高位先入还是低位先入，并行结果差很多（见例 3）。
- 555 的 $R_1$ 不能为 0，否则放电管直通；多谐公式里的 $2R_2$ 来自电容充、放电路径不对称，别漏掉系数 2。
- 自检：拖 <ModCounterDemo /> 把 N 设成 6，数一数循环是不是正好 0~5 六个状态？是就说明清零法你真懂了。
