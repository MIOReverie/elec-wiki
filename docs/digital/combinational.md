# 04 · 组合逻辑电路

<Meta time="35 min" level="核心" note="分析/设计两步走 + 三类中规模器件（译码器/选择器/加法器）" />

## 结论先行

1. **组合逻辑**：输出**只取决于当前输入**，没有记忆——这是它和时序逻辑（下一章）的根本分界线。
2. 做事只有两套流程：**分析**（拿到图 → 表达式 → 真值表 → 说功能）和**设计**（拿到需求 → 真值表 → 化简 → 画图）。
3. 别每道题都从门搭起。三大**中规模器件**直接拿来用：
   - **译码器 74LS138**：输出就是全部最小项，加一个门就能拼出任意 3 变量函数；
   - **数据选择器 74LS151**：把地址当变量、数据端接 0/1，可拼出任意组合逻辑，**连化简都不用**；
   - **加法器**：半加器、全加器，多位用超前进位提速。
4. **竞争冒险**：不同路径门延迟不同 → 输出冒出不该有的窄毛刺，靠滤波电容 / 冗余项 / 选通脉冲消除。

## 推导脉络：两类流程

**分析电路**（你手上有一张逻辑图，要说出它干嘛）：

```
① 从输入到输出逐级写表达式
② 化简（卡诺图或公式法，见 02 章）
③ 列真值表
④ 归纳功能（是加法器？比较器？还是个什么）
```

**设计电路**（你手上是一个功能需求，要画出图）：

```
① 定输入/输出变量并赋值（A/B/C 是什么，Y 是什么）
② 列真值表（把功能翻译成 0/1 表格）
③ 写表达式（从输出为 1 的行写「与或式」）
④ 化简
⑤ 按手头有的门类型变换形式、画图
```

口诀：**分析是「图 → 功能」，设计是「功能 → 图」**，中间都过真值表这一关。

## 三种中规模器件

### 1. 译码器（以 3-8 线 74LS138 为例）

3 位地址进来，8 个输出里**只有一个有效**。关键点在于：它的每个输出恰好就是一个**最小项**（低电平有效，即 $\bar m_i$）。所以——

> 任意 3 变量逻辑函数 $Y=\sum m(\dots)$，只要把对应那几个输出端用**一个与非门**收起来就行，根本不用自己化简。

例如 $Y=\sum m(1,3,5,6,7)$，对应 $Y=\overline{\bar Y_1\cdot\bar Y_3\cdot\bar Y_5\cdot\bar Y_6\cdot\bar Y_7}$（138 输出低有效，取反后相与）。

### 2. 数据选择器 MUX（以 8 选 1 74LS151 为例）

$$Y = \sum_i m_i D_i$$

把地址端当逻辑变量、数据端 $D_i$ 接 0 或 1，就能直接实现任意组合函数，**跳过化简**。例如要 $F(A,B,C)=\sum m(1,2,4,7)$，就把 $D_1=D_2=D_4=D_7=1$，其余 $D_i=0$。这是考试里的「偷懒神器」。

### 3. 加法器

- **半加器**：$S=A\oplus B,\ C=AB$（不管低位进位）
- **全加器**：$S=A\oplus B\oplus C_{in},\ C_{out}=AB+(A\oplus B)C_{in}$
- 多位加法：串行进位简单但慢（进位一级级爬）；**超前进位**靠组合逻辑直接算每位进位，快得多。

### 4. 数值比较器

1 位：$A>B \Leftrightarrow A\bar B$。多位从高位往低位比，高位不等就定了，相等才看下一位。

## 典型例题（数字均经计算）

::: tip 例 1 · 全加器算 1+1+1
输入 $A=1,\ B=1,\ C_{in}=1$。按公式：$S=1\oplus1\oplus1=1$，$C_{out}=1\cdot1+(1\oplus1)\cdot1=1+0=1$。
即本位和 $S=1$、向高位进位 $C_{out}=1$，结果写成二进制 `11`（本位 1，进 1）。拖上面的全加器把三个开关都拨到 1 即可验证。
:::

::: tip 例 2 · 4 位加法 9 + 7
按位加并进位：$1001+0111$，最低位 $1+1=0$ 进 1，逐级得到本位 `0000`、最高进位 1，合起来 $S=10000_2=16_{10}$，进位 $C=1$。手算 $9+7=16$ 吻合。多位加法器就是例 1 的全加器级联。
:::

::: tip 例 3 · 用 74LS138 实现 $F=\sum m(1,3,5,6,7)$
138 输出是低有效最小项 $\bar m_i$。目标函数包含的最小项是 $m_1,m_3,m_5,m_6,m_7$，于是
$$F=\overline{\bar m_1\cdot\bar m_3\cdot\bar m_5\cdot\bar m_6\cdot\bar m_7}=\overline{\bar Y_1\cdot\bar Y_3\cdot\bar Y_5\cdot\bar Y_6\cdot\bar Y_7}$$
即把 $Y_1,Y_3,Y_5,Y_6,Y_7$ 五个输出送进一个**五输入与非门**。注意使能端 $G_1$、$\bar G_{2A}$、$\bar G_{2B}$ 必须接成有效电平，138 才工作。
:::

::: tip 例 4 · 用 74LS151 实现 $F(A,B,C)=\sum m(1,2,4,7)$
把地址 $C,B,A$ 接到选择端，数据端按最小项填：$D_1=D_2=D_4=D_7=1$，其余为 0。则
$$F=\bar m_1\cdot1+\bar m_2\cdot1+\bar m_4\cdot1+\bar m_7\cdot1+\text{其余项}\cdot0=\sum m(1,2,4,7)$$
无需任何化简，拖上面的 MUX，把 $S_1S_0$ 拨到对应地址、$D$ 按表接好即可看到输出。
:::

## 工程实例：用 138 搭一个 3 位二进制「多数表决」

需求：3 个输入中至少 2 个为 1 时输出 1。真值表里 $m_3,m_5,m_6,m_7$ 为 1（即 $\sum m(3,5,6,7)$），直接对应 138 的四个输出端接一个四输入与非门——比用与或非门硬搭省事且可靠。这就是中规模器件「函数发生器」用法。

## 易错清单 + 自检

- 组合逻辑**没有记忆**；一旦你发现「上一拍的输出影响这一拍」，那已经掉进时序逻辑的坑了。
- 74LS138 输出是**低电平有效**（$\bar Y_i$），实现函数时要取反再与，别把逻辑搞反。
- 用 138/151 实现函数，**使能端必须接对有效电平**，否则片子根本不工作。
- 优先编码器优先级是**下标大的高**（$I_7$ 最高），接错优先级会「抢答」错误。
- 竞争冒险：表达式里某变量同时以原、反变量出现（如 $A+\bar A$ 型）就可能冒毛刺，消除靠冗余项最稳。
- 自检：拨动 <CombinationalDemo /> 里任意一组输入，输出是否和对应公式逐位吻合？吻合就说明你真的懂了，不只是背了。
