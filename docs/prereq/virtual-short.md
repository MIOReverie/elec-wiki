# 虚短与虚断

## 结论先行

- 运放在**线性区**（负反馈主导、输出不饱和）时有两条近似规则：
  - **虚断**：$i_-=i_+\approx0$。因为差分输入的输入电阻极高，$r_{id}$ 可达 $10^{12}\,\Omega$ 级。
  - **虚短**：$u_-\approx u_+$。因为开环增益 $A_{od}$ 极大（$10^5\sim10^6$），微小差压就能产生大输出。
- 于是运放变成一个「**电压跟随器**」：输出被反馈网络「绑」在输入上，输出与输入之间只隔一个**阻抗比**。
- **前提是负反馈**。没有负反馈（比较器、正反馈、自激）时，虚短虚断**不成立**——套上去是概念性错误。
- 虚短虚断是**近似**：精度受 $A_{od}$ 与 $r_{id}$ 限制；高精应用要看运放手册的输入偏置电流与失调电压。

**为什么它承重**：比例、加减、积分、微分、有源滤波、仪放——所有模拟运算电路的公式都是这两条规则的排列组合。记住这两条，公式不用背。

## 典型数值

- 典型运放 $A_{od}=10^5\sim10^6$，$r_{id}=10^{12}\,\Omega$。
- 反相比例器 $u_o=-\dfrac{R_f}{R_1}u_i$：$R_f=10\,\text{k}\Omega$、$R_1=10\,\text{k}\Omega$ 时 $A_u=-1$。
- 同相比例器 $u_o=\left(1+\dfrac{R_f}{R_1}\right)u_i$：$R_f=9\,\text{k}\Omega$、$R_1=1\,\text{k}\Omega$ 时 $A_u=10$。
- 输入偏置电流典型 1 nA 量级，$R_s=1\,\text{M}\Omega$ 时产生的失调约 $1\,\text{mV}$——**高阻输入必须用低偏置电流的运放**。
- 虚短的误差量级：$u_- - u_+ = u_o/A_{od}$。输出 10 V、$A_{od}=10^5$ 时，差压约 0.1 mV。

## 常见坑

- **给比较器套虚短**：比较器是开环工作，输出只到正负饱和，$u_-\ne u_+$。
- 忘记负反馈前提，把运放当「理想电压源」随便接。
- 同相输入端**没有接地或偏置电路**，输入电阻无穷大会把输入电压拉偏——**虚断 ≠ 输入端可以悬空**。
- 积分器输入含直流偏置时，输出单向爬顶直到电源轨限幅（实用做法是在反馈电容上并一个大电阻，限制直流增益）。
- 微分器在高频增益 $\omega R_f C$ 无限大，输入端要加小电阻限带宽，否则噪声被放大到满幅。

::: tip 例 1 · 反相放大器的增益 {#ex-virtual-short-1}

已知 $R_1=2\,\text{k}\Omega$、$R_f=20\,\text{k}\Omega$，输入 $u_i=0.5\,\text{V}$。

由虚断：输入端电流 $i_1=u_i/R_1=0.5/2\text{k}=0.25\,\text{mA}$，且全部流过反馈支路。由虚短：$u_-=u_+=0$（同相端接地），故 $u_o=-i_1 R_f=-0.25\text{mA}\times20\text{k}=-5\,\text{V}$。

$$A_u = -\frac{R_f}{R_1} = -10,\qquad u_o = -10\times0.5 = -5\,\text{V}$$

负号表示**反相**，这是反相结构固有的性质（不是「算错了」）。

> **为什么这么想**
> 虚断把输入变成「只取电压不取电流」，于是输入电流全部被逼进反馈支路；虚短把同相端的地平「搬」到反相端。这一搬，输出电压就等于「电流 × 反馈阻抗」，比例电路自然得出。

:::
