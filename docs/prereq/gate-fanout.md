# 门电路扇出与驱动能力

<Meta time="4 min" level="卡片" note="两个方向各算一次取小者；只看低电平扇出会把高电平带塌" />

一个输出挂了 20 个输入，电路图上看着好好的，现场却偶发死机。多半是扇出超了：低电平方向算得下，高电平方向早就塌了。

扇出是一个门的输出能同时带动多少个同族门输入。它得从两个方向各算一次，取小的那个：

- 高电平方向：$\text{扇出}_H = \dfrac{I_{OH}}{I_{IH}}$
- 低电平方向：$\text{扇出}_L = \dfrac{I_{OL}}{I_{IL}}$

扇入是另一回事：一个门的输入端连了几个源，它就是几扇入、$R_{in}$ 是几倍。两者别混。

## TTL 与 CMOS 差在哪

- TTL（双极型工艺）的高电平扇出通常远小于低电平扇出。原因是输入高电平电流在几十 µA 级，输入低电平电流在零点几 mA 级，前者难提供得多。
- CMOS（互补金属氧化物半导体，74HC 系列）扇出基本不受直流电流限制，只受电容负载限制，典型可达 50 个同族输入。
- 扇出不够的正解是加缓冲器（同相或反相），不是加电阻。

扇出算错的后果不是「信号弱一点」，而是输出电平掉出有效判决区，接收端随机翻转。这类故障在现场表现为偶发死机，最难查。

## 典型数值

以 74LS00（与非门）为例：

| 参数 | 数值 |
| --- | --- |
| $I_{OH}$（拉高输出电流） | 0.4 mA |
| $I_{OL}$（灌电流） | 16 mA |
| $I_{IH}$（输入高电平电流） | 40 µA |
| $I_{IL}$（输入低电平电流） | 0.4 mA |

于是 $\text{扇出}_H = 0.4\text{ mA}/40\ \mu\text{A} = 10$，$\text{扇出}_L = 16\text{ mA}/0.4\text{ mA} = 40$，取小者：扇出 = 10。

- 74HC00 同类参数下扇出典型值 50；74HCT 系列保持 TTL 阈值兼容，扇出与 74LS 同量级。
- 工程里扇出 10 往往不够用，一个输出常要接多个芯片的使能脚、或接长排线上的多个输入。所以 74LS 在系统里常配 74LS244/74LS125 做扇出扩展。

## 常见坑

- 只算一个方向：高电平扇出 10、低电平扇出 40，只看低电平就以为能带 40 个，接到 20 个时高电平已经塌了。
- 混淆扇出与扇入：压垮输出的是负载的输入电流，限制输出的是它自己的输出电流。
- 把「加一个下拉/上拉电阻改善边沿」当成增大扇出的手段。电阻治不了电流不够。
- 跨电压域时用 TTL 驱动 CMOS 只查高电平，忘了 TTL 的 $V_{OH(\min)}=2.7\,\text{V}$ 未必达到 74HC 的 $V_{IH(\min)}=3.5\,\text{V}$。

::: tip 例 1 · 某门电路的扇出是多少 {#ex-gate-fanout-1}

某 TTL 门参数：$I_{OH}=0.4\,\text{mA}$、$I_{OL}=8\,\text{mA}$、$I_{IH}=25\ \mu\text{A}$、$I_{IL}=0.4\,\text{mA}$。

$$\text{扇出}_H = \frac{0.4\text{ mA}}{25\ \mu\text{A}} = 16,\qquad \text{扇出}_L = \frac{8\text{ mA}}{0.4\text{ mA}} = 20$$

取小者，扇出 = 16。若实际要带 20 个输入，高电平方向不够：$20\times25\ \mu\text{A}=0.5\,\text{mA}>0.4\,\text{mA}$，输出高电平会掉到判决区以下。解法是加一个同相缓冲器，把负载拆成两组各 10 个。

> **为什么这么想**
> 高电平方向永远是短板，它同时受「输出电流小」和「输入电流大」两头挤压。算扇出先算两个方向再取小，而不是先算一个再说。

:::
