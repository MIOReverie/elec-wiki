# 输入阻抗

<Meta time="4 min" level="卡片" note="输入阻抗是「这一级从前级借走多少电流」的尺子——它不是新东西，模电里叫输入电阻 r_i" />

一句话结论：**输入阻抗 $Z_i=\dot U_i/\dot I_i$ 是从一个电路的输入端看进去的等效阻抗；在工作频段内它就是模电里那个输入电阻 $r_i$，它越大，从前级「借」走的电流越小，前级信号被分掉得越少。**

## 日常说法与正式定义

- 日常说法：把信号源接到放大器上，放大器会「吸」走一部分电流。吸得越多，信号源内部的电阻上压降越大，真正送到放大器输入端的电压就越小——这就是**负载效应**。
- 正式定义：在输入端加一个测试电压 $\dot U_i$、量流入的电流 $\dot I_i$，两者之比即**输入阻抗**：

$$
Z_i=\frac{\dot U_i}{\dot I_i}
$$

它一般是一个复数；**在纯电阻网络、且工作频率低到电抗可以忽略时，$Z_i$ 退化为实数，就是模电里说的输入电阻 $r_i$**。

## 「输入阻抗」与「输入电阻」是同一个东西吗

这是本站最容易混淆的一对名字，答案是：**同一件事的两种叫法，取决于要不要考虑电抗与频率。**

| 名字 | 什么时候用 | 量 |
| --- | --- | --- |
| **输入电阻** $r_i$ | 模电里算放大电路动态参数时，默认在中频区、电抗可忽略 | 实数，$\Omega$ |
| **输入阻抗** $Z_i$ | 含电容/电感、或要谈频率特性（如示波器探头、ADC 采样前端）时 | 复数，$\Omega$ |

所以：

- 「共基电路输入电阻太低」（[第 2 章 · 基本放大电路](../analog/amplifiers.md)）与「共基电路输入阻抗太低」说的是同一件事，前者是后者的低频特例；
- 「示波器输入阻抗 1 MΩ」（[实验 · 示波器](../lab/oscilloscope.md)）一定要用阻抗，因为 1 MΩ 旁边还**并联着十几 pF 的输入电容**，频率一高它就不是 1 MΩ 了。

## 为什么它越大越好（电压测量场合）

信号源有内阻 $R_s$，放大器输入阻抗 $Z_i$ 与它构成分压：

$$
\dot U_i=\frac{Z_i}{R_s+Z_i}\,\dot U_s
$$

- $Z_i\gg R_s$ → $\dot U_i\approx\dot U_s$，信号几乎全送到（**电压测量要的就是这个**）；
- $Z_i$ 与 $R_s$ 可比 → 信号被分掉一半甚至更多。

工程上的经验值：万用表电压档 $10\ \text{M}\Omega$、示波器 $1\ \text{M}\Omega$（10X 探头 $10\ \text{M}\Omega$），都是为了让 $Z_i$ 远大于一般电路的输出阻抗。反过来，**电流测量**要求输入阻抗越小越好（电流表串进回路，阻抗大了会改变回路电流）；**功率传输最大**则要求负载阻抗等于源阻抗（共轭匹配），三条要求互不相同，别混用。

## 常见误解

1. **把「输入阻抗」当成一个新的电路参数去单独算** → 它就是输入电阻在含电抗时的推广，电路不变、算法不变，只是把 $R$ 换成 $Z$。
2. **以为「阻抗大」就是「电阻大」** → 阻抗是复数，$|Z_i|$ 大不代表实部（耗能部分）大；纯电容的输入阻抗在低频下可以很大，但它不耗能。
3. **高频下还用万用表量出来的 $r_i$** → 高频时并联的输入电容把 $|Z_i|$ 拉下来，必须用阻抗而不是电阻。
4. **负反馈改变了它却没意识到** → 串联负反馈把输入电阻乘上 $(1+AF)$，并联负反馈把它除掉 $(1+AF)$，见 [06 · 放大电路中的反馈](../analog/feedback.md)。
