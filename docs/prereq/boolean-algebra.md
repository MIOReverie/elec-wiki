# 布尔代数与化简

<Meta time="4 min" level="卡片" note="德摩根穿过门时「与」「或」要对调，括号错一个意思就反了" />

**数字逻辑只由与、或、非三种运算构成，「非」穿过门时要按德摩根定律把「与」和「或」对调——化简的判据是项数最少，其次每项的字面数最少。**

## 记住这几条

- 一切数字逻辑只由三种运算构成：与（$\cdot$）、或（$+$）、非（$\bar A$）。其它门都是这三者的组合。
- **德摩根定律**是唯一必须背熟的公式：$\overline{A+B}=\bar A\cdot\bar B$，$\overline{AB}=\bar A+\bar B$——「非」穿过门时，符号要跟着翻。
- 化简的三个常用武器：吸收律 $A+AB=A$、分配律 $A+BC=(A+B)(A+C)$、冗余项 $AB+\bar AC+BC=AB+\bar AC$。
- **最简式的判据是项数最少，其次每项的字面数最少**，不是「看起来对称」。
- 与非门和或非门是**全能门**：只用其中一种就能搭出任意逻辑函数。

**为什么它承重**：化简不是应试技巧，而是直接的工程收益——门更少、延迟更低、面积与功耗更小；而德摩根是把「电路图 → 表达式 → 电路图」这条回路接通的唯一钥匙。

## 典型数值

- **最小项**（minterm：让函数取值为 1 的那一种变量取值组合）最多 $2^n$ 个：4 变量就是 16 个最小项、16 张卡诺图格子。
- 常见量级的收益：一个原本要 12 个门实现的监控逻辑，化简后 4 个门，面积与功耗大致按比例下降。
- 全与非实现并不总最省：与门用 2 个与非、或门用 3 个（非或非），**要按手头门型库实际折算**，而不是默认「与非最省」。

## 常见坑

- 化简后不验算：至少代入几个关键点，确认布尔值与原式完全一致再收工。
- **把或门的与非写错**：$A+B$ 的与非是 $\overline{AB}$，而 $\bar A\bar B$ 是「$A$ 与 $B$ 的与非」——两者只差一个括号，含义却完全不同。
- 把冗余项当「多余」删掉。它和原函数完全等价，删掉反而让竞争冒险冒出来。
- 正式书写一律用 $\bar{\ }$，不要手写 $A'$、$A''$，扫描时容易看错。

::: tip 例 1 · 化简 $Y = A + \bar{A}BC + BCD$ {#ex-boolean-algebra-1}

用 $A+\bar AX=A+X$ 得 $A+\bar{A}BC=A+BC$。再代 $BCD=BC\cdot D$，而 $BC$ 已含 $B$，故 $BC+BCD=BC$。

$$Y = A + BC$$

验算：$A=0,B=0$ 时原式 $0+1\cdot0\cdot C+0=0$，新式 $0$ ✓；$A=0,B=1,C=1,D=1$ 时原式 $0+1+1=1$，新式 $1$ ✓。

> **为什么这么想**
> 关键是先找**能配对的项**。$A$ 与 $\bar{A}BC$ 一眼能配成 $A+\bar AX$；先做完这一步，式子里就只剩三个乘积项，冗余项 $BCD$ 自然被吸收律吃掉。

:::
