# 静态工作点与负载线

<Meta time="5 min" level="卡片" note="最大摆幅取两侧余量的较小值，不是二分之一 V_CC" />

放大器调好了，波形下半边却被削平。这不是增益不够，是 Q 点压得太低，输出先撞上了截止。

静态工作点 Q 就是直流分析得到的 $V_{CEQ}$ 与 $I_{CQ}$，它决定交流信号「站在哪」。站偏了，一侧就先到边。

## 两条负载线

直流负载线由 $V_{CC}$ 与 $R_C$ 决定，$V_{CE}=V_{CC}-I_C R_C$，是一条直线。交流负载线换用 $R_L'=R_C//R_L$，斜率更陡。

Q 点得给上下两侧都留出摆幅：偏低会撞截止，输出顶部削平；偏高会撞饱和，输出底部削平。

最大不失真输出电压，取两侧余量里较小的那个，而不是简单地取 $\frac12 V_{CC}$。想让输出幅度最大，就让两侧余量相等。

Q 点是直流与交流两套分析的交接点：静态定位置，动态算增益，两套图分开画、结果互为印证。Q 点错了，后面的增益、输入输出电阻、失真分析都跟着错。

## 典型数值

分压式偏置共射电路：$V_{CC}=12\,\text{V}$、$R_{b1}=20\,\text{k}\Omega$、$R_{b2}=10\,\text{k}\Omega$、$R_C=2\,\text{k}\Omega$、$R_E=2\,\text{k}\Omega$、$\beta=60$：

- $V_B\approx V_{CC}\frac{R_{b2}}{R_{b1}+R_{b2}}=4\,\text{V}$
- $V_E=4-0.7=3.3\,\text{V}$，$I_E=3.3/2\text{k}=1.65\,\text{mA}$，$I_C\approx1.65\,\text{mA}$
- $V_{CE}=12-1.65\text{mA}\times4\text{k}=5.4\,\text{V}$（接近 $\frac12V_{CC}=6\,\text{V}$ ✓）

同一电路的最大不失真峰值：饱和侧 $5.4-0.3=5.1\,\text{V}$，截止侧 $1.65\,\text{mA}\times1.2\,\text{k}\Omega=1.98\,\text{V}$，取 1.98 V（有效值 1.40 V）。

## 常见坑

- 直流通路与交流通路混用。电容在直流是开路、在交流是短路：静态算 $V_{CE}$ 不带 $R_L$，动态算增益必须带 $R_L'$。
- 静态时把 $R_L$ 也算进去。负载是交流负载，静态时被电容隔断。
- 以为 $V_{CE}=\frac12V_{CC}$ 就一定最优。只有两侧的等效余量相等时才最优；本例里截止侧先到，实际最大输出只有 1.98 V，而不是 2.7 V。
- 分压式偏置不检查分压器够不够硬。应验证 $I_{R_{b1}}$ 至少是 $I_B$ 的 5~10 倍，本例 $600\ \mu\text{A}/27.5\ \mu\text{A}\approx22$ ✓。

::: tip 例 1 · Q 点该放在哪 {#ex-q-point-loadline-1}

某共射电路 $V_{CC}=12\,\text{V}$、$R_C=2\,\text{k}\Omega$、$R_L=4\,\text{k}\Omega$。现取 $I_{CQ}=1\,\text{mA}$，求最大不失真输出峰值。

第一步，交流负载线：$R_L'=R_C//R_L=\dfrac{2\times4}{2+4}=1.33\,\text{k}\Omega$。

第二步，两侧余量：

- 饱和侧：$V_{CEQ}-V_{CE(sat)}$。由直流负载线得 $V_{CEQ}=12-1\text{mA}\times2\text{k}=10\,\text{V}$，故饱和侧余量 $10-0.3=9.7\,\text{V}$。
- 截止侧：$I_{CQ}\times R_L' = 1\,\text{mA}\times1.33\,\text{k}\Omega = 1.33\,\text{V}$。

第三步，取小者：最大不失真峰值 $=1.33\,\text{V}$（有效值 0.94 V）。

结论：Q 点太高（$10\,\text{V}$，太靠近饱和端），截止侧先到。若把 $I_{CQ}$ 降到约 $0.6\,\text{mA}$，两侧余量会接近相等，输出幅度能接近翻倍。

> **为什么这么想**
> 输出摆幅被「哪一侧先撞墙」限制。只盯着 $V_{CEQ}$ 离 $V_{CC}$ 有多远不够，截止侧受的是 $I_{CQ}R_L'$ 约束，和 $R_L$ 有关。两个余量要一起算。

:::
