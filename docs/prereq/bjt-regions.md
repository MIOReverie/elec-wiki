# 三极管工作区

<Meta time="4 min" level="卡片" note="饱和区里 I_C 不等于 βI_B，这是最常犯的公式错误" />

**三极管的工作区由两个结的偏置决定，而 $I_C = \beta I_B$ 只在放大区成立——所以判区永远是第一步。**

## 记住这几条

- BJT（bipolar junction transistor，双极型晶体管）是**电流控制器件**：$I_C=\beta I_B$ 只在**放大区**成立。判断工作区永远是第一步。
- 判据看两个结的偏置：
  - 发射结**正偏**、集电结**反偏** → **放大区**（线性放大用）
  - 两个结都**正偏** → **饱和区**（$V_{CE}\approx0.2\sim0.3\,\text{V}$，当开关闭合用）
  - 发射结**反偏**（$I_B\le0$）→ **截止区**（$I_C\approx0$，当开关断开用）
- 实用判据（给定 $V_{CC}$、$R_C$、$I_B$）：先算需求 $I_C=\beta I_B$，再算天花板 $V_{CC}/R_C$，**谁小听谁的**。
- 饱和区的 $I_C\ne\beta I_B$——这是最常见的分析错误。

**为什么它承重**：放大电路、开关电路、逻辑驱动电路用的是同一种管子的不同工作区。分不清区，公式就会用错；而 $I_C=\beta I_B$ 在饱和时失效这一点，是模拟电路与数字电路之间的接缝。

## 典型数值

- 硅管 $V_{BE}\approx0.7\,\text{V}$（发射结），$V_{CE(sat)}\approx0.2\sim0.3\,\text{V}$。
- 常见 $\beta$ 值 50~200；设计时**取最小值**（甚至按 $\beta/2$ 折算）留余量，因为 $\beta$ 随 $I_C$、温度显著变化。
- 例：$\beta=100$、$I_B=20\ \mu\text{A}$ → 需求 $I_C=2.0\,\text{mA}$；若 $V_{CC}=12\,\text{V}$、$R_C=3\,\text{k}\Omega$，天花板 $=4.0\,\text{mA}>2.0\,\text{mA}$ → **放大区**。
- 若 $I_B$ 升到 $60\ \mu\text{A}$，需求 $6.0\,\text{mA}>4.0\,\text{mA}$ → **饱和**，$V_{CE}$ 被摁在 0.3 V 附近。

## 常见坑

- 用 $\beta$ 判断饱和时忘了 $\beta$ 本身是变量；饱和判据应该用**固定的 $V_{CE(sat)}$**。
- 饱和时仍写 $I_C=\beta I_B$，算出远大于实际的值。
- 忘记**基极需要足够电流才能让集电极电流流出来**：集电极电流的来源是 $V_{CC}$ 经 $R_C$，不是从基极「变出来」的；基极的作用只是「控制」。
- 把 $V_{BE}=0.7\,\text{V}$ 当常数精确使用：高温时它掉到 0.5 V 以下，会造成热失控。

::: tip 例 1 · 判断三极管的工作区 {#ex-bjt-regions-1}

$\beta=100$、$I_B=20\,\mu\text{A}$、$V_{CC}=12\,\text{V}$、$R_C=3\,\text{k}\Omega$。

**第一步 需求**：$I_C = \beta I_B = 100\times20\,\mu\text{A} = 2.0\,\text{mA}$。

**第二步 天花板**：$I_{C(max)} = V_{CC}/R_C = 12/3\text{k} = 4.0\,\text{mA}$。

**第三步 比较**：$2.0 < 4.0$，需求没超过天花板 → **放大区**。此时

$$V_{CE} = V_{CC}-I_C R_C = 12 - 2.0\text{mA}\times3\text{k} = 6.0\,\text{V}$$

若把 $I_B$ 提到 $60\ \mu\text{A}$：需求 $6.0\,\text{mA} > 4.0\,\text{mA}$ → **饱和**，$V_{CE}\approx0.3\,\text{V}$，$I_C$ 被 $R_C$ 限死在 $4.0\,\text{mA}$（不是 $6.0\,\text{mA}$）。

> **为什么这么想**
> 把三极管当成一个「电流阀门」：基极电流决定阀门开多大，但流过的电流由外部电源和 $R_C$ 决定。**开多大是控制，开多大能开是电路**。两件事分开算，就不会错。

:::
