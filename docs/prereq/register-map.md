# 寄存器映射

<Meta time="5 min" level="卡片" note="偏移量单位是字节，不是「第几个寄存器」；写错不报错，只是行为诡异" />

**「配置外设」就是往固定地址写特定的数——寄存器是占着固定地址的一小块内存，不是某种特殊硬件。**

## 记住这几条

- 「配置外设」的本质是**往固定地址写特定的数**。寄存器不是某种特殊硬件，而是**占据固定地址的一小块内存**。
- Cortex-M 有 4 GB 线性地址空间，厂商把它切成：Flash（代码与 `const`）、SRAM（变量、栈、堆）、**外设寄存器区**、内核系统控制块（NVIC、SysTick）。
- 外设寄存器按**基地址 + 固定偏移**排列，偏移量写在手册里（通常是 4 的倍数）。
- CMSIS（Cortex 微控制器软件接口标准）把这些地址定义成**结构体指针**，于是 `GPIOA->ODR |= (1<<5)` 这种写法，本质是往 `0x4001080C` 写一个数。
- 三个动作各归其位：**读-改-写**改寄存器位，**置位/清零**用 `BSRR` 原子完成，**配引脚模式**用 `CRL/CRH`。
- 寄存器字段常常是**位段**（一个 32 位字里挤着十几个互不相干的配置位），所以位操作是基本功而不是技巧。

**为什么它承重**：嵌入式和上位的分水岭就在这里——没有「内存」这个概念，就没法理解指针、地址、`volatile`、原子性，也没法写出第一行驱动代码。

## 典型数值

以 F103 的 GPIOA 为例，寄存器组从 `0x4001 0800` 开始：

| 偏移 | 寄存器 | 作用 |
| --- | --- | --- |
| `0x00` | `CRL` | 配置 Pin0~7（每脚 4 位） |
| `0x04` | `CRH` | 配置 Pin8~15（每脚 4 位） |
| `0x08` | `IDR` | 输入数据（读引脚电平） |
| `0x0C` | `ODR` | 输出数据（写引脚电平） |
| `0x10` | `BSRR` | **原子**置位/清零 |
| `0x14` | `BRR` | 清零（等价于 BSRR 高 16 位） |

CMSIS 把这张表变成一个结构体指针，于是下面两行完全等价：

```c
#define GPIOA_BASE 0x40010800UL
typedef struct {
  volatile uint32_t CRL, CRH, IDR, ODR, BSRR, BRR, LCKR;
} GPIO_TypeDef;
#define GPIOA ((GPIO_TypeDef *)GPIOA_BASE)
```

- 地址区间速记：Flash `0x0800 0000`~、SRAM `0x2000 0000`~、外设 `0x4000 0000`~、内核 `0xE000 0000`~。
- 32 位寄存器里常塞十几个字段，**一个 32 位字 = 4 个字节 = 4 个外设寄存器**——按字节偏移时别把 `0x04` 写成 `0x01`。
- 指针加 1 走的是**下一个 32 位寄存器**，不是下一个字节：`(uint32_t *)0x40010800 + 1` 落在 `0x40010804`（CRH），不是 `0x40010801`。
- 结构体里的 `volatile` 不是装饰：没有它，编译器会把「读一次、算一次、写回」优化掉，改配置就完全失效。

## 常见坑

- **偏移量写错单位**：手册给的是字节偏移，不是「第几个寄存器」。
- 忘记使能外设时钟就写寄存器：写进去了，硬件不响应（见[时钟树](./clock-tree.md)）。
- **「读-改-写」不是原子的**：在中断里可能被抢占，必须用 `BSRR`。
- 用 `ODR` 直接改引脚电平时忘了先配 `CRL/CRH` 的模式位（推挽/开漏、上下拉、速度）。
- 把结构体指针强转成 `uint32_t*` 逐个访问：结构体的对齐与打包假设可能不成立。
- **地址算完不核对用途**：`0x4000 0000` 起的整段都是外设区，不同外设的基地址彼此独立，抄错一位就会写到别的外设上——而且**不报错**，只是行为诡异。

::: tip 例 1 · 用偏移算出 GPIOA 的 ODR 地址 {#ex-register-map-1}

F103 的 GPIOA 基地址是 `0x4001 0800`，ODR 偏移 `0x0C`。

$$0x40010800 + 0x0C = 0x4001080C$$

于是把 PA5 置 1，写的就是这个地址上的第 5 位：

```c
GPIOA->ODR |= (1 << 5);   // 即向 0x4001080C 写 OR 后的 32 位数
```

要原子地置位（可能正在中断里），改用 `BSRR`（偏移 `0x10`）：

```c
GPIOA->BSRR = (1 << 5);   // 置位；清零则写 GPIOA->BSRR = (1 << 21)
```

> **为什么这么想**
> 「寄存器」这个词容易让人以为它是某种独立的硬件机制，其实它就是内存。把寄存器想成内存，普通 C 的指针、`volatile`、位运算就全都对得上了——`ODR` 是内存中的一个 32 位字，和读一个变量没有本质区别。

:::
