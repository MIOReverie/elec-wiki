# 线性代数 · 经典结构

<Meta time="3 min" level="指南" note="临时复习板块：先花 3 分钟看清六章路线和每章对应的同济教材章号，再决定跟教材进度走还是按需补漏；与电学课相互独立，复习完即可从导航与首页移除入口" />

这块「线性代数 · 经典结构」是给你**跟着同济《线性代数》教材走**用的临时复习板块。它和本站四门电学课（[电工学](../ee/)、[数字电路](../digital/)、[模拟电子](../analog/)、[嵌入式](../embedded/)）**没有前置依赖，也不被它们依赖**；它也不与[现代结构版](../linalg/)互相依赖——两版讲的是同一门线性代数，只是**顺序和讲法不同**，学完即可把入口整个拿掉，不影响其它任何内容。

经典结构按国内主流教材（同济《线性代数》）的教学顺序走：**行列式 → 矩阵 → 初等变换与方程组 → 向量组 → 特征值 → 二次型**。它侧重「怎么算、步骤是什么」：每章先给结论和标准动作，再配能亲手照着算的例题；每章页头都标了「对应教材第几章」，方便跟着课堂进度讲到哪章读哪章。想懂「为什么」的几何直觉，就去查[现代结构版](../linalg/)，两版同主题可互查。

## 经典结构与现代结构的对照

两版并行，选哪版看你的目标：

| 维度 | 经典结构（本版） | 现代结构（[点此进入](../linalg/)） |
| --- | --- | --- |
| 顺序 | 行列式 → 矩阵 → 方程组 → 向量组 → 特征值 → 二次型 | 向量 → 线性变换 → 消元 → 子空间 → 行列式 → 特征值 → 正交 |
| 讲法 | 计算方法与解题步骤先行 | 几何直觉先行，再落公式 |
| 对齐 | 同济《线性代数》逐章对齐 | Strang / 3Blue1Brown |
| 适合 | 跟着教材进度走、应付考试计算 | 想搞懂「为什么」、重建几何图景 |

两版**同一主题可互查**：经典版某页开头会指路「想懂几何意义去现代版哪页」，现代版某页也会回指经典版的对应计算。比如行列式——经典版教你怎么用性质把 4 阶行列式算出来，现代版告诉你行列式是面积、体积的缩放因子。

## 怎么跟踪教材进度

因为每章页头都标了「对应教材第 N 章」，你可以直接把它当**教材进度条**用：

1. **课堂讲到哪章，就读哪章**：六章顺序与同济教材一致，页头章号对得上，不用再翻目录找。
2. **每章先读「结论先行」**：5 条结论先把本章要背的结论和易错点列出来，几分钟扫完再决定细读哪几节。
3. **例题亲手算**：每道例题都配了手写 SVG 和 node 验算过的数字，照着步骤抄一遍，再回头对结论。
4. **卡住就地补**：每章开头有「读这页之前」写明前置，末尾有「易错清单」和「自检」，算不过说明前面某章要回补。

跟课堂进度走最省力：**行列式算熟 → 矩阵会乘会求逆 → 方程组化成阶梯形判解 → 向量组会判相关求秩 → 特征值会解特征方程 → 二次型会配方判正定**，六步走完就是同济教材的主干。
