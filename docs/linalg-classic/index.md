# 线性代数 · 经典结构

<Meta time="3 min" level="指南" note="六章与同济教材章号对齐，页头标了对应第几章；跟课堂进度读最省事" />

这一版按同济《线性代数》的章序排：行列式，矩阵，初等变换与方程组，向量组，特征值，二次型。它是给要跟课堂、要交作业的人用的：每章先说要会做哪几件事，再给能照着落笔的步骤和例题，页头标了对应教材第几章。

想搞清「为什么长这样」，同一门课还有一版[现代结构版](../linalg/)，从箭头和变换讲起。两版不互为前置，选一版读就够：跟课堂走读这一版，补直觉去那一版。

## 先读哪章、能跳哪章

```
01 → 02 → 03 → 04
01、02、03 一起供 05，05 再供 06
```

04 只在 05 里用到一处，就是「$n$ 个无关的特征向量」里的无关那两个字。老师直接跳到第五章、你想先跟 05 时，进 05 之前把 04 第一节（讲「线性无关」那条定义的那一节）读一遍就够，其余可以后补，05 的前置块里也把这条定义写全了。

## 跟着课堂进度怎么用

四条经验，按你会用到的先后排：

1. 对章号。页头「对应教材第 N 章」与上表一致，课堂讲到哪章就读哪章；两版章号排法不同，别拿另一版的章号来对。
2. 先看那几类题。每页开头会把要解决的动作列出来，只写动作不写术语，这几件事会做了，那页就可以过。
3. 例题照抄一遍。每道例题都是先猜结果的量级与符号，再一步步算，最后代回原式核对；抄完一遍再遮住答案自己走一次。
4. 收尾回看。每页末尾那几句是这一章的落点；算不过就回上一章的末尾几句，而不是继续往下翻。

这个板块是临时加的，与四门电学课互不依赖，复习完可以从导航里移除；开始读就从上面的 01 进。
