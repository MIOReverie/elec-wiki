# 线性代数 · 现代结构

学过一遍、考试也过了，现在翻开只记得几个名词，这是多数人回来时的状态；也有人当时就没学明白。这一版是给这两种状态写的：每个符号先还原成一件画得出来的事，再交回要算的步骤，不重讲定义，也不跳过「为什么」。

同一门课还有一版[经典结构版](../linalg-classic/)，按同济教材章序排，页头标着对应第几章，用来对课堂进度、做作业。两版不互为前置：这一版回答「为什么长这样」，那一版回答「这一步怎么落笔」。要对章号就去那一版，这里按理解顺序排。

## 正文与例题怎么用

几条能省时间的习惯，按重要程度排：

1. 页头两段先看。一段说清进来时卡在哪里、读完会做什么；另一段列出要先会的东西，每条后面都跟一句复习，不用翻回去。
2. 例题先猜再算。每道都是先猜结果的量级、符号、个数，再一步步算，最后代回原式核对。先遮住答案自己猜一遍，再对照。
3. 算不动的时候，回上一页末尾那几行；还不行就把这一步的算式抄在纸上，逐项念出每个符号是什么。
