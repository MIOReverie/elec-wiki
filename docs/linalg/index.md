# 线性代数

<Meta time="3 min" level="指南" note="临时复习板块：先花 3 分钟看清七章路线图和每条几何主线，再决定从哪章开始；与电学课相互独立，复习完即可从导航与首页移除入口" />

这块「线性代数」是给你**复习**用的临时板块，和本站四门电学课（[电工学](../ee/)、[数字电路](../digital/)、[模拟电子](../analog/)、[嵌入式](../embedded/)）**没有前置依赖，也不被它们依赖**：它是一份独立的数学复习，学完即可从导航栏和首页把这个入口整个拿掉，不会影响其它任何内容。

它按**现代结构**而不是传统「行列式先行」的顺序讲：每个概念都先给你一张几何图景——箭头、被掰变形的网格、扫过的区域、被压扁的空间——再落到代数公式。这条思路来自 Gilbert Strang《Introduction to Linear Algebra》和 3Blue1Brown《线性代数的本质》，面向「见过这些词、会算但不知道在干什么」的复习者，不重新从零教起，也不跳过直觉只给公式。

## 七章路线图

| 章 | 一句话几何直觉 | 落在纸上的代数 |
| --- | --- | --- |
| [01 · 向量、线性组合与张成](./01-vectors) | 箭头和列坐标是同一个东西的两面；线性组合是掰箭头、张成是扫过的区域 | $\mathbf v$、$c_1\mathbf v_1+c_2\mathbf v_2$、span、线性无关 |
| [02 · 矩阵与线性变换](./02-matrices) | 矩阵是一台把整张网格掰变形的机器，两列就是基向量 $\mathbf i,\mathbf j$ 的像 | $A\mathbf x$、$AB$（先 B 后 A）、$A^{-1}$、$A^T$ |
| [03 · 高斯消元与线性方程组](./03-elimination) | 每个方程是一条直线/平面，解是公共交点；消元就是一步步削成上三角 | 初等行变换、主元、行阶梯形、$A=LU$ |
| [04 · 向量空间与四大子空间](./04-subspaces) | 列空间是 A 能扫出的位置，零空间是被 A 压到原点的箭头 | 基、维数、秩、$\dim C(A)+\dim N(A)=n$ |
| [05 · 行列式：面积缩放的因子](./05-determinant) | 行列式是变换把面积/体积放大了多少倍，负号表示翻转 | $\det A$、代数余子式、$\det A=0\iff$ 不可逆 |
| [06 · 特征值、特征向量与对角化](./06-eigenvalues) | 特征向量是方向不变的箭头，特征值是那个拉伸倍数 | $\det(A-\lambda I)=0$、$A=PDP^{-1}$ |
| [07 · 正交、投影与二次型](./07-orthogonality) | 垂直就是点积为零；投影是垂足，是最短距离 | 点积、Gram-Schmidt、最小二乘、正定 |

## 一条几何主线串起七章

七章不是七个孤立的主题，而是一条从「箭头」长出来的主线：

```
箭头(01)  →  掰变形的机器(02)  →  解交点的消元(03)  →  空间被压成什么(04)
              ↘ 放大了多少倍(05)   ↘ 谁方向不变(06)   →  垂直与垂足(07)
```

- **01–02 建立视角**：先把向量看成箭头，再把矩阵看成变换——后面每一章的几何图景都建立在这两句上。
- **03–04 回答两个基本问题**：方程组怎么解（消元）、变换把空间压成什么形状（子空间与秩）。
- **05–06 给变换配数字**：行列式是「面积放大的倍数」，特征值是「方向不变那个方向上的拉伸倍数」。
- **07 把角度请回来**：正交、投影、最小二乘是这一章的三件工具，也是让几何直觉落地成计算的地方。
