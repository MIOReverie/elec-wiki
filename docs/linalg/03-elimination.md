# 03 · 高斯消元与线性方程组

<Meta time="30 min" level="核心" note="消元就是把系数矩阵一步步削成上三角；把每步的乘子按位置存进下三角矩阵 L，消元结果就是上三角 U，于是 A=LU。" />

**这一页要解决什么**：前两章把矩阵看成「把向量掰到新位置」的线性变换，这一章回到一个更朴素的问题——方程组 $A\mathbf x=\mathbf b$ 到底怎么解、什么时候有解。高斯消元（Gaussian elimination）是标准答案：它不改变解集，只把矩阵「削」成上三角，然后从最后一个方程倒着往上代。读完你应该能：对任意方阵走完整套消元、认出主元、判定唯一解/无穷多解/无解，并且说出 $A=LU$ 为什么等价于「把消元过程存进两个矩阵」。

::: tip 读这页之前
- **需要会**：矩阵乘向量 = 各列按分量加权相加（列视角），见同板块第 2 章《矩阵与线性变换》；向量加减与数乘见第 1 章《向量、线性组合与张成》。符号约定可查 [符号与约定](../guide/notation.md)。
- **高中数学必要部分**：会解二元一次方程组（代入法、加减法）、会把 $ax+by=c$ 画成一条直线。
- **本页术语**：增广矩阵、初等行变换、主元、行阶梯形、LU 分解，正文在首次出现处都会解释。
- **学完去哪**：本页是第 4 章《向量空间与四大子空间》的入口——「无解 vs 无穷多解」的区别，会分别用列空间和零空间重新解释一遍。
:::

先回到最熟悉的高中画面：解二元一次方程组，就是在平面上找两条直线的交点。方程 $ax+by=c$ 对应一条直线，「同时满足两个方程」就是「同时落在两条直线上」——也就是交点。交点有一个、没有、还是整条线都是公共部分，正好对应解的三种命运：唯一解、无解、无穷多解。到三个未知数，每个方程从直线升级成平面，解从交点变成「三个平面的公共点」。高斯消元做的事，就是把这些几何上的「找公共部分」，翻译成一串机械、可编程、且不改变解集的矩阵行变换。

## 结论先行

1. **$A\mathbf x=\mathbf b$ 的每一行是一个方程**；把系数矩阵 $A$ 和右端 $\mathbf b$ 并排写成增广矩阵 $[A\ \ \mathbf b]$，消元时对两边一起做，才不会把解改错。
2. **高斯消元只做三种初等行变换**：交换两行、某行乘非零数、某行减去另一行的倍数。它们都可逆，因此**不改变解集**；目标是让 $A$ 变成上三角。
3. **主元是每一列「第一个非零、并负责把下方削成 0」的数**；非零主元的个数，就是第 4 章要讲的「秩」。
4. **解的判定看最后一行**：上三角里出现 $0=k\ (k\neq0)$ 就无解；出现整行 $0=0$ 就有自由变量、无穷多解；否则每列都有主元、唯一解。
5. **LU 分解就是消元本身**：把「用第 $j$ 行消第 $i$ 行」的乘子按位置塞进下三角矩阵 $L$，消元得到上三角 $U$，就有 $A=LU$。解方程于是拆成「先解 $L\mathbf c=\mathbf b$，再解 $U\mathbf x=\mathbf c$」两段更简单的前代与回代。

## 一、方程组的三张脸

这一节目标是让你先建立「行视角、列视角、矩阵视角」三种读法，因为消元全程都活在行视角里，但解的几何意义要靠行视角和列视角一起理解。

先看一个二元例子，$x+y=3$ 与 $x-y=1$。**行视角（row picture）**是「求两条直线 $x+y=3$ 与 $x-y=1$ 的交点」——解是交点坐标 $(2,1)$。**列视角（column picture）**是把同一个方程组改写成 $x\binom{1}{1}+y\binom{1}{-1}=\binom{3}{1}$，也就是「用多少倍的 $\binom11$ 加多少倍的 $\binom{1}{-1}$ 能拼出 $\binom31$」——答案 $x=2,y=1$。**矩阵视角（matrix picture）**只是把列视角压缩成 $A\mathbf x=\mathbf b$ 一个符号，其中 $A$ 的列就是那两个系数向量、$\mathbf x$ 是未知数、$\mathbf b$ 是右端。

三种视角里，**消元是在行视角下最自然**：因为「把一个方程的倍数加到另一个方程上」是纯行操作。理解了行视角，下一节就开始动手削矩阵。

## 二、高斯消元：把矩阵削成上三角

这一节目标是把「加减消元」这个中学手艺，改造成一套对任意矩阵都管用的机械流程，并解释它为什么不改变解。

消元前先做两件准备工作。第一，把方程组的系数和右端并排写成一张表，叫**增广矩阵（augmented matrix）**：对 $A\mathbf x=\mathbf b$，写 $[A\ \ \mathbf b]$。比如下面的三未知数方程组，对应增广矩阵是：

$$2x+y+z=5,\qquad 4x-6y=-2,\qquad -2x+7y+2z=9$$

$$\left[\begin{array}{ccc|c}2&1&1&5\\4&-6&0&-2\\-2&7&2&9\end{array}\right]$$

第二，明确允许哪些操作。我们只做三种**初等行变换（elementary row operations）**，它们都等价于「方程两边同时做合法操作」，因此不改变解集：

| 变换 | 记号 | 为什么解集不变 |
| --- | --- | --- |
| 交换两行 | $R_i\leftrightarrow R_j$ | 方程顺序不影响「同时成立」 |
| 某行乘非零常数 | $R_i\gets cR_i\ (c\neq0)$ | 等式两边同乘，可逆 |
| 某行减另一行的倍数 | $R_i\gets R_i-cR_j$ | 等量替换，可逆 |

所谓**高斯消元**，就是从左上角开始，用「第 $k$ 行把下面每一行第 $k$ 列削成 0」，一列一列往右推进，直到矩阵变成上三角（对角线以下全是 0）。每一步里，负责「坐镇」第 $k$ 列的那个非零数叫**主元（pivot）**；用它消第 $i$ 行（$i>k$）时算出的比例 $l_{ik}=a_{ik}/a_{kk}$ 叫**乘子（multiplier）**。

用上面的方程组演示。主元 $a_{11}=2$，乘子 $l_{21}=4/2=2$、$l_{31}=-2/2=-1$，对第 2、3 行消元后：

$$\left[\begin{array}{ccc|c}2&1&1&5\\0&-8&-2&-12\\0&8&3&14\end{array}\right]$$

主元 $a_{22}=-8$，乘子 $l_{32}=8/(-8)=-1$，再消第 3 行：

$$\left[\begin{array}{ccc|c}2&1&1&5\\0&-8&-2&-12\\0&0&1&2\end{array}\right]$$

削成上三角后，从最后一行倒着解就是**回代（back substitution）**：由 $z=2$，代入第二行 $-8y-2z=-12$ 得 $y=1$，再代入第一行 $2x+y+z=5$ 得 $x=1$。所以解是 $x=1,\ y=1,\ z=2$。

::: tip 例 1 · 高斯消元求 $x,y,z$
**先想什么**：先把方程组写成增广矩阵，一列一列削，每列记录乘子，削到上三角再回代。

**为什么**：消元只做可逆行变换，所以削出来的上三角与原方程组同解；回代时每步只剩一个未知数，不会出错。

**过程**（承上面正文）：

$$2x+y+z=5,\quad 4x-6y=-2,\quad -2x+7y+2z=9$$

$$l_{21}=2,\ l_{31}=-1:\quad\left[\begin{array}{ccc|c}2&1&1&5\\0&-8&-2&-12\\0&8&3&14\end{array}\right]$$

$$l_{32}=-1:\quad\left[\begin{array}{ccc|c}2&1&1&5\\0&-8&-2&-12\\0&0&1&2\end{array}\right]$$

回代：$z=2$，$-8y-2z=-12\Rightarrow y=1$，$2x+y+z=5\Rightarrow x=1$。

**验算**：把 $(1,1,2)$ 代回原方程组，$2+1+2=5$、$4-6=-2$、$-2+7+4=9$，三式都成立（node 验算见页脚）。
:::

到这里，解是唯一解还是别的，其实在消元过程中就已经被「主元」决定了。下一节就把判定条件说清楚。

## 三、主元、行阶梯形与解的判定

这一节目标是把「有没有解、解有几个」从消元结果里读出来，方法是看主元是否在中途「掉链子」。

削到上三角后，把每行第一个非零元（主元）的位置记下来，整个矩阵就呈现出阶梯状，称为**行阶梯形（row echelon form）**。上三角只是它的一个特例。判定解的情况，本质就是数「主元是否覆盖了每一列」以及「最后是否冒出矛盾行」：

| 消元后出现的行 | 含义 | 结论 |
| --- | --- | --- |
| 出现 $0=k$（$k\neq 0$） | 方程要求 $0$ 等于非零数，自相矛盾 | 无解 |
| 出现整行 $0=0$ | 有效方程少于未知数，出现自由变量 | 无穷多解 |
| 每列都有主元 | 回代时每步唯一确定 | 唯一解 |

几何上这套判定一目了然：$0=k$ 对应「两条直线平行、永远不相交」；整行 $0=0$ 对应「两条直线其实是同一条，交点无穷多个」；每列都有主元对应「两条直线斜率不同，交于唯一一点」——正是上面那张三格图。对 $n$ 个未知数，直线换成超平面，逻辑完全一样。

::: tip 例 2 · 无解与无穷多解的判定
**先想什么**：不急着解，先消元看最后一行是不是 $0=k$ 或 $0=0$。

**为什么**：判定解的存在性与个数，只取决于消元后的阶梯形状，不取决于具体数值。

- **无解**：$x+y=3$ 与 $x+y=5$。两式相减得 $0=2$，矛盾 → 无解（两条斜率相同的直线平行）。
- **无穷多解**：$x+y=3$ 与 $2x+2y=6$。第二式是第一式的 2 倍，相减得 $0=0$ → 无穷多解（两条直线重合，通解 $y=3-x$，$x$ 自由）。
- **唯一解**：$x+y=3$ 与 $x-y=1$。每列都有主元，回代得 $x=2,y=1$。

**验算**：无解情形消元后 $0=2\neq0$；重合情形 $6-2\times3=0$；唯一解代回 $2+1=3$、$2-1=1$ 都成立。
:::

判定只依赖上三角 $U$ 的形状，而 $U$ 是消元一步步「削」出来的。既然每步都可逆、都能写成矩阵乘法，消元本身就应该能写成矩阵分解——这就是下一节的 LU 分解。

## 四、LU 分解：消元就是矩阵分解

这一节目标是把「消元」从一套手工步骤升级成一个等式 $A=LU$，并理解它为什么是同一个东西的两种说法。

先补一个工具：每次初等行变换都可以用一个矩阵左乘来实现。比如「把第 1 行的 2 倍加到第 2 行」就是左乘一个几乎等于单位阵、只在第 $(2,1)$ 位置填 $-2$ 的矩阵——这类矩阵叫**初等矩阵（elementary matrix）**，本章只需记住这一句：**初等行变换 = 左乘一个初等矩阵**。

消元全程就是一连串初等矩阵左乘 $A$。关键观察是：这些「下三角的、只动第 $i$ 行」的变换叠加起来，等价于**一次**左乘一个下三角矩阵 $E$，让 $EA=U$。再把 $E$ 取逆移到右边，就得到 $A=E^{-1}U$，记 $L=E^{-1}$，就是著名的 **LU 分解**：

$$A=LU$$

其中 $L$ 是**下三角矩阵（lower triangular）**、对角线全是 1，$U$ 是**上三角矩阵（upper triangular）**。神奇的是 $L$ 根本不用算逆：**直接把每步的乘子按位置填进 $L$ 就行**——消第 $i$ 行的乘子 $l_{ik}$ 就放在 $L$ 的第 $(i,k)$ 位置，对角线填 1。

为什么这么巧？因为「先消第 1 列、再消第 2 列」这些变换天然可逆且顺序明确，把它们倒过来排列，乘子会自动落在下三角的正确位置。于是**消元 = 把 $A$ 分解成 $L$ 和 $U$ 这两个更简单的矩阵**：解 $A\mathbf x=\mathbf b$ 就拆成两步——先用前代解下三角方程 $L\mathbf c=\mathbf b$（从上往下代），再用回代解上三角方程 $U\mathbf x=\mathbf c$（从下往上代）。

::: tip 例 3 · 写出 LU 分解
**先想什么**：对着例 1 的消元过程，把乘子 $l_{21}=2,\ l_{31}=-1,\ l_{32}=-1$ 按位置塞进 $L$。

**为什么**：$L$ 的对角线是 1，第 $(i,k)$ 位置就是消第 $i$ 行用的乘子，无需再算逆矩阵。

**过程**：

$$A=\begin{bmatrix}2&1&1\\4&-6&0\\-2&7&2\end{bmatrix}=LU=\begin{bmatrix}1&0&0\\2&1&0\\-1&-1&1\end{bmatrix}\begin{bmatrix}2&1&1\\0&-8&-2\\0&0&1\end{bmatrix}$$

**验算**：把 $L$ 与 $U$ 相乘，第 1 行 $(2,1,1)$、第 2 行 $(4,-6,0)$、第 3 行 $(-2,7,2)$，正好还原 $A$（node 验算见页脚）。解方程时先 $L\mathbf c=\mathbf b$ 得 $\mathbf c=(5,-12,2)$，再 $U\mathbf x=\mathbf c$ 回代得 $\mathbf x=(1,1,2)$，与例 1 一致。
:::

LU 分解把「解一个方程组」变成了「存一次分解 + 反复前代回代」。当同一个 $A$ 要对付很多个右端 $\mathbf b$ 时（下一章、乃至最小二乘都会遇到），这个分解只算一次、反复用。下一节用清单把这一章的坑收个尾。

## 五、易错点

1. **只消系数矩阵、忘了右端**。消元必须对增广矩阵 $[A\ \ \mathbf b]$ 整行一起做，漏掉右端就解错。
2. **主元是 0 却不换行**。当前列主元为 0 时，先和下方某行交换（换到非零主元），不能硬除；交换行也是合法初等行变换。
3. **乘子写错位置或符号**。$R_i\gets R_i-cR_j$ 里，乘子进 $L$ 时取 $+c$（不是 $-c$），且放在第 $(i,j)$ 位置——把例 3 的 $L$ 反查一遍最稳妥。
4. **把「无解」和「无穷多解」混为一谈**。$0=k$ 是无解（矛盾），$0=0$ 是无穷多解（自由变量），两者天差地别。
5. **回代顺序颠倒**。上三角必须从最后一行往上代；先代第一行会因为未知数没消干净而出错。
